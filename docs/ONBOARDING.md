# 참여 안내 (멤버용)

자세한 사용법은 **레포 메인 [README](../README.md)** 에 화면과 함께 정리되어 있습니다. 여기는 처음 시작할 때 순서대로 확인하는 체크리스트입니다.

## 시작 체크리스트

1. [ ] 조직 `15th-algo-study` 초대 메일에서 **Join** (수락해야 PR 을 올릴 수 있습니다)
2. [ ] **Docker Desktop** 설치 후 실행 (`docker compose version` 이 동작) — README 1절
3. [ ] 레포 받기: `git clone` 또는 **Code → Download ZIP** — README 2절
4. [ ] 레포 폴더에서 `docker compose up --build` → <http://localhost:15015> — README 3절
5. [ ] 오른쪽 위 **GitHub 로그인** → 코드 입력 → Authorize — README 4절
6. [ ] (ZIP 으로 받았다면) **GitHub 저장소와 연결** 버튼 — README 5절
7. [ ] 1일차 lv0 를 풀고 **▶ 실행** → **제출** → PR 링크 확인 — README 7절
8. [ ] 1~2분 뒤 PR 이 자동 머지되고 **출석표**에 내 행이 생겼는지 확인 — README 9절

## 꼭 알아 둘 것

- **출석표 등록은 자동**입니다. 첫 PR 이 머지되는 날이 합류일이고, 그 전 날짜는 `-` 로 표시됩니다.
- 제출은 `solutions/<내 아이디>/` 아래 파일만 가능합니다. 앱이 알아서 그 경로에 저장·커밋·PR 까지 합니다.
- 해설과 다른 사람 풀이는 언제든 볼 수 있습니다. 보고 나서 직접 다시 짜서 제출하세요.
- 시간 제한은 CI(GitHub Actions) 기준입니다. 로컬 제출은 2배 여유를 두므로, 로컬에서 아슬아슬하게 통과한 풀이는 CI 에서 떨어질 수 있습니다. 그러면 PR 코멘트를 보고 고쳐서 다시 제출하면 됩니다.
- **레포는 public 입니다.** 풀이는 누구나 볼 수 있고 그대로 포트폴리오가 됩니다. 코드에 개인 정보를 넣지 마세요(README 12절).

막히면 README 11절 "문제가 생기면" 표를 먼저 보고, 없으면 Slack 에 물어보세요.
