# [lv3] 사막 캠프의 급수탑

곧게 뻗은 사막 도로를 따라 캠프 `n`개가 있습니다. `i`번 캠프의 위치(도로 시작점에서의 거리, 정수)는 `camps[i]`이며 **순서 없이** 주어지고, 같은 위치에 캠프가 여럿 있을 수도 있습니다.

도로 위 **정수 위치**에 급수탑을 최대 `k`개 세우려 합니다. 각 캠프는 가장 가까운 급수탑까지 물을 길으러 가는데, 이 거리를 그 캠프의 **급수 거리**라 합니다. 급수탑을 잘 배치해서 모든 캠프의 급수 거리 중 **최댓값을 가장 작게** 만들었을 때, 그 최댓값을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `camps`의 길이 `n` ≤ 200,000
- 0 ≤ `camps`의 원소 ≤ 1,000,000,000
- 1 ≤ `k` ≤ `n`
- 급수탑은 캠프와 같은 위치에 세워도 되고, 한 위치에 여러 개를 세워도 됩니다.

## 입출력 예

| camps | k | result |
|---|---|---|
| [1, 2, 8, 10, 13] | 2 | 3 |
| [0, 10] | 1 | 5 |
| [0, 1] | 1 | 1 |

## 입출력 예 설명
- 예 #1: 급수탑을 위치 2와 11에 세우면 급수 거리는 1, 0, 3, 1, 2로 최댓값이 3입니다. 최댓값을 2 이하로 만들려면 1·2번 캠프, 8·10번 캠프, 13번 캠프를 각각 따로 맡을 급수탑 3개가 필요하므로 불가능합니다.
- 예 #2: 가운데 5에 세우면 두 캠프 모두 거리 5입니다.
- 예 #3: 급수탑은 정수 위치에만 세울 수 있으므로 0 또는 1에 세워야 하고, 어느 쪽이든 한 캠프는 거리 1입니다.
