# 해설 — 사막 캠프의 급수탑

## 접근
답(최대 급수 거리) `r`을 직접 구하기는 어렵지만, **"`r`로 가능한가?"는 쉽게 판정**할 수 있습니다. 그리고 `r`로 가능하면 더 큰 `r`로도 당연히 가능하므로(단조성), 가능한 최소 `r`을 **답에 대한 이분 탐색(파라메트릭 서치)** 으로 찾습니다.

**판정 `check(r)`**: 캠프를 위치순으로 정렬해 두고, 아직 물을 못 받는 가장 왼쪽 캠프 `camps[i]`에 대해 급수탑을 `camps[i] + r`에 세웁니다(정수 위치). 이 탑은 `camps[i] .. camps[i] + 2r`을 덮으므로, 이 범위 안의 캠프를 모두 건너뛰고 다음 캠프로 갑니다. 탑 개수가 `k` 이하이면 가능합니다.

- 왜 그리디가 최선인가: 가장 왼쪽 캠프는 어떤 탑이든 덮어야 하고, 그 탑을 가능한 한 오른쪽(`camps[i] + r`)에 두는 것이 오른쪽 캠프를 가장 많이 덮습니다. 교환 논법으로 탑 수가 최소가 됩니다.
- 탐색 범위: `lo = 0`, `hi = ⌈(max − min) / 2⌉` (탑 하나를 가운데 두면 항상 가능).

## 주의할 점
- `camps[i] + 2r`은 최대 약 2 × 10^9로 `int`를 넘습니다. `long`으로 계산하세요.
- 같은 위치의 캠프는 한 탑이 함께 덮습니다. `<=` 비교로 자연스럽게 처리됩니다.
- `k ≥ 서로 다른 위치 수`이면 답은 0입니다. `lo = 0`부터 탐색하면 따로 처리할 필요가 없습니다.
- `r = 0, 1, 2, …`를 차례로 시도하는 풀이는 답이 수억인 large 케이스에서 시간 초과입니다. 이분 탐색은 판정을 약 30번만 호출합니다.

## 복잡도
- 시간 O(n log n + n log C) (C = 좌표 범위), 공간 O(1) (정렬 제외)
