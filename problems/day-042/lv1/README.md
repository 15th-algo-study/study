# [lv1] 진주 크기 등급 조회

진주 양식장에서 수확한 진주 `n`개의 지름(단위: 마이크로미터)이 배열 `sizes`에 **순서 없이** 담겨 있습니다. 보석상들이 각자 원하는 크기 범위를 문의합니다. `ranges[j] = [lo, hi]`는 "지름이 `lo` 이상 `hi` 이하인 진주가 몇 개인가"라는 질문입니다.

각 질문의 답을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `sizes`의 길이 `n` ≤ 200,000
- 1 ≤ `sizes`의 원소 ≤ 1,000,000,000 (같은 값 가능)
- 1 ≤ `ranges`의 길이 ≤ 200,000
- 0 ≤ `lo` ≤ `hi` ≤ 1,000,000,000

## 입출력 예

| sizes | ranges | result |
|---|---|---|
| [7, 3, 9, 3, 5] | [[3, 5], [6, 10], [4, 4]] | [3, 2, 0] |
| [10] | [[10, 10], [1, 9], [11, 20]] | [1, 0, 0] |
| [100, 50, 50, 75] | [[50, 50], [51, 99], [76, 100], [0, 49]] | [2, 1, 1, 0] |

## 입출력 예 설명
- 예 #1: 3 이상 5 이하는 3, 3, 5로 3개. 6 이상 10 이하는 7, 9로 2개. 정확히 4인 진주는 없습니다.
- 예 #2: 진주가 하나뿐이고 10입니다.
- 예 #3: 50은 두 개라 [50, 50]의 답이 2입니다.
