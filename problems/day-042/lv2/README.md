# [lv2] 양봉장 출하 가능일

양봉장에서 `n`일 동안 매일 채밀한 꿀의 양이 배열 `honey`에 담겨 있습니다. `honey[i]`는 `i`일(0번부터 셈)에 거둔 꿀의 양(그램)이고, 거두지 못한 날은 0입니다.

주문이 여러 건 들어옵니다. `orders[j] = [s, x]`는 "`s`일부터 거둔 꿀을 모아 두었다가 `x`그램이 되면 바로 출하한다"는 뜻입니다. 즉 `s`일부터 `d`일까지 거둔 꿀의 합(`s`일과 `d`일 포함)이 처음으로 `x` 이상이 되는 날 `d`에 출하합니다.

각 주문의 출하일 `d`를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 마지막 날(`n-1`일)까지 모아도 `x`그램이 안 되면 -1을 담습니다. 주문들은 서로 독립적입니다(한 주문이 꿀을 가져가도 다른 주문에 영향이 없습니다).

## 제한사항
- 1 ≤ `honey`의 길이 `n` ≤ 1,000,000
- 0 ≤ `honey`의 원소 ≤ 1,000,000,000
- 1 ≤ `orders`의 길이 ≤ 200,000
- 0 ≤ `s` ≤ `n - 1`, 1 ≤ `x` ≤ 1,000,000,000

## 입출력 예

| honey | orders | result |
|---|---|---|
| [3, 0, 5, 2, 4] | [[0, 8], [1, 5], [2, 20], [4, 4]] | [2, 2, -1, 4] |
| [1, 1, 1, 1, 1] | [[0, 5], [1, 5], [2, 3]] | [4, -1, 4] |
| [1000000000, 1000000000, 1000000000] | [[0, 1000000000], [2, 1000000000], [0, 1000000001]] | [0, 2, 1] |

## 입출력 예 설명
- 예 #1
  - [0, 8]: 0일부터 3 → 3 → 8이 되어 2일에 출하합니다.
  - [1, 5]: 1일부터 0 → 5가 되어 2일에 출하합니다.
  - [2, 20]: 2일부터 끝까지 모아도 5 + 2 + 4 = 11이라 -1입니다.
  - [4, 4]: 4일 하루에 4그램이 모여 당일 출하합니다.
- 예 #2: 매일 1그램씩이라 5그램은 0일부터 모아야 4일에 맞출 수 있고, 1일부터는 4그램뿐입니다.
- 예 #3: 하루 수확이 10억 그램인 경우, 합이 `int` 범위를 넘습니다.
