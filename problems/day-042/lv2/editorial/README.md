# 해설 — 양봉장 출하 가능일

## 접근
주문마다 `s`일부터 하루씩 더해 가면 한 주문에 O(n), 전체 O(nq)로 large에서 수백억 번이라 시간 초과입니다.

누적합 `P[i] = honey[0] + … + honey[i-1]` (`P[0] = 0`)을 만들면 "`s`일부터 `d`일까지의 합"은 `P[d+1] − P[s]`입니다. 조건 `P[d+1] − P[s] ≥ x`는 `P[d+1] ≥ P[s] + x`이고, 수확량이 음수가 아니므로 **`P`는 단조 증가(같은 값 가능)** 합니다. 따라서

> `P[1..n]`에서 `P[s] + x` 이상인 첫 위치 `i`를 이분 탐색(lower bound)으로 찾고, 답은 `d = i − 1`

입니다. 그런 `i`가 없으면(모든 값이 작으면) -1입니다. `s`일부터 시작하므로 탐색 범위는 `i ∈ [s + 1, n]`로 두어도 되고, `P[s] + x > P[s]`이므로 `[1, n]` 전체를 탐색해도 자동으로 `i ≥ s + 1`이 됩니다.

## 주의할 점
- 누적합은 최대 10^6 × 10^9 = 10^15이므로 반드시 `long`입니다. `P[s] + x`도 `long`으로 계산하세요.
- 수확량이 0인 날이 있어 `P`에 같은 값이 반복됩니다. "처음으로 `x` 이상이 되는 날"이므로 **lower bound**(이상인 첫 위치)를 써야 합니다. 같은 값 중 뒤쪽을 고르면 출하일이 늦어집니다.
- 당일 수확만으로 충족되면 답은 `s` 자신입니다 (예 #1의 마지막 주문).

## 복잡도
- 시간 O(n + q log n), 공간 O(n)
