# 해설 — 헬스장 회원 번호 조회

## 접근
질의마다 배열을 처음부터 훑으면 20만 × 20만 = 4 × 10^10번 비교라 시간 초과입니다. 배열이 **정렬되어 있고 중복이 없으므로** 자바가 제공하는 이분 탐색 `java.util.Arrays.binarySearch(members, x)`를 그대로 쓰면 됩니다.

- 값이 있으면 그 인덱스를 돌려줍니다.
- 없으면 음수 `-(삽입 위치) - 1`을 돌려줍니다. 이 문제에서는 "음수이면 -1"로 바꿔 담으면 됩니다.

## 주의할 점
- `binarySearch`는 **정렬된 배열**에서만 올바르게 동작합니다. 이 문제는 정렬을 보장합니다.
- 값이 없을 때 돌아오는 음수는 -1이 아닐 수 있습니다 (예: 삽입 위치가 2이면 -3). `< 0`으로 판정하세요.
- 같은 값이 여러 개 있으면 어느 인덱스를 돌려줄지 정해져 있지 않지만, 이 문제는 중복이 없으므로 괜찮습니다.

## 복잡도
- 시간 O(q log n), 공간 O(q)
