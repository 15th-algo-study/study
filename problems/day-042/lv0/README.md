# [lv0] 헬스장 회원 번호 조회

헬스장 출입문 단말기에는 등록된 회원 번호가 **오름차순**으로, 중복 없이 배열 `members`에 저장되어 있습니다. 출입을 시도한 사람들이 입력한 번호가 순서대로 `queries`에 담겨 있습니다.

각 입력 번호에 대해 그 번호가 `members`의 몇 번 인덱스(0번부터 셈)에 있는지를 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 등록되지 않은 번호이면 -1을 담습니다.

## 제한사항
- 1 ≤ `members`의 길이 ≤ 200,000
- 1 ≤ `members`의 원소 ≤ 1,000,000,000, 오름차순이며 서로 다릅니다
- 0 ≤ `queries`의 길이 ≤ 200,000
- 1 ≤ `queries`의 원소 ≤ 1,000,000,000

## 입출력 예

| members | queries | result |
|---|---|---|
| [1001, 1005, 1010] | [1005, 1002, 1010] | [1, -1, 2] |
| [3] | [3, 4] | [0, -1] |
| [10, 20, 30, 40] | [40, 10, 25] | [3, 0, -1] |

## 입출력 예 설명
- 예 #1: 1005는 1번, 1010은 2번 인덱스에 있고 1002는 등록되어 있지 않습니다.
- 예 #2: 회원이 한 명뿐입니다.
- 예 #3: 25는 20과 30 사이의 값이지만 등록된 번호가 아닙니다.
