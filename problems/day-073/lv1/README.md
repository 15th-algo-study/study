# [lv1] 조각보의 대칭 구간

전통 조각보 공방에서 색 천 조각을 한 줄로 이어 붙인 긴 띠를 만들었습니다. 띠의 색 배열은 문자열 `strip`으로 주어지며, 알파벳 소문자 하나가 천 조각 하나의 색입니다.

띠에서 **연속한** 조각 몇 개를 잘라 냈을 때, 잘라 낸 조각들의 색 순서를 왼쪽에서 읽어도 오른쪽에서 읽어도 같으면 그 구간을 **대칭 구간**이라고 부릅니다.

- 조각 하나짜리 구간도 대칭 구간입니다.
- 색 순서가 같더라도 띠에서의 위치(시작 위치나 끝 위치)가 다르면 다른 구간으로 셉니다.

`strip`에 있는 **대칭 구간의 개수**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `strip`의 길이 ≤ 10,000
- `strip`은 알파벳 소문자로만 이루어져 있습니다.

## 입출력 예

| strip | result |
|---|---|
| "aba" | 4 |
| "aaa" | 6 |
| "abacaba" | 12 |

## 입출력 예 설명
- 예 #1: 한 조각짜리 `a`, `b`, `a` 세 개와 `aba` 하나로 4개입니다.
- 예 #2: 한 조각짜리 3개, `aa` 2개(앞쪽·뒤쪽), `aaa` 1개로 6개입니다.
- 예 #3: 한 조각짜리 7개, 세 조각짜리 `aba`, `aca`, `aba` 3개, 다섯 조각짜리 `bacab` 1개, 전체 `abacaba` 1개로 12개입니다.
