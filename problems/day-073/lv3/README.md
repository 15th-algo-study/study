# [lv3] 필사본 대조

옛 문헌을 손으로 베껴 쓴 필사본이 원본과 얼마나 다른지 확인하려고 합니다. 원본은 문자열 `original`, 필사본은 문자열 `copy`입니다. 필사가는 다음 세 가지 실수를 할 수 있습니다.

- 원본의 글자 하나를 **빠뜨림** (필사본에 없음)
- 원본에 없는 글자 하나를 **끼워 넣음**
- 원본의 글자 하나를 **다른 글자로 잘못 씀**

실수 하나는 1회로 셉니다. `original`을 `copy`로 바꾸는 데 필요한 **최소 실수 횟수**를 구하려고 합니다. 다만 감정사는 실수가 `k`회를 넘는 필사본은 위작으로 보고 정확한 횟수를 따지지 않습니다.

최소 실수 횟수가 `k` 이하이면 그 횟수를, `k`보다 크면 -1을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `original`의 길이, `copy`의 길이 ≤ 200,000
- `original`과 `copy`는 알파벳 소문자로만 이루어져 있습니다.
- 0 ≤ `k` ≤ 100

## 입출력 예

| original | copy | k | result |
|---|---|---|---|
| "manuscript" | "manuscrpit" | 2 | 2 |
| "kingdom" | "kingdoms" | 0 | -1 |
| "abcdefgh" | "abxdefh" | 3 | 2 |

## 입출력 예 설명
- 예 #1: 끝의 `ipt`를 `pit`로 잘못 썼습니다. `i`→`p`, `p`→`i` 두 번의 잘못 쓰기(또는 빠뜨림 1 + 끼워 넣음 1)로 설명할 수 있고, 한 번으로는 불가능합니다. 2 ≤ 2이므로 2입니다.
- 예 #2: `s`를 끼워 넣은 실수 1회가 있는데 `k = 0`이므로 -1입니다.
- 예 #3: `c`를 `x`로 잘못 쓰고 `g`를 빠뜨렸습니다. 2회입니다.
