# 해설 — 필사본 대조

## 접근
최소 실수 횟수는 두 문자열의 **편집 거리**입니다. 보통은 `dist[i][j]`(원본 앞 `i`글자 → 필사본 앞 `j`글자) 표를 모두 채우지만, 길이가 20만이면 4×10^10칸이라 시간 초과입니다.

**관찰**: 답이 `k` 이하인지만 알면 됩니다. 원본 앞 `i`글자를 필사본 앞 `j`글자로 맞추려면 길이 차이만큼은 빠뜨리거나 끼워 넣어야 하므로 `dist[i][j] ≥ |i − j|`입니다. 그리고 최종 답까지 가는 최적 경로 위의 칸들은 값이 답 이하입니다. 따라서

> 답이 `k` 이하라면, 최적 경로는 `|i − j| ≤ k`인 칸만 지난다.

그러므로 대각선 주변 폭 `2k + 1`의 **띠**만 계산하면 됩니다. 띠 바깥 칸은 "k보다 큼"으로 취급합니다.

- 먼저 `|n − m| > k`이면 바로 -1입니다.
- 행 `i`에서는 `j = i − k … i + k`만 계산합니다. 열 번호 대신 대각선 기준 위치 `d = j − i + k`(0 … 2k)로 저장하면 한 행이 길이 `2k + 1`인 배열이 됩니다.
  - 잘못 씀/일치: 윗행의 같은 `d` (`(i−1, j−1)`)
  - 빠뜨림: 윗행의 `d + 1` (`(i−1, j)`)
  - 끼워 넣음: 같은 행의 `d − 1` (`(i, j−1)`)
- 값이 `k`를 넘으면 `k + 1`로 잘라 두면 충분합니다. 한 행 전체가 `k + 1`이 되면 더 볼 필요 없이 -1입니다.

마지막으로 `(n, m)` 칸의 값이 `k` 이하면 그 값, 아니면 -1입니다.

## 주의할 점
- 띠 위치 `d`에 대응하는 `j`가 0보다 작거나 `m`보다 크면 존재하지 않는 칸이므로 "무한대(`k + 1`)"로 둡니다. 0행(`dist[0][j] = j`)과 0열(`dist[i][0] = i`)의 초깃값도 띠 안에서 처리해야 합니다.
- 윗행에서 `d + 1`은 열이 같은 칸, `d`는 열이 하나 왼쪽인 칸입니다. 일반 표와 이웃 위치가 달라지니 그림을 그려 확인하세요.
- 일반 편집 거리 표를 모두 채우는 풀이는 O(n × m) = 4×10^10으로 시간 초과입니다. 띠 풀이는 O(n × k) ≈ 4×10^7입니다.
- `k = 0`이면 두 문자열이 완전히 같은지만 보는 것과 같습니다.

## 복잡도
- 시간 O(n × k), 공간 O(k)
