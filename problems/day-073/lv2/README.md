# [lv2] 코스 요리 고르기

한 레스토랑은 손님이 코너별로 요리를 골라 자기만의 코스를 짜는 방식으로 운영합니다. 메뉴판은 2차원 배열 `menus`로 주어지며, `menus[i] = [corner, price, joy]`는 `corner`번 코너의 요리 하나가 가격 `price`원이고 먹으면 만족도 `joy`를 준다는 뜻입니다.

- 한 코너에서는 요리를 **최대 한 가지**만 고를 수 있습니다. 코너를 통째로 건너뛰어도 됩니다.
- 고른 요리 가격의 합이 예산 `budget`원 이하여야 합니다.

고른 요리들의 **만족도 합의 최댓값**을 return 하도록 `solution` 함수를 완성해 주세요. 아무 요리도 고를 수 없으면 0을 return 합니다.

## 제한사항
- 1 ≤ `menus`의 길이 ≤ 1,000
- `menus[i]`는 `[corner, price, joy]` 형태입니다.
  - 1 ≤ `corner` ≤ 1,000
  - 1 ≤ `price` ≤ 10,000
  - 1 ≤ `joy` ≤ 10,000
- `menus`는 코너 번호 순으로 정렬되어 있지 않을 수 있습니다.
- 1 ≤ `budget` ≤ 10,000

## 입출력 예

| menus | budget | result |
|---|---|---|
| [[1, 3, 5], [1, 5, 8], [2, 4, 6], [2, 2, 3], [3, 3, 4]] | 10 | 15 |
| [[1, 5, 10]] | 4 | 0 |
| [[7, 2, 3], [7, 3, 4], [7, 4, 6]] | 9 | 6 |

## 입출력 예 설명
- 예 #1: 1번 코너의 (5원, 8), 2번 코너의 (2원, 3), 3번 코너의 (3원, 4)를 고르면 10원에 만족도 15입니다. 1번 코너의 (3원, 5), 2번 코너의 (4원, 6), 3번 코너를 고르는 방법도 15입니다. 1번 코너의 두 요리를 함께 고를 수는 없습니다.
- 예 #2: 예산 4원으로는 아무것도 고를 수 없습니다.
- 예 #3: 모두 7번 코너라 하나만 고를 수 있으므로 만족도가 가장 큰 (4원, 6)을 고릅니다.
