# [lv2] 불꽃놀이 발사 순서

불꽃놀이 쇼에서 불꽃 `n`발을 한 발씩 차례로 쏘려 합니다. 불꽃의 색은 `k`가지이며 알파벳 소문자 `'a'`부터 `k`번째 글자까지로 나타냅니다. 같은 색을 여러 번 써도 됩니다.

다만 어떤 색 바로 다음에 어떤 색을 쏘면 보기에 어색합니다. 어색한 조합 목록 `banned`의 원소 `"xy"`는 색 `x` 불꽃 **바로 다음에** 색 `y` 불꽃을 쏘면 안 된다는 뜻입니다. `x`와 `y`가 같을 수도 있으며, 그러면 그 색을 연달아 쏠 수 없습니다.

가능한 발사 순서(색을 쏘는 차례의 나열)의 수를 1,000,000,007로 나눈 나머지를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 100,000
- 1 ≤ `k` ≤ 26
- 0 ≤ `banned`의 길이 ≤ 10,000
- `banned`의 원소는 길이 2인 문자열이며, 두 글자 모두 `'a'`부터 `k`번째 글자 사이의 소문자입니다.
- `banned`에 같은 조합이 여러 번 들어 있을 수 있습니다.

## 입출력 예

| n | k | banned | result |
|---|---|---|---|
| 3 | 2 | ["aa"] | 5 |
| 2 | 3 | ["ab", "ba", "cc"] | 6 |
| 4 | 3 | [] | 81 |

## 입출력 예 설명
- 예 #1: 색 a, b로 3발을 쏘는 8가지 중 a를 연달아 쏘는 aaa, aab, baa를 빼면 aba, abb, bab, bba, bbb의 5가지입니다.
- 예 #2: 2발을 쏘는 9가지 중 ab, ba, cc를 뺀 6가지입니다.
- 예 #3: 금지된 조합이 없으므로 3^4 = 81가지입니다.
