# 해설 — 불꽃놀이 발사 순서

## 접근
모든 순서는 k^n가지라 하나씩 확인할 수 없습니다. 그런데 다음 불꽃으로 어떤 색을 쏠 수 있는지는 **바로 앞 불꽃의 색**에만 달려 있습니다. 그래서 "지금까지 몇 발을 쐈고, 마지막 색이 무엇인가"를 상태로 잡습니다.

- `end[c]` = 지금까지 쏜 순서 중 마지막 색이 `c`인 것의 수
- 1발일 때: 모든 `c`에 대해 `end[c] = 1`
- 한 발 더 쏠 때: `next[y] = Σ end[x]` (x 다음 y가 금지되지 않은 모든 x)

이것을 `n - 1`번 반복하고 마지막 `end`를 모두 더하면 답입니다. 한 번 갱신에 O(k²)이라 전체 O(n·k²) ≈ 6.8 × 10^7번으로 충분히 빠릅니다.

금지 목록은 `boolean[k][k]` 표로 바꿔 두면 `x`, `y` 쌍마다 O(1)에 확인할 수 있습니다. 같은 조합이 여러 번 나와도 표에는 한 번만 표시되므로 따로 처리할 것이 없습니다.

## 주의할 점
- 갱신할 때 `end`를 바로 덮어쓰면 아직 쓰지 않은 이전 값이 바뀝니다. 새 배열 `next`에 계산한 뒤 바꿔치기하세요.
- `end[x]`를 최대 26개 더하면 약 2.6 × 10^10이라 `int`를 넘습니다. `long`으로 더하고 나머지를 구합니다.
- "전체 합에서 금지된 것만 빼기"(`next[y] = total − Σ end[x] (금지된 x)`)로 계산해도 됩니다. 이때는 같은 금지 조합을 두 번 빼지 않도록 반드시 중복을 없앤 표를 쓰고, 뺄셈 뒤 음수를 양수로 맞춰야 합니다.
- `n = 1`이면 금지 조합과 상관없이 답은 `k`입니다.

## 복잡도
- 시간 O(n·k² + 금지 조합 수), 공간 O(k²)
