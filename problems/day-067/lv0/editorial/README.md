# 해설 — 화살표 보드

## 접근
칸마다 말을 직접 움직여 세면, 화살표가 모두 1일 때 0번 칸 하나만 해도 n번을 움직여야 합니다. 모든 칸을 그렇게 하면 약 n²/2 = 200억 번이라 너무 느립니다.

**관찰**: `i`번 칸에서 출발한 말은 첫 이동으로 `j = i + arrows[i]`번 칸에 가고, 그다음부터는 **`j`번 칸에서 출발한 말과 똑같이** 움직입니다. 그러므로

- `j ≥ n`이면 `moves[i] = 1`
- 아니면 `moves[i] = 1 + moves[j]`

입니다. `j`는 항상 `i`보다 크므로, **뒤쪽 칸부터** 답을 구해 배열에 적어 두면(메모) 앞쪽 칸의 답을 한 번의 계산으로 얻을 수 있습니다.

```java
for (int i = n - 1; i >= 0; i--) {
    int j = i + arrows[i];
    moves[i] = (j >= n) ? 1 : 1 + moves[j];
}
```

## 주의할 점
- 반복 방향이 중요합니다. 앞에서부터 채우면 `moves[j]`가 아직 비어 있습니다.
- `i + arrows[i]`는 최대 약 40만이라 `int`로 충분합니다. 다만 배열 범위를 넘는지 먼저 확인한 뒤에 `moves[j]`를 읽어야 합니다.

## 복잡도
- 시간 O(n), 공간 O(n)
