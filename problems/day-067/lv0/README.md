# [lv0] 화살표 보드

칸 `n`개가 일렬로 놓인 보드게임 판이 있습니다. 칸 번호는 0번부터 `n - 1`번까지이고, `i`번 칸에는 앞쪽(번호가 커지는 쪽)으로 `arrows[i]`칸을 가리키는 화살표가 그려져 있습니다.

말이 `i`번 칸에 있으면 화살표를 따라 `i + arrows[i]`번 칸으로 한 번 이동합니다. 이동한 칸의 번호가 `n` 이상이면 말은 판 밖으로 나가고 놀이가 끝납니다. 판 안의 칸에 도착했다면 그 칸의 화살표를 따라 또 이동합니다.

각 칸에서 말을 출발시켰을 때 판 밖으로 나갈 때까지 이동하는 횟수를, 출발 칸 번호 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `arrows`의 길이 `n` ≤ 200,000
- 1 ≤ `arrows[i]` ≤ 200,000

## 입출력 예

| arrows | result |
|---|---|
| [2, 1, 1, 3] | [3, 3, 2, 1] |
| [1, 1, 1, 1, 1] | [5, 4, 3, 2, 1] |
| [5, 4, 3] | [1, 1, 1] |

## 입출력 예 설명
- 예 #1
  - 3번 칸 → 6번(판 밖): 1번
  - 2번 칸 → 3번 칸 → 판 밖: 2번
  - 1번 칸 → 2번 칸 → 3번 칸 → 판 밖: 3번
  - 0번 칸 → 2번 칸 → 3번 칸 → 판 밖: 3번
- 예 #2: 한 칸씩 움직이므로 `i`번 칸에서는 `5 - i`번 이동합니다.
- 예 #3: 어느 칸에서든 한 번에 판 밖으로 나갑니다.
