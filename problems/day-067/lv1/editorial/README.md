# 해설 — 미술관 관람 동선

## 접근
동선을 하나씩 따라가며 세면(DFS) 동선의 수만큼 시간이 걸립니다. 1000×1000 격자에서 동선은 천문학적으로 많아 끝나지 않습니다.

`ways[r][c]`를 "입구에서 (r, c)까지 오는 동선 수"라고 합시다. (r, c)에 들어오는 마지막 한 걸음은 위쪽 (r-1, c)에서 내려오거나 왼쪽 (r, c-1)에서 오는 것 둘 중 하나이고, 두 경우는 겹치지 않습니다. 그러므로

- `ways[r][c] = ways[r-1][c] + ways[r][c-1]` (범위 밖은 0)
- 공사 중인 방은 `ways = 0`
- `ways[0][0] = 1` (입구가 공사 중이면 0)

위쪽 줄부터, 한 줄 안에서는 왼쪽부터 채우면 필요한 두 값이 항상 먼저 계산되어 있습니다. 답은 `ways[R-1][C-1]`입니다.

## 주의할 점
- 동선 수는 매우 커지므로 더할 때마다 1,000,000,007로 나눈 나머지를 저장합니다. 두 값의 합은 약 2 × 10^9로 `int`를 넘을 수 있으니 `long`으로 더하거나, 더한 뒤 바로 나머지를 구할 때 오버플로가 나지 않게 주의하세요.
- 공사 중인 방은 "0으로 두고 건너뛰기"만 하면 그 방을 지나는 동선이 자동으로 빠집니다.
- 줄 하나짜리 배열 `ways[c]`를 위에서 아래로 덮어쓰며 갱신해도 됩니다(`ways[c] += ways[c-1]`).

## 복잡도
- 시간 O(R × C), 공간 O(R × C) (한 줄 배열이면 O(C))
