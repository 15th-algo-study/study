# [lv1] 미술관 관람 동선

미술관의 전시실이 격자 모양으로 배치되어 있습니다. 배치도 `rooms`의 `r`번째 문자열의 `c`번째 문자가 (r, c) 전시실을 나타내며, `.`은 관람할 수 있는 방, `#`은 공사 중이라 들어갈 수 없는 방입니다.

관람객은 입구가 있는 (0, 0) 방에서 출발해 출구가 있는 오른쪽 아래 끝 방까지 갑니다. 관람 동선이 엉키지 않도록 한 번에 **오른쪽 또는 아래쪽**으로 붙어 있는 방으로만 이동할 수 있습니다.

입구에서 출구까지 가는 서로 다른 동선의 수를 1,000,000,007로 나눈 나머지를 return 하도록 `solution` 함수를 완성해 주세요. 입구나 출구 방이 공사 중이면 0을 return 합니다.

## 제한사항
- 1 ≤ `rooms`의 길이 ≤ 1,000
- 1 ≤ `rooms[r]`의 길이 ≤ 1,000이며, 모든 문자열의 길이는 같습니다.
- `rooms`는 `.`과 `#`으로만 이루어져 있습니다.

## 입출력 예

| rooms | result |
|---|---|
| ["...", "...", "..."] | 6 |
| ["..#", "...", "#.."] | 4 |
| [".#", "#."] | 0 |

## 입출력 예 설명
- 예 #1: 오른쪽 2번, 아래쪽 2번을 늘어놓는 방법의 수와 같아 6가지입니다.
- 예 #2: 6가지 중 (0, 2)를 지나는 "오른쪽, 오른쪽, 아래, 아래"와 (2, 0)을 지나는 "아래, 아래, 오른쪽, 오른쪽"이 막혀 4가지입니다.
- 예 #3: 입구에서 오른쪽과 아래쪽 방이 모두 공사 중입니다.
