# [lv2] 스프레드시트 정렬 되감기

스프레드시트에 `n`개의 행이 있고, 각 행은 정수 `m`개로 이루어져 있습니다. 행의 내용은 2차원 배열 `rows`로 주어지며, 처음에는 `rows[0]`, `rows[1]`, …, `rows[n-1]` 순서로 놓여 있습니다.

사용자가 열 머리글을 눌러 정렬한 기록이 문자열 배열 `commands`로 주어집니다. 각 명령은 `"c asc"` 또는 `"c desc"` 형식이고, `c`번 열(0번부터 셈)을 기준으로 **현재 순서**의 행들을 오름차순(`asc`) 또는 내림차순(`desc`)으로 정렬한다는 뜻입니다. 스프레드시트의 정렬은 **안정 정렬**입니다. 즉, 기준 열의 값이 같은 행들은 정렬 직전의 상대적 순서를 그대로 유지합니다.

모든 명령을 순서대로 적용한 뒤의 행 순서를, **원래 행 번호**의 배열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `rows`의 길이 `n` ≤ 100,000
- 1 ≤ `rows[i]`의 길이 `m` ≤ 5, 모든 행의 길이는 같습니다.
- -1,000,000,000 ≤ `rows[i][j]` ≤ 1,000,000,000
- 0 ≤ `commands`의 길이 ≤ 100,000
- 각 명령은 `"c asc"` 또는 `"c desc"` 형식이고 0 ≤ `c` < `m` 입니다.

## 입출력 예

| rows | commands | result |
|---|---|---|
| [[3, 1], [1, 2], [2, 1], [1, 1]] | ["1 desc", "0 asc"] | [1, 3, 2, 0] |
| [[5], [2], [9]] | [] | [0, 1, 2] |
| [[1, 1], [1, 1], [1, 1]] | ["0 desc", "1 asc", "0 asc"] | [0, 1, 2] |

## 입출력 예 설명
- 예 #1
  - `"1 desc"`: 1번 열 기준 내림차순. 값 2인 1번 행이 앞으로 가고, 값 1인 0, 2, 3번 행은 원래 순서를 유지합니다 → [1, 0, 2, 3]
  - `"0 asc"`: 0번 열 기준 오름차순. 값 1인 행은 1번과 3번인데 직전 순서에서 1번이 앞이므로 그대로, 이어서 값 2인 2번, 값 3인 0번 → **[1, 3, 2, 0]**
- 예 #2: 명령이 없으면 처음 순서 그대로입니다.
- 예 #3: 모든 값이 같으므로 어떤 정렬을 해도 순서가 바뀌지 않습니다.
