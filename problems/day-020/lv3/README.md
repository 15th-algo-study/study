# [lv3] 소풍 돗자리 넓이

넓은 잔디밭을 좌표평면으로 보고, 소풍 온 사람들이 직사각형 돗자리를 `n`장 깔았습니다. `i`번 돗자리의 정보는 `mats[i] = [x, y, w, h]` 로, 왼쪽 아래 꼭짓점이 `(x, y)`이고 가로 길이 `w`, 세로 길이 `h` 인 축에 평행한 직사각형입니다. 즉 `x ≤ X < x + w`, `y ≤ Y < y + h` 인 영역을 덮습니다.

돗자리는 서로 겹쳐 깔려 있을 수 있습니다. **돗자리가 한 장이라도 깔린 잔디밭의 총 넓이**를 return 하도록 `solution` 함수를 완성해 주세요. 넓이는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `mats`의 길이 `n` ≤ 5,000
- `mats[i]`의 길이는 4입니다.
- 0 ≤ `x`, `y`
- 1 ≤ `w`, `h`
- `x + w` ≤ 1,000,000,000, `y + h` ≤ 1,000,000,000

## 입출력 예

| mats | result |
|---|---|
| [[0, 0, 4, 3], [2, 1, 4, 3]] | 20 |
| [[0, 0, 10, 10], [2, 2, 3, 3]] | 100 |
| [[0, 0, 1, 1], [1, 1, 1, 1]] | 2 |

## 입출력 예 설명
- 예 #1: 두 돗자리의 넓이는 각각 12이고, 겹치는 부분은 `2 ≤ X < 4`, `1 ≤ Y < 3` 인 넓이 4입니다. 12 + 12 − 4 = **20**.
- 예 #2: 작은 돗자리가 큰 돗자리 안에 완전히 들어 있어 100입니다.
- 예 #3: 두 돗자리는 꼭짓점 한 점에서만 만나므로 겹치는 넓이는 0이고 합은 2입니다.
