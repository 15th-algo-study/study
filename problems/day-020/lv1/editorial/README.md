# 해설 — 듀엣 짝 정하기

## 접근
두 배열을 각각 오름차순으로 정렬한 뒤 **같은 순번끼리** 짝지으면 차이의 합이 최소입니다.

**왜 그런가 (교환 논법)**: 소프라노 `a ≤ b`, 알토 `c ≤ d`가 있을 때, 엇갈려 짝지은 `|a − d| + |b − c|`는 순서대로 짝지은 `|a − c| + |b − d|`보다 작아질 수 없습니다. 네 수를 수직선에 놓고 경우를 나눠 보면 엇갈린 짝은 항상 같은 구간을 두 번 이상 덮기 때문입니다. 엇갈린 쌍이 있으면 풀어서 손해 없이 바꿀 수 있으므로, 결국 모두 순서대로 짝지은 상태가 최적입니다.

1. `Arrays.sort(sopranos)`, `Arrays.sort(altos)`
2. `Σ |sopranos[i] − altos[i]|`를 `long`으로 누적합니다.

## 주의할 점
- 차이 하나는 최대 10^9 − 1 이지만 20만 개를 더하면 약 2×10^14 라 **`long`** 이 필요합니다. 누적 변수를 `int`로 두면 large 케이스에서 틀립니다.
- 절댓값은 `Math.abs(a - b)` 로 구합니다. 두 값 모두 양수이고 10^9 이하이므로 뺄셈 자체는 넘치지 않습니다.
- "입력 순서대로 가장 가까운 상대를 가져가는" 탐욕은 틀립니다. 소프라노 [10, 1], 알토 [8, 12]에서 10이 먼저 8을 가져가면(차이 2) 1은 12와 짝이 되어(차이 11) 합이 13이지만, 정렬해서 (1, 8), (10, 12)로 짝지으면 7 + 2 = 9입니다.

## 복잡도
- 시간 O(n log n), 공간 O(1)
