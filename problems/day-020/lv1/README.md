# [lv1] 듀엣 짝 정하기

합창단의 소프라노 파트 `n`명과 알토 파트 `n`명이 듀엣 무대를 꾸밉니다. 소프라노 한 명과 알토 한 명이 한 쌍이 되며, 모든 단원은 정확히 한 쌍에만 속합니다.

무대 위에서 보기 좋도록 **쌍을 이룬 두 사람의 키 차이**를 작게 만들고 싶습니다. 소프라노의 키 배열 `sopranos`와 알토의 키 배열 `altos`가 주어질 때, 모든 쌍의 키 차이(절댓값)의 합이 **최소**가 되도록 짝을 지을 때의 그 합을 return 하도록 `solution` 함수를 완성해 주세요. 합은 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `sopranos`의 길이 = `altos`의 길이 = `n` ≤ 200,000
- 1 ≤ 키 ≤ 1,000,000,000

## 입출력 예

| sopranos | altos | result |
|---|---|---|
| [160, 175, 168] | [170, 158, 181] | 10 |
| [150, 150] | [190, 190] | 80 |
| [1, 1000000000] | [1000000000, 1] | 0 |

## 입출력 예 설명
- 예 #1: (160, 158), (168, 170), (175, 181)로 짝지으면 차이가 2 + 2 + 6 = **10**입니다. 다른 어떤 방법도 이보다 작을 수 없습니다.
- 예 #2: 어떻게 짝지어도 쌍마다 40씩 차이 나므로 80입니다.
- 예 #3: 키가 같은 사람끼리 짝지으면 0입니다.
