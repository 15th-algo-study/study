# 해설 — 별 목록 정렬

## 접근
2차원 배열 `int[][]`는 "`int[]`를 원소로 갖는 배열"이므로 `Arrays.sort(stars, 비교자)`로 **행 단위** 정렬이 가능합니다. 비교자는 두 행 `a`, `b`를 받아 `x`를 먼저, 같으면 `y`를 비교합니다.

```java
Arrays.sort(stars, (a, b) -> {
    if (a[0] != b[0]) return Integer.compare(a[0], b[0]);
    return Integer.compare(a[1], b[1]);
});
```

## 주의할 점
- **`a[0] - b[0]`으로 비교하면 안 됩니다.** 좌표가 -10^9 ~ 10^9 이므로 뺄셈 결과가 최대 2×10^9 로 `int` 범위를 넘어 부호가 뒤집힙니다. 반드시 `Integer.compare`를 쓰세요. 이 문제의 large 케이스는 바로 이 실수를 걸러냅니다.
- `Arrays.sort(int[][])`처럼 비교자 없이 호출하면 `int[]`끼리 비교하는 방법을 몰라 예외가 납니다.
- `x`가 같을 때 `y`를 비교하는 두 번째 기준을 빠뜨리지 마세요.

## 복잡도
- 시간 O(n log n), 공간 O(n)
