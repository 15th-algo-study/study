# [lv0] 별 목록 정렬

천문대에서 관측한 별들의 위치가 2차원 배열 `stars`로 주어집니다. `stars[i] = [x, y]`는 `i`번 별의 가로 좌표 `x`와 세로 좌표 `y`입니다.

별 목록을 다음 규칙으로 정렬한 결과를 return 하도록 `solution` 함수를 완성해 주세요.

1. `x`가 작은 별이 앞에 옵니다.
2. `x`가 같으면 `y`가 작은 별이 앞에 옵니다.

좌표가 완전히 같은 별이 여러 개 있을 수 있으며, 그 경우 어느 것이 앞에 와도 결과 배열은 같습니다.

## 제한사항
- 1 ≤ `stars`의 길이 ≤ 200,000
- `stars[i]`의 길이는 2입니다.
- -1,000,000,000 ≤ `x`, `y` ≤ 1,000,000,000

## 입출력 예

| stars | result |
|---|---|
| [[3, 1], [1, 5], [1, 2], [2, 9]] | [[1, 2], [1, 5], [2, 9], [3, 1]] |
| [[0, 0], [-1, 7], [0, -3]] | [[-1, 7], [0, -3], [0, 0]] |

## 입출력 예 설명
- 예 #1: `x`가 1인 두 별은 `y`가 작은 [1, 2]가 먼저입니다.
- 예 #2: 음수 좌표도 그대로 수의 크기로 비교합니다. `x`가 0인 두 별은 `y`가 -3인 쪽이 먼저입니다.
