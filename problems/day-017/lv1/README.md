# [lv1] 화분과 받침

화분 가게에 화분과 물받침이 여러 개 있습니다. 화분의 지름은 배열 `pots`에, 물받침의 지름은 배열 `saucers`에 담겨 있습니다.

- 물받침의 지름이 화분의 지름 **이상**이면 그 물받침을 화분 아래에 받칠 수 있습니다.
- 화분 하나에는 물받침 하나만 받치고, 물받침 하나는 화분 하나에만 씁니다.

물받침을 받친 화분의 수가 **최대**가 되도록 짝을 지을 때, 그 최대 개수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `pots`의 길이 ≤ 200,000
- 1 ≤ `saucers`의 길이 ≤ 200,000
- 1 ≤ `pots`, `saucers`의 원소 ≤ 1,000,000,000

## 입출력 예

| pots | saucers | result |
|---|---|---|
| [15, 10, 25] | [12, 30, 9, 16] | 3 |
| [20, 20, 20] | [19, 20] | 1 |
| [8, 9] | [7] | 0 |

## 입출력 예 설명
- 예 #1: 화분 10에 받침 12, 화분 15에 받침 16, 화분 25에 받침 30을 쓰면 세 화분 모두 받칠 수 있습니다. 받침 9는 쓰이지 않습니다.
- 예 #2: 지름 20 이상인 받침은 하나뿐이므로 한 화분만 받칠 수 있습니다.
- 예 #3: 받침 7은 어느 화분보다도 작습니다.
