# 해설 — 화분과 받침

## 접근
두 배열을 모두 오름차순으로 정렬한 뒤 **투 포인터**로 짝을 짓습니다.

- `i`: 아직 받침이 없는 화분 중 가장 작은 것, `j`: 아직 쓰지 않은 받침 중 가장 작은 것
- `saucers[j] ≥ pots[i]` 이면 짝을 짓고 `i`, `j`를 모두 다음으로 옮깁니다.
- 그렇지 않으면 받침 `j`는 (남은 화분이 모두 `pots[i]` 이상이므로) 어느 화분에도 못 쓰니 버리고 `j`만 옮깁니다.

**왜 최대인가**: 가장 작은 화분에는 "그 화분을 받칠 수 있는 가장 작은 받침"을 주는 것이 손해가 없습니다. 더 큰 받침을 주면 나중에 큰 화분이 쓸 받침만 줄어들기 때문입니다.

## 주의할 점
- 두 배열의 길이가 다를 수 있습니다. 반복 조건은 `i < pots.length && j < saucers.length` 입니다.
- 화분마다 "아직 안 쓴 받침 중 맞는 가장 작은 것"을 매번 처음부터 찾으면 O(n·m) = 4×10^10 이라 시간 초과입니다. 정렬 덕분에 포인터가 되돌아갈 필요가 없습니다.
- `Arrays.sort`는 입력 배열을 바꿉니다. 이 문제에서는 상관없지만, 원본 순서가 필요한 문제라면 복사본을 정렬하세요.

## 복잡도
- 시간 O(n log n + m log m), 공간 O(1)
