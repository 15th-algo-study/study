# [lv0] 호박 품평회 상위 k개

호박 품평회에 출품된 호박들의 무게가 정수 배열 `weights`로 주어집니다. 무게가 큰 순서로 `k`개를 골라 그 무게의 합을 return 하도록 `solution` 함수를 완성해 주세요.

무게의 합은 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `weights`의 길이 ≤ 200,000
- 1 ≤ `weights`의 원소 ≤ 1,000,000,000
- 1 ≤ `k` ≤ `weights`의 길이

## 입출력 예

| weights | k | result |
|---|---|---|
| [300, 1200, 850, 400] | 2 | 2050 |
| [5, 5, 5] | 3 | 15 |
| [1000000000, 1000000000, 1] | 2 | 2000000000 |

## 입출력 예 설명
- 예 #1: 무거운 순서로 1200, 850, 400, 300 이므로 상위 2개의 합은 1200 + 850 = **2050**입니다.
- 예 #2: 세 개를 모두 더합니다.
- 예 #3: 상위 2개의 합 2,000,000,000 은 `int`의 최댓값(약 21억)에 가깝습니다. 더 큰 입력에서는 `int`로 담을 수 없습니다.
