# 해설 — 호박 품평회 상위 k개

## 접근
`Arrays.sort(weights)` 로 오름차순 정렬하면 가장 무거운 `k`개는 배열의 **뒤쪽 `k`칸**에 있습니다. 인덱스 `n - k`부터 `n - 1`까지 더하면 됩니다.

내림차순으로 정렬하고 앞에서 k개를 더해도 되지만, `int[]`에는 `Collections.reverseOrder()`를 쓸 수 없습니다. 오름차순으로 정렬한 뒤 뒤에서부터 읽는 쪽이 간단합니다.

## 주의할 점
- **오버플로**: 무게 10^9 짜리 호박 20만 개의 합은 2×10^14 라 `int`(최대 약 2.1×10^9)를 넘습니다. 합을 담는 변수를 `long`으로 선언하세요. `int`로 더하다 마지막에 `long`으로 바꾸는 것은 소용없습니다.
- `k`가 배열 길이와 같으면 전체 합입니다. 반복 범위가 `n - k`부터 시작하므로 따로 처리할 필요는 없습니다.

## 복잡도
- 시간 O(n log n), 공간 O(1)
