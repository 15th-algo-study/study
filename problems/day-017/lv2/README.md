# [lv2] 케이블카 2인 탑승 조합

케이블카 한 대에는 최대 두 사람이 탈 수 있고, 탑승 인원의 몸무게 합이 `limit`을 넘으면 안 됩니다. 탑승 대기 중인 사람들의 몸무게가 배열 `weights`로 주어집니다.

서로 다른 두 사람을 골라 함께 태울 수 있는 **조합의 수**를 return 하도록 `solution` 함수를 완성해 주세요. 즉, `i < j` 이고 `weights[i] + weights[j] ≤ limit` 인 쌍 `(i, j)`의 개수입니다. 몸무게가 같아도 사람이 다르면 다른 조합입니다. 개수는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `weights`의 길이 ≤ 500,000
- 1 ≤ `weights`의 원소 ≤ 1,000,000,000
- 1 ≤ `limit` ≤ 2,000,000,000

## 입출력 예

| weights | limit | result |
|---|---|---|
| [70, 50, 80, 60, 90] | 130 | 4 |
| [100, 100, 100] | 200 | 3 |
| [1000000000, 1000000000] | 1999999999 | 0 |

## 입출력 예 설명
- 예 #1: 합이 130 이하인 조합은 (50, 60), (50, 70), (50, 80), (60, 70) 네 가지입니다.
- 예 #2: 세 사람 중 두 사람을 고르는 모든 조합(3가지)이 가능합니다.
- 예 #3: 두 사람의 합 2,000,000,000 이 `limit`보다 1 큽니다.
