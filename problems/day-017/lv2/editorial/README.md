# 해설 — 케이블카 2인 탑승 조합

## 접근
모든 쌍을 확인하면 50만 명에서 약 1.25×10^11 번이라 시간 초과입니다. **정렬 후 투 포인터**를 씁니다.

1. `weights`를 오름차순으로 정렬합니다.
2. `lo = 0`, `hi = n - 1`에서 시작합니다.
   - `weights[lo] + weights[hi] ≤ limit` 이면, `lo`는 `lo+1 … hi` 중 **누구와도** 합이 `limit` 이하입니다 (그들은 모두 `weights[hi]` 이하이므로). 그러니 `hi - lo`개를 한꺼번에 세고 `lo`를 옮깁니다.
   - 그렇지 않으면 `weights[hi]`는 (가장 가벼운 `lo`와도 안 되므로) 누구와도 짝이 될 수 없습니다. `hi`를 옮깁니다.
3. `lo < hi` 인 동안 반복합니다.

각 단계에서 `lo` 또는 `hi`가 한 칸씩 움직이므로 반복은 최대 n번입니다.

## 주의할 점
- 쌍의 개수는 최대 n(n−1)/2 ≈ 1.25×10^11 이므로 **`long`** 으로 셉니다.
- 두 몸무게의 합은 최대 2×10^9 로 `int` 최댓값(약 2.147×10^9) 안에 들어가긴 하지만 아슬아슬합니다. 습관적으로 `long`으로 더하는 편이 안전합니다.
- 조건이 "이하(≤)"입니다. 예 #3처럼 경계값이 나오므로 부등호를 확인하세요.
- `hi - lo`개를 한 번에 세는 부분이 핵심입니다. `lo`마다 가능한 `hi`를 하나씩 세면 다시 O(n²)이 됩니다.

## 복잡도
- 시간 O(n log n), 공간 O(1)
