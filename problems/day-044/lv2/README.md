# [lv2] 우물 두레박으로 물통 채우기

마을 우물에는 두레박 `m`개가 있습니다. `i`번 두레박은 한 번 내렸다 올리는 데 `trip[i]`초가 걸리고, 올릴 때마다 물 `cap[i]`리터를 길어 옵니다. 모든 두레박은 0초에 동시에 시작해 쉬지 않고 반복해서 물을 긷고, 각 두레박의 물은 한 번 왕복이 **끝나는 순간** 물통에 더해집니다.

물통의 용량이 `volume`리터일 때, 물통에 담긴 물이 처음으로 `volume`리터 이상이 되는 시각(초)을 return 하도록 `solution` 함수를 완성해 주세요. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `cap`의 길이 = `trip`의 길이 = `m` ≤ 200,000
- 1 ≤ `cap`의 원소 ≤ 10,000
- 1 ≤ `trip`의 원소 ≤ 10,000
- 1 ≤ `volume` ≤ 10^12

## 입출력 예

| cap | trip | volume | result |
|---|---|---|---|
| [3, 1] | [5, 2] | 10 | 10 |
| [2] | [3] | 7 | 12 |
| [2, 3] | [4, 6] | 12 | 12 |

## 입출력 예 설명
- 예 #1: 10초가 되면 첫 두레박은 2번(6리터), 둘째 두레박은 5번(5리터) 길어 11리터입니다. 9초에는 1번 + 4번으로 7리터뿐이라 10초가 답입니다.
- 예 #2: 2리터씩 3초마다 들어오므로 4번째 왕복이 끝나는 12초에 8리터가 되어 7리터를 넘습니다.
- 예 #3: 12초에 첫 두레박 3번(6리터) + 둘째 두레박 2번(6리터)으로 정확히 12리터입니다.
