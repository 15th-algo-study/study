# 해설 — 우물 두레박으로 물통 채우기

## 접근
시각 `T`까지 모이는 물의 양은

> `water(T) = Σ ⌊T / trip[i]⌋ × cap[i]`

이고, `T`가 커질수록 **줄지 않습니다**. "`water(T) ≥ volume`인가?"는 O(m)에 판정할 수 있으므로, 조건을 만족하는 가장 작은 `T`를 **답에 대한 이분 탐색(파라메트릭 서치)** 으로 찾습니다.

- `lo = 1`, `hi = volume × min(trip)`: 왕복이 가장 짧은 두레박 하나만으로도 `volume`번 왕복하면 충분하므로(한 번에 1리터 이상) 이 시각에는 반드시 가능합니다.
- `check(mid)`가 참이면 `hi = mid`, 거짓이면 `lo = mid + 1`.

## 주의할 점
- `hi`는 최대 10^12 × 10^4 = 10^16이라 `long`입니다. 이 상한을 쓰면 모든 `i`에 대해 `T / trip[i] ≤ volume`이므로 항 하나가 최대 10^12 × 10^4 = 10^16이고, 더하는 도중 `volume` 이상이 되면 바로 참을 돌려주고 멈추면 합도 `volume + 10^16`을 넘지 않아 안전합니다.
- `hi`를 무작정 `Long.MAX_VALUE`나 10^18로 잡으면 `⌊T / trip[i]⌋ × cap[i]`가 넘칩니다. 위처럼 근거 있는 상한을 쓰거나, 항을 더하기 전에 `(volume - water + cap - 1) / cap ≤ T / trip`처럼 나눗셈으로 비교하세요.
- 1초씩 시뮬레이션하거나 두레박별 도착 시각을 우선순위 큐로 하나씩 꺼내는 풀이는 답이 10^16까지 커지는 large 케이스에서 시간 초과입니다.
- `T = 0`에서는 물이 없으므로 `lo = 1`부터 시작합니다 (`volume ≥ 1`).

## 복잡도
- 시간 O(m log(volume × trip)), 공간 O(1)
