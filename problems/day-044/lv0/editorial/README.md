# 해설 — 펭귄 줄에서 같은 키 찾기

## 접근
정렬되어 있으므로 키가 `x`인 펭귄들은 **연속해서** 서 있습니다. 앞에서부터 훑으며

- 처음 `x`를 만난 위치를 `first`에 기록하고 (아직 -1일 때만),
- `x`를 만날 때마다 `last`를 그 위치로 덮어씁니다.

`x`보다 큰 값을 만나면 그 뒤에는 `x`가 없으므로 멈춰도 됩니다.

## 주의할 점
- `first`는 **처음 한 번만** 기록해야 합니다. 매번 덮어쓰면 `first == last`가 됩니다.
- 하나도 못 찾으면 둘 다 -1인 상태 그대로 반환하면 됩니다.
- 질의가 하나라 O(n) 순회로 충분하지만, 이분 탐색으로 "`x` 이상인 첫 위치"와 "`x` 초과인 첫 위치 − 1"을 구해도 같은 답입니다.

## 복잡도
- 시간 O(n), 공간 O(1)
