# [lv0] 펭귄 줄에서 같은 키 찾기

펭귄 `n`마리가 키 순서대로 한 줄로 서 있습니다. `i`번째 펭귄(0번부터 셈)의 키는 `heights[i]`이고, 배열은 **오름차순**으로 정렬되어 있습니다. 같은 키의 펭귄이 여럿일 수 있습니다.

키가 정확히 `x`인 펭귄 중 **가장 앞에 선 펭귄의 번호와 가장 뒤에 선 펭귄의 번호**를 `[앞, 뒤]` 형태로 return 하도록 `solution` 함수를 완성해 주세요. 키가 `x`인 펭귄이 없으면 `[-1, -1]`을 return 합니다.

## 제한사항
- 1 ≤ `heights`의 길이 `n` ≤ 1,000,000
- 1 ≤ `heights`의 원소 ≤ 1,000,000,000, 오름차순으로 정렬되어 있습니다 (같은 값 가능)
- 0 ≤ `x` ≤ 1,000,000,000

## 입출력 예

| heights | x | result |
|---|---|---|
| [50, 60, 60, 60, 70] | 60 | [1, 3] |
| [50, 70] | 60 | [-1, -1] |
| [5] | 5 | [0, 0] |

## 입출력 예 설명
- 예 #1: 키 60인 펭귄은 1, 2, 3번에 있습니다.
- 예 #2: 키 60인 펭귄이 없습니다.
- 예 #3: 한 마리뿐이고 키가 `x`와 같아 앞과 뒤가 모두 0번입니다.
