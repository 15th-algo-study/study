# [lv1] 피아노 조율사의 음 찾기

피아노 조율사는 표준 음 주파수 표를 가지고 있습니다. 표준 주파수(Hz, 정수)는 배열 `standard`에 **오름차순**으로, 중복 없이 담겨 있습니다.

조율사가 건반을 하나씩 눌러 측정한 주파수가 배열 `measured`에 담겨 있습니다. 측정값마다 **차이의 절댓값이 가장 작은 표준 주파수**를 찾아 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 차이가 같은 표준 주파수가 둘이면 **더 낮은(작은) 주파수**를 고릅니다.

## 제한사항
- 1 ≤ `standard`의 길이 `n` ≤ 200,000
- 1 ≤ `standard`의 원소 ≤ 1,000,000,000, 오름차순이며 서로 다릅니다
- 0 ≤ `measured`의 길이 ≤ 200,000
- 1 ≤ `measured`의 원소 ≤ 1,000,000,000

## 입출력 예

| standard | measured | result |
|---|---|---|
| [220, 440, 880] | [430, 660, 100, 1000] | [440, 440, 220, 880] |
| [10, 20, 30] | [15, 25, 10, 30] | [10, 20, 10, 30] |
| [1, 1000000000] | [500000000, 500000001] | [1, 1000000000] |

## 입출력 예 설명
- 예 #1: 430은 440과 10 차이로 가장 가깝습니다. 660은 440·880과 모두 220 차이라 낮은 440을 고릅니다. 100은 220, 1000은 880이 가장 가깝습니다.
- 예 #2: 15는 10과 20의 한가운데이므로 10을, 25는 20을 고릅니다. 표준 주파수와 정확히 같으면 그 값입니다.
- 예 #3: 500000000은 1과 499999999, 1000000000과 500000000 차이라 1이 더 가깝습니다. 500000001은 반대로 1000000000이 더 가깝습니다.
