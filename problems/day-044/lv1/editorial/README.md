# 해설 — 피아노 조율사의 음 찾기

## 접근
측정값마다 표 전체를 훑으면 O(nq) = 4 × 10^10으로 시간 초과입니다. 표가 정렬되어 있으므로 **이분 탐색**으로 후보를 두 개로 좁힙니다.

1. `x` 이상인 첫 위치 `i`를 lower bound로 찾습니다.
2. 가장 가까운 값은 `standard[i]`(`x` 이상 중 최솟값) 또는 `standard[i-1]`(`x` 미만 중 최댓값) 둘 중 하나입니다.
3. 두 후보의 차이를 비교하되, 같으면 작은 쪽인 `standard[i-1]`을 고릅니다. `i == 0`이면 앞 후보가 없고, `i == n`이면 뒤 후보가 없습니다.

## 주의할 점
- 차이가 같을 때 **작은 값**을 고르는 규칙 때문에 비교를 `standard[i] - x < x - standard[i-1]`(엄격 부등호)로 써야 뒤쪽을 고릅니다. `<=`로 쓰면 예 #1의 660에서 880이 나옵니다.
- `i`가 0 또는 `n`인 경계(측정값이 표 범위 밖)를 먼저 처리하세요.
- 차이는 최대 10^9 − 1이라 `int`로 계산해도 넘치지 않습니다.
- `Arrays.binarySearch`를 쓰면 없는 값일 때 `-(삽입 위치) - 1`이 돌아오므로 `-(idx + 1)`로 삽입 위치를 복원해 같은 방식으로 풀 수 있습니다.

## 복잡도
- 시간 O(q log n), 공간 O(q)
