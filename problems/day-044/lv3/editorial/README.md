# 해설 — 유람선 선착장 k번째 거리

## 접근
두 선착장 사이의 거리는 `gaps`의 **연속 부분 배열의 합**입니다. 거리는 n(n+1)/2 ≈ 2 × 10^10개라 모두 만들어 정렬할 수 없습니다.

**핵심 관찰**: "거리가 `X` 이하인 쌍의 개수 `count(X)`"는 `X`가 커질수록 늘어나는 단조 함수이고, 답은 **`count(X) ≥ k`를 만족하는 가장 작은 `X`** 입니다. 그러므로 `X`를 이분 탐색하면 됩니다.

`count(X)`는 **슬라이딩 윈도우**로 O(n)에 구합니다. 거리가 모두 양수라 부분 배열을 늘리면 합이 커지므로, 오른쪽 끝 `r`마다 합이 `X` 이하가 되는 가장 왼쪽 `l`을 유지하면 끝이 `r`인 유효 부분 배열은 `r − l + 1`개입니다.

- 탐색 범위: `lo = 1`, `hi = 전체 합`.
- `count(mid) ≥ k`이면 `hi = mid`, 아니면 `lo = mid + 1`.

왜 답이 실제로 존재하는 거리인가: `count(X)`는 어떤 거리 값에서만 값이 바뀌므로, 조건을 처음 만족하는 `X`는 반드시 어떤 쌍의 거리와 같습니다.

## 주의할 점
- 전체 합은 최대 2 × 10^14, `k`와 `count`는 최대 2 × 10^10이므로 모두 `long`입니다. `mid` 계산도 `long`으로 하세요.
- `count(X)`를 매 이분 탐색마다 O(n²)으로 세면 시간 초과입니다. 창으로 O(n)에 세야 합니다. 이분 탐색은 약 48번 돌므로 전체 O(48n)입니다.
- 모든 쌍을 만들어 정렬하거나 k번째를 고르는 풀이는 메모리·시간 모두 불가능합니다.

## 복잡도
- 시간 O(n log S) (S = 전체 거리 합), 공간 O(1)
