# [lv3] 유람선 선착장 k번째 거리

강을 따라 유람선 선착장 `n + 1`개가 일렬로 있습니다. 이웃한 선착장 사이의 거리가 배열 `gaps`로 주어져, `i`번 선착장과 `i + 1`번 선착장 사이의 거리는 `gaps[i]`입니다. 두 선착장 사이의 거리는 그 사이에 있는 이웃 거리들의 합입니다.

서로 다른 두 선착장을 고르는 모든 방법(`n(n + 1) / 2`가지)에 대해 두 선착장 사이의 거리를 구해 **오름차순으로 늘어놓았을 때 `k`번째(1번부터 셈) 값**을 return 하도록 `solution` 함수를 완성해 주세요. 같은 거리가 여러 번 나오면 그만큼 여러 번 셉니다. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `gaps`의 길이 `n` ≤ 200,000
- 1 ≤ `gaps`의 원소 ≤ 1,000,000,000
- 1 ≤ `k` ≤ `n(n + 1) / 2`

## 입출력 예

| gaps | k | result |
|---|---|---|
| [3, 1, 2] | 4 | 3 |
| [1, 1, 1, 1] | 7 | 2 |
| [1, 3, 1] | 5 | 4 |

## 입출력 예 설명
- 예 #1: 선착장은 4개이고 거리는 3, 1, 2, 3+1=4, 1+2=3, 3+1+2=6입니다. 정렬하면 1, 2, 3, 3, 4, 6이고 4번째는 3입니다.
- 예 #2: 거리 1이 4개, 2가 3개, 3이 2개, 4가 1개입니다. 7번째는 2입니다.
- 예 #3: 거리는 1, 3, 1, 4, 4, 5이고 정렬하면 1, 1, 3, 4, 4, 5이므로 5번째는 4입니다.
