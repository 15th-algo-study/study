# [lv3] 정글 캠프와 밧줄 다리

정글에 캠프 `n`개가 있고 0번부터 `n-1`번까지 번호가 붙어 있습니다. 몇몇 캠프 쌍 사이에는 밧줄 다리가 놓여 있어 양방향으로 오갈 수 있습니다. 다리 목록은 2차원 배열 `bridges`로 주어지며 `bridges[i] = [a, b]`는 `a`번과 `b`번 캠프 사이의 다리입니다.

탐험대는 다리를 **하나 더** 놓는 계획을 여러 개 검토하고 있습니다. 계획 목록 `plans`의 `plans[i] = [a, b]`는 "`a`번과 `b`번 캠프 사이에 다리를 하나 놓았다고 가정했을 때, `a`번 캠프에서 다리만 건너 갈 수 있는 캠프의 수(자기 자신 포함)"를 묻습니다. 각 계획은 **독립적**이며, 한 계획의 다리가 다른 계획에 영향을 주지 않습니다.

각 계획의 답을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 200,000
- 0 ≤ `bridges`의 길이 ≤ 200,000
- 1 ≤ `plans`의 길이 ≤ 200,000
- 0 ≤ `a`, `b` < `n`
- `bridges`에는 같은 쌍이 여러 번 나오거나 `a = b`인 쌍이 있을 수 있습니다. `plans`에서도 `a = b`일 수 있으며, 이 경우 다리는 아무 의미가 없습니다.

## 입출력 예

| n | bridges | plans | result |
|---|---|---|---|
| 6 | [[0, 1], [2, 3], [3, 4]] | [[0, 2], [1, 0], [5, 4], [5, 5]] | [5, 2, 4, 1] |
| 3 | [] | [[0, 1], [1, 2]] | [2, 2] |
| 4 | [[0, 1], [1, 2], [2, 0], [0, 3]] | [[3, 2]] | [4] |

## 입출력 예 설명
- 예 #1: 현재 서로 오갈 수 있는 캠프 묶음은 {0, 1}, {2, 3, 4}, {5}입니다.
  - [0, 2]: 두 묶음이 이어져 0번에서 2 + 3 = 5개 캠프에 갈 수 있습니다.
  - [1, 0]: 이미 같은 묶음이므로 그대로 2개입니다.
  - [5, 4]: 1 + 3 = 4개.
  - [5, 5]: 자기 자신과의 다리는 의미가 없어 1개입니다.
- 예 #2: 다리가 없으므로 어떤 계획이든 두 캠프를 잇게 되어 2입니다.
- 예 #3: 네 캠프가 이미 모두 이어져 있어 4입니다.
