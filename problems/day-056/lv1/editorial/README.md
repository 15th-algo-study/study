# 해설 — 봉수대 불 지피기

## 접근
봉수대를 정점, "서로 보이는" 관계를 간선으로 보면, 0번에서 간선을 따라 **도달할 수 있는 정점**을 모두 찾는 문제입니다.

1. **인접 리스트**를 만듭니다. `List<Integer>[] adj`를 `n`개 만들고, 각 쌍 `[a, b]`에 대해 `adj[a].add(b)`, `adj[b].add(a)` 둘 다 넣습니다(양방향).
2. 0번을 큐에 넣고 `visited[0] = true`로 표시합니다.
3. 큐에서 하나씩 꺼내 이웃을 보며, 아직 방문하지 않은 이웃은 표시하고 큐에 넣습니다 (BFS).
4. `visited`가 `true`인 수가 불붙은 수이고, `false`인 가장 작은 인덱스가 두 번째 답입니다.

**큐에 넣을 때 방문 표시**를 해야 같은 정점이 여러 번 큐에 들어가지 않습니다. 중복 쌍과 `a = b`인 쌍은 방문 표시 덕분에 자연스럽게 무시됩니다.

## 주의할 점
- 2차원 `boolean[n][n]` 인접 행렬은 `n = 200,000`일 때 메모리가 4×10^10바이트라 만들 수 없습니다. 인접 리스트를 쓰세요.
- "불이 붙은 봉수대가 생길 때마다 `pairs` 전체를 다시 훑는" 방식은 O(n × m)이라 large 에서 시간 초과입니다. 각 간선은 BFS 과정에서 양쪽으로 한 번씩만 보면 충분합니다.
- 재귀 DFS 로도 풀 수 있지만, 봉수대가 한 줄로 길게 이어지면 재귀 깊이가 `n`까지 커져 StackOverflowError 위험이 있습니다. 큐(`ArrayDeque`)를 쓰는 BFS 나 스택을 쓰는 반복문 DFS 를 권장합니다.

## 복잡도
- 시간 O(n + m), 공간 O(n + m)
