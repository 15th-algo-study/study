# [lv1] 봉수대 불 지피기

산등성이에 봉수대 `n`개가 있고 0번부터 `n-1`번까지 번호가 붙어 있습니다. 서로 **마주 보이는** 봉수대 쌍의 목록이 2차원 배열 `pairs`로 주어집니다. `pairs[i] = [a, b]`는 `a`번과 `b`번 봉수대가 서로 보인다는 뜻이며, 보이는 관계는 양방향입니다.

밤이 되자 0번 봉수대에 불을 지폈습니다. 불이 붙은 봉수대가 보이는 봉수대는 모두 따라서 불을 지피고, 이 과정이 더 이상 새로 불붙는 봉수대가 없을 때까지 이어집니다.

최종적으로 **불이 붙은 봉수대의 수**와, **불이 붙지 않은 봉수대 중 가장 작은 번호**(모두 불이 붙었으면 -1)를 `[불붙은 수, 번호]` 형태의 배열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 200,000
- 0 ≤ `pairs`의 길이 ≤ 300,000
- 0 ≤ `a`, `b` < `n`
- 같은 쌍이 여러 번 나오거나 `a = b`인 쌍이 있을 수 있습니다. 결과에는 영향을 주지 않습니다.

## 입출력 예

| n | pairs | result |
|---|---|---|
| 6 | [[0, 1], [1, 2], [3, 4]] | [3, 3] |
| 4 | [[0, 1], [1, 2], [2, 3]] | [4, -1] |
| 5 | [[1, 2], [2, 3]] | [1, 1] |

## 입출력 예 설명
- 예 #1: 0번 → 1번 → 2번 순서로 불이 옮겨 붙습니다. 3, 4, 5번은 불이 붙지 않으며 그중 가장 작은 번호는 3입니다.
- 예 #2: 0번에서 시작해 1, 2, 3번까지 모두 불이 붙습니다.
- 예 #3: 0번과 보이는 봉수대가 없으므로 0번만 불이 붙습니다. 불이 붙지 않은 봉수대 중 가장 작은 번호는 1입니다.
