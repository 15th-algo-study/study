# 해설 — 퀼트 이불의 테두리 조각

## 접근
2차원 배열을 이중 반복문으로 순회하면서, 현재 칸이 테두리인지 인덱스로 판단합니다.

- 테두리 조건: `r == 0 || r == rows - 1 || c == 0 || c == cols - 1`

조건을 만족하는 칸의 값만 더하면 됩니다. "첫 줄 합 + 마지막 줄 합 + 첫 칸 합 + 마지막 칸 합"처럼 네 변을 따로 더하면 모서리가 두 번 더해지고, 줄이 하나뿐일 때는 첫 줄과 마지막 줄이 같아 모든 조각이 두 번 더해집니다. 칸마다 "테두리인가?"를 한 번씩만 묻는 방식이 이런 중복을 자연스럽게 피합니다.

## 주의할 점
- 조각 무게가 최대 2,000,000이고 테두리 조각이 최대 약 4,000개이므로 합이 8×10^9까지 가능합니다. `int`로 누적하면 넘치므로 `long`을 씁니다.
- 1×1, 1×m, n×1 같은 작은 입력에서 모든 조각이 정확히 한 번씩 더해지는지 확인하세요.

## 복잡도
- 시간 O(rows × cols), 공간 O(1)
