# [lv0] 퀼트 이불의 테두리 조각

정사각 천 조각을 격자 모양으로 이어 붙여 퀼트 이불을 만들었습니다. 조각마다 무게(g)가 다르고, 이불의 조각 무게는 2차원 배열 `quilt`로 주어집니다. `quilt[r][c]`는 `r`번째 줄, `c`번째 칸 조각의 무게입니다.

이불의 **테두리**(첫 줄, 마지막 줄, 첫 칸, 마지막 칸에 속하는 조각)에 들어가는 조각들의 무게 합을 return 하도록 `solution` 함수를 완성해 주세요. 한 조각은 한 번만 더합니다. 합이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `quilt`의 줄 수, 각 줄의 칸 수 ≤ 1,000
- 모든 줄의 칸 수는 같습니다.
- 1 ≤ `quilt[r][c]` ≤ 2,000,000
- 줄이 하나뿐이거나 칸이 하나뿐이면 모든 조각이 테두리입니다.

## 입출력 예

| quilt | result |
|---|---|
| [[1, 2, 3], [4, 5, 6], [7, 8, 9]] | 40 |
| [[5, 6, 7]] | 18 |
| [[2], [3], [4]] | 9 |

## 입출력 예 설명
- 예 #1: 가운데 조각 5를 뺀 나머지 여덟 조각의 합 1+2+3+4+6+7+8+9 = 40입니다.
- 예 #2: 줄이 하나뿐이므로 세 조각 모두 테두리입니다. 5+6+7 = 18.
- 예 #3: 칸이 하나뿐이므로 세 조각 모두 테두리입니다. 2+3+4 = 9.
