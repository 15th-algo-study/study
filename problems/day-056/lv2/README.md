# [lv2] 동굴 탐사 일지

지하 동굴에 방이 `n`개 있고 0번부터 `n-1`번까지 번호가 붙어 있습니다. 어떤 방들 사이에는 통로가 있지만 통로 지도는 남아 있지 않고, 탐사대가 남긴 **탐사 일지**만 있습니다.

일지는 2차원 배열 `logs`로 주어집니다. `logs[i]`는 한 번의 탐사에서 **통로를 따라 차례로 지나간 방 번호**를 적은 배열입니다. 즉 `logs[i][j]`번 방과 `logs[i][j+1]`번 방 사이에는 통로가 있습니다(통로는 양방향). 일지에 적힌 통로 외에 다른 통로는 없다고 가정합니다. 방 하나만 적힌 일지는 통로 정보를 주지 않습니다.

통로로 서로 오갈 수 있는 방들의 묶음을 **동굴계**라고 합니다. 어떤 일지에도 등장하지 않는 방은 혼자서 크기 1인 동굴계를 이룹니다. 모든 동굴계의 크기(방의 수)를 **내림차순**으로 정렬해 배열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 2,000,000
- 0 ≤ `logs`의 길이 ≤ 200,000
- 1 ≤ 각 `logs[i]`의 길이, 모든 일지의 길이 합 ≤ 2,000,000
- 0 ≤ `logs[i][j]` < `n`
- 같은 방을 연달아 적거나(`logs[i][j] = logs[i][j+1]`), 같은 통로가 여러 일지에 나올 수 있습니다.

## 입출력 예

| n | logs | result |
|---|---|---|
| 7 | [[0, 1, 2], [3, 4], [2, 0], [5]] | [3, 2, 1, 1] |
| 4 | [[1, 2, 3, 1]] | [3, 1] |
| 3 | [] | [1, 1, 1] |

## 입출력 예 설명
- 예 #1: 통로는 0–1, 1–2, 3–4, 2–0 입니다. 동굴계는 {0, 1, 2}, {3, 4}, {5}, {6} 이므로 크기를 내림차순으로 나열하면 [3, 2, 1, 1]입니다.
- 예 #2: 통로 1–2, 2–3, 3–1 로 {1, 2, 3}이 한 동굴계이고 0번 방은 혼자입니다.
- 예 #3: 일지가 없으므로 세 방 모두 혼자입니다.
