# [lv2] 오리엔티어링 길 안내

오리엔티어링 대회 지도를 격자 모양의 지도 `field`로 나타냈습니다. `field[r]`의 `c`번째 문자가 (r, c) 칸이며, 각 문자의 뜻은 다음과 같습니다.

- `A`: 출발 지점 (정확히 하나)
- `B`: 도착 지점 (정확히 하나)
- `.`: 지나갈 수 있는 칸
- `#`: 늪이나 절벽이라 지나갈 수 없는 칸

참가자는 한 번에 상하좌우로 붙은 칸으로 한 칸씩 움직이며, 지도 밖이나 `#` 칸으로는 갈 수 없습니다. `A`와 `B` 칸은 지나갈 수 있습니다.

운영진은 참가자에게 줄 길 안내문을 방위 글자로 씁니다.

| 글자 | `E` | `N` | `S` | `W` |
|---|---|---|---|---|
| 뜻 | 동쪽 (열 번호 +1) | 북쪽 (행 번호 −1) | 남쪽 (행 번호 +1) | 서쪽 (열 번호 −1) |

예를 들어 `"EES"`는 동쪽으로 두 칸, 남쪽으로 한 칸 가라는 뜻입니다. 안내문은 출발 지점에서 도착 지점까지 가는 **최단 경로**여야 합니다. 최단 경로가 여러 개라면 그중 안내문 문자열이 **사전순으로 가장 앞서는 것**(알파벳 순서 `E` < `N` < `S` < `W`)을 고릅니다.

운영진이 고르는 안내문을 return 하도록 `solution` 함수를 완성해 주세요. 도착 지점에 갈 수 없으면 빈 문자열 `""`을 return 합니다.

## 제한사항
- 1 ≤ `field`의 길이 ≤ 1,000
- 1 ≤ 각 `field[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같습니다.
- `field`는 `A`, `B`, `.`, `#`로만 이루어지며 `A`와 `B`는 각각 정확히 한 번 나옵니다.

## 입출력 예

| field | result |
|---|---|
| ["A..", ".#.", "..B"] | "EESS" |
| ["..A", ".#.", "B.."] | "SSWW" |
| ["A#B"] | "" |

## 입출력 예 설명
- 예 #1: 최단 경로는 위로 도는 `"EESS"`와 아래로 도는 `"SSEE"` 두 가지이고, `E`가 `S`보다 앞서므로 `"EESS"`입니다.
- 예 #2: 최단 경로는 `"WWSS"`와 `"SSWW"`이고, `S`가 `W`보다 앞서므로 `"SSWW"`입니다.
- 예 #3: 도착 지점에 갈 수 없습니다.
