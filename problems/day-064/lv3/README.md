# [lv3] 인라인스케이트 배달

인라인스케이트를 신은 배달원이 광장을 가로질러 배달하려고 합니다. 광장을 격자 모양의 지도 `plaza`로 나타냈고, `plaza[r]`의 `c`번째 문자가 (r, c) 칸입니다.

- `S`: 배달원이 출발하는 칸 (정확히 하나)
- `T`: 배달할 곳 (정확히 하나)
- `.`: 빈 칸
- `#`: 화단이나 벤치가 있어 지나갈 수 없는 칸

배달원은 1초 동안 상하좌우 중 한 방향을 골라, 그 방향으로 **1칸 이상 `k`칸 이하**를 곧게 미끄러져 갑니다. 미끄러지는 동안 지나가는 칸과 멈추는 칸 중에 `#` 칸이 있거나 광장 밖으로 나가면 안 됩니다. `S`와 `T` 칸은 빈 칸처럼 지나갈 수 있습니다.

출발 칸에서 배달할 곳에 **멈춰 서는** 데 걸리는 최소 시간(초)을 return 하도록 `solution` 함수를 완성해 주세요. 갈 수 없으면 -1을 return 합니다.

## 제한사항
- 1 ≤ `plaza`의 길이 × 각 `plaza[r]`의 길이 ≤ 1,000,000 (가로나 세로로 아주 긴 광장일 수도 있습니다)
- 모든 줄의 길이는 같습니다.
- `plaza`는 `S`, `T`, `.`, `#`로만 이루어지며 `S`와 `T`는 각각 정확히 한 번 나옵니다.
- 1 ≤ `k` ≤ 1,000,000

## 입출력 예

| plaza | k | result |
|---|---|---|
| ["S...", "###.", "T..."] | 3 | 3 |
| ["S...", "###.", "T..."] | 2 | 5 |
| ["S#T"] | 5 | -1 |

## 입출력 예 설명
- 예 #1: 오른쪽으로 3칸 (0,3), 아래로 2칸 (2,3), 왼쪽으로 3칸 미끄러지면 (2,0)에 멈춥니다. 3초입니다.
- 예 #2: 한 번에 2칸까지만 갈 수 있어 (0,0) → (0,2) → (0,3) → (2,3) → (2,1) → (2,0)으로 5초가 걸립니다.
- 예 #3: 화단을 넘어갈 수 없습니다.
