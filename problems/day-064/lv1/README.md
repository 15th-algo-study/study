# [lv1] 가까운 카페 k곳

새로 이사 온 동네를 격자 모양의 지도 `town`으로 나타냈습니다. `town[r]`의 `c`번째 문자가 (r, c) 칸이며, 각 문자의 뜻은 다음과 같습니다.

- `S`: 우리 집 (정확히 하나)
- `C`: 카페
- `.`: 길
- `#`: 건물이라 지나갈 수 없는 칸

한 걸음에 상하좌우로 붙은 칸으로 한 칸씩 걸을 수 있습니다. 건물 칸과 지도 밖으로는 갈 수 없고, 카페 칸과 우리 집 칸은 길처럼 지나갈 수 있습니다. 카페까지의 거리는 우리 집에서 그 카페까지 걷는 최소 걸음 수입니다.

걸어서 갈 수 있는 카페들을 **가까운 순서**로 늘어놓았을 때 앞에서부터 최대 `k`곳의 좌표 `[r, c]`를 차례로 담은 2차원 배열을 return 하도록 `solution` 함수를 완성해 주세요. 가까운 순서는 다음과 같이 정합니다.

1. 거리가 짧은 카페가 앞입니다.
2. 거리가 같으면 행 번호 `r`가 작은 카페가 앞입니다.
3. 행 번호도 같으면 열 번호 `c`가 작은 카페가 앞입니다.

걸어서 갈 수 있는 카페가 `k`곳보다 적으면 갈 수 있는 카페를 모두 담고, 하나도 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `town`의 길이 ≤ 1,000
- 1 ≤ 각 `town[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같고, `town`은 `S`, `C`, `.`, `#`로만 이루어지며 `S`는 정확히 한 번 나옵니다.
- 1 ≤ `k` ≤ 1,000,000

## 입출력 예

| town | k | result |
|---|---|---|
| ["C.S", ".#.", "C.C"] | 2 | [[0, 0], [2, 2]] |
| ["S#C"] | 3 | [] |
| ["CSC", "CCC"] | 10 | [[0, 0], [0, 2], [1, 1], [1, 0], [1, 2]] |

## 입출력 예 설명
- 예 #1: (0,0)과 (2,2) 카페는 모두 2걸음, (2,0) 카페는 4걸음입니다. 거리가 같은 두 곳은 행 번호가 작은 (0,0)이 앞입니다.
- 예 #2: 건물에 막혀 갈 수 있는 카페가 없습니다.
- 예 #3: 1걸음인 (0,0), (0,2), (1,1)이 행·열 순서로 먼저 오고, 2걸음인 (1,0), (1,2)가 뒤에 옵니다. 카페가 5곳뿐이라 모두 담습니다.
