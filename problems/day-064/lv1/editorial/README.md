# 해설 — 가까운 카페 k곳

## 접근
모든 카페의 거리는 출발점이 같은(우리 집) 최단 거리이므로, 우리 집에서 **BFS를 한 번** 돌리면 모든 카페의 거리를 한꺼번에 얻습니다.

1. `S`에서 BFS를 하며, 꺼낸 칸이 카페면 `(거리, 행, 열)`을 기록합니다.
2. 기록한 카페들을 거리 → 행 → 열 순으로 정렬합니다.
3. 앞에서부터 `min(k, 카페 수)`개를 담습니다.

정렬 기준을 `long` 하나로 묶으면 편합니다. 칸 번호 `r * cols + c`는 행이 작을수록, 같은 행이면 열이 작을수록 작으므로 `거리 * (rows * cols) + 칸 번호`를 정렬하면 원하는 순서가 됩니다.

## 주의할 점
- 카페마다 "집에서 그 카페까지" BFS를 따로 돌리면 카페 수 × 칸 수라, 카페가 수십만 곳이면 시간 초과입니다. 출발점이 하나이니 BFS도 한 번이면 됩니다.
- BFS가 꺼내는 순서는 거리 순이긴 하지만, **같은 거리 안에서는 행·열 순이 아닙니다**(방향 배열 순서와 큐에 들어간 순서에 따라 달라집니다). 그대로 앞에서 `k`개를 자르면 동률 처리에서 틀립니다. 예를 들어 `["C..", ".S.", "..C"]`에서 두 카페는 모두 2걸음인데 (0,0)이 앞이어야 합니다.
- 갈 수 없는 카페는 담지 않습니다. 갈 수 있는 카페가 `k`곳보다 적으면 있는 만큼만 return 합니다.

## 복잡도
- 시간 O(rows × cols + m log m) (m = 갈 수 있는 카페 수), 공간 O(rows × cols)
