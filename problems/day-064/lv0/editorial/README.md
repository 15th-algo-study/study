# 해설 — 도서 등록 번호 검증

## 접근
1. 번호의 글자를 앞에서부터 보며 `-`가 아닌 글자만 숫자로 바꿔 모읍니다. 숫자 글자 `ch`를 수로 바꿀 때는 `ch - '0'`을 씁니다.
2. 모은 숫자가 `m`개일 때, 마지막 숫자를 뺀 앞의 `m - 1`개에 1, 2, 3, …을 곱해 더합니다.
3. 그 합을 10으로 나눈 나머지가 마지막 숫자와 같으면 올바른 번호로 셉니다.

`code.replace("-", "")`로 하이픈을 먼저 지운 뒤 처리해도 됩니다.

## 주의할 점
- 곱하는 수는 **원래 문자열에서의 위치가 아니라 하이픈을 뺀 숫자의 순서**입니다. `"--7-7"`에서 첫 번째 7은 1번째 숫자입니다.
- `code.charAt(i)`를 그대로 곱하면 글자 코드(`'7'`은 55)가 곱해집니다. 반드시 `- '0'`으로 숫자로 바꾸세요.
- 숫자가 최대 30개라 합은 최대 9 × (1 + 2 + … + 29) = 3,915로 `int`에 충분합니다.
- 번호 전체를 `Long.parseLong`으로 바꾸는 방식은 30자리 수가 `long` 범위를 넘으므로 쓸 수 없습니다.

## 복잡도
- 시간 O(전체 글자 수), 공간 O(번호 하나의 길이)
