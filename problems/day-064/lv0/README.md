# [lv0] 도서 등록 번호 검증

도서관의 책마다 등록 번호가 붙어 있습니다. 등록 번호는 숫자와 하이픈(`-`)으로 이루어지며, 하이픈은 읽기 쉽게 끊어 쓴 것일 뿐 아무 뜻이 없습니다.

하이픈을 모두 빼고 남은 숫자를 앞에서부터 d₁, d₂, …, dₘ이라고 할 때, 마지막 숫자 dₘ은 잘못 적힌 번호를 찾아내기 위한 **검증 숫자**입니다. 다음 식을 만족하면 올바른 등록 번호입니다.

(1 × d₁ + 2 × d₂ + … + (m−1) × dₘ₋₁)을 10으로 나눈 나머지 = dₘ

등록 번호를 담은 문자열 배열 `codes`가 주어질 때, 올바른 등록 번호의 개수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `codes`의 길이 ≤ 100,000
- 2 ≤ 각 원소의 길이 ≤ 30
- 각 원소는 숫자(`0`~`9`)와 `-`로만 이루어지며, 숫자가 두 개 이상 들어 있습니다.

## 입출력 예

| codes | result |
|---|---|
| ["12-3-4", "9-8", "000"] | 2 |
| ["5-5", "--7-7", "123456-1"] | 3 |
| ["00-01"] | 0 |

## 입출력 예 설명
- 예 #1
  - `"12-3-4"`: 숫자는 1, 2, 3, 4입니다. 1×1 + 2×2 + 3×3 = 14, 14를 10으로 나눈 나머지 4가 마지막 숫자 4와 같아 올바릅니다.
  - `"9-8"`: 1×9 = 9인데 마지막 숫자는 8이라 틀립니다.
  - `"000"`: 1×0 + 2×0 = 0으로 올바릅니다.
- 예 #2: `"5-5"`는 5 = 5, `"--7-7"`은 7 = 7, `"123456-1"`은 1+4+9+16+25+36 = 91 → 1로 모두 올바릅니다.
- 예 #3: 숫자 0, 0, 0, 1에서 앞의 합은 0인데 마지막 숫자가 1이라 틀립니다.
