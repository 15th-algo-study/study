# [lv2] 양궁 단체전 순번

양궁 단체전에서 우리 팀 선수 `n`명과 상대 팀 선수 `n`명이 **한 명씩 짝을 지어** 대결합니다. 각 선수의 기대 점수가 배열 `ours`(우리 팀)와 `theirs`(상대 팀)로 주어집니다. 한 대결에서 우리 선수의 점수가 상대 선수보다 **높으면** 우리가 이기고, 같거나 낮으면 이기지 못합니다.

상대 팀의 순번은 이미 공개되어 있고, 우리는 누가 누구와 대결할지 자유롭게 정할 수 있습니다(우리 선수 한 명은 상대 선수 정확히 한 명과 대결합니다). 우리 팀이 **이기는 대결 수의 최댓값**을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 200,000 (`ours`와 `theirs`의 길이는 같습니다)
- 1 ≤ `ours`의 원소, `theirs`의 원소 ≤ 1,000,000,000

## 입출력 예

| ours | theirs | result |
|---|---|---|
| [8, 2, 5, 1] | [4, 5, 7, 9] | 2 |
| [5, 5, 5] | [5, 5, 5] | 0 |
| [3, 7] | [1, 2] | 2 |

## 입출력 예 설명
- 예 #1: 5 → 4, 8 → 5(또는 7)와 붙이면 2승입니다. 1과 2는 누구도 이길 수 없고, 9는 누구도 못 이기므로 3승은 불가능합니다. 센 선수끼리 순서대로 붙이면(8-9, 5-7, 2-5, 1-4) 0승입니다.
- 예 #2: 점수가 같으면 이기지 못합니다.
- 예 #3: 어떻게 붙여도 2승입니다.
