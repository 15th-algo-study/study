# 해설 — 금고 비밀번호 힌트

## 접근
번호를 **뒤에서부터**(`% 10`, `/ 10`) 한 자리씩 꺼내면 자릿수가 거꾸로 나옵니다. 홀수 자릿수를 만날 때마다 `result += digit * place`로 더하고 `place`를 10배 하면, 원래 순서 그대로 이어 붙인 수가 만들어집니다. 짝수 자릿수는 `place`를 늘리지 않고 그냥 건너뜁니다.

예: 48235 → 5(자리 1) → 3(자리 10) → 2 건너뜀 → 8 건너뜀 → 4 건너뜀 → 5 + 30 = 35.

## 주의할 점
- `place`는 최대 10^17, 결과는 최대 10^18이므로 둘 다 `long`이어야 합니다. `int`로 두면 10자리부터 넘칩니다.
- 홀수 판별은 `digit % 2 == 1`입니다. 자릿수는 음수가 아니므로 음수 나머지 걱정은 없습니다.
- 자릿수를 문자열로 모아 `Long.parseLong`을 써도 되지만, 빈 문자열(홀수가 없는 경우)을 따로 처리해야 합니다.

## 복잡도
- 시간 O(n × 19), 공간 O(n)
