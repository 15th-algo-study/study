# [lv0] 금고 비밀번호 힌트

할머니는 금고 비밀번호를 잊지 않으려고 긴 번호를 적어 두고, 그중 **홀수인 자릿수만 순서대로 이어 붙인 수**를 실제 비밀번호로 씁니다. 예를 들어 적어 둔 번호가 48235이면 짝수인 4, 8, 2를 지우고 남은 3, 5를 이어 붙여 **35**가 됩니다. 번호 7183은 8을 지우고 7, 1, 3을 이어 붙여 713이 됩니다. 홀수인 자릿수가 하나도 없으면 비밀번호는 0입니다.

적어 둔 번호 배열 `codes`가 주어질 때, 각 번호에서 만든 비밀번호를 같은 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `codes`의 길이 ≤ 100,000
- 0 ≤ `codes`의 원소 ≤ 1,000,000,000,000,000,000 (10^18, `long`)
- 결과도 `long` 배열로 return 합니다. 남는 자릿수가 모두 홀수이므로 맨 앞에 0이 오는 일은 없습니다.

## 입출력 예

| codes | result |
|---|---|
| [48235, 2468, 7183] | [35, 0, 713] |
| [1000000000000000000, 9999] | [1, 9999] |

## 입출력 예 설명
- 예 #1: 48235 → 3, 5만 남아 35. 2468 → 홀수가 없어 0. 7183 → 7, 1, 3이 남아 713.
- 예 #2: 10^18은 1 뒤에 0이 열여덟 개이므로 1만 남습니다. 9999는 모두 홀수라 그대로입니다.
