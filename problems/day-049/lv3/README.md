# [lv3] 세탁소의 세탁기와 건조기

세탁소에 세탁기 한 대와 건조기 한 대가 있습니다. 빨래 `n`묶음이 들어왔고, 묶음 `i`는 세탁에 `wash[i]`분, 건조에 `dry[i]`분이 걸립니다. 규칙은 다음과 같습니다.

- 모든 묶음은 **세탁을 마친 뒤** 건조해야 합니다.
- 세탁기와 건조기는 각각 한 번에 한 묶음만 처리하며, 처리 중에 끊을 수 없습니다.
- 세탁은 정한 순서대로 쉬지 않고 이어서 합니다. 건조도 **세탁한 순서와 같은 순서**로 하며, 세탁이 끝났고 건조기가 비어 있으면 바로 건조를 시작합니다. 세탁이 끝난 묶음은 건조기가 빌 때까지 얼마든지 기다릴 수 있습니다.

세탁 순서를 잘 정해 **마지막 묶음의 건조가 끝나는 시각**을 가장 이르게 하려 합니다. 시각 0에 시작할 때 그 최솟값을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 200,000 (`wash`와 `dry`의 길이는 같습니다)
- 1 ≤ `wash[i]`, `dry[i]` ≤ 1,000,000,000
- 답이 `int` 범위를 넘을 수 있으므로 `long`을 return 합니다.

## 입출력 예

| wash | dry | result |
|---|---|---|
| [9, 2, 2, 8] | [7, 7, 2, 2] | 23 |
| [1, 2, 3] | [3, 2, 1] | 7 |
| [5] | [5] | 10 |

## 입출력 예 설명
- 예 #1: 묶음 1(2, 7) → 묶음 0(9, 7) → 묶음 2(2, 2) → 묶음 3(8, 2) 순서로 하면
  - 세탁 끝 시각: 2, 11, 13, 21
  - 건조 시작·끝: 묶음 1은 2~9, 묶음 0은 11~18, 묶음 2는 18~20, 묶음 3은 21~23
  이라 23에 끝납니다. 세탁이 짧은 순서(2, 2, 8, 9)로 하면 28, 세탁+건조 합이 작은 순서로 해도 28이 걸립니다.
- 예 #2: 묶음 0(1, 3) → 묶음 1(2, 2) → 묶음 2(3, 1) 순서로 하면 세탁 끝 1, 3, 6, 건조는 1~4, 4~6, 6~7이라 7입니다. 세탁 시간 합 6에 마지막 건조 1분은 반드시 더해지므로 7보다 이를 수 없습니다.
- 예 #3: 세탁 5분 뒤 건조 5분입니다.
