# 해설 — 장학금 신청

## 접근
**적게 요청한 사람부터** 지급합니다. 오름차순으로 정렬한 뒤 앞에서부터 누적 합이 예산을 넘지 않는 동안 세면 됩니다.

왜 맞는지(교환 논법): 어떤 최적해가 `m`명에게 지급했다고 합시다. 그 `m`명 중 누군가가 "가장 적게 요청한 `m`명"에 들지 않는다면, 그 사람을 빠진 사람 중 가장 적게 요청한 사람으로 바꿔도 총액은 줄거나 같으므로 여전히 예산 안입니다. 따라서 가장 적게 요청한 `m`명에게 주는 해도 최적이고, 이는 정렬 후 앞에서부터 세는 것과 같습니다.

## 주의할 점
- 누적 합은 최대 2×10^14라 `long`으로 둬야 합니다. 요청액 세 개만 더해도 `int`를 넘습니다.
- 예산이 0이거나 가장 적은 요청보다 작으면 0명입니다. 누적하기 **전에** 더한 값이 예산을 넘는지 확인하세요.

## 복잡도
- 시간 O(n log n), 공간 O(1) 추가
