# [lv1] 장학금 신청

장학 재단에 올해 신청서 `n`장이 들어왔습니다. 신청서 `i`가 요청한 금액은 `requests[i]`이고, 재단의 올해 예산은 `budget`입니다. 재단은 **요청 금액을 전액** 지급하는 것을 원칙으로 하며 일부만 주지는 않습니다. 예산 안에서 **가능한 한 많은 신청자**에게 지급하려 합니다.

지급할 수 있는 신청자 수의 최댓값을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `requests`의 길이 `n` ≤ 200,000
- 1 ≤ `requests`의 원소 ≤ 1,000,000,000
- 0 ≤ `budget` ≤ 1,000,000,000,000,000 (10^15, `long`)

## 입출력 예

| requests | budget | result |
|---|---|---|
| [300, 100, 500, 200] | 600 | 3 |
| [700, 800] | 650 | 0 |
| [1, 1, 1] | 1000000000000 | 3 |

## 입출력 예 설명
- 예 #1: 100 + 200 + 300 = 600으로 세 명에게 줄 수 있습니다. 네 명 모두에게 주려면 1100이 필요합니다.
- 예 #2: 가장 적게 요청한 사람도 예산을 넘습니다.
- 예 #3: 예산이 넉넉해 모두에게 줍니다.
