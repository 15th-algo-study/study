# [lv1] 놀이기구 탑승 시각

놀이기구는 시각 0부터 `t`초마다(0, `t`, 2`t`, …) 출발하며 한 번에 최대 `c`명을 태웁니다. 손님 `n`명이 줄을 서는데, 손님들의 도착 시각이 줄 선 순서대로 배열 `arrivals`에 담겨 있습니다(오름차순, 같은 시각 가능).

각 출발 시각에는 그 시각까지 도착해 줄에 서 있는 손님(도착 시각 ≤ 출발 시각) 중 앞에서부터 최대 `c`명이 탑승합니다. 타지 못한 손님은 줄에 그대로 서서 다음 출발을 기다립니다.

각 손님이 탑승한 출발 시각을 배열 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 출발 시각이 `int` 범위를 넘을 수 있으므로 `long[]`으로 return 합니다.

## 제한사항
- 1 ≤ `arrivals`의 길이 `n` ≤ 200,000
- 0 ≤ `arrivals[i]` ≤ 1,000,000,000, `arrivals`는 오름차순(같은 값 가능)으로 정렬되어 있습니다.
- 1 ≤ `c` ≤ 200,000
- 1 ≤ `t` ≤ 1,000,000,000

## 입출력 예

| arrivals | c | t | result |
|---|---|---|---|
| [0, 0, 0, 1, 7] | 2 | 3 | [0, 0, 3, 3, 9] |
| [5, 5, 5] | 5 | 4 | [8, 8, 8] |
| [0, 10] | 1 | 10 | [0, 10] |

## 입출력 예 설명
- 예 #1: 0초 출발에 앞의 두 명이 탑니다. 3초 출발에는 0초에 도착해 남아 있던 한 명과 1초에 도착한 한 명이 탑니다. 7초에 도착한 손님은 9초 출발에 탑니다.
- 예 #2: 5초 이후 첫 출발은 8초이고 다섯 명까지 탈 수 있으므로 세 명이 함께 탑니다.
- 예 #3: 각자 도착하자마자 있는 출발에 탑니다.
