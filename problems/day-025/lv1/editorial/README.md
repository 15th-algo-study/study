# 해설 — 놀이기구 탑승 시각

## 접근
줄은 배열 순서 그대로이므로 손님을 앞에서부터 한 명씩 보며 "지금 보고 있는 출발"을 따라갑니다. 출발 시각 `dep`과 그 출발의 남은 자리 `seats`를 들고 갑니다.

손님 `i`(도착 `a`)에 대해:

1. `a > dep`이면 이 손님은 지금 출발에 못 탑니다. `a` 이후 첫 출발 `dep = ceil(a / t) × t`로 건너뛰고 자리를 `c`로 되돌립니다.
2. 자리가 없으면(`seats == 0`) 다음 출발 `dep += t`, 자리 `c`.
3. 이 손님은 `dep`에 탑승. `seats--`.

1번 조건은 출발을 **한 번에 건너뛰는** 것이 핵심입니다. 0초부터 `t`초씩 출발을 하나하나 넘기면 `t = 1`, 도착 시각 10^9에서 10억 번 돌게 됩니다.

## 주의할 점
- `ceil(a / t) × t`는 `(a + t - 1) / t * t`로 계산합니다. `a + t - 1`이 최대 2×10^9 - 1이라 `int`를 넘으므로 `long`으로 계산하세요.
- 출발 시각은 최대 약 10^9 + (n / c) × t ≈ 2×10^14까지 커질 수 있어 `dep`도 `long`이어야 합니다.
- `c`명이 꽉 찬 뒤 다음 손님이 아직 도착하지 않았다면, 2번보다 1번(건너뛰기)이 먼저 적용되어야 빈 출발이 생기지 않습니다. 모범 풀이의 조건 순서를 확인하세요.

## 복잡도
- 시간 O(n), 공간 O(n)
