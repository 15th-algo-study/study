# [lv3] 스키장 개장일 질의

스키장에서 `n`일 동안 매일 아침 적설량을 쟀습니다. `i`번째 날(0부터 셈)의 적설량은 `snow[i]`(cm)입니다.

슬로프마다 개장에 필요한 적설량이 다릅니다. 질의 `[d, x]`는 "`d`일 **이후**(`d + 1`일부터) 적설량이 `x` 이상인 첫 번째 날은 언제인가"를 묻습니다. 그런 날이 없으면 `-1`입니다.

질의 목록 `queries`가 주어질 때, 각 질의의 답을 질의 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `snow`의 길이 `n` ≤ 1,000,000
- 0 ≤ `snow[i]` ≤ 1,000,000,000
- 1 ≤ `queries`의 길이 ≤ 1,000,000
- `queries[j] = [d, x]`, 0 ≤ `d` ≤ `n - 1`, 1 ≤ `x` ≤ 1,000,000,000

## 입출력 예

| snow | queries | result |
|---|---|---|
| [3, 5, 2, 8, 4, 8] | [[0, 5], [1, 5], [1, 9], [3, 4], [4, 8]] | [1, 3, -1, 4, 5] |
| [1, 1, 1] | [[0, 1], [2, 1], [0, 2]] | [1, -1, -1] |
| [10, 1, 2, 3, 10] | [[0, 10], [0, 3], [1, 3], [3, 10]] | [4, 3, 3, 4] |

## 입출력 예 설명
- 예 #1: 0일 이후 5 이상인 첫날은 1일. 1일 이후로는 2일(2)을 지나 3일(8). 9 이상인 날은 없어 -1. 3일 이후 4 이상은 4일, 4일 이후 8 이상은 5일.
- 예 #2: 2일 이후에는 날이 없으므로 -1, 2 이상인 날은 없으므로 -1.
- 예 #3: 0일 이후 10 이상은 4일, 3 이상은 3일입니다.
