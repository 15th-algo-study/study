# [lv2] 그림판 되돌리기

그림판에서 사용자가 내린 명령 기록이 2차원 배열 `ops`로 주어집니다. 각 원소는 `[종류, 값]` 꼴입니다.

- `[1, x]`: 번호가 `x`인 획을 하나 그립니다.
- `[2, k]`: **되돌리기** — 그림을 "직전 `k`개 명령을 내리기 전의 상태"로 되돌립니다. 되돌리기 명령도 명령 하나로 세므로, 되돌리기를 되돌리면 지워졌던 획이 되살아납니다. 앞선 명령이 `k`개보다 적으면 처음 상태(빈 그림)로 돌아갑니다.

모든 명령을 처리한 뒤 그림에 남아 있는 획의 번호를 **그린 순서대로** 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 남은 획이 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `ops`의 길이 ≤ 1,000,000
- 종류는 1 또는 2입니다.
- 1 ≤ `x` ≤ 1,000,000,000 (획 번호는 중복될 수 있습니다)
- 1 ≤ `k` ≤ 1,000,000

## 입출력 예

| ops | result |
|---|---|
| [[1, 1], [1, 2], [2, 1], [1, 3]] | [1, 3] |
| [[1, 1], [1, 2], [2, 1], [2, 1]] | [1, 2] |
| [[1, 5], [2, 1], [1, 6], [2, 2]] | [5] |

## 입출력 예 설명
- 예 #1: [1, 2]를 그린 뒤 되돌리기 1로 [1], 3을 그려 [1, 3].
- 예 #2: 되돌리기 1로 [1]이 되었다가, 다시 되돌리기 1은 "직전 명령(되돌리기)을 내리기 전"인 [1, 2]로 돌아갑니다.
- 예 #3: [5] → 되돌리기 1로 [] → 6을 그려 [6] → 되돌리기 2는 두 명령 전, 즉 5만 그려져 있던 상태 [5]로 돌아갑니다.
