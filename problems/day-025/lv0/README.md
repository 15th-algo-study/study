# [lv0] 양 끝에서 먹는 사탕

사탕 `n`개가 한 줄로 놓여 있고, 각 사탕의 크기가 왼쪽부터 배열 `candies`에 담겨 있습니다. 사탕은 줄의 **양쪽 끝**에서만 집을 수 있습니다.

사탕이 없어질 때까지 다음을 반복합니다.

- 양쪽 끝 사탕 중 **더 작은** 것을 먹습니다. 크기가 같으면 **왼쪽** 것을 먹습니다.
- 사탕이 하나만 남았으면 그것을 먹습니다.

먹은 사탕의 크기를 먹은 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `candies`의 길이 ≤ 500,000
- 1 ≤ `candies[i]` ≤ 1,000,000,000

## 입출력 예

| candies | result |
|---|---|
| [3, 1, 4, 2] | [2, 3, 1, 4] |
| [5, 5, 5] | [5, 5, 5] |
| [2, 9, 1] | [1, 2, 9] |

## 입출력 예 설명
- 예 #1: 3과 2 중 2 → [3, 1, 4]에서 3과 4 중 3 → [1, 4]에서 1 → 4.
- 예 #2: 모두 같으므로 매번 왼쪽을 먹습니다.
- 예 #3: 2와 1 중 1 → [2, 9]에서 2 → 9.
