# [lv3] 양념 가방과 요리 점수

요리 대회에 출전하려고 합니다. 대회장에는 양념이 없어서 집에 있는 양념 `k`종류 중 일부를 가방에 챙겨 가야 합니다.

준비한 레시피는 `n`개입니다. `i`번 레시피는 `needs[i]`에 적힌 양념이 **모두** 있어야 만들 수 있고, 만들면 `scores[i]`점을 받습니다. `needs[i]`는 길이 `k`의 문자열로, `j`번째 문자가 `'1'`이면 `j`번 양념이 필요하다는 뜻입니다. 양념은 쓴다고 없어지지 않으므로 챙겨 간 양념으로 만들 수 있는 레시피는 전부 만듭니다.

가방 크기 때문에 양념을 몇 종류까지 챙길 수 있는지는 아직 모릅니다. 그래서 `c = 0, 1, …, k` 각각에 대해, **양념을 최대 `c`종류 챙길 때 받을 수 있는 점수 합의 최댓값**을 미리 계산해 두려고 합니다.

`needs`와 `scores`가 주어질 때, `c`번째 원소가 "최대 `c`종류를 챙길 때의 최대 점수 합"인 길이 `k + 1`의 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `needs`의 길이 `n` ≤ 1,000,000
- `needs`의 모든 원소는 길이가 같고(= `k`), 1 ≤ `k` ≤ 17 이며 `'0'`과 `'1'`로만 이루어져 있습니다.
- `scores`의 길이는 `n`이고, 1 ≤ `scores[i]` ≤ 1,000,000,000 입니다.
- 점수 합이 `int` 범위를 넘을 수 있으므로 `long[]`을 return 합니다.
- 양념이 전혀 필요 없는 레시피(`"00…0"`)도 있을 수 있습니다.

## 입출력 예

| needs | scores | result |
|---|---|---|
| ["10", "01", "11"] | [5, 7, 10] | [0, 7, 22] |
| ["000", "101", "010", "111"] | [3, 4, 5, 6] | [3, 8, 8, 18] |
| ["1"] | [100] | [0, 100] |

## 입출력 예 설명
- 예 #1: 양념을 하나도 안 챙기면 만들 수 있는 레시피가 없어 0점입니다. 한 종류만 챙긴다면 1번 양념을 챙겨 7점이 최대입니다. 두 종류를 다 챙기면 세 레시피 모두 만들어 22점입니다.
- 예 #2: 0종류: `"000"` 레시피만 만들어 3점. 1종류: 1번 양념을 챙기면 `"000"`, `"010"`으로 8점. 2종류: 어떤 두 종류를 골라도 8점이 최대입니다 ({0, 2}는 3 + 4 = 7점). 3종류: 전부 만들어 18점.
- 예 #3: 양념을 챙기지 않으면 0점, 챙기면 100점입니다.
