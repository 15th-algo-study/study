# [lv2] 캠핑 배낭 꾸리기

캠핑 장비 `n`개의 무게가 배열 `weights`에 들어 있습니다. 배낭에는 총 무게가 `limit` 이하가 되도록만 장비를 넣을 수 있습니다. 장비는 모두 서로 다른 물건이므로 무게가 같아도 구별합니다.

`weights`와 `limit`가 주어질 때, 배낭에 넣을 장비를 고르는 방법의 수를 return 하도록 `solution` 함수를 완성해 주세요. 아무것도 넣지 않는 방법도 한 가지로 셉니다.

## 제한사항
- 1 ≤ `weights`의 길이 `n` ≤ 40
- 1 ≤ `weights`의 원소 ≤ 1,000,000,000
- 0 ≤ `limit` ≤ 40,000,000,000 (`long`)
- 조건을 만족하는 방법의 수는 **2,000,000을 넘지 않음**이 보장됩니다.

## 입출력 예

| weights | limit | result |
|---|---|---|
| [3, 5, 8] | 8 | 5 |
| [10, 20, 30, 40] | 25 | 3 |
| [1, 1, 1] | 0 | 1 |

## 입출력 예 설명
- 예 #1: 넣을 수 있는 조합은 {}, {3}, {5}, {8}, {3, 5}의 5가지입니다. {3, 8}, {5, 8}, {3, 5, 8}은 8을 넘습니다.
- 예 #2: {}, {10}, {20}의 3가지입니다.
- 예 #3: 아무것도 넣지 못하므로 빈 배낭 한 가지입니다.
