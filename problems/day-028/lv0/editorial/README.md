# 해설 — 집안일 달력

## 접근
1일부터 `n`일까지 하루씩 돌면서 `day % a == 0`(청소)과 `day % b == 0`(장보기)을 확인합니다.

- 둘 중 하나라도 참이면 첫 번째 답을, 둘 다 참이면 두 번째 답을 1씩 늘립니다.

`n ≤ 1,000,000`이므로 반복 100만 번이면 충분합니다. (수학적으로는 `n/a + n/b − n/lcm(a,b)`로 바로 구할 수도 있지만, 반복문으로 배수를 세는 연습이 목적입니다.)

## 주의할 점
- 날짜는 1일부터 시작합니다. 0일부터 돌리면 `0 % a == 0`이라 하루가 더 세어집니다.
- `a == b`이면 "하나라도"와 "둘 다"가 같습니다(예 #2). 조건을 `||`와 `&&`로 따로 쓰면 자연스럽게 맞습니다.
- `a`나 `b`가 `n`보다 크면 해당 집안일은 한 번도 하지 않습니다.

## 복잡도
- 시간 O(n), 공간 O(1)
