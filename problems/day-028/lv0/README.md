# [lv0] 집안일 달력

새해 첫날(1일)부터 `n`일까지의 집안일 달력을 만들려고 합니다.

- 날짜가 `a`의 배수인 날에는 **청소**를 합니다.
- 날짜가 `b`의 배수인 날에는 **장보기**를 합니다.

`n`, `a`, `b`가 주어질 때, `[청소나 장보기 중 하나라도 하는 날의 수, 둘 다 하는 날의 수]`를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 1,000,000
- 1 ≤ `a`, `b` ≤ 1,000,000
- `a`와 `b`는 같을 수 있습니다.

## 입출력 예

| n | a | b | result |
|---|---|---|---|
| 10 | 2 | 3 | [7, 1] |
| 7 | 3 | 3 | [2, 2] |
| 5 | 6 | 7 | [0, 0] |

## 입출력 예 설명
- 예 #1: 청소는 2, 4, 6, 8, 10일, 장보기는 3, 6, 9일입니다. 하나라도 하는 날은 2, 3, 4, 6, 8, 9, 10일로 7일, 둘 다 하는 날은 6일 하루입니다.
- 예 #2: 3일과 6일에 청소와 장보기를 함께 합니다.
- 예 #3: 5일 안에는 6의 배수도 7의 배수도 없습니다.
