# 해설 — 자전거 자물쇠 비밀번호 후보

## 접근
다이얼이 최대 6개이므로 비밀번호 후보는 10^6가지뿐입니다. 후보를 모두 만들어 보는 완전탐색으로 풀 수 있지만, 후보마다 힌트 20만 개를 일일이 확인하면 10^6 × 2×10^5번이라 시간 초과입니다.

힌트는 "어떤 다이얼의 어떤 숫자는 안 된다"는 뜻이므로, 먼저 `forbidden[p][d]` 표(`wheels`×10)에 한 번만 정리합니다. 그다음 재귀로 다이얼을 0번부터 하나씩 채웁니다.

- `p`번 다이얼에 금지되지 않은 숫자 `d`를 놓고, 합에 `d`를 더한 뒤 다음 다이얼로 갑니다.
- 다이얼을 다 채웠을 때 합이 `s`의 배수이면 1가지로 셉니다.

후보마다 표를 O(1)에 조회하므로 전체는 10^6 × 6 정도의 연산입니다. 중첩 반복문 6겹으로 써도 되지만, `wheels`가 입력이므로 재귀가 깔끔합니다.

## 주의할 점
- 합이 0이어도 `s`의 배수입니다(`0 % s == 0`). 모든 다이얼이 0인 후보를 빠뜨리지 마세요.
- 같은 힌트가 반복되어도 표에 표시만 하면 되므로 중복을 따로 처리할 필요가 없습니다.
- 어떤 다이얼의 열 가지 숫자가 모두 금지되면 답은 0입니다. 재귀가 그 다이얼에서 아무 숫자도 못 놓으므로 자연스럽게 0이 됩니다.

## 복잡도
- 시간 O(h + 10^wheels · wheels) (h = 힌트 수), 공간 O(wheels × 10)
