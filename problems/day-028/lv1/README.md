# [lv1] 자전거 자물쇠 비밀번호 후보

자전거 자물쇠에 숫자 다이얼이 `wheels`개 있고, 각 다이얼은 0부터 9까지의 숫자 하나를 가리킵니다. 비밀번호를 잊어버렸지만 다음 사실은 기억합니다.

- 힌트 목록 `hints`: 각 원소 `[p, d]`는 "`p`번 다이얼(0번부터)의 숫자는 `d`가 **아니다**"라는 뜻입니다. 같은 힌트가 여러 번 나올 수 있습니다.
- 모든 다이얼 숫자의 합은 `s`의 배수입니다. (0도 `s`의 배수입니다.)

`wheels`, `hints`, `s`가 주어질 때, 기억과 모순되지 않는 비밀번호가 몇 가지인지 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `wheels` ≤ 6
- 0 ≤ `hints`의 길이 ≤ 200,000
- `hints`의 각 원소는 `[p, d]` 형태이며 0 ≤ `p` < `wheels`, 0 ≤ `d` ≤ 9 입니다.
- 1 ≤ `s` ≤ 60

## 입출력 예

| wheels | hints | s | result |
|---|---|---|---|
| 2 | [[0, 0], [1, 9]] | 9 | 9 |
| 1 | [] | 3 | 4 |
| 3 | [[0, 1], [0, 1], [2, 5]] | 1 | 810 |

## 입출력 예 설명
- 예 #1: 0번 다이얼은 0이 아니고 1번 다이얼은 9가 아니며, 두 숫자의 합이 9의 배수(0, 9, 18)여야 합니다. 합 0은 `00`뿐인데 0번 다이얼이 0이라 안 되고, 합 18은 `99`뿐인데 1번 다이얼이 9라 안 됩니다. 합 9인 `18, 27, 36, 45, 54, 63, 72, 81, 90`은 모두 가능하므로 9가지입니다.
- 예 #2: 한 자리 숫자 중 3의 배수는 0, 3, 6, 9입니다.
- 예 #3: 합은 항상 1의 배수이므로 힌트만 보면 됩니다. 0번 다이얼 9가지 × 1번 다이얼 10가지 × 2번 다이얼 9가지 = 810가지입니다.
