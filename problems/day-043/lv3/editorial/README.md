# 해설 — 자수 띠의 균형 조각

## 접근
"모든 색이 `m`번 이상"이라는 조건은 구간을 늘린다고 유지되지도, 줄인다고 유지되지도 않습니다 (늘리면 새 색이 1개 들어와 깨지고, 줄이면 어떤 색이 `m` 아래로 떨어집니다). 그래서 그대로는 슬라이딩 윈도우를 쓸 수 없습니다.

**핵심 관찰**: 답이 되는 조각에 쓰인 **색의 종류 수 `h`를 고정**하면 조건이 단조로워집니다. 색이 26가지뿐이므로 `h = 1, 2, …, 26`을 모두 시도합니다.

`h`를 고정했을 때:
1. 창 안의 종류 수 `distinct`가 `h`를 넘지 않도록 유지하는 전형적인 투 포인터 창을 돌립니다 (`distinct > h`이면 왼쪽을 올림).
2. 동시에 "개수가 `m` 이상인 색의 수" `satisfied`를 유지합니다 (`cnt`가 `m-1 → m`이면 ++, `m → m-1`이면 −−).
3. `distinct == h`이고 `satisfied == h`이면 창 안의 모든 색이 `m`번 이상이므로 길이로 답을 갱신합니다.

왜 맞는가: 최적 조각의 종류 수가 `h*`라 하면, `h = h*`인 패스에서 그 조각의 오른쪽 끝 `r`에 도달했을 때 창 `[l, r]`은 종류 수 ≤ `h*`인 가장 긴 창이므로 최적 조각을 포함합니다. 최적 조각 밖에서 `[l, r]` 안에 추가된 칸들도 같은 `h*`가지 색뿐이고(종류가 늘면 `h*`를 넘음) 개수만 늘어나므로 `[l, r]`도 균형 조각이며 길이는 최적 이상입니다.

## 주의할 점
- 왼쪽 끝마다 오른쪽으로 늘려 보는 O(n²) 풀이는 조건이 단조롭지 않아 중간에 끊을 수도 없고, n = 5 × 10^5에서 10^11번이라 시간 초과입니다.
- `satisfied`는 `cnt`가 정확히 `m`을 지나는 순간에만 갱신합니다. `m = 1`이면 색이 들어오는 순간 바로 만족입니다.
- 각 패스마다 `cnt` 배열을 새로 비워야 합니다.
- 분할 정복(개수가 `m` 미만인 색을 경계로 쪼개기)으로도 풀 수 있습니다.

## 복잡도
- 시간 O(26 n), 공간 O(26)
