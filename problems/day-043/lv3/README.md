# [lv3] 자수 띠의 균형 조각

자수 띠 한 줄에 색실로 수를 놓았습니다. 띠의 각 칸에 쓰인 실 색이 영문 소문자 하나로 표현되어, 띠 전체는 문자열 `s`로 주어집니다.

띠에서 **연속한 구간**을 잘라 조각을 만드는데, 조각 안에 **쓰인 모든 색**이 각각 **`m`칸 이상** 등장하면 그 조각을 "균형 조각"이라 부릅니다 (조각에 전혀 쓰이지 않은 색은 상관없습니다).

균형 조각 중 가장 긴 것의 길이를 return 하도록 `solution` 함수를 완성해 주세요. 균형 조각이 하나도 없으면 0을 return 합니다.

## 제한사항
- 1 ≤ `s`의 길이 `n` ≤ 500,000
- `s`는 영문 소문자로만 이루어져 있습니다.
- 1 ≤ `m` ≤ `n`

## 입출력 예

| s | m | result |
|---|---|---|
| "aaabbbcd" | 3 | 6 |
| "ababbc" | 2 | 5 |
| "abab" | 3 | 0 |

## 입출력 예 설명
- 예 #1: "aaabbb"는 a와 b가 각각 3칸이라 균형 조각입니다. c나 d를 포함하면 그 색이 1칸뿐이라 안 됩니다.
- 예 #2: "ababb"는 a가 2칸, b가 3칸입니다. c를 포함하면 c가 1칸뿐입니다.
- 예 #3: 어떤 구간을 잡아도 a 또는 b가 3칸 미만입니다.
