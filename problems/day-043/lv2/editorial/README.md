# 해설 — 꽃길 산책 코스

## 접근
먼저 배열 전체에 등장하는 종류 수 `total`을 셉니다. 그다음 **"모든 종류를 포함한다"는 조건은 구간을 늘리면 유지되고 줄이면 깨질 수 있는 단조 조건**이므로 가변 창으로 풉니다.

1. 종류별 개수 `cnt`와 "창 안에 있는 종류 수" `have`를 유지하며 오른쪽 끝 `r`을 늘립니다. `cnt[v]`가 0 → 1이 되면 `have++`.
2. `have == total`인 동안 창 길이로 답을 갱신하고 왼쪽 끝을 올립니다. 빼는 값의 `cnt`가 1 → 0이 되면 `have--`가 되어 while 문이 멈춥니다.

끝이 `r`인 구간 중 가장 짧은 유효 구간을 매번 확인하므로 전체 최소를 놓치지 않습니다.

## 주의할 점
- 종류 수는 "배열에 **실제로 등장하는**" 종류 수입니다. 번호의 최댓값이 아닙니다.
- `have`는 개수 배열의 0↔1 경계에서만 바뀝니다. 같은 종류가 또 들어와도 종류 수는 그대로입니다.
- 종류 번호가 20만 이하라 `HashMap` 대신 `int[200001]` 배열이 빠릅니다. n이 100만이므로 상수도 신경 쓰세요.
- 왼쪽 끝마다 오른쪽으로 늘려 보는 O(n²) 풀이는 n = 10^6에서 시간 초과입니다.

## 복잡도
- 시간 O(n), 공간 O(200000)
