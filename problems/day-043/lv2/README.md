# [lv2] 꽃길 산책 코스

둘레길을 따라 꽃 `n`송이가 한 줄로 피어 있고, `i`번째 꽃의 종류 번호는 `flowers[i]`입니다. 식물 도감을 채우려는 산책객은 **연속한 구간**을 골라 그 구간의 꽃만 관찰합니다.

둘레길에 피어 있는 **모든 종류**의 꽃을 적어도 한 송이씩 볼 수 있는 연속 구간 중 **가장 짧은 구간의 길이**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `flowers`의 길이 `n` ≤ 1,000,000
- 1 ≤ `flowers`의 원소 ≤ 200,000

## 입출력 예

| flowers | result |
|---|---|
| [1, 2, 1, 3, 2, 1] | 3 |
| [7, 7, 7] | 1 |
| [1, 2, 2, 2, 1, 3] | 3 |

## 입출력 예 설명
- 예 #1: 종류는 1, 2, 3입니다. [2, 1, 3](1~3번)이 세 종류를 모두 포함하는 가장 짧은 구간입니다.
- 예 #2: 종류가 하나뿐이라 한 송이면 됩니다.
- 예 #3: 3번 종류는 맨 끝에만 있으므로 [2, 1, 3](3~5번)이 답입니다.
