# [lv1] 전기차 급속 충전 시간

전기차 충전기는 전력 사정에 따라 분마다 충전량이 달라집니다. 앞으로 `n`분 동안 `i`번째 분(0번부터 셈)에 충전되는 양이 배열 `charge`에 예보되어 있습니다.

운전자는 **연속한 몇 분** 동안만 충전기를 쓸 수 있습니다. 충전량의 합이 `target` 이상이 되는 연속 구간 중 **가장 짧은 구간의 길이(분)** 를 return 하도록 `solution` 함수를 완성해 주세요. 어떤 연속 구간으로도 `target`에 못 미치면 -1을 return 합니다.

## 제한사항
- 1 ≤ `charge`의 길이 `n` ≤ 500,000
- 0 ≤ `charge`의 원소 ≤ 10,000
- 1 ≤ `target` ≤ 1,000,000,000

## 입출력 예

| charge | target | result |
|---|---|---|
| [2, 1, 5, 2, 3, 1] | 7 | 2 |
| [1, 1, 1] | 5 | -1 |
| [3, 0, 0, 4] | 7 | 4 |

## 입출력 예 설명
- 예 #1: [5, 2]의 합이 7이라 2분이면 됩니다. 한 분만으로는 7 이상인 곳이 없습니다.
- 예 #2: 전부 더해도 3이라 불가능합니다.
- 예 #3: 가운데 두 분은 충전이 안 되지만, 7을 채우려면 양 끝을 모두 포함해야 하므로 4분입니다.
