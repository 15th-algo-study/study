# 해설 — 감자 무게 등급 나누기

## 접근
원소를 하나씩 보며 세 조건 중 어디에 드는지 세면 됩니다. `if (w < lo) … else if (w > hi) … else …` 순서로 쓰면 가운데 조건을 따로 쓰지 않아도 됩니다.

배열이 정렬되어 있으므로 `w > hi`를 만난 뒤에는 나머지가 전부 대형이라는 것도 알 수 있지만(`n - i`개), 한 번 훑는 O(n)으로도 충분합니다.

## 주의할 점
- 경계는 모두 **포함**입니다. `lo`와 `hi`에 딱 걸리는 값은 정품입니다 (예 #3).
- `lo = hi`인 경우에도 같은 코드로 처리됩니다.
- 반환 배열은 `[소형, 정품, 대형]` 순서입니다.

## 복잡도
- 시간 O(n), 공간 O(1)
