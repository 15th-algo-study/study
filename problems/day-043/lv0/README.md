# [lv0] 감자 무게 등급 나누기

수확한 감자 `n`개의 무게(그램)가 **오름차순**으로 정렬된 배열 `weights`로 주어집니다. 무게가 `lo` 이상 `hi` 이하이면 "정품", `lo` 미만이면 "소형", `hi` 초과이면 "대형"으로 분류합니다.

소형, 정품, 대형의 개수를 순서대로 담은 길이 3인 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `weights`의 길이 `n` ≤ 1,000,000
- 1 ≤ `weights`의 원소 ≤ 1,000,000,000, 오름차순으로 정렬되어 있습니다 (같은 값 가능)
- 0 ≤ `lo` ≤ `hi` ≤ 1,000,000,000

## 입출력 예

| weights | lo | hi | result |
|---|---|---|---|
| [80, 95, 100, 120, 150, 200] | 100 | 150 | [2, 3, 1] |
| [1, 2, 3] | 5 | 10 | [3, 0, 0] |
| [50, 50, 50] | 50 | 50 | [0, 3, 0] |

## 입출력 예 설명
- 예 #1: 80, 95는 소형, 100·120·150은 정품(경계 포함), 200은 대형입니다.
- 예 #2: 모두 `lo`보다 가벼워 소형입니다.
- 예 #3: `lo = hi = 50`이고 모두 50이라 전부 정품입니다.
