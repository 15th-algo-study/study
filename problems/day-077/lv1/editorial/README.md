# 해설 — 스탬프 투어 이동 시간

## 접근
구간은 최대 20만 개지만 놀이기구는 300개뿐입니다. 구간마다 최단 경로를 새로 찾지 말고, **모든 쌍의 최단 거리를 한 번에** 구해 두면 각 구간은 표를 한 번 보는 것으로 끝납니다.

1. 플로이드–워셜로 `dist[i][j]`(i에서 j까지 최단 시간)를 구합니다. 산책로가 한 방향이므로 `dist[a][b]`만 채웁니다.
2. `route`의 이웃한 두 원소 `(u, v)`마다 `dist[u][v]`를 더합니다. 하나라도 INF면 -1입니다.

## 주의할 점
- 한 방향 산책로이므로 `dist[b][a]`를 같이 채우면 틀립니다(예 #2에서 3 → 0이 생겨 버림).
- 같은 쌍의 산책로가 여러 개면 가장 짧은 것만 남기고, `a = b`인 산책로는 `dist[a][a] = 0`을 덮어쓰지 않게 `min`으로 넣습니다.
- 합계는 최대 199,999 × 299 × 1,000 ≈ 6 × 10^10이라 `long`으로 더합니다.
- 구간마다 다익스트라를 돌리면 20만 번이라 시간 초과입니다. 플로이드–워셜은 300³ = 2.7 × 10^7번이면 끝납니다.

## 복잡도
- 시간 O(n³ + m + |route|), 공간 O(n²)
