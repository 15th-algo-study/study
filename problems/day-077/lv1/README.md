# [lv1] 스탬프 투어 이동 시간

놀이공원에 놀이기구 `n`개(0번 ~ `n - 1`번)가 있고, 놀이기구 사이에는 **한 방향으로만** 걸을 수 있는 산책로가 있습니다. 산책로 정보 `paths`의 원소 `[a, b, t]`는 `a`번에서 `b`번으로 `t`분 만에 걸어갈 수 있다는 뜻입니다.

스탬프 투어는 `route`에 적힌 놀이기구를 **적힌 순서대로** 들러 도장을 찍는 행사입니다. `route[0]`에서 출발해 `route[1]`, `route[2]`, … 순서로 이동하며, 각 구간은 가장 빠른 길로 걷습니다. 구간 중간에 다른 놀이기구를 지나가도 됩니다. 도장을 찍는 시간은 생각하지 않습니다.

투어 전체에 걸리는 최소 시간을 return 하도록 `solution` 함수를 완성해 주세요. 한 구간이라도 걸어서 갈 수 없으면 -1을 return 합니다. 시간이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

- `route`에 같은 놀이기구가 연달아 나오면 그 구간은 0분입니다.
- 같은 두 놀이기구 사이에 산책로가 여러 개일 수 있고, `a = b`인 산책로(제자리를 도는 길)가 있을 수도 있습니다.

## 제한사항
- 2 ≤ `n` ≤ 300
- 0 ≤ `paths`의 길이 ≤ 30,000
- `paths`의 원소는 `[a, b, t]` 형태이며 0 ≤ `a`, `b` < `n`, 1 ≤ `t` ≤ 1,000
- 2 ≤ `route`의 길이 ≤ 200,000
- 0 ≤ `route`의 원소 < `n`

## 입출력 예

| n | paths | route | result |
|---|---|---|---|
| 4 | [[0, 1, 5], [1, 2, 3], [2, 0, 2], [0, 2, 10], [2, 3, 4]] | [0, 2, 2, 1] | 15 |
| 4 | [[0, 1, 5], [1, 2, 3], [2, 0, 2], [0, 2, 10], [2, 3, 4]] | [1, 3, 0] | -1 |
| 2 | [[0, 1, 1000], [1, 0, 1]] | [0, 1, 0, 1, 0] | 2002 |

## 입출력 예 설명
- 예 #1
  - 0 → 2: 직통 산책로(10분)보다 0 → 1 → 2(5 + 3 = 8분)가 빠릅니다.
  - 2 → 2: 같은 곳이라 0분입니다.
  - 2 → 1: 2 → 0 → 1(2 + 5 = 7분)입니다.
  - 합계 8 + 0 + 7 = 15분입니다.
- 예 #2: 1 → 3은 1 → 2 → 3(7분)으로 갈 수 있지만, 3번에서 나가는 산책로가 없어 3 → 0을 갈 수 없습니다.
- 예 #3: 1000 + 1 + 1000 + 1 = 2002분입니다.
