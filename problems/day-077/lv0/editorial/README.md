# 해설 — 음악 분수 노즐 제어

## 접근
`i`번 비트만 1인 마스크 `1 << i`를 만들어 비트 연산 하나로 처리합니다.

| 명령 | 연산 | 이유 |
|---|---|---|
| `ON i` | `state \|= 1 << i` | OR 은 그 자리를 1로 만들고 나머지는 그대로 |
| `OFF i` | `state &= ~(1 << i)` | `~`로 그 자리만 0인 마스크를 만들어 AND |
| `FLIP i` | `state ^= 1 << i` | XOR 1은 뒤집기, XOR 0은 그대로 |
| `INVERT` | `state ^= (1 << n) - 1` | 0번~n−1번 비트가 모두 1인 마스크와 XOR |

명령 문자열은 공백으로 나눠 앞부분으로 종류를, 뒷부분을 `Integer.parseInt`로 번호를 얻습니다.

## 주의할 점
- `INVERT`를 `state = ~state`로 하면 `n`번 이상의 비트(31번 부호 비트 포함)까지 켜져 음수가 됩니다. 반드시 `n`개 비트만 뒤집도록 마스크를 씁니다.
- `(1 << n) - 1`은 `n ≤ 30`이라 넘치지 않습니다. (`n = 32`였다면 `1 << 32`는 자바에서 `1`이 되어 틀립니다.)
- `OFF`에서 `state ^= 1 << i`를 쓰면 꺼진 노즐이 켜집니다. 끄기는 AND NOT 입니다.

## 복잡도
- 시간 O(명령 수), 공간 O(1)
