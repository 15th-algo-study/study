# [lv0] 음악 분수 노즐 제어

음악 분수에 노즐 `n`개(0번 ~ `n - 1`번)가 있습니다. 제어기는 노즐 상태를 정수 하나로 기억합니다. 정수의 `i`번 비트(가장 오른쪽이 0번)가 1이면 `i`번 노즐이 켜져 있다는 뜻입니다. 처음에는 모든 노즐이 꺼져 있습니다(상태 0).

제어기에는 다음 명령이 순서대로 들어옵니다.

- `"ON i"`: `i`번 노즐을 켭니다. 이미 켜져 있으면 그대로입니다.
- `"OFF i"`: `i`번 노즐을 끕니다. 이미 꺼져 있으면 그대로입니다.
- `"FLIP i"`: `i`번 노즐이 켜져 있으면 끄고, 꺼져 있으면 켭니다.
- `"INVERT"`: `n`개 노즐 모두를 FLIP 합니다.

노즐 수 `n`과 명령 목록 `commands`가 주어질 때, 모든 명령을 실행한 뒤의 상태를 정수로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 30
- 1 ≤ `commands`의 길이 ≤ 200,000
- `commands`의 원소는 `"ON i"`, `"OFF i"`, `"FLIP i"`, `"INVERT"` 중 하나이며 0 ≤ `i` < `n`입니다.

## 입출력 예

| n | commands | result |
|---|---|---|
| 4 | ["ON 0", "ON 2", "FLIP 1", "OFF 0", "INVERT"] | 9 |
| 3 | ["FLIP 2", "FLIP 2", "OFF 1"] | 0 |
| 30 | ["INVERT", "OFF 29"] | 536870911 |

## 입출력 예 설명
- 예 #1: 상태를 4자리 2진수로 쓰면 `0000` → `0001` → `0101` → `0111` → `0110` → `1001` 이고, `1001`₂ = 9입니다.
- 예 #2: 2번 노즐을 두 번 뒤집으면 원래대로 꺼집니다. 꺼진 1번 노즐을 끄는 것은 아무 변화가 없습니다.
- 예 #3: `INVERT` 뒤에는 0번~29번 노즐이 모두 켜져 2^30 − 1 = 1,073,741,823입니다. 29번을 끄면 2^29 − 1 = 536,870,911입니다.
