# [lv2] 가장 가까운 소방서

도시의 교차로 `n`개(1번 ~ `n`번)가 양방향 도로로 이어져 있습니다. 일부 교차로에는 소방서가 있습니다. 화재 신고가 들어오면 신고 지점에서 **도로를 따라 가장 가까운** 소방서가 출동합니다.

도로 정보 `roads`, 소방서가 있는 교차로 목록 `stations`, 신고가 들어온 교차로 목록 `houses`가 주어집니다. `houses`의 각 교차로마다 가장 가까운 소방서까지의 도로 거리를 차례로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

- `roads`의 원소 `[a, b, len]`은 교차로 `a`와 `b`를 잇는 길이 `len`의 양방향 도로입니다. 같은 두 교차로를 잇는 도로가 여러 개이거나 `a = b`인 도로(회전 교차로)가 있을 수 있습니다.
- 신고 지점에 소방서가 있으면 거리는 0입니다.
- 어떤 소방서에도 도로로 갈 수 없으면 -1입니다.
- 거리가 `int` 범위를 넘을 수 있으므로 `long[]`로 return 합니다.

## 제한사항
- 1 ≤ `n` ≤ 200,000
- 0 ≤ `roads`의 길이 ≤ 300,000
- `roads`의 원소는 `[a, b, len]` 형태이며 1 ≤ `a`, `b` ≤ `n`, 1 ≤ `len` ≤ 1,000,000,000
- 1 ≤ `stations`의 길이 ≤ `n`, `stations`의 원소는 서로 다르고 1 이상 `n` 이하입니다.
- 1 ≤ `houses`의 길이 ≤ 200,000, `houses`의 원소는 1 이상 `n` 이하입니다(중복 가능).

## 입출력 예

| n | roads | stations | houses | result |
|---|---|---|---|---|
| 6 | [[1, 2, 3], [2, 3, 4], [3, 4, 2], [4, 5, 7], [1, 5, 20]] | [1, 4] | [3, 5, 6, 1] | [2, 7, -1, 0] |
| 3 | [[1, 2, 1000000000], [2, 3, 1000000000]] | [3] | [1] | [2000000000] |

## 입출력 예 설명
- 예 #1
  - 3번: 4번 소방서까지 2, 1번 소방서까지 7(3 → 2 → 1) → 2
  - 5번: 4번 소방서까지 7, 1번 소방서까지 20 → 7
  - 6번: 이어진 도로가 없어 -1
  - 1번: 소방서가 있는 곳이라 0
- 예 #2: 1 → 2 → 3으로 20억입니다. `int` 범위를 넘습니다.
