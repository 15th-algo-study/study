# 해설 — 가장 가까운 소방서

## 접근
"각 지점에서 가장 가까운 소방서까지 거리"는 "**아무** 소방서에서 그 지점까지 오는 최단 거리"와 같습니다(도로가 양방향이므로).

그러면 출발점이 여러 개인 최단 거리 문제가 됩니다. **모든 소방서를 거리 0으로 동시에 우선순위 큐에 넣고** 다익스트라를 한 번 돌리면 됩니다. 이것은 "모든 소방서와 길이 0인 도로로 이어진 가상의 본부 정점"에서 다익스트라를 돌리는 것과 같아서 정당합니다.

다익스트라가 끝나면 `dist[v]`가 v에서 가장 가까운 소방서까지 거리이므로, `houses`의 각 원소는 표를 보기만 하면 됩니다.

## 주의할 점
- 소방서마다 다익스트라를 돌리면 소방서가 수만 개일 때 시간 초과입니다.
- 신고마다 다익스트라를 돌리고 소방서를 처음 만날 때 멈추는 방법도, 소방서가 몇 개 없고 멀리 있으면 신고마다 그래프의 상당 부분을 훑어 시간 초과입니다.
- 거리는 최대 약 2 × 10^14라 `long`입니다.
- `a = b`인 도로는 거리를 줄이지 못하므로 그대로 넣어도 상관없습니다.

## 복잡도
- 시간 O((n + m) log m + q), 공간 O(n + m)
