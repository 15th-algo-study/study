# [lv3] 반값 통행권

도시 `n`개(0번 ~ `n - 1`번)가 양방향 고속도로로 이어져 있습니다. 고속도로를 한 번 지날 때마다 그 도로의 통행료를 냅니다. 0번 도시에서 `n - 1`번 도시까지 가려고 하는데, 손에 **반값 통행권**이 `k`장 있습니다.

- 고속도로를 지날 때 통행권 한 장을 내면 그 도로의 통행료가 절반이 됩니다. 절반이 정수가 아니면 버림합니다(통행료 7 → 3).
- 한 번 지날 때 통행권은 최대 한 장만 쓸 수 있습니다.
- 통행권을 다 쓰지 않아도 됩니다.

고속도로 정보 `highways`와 통행권 수 `k`가 주어질 때, 0번 도시에서 `n - 1`번 도시까지 가는 최소 통행료를 return 하도록 `solution` 함수를 완성해 주세요. 갈 수 없으면 -1을 return 합니다. 통행료 합이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

- `highways`의 원소 `[a, b, toll]`은 도시 `a`와 `b`를 잇는 통행료 `toll`의 양방향 고속도로입니다. 같은 두 도시를 잇는 고속도로가 여러 개이거나 `a = b`인 고속도로가 있을 수 있습니다.

## 제한사항
- 2 ≤ `n` ≤ 30,000
- 0 ≤ `highways`의 길이 ≤ 60,000
- `highways`의 원소는 `[a, b, toll]` 형태이며 0 ≤ `a`, `b` < `n`, 1 ≤ `toll` ≤ 1,000,000,000
- 0 ≤ `k` ≤ 10

## 입출력 예

| n | highways | k | result |
|---|---|---|---|
| 4 | [[0, 1, 10], [1, 3, 10], [0, 2, 4], [2, 3, 15]] | 1 | 11 |
| 4 | [[0, 1, 10], [1, 3, 10], [0, 2, 4], [2, 3, 15]] | 2 | 9 |
| 3 | [[0, 1, 5]] | 3 | -1 |

## 입출력 예 설명
- 예 #1: 통행권 없이는 0 → 2 → 3(4 + 15 = 19)이 가장 쌉니다. 통행권 한 장을 2 → 3에 쓰면 4 + 7 = 11이고, 0 → 1 → 3에 쓰면 5 + 10 = 15라 11이 최소입니다.
- 예 #2: 두 장이면 0 → 2 → 3은 2 + 7 = 9, 0 → 1 → 3은 5 + 5 = 10이라 9입니다.
- 예 #3: 2번 도시로 가는 고속도로가 없습니다.
