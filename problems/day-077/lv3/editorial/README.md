# 해설 — 반값 통행권

## 접근
"통행권 없이 최단 경로를 구한 뒤 그 경로에서 가장 비싼 도로 `k`개에 통행권을 쓴다"는 틀립니다. 원래는 더 비쌌던 경로가 통행권 덕분에 더 싸질 수 있기 때문입니다. 예를 들어 0 → 1 → 3(40 + 40 = 80)과 0 → 2 → 3(110 + 1 = 111)에서 통행권이 한 장이면, 앞 경로는 20 + 40 = 60이지만 뒤 경로는 55 + 1 = 56입니다.

**관찰**: 같은 도시에 있어도 "통행권을 몇 장 썼는지"에 따라 앞으로 쓸 수 있는 할인이 다릅니다. 그러므로 정점을 `(도시, 사용한 통행권 수 j)`로 늘린 그래프에서 다익스트라를 돌립니다.

상태 `(v, j)`에서 고속도로 `(v, u, toll)`을 지나는 방법은 두 가지입니다.
- 통행권 없이: `(u, j)`로, 비용 `toll`
- 통행권을 쓰고: `j < k`일 때 `(u, j + 1)`로, 비용 `toll / 2`

상태 수는 `n(k + 1)` ≤ 33만, 간선 수는 상태마다 2배라 다익스트라 한 번으로 충분합니다. 답은 `min over j (dist[n-1][j])`입니다(통행권을 다 쓰지 않아도 되므로).

## 주의할 점
- `dist`를 도시 단위 1차원으로만 두면 틀립니다. 통행권을 많이 쓰고 먼저 도착한 경로가, 통행권을 아끼고 조금 늦게 도착한 경로를 막아 버립니다.
- 한 번 지날 때 통행권은 한 장뿐이므로 `toll / 4` 같은 전이는 없습니다.
- 상태를 `j * n + v`처럼 정수 하나로 묶으면 배열 하나로 거리를 관리할 수 있습니다.
- 통행료 합은 최대 약 3 × 10^13이라 `long`입니다.
- 도로 조합을 고르는 완전탐색이나, 도로마다 반값을 적용해 다익스트라를 다시 돌리는 방법은 시간 초과입니다.

## 복잡도
- 상태 수 S = n(k + 1), 전이 수 E = 4m(k + 1)일 때 시간 O((S + E) log E), 공간 O(S + m)
