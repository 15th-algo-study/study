# 해설 — 제방 공사 보고서

## 접근
두 단계입니다. 각 단계에서 "구간을 돌며 하나씩" 처리하면 최악 20만 × 100만 번이라 시간 초과이므로, 두 단계 모두 한 번의 훑기로 끝냅니다.

1. **차분 배열로 구간 갱신**: 공사 `[l, r]`에 `h`를 더하는 것은 `diff[l] += h`, `diff[r + 1] -= h`. 모든 공사를 적은 뒤 누적하면 구간별 층수 `height[i]`가 됩니다.
2. **누적합으로 구간 질의**: `height`의 누적합 `prefix[i + 1] = prefix[i] + height[i]`를 만들면 질의 `[l, r]`의 답은 `prefix[r + 1] − prefix[l]`.

차분 배열을 누적하면 값이 되고, 값을 한 번 더 누적하면 구간 합이 되는 구조입니다. 사실 `diff`를 **두 번 누적**한 배열 하나면 충분합니다.

공사와 질의 모두 두 번호의 순서가 보장되지 않으므로 `min`/`max`로 정리합니다.

## 주의할 점
- 한 구간의 층수는 최대 20만 × 1,000 = 2 × 10^8이라 `int`에 들어가지만, 구간 합은 최대 2 × 10^14이므로 `prefix`와 답은 `long`입니다. 처음부터 모두 `long`으로 두는 편이 안전합니다.
- `diff`는 길이 `n + 1`, `prefix`는 길이 `n + 1`이 필요합니다 (`r + 1 = n`까지 접근).
- 공사를 모두 반영한 **뒤에** 질의에 답합니다. 공사와 질의를 번갈아 처리하는 문제가 아닙니다.

## 복잡도
- 시간 O(n + m + q), 공간 O(n)
