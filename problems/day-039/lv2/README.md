# [lv2] 제방 공사 보고서

강둑을 따라 제방 구간 `n`개가 0번부터 `n − 1`번까지 이어져 있습니다. 처음에는 모래주머니가 하나도 없습니다.

공사 기록 `works`가 주어집니다. 각 기록은 `[a, b, h]`로, `a`번 구간과 `b`번 구간 사이의 모든 구간(양 끝 포함)에 모래주머니를 `h`층씩 더 쌓았다는 뜻입니다. `a`가 `b`보다 클 수도 있습니다.

모든 공사가 끝난 뒤 보고서용 질의 `queries`가 들어옵니다. 각 질의는 `[c, d]`로, `c`번과 `d`번 사이의 모든 구간(양 끝 포함)에 쌓인 층수의 **합**(총 사용한 모래주머니 수)을 묻습니다. 역시 `c`가 `d`보다 클 수 있습니다.

각 질의의 답을 순서대로 담은 `long` 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 1,000,000
- 1 ≤ `works`의 길이 ≤ 200,000
- 0 ≤ `a`, `b`, `c`, `d` < `n`
- 1 ≤ `h` ≤ 1,000
- 1 ≤ `queries`의 길이 ≤ 200,000
- 답이 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| n | works | queries | result |
|---|---|---|---|
| 5 | [[1, 3, 2], [4, 0, 1]] | [[0, 4], [2, 1], [4, 4]] | [11, 6, 1] |
| 3 | [[2, 2, 5]] | [[0, 1], [0, 2]] | [0, 5] |
| 4 | [[0, 3, 1], [3, 0, 1], [1, 2, 1]] | [[1, 2]] | [6] |

## 입출력 예 설명
- 예 #1: 공사 후 층수는 `[1, 3, 3, 3, 1]`입니다. 전체 합 11, 1~2번 합 6, 4번 하나 1입니다.
- 예 #2: 2번 구간에만 5층입니다. 0~1번에는 없습니다.
- 예 #3: 층수는 `[2, 3, 3, 2]`이고 1~2번의 합은 6입니다.
