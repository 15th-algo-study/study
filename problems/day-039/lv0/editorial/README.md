# 해설 — 가로등 전력 사용량 조회

## 접근
조회마다 반복문으로 더하면 조회 하나에 최대 20만 번, 전체 4 × 10^10번이라 시간 초과입니다. **누적 배열**을 미리 만들어 두면 조회 하나가 뺄셈 한 번입니다.

- `prefix[i]` = 0번부터 `i − 1`번까지의 합 (`prefix[0] = 0`, 길이 `n + 1`)
- `l`번부터 `r`번까지(양 끝 포함)의 합 = `prefix[r + 1] − prefix[l]`

조회의 두 번호는 순서가 뒤바뀔 수 있으므로 `l = Math.min(a, b)`, `r = Math.max(a, b)`로 정리한 뒤 공식을 씁니다.

## 주의할 점
- 누적 배열은 `long[]`로 만듭니다. 전체 합이 최대 2 × 10^11입니다.
- `prefix[r + 1] − prefix[l]`에서 `+1`을 빼먹으면 `r`번 가로등이 빠집니다. "앞 `i`개의 합"이라는 정의를 기억하세요.
- `a > b`인 조회를 그대로 `prefix[b + 1] − prefix[a]`에 넣으면 음수가 나옵니다.

## 복잡도
- 시간 O(n + q), 공간 O(n)
