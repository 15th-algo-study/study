# [lv0] 가로등 전력 사용량 조회

도로를 따라 가로등 `n`개가 0번부터 `n − 1`번까지 번호 순서대로 서 있습니다. `usage[i]`는 `i`번 가로등의 하루 전력 사용량(Wh)입니다.

관리 시스템에 조회 `queries`가 여러 개 들어옵니다. 각 조회는 `[a, b]`로, `a`번 가로등과 `b`번 가로등 **사이에 있는 가로등들(양 끝 포함)**의 사용량 합을 묻습니다. `a`가 `b`보다 클 수도 있으며, 그 경우에도 두 번호 사이의 가로등을 모두 더합니다.

각 조회의 답을 순서대로 담은 `long` 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `usage`의 길이 `n` ≤ 200,000
- 0 ≤ `usage`의 원소 ≤ 1,000,000
- 1 ≤ `queries`의 길이 ≤ 200,000
- 0 ≤ `a`, `b` < `n`
- 합이 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| usage | queries | result |
|---|---|---|
| [3, 1, 4, 1, 5] | [[1, 3], [4, 0], [2, 2]] | [6, 14, 4] |
| [10] | [[0, 0]] | [10] |
| [1, 2, 3, 4] | [[3, 1], [0, 3]] | [9, 10] |

## 입출력 예 설명
- 예 #1: `[1, 3]`은 1 + 4 + 1 = 6, `[4, 0]`은 0번부터 4번까지 전부 14, `[2, 2]`는 2번 하나로 4입니다.
- 예 #2: 가로등이 하나뿐입니다.
- 예 #3: `[3, 1]`은 1, 2, 3번의 합 9입니다.
