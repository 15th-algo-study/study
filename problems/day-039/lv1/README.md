# [lv1] 시소의 균형점

긴 널빤지 위에 추 `n`개가 1m 간격으로 놓여 있습니다. 추는 왼쪽부터 0번, 1번, …, `n − 1`번이고 `weights[i]`는 `i`번 추의 무게입니다. 널빤지 자체의 무게는 무시합니다.

받침점을 어느 한 추의 **바로 아래**(위치 `p`)에 두면, 받침점 왼쪽의 추들은 널빤지를 왼쪽으로, 오른쪽의 추들은 오른쪽으로 기울입니다. 기울이는 힘(토크)은 `무게 × 받침점까지의 거리`의 합입니다.

- 왼쪽 토크: `weights[i] × (p − i)`를 `i < p`인 모든 `i`에 대해 더한 값
- 오른쪽 토크: `weights[i] × (i − p)`를 `i > p`인 모든 `i`에 대해 더한 값
- 받침점 바로 위의 추(`i = p`)는 거리가 0이라 토크가 없습니다.

왼쪽 토크와 오른쪽 토크가 같아지는 받침점 위치 `p`를 return 하도록 `solution` 함수를 완성해 주세요. 그런 위치가 없으면 −1을 return 합니다. 무게가 모두 양수이므로 균형이 되는 위치는 둘 이상일 수 없습니다.

## 제한사항
- 1 ≤ `weights`의 길이 `n` ≤ 200,000
- 1 ≤ `weights`의 원소 ≤ 1,000,000
- 토크의 합이 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| weights | result |
|---|---|
| [1, 1, 5, 3] | 2 |
| [4, 2, 4] | 1 |
| [1, 2] | -1 |

## 입출력 예 설명
- 예 #1: `p = 2`일 때 왼쪽 토크는 1 × 2 + 1 × 1 = 3, 오른쪽 토크는 3 × 1 = 3으로 같습니다. 받침점 위의 추(무게 5)는 토크에 영향이 없습니다.
- 예 #2: `p = 1`일 때 양쪽 모두 4입니다.
- 예 #3: `p = 0`이면 오른쪽 토크만 2, `p = 1`이면 왼쪽 토크만 1이라 균형이 되는 위치가 없습니다.
