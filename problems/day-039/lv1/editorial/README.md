# 해설 — 시소의 균형점

## 접근
위치마다 양쪽 토크를 처음부터 더하면 O(n²)으로 시간 초과입니다. 받침점을 **한 칸 오른쪽으로 옮길 때 토크가 어떻게 변하는지** 보면 O(1)로 갱신할 수 있습니다.

받침점이 `p`에서 `p + 1`로 갈 때,

- 왼쪽에 있던 추들은 모두 거리가 1씩 늘어나고, `p`번 추가 거리 1로 새로 들어옵니다. 따라서 `왼쪽 토크 += (0번부터 p번까지의 무게 합)`.
- 오른쪽 추들은 모두 거리가 1씩 줄어들고, `p + 1`번 추는 거리 0이 되어 빠집니다. 따라서 `오른쪽 토크 −= (p + 1번부터 n − 1번까지의 무게 합)`.

즉 **무게의 누적합**만 있으면 토크를 한 칸씩 밀며 계산할 수 있습니다. `p = 0`의 초기 오른쪽 토크(`Σ weights[i] × i`)를 먼저 구하고, `p`를 0부터 `n − 1`까지 옮기며 두 토크가 같아지는 순간 `p`를 돌려줍니다.

무게가 모두 양수이면 왼쪽 토크는 증가만 하고 오른쪽 토크는 감소만 하므로, 같아지는 위치는 많아야 하나입니다.

## 주의할 점
- 토크는 최대 10^6 × (200,000² / 2) ≈ 2 × 10^16이라 `long`이어야 합니다. 초기 오른쪽 토크를 구할 때 `weights[i] * i`도 `long`으로 곱하세요.
- `n = 1`이면 양쪽 토크가 모두 0이라 답은 0입니다.
- 위치를 옮기는 순서(먼저 비교, 그 다음 갱신)를 지켜야 `p = 0`도 검사됩니다.

## 복잡도
- 시간 O(n), 공간 O(1)
