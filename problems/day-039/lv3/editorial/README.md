# 해설 — 온실 난방 구역

## 접근
직사각형은 (위 행, 아래 행, 왼쪽 열, 오른쪽 열)로 정해지므로 모두 세면 O(R²C²) ≈ 6 × 10^10개이고, 2차원 누적합으로 각각을 O(1)에 구해도 시간 초과입니다.

핵심 관찰은 **행 쌍을 고정하면 1차원 문제가 된다**는 것입니다.

1. 위 행 `top`과 아래 행 `bottom`을 고정합니다 (O(R²)가지).
2. 열 `c`마다 `top..bottom` 행의 비용 합 `colSum[c]`를 구합니다. 열 방향 누적합 `colPrefix[r][c]` = `0..r − 1`행 `c`열의 합을 미리 만들어 두면 `colSum[c] = colPrefix[bottom + 1][c] − colPrefix[top][c]`로 O(1)입니다.
3. 이제 "`colSum`에서 합이 `budget` 이하인 **가장 긴 연속 구간**"을 찾으면 됩니다. 비용이 0 이상이라 구간을 늘리면 합이 줄지 않으므로 **투 포인터**로 O(C)에 찾습니다.
4. 넓이 = (행 수) × (구간 길이)의 최댓값을 갱신합니다.

더 간단히, `bottom`을 `top`부터 아래로 하나씩 늘리면서 `colSum[c] += cost[bottom][c]`로 갱신하면 누적합 없이도 같은 복잡도입니다.

## 주의할 점
- 합은 `long`입니다. 700 × 700 × 10^6 = 4.9 × 10^11입니다.
- 비용이 0인 칸이 있어도 투 포인터는 그대로 맞습니다 (합이 줄지 않기만 하면 됩니다). 비용이 음수면 이 방법은 쓸 수 없습니다.
- 투 포인터에서 `left`가 `right`를 넘어가면 길이가 0입니다. 한 칸도 예산 안에 없으면 전체 답이 0이 됩니다.
- "정사각형이 클수록 비싸다"는 식의 이분 탐색은 **직사각형**에는 적용되지 않습니다. 가로로 길고 세로로 짧은 구역이 답일 수 있습니다.

## 복잡도
- 시간 O(R² · C), 공간 O(C)
