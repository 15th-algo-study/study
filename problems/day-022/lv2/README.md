# [lv2] 병원 접수 대기열

병원 접수대의 대기열 기록이 2차원 배열 `events`로 주어집니다. 각 원소는 `[종류, 값]` 꼴입니다.

- `[1, id]`: 환자 `id`가 대기열 **맨 뒤**에 섭니다. 이미 대기 중인 환자면 무시합니다.
- `[2, id]`: 환자 `id`가 대기열에서 나갑니다. 대기 중이 아니면 무시합니다.
- `[3, x]`: 호출 — 대기열 **맨 앞** 환자를 진료실로 부르고 대기열에서 뺍니다. 그 환자의 `id`를 기록합니다. 아무도 없으면 `-1`을 기록합니다. `x`는 쓰지 않는 값이며 무시합니다.

호출되었거나 나간 환자는 더 이상 대기 중이 아니므로 나중에 다시 `[1, id]`로 줄을 설 수 있습니다.

호출할 때마다 기록한 값을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 호출이 한 번도 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `events`의 길이 ≤ 1,000,000
- 종류는 1, 2, 3 중 하나입니다.
- 1 ≤ `id` ≤ 1,000,000
- 종류 3의 `x`는 0 이상 1,000,000 이하의 아무 값입니다.

## 입출력 예

| events | result |
|---|---|
| [[1, 5], [1, 8], [2, 5], [3, 0], [1, 5], [3, 0], [3, 0]] | [8, 5, -1] |
| [[1, 2], [1, 2], [3, 0], [3, 0]] | [2, -1] |
| [[1, 1], [1, 2], [2, 1], [1, 1], [3, 0], [3, 0]] | [2, 1] |

## 입출력 예 설명
- 예 #1: 대기열 [5, 8]에서 5가 나가 [8]. 호출 → 8. 5가 다시 서서 [5]. 호출 → 5. 호출 → 아무도 없어 -1.
- 예 #2: 두 번째 `[1, 2]`는 이미 대기 중이라 무시됩니다.
- 예 #3: [1, 2]에서 1이 나갔다가 **맨 뒤**에 다시 섭니다 → [2, 1]. 호출 순서는 2, 1입니다.
