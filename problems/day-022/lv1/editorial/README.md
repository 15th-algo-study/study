# 해설 — 풍선 세 개

## 접근
항상 **오른쪽 끝**에서만 변화가 일어나므로 스택이 어울립니다. 풍선을 하나씩 스택에 쌓되, 같은 색이 연속으로 쌓인 개수를 함께 들고 있으면 "세 개 연속" 검사가 O(1)입니다.

- 스택 원소: `(색, 그 색이 연속으로 쌓인 개수)`
- 새 풍선 색 `c`를 매달 때
  - 스택 맨 위의 색이 `c`이면 개수를 1 늘립니다. 개수가 3이 되면 그 원소를 통째로 꺼냅니다(세 개가 터짐).
  - 아니면 `(c, 1)`을 새로 쌓습니다.
- 끝나면 스택을 아래부터 읽어 각 원소를 개수만큼 펼칩니다.

스택 안의 이웃한 원소는 항상 색이 다르고 개수는 1 또는 2이므로, 세 개가 터진 뒤 새로 드러난 맨 위와 그 아래가 합쳐질 일은 없습니다.

## 주의할 점
- 풍선을 일반 배열/`StringBuilder`에 모두 넣고 터질 때마다 앞으로 당기면 최악 O(n²)입니다. 뒤에서만 넣고 빼는 구조를 쓰세요.
- `ArrayDeque<int[]>`에 `{색, 개수}`를 넣어도 되고, 색 배열과 개수 배열 두 개를 `int[]`로 두고 top 인덱스로 관리하면 더 가볍습니다.
- 결과 길이는 개수들의 합이므로 먼저 합을 구해 배열을 만든 뒤 채웁니다.

## 복잡도
- 시간 O(n), 공간 O(n)
