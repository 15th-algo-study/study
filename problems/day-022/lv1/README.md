# [lv1] 풍선 세 개

가게 앞 줄에 색색의 풍선을 **왼쪽부터 한 개씩** 차례로 매답니다. 풍선 하나를 매단 직후, 줄의 **오른쪽 끝**에 같은 색 풍선이 세 개 연속으로 매달려 있으면 그 세 개는 동시에 터져 사라집니다. 터진 자리는 비지 않고 양옆이 이어집니다.

매달 풍선의 색이 순서대로 배열 `colors`에 주어질 때, 모든 풍선을 매단 뒤 줄에 남아 있는 풍선의 색을 왼쪽부터 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 남은 풍선이 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `colors`의 길이 ≤ 200,000
- 1 ≤ `colors[i]` ≤ 1,000,000
- 풍선은 매달 때마다 검사하므로, 세 개가 터진 뒤 그 왼쪽에 같은 색이 두 개 남아 있고 다음에 같은 색을 매달면 다시 세 개가 되어 터집니다.

## 입출력 예

| colors | result |
|---|---|
| [1, 1, 2, 2, 2, 1] | [] |
| [3, 3, 1, 3, 3] | [3, 3, 1, 3, 3] |
| [2, 5, 5, 5, 5, 2, 2] | [2, 5, 2, 2] |

## 입출력 예 설명
- 예 #1: [1, 1] → 2를 세 개 매달면 [1, 1, 2, 2, 2]에서 2 세 개가 터져 [1, 1] → 마지막 1을 매달면 [1, 1, 1]이 되어 모두 터집니다.
- 예 #2: 같은 색이 세 개 연속인 순간이 없습니다.
- 예 #3: [2, 5, 5, 5]에서 5 세 개가 터져 [2], 그 뒤 5, 2, 2를 매달아 [2, 5, 2, 2]가 됩니다.
