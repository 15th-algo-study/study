# [lv0] 접시 쌓기

식당 주방에서는 설거지가 끝난 접시를 한 더미로 쌓아 두고, 필요할 때 맨 위의 접시부터 꺼내 씁니다. 하루 동안의 기록이 배열 `ops`로 주어집니다.

- 양수 `v`: 번호가 `v`인 접시를 더미 맨 위에 올립니다.
- `0`: 더미 맨 위의 접시를 꺼냅니다. 더미가 비어 있으면 아무 일도 일어나지 않습니다.

모든 기록을 처리한 뒤 더미에 남은 접시 번호를 **맨 아래부터 맨 위 순서로** 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 남은 접시가 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `ops`의 길이 ≤ 200,000
- 0 ≤ `ops[i]` ≤ 1,000,000,000
- 접시 번호는 중복될 수 있습니다.

## 입출력 예

| ops | result |
|---|---|
| [3, 7, 0, 5, 2, 0] | [3, 5] |
| [0, 0, 4] | [4] |
| [1, 2, 3, 0, 0, 0] | [] |

## 입출력 예 설명
- 예 #1: 3, 7을 올리고 7을 꺼냅니다 → [3]. 5, 2를 올리고 2를 꺼냅니다 → [3, 5].
- 예 #2: 빈 더미에서 꺼내는 두 번은 무시되고, 4만 남습니다.
- 예 #3: 세 개를 올리고 세 개를 모두 꺼내 비었습니다.
