# 해설 — 가림막 위의 현수막

## 접근
현수막의 높이는 어떤 패널 `i`의 높이 `heights[i]`와 같다고 봐도 됩니다(더 낮추면 넓이만 줄어듭니다). 그러면 답은

> 각 패널 `i`에 대해, `i`를 포함하면서 모든 패널 높이가 `heights[i]` 이상인 **가장 넓은 구간**의 폭 × `heights[i]`

의 최댓값입니다. 패널마다 양옆으로 뻗어 나가며 구간을 구하면 높이가 모두 같은 입력에서 O(n²) = 10^12 번이라 시간 초과입니다.

**단조 스택**으로 모든 패널의 "뻗을 수 있는 범위"를 한 번의 순회로 구합니다.

1. 폭의 누적합 `prefix[i]` = 0번부터 `i-1`번 패널까지의 폭 합을 미리 구합니다. 구간 `[l, r]`의 폭은 `prefix[r+1] - prefix[l]`입니다.
2. 스택에는 높이가 **오름차순**이 되도록 패널 인덱스를 쌓습니다.
3. 패널 `j`를 볼 때 스택 맨 위 `i`의 높이가 `heights[j]`보다 **크면** `i`는 더 이상 오른쪽으로 뻗을 수 없습니다. `i`를 꺼내고, 왼쪽 경계는 꺼낸 뒤 스택 맨 위(없으면 맨 왼쪽)의 바로 오른쪽이므로 폭은 `prefix[j] - prefix[새 맨 위 + 1]`(스택이 비면 `prefix[j]`)이고, 넓이 `heights[i] × 폭`으로 답을 갱신합니다.
4. 모든 패널을 본 뒤 스택에 남은 패널은 오른쪽 끝(`prefix[n]`)까지 뻗습니다. 끝에 높이 0인 가상 패널을 하나 둔 것처럼 처리하면 한 루프로 끝납니다.

각 패널은 한 번 들어가고 한 번 나오므로 O(n)입니다.

## 주의할 점
- 높이가 **같은** 패널은 꺼내지 않아도 됩니다(`>`로 비교). 같은 높이끼리는 나중 것이 꺼내질 때 앞 것까지 포함한 넓이가 계산되므로 답이 빠지지 않습니다.
- 넓이는 최대 10^9 × 10^9 = 10^18이므로 `long`으로 곱해야 합니다. `heights[i] * width`를 `int`끼리 곱하면 넘칩니다.
- 누적합도 최대 10^9이라 `int`에 들어가지만, 곱셈 전에 `long`으로 바꿔야 합니다.
- n = 10^6이면 `ArrayDeque<Integer>`보다 `int[]` 스택이 눈에 띄게 빠릅니다.

## 복잡도
- 시간 O(n), 공간 O(n)
