# [lv3] 가림막 위의 현수막

공사장 가림막은 패널 `n`장을 왼쪽부터 빈틈없이 이어 세운 것입니다. `i`번째 패널의 폭은 `widths[i]`, 높이는 `heights[i]`이고, 모든 패널의 아래쪽 끝은 땅에 닿아 있습니다.

이 가림막에 직사각형 현수막 한 장을 붙이려 합니다. 현수막은 다음 조건을 만족해야 합니다.

- 연속한 패널 구간에 걸쳐 붙이며, 구간의 양 끝은 패널 경계와 일치합니다(패널의 일부만 덮을 수 없습니다). 현수막의 폭은 구간에 속한 패널 폭의 합입니다.
- 현수막의 아래쪽 끝은 땅에 닿습니다.
- 현수막의 높이는 구간에 속한 패널 중 **가장 낮은** 패널의 높이 이하여야 합니다.

붙일 수 있는 현수막 넓이의 최댓값을 return 하도록 `solution` 함수를 완성해 주세요. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `heights`의 길이 = `widths`의 길이 = `n` ≤ 1,000,000
- 1 ≤ `heights[i]` ≤ 1,000,000,000
- 1 ≤ `widths[i]` ≤ 1,000

## 입출력 예

| heights | widths | result |
|---|---|---|
| [2, 1, 4, 5, 1, 3] | [1, 1, 1, 1, 1, 1] | 8 |
| [3, 1, 3] | [2, 5, 2] | 9 |
| [5, 4, 3] | [1, 2, 3] | 18 |

## 입출력 예 설명
- 예 #1: 높이 4, 5인 두 패널에 높이 4, 폭 2의 현수막을 붙이면 8입니다. 여섯 장 전체는 높이 1로 6, 한 장짜리는 최대 5입니다.
- 예 #2: 세 장 전체에 높이 1, 폭 9로 9입니다. 양 끝 한 장씩은 3 × 2 = 6에 그칩니다.
- 예 #3: 세 장 전체에 높이 3, 폭 6으로 18입니다. 앞 두 장은 4 × 3 = 12, 뒤 두 장은 3 × 5 = 15입니다.
