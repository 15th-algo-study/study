# [lv2] 냉방기 가동 계획

무더운 날 사무실 냉방기를 `n`시간 동안 어떻게 켜고 끌지 정하려 합니다. 0번 시간부터 `n - 1`번 시간까지 시간마다 냉방기를 켜 둘지 꺼 둘지 하나를 고르며, 비용은 다음과 같습니다.

- `i`번 시간에 냉방기가 켜져 있으면 전기 요금 `power[i]`가 듭니다.
- `i`번 시간에 냉방기가 꺼져 있으면 더위로 인한 손실 `heat[i]`가 듭니다.
- 직전 시간에 꺼져 있던 냉방기를 켤 때마다 기동 비용 `start`가 추가로 듭니다. 0번 시간 직전에는 냉방기가 꺼져 있으므로, 0번 시간에 켜 두려면 기동 비용이 듭니다. 끄는 데는 비용이 들지 않습니다.

총비용의 최솟값을 return 하도록 `solution` 함수를 완성해 주세요. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `power`의 길이 = `heat`의 길이 = `n` ≤ 200,000
- 0 ≤ `power[i]`, `heat[i]` ≤ 1,000,000,000
- 0 ≤ `start` ≤ 1,000,000,000

## 입출력 예

| power | heat | start | result |
|---|---|---|---|
| [3, 3, 3, 3] | [1, 9, 9, 1] | 4 | 12 |
| [2, 2, 2, 2, 2] | [10, 10, 1, 10, 10] | 5 | 15 |
| [5, 1, 4] | [2, 3, 4] | 0 | 7 |

## 입출력 예 설명
- 예 #1: 1번과 2번 시간에만 켭니다. 0번 시간 손실 1, 1번 시간 기동 4 + 전기 3, 2번 시간 전기 3, 3번 시간 손실 1로 총 12입니다. 계속 꺼 두면 20, 계속 켜 두면 16입니다.
- 예 #2: 계속 켜 두면 기동 5 + 전기 2 × 5 = 15입니다. 손실이 1뿐인 2번 시간에 잠깐 끄면 다시 켤 때 기동 비용이 또 들어 5 + 2 + 2 + 1 + 5 + 2 + 2 = 19로 더 비쌉니다.
- 예 #3: 기동 비용이 없으므로 시간마다 더 싼 쪽을 고르면 됩니다. 2 + 1 + 4 = 7입니다.
