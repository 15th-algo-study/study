# 해설 — 트램펄린 공원

## 접근
`ways[j]`를 "0번에서 j번까지 오는 경로 수"라고 하면, j번에 착지할 수 있는 모든 출발점 i에 대해 `ways[j] += ways[i]`입니다. 번호가 작은 쪽에서 큰 쪽으로만 뛰므로 앞에서부터 차례로 확정됩니다.

가장 직접적인 방법은 i번의 값이 확정될 때 `i + low[i]`부터 `i + high[i]`까지 **모든 칸에 하나씩** `ways[i]`를 더해 주는 것입니다. 하지만 범위가 넓으면 트램펄린 하나에 O(n)이라 전체 O(n²) — n = 50만이면 10^11번이 넘어 시간 초과입니다.

**관찰**: 하는 일은 "구간 [l, r]의 모든 칸에 같은 값 v를 더하기"뿐이고, 각 칸의 값은 그 칸 차례가 왔을 때 한 번만 읽습니다. 이것은 **차분 배열**로 O(1)에 처리할 수 있습니다.

- 구간 [l, r]에 v 더하기 → `diff[l] += v`, `diff[r + 1] -= v`
- 앞에서부터 `diff`를 누적한 값이 그 칸에 도착하는 경로 수

i번 차례에 누적값 `arrive += diff[i]`로 `ways[i]`를 확정하고(0번은 1), 바로 자기 구간을 `diff`에 기록합니다. 기록하는 위치는 항상 i보다 뒤이므로, 누적이 그 위치에 닿기 전에 기록이 끝나 있습니다. 이렇게 "확정된 값을 뒤쪽 구간으로 밀어 주는" DP를 밀어 주기(push) 방식이라고 합니다.

## 주의할 점
- 구간 끝은 `min(i + high[i], n - 1)`로 자르고, 시작 `i + low[i]`가 `n - 1`보다 크면 기록하지 않습니다. `high[i]`는 최대 n이라 `i + high[i]`도 `int` 범위 안입니다.
- `diff`에서 빼는 값 때문에 음수가 생길 수 있으니 `(x - v + MOD) % MOD`처럼 양수로 맞춥니다.
- 도착 경로가 0인 트램펄린은 기록할 필요가 없습니다(해도 결과는 같습니다).

## 복잡도
- 시간 O(n), 공간 O(n)
