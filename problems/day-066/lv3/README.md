# [lv3] 트램펄린 공원

트램펄린 `n`개가 일렬로 놓여 있고, 앞에서부터 0번, 1번, …, `n - 1`번입니다. 0번 트램펄린에서 출발해 앞으로만 뛰어서 `n - 1`번 트램펄린까지 가려 합니다.

`i`번 트램펄린은 탄성이 정해져 있어서, 여기서 뛰면 `i + low[i]`번부터 `i + high[i]`번까지의 트램펄린 중 원하는 하나에 착지할 수 있습니다. 번호가 `n - 1`보다 큰 곳은 공원 밖이라 착지할 수 없습니다.

0번에서 `n - 1`번까지 가는 서로 다른 경로의 수를 1,000,000,007로 나눈 나머지를 return 하도록 `solution` 함수를 완성해 주세요. 밟은 트램펄린 번호의 나열이 다르면 다른 경로입니다.

## 제한사항
- 2 ≤ `low`의 길이 = `high`의 길이 = `n` ≤ 500,000
- 1 ≤ `low[i]` ≤ `high[i]` ≤ `n`
- `n - 1`번 트램펄린에 도착하면 끝나므로 `low[n-1]`, `high[n-1]`은 쓰이지 않습니다.

## 입출력 예

| low | high | result |
|---|---|---|
| [1, 1, 1, 1] | [2, 2, 2, 2] | 3 |
| [1, 2, 1, 1, 1] | [3, 3, 2, 1, 1] | 5 |
| [3, 1, 1] | [3, 1, 1] | 0 |

## 입출력 예 설명
- 예 #1: 어디서든 1칸 또는 2칸 앞으로 뛸 수 있습니다. 0→1→2→3, 0→1→3, 0→2→3의 3가지입니다.
- 예 #2: 0번에서는 1·2·3번, 1번에서는 3·4번, 2번에서는 3·4번, 3번에서는 4번으로 갈 수 있습니다. 0→1→3→4, 0→1→4, 0→2→3→4, 0→2→4, 0→3→4의 5가지입니다.
- 예 #3: 0번에서는 3번으로만 뛸 수 있는데 공원 밖이라 도착할 방법이 없습니다.
