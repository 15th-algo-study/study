# [lv0] 번역 메모장

번역기 앱은 단어를 번역할 때 메모장을 함께 씁니다. 단어 목록 `words`를 앞에서부터 하나씩 번역하며, 처음에 메모장은 비어 있습니다.

- 메모장에 **없는** 단어는 직접 번역합니다. 단어의 길이만큼 초가 걸리고, 번역이 끝나면 그 단어를 메모장에 적어 둡니다.
- 메모장에 **있는** 단어는 메모장에서 찾아 1초 만에 번역합니다.

모든 단어를 번역하는 데 걸린 총 시간(초)과 메모장에서 찾아 번역한 횟수를 차례로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `words`의 길이 ≤ 200,000
- `words`의 원소는 알파벳 소문자로만 이루어진 길이 1 이상 10 이하의 문자열입니다.

## 입출력 예

| words | result |
|---|---|
| ["apple", "banana", "apple", "kiwi", "banana", "apple"] | [18, 3] |
| ["go", "go", "go"] | [4, 2] |
| ["a"] | [1, 0] |

## 입출력 예 설명
- 예 #1: apple 5초, banana 6초, apple 1초(메모장), kiwi 4초, banana 1초(메모장), apple 1초(메모장). 총 18초이고 메모장에서 3번 찾았습니다.
- 예 #2: 처음 나온 go는 2초가 걸리고, 그다음 두 번은 메모장에서 1초씩 찾습니다. 총 4초입니다.
- 예 #3: 단어가 하나뿐이라 메모장에서 찾을 일이 없습니다.
