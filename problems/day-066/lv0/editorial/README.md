# 해설 — 번역 메모장

## 접근
"한 번 계산한 결과를 적어 두고, 같은 입력이 다시 오면 적어 둔 것을 쓴다"가 메모이제이션의 핵심입니다. 이 문제의 메모장이 바로 그 역할입니다.

메모장은 "이 단어를 본 적이 있는가?"만 빠르게 답하면 되므로 `HashSet<String>`이 알맞습니다.

1. 단어를 하나씩 보면서 `memo.contains(word)`로 확인합니다.
2. 있으면 1초를 더하고 찾은 횟수를 1 늘립니다.
3. 없으면 단어 길이만큼 초를 더하고 `memo.add(word)`로 적어 둡니다.

`Set.add`는 새로 넣었으면 `true`, 이미 있었으면 `false`를 돌려주므로 `if (!memo.add(word))` 한 줄로 확인과 추가를 함께 할 수도 있습니다.

## 주의할 점
- 메모장을 `ArrayList`로 만들면 `contains`가 리스트 전체를 훑어 단어 하나에 O(n)이 걸립니다. 단어가 20만 개면 최악 O(n²)이라 느립니다. 해시 기반 자료구조를 쓰세요.
- 길이가 1인 단어는 직접 번역해도 1초, 메모장에서 찾아도 1초입니다. 그래도 두 번째부터는 메모장에서 찾은 횟수에 들어갑니다.
- 총 시간은 최대 20만 × 10 = 200만 초라 `int`로 충분합니다.

## 복잡도
- 시간 O(전체 글자 수), 공간 O(서로 다른 단어의 글자 수)
