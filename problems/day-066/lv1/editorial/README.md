# 해설 — 보도블록 이음매

## 접근
`ways[i]`를 "위치 0부터 i까지를 블록으로 덮되, 위치 i에서 블록이 딱 끝나는 방법의 수"라고 정합니다. 위치 i에서 끝나는 마지막 블록의 길이는 1, 2, 3 중 하나이므로

- `ways[i] = ways[i - 1] + ways[i - 2] + ways[i - 3]` (음수 위치는 0으로 봄)
- `ways[0] = 1` (아무것도 놓지 않은 상태 하나)

입니다. 위치 i에서 블록이 끝난다는 것은 그곳에 이음매가 생긴다는 뜻이므로, i가 배수구 위치이면 `ways[i] = 0`으로 둡니다. 끝 위치 `n`은 이음매가 아니므로 막지 않습니다. 답은 `ways[n]`입니다.

배수구 위치는 정렬되어 있지 않으므로, 길이 `n + 1`짜리 `boolean` 배열에 표시해 두고 O(1)로 확인합니다.

## 주의할 점
- 재귀로 "마지막 블록을 하나씩 정해 보는" 방법은 같은 위치를 계속 다시 계산해서 경우의 수만큼(약 1.84^n) 시간이 걸립니다. 앞에서부터 표를 채우세요.
- 위치마다 `drains` 배열 전체를 훑어 배수구인지 확인하면 O(n × 배수구 수)입니다. n = 100만, 배수구 30만 개면 수천억 번이라 시간 초과입니다.
- 세 값을 더하면 최대 약 3 × 10^9로 `int`를 넘습니다. `long`으로 더한 뒤 나머지를 구하세요.
- 연속한 세 위치가 모두 배수구이면 그 구간을 건너뛸 블록이 없어 답은 0입니다. 점화식이 자연스럽게 0을 만들어 줍니다.

## 복잡도
- 시간 O(n), 공간 O(n)
