# [lv1] 보도블록 이음매

길이가 `n`인 보도를 길이 1, 2, 3짜리 보도블록으로 한 줄로 빈틈없이 덮으려 합니다. 길이가 같은 블록끼리는 구별하지 않으며, 블록을 놓는 순서가 다르면 다른 방법으로 봅니다. 예를 들어 길이 3인 보도는 [1, 1, 1], [1, 2], [2, 1], [3]의 4가지 방법으로 덮을 수 있습니다.

보도의 왼쪽 끝에서 잰 거리를 위치라고 하면, 두 블록이 맞닿는 곳(이음매)은 1 이상 `n - 1` 이하의 정수 위치에 생깁니다. 배수구 덮개가 있는 위치의 목록 `drains`가 주어지며, 이 위치에는 이음매가 오면 안 됩니다.

조건을 지키며 보도를 덮는 방법의 수를 1,000,000,007로 나눈 나머지를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 1,000,000
- 0 ≤ `drains`의 길이 ≤ `n` - 1
- 1 ≤ `drains`의 원소 ≤ `n` - 1
- `drains`의 원소는 서로 다르며, 정렬되어 있지 않을 수 있습니다.

## 입출력 예

| n | drains | result |
|---|---|---|
| 4 | [] | 7 |
| 5 | [2] | 5 |
| 6 | [3, 1, 4] | 1 |

## 입출력 예 설명
- 예 #1: [1, 1, 1, 1], [1, 1, 2], [1, 2, 1], [2, 1, 1], [2, 2], [1, 3], [3, 1]의 7가지입니다.
- 예 #2: 위치 2에 이음매가 오면 안 되므로 첫 블록이 2일 수 없고, 1 다음에 1이 올 수도 없습니다. [1, 2, 1, 1], [1, 2, 2], [1, 3, 1], [3, 1, 1], [3, 2]의 5가지입니다.
- 예 #3: 이음매는 위치 2나 5에만 올 수 있습니다. 블록 길이가 3 이하이므로 [2, 3, 1] 한 가지뿐입니다.
