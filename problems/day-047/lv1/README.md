# [lv1] 복사기 대기줄

동네 문구점의 복사기는 한 대뿐입니다. 손님 `n`명이 동시에 도착했고, 손님 `i`의 복사에 걸리는 시간은 `jobs[i]`분입니다. 복사는 한 번에 한 명씩, 쉬지 않고 이어서 합니다.

손님이 **기다린 시간**은 자기 복사가 시작되기 전까지 흐른 시간, 즉 자기보다 앞서 복사한 손님들의 복사 시간 합입니다. 주인은 손님 순서를 마음대로 정할 수 있습니다. 모든 손님이 기다린 시간의 합이 **가장 작아지도록** 순서를 정했을 때, 그 합을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `jobs`의 길이 `n` ≤ 200,000
- 1 ≤ `jobs`의 원소 ≤ 1,000,000
- 답이 `int` 범위를 넘을 수 있으므로 `long`을 return 합니다.

## 입출력 예

| jobs | result |
|---|---|
| [5, 1, 3] | 5 |
| [4, 4, 4] | 12 |
| [10] | 0 |

## 입출력 예 설명
- 예 #1: 1분, 3분, 5분 손님 순서로 하면 기다린 시간은 0, 1, 4분이라 합이 5입니다. 들어온 순서(5, 1, 3)대로 하면 0 + 5 + 6 = 11입니다.
- 예 #2: 모두 4분이면 어떤 순서든 0 + 4 + 8 = 12입니다.
- 예 #3: 혼자이면 기다리지 않습니다.
