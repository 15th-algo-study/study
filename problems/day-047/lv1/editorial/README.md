# 해설 — 복사기 대기줄

## 접근
**짧은 복사부터** 처리합니다. 오름차순으로 정렬한 뒤 앞에서부터 누적 합을 더해 가면, 각 손님이 기다린 시간은 그 앞까지의 누적 합입니다.

왜 맞는지(교환 논법): 어떤 순서에서 이웃한 두 손님 `a`(앞), `b`(뒤)가 `jobs[a] > jobs[b]`라고 합시다. 둘을 바꾸면 다른 손님의 대기 시간은 그대로이고, 두 사람의 대기 시간 합은 `jobs[a]`만큼 줄고 `jobs[b]`만큼 늘어 결과적으로 `jobs[a] − jobs[b] > 0`만큼 줄어듭니다. 따라서 "앞이 더 긴" 이웃 쌍이 하나라도 있으면 더 좋은 순서가 있으므로, 최적 순서는 오름차순입니다.

## 주의할 점
- 대기 시간 합은 최대 약 2×10^5 × 2×10^11 / 2 = 2×10^16이라 `long`이 필요합니다. 누적 합 변수도 `long`으로 두세요.
- 마지막 손님의 복사 시간은 누구의 대기 시간에도 포함되지 않습니다. "앞사람까지의 누적 합"을 더한 뒤 자기 시간을 누적하는 순서를 지키세요.

## 복잡도
- 시간 O(n log n), 공간 O(1) 추가
