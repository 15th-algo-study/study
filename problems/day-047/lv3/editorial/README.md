# 해설 — 목장 급수대 설치

## 접근
위치를 오름차순으로 정렬하고 왼쪽부터 처리합니다. 아직 물이 닿지 않는 **가장 왼쪽 우리** `p`를 보면, `p`에 물을 대는 급수대는 `[p − r, p + r]` 안에 있어야 합니다. 그런데 `p`보다 왼쪽 우리는 이미 모두 처리됐고 급수대는 우리 위치에만 놓을 수 있으므로, 후보는 `[p, p + r]` 안의 우리 위치뿐입니다. 이 중 **가장 오른쪽 우리 위치 `q`** 에 설치합니다. 그 다음 `q + r` 이하의 우리를 모두 건너뛰고 반복합니다.

왜 맞는지(교환 논법): 어떤 최적해에서 `p`에 물을 대는 급수대가 위치 `t`(`p ≤ t ≤ q`)에 있다고 합시다. 이 급수대를 `q`로 옮기면 덮는 범위가 `[t − r, t + r]`에서 `[q − r, q + r]`로 바뀌는데, 아직 처리하지 않은 우리는 모두 `p` 이상이고 `q − r ≤ p`이므로 잃는 우리는 없고(오른쪽 끝은 `t + r ≤ q + r`로 늘어남) 급수대 수는 같습니다. 따라서 `q`에 설치하는 최적해가 있고, 남은 우리에 같은 논리를 반복하면 그리디가 최적입니다.

### 가짜 그리디
- "가장 왼쪽 우리 위치에 설치": 예 #1에서 3개가 나옵니다. 급수대는 왼쪽으로도 `r`만큼 덮으므로 최대한 오른쪽으로 미는 것이 핵심 관찰입니다.
- "아직 물이 안 닿는 우리를 가장 많이 덮는 위치부터": 예 #1에서 위치 9(5, 6, 9, 12, 13을 덮음)를 먼저 고르면 4와 14가 따로 남아 3개가 됩니다.

## 주의할 점
- `p + r`, `q + r`은 최대 2×10^9라 `int`를 넘칩니다. `long`으로 계산하세요.
- 같은 위치의 우리는 하나의 급수대로 모두 덮입니다. `r = 0`이면 서로 다른 위치 수가 답입니다.
- 포인터 두 개(다음 처리할 우리, 후보 탐색 위치)가 각각 앞으로만 움직이므로 정렬 뒤에는 O(n)입니다. 급수대를 하나 놓을 때마다 배열 전체를 훑어 덮인 우리를 지우는 방식은 급수대가 많을 때 O(n²)이라 시간 초과입니다.

## 복잡도
- 시간 O(n log n), 공간 O(1) 추가
