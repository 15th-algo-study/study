# [lv3] 목장 급수대 설치

곧게 뻗은 목장 울타리를 따라 양 우리 `n`개가 있습니다. 우리의 위치는 배열 `pens`로 주어지며, 같은 위치에 우리가 여러 개 있을 수도 있습니다. 목장 주인은 급수대를 설치하려 하는데, 배관 사정상 급수대는 **어떤 우리가 있는 위치에만** 설치할 수 있습니다(같은 위치에 급수대는 하나면 충분합니다). 급수대 하나는 거리 `r` **이하**에 있는 모든 우리에 물을 댈 수 있습니다.

모든 우리에 물이 닿도록 할 때 필요한 **급수대 수의 최솟값**을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `pens`의 길이 `n` ≤ 200,000
- 0 ≤ `pens`의 원소 ≤ 1,000,000,000
- 0 ≤ `r` ≤ 1,000,000,000

## 입출력 예

| pens | r | result |
|---|---|---|
| [4, 5, 6, 9, 12, 13, 14] | 4 | 2 |
| [1, 10, 20] | 3 | 3 |
| [8, 3, 3, 15, 12] | 5 | 2 |

## 입출력 예 설명
- 예 #1: 위치 6과 14에 설치하면 6은 [2, 10]의 우리(4, 5, 6, 9)에, 14는 [10, 18]의 우리(12, 13, 14)에 물을 댑니다. 하나로는 4부터 14까지(거리 10)를 덮을 수 없습니다. 참고로 가장 왼쪽 우리 4에 설치하면 4, 5, 6만 덮이고, 9와 12·13·14에 각각 하나씩 더 필요해 3개가 됩니다.
- 예 #2: 서로 거리가 3을 넘으므로 우리마다 하나씩 필요합니다.
- 예 #3: 위치 8(3, 3, 8, 12를 덮음)과 15(12, 15를 덮음)에 설치합니다.
