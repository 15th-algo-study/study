# [lv0] 추첨권의 행운 숫자

마을 축제의 경품 추첨에서는 추첨권 번호에 **행운 숫자**가 몇 번 들어 있는지에 따라 경품을 줍니다. 추첨권 번호 배열 `tickets`와 행운 숫자 `lucky`(0~9)가 주어질 때, 모든 추첨권 번호의 자릿수 가운데 `lucky`와 같은 숫자가 **모두 몇 번** 나오는지 세어 return 하도록 `solution` 함수를 완성해 주세요.

예를 들어 번호 707에는 7이 두 번, 번호 1234에는 7이 없습니다.

## 제한사항
- 1 ≤ `tickets`의 길이 ≤ 100,000
- 0 ≤ `tickets`의 원소 ≤ 1,000,000,000,000,000,000 (10^18, `long`)
- 0 ≤ `lucky` ≤ 9
- 번호 0은 숫자 0 하나로 이루어진 번호로 봅니다. 그 밖의 번호에는 맨 앞에 0이 오지 않습니다.

## 입출력 예

| tickets | lucky | result |
|---|---|---|
| [707, 1234, 77] | 7 | 4 |
| [0, 100, 1000000000000000000] | 0 | 21 |

## 입출력 예 설명
- 예 #1: 707에 2번, 1234에 0번, 77에 2번 → 4.
- 예 #2: 0에 1번, 100에 2번, 10^18에는 0이 18번 → 21.
