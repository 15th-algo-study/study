# 해설 — 추첨권의 행운 숫자

## 접근
각 번호를 `% 10`으로 마지막 자릿수를 꺼내고 `/ 10`으로 떼어 내는 일을 0이 될 때까지 반복하며 `lucky`와 같은지 셉니다. 결과를 하나의 카운터에 더합니다.

## 주의할 점
- 번호가 0일 때 `while (n > 0)`은 한 번도 돌지 않아 `lucky = 0`인 경우 1을 놓칩니다. `do-while`을 쓰거나 0을 따로 처리하세요.
- 번호는 `long`입니다. `% 10`의 결과를 `int`와 비교하려면 `(int)`로 바꾸거나 `lucky`를 `long`으로 올려 비교합니다.
- 최대 10만 개 × 19자리 = 190만이라 결과는 `int`에 들어갑니다.

## 복잡도
- 시간 O(n × 19), 공간 O(1)
