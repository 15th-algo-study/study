# [lv2] 뗏목 2인 1조

계곡 체험장에서 참가자 `n`명(짝수)이 **정확히 두 명씩** 짝을 지어 뗏목 하나에 탑니다. 참가자의 몸무게는 배열 `weights`로 주어집니다. 체험장은 뗏목을 모두 같은 규격으로 주문하는데, 뗏목의 **적재 한도**는 가장 무거운 조의 몸무게 합 이상이어야 합니다.

짝을 잘 지어 필요한 적재 한도를 가장 작게 만들려 합니다. 두 명씩 짝을 지었을 때 **조별 몸무게 합의 최댓값**이 가장 작아지도록 했을 때의 그 값을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 2 ≤ `weights`의 길이 `n` ≤ 200,000, `n`은 짝수
- 1 ≤ `weights`의 원소 ≤ 1,000,000,000
- 모든 참가자는 반드시 어느 한 조에 속하고, 한 조는 정확히 두 명입니다.

## 입출력 예

| weights | result |
|---|---|
| [3, 8, 5, 2] | 10 |
| [1, 2, 3, 4] | 5 |
| [7, 7] | 14 |

## 입출력 예 설명
- 예 #1: (2, 8), (3, 5)로 짝지으면 합이 10, 8이라 최댓값 10입니다. (2, 3), (5, 8)로 하면 13, (2, 5), (3, 8)로 하면 11입니다.
- 예 #2: (1, 4), (2, 3)으로 하면 5, 5라 5입니다. 비슷한 사람끼리 (1, 2), (3, 4)로 묶으면 7입니다.
- 예 #3: 두 명뿐이라 14입니다.
