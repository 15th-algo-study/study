# 해설 — 뗏목 2인 1조

## 접근
정렬한 뒤 **가장 가벼운 사람과 가장 무거운 사람**, 두 번째로 가벼운 사람과 두 번째로 무거운 사람, … 을 짝지으면 됩니다. 즉 `weights[i] + weights[n − 1 − i]`의 최댓값이 답입니다.

왜 맞는지(교환 논법): 가장 무거운 사람 `H`는 반드시 누군가와 짝이 됩니다. 최적해에서 `H`의 짝이 가장 가벼운 사람 `L`이 아니라 `x`이고, `L`의 짝이 `y`라고 합시다. `(H, x), (L, y)`를 `(H, L), (x, y)`로 바꾸면 `L ≤ x`이므로 `H + L ≤ H + x`, `y ≤ H`이므로 `x + y ≤ H + x`가 되어 새 두 조의 합이 모두 원래 조 `(H, x)`의 합 이하입니다. 즉 최댓값이 커지지 않습니다. 따라서 `H`와 `L`을 짝짓는 최적해가 있고, 둘을 빼고 같은 논리를 반복하면 양 끝에서 짝짓는 방법이 최적입니다.

## 주의할 점
- "비슷한 사람끼리 묶는다"(정렬 후 이웃끼리)는 그럴듯하지만 예 #2에서 틀립니다. 무거운 사람끼리 묶이면 그 조가 적재 한도를 끌어올립니다.
- 두 사람 합은 최대 2×10^9라 `int` 최댓값(약 2.147×10^9) 안에 들어가지만, 세 명 이상의 합을 계산하는 코드를 쓰면 넘칩니다.
- 남은 사람 가운데 가장 가벼운·무거운 사람을 매번 훑어 찾고 리스트에서 지우는 방식은 O(n²)이라 20만 명에서 시간 초과입니다. 정렬 한 번으로 끝내세요.

## 복잡도
- 시간 O(n log n), 공간 O(1) 추가
