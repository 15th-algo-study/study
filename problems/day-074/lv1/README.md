# [lv1] 갈매기의 오르내림 비행

해안 관측소에서 갈매기 한 마리의 비행 고도를 일정한 간격으로 기록했습니다. 배열 `altitudes`의 `i`번째 값은 `i`번째로 잰 고도(m)입니다.

연구원은 기록 중 일부를 골라(순서는 그대로) **오르내림 기록**을 만들려고 합니다. 고른 기록을 차례로 `h1, h2, …, hk`라고 할 때 오르내림 기록의 조건은 다음과 같습니다.

- 이웃한 두 기록은 고도가 달라야 합니다(`hi ≠ hi+1`).
- 올라감(`hi < hi+1`)과 내려감(`hi > hi+1`)이 **번갈아** 나타나야 합니다. 올라감으로 시작해도, 내려감으로 시작해도 됩니다.
- 기록 하나만 고른 것도 오르내림 기록이며 길이는 1입니다.

만들 수 있는 **가장 긴 오르내림 기록의 길이**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `altitudes`의 길이 ≤ 200,000
- 0 ≤ `altitudes`의 원소 ≤ 1,000,000,000

## 입출력 예

| altitudes | result |
|---|---|
| [3, 8, 6, 6, 9, 1] | 5 |
| [5, 5, 5] | 1 |
| [1, 2, 3, 4, 3, 2, 1, 5] | 4 |

## 입출력 예 설명
- 예 #1: 같은 고도 6이 두 번 이어지므로 하나를 빼고 3, 8, 6, 9, 1을 고르면 올라감·내려감·올라감·내려감이 번갈아 나타납니다. 길이 5입니다.
- 예 #2: 이웃한 기록의 고도가 모두 같아 하나만 고를 수 있습니다.
- 예 #3: 1, 4, 1, 5처럼 고르면 길이 4입니다. 계속 올라가거나 계속 내려가는 구간에서는 두 개 이상을 함께 쓸 수 없습니다.
