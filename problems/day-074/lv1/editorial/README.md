# 해설 — 갈매기의 오르내림 비행

## 접근
기록을 왼쪽부터 보면서 두 값만 관리합니다.

- `up` = 지금까지 본 기록으로 만들 수 있는, **마지막이 올라감**으로 끝나는 오르내림 기록의 최대 길이
- `down` = **마지막이 내려감**으로 끝나는 오르내림 기록의 최대 길이
- 처음에는 둘 다 1 (기록 하나)

`i`번째 기록을 볼 때 바로 앞 기록과 비교합니다.
- `altitudes[i] > altitudes[i-1]`이면 `up = down + 1`
- `altitudes[i] < altitudes[i-1]`이면 `down = up + 1`
- 같으면 아무것도 바뀌지 않습니다.

답은 `max(up, down)`입니다.

**왜 바로 앞 기록과만 비교해도 될까?** 같은 고도가 이어지는 부분을 하나로 합치고 고도 그래프를 '오르막 구간'과 '내리막 구간'으로 나눠 봅시다. 오르내림 기록은 같은 방향 구간 안에서 두 번 연속 움직일 수 없으므로, 길이는 많아야 (구간 수 + 1)입니다. 반대로 맨 처음 기록과 각 구간의 끝점(봉우리·골짜기)을 고르면 방향이 번갈아 바뀌므로 정확히 (구간 수 + 1)을 만들 수 있습니다.

위 갱신식은 바로 이 값을 셉니다. 같은 방향이 이어지면 `up = down + 1`(또는 `down = up + 1`)을 다시 계산해도 값이 그대로이고, 방향이 바뀌는 순간에만 1이 늘어납니다.

## 주의할 점
- 모든 앞 기록 `j < i`를 살피는 O(n²) DP(`up[i] = max(down[j]) + 1`)도 맞지만, n = 200,000이면 약 2×10^10번이라 시간 초과입니다.
- 같은 고도가 이어지는 경우를 "올라감"이나 "내려감"으로 세면 안 됩니다(예 #2).
- 기록이 하나뿐이어도 답은 1입니다.

## 복잡도
- 시간 O(n), 공간 O(1)
