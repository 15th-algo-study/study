# 해설 — 비스듬히 닦는 유리창

## 접근
줄 번호 `s = r + c`를 0부터 `rows + cols - 2`까지 늘려 가며, 각 줄에서 행 `r`을 작은 쪽부터 돌고 열은 `c = s - r`로 계산합니다.

다만 `(r, s - r)`이 격자 밖일 수 있습니다. 줄 `s`에서 가능한 행의 범위는
- `r ≥ 0`이고 `c = s - r ≤ cols - 1` → `r ≥ s - (cols - 1)`
- `r ≤ rows - 1`이고 `c = s - r ≥ 0` → `r ≤ s`

이므로 `r`은 `max(0, s - cols + 1)`부터 `min(rows - 1, s)`까지입니다. 이 범위만 돌면서 번호를 1씩 늘려 적습니다.

## 주의할 점
- 범위를 계산하기 어렵다면 `r`을 0부터 `rows - 1`까지 모두 돌며 `0 ≤ c < cols`인지 검사해도 됩니다. 줄이 최대 1,999개, 행이 최대 1,000개라 약 200만 번이면 충분히 빠릅니다.
- 마지막 줄 번호는 `(rows - 1) + (cols - 1)`입니다. `rows + cols - 1`까지 돌면 빈 줄을 한 번 더 돌게 되고, 범위를 잘못 잡으면 배열 밖을 접근합니다.
- 번호는 최대 10^6이라 `int`로 충분합니다.

## 복잡도
- 시간 O(rows × cols), 공간 O(rows × cols) (결과 배열)
