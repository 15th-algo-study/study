# [lv0] 비스듬히 닦는 유리창

빌딩 외벽의 유리창이 `rows`행 `cols`열로 붙어 있습니다. 맨 위 행이 0번 행, 맨 왼쪽 열이 0번 열입니다. 유리창 청소 로봇은 창을 **비스듬한 줄** 단위로 닦습니다.

- 행 번호와 열 번호의 합 `r + c`가 같은 창들이 한 줄을 이룹니다.
- 로봇은 `r + c = 0`인 줄부터 시작해 `r + c`가 1씩 큰 줄로 차례대로 옮겨 갑니다.
- 한 줄 안에서는 **위쪽 행의 창부터**(행 번호가 작은 창부터) 닦습니다. 즉 오른쪽 위에서 왼쪽 아래 방향으로 내려가며 닦습니다.

로봇이 처음 닦는 창이 1번, 다음 창이 2번, …, 마지막 창이 `rows × cols`번입니다. 각 창에 닦는 순번을 적은 `rows`행 `cols`열의 2차원 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `rows`, `cols` ≤ 1,000

## 입출력 예

| rows | cols | result |
|---|---|---|
| 3 | 4 | [[1, 2, 4, 7], [3, 5, 8, 10], [6, 9, 11, 12]] |
| 2 | 2 | [[1, 2], [3, 4]] |
| 1 | 4 | [[1, 2, 3, 4]] |

## 입출력 예 설명
- 예 #1: `r + c = 0`: (0,0)=1. `r + c = 1`: (0,1)=2, (1,0)=3. `r + c = 2`: (0,2)=4, (1,1)=5, (2,0)=6. `r + c = 3`: (0,3)=7, (1,2)=8, (2,1)=9. `r + c = 4`: (1,3)=10, (2,2)=11. `r + c = 5`: (2,3)=12.
- 예 #2: (0,0)=1, 그다음 줄은 (0,1)=2, (1,0)=3, 마지막으로 (1,1)=4입니다.
- 예 #3: 행이 하나면 줄마다 창이 하나씩이라 왼쪽부터 차례로 닦습니다.
