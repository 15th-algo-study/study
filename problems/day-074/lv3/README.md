# [lv3] 기념품 가게 사입

관광지 기념품 가게 주인이 도매 시장에서 물건을 떼어 오려고 합니다. 상품은 `n`종류이며 `goods[i] = [size, profit, stock]`은 `i`번 상품 하나의 부피가 `size`, 가게에서 팔았을 때 남는 이익이 `profit`, 도매 시장에 남은 재고가 `stock`개라는 뜻입니다.

- 같은 상품을 **재고 수 이하**로 여러 개 살 수 있습니다. 0개를 사도 됩니다.
- 사 온 상품 부피의 합은 트럭 적재 부피 `capacity` 이하여야 합니다.

사 온 상품들로 얻을 수 있는 **이익 합의 최댓값**을 return 하도록 `solution` 함수를 완성해 주세요. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `goods`의 길이 `n` ≤ 100
- `goods[i]`는 `[size, profit, stock]` 형태입니다.
  - 1 ≤ `size` ≤ 100,000
  - 1 ≤ `profit` ≤ 100,000
  - 1 ≤ `stock` ≤ 10,000
- 1 ≤ `capacity` ≤ 100,000

## 입출력 예

| goods | capacity | result |
|---|---|---|
| [[2, 3, 3], [3, 5, 1]] | 7 | 11 |
| [[1, 10, 2], [5, 30, 4]] | 10 | 60 |
| [[10, 100, 5]] | 9 | 0 |

## 입출력 예 설명
- 예 #1: 1번 상품 1개(부피 3, 이익 5)와 0번 상품 2개(부피 4, 이익 6)를 사면 부피 7에 이익 11입니다. 0번 상품만 3개 사면 이익 9입니다.
- 예 #2: 0번 상품은 부피 대비 이익이 크지만 재고가 2개뿐입니다. 0번 2개 + 1번 1개는 이익 50(부피 7)이고, 1번만 2개 사면 이익 60(부피 10)으로 더 큽니다.
- 예 #3: 상품 하나의 부피가 트럭보다 커서 아무것도 살 수 없습니다.
