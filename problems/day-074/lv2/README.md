# [lv2] 모빌 균형 맞추기

공예가가 장식 `n`개로 천장에 매다는 모빌을 만들려고 합니다. 장식은 왼쪽부터 한 줄로 놓여 있고, `i`번 장식의 무게는 `weights[i]`그램입니다. 장식의 **순서는 바꿀 수 없습니다.**

모빌은 다음 작업을 `n - 1`번 반복해 만듭니다.

- 처음에는 장식 하나하나가 각각 하나의 덩어리입니다.
- 줄에서 **이웃한 두 덩어리**를 골라 막대 하나의 왼쪽 끝과 오른쪽 끝에 매달아 한 덩어리로 합칩니다. 왼쪽 덩어리는 왼쪽 끝에, 오른쪽 덩어리는 오른쪽 끝에 매답니다.
- 이때 그 막대의 **흔들림**은 |왼쪽 덩어리 무게 − 오른쪽 덩어리 무게|입니다. 덩어리의 무게는 그 안의 장식 무게의 합이며, 막대의 무게는 생각하지 않습니다.

마지막에 덩어리 하나가 남으면 모빌이 완성됩니다. 모든 막대의 **흔들림 합의 최솟값**을 return 하도록 `solution` 함수를 완성해 주세요. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `weights`의 길이 `n` ≤ 500
- 1 ≤ `weights[i]` ≤ 1,000,000

## 입출력 예

| weights | result |
|---|---|
| [1, 2, 3] | 1 |
| [4, 4, 4, 4] | 0 |
| [3, 1, 1, 3] | 3 |

## 입출력 예 설명
- 예 #1: 먼저 1과 2를 합치면 흔들림 |1 − 2| = 1, 그 덩어리(3)와 3을 합치면 흔들림 0으로 합계 1입니다. 2와 3을 먼저 합치면 1 + |1 − 5| = 5입니다.
- 예 #2: 둘씩 짝지은 뒤 두 덩어리(8, 8)를 합치면 모든 막대의 흔들림이 0입니다.
- 예 #3: 가운데에서 나눠 (3, 1)과 (1, 3)을 먼저 만들면 두 막대가 2씩 흔들려 합계 4입니다. 대신 1과 1을 합치고(0), 3을 붙이고(|2 − 3| = 1), 마지막에 왼쪽 3을 붙이면(|3 − 5| = 2) 합계 3입니다. 가장 무게가 고른 곳을 먼저 나누는 방법이 항상 최선은 아닙니다.
