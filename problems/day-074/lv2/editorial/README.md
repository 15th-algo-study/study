# 해설 — 모빌 균형 맞추기

## 접근
완성된 모빌을 위에서부터 보면, 맨 위 막대는 장식 줄을 어떤 위치 `k`에서 **왼쪽 구간과 오른쪽 구간으로 나눈** 것입니다. 그리고 왼쪽 구간과 오른쪽 구간은 각각 독립적인 작은 모빌입니다. 그러므로 구간 단위로 답을 저장하는 **구간 DP**로 풉니다.

- `cost[l][r]` = 장식 `l..r`로 모빌을 만들 때 흔들림 합의 최솟값
- `cost[i][i] = 0` (장식 하나는 막대가 없음)
- `cost[l][r] = min over k (l ≤ k < r) of cost[l][k] + cost[k+1][r] + |S(l, k) − S(k+1, r)|`
  - `S(a, b)`는 장식 `a..b`의 무게 합이며, 누적합 `prefix`로 O(1)에 구합니다.

`cost[l][r]`은 더 짧은 구간들만 참조하므로, **구간 길이를 2, 3, …, n 순서로** 채웁니다. 답은 `cost[0][n-1]`입니다.

## 주의할 점
- 매번 "가장 무게가 비슷하게 나뉘는 곳"을 고르는 그리디는 틀립니다(예 #3: 그리디 4, 정답 3).
- 모든 합치는 순서를 재귀로 시도하면 카탈랑 수만큼 늘어나 n = 500에서 끝나지 않습니다. 같은 구간을 여러 번 계산하지 않도록 표에 저장하세요.
- 흔들림 합은 최대 약 499 × (5×10^8)로 `int`를 넘습니다. 표와 누적합을 `long`으로 둡니다.
- 구간을 `l`의 오름차순으로 채우면 `cost[k+1][r]`이 아직 비어 있습니다. 길이 순서(또는 `l`을 큰 쪽부터)로 채우세요.

## 복잡도
- 시간 O(n³) (약 n³/6 ≈ 2×10^7), 공간 O(n²)
