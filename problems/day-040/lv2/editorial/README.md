# 해설 — 선물 세트 예산 맞추기

## 접근
모든 쌍을 보면 O(n·m) = 4 × 10^10으로 시간 초과입니다. 두 배열을 **정렬**한 뒤 **양 끝에서 좁혀 오는 투 포인터**를 씁니다.

- `i`는 와인의 맨 앞(가장 쌈), `j`는 치즈의 맨 뒤(가장 비쌈)에서 시작합니다.
- `wines[i] + cheeses[j] ≤ budget`이면 이 합은 "와인 `i`와 짝지을 수 있는 가장 비싼 치즈"와의 합이므로 답 후보로 기록하고 `i++` (더 비싼 와인을 시도).
- 넘으면 치즈가 너무 비싼 것이므로 `j--`.

와인이 비싸질수록 짝이 되는 치즈의 상한은 내려가기만 하므로 `j`는 되돌아가지 않습니다. 두 포인터가 각각 한 번씩 끝까지 가므로 정렬 O(n log n + m log m) 뒤에 O(n + m)입니다.

## 주의할 점
- `wines[i] + cheeses[j]`는 최대 2 × 10^9로 `int`를 넘어 **음수**가 됩니다. 그러면 예산 이하로 잘못 판정되어 엉뚱한 답(음수)이 나옵니다. `long`으로 더하세요.
- 답은 예산 이하이므로 `int`로 돌려줄 수 있습니다.
- 한 배열마다 이분 탐색(`budget − wines[i]` 이하인 가장 비싼 치즈)을 해도 O(n log m)으로 통과합니다.

## 복잡도
- 시간 O(n log n + m log m), 공간 O(1) (정렬 제외)
