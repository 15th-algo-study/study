# [lv1] 등대에서 보이는 등대

곧게 뻗은 해안선을 따라 등대 `n`개가 서 있습니다. 등대의 위치는 배열 `pos`로 주어지며 **오름차순**으로 정렬되어 있고, 같은 위치에 등대가 여럿 있을 수도 있습니다. 등대의 불빛은 거리 `d`까지 보입니다.

각 등대에서, 자기 자신을 제외하고 거리가 `d` **이하**인 등대의 수를 세어 등대 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `pos`의 길이 `n` ≤ 200,000
- 0 ≤ `pos`의 원소 ≤ 1,000,000,000, 오름차순 정렬(같은 값 가능)
- 0 ≤ `d` ≤ 1,000,000,000

## 입출력 예

| pos | d | result |
|---|---|---|
| [1, 3, 6, 10] | 3 | [1, 2, 1, 0] |
| [5, 5, 5] | 0 | [2, 2, 2] |
| [0, 1000000000] | 999999999 | [0, 0] |

## 입출력 예 설명
- 예 #1: 위치 3인 등대에서는 1(거리 2)과 6(거리 3)이 보여 2개입니다. 위치 6에서는 10까지 거리가 4라 보이지 않습니다.
- 예 #2: 같은 자리의 등대는 거리 0이므로 `d = 0`이어도 서로 보입니다. 자기 자신은 세지 않습니다.
- 예 #3: 거리 10^9는 `d`보다 1 큽니다.
