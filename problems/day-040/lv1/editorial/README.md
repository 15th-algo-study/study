# 해설 — 등대에서 보이는 등대

## 접근
등대마다 전체를 훑으면 O(n²)으로 시간 초과입니다. 배열이 정렬되어 있으므로, 등대 `i`에서 보이는 등대들은 **연속한 구간** `[lo, hi]`를 이룹니다.

- `lo` = `pos[j] ≥ pos[i] − d`인 가장 작은 `j`
- `hi` = `pos[j] ≤ pos[i] + d`인 가장 큰 `j`
- 답 = `hi − lo + 1 − 1` (자기 자신 제외) = `hi − lo`

`i`가 커지면 `pos[i]`가 커지므로 `lo`와 `hi`도 **왼쪽으로 되돌아가지 않습니다**. 따라서 두 포인터를 `i`와 함께 앞으로만 밀면 전체가 O(n)입니다.

- `while (pos[lo] < pos[i] - d) lo++;`
- `while (hi + 1 < n && pos[hi + 1] <= pos[i] + d) hi++;`

## 주의할 점
- `pos[i] + d`는 최대 2 × 10^9로 `int`를 넘습니다. `long`으로 비교하거나, `pos[hi + 1] − pos[i] ≤ d`처럼 **뺄셈**으로 바꿔 비교하세요 (두 위치의 차는 최대 10^9라 안전합니다).
- 거리는 "이하"입니다. `<`로 쓰면 예 #1의 거리 3인 쌍이 빠집니다.
- 같은 위치의 등대들은 서로 거리 0이라 `d = 0`이어도 보입니다.
- 이분 탐색(`lowerBound`/`upperBound`)으로 풀어도 O(n log n)으로 통과합니다.

## 복잡도
- 시간 O(n), 공간 O(n)
