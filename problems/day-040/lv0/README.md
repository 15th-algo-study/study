# [lv0] 전광판 패널 교체

전광판은 LED 패널 `n`개가 한 줄로 이어진 것이고, `board[i]`는 `i`번(0번부터 셈) 패널의 밝기 값입니다.

고장 난 부분을 새 패널 묶음 `patch`로 갈아 끼우려 합니다. `patch`는 `pos`번 패널부터 차례로 덮어씌워져, `pos + i`번 패널의 밝기가 `patch[i]`가 됩니다. 나머지 패널은 그대로입니다.

원래 배열 `board`는 바꾸지 말고, 교체가 끝난 전광판의 밝기 배열을 **새 배열**로 만들어 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `board`의 길이 `n` ≤ 1,000,000
- 1 ≤ `patch`의 길이 ≤ `n`
- 0 ≤ `pos`, `pos + patch의 길이` ≤ `n` (묶음이 전광판 밖으로 나가지 않습니다)
- 0 ≤ 밝기 값 ≤ 255

## 입출력 예

| board | patch | pos | result |
|---|---|---|---|
| [1, 2, 3, 4, 5] | [9, 9] | 1 | [1, 9, 9, 4, 5] |
| [0, 0, 0] | [7, 7, 7] | 0 | [7, 7, 7] |
| [5, 6, 7, 8] | [1] | 3 | [5, 6, 7, 1] |

## 입출력 예 설명
- 예 #1: 1번과 2번 패널이 9로 바뀝니다.
- 예 #2: 전체를 새 묶음으로 바꿉니다.
- 예 #3: 마지막 패널 하나만 바꿉니다.
