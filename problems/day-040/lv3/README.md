# [lv3] 드론 두 대의 송전탑 점검

송전탑 `n`개가 일렬로 서 있고 `power[i]`는 `i`번(0번부터 셈) 송전탑을 점검하는 데 드는 드론의 전력입니다.

점검 드론은 두 대, A와 B입니다. A의 배터리는 `a`, B의 배터리는 `b`입니다. 각 드론은 **연속한 송전탑 구간** 하나를 맡아 차례로 점검하며, 맡은 구간의 전력 합이 자기 배터리 이하여야 합니다. 두 드론의 구간은 **겹치면 안 됩니다**(같은 송전탑을 둘 다 점검할 수 없습니다). 드론이 송전탑을 하나도 맡지 않아도 됩니다.

두 드론이 점검하는 송전탑 수의 합의 최댓값을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `power`의 길이 `n` ≤ 200,000
- 1 ≤ `power`의 원소 ≤ 1,000,000
- 0 ≤ `a`, `b` ≤ 10^12 (`long`)

## 입출력 예

| power | a | b | result |
|---|---|---|---|
| [3, 1, 4, 1, 5] | 5 | 4 | 4 |
| [1, 2, 3, 4, 5, 6] | 6 | 9 | 5 |
| [10, 10] | 5 | 5 | 0 |

## 입출력 예 설명
- 예 #1: A가 2~3번(4 + 1 = 5), B가 0~1번(3 + 1 = 4)을 맡으면 4개입니다. 5개를 모두 점검하려면 전체를 두 연속 구간으로 나눠야 하는데, 어떻게 나눠도 한쪽이 배터리를 넘습니다.
- 예 #2: A가 0~2번(합 6), B가 3~4번(합 9)을 맡아 5개입니다. 6개 모두는 불가능합니다.
- 예 #3: 어느 드론도 송전탑 하나를 점검할 전력이 없습니다.
