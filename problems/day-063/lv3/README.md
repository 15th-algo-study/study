# [lv3] 야영장 모기향

여름 야영장을 격자 모양의 지도 `camp`로 나타냈습니다. `camp[r]`의 `c`번째 문자가 (r, c) 칸이며, 각 문자의 뜻은 다음과 같습니다.

- `M`: 모기향이 하나 놓인 빈 땅
- `.`: 빈 땅
- `#`: 텐트나 나무가 있어 연기가 들어가지 못하는 칸

모기향마다 세기가 있습니다. 모기향의 세기는 정수 배열 `powers`에 **지도의 위쪽 줄부터, 같은 줄에서는 왼쪽부터** 차례로 적혀 있습니다. 즉 `powers[0]`은 지도에서 가장 먼저 나오는 `M`의 세기입니다.

연기는 상하좌우로 붙은 칸으로만 퍼지며 `#` 칸과 야영장 밖으로는 들어가지 못합니다. 세기가 `p`인 모기향의 연기는 그 모기향 칸에서 **`p`걸음 이내**로 갈 수 있는 모든 빈 땅 칸(`.`, `M`)에 닿습니다. 모기향이 놓인 칸 자신도 포함되며, 세기가 0이면 그 칸에만 닿습니다. 다른 모기향이 놓인 칸이나 다른 모기향의 연기가 닿은 칸도 막지 않고 그대로 지나갑니다.

하나 이상의 모기향 연기가 닿는 칸의 수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `camp`의 길이 ≤ 1,000
- 1 ≤ 각 `camp[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같고, `camp`는 `M`, `.`, `#`로만 이루어집니다.
- `powers`의 길이는 `camp`에 있는 `M`의 개수와 같으며 1 이상입니다.
- 0 ≤ `powers`의 원소 ≤ 1,000,000

## 입출력 예

| camp | powers | result |
|---|---|---|
| ["M...", ".##.", "...M"] | [1, 2] | 8 |
| ["M.#..", "..#.."] | [100] | 4 |
| ["...M...M."] | [0, 7] | 9 |

## 입출력 예 설명
- 예 #1: (0,0)의 세기 1 모기향은 (0,0), (0,1), (1,0)에 닿습니다. (2,3)의 세기 2 모기향은 (2,3), (1,3), (2,2), (0,3), (2,1)에 닿습니다. 모두 8칸이고 (0,2)와 (2,0)에는 닿지 않습니다.
- 예 #2: 세기가 커도 `#`로 막힌 오른쪽으로는 퍼지지 못합니다.
- 예 #3: (0,7)의 세기 7 모기향 연기는 세기 0인 (0,3) 모기향 칸을 지나 왼쪽 끝까지 닿습니다. 9칸 모두입니다.
