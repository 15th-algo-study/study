# [lv0] 자릿값으로 펼쳐 쓰기

수학 학습지에 수를 자릿값의 합으로 펼쳐 쓰는 문제가 나왔습니다. 예를 들어 `4305`는 `"4000+300+5"`로 씁니다. 펼쳐 쓰는 규칙은 다음과 같습니다.

- 각 자리의 숫자 뒤에 그 자리만큼 0을 붙인 수를 씁니다. (천의 자리 4 → `4000`)
- 숫자가 0인 자리는 쓰지 않습니다.
- 높은 자리부터 차례로 `+`로 이어 씁니다. 빈칸은 넣지 않습니다.
- 수가 0이면 `"0"`이라고 씁니다.

`long` 배열 `numbers`가 주어질 때, 각 수를 펼쳐 쓴 문자열을 같은 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `numbers`의 길이 ≤ 20,000
- 0 ≤ `numbers`의 원소 ≤ 1,000,000,000,000,000,000 (10^18)

## 입출력 예

| numbers | result |
|---|---|
| [4305, 70, 0] | ["4000+300+5", "70", "0"] |
| [1000000000000000000, 11] | ["1000000000000000000", "10+1"] |
| [909] | ["900+9"] |

## 입출력 예 설명
- 예 #1: 4305의 백의 자리는 3, 십의 자리는 0이므로 `"4000+300+5"`입니다. 70은 일의 자리가 0이라 `"70"` 하나만 남습니다. 0은 `"0"`입니다.
- 예 #2: 10^18은 맨 앞 자리만 1이고 나머지가 모두 0입니다. 11은 `"10+1"`입니다.
- 예 #3: 가운데 0은 쓰지 않습니다.
