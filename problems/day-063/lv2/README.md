# [lv2] 정확히 k걸음 산책

강아지 산책 앱에 "정확히 `k`걸음 걸어서 지정된 칸에서 산책을 마치기" 미션이 올라왔습니다. 공원을 격자 모양의 지도 `park`로 나타냈고, `park[r]`의 `c`번째 문자가 (r, c) 칸입니다.

- `S`: 산책을 시작하는 칸 (정확히 하나)
- `.`: 걸을 수 있는 칸
- `#`: 꽃밭이라 들어갈 수 없는 칸

한 걸음은 상하좌우로 붙어 있는 걸을 수 있는 칸으로 한 칸 옮겨 가는 것입니다. `S` 칸도 걸을 수 있는 칸입니다. 공원 밖으로는 나갈 수 없고, **제자리에 머무르는 것은 걸음으로 치지 않습니다.** 같은 칸을 여러 번 지나도 됩니다.

미션 목록 `missions`의 각 원소 `[r, c, k]`는 "`S`에서 출발해 **정확히 `k`걸음**을 걸은 직후 (r, c) 칸에 있기"입니다. 각 미션을 달성할 수 있으면 `true`, 없으면 `false`를 같은 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `park`의 길이 ≤ 1,000
- 1 ≤ 각 `park[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같고, `park`는 `S`, `.`, `#`로만 이루어지며 `S`는 정확히 한 번 나옵니다.
- 1 ≤ `missions`의 길이 ≤ 200,000
- `missions[i] = [r, c, k]`, 0 ≤ r < `park`의 길이, 0 ≤ c < `park[0]`의 길이, 0 ≤ k ≤ 1,000,000,000
- (r, c)가 `#` 칸일 수도 있습니다.

## 입출력 예

| park | missions | result |
|---|---|---|
| ["S.#", "..#", "#.."] | [[0, 1, 1], [0, 1, 2], [2, 2, 4], [2, 2, 6], [0, 2, 5], [0, 0, 0]] | [true, false, true, true, false, true] |
| ["S"] | [[0, 0, 0], [0, 0, 2]] | [true, false] |
| ["S#."] | [[0, 2, 2]] | [false] |

## 입출력 예 설명
- 예 #1
  - (0,1)은 `S` 바로 오른쪽이라 1걸음이면 됩니다. 하지만 2걸음 뒤에 (0,1)에 있을 방법은 없습니다.
  - (2,2)는 (0,0) → (0,1) → (1,1) → (2,1) → (2,2)로 4걸음입니다. 6걸음은 (2,1)에 한 번 다녀오는 2걸음을 더하면 됩니다.
  - (0,2)는 꽃밭입니다. 0걸음 뒤에는 `S`에 있습니다.
- 예 #2: 움직일 수 있는 칸이 없어 한 걸음도 걸을 수 없습니다.
- 예 #3: (0,2)로 가는 길이 꽃밭에 막혀 있습니다.
