# 해설 — 연잎 위의 개구리

## 접근
연잎을 정점, 한 번의 점프를 길이 1인 간선으로 보면 "최소 점프 횟수"는 최단 거리입니다. 격자 BFS와 똑같이 풀되, 이웃이 "바로 옆 칸"이 아니라 **`pads[r][c]`칸 떨어진 칸**이라는 점만 다릅니다.

1. (0, 0)을 거리 0으로 큐에 넣습니다.
2. 꺼낸 연잎의 수 `len`만큼 네 방향으로 떨어진 칸 `(r + dr*len, c + dc*len)`을 계산합니다. 연못 안이고 처음 가는 칸이면 거리 + 1을 적고 큐에 넣습니다.
3. 도착 연잎을 꺼내면 그 거리가 답입니다. 큐가 빌 때까지 못 꺼내면 -1입니다.

## 주의할 점
- 0이 적힌 연잎은 갈 수는 있지만 거기서 더 뛸 수 없습니다. `len == 0`이면 이웃을 만들지 않습니다(자기 자신으로 가는 간선이 생기지 않게).
- 왼쪽 위에서 오른쪽 아래로 가는 문제라고 해서 "오른쪽·아래로만" 채우는 DP를 쓰면 틀립니다. 위나 왼쪽으로 되돌아 뛰어야 하는 경로가 있습니다. 행 순서로 표를 여러 번 훑으며 값이 안 바뀔 때까지 고치는 방식도, 지그재그 경로에서는 훑는 횟수가 수십만 번이 되어 시간 초과입니다.
- 칸 번호를 `r * cols + c`로 묶어 `int[]` 큐에 넣으면 100만 칸도 빠릅니다.
- 행 수와 열 수가 모두 1이면 출발이 곧 도착이므로 0입니다.

## 복잡도
- 시간 O(rows × cols), 공간 O(rows × cols)
