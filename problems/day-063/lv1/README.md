# [lv1] 연잎 위의 개구리

연못에 연잎이 격자 모양으로 떠 있습니다. 2차원 정수 배열 `pads`의 `pads[r][c]`는 (r, c) 연잎에 적힌 수입니다.

개구리는 (r, c) 연잎에서 **정확히 `pads[r][c]`칸** 떨어진 위·아래·왼쪽·오른쪽 연잎 중 하나로 한 번에 뛸 수 있습니다. 예를 들어 3이 적힌 연잎에서는 (r-3, c), (r+3, c), (r, c-3), (r, c+3) 중 하나로 뜁니다. 연못 밖으로는 뛸 수 없고, 0이 적힌 연잎에서는 뛸 수 없습니다.

개구리는 왼쪽 위 (0, 0) 연잎에 있고, 오른쪽 아래 (rows-1, cols-1) 연잎으로 가려 합니다. 필요한 **최소 점프 횟수**를 return 하도록 `solution` 함수를 완성해 주세요. 갈 수 없으면 -1을, 출발 연잎과 도착 연잎이 같으면 0을 return 합니다.

## 제한사항
- 1 ≤ `pads`의 행 수(rows) ≤ 1,000
- 1 ≤ `pads`의 열 수(cols) ≤ 1,000
- 0 ≤ `pads[r][c]` ≤ 1,000

## 입출력 예

| pads | result |
|---|---|
| [[2, 3, 1], [1, 0, 1], [2, 1, 4]] | 2 |
| [[0, 1], [1, 1]] | -1 |
| [[1, 2, 1, 1], [3, 1, 1, 2], [1, 1, 1, 1], [2, 1, 3, 1]] | 3 |

## 입출력 예 설명
- 예 #1: (0,0)에서 아래로 2칸 뛰어 (2,0), 거기서 오른쪽으로 2칸 뛰어 (2,2)에 도착합니다.
- 예 #2: 출발 연잎에 0이 적혀 있어 뛸 수 없습니다.
- 예 #3: (0,0) → (1,0) → (1,3) → (3,3)으로 3번입니다. (0,0)에서 한 번에 갈 수 있는 곳은 (1,0)과 (0,1)뿐이고, 거기서 한 번 더 뛰어도 도착 연잎에는 닿지 않습니다.
