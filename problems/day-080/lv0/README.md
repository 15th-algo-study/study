# [lv0] 회전 인코더 눈금 읽기

회전 손잡이의 각도를 읽는 인코더는 눈금 위치 `p`를 그대로 보내지 않고 **그레이 코드** `g = p ^ (p >> 1)`로 바꿔 보냅니다. 그레이 코드는 이웃한 눈금끼리 비트가 딱 하나만 달라서 읽는 순간 비트가 어긋나도 오차가 작다는 장점이 있습니다.

| 위치 p | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 그레이 코드 g (2진수) | 000 | 001 | 011 | 010 | 110 | 111 | 101 | 100 |

받은 코드 `g`에서 위치 `p`를 되살리는 규칙은 다음과 같습니다.

- `p`의 `k`번 비트는 `g`의 `k`번 비트부터 가장 높은 비트까지를 **모두 XOR** 한 값입니다.
- 즉 `p = g ^ (g >> 1) ^ (g >> 2) ^ (g >> 3) ^ …` 이고, 밀어서 0이 될 때까지 계속합니다.

인코더가 보낸 코드 목록 `codes`가 주어질 때, 각 코드의 눈금 위치를 차례로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `codes`의 길이 ≤ 100,000
- 0 ≤ `codes`의 원소 ≤ 1,073,741,823 (2^30 − 1)

## 입출력 예

| codes | result |
|---|---|
| [0, 1, 3, 2, 6] | [0, 1, 2, 3, 4] |
| [7, 5, 4] | [5, 6, 7] |
| [536870912] | [1073741823] |

## 입출력 예 설명
- 예 #1: 위 표의 0~4번 위치입니다.
- 예 #2: `7` = `111`₂ → `111 ^ 011 ^ 001` = `101`₂ = 5. `5` = `101`₂ → `101 ^ 010 ^ 001` = `110`₂ = 6. `4` = `100`₂ → `100 ^ 010 ^ 001` = `111`₂ = 7.
- 예 #3: 2^29는 29번 비트만 켜진 수라, 0번~29번 비트가 모두 1이 됩니다. 2^30 − 1 = 1,073,741,823입니다.
