# 해설 — 회전 인코더 눈금 읽기

## 접근
규칙 그대로 `g`를 한 칸씩 오른쪽으로 밀면서 XOR 합니다.

```java
int p = 0;
for (int x = g; x != 0; x >>= 1) p ^= x;
```

`x`가 `g`, `g >> 1`, `g >> 2`, … 를 차례로 거치고, 0이 되면 더 XOR 해도 변화가 없으므로 멈춥니다. 30비트 수라 반복은 최대 30번입니다.

검산: 이렇게 얻은 `p`로 `p ^ (p >> 1)`을 계산하면 원래 `g`가 나와야 합니다.

## 주의할 점
- `p = g ^ (g >> 1)`만 하면 인코딩(위치 → 코드)을 한 번 더 한 것이지 복원이 아닙니다.
- 원소가 음수가 아니므로 `>>`와 `>>>`의 결과가 같습니다. 음수였다면 `>>`는 부호 비트를 채워 넣어 반복이 끝나지 않을 수 있으니 `>>>`를 씁니다.
- (참고) `p ^= p >> 1; p ^= p >> 2; p ^= p >> 4; p ^= p >> 8; p ^= p >> 16;` 다섯 줄로도 같은 결과를 얻습니다. 밀어서 XOR 한 결과를 다시 두 배 거리로 밀어 XOR 하기 때문입니다.

## 복잡도
- 시간 O(n × 30), 공간 O(n)
