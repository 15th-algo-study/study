# [lv1] 새 도로 후보 평가

마을 `n`개(0번 ~ `n - 1`번)가 양방향 도로로 이어져 있습니다. 군청은 새 도로 하나를 놓으려고 후보 `candidates`를 받았습니다. 후보마다 **그 도로 하나만 새로 놓았을 때**, 최단 거리가 **줄어드는** 마을 쌍이 몇 개인지 세어 비교하려고 합니다.

- `roads`의 원소 `[a, b, len]`은 마을 `a`와 `b`를 잇는 길이 `len`의 기존 양방향 도로입니다.
- `candidates`의 원소 `[a, b, len]`은 마을 `a`와 `b`를 잇는 길이 `len`의 양방향 도로 후보입니다.
- 후보는 서로 독립입니다. 각 후보는 기존 도로에 그 후보 하나만 더한 상황에서 평가합니다.
- 마을 쌍은 순서 없이 `{i, j}`(`i < j`) 하나로 셉니다. 원래 서로 갈 수 없던 쌍이 새 도로 덕분에 갈 수 있게 되면 "줄어든" 것으로 셉니다. 거리가 같아지는 것은 줄어든 것이 아닙니다.

후보마다 최단 거리가 줄어드는 마을 쌍의 수를 후보 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 2 ≤ `n` ≤ 800
- 0 ≤ `roads`의 길이 ≤ 50,000
- 1 ≤ `candidates`의 길이 ≤ 500
- `roads`, `candidates`의 원소는 `[a, b, len]` 형태이며 0 ≤ `a`, `b` < `n`, `a` ≠ `b`, 1 ≤ `len` ≤ 10,000

## 입출력 예

| n | roads | candidates | result |
|---|---|---|---|
| 4 | [[0, 1, 4], [1, 2, 4], [2, 3, 4]] | [[0, 3, 5], [0, 2, 8], [1, 3, 1]] | [1, 0, 2] |
| 3 | [[0, 1, 2]] | [[1, 2, 3], [0, 1, 1]] | [2, 1] |

## 입출력 예 설명
- 예 #1: 기존 최단 거리는 0-1: 4, 0-2: 8, 0-3: 12, 1-2: 4, 1-3: 8, 2-3: 4입니다.
  - `[0, 3, 5]`: 0-3이 12 → 5로 줄어듭니다. 1-3은 1 → 0 → 3(4 + 5 = 9)이라 8보다 길고, 0-2도 0 → 3 → 2(5 + 4 = 9)라 줄지 않습니다. → 1
  - `[0, 2, 8]`: 0-2가 8 → 8로 같고, 다른 쌍도 줄지 않습니다. → 0
  - `[1, 3, 1]`: 1-3이 8 → 1, 0-3이 12 → 0 → 1 → 3(4 + 1 = 5)으로 줄어듭니다. → 2
- 예 #2: 2번 마을은 원래 갈 수 없는 곳입니다.
  - `[1, 2, 3]`: 1-2(3)와 0-2(2 + 3 = 5)가 새로 이어집니다. → 2
  - `[0, 1, 1]`: 0-1이 2 → 1로 줄어듭니다. → 1
