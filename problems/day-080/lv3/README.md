# [lv3] 검문소를 세울 교차로

교차로 `n`개(0번 ~ `n - 1`번)가 양방향 도로로 이어져 있습니다. 0번 교차로에서 도주한 차량이 `n - 1`번 교차로로 향하고 있습니다. 차량은 반드시 **이동 시간이 가장 짧은 경로** 중 하나로 움직이지만, 그런 경로가 여러 개면 어느 것을 고를지 알 수 없습니다.

경찰은 차량이 **어떤 최단 경로를 고르더라도 반드시 지나가는** 교차로에 검문소를 세우려고 합니다. 출발 교차로(0번)와 도착 교차로(`n - 1`번)는 제외합니다.

도로 정보 `roads`가 주어질 때, 검문소를 세울 수 있는 교차로 번호를 오름차순으로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 그런 교차로가 없거나 0번에서 `n - 1`번으로 갈 수 없으면 빈 배열을 return 합니다.

- `roads`의 원소 `[a, b, t]`는 교차로 `a`와 `b`를 잇고 지나는 데 `t`분 걸리는 양방향 도로입니다. 같은 두 교차로를 잇는 도로가 여러 개이거나 `a = b`인 도로가 있을 수 있습니다.

## 제한사항
- 2 ≤ `n` ≤ 200,000
- 0 ≤ `roads`의 길이 ≤ 300,000
- `roads`의 원소는 `[a, b, t]` 형태이며 0 ≤ `a`, `b` < `n`, 1 ≤ `t` ≤ 1,000,000,000

## 입출력 예

| n | roads | result |
|---|---|---|
| 6 | [[0, 1, 2], [1, 2, 3], [1, 3, 3], [2, 4, 1], [3, 4, 1], [4, 5, 2], [0, 5, 20]] | [1, 4] |
| 4 | [[0, 1, 1], [1, 3, 1], [0, 2, 1], [2, 3, 1]] | [] |
| 4 | [[0, 1, 1], [1, 3, 2], [0, 2, 2], [2, 3, 1]] | [] |

## 입출력 예 설명
- 예 #1: 최단 시간은 8분이고 최단 경로는 0 → 1 → 2 → 4 → 5와 0 → 1 → 3 → 4 → 5 두 개입니다. 두 경로가 모두 지나는 교차로는 1번과 4번입니다.
- 예 #2: 0 → 1 → 3과 0 → 2 → 3이 모두 2분이고 겹치는 교차로가 없습니다.
- 예 #3: 0 → 1 → 3과 0 → 2 → 3이 모두 3분입니다. 1번은 출발 1분 뒤에 지나는 유일한 교차로이지만, 0 → 2 도로가 그 시점을 건너뛰어 버리므로 반드시 지나는 곳이 아닙니다. 2번도 마찬가지입니다.
