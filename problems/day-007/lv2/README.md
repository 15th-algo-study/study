# [lv2] 커서가 있는 입력기

한 줄짜리 텍스트 입력기에 키를 누른 기록이 문자열 `keys`로 주어집니다. 입력기는 처음에 비어 있고, 커서는 맨 앞에 있습니다. 각 키는 다음과 같이 동작합니다.

- 영문 소문자, 숫자: 커서 위치에 그 글자를 끼워 넣고, 커서는 그 글자 바로 뒤로 이동합니다.
- `<`: 커서 바로 앞의 글자 하나를 지웁니다. 커서가 맨 앞이면 아무 일도 일어나지 않습니다.
- `[`: 커서를 한 칸 왼쪽으로 옮깁니다. 커서가 맨 앞이면 아무 일도 일어나지 않습니다.
- `]`: 커서를 한 칸 오른쪽으로 옮깁니다. 커서가 맨 뒤면 아무 일도 일어나지 않습니다.

모든 키를 누른 뒤 입력기에 남아 있는 텍스트를 return 하도록 `solution` 함수를 완성해 주세요. 텍스트가 비어 있으면 빈 문자열을 return 합니다.

## 제한사항
- 1 ≤ `keys`의 길이 ≤ 1,000,000
- `keys`는 영문 소문자, 숫자, `<`, `[`, `]`로만 이루어져 있습니다.

## 입출력 예

| keys | result |
|---|---|
| "abc[[d" | "adbc" |
| "hello[[[<]]<" | "hlo" |
| "<<x]]" | "x" |

## 입출력 예 설명
- 예 #1: `abc`를 입력하면 `abc|` (`|`는 커서). `[` 두 번으로 `a|bc`가 되고, `d`를 끼워 넣어 `ad|bc`가 됩니다.
- 예 #2: `hello|` → `[` 세 번 → `he|llo` → `<`로 `e`를 지워 `h|llo` → `]` 두 번 → `hll|o` → `<`로 `l`을 지워 `hl|o`. 결과는 `hlo`입니다.
- 예 #3: 비어 있을 때의 `<`와 맨 뒤에서의 `]`는 아무 일도 하지 않습니다.
