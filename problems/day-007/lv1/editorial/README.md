# 해설 — 순찰 경로의 길이

## 접근
1. `route.split(" ")`으로 지점 문자열들을 나눕니다.
2. 각 지점 `"(x,y)"`에서 괄호를 떼고 쉼표 위치를 찾아 `x`, `y`를 `Long.parseLong`으로 읽습니다. 음수 부호는 `parseLong`이 처리해 줍니다.
3. 바로 앞 지점과의 `|dx| + |dy|`를 누적합니다.

## 주의할 점
- 좌표 하나는 `int`에 들어가지만, 한 구간의 거리는 최대 4×10^9이고 누적 거리는 그보다 훨씬 커서 **`long`으로 계산**해야 합니다. `Math.abs(x1 - x2)`를 `int`로 계산하면 2×10^9를 넘는 순간 넘칩니다.
- `substring(1, s.length() - 1)`로 괄호를 떼고 `indexOf(',')`로 쉼표를 찾는 것이 정규식 `split`보다 빠릅니다. 20만 개 정도는 어느 쪽이든 통과합니다.
- 지점이 하나면 0입니다. 반복문이 두 번째 지점부터 돌도록 하세요.

## 복잡도
- 시간 O(|route|), 공간 O(|route|)
