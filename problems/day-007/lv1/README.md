# [lv1] 순찰 경로의 길이

경비 로봇이 지나갈 지점들이 문자열 `route`로 주어집니다. 각 지점은 `(x,y)` 형태이고, 지점과 지점 사이는 공백 하나로 구분됩니다. 예를 들어 `"(0,0) (3,4) (-2,4)"`는 (0, 0) → (3, 4) → (-2, 4) 순서로 이동한다는 뜻입니다.

로봇은 격자 위를 움직이므로 두 지점 사이의 이동 거리는 `|x1 - x2| + |y1 - y2|`입니다. `route`에 적힌 순서대로 모든 지점을 지날 때 **총 이동 거리**를 return 하도록 `solution` 함수를 완성해 주세요. 총 이동 거리는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- `route`에 적힌 지점의 수는 1 이상 200,000 이하입니다.
- 각 지점은 `(x,y)` 형태이며, `x`와 `y`는 -1,000,000,000 이상 1,000,000,000 이하의 정수입니다. 괄호와 쉼표 주변에 공백은 없습니다.
- 지점 사이는 공백 하나로 구분되고, `route`의 맨 앞과 맨 뒤에 공백은 없습니다.
- 같은 지점이 연달아 나올 수도 있습니다.

## 입출력 예

| route | result |
|---|---|
| "(0,0) (3,4) (-2,4)" | 12 |
| "(5,5)" | 0 |
| "(1000000000,1000000000) (-1000000000,-1000000000)" | 4000000000 |

## 입출력 예 설명
- 예 #1: (0, 0) → (3, 4)는 3 + 4 = 7, (3, 4) → (-2, 4)는 5 + 0 = 5 이므로 총 12입니다.
- 예 #2: 지점이 하나뿐이면 이동하지 않습니다.
- 예 #3: 2,000,000,000 + 2,000,000,000 = 4,000,000,000 으로 `int` 범위를 넘습니다.
