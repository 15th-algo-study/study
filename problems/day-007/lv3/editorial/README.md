# 해설 — 주차장 기록의 오류 한 줄

## 접근
`I`를 +1, `O`를 -1로 보고 접두 합 `bal[j]`(0번부터 j번 글자까지의 합)를 구합니다. 정상 기록 = 모든 접두 합이 0 이상이고 마지막 합이 0.

위치 `i`의 글자를 지우면 접두 합은 다음처럼 바뀝니다.
- `j < i`인 위치: 그대로 `bal[j]`
- `j ≥ i`인 위치: 지운 글자만큼 달라집니다. `I`를 지웠으면 `bal[j] - 1`, `O`를 지웠으면 `bal[j] + 1`

따라서 위치 `i`를 지워 정상이 되려면
1. **앞쪽 조건**: `bal[0..i-1]`이 모두 0 이상 (앞에서부터 훑으며 "지금까지 음수가 없었는지" 플래그로 유지)
2. **뒤쪽 조건**: `bal[i..n-1]`의 최솟값을 `sufMin[i]`라 할 때,
   - `I`를 지우는 경우 `sufMin[i] - 1 ≥ 0`, 즉 `sufMin[i] ≥ 1`
   - `O`를 지우는 경우 `sufMin[i] + 1 ≥ 0`, 즉 `sufMin[i] ≥ -1`
3. **끝 조건**: 전체 합 `total`이 `I`를 지우면 1, `O`를 지우면 -1이어야 합니다. 즉 `total == 1`이면 `I`만, `total == -1`이면 `O`만 후보이고, 그 밖이면 답은 0입니다.

`sufMin`은 뒤에서부터 한 번 훑어 만들고, 앞에서부터 한 번 더 훑으며 세 조건을 만족하는 위치를 세면 끝입니다.

## 주의할 점
- 위치마다 글자를 지운 문자열을 실제로 만들어 검사하면 O(n²)입니다. 길이 50만이면 2.5×10^11번 연산이라 시간 초과입니다. 특히 `"III…IOO…O"` 같은 기록은 검사가 끝까지 가므로 "운 좋게 빨리 끝나는" 일도 없습니다.
- 전체 합을 먼저 확인하면 길이가 짝수인 기록은 바로 0입니다.
- `sufMin[i]`는 **i번 위치를 포함**한 최솟값입니다. `O`를 지울 때 `bal[i] = bal[i-1] - 1`이 -1이어도 지운 뒤에는 0이 되므로 괜찮다는 점이 `≥ -1` 조건에 들어 있습니다.
- 길이 1인 기록(`"I"` 또는 `"O"`)은 지우면 빈 문자열이 되어 정상이므로 답이 1입니다. 위 조건식에서 자연스럽게 처리됩니다.

## 복잡도
- 시간 O(n), 공간 O(n)
