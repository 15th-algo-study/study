# [lv3] 주차장 기록의 오류 한 줄

주차장 입구 센서가 하루 동안 차가 드나든 순서를 기록합니다. 기록은 문자열 `log`로 주어지며, `I`는 차 한 대가 들어온 것, `O`는 차 한 대가 나간 것을 뜻합니다. 주차장은 아침에 비어 있었고 저녁에도 비어 있었습니다.

정상적인 기록은 다음 두 조건을 모두 만족합니다.
- 기록을 앞에서부터 읽는 동안 어느 순간에도 (들어온 차의 수) - (나간 차의 수)가 음수가 되지 않습니다.
- 기록을 끝까지 읽으면 (들어온 차의 수) - (나간 차의 수)가 0입니다.

그런데 센서 오작동으로 **기록 한 글자가 잘못 끼어들었습니다.** 어느 글자를 지우면 정상적인 기록이 되는지 알아보려고 합니다. `log`에서 글자 하나를 지웠을 때 정상적인 기록이 되는 **위치의 개수**를 return 하도록 `solution` 함수를 완성해 주세요. 그런 위치가 없으면 0을 return 합니다. 글자 하나를 지운 결과가 빈 문자열이면 정상적인 기록으로 봅니다.

## 제한사항
- 1 ≤ `log`의 길이 ≤ 500,000
- `log`는 `I`와 `O`로만 이루어져 있습니다.
- 같은 글자라도 위치가 다르면 서로 다른 위치로 셉니다.

## 입출력 예

| log | result |
|---|---|
| "IIO" | 2 |
| "IOIIO" | 2 |
| "IIII" | 0 |

## 입출력 예 설명
- 예 #1: 0번 또는 1번 위치의 `I`를 지우면 `IO`가 되어 정상입니다. 2번 위치의 `O`를 지우면 `II`가 되어 끝에 차가 남습니다.
- 예 #2: 2번 또는 3번 위치의 `I`를 지우면 `IOIO`가 되어 정상입니다. 0번 위치의 `I`를 지우면 `OIIO`가 되어 첫 글자에서 음수가 되고, 4번 위치의 `O`를 지우면 끝에 차가 남습니다.
- 예 #3: 어느 글자를 지워도 `III`가 되어 정상이 아닙니다.
