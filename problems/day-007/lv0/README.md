# [lv0] 거꾸로 쓴 이름표

유리문에 붙일 이름표를 만들려고 합니다. 안쪽에서 보면 글자가 좌우로 뒤집혀 보이므로, 문자열을 **뒤에서부터** 쓰고, 뒤집힌 티가 나도록 영문자의 **대소문자를 서로 바꿔** 씁니다. 숫자는 그대로 둡니다.

영문 대소문자와 숫자로 이루어진 문자열 `s`가 주어질 때, 위 규칙으로 만든 이름표 문자열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 1,000,000
- `s`는 영문 대문자, 영문 소문자, 숫자(`0`~`9`)로만 이루어져 있습니다.

## 입출력 예

| s | result |
|---|---|
| "Abc1" | "1CBa" |
| "Hello2024" | "4202OLLEh" |
| "7" | "7" |

## 입출력 예 설명
- 예 #1: 뒤집으면 `1cbA`이고, 대소문자를 바꾸면 `1CBa`입니다.
- 예 #2: 뒤집으면 `4202olleH`이고, 대소문자를 바꾸면 `4202OLLEh`입니다.
- 예 #3: 숫자 하나뿐이므로 그대로입니다.
