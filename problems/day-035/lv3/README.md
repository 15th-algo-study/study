# [lv3] 향신료 배합 레시피 수

향신료 통이 `n`개 있고, `i`번 통에는 향신료가 `weights[i]` 그램 들어 있습니다. 레시피는 통 중 **하나 이상을 골라** 각 통의 향신료를 **통째로** 넣는 것으로 정해지고, 고른 통의 집합이 다르면 다른 레시피입니다.

넣은 향신료의 총량이 `lo` 그램 이상 `hi` 그램 이하인 레시피의 수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `weights`의 길이 `n` ≤ 40
- 1 ≤ `weights`의 원소 ≤ 1,000,000,000
- 1 ≤ `lo` ≤ `hi` ≤ 40,000,000,000 (`long`)
- 레시피 수는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 입출력 예

| weights | lo | hi | result |
|---|---|---|---|
| [1, 2, 3] | 3 | 4 | 3 |
| [5, 5, 5] | 10 | 10 | 3 |
| [4] | 5 | 9 | 0 |

## 입출력 예 설명
- 예 #1: 총량이 3 또는 4인 고르기는 {3}, {1, 2}, {1, 3}의 3가지입니다.
- 예 #2: 세 통 중 두 통을 고르는 3가지입니다. 통은 서로 구분되므로 각각 다른 레시피입니다.
- 예 #3: 가능한 총량은 4뿐이라 조건을 만족하는 레시피가 없습니다.
