# 해설 — 원단을 정사각형으로

## 접근
`w ≥ h`라고 하면 한 변 `h`인 정사각형을 **한 장씩이 아니라 `w / h`장 한꺼번에** 잘라낼 수 있고, 그러면 `(w mod h) × h` 직사각형이 남습니다. 남은 직사각형에 같은 일을 반복하는 재귀입니다.

> `squares(w, h)` = `h == 0 ? 0 : w / h + squares(h, w mod h)`  (`w ≥ h`가 되도록 순서를 맞춘 뒤)

인자가 유클리드 호제법과 똑같이 줄어들므로 `w`, `h`가 10^18이어도 재귀는 90번을 넘지 않습니다.

## 주의할 점
- 정사각형을 **한 장씩** 잘라내며 세면(`w -= h`를 반복) 10^18 × 1 원단에서 10^18번 반복해 시간 초과입니다. 몫으로 한 번에 처리하는 것이 핵심입니다. 같은 이유로 한 장씩 재귀하면 깊이도 10^18이 되어 StackOverflowError가 납니다. `large_02`, `large_03`이 이를 걸러냅니다.
- 조각 수는 최대 10^18이라 `long`에 누적합니다.
- `w < h`인 입력도 들어옵니다. 함수 시작에서 큰 쪽을 `w`로 두세요.
- 정사각형 원단(`w == h`)은 `w / h = 1`, 나머지 0으로 1장이 됩니다.

## 복잡도
- 시간 O(q × log M) (q = 원단 수, M = 길이 최댓값), 공간 O(q)
