# [lv2] 전시 작품 조합 찾기

미술관에 작품이 `n`점 있고 1번부터 `n`번까지 번호가 붙어 있습니다. 이 중 `r`점을 골라 전시하려고 합니다.

고른 작품 번호를 오름차순으로 나열한 것을 **조합**이라고 부릅니다. 예를 들어 `n = 4`, `r = 2`이면 조합은 [1, 2], [1, 3], [1, 4], [2, 3], [2, 4], [3, 4]의 6가지이고, 이 순서가 **사전순**입니다(앞에서부터 번호를 비교해 작은 쪽이 먼저).

모든 조합을 사전순으로 나열해 1번부터 번호를 붙였을 때, 질문 `ks[i]`에 대해 `ks[i]`번째 조합을 구해 질문 순서대로 담은 2차원 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `r` ≤ `n` ≤ 60
- 1 ≤ `ks`의 길이 ≤ 20,000
- 1 ≤ `ks`의 원소 ≤ (조합의 총수 = nCr) (`long`). `n = 60`, `r = 30`일 때 조합의 총수는 118,264,581,564,861,424입니다.
- 각 답은 길이 `r`인 오름차순 배열입니다.

## 입출력 예

| n | r | ks | result |
|---|---|---|---|
| 4 | 2 | [4, 6, 1] | [[2, 3], [3, 4], [1, 2]] |
| 5 | 3 | [7] | [[2, 3, 4]] |
| 3 | 3 | [1] | [[1, 2, 3]] |

## 입출력 예 설명
- 예 #1: 사전순 4번째는 [2, 3], 6번째는 [3, 4], 1번째는 [1, 2]입니다.
- 예 #2: `n = 5`, `r = 3`의 조합은 [1,2,3], [1,2,4], [1,2,5], [1,3,4], [1,3,5], [1,4,5], [2,3,4], … 순서이므로 7번째는 [2, 3, 4]입니다.
- 예 #3: 조합이 하나뿐입니다.
