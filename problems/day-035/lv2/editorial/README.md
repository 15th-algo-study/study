# 해설 — 전시 작품 조합 찾기

## 접근
조합을 사전순으로 하나씩 만들어 k번째까지 세는 백트래킹은 k가 10^17까지 가므로 불가능합니다. 대신 **"어떤 번호로 시작하는 조합이 몇 개인지"를 세어 첫 번호를 바로 확정**하고, 나머지에 대해 같은 일을 반복합니다.

지금 고를 수 있는 가장 작은 번호가 `x`이고 앞으로 `r`개를 더 골라야 한다고 합시다.

- `x`를 고르는 조합의 수는 "`x`보다 큰 번호 `n − x`개 중 `r − 1`개를 고르는 수" = `C(n − x, r − 1)`입니다.
- `k ≤ C(n − x, r − 1)`이면 답은 `x`로 시작합니다. `x`를 확정하고 `r − 1`개를 `x + 1`부터 고르는 문제로 내려갑니다.
- 아니면 `x`로 시작하는 조합을 모두 건너뛰므로 `k −= C(n − x, r − 1)`을 하고 `x + 1`을 시도합니다.

`x`는 1부터 `n`까지 한 방향으로만 증가하므로 질문당 O(n)입니다. 이항계수 `C(i, j)`는 파스칼의 삼각형(`C(i, j) = C(i−1, j−1) + C(i−1, j)`)으로 61 × 61 표를 한 번 만들어 둡니다.

## 주의할 점
- `C(60, 30) ≈ 1.18×10^17` 이므로 표와 `k`는 `long`입니다. `C(i, j)`를 팩토리얼로 구하면 60!이 `long`을 한참 넘치므로 파스칼의 삼각형을 쓰세요.
- `r − 1 > n − x`이면 `C(n − x, r − 1) = 0`입니다. 표의 범위 밖 인덱스가 되지 않도록 `j > i`인 칸은 0으로 두거나 조건으로 막습니다.
- 질문이 2만 개이고 답마다 길이 `r`인 배열을 만드므로 결과 크기는 최대 60만 정수입니다. 질문마다 새 `int[r]`을 만들어 채우면 됩니다.
- 사전순은 "번호가 작은 쪽이 먼저"입니다. 이 순서에서는 `[1, 60]`이 `[2, 3]`보다 앞섭니다.

## 복잡도
- 시간 O(n² + q × n) (q = 질문 수), 공간 O(n² + q × r)
