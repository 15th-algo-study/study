# 해설 — 1층까지 내려가기

## 접근
"한 번 움직인 뒤의 층에서 같은 일을 다시 한다"이므로 재귀로 그대로 적을 수 있습니다.

> `moves(n)` = `n == 1 ? 0 : 1 + moves(n이 짝수 ? n / 2 : n − 1)`

홀수 층에서 한 층 내려가면 반드시 짝수가 되어 바로 절반으로 줄어듭니다. 즉 두 번 움직일 때마다 층 수가 최소 절반이 되므로, 10^18층에서도 약 2 × 60 = 120번 안에 끝납니다. 재귀 깊이도 그만큼이라 안전합니다.

## 주의할 점
- 층 수는 `long`입니다. `n % 2 == 0`, `n / 2`, `n - 1` 모두 `long` 연산으로 씁니다.
- 1층에서 시작하면 0입니다. 종료 조건을 `n == 1`로 두면 됩니다 (`n == 0`은 등장하지 않습니다).
- 횟수 자체는 120 이하라 `int`에 담아도 됩니다.
- (참고) 답은 "2진법 자릿수 − 1 + (1인 비트 수 − 1)"과 같습니다. 재귀를 손으로 따라가 보면 왜 그런지 알 수 있습니다.

## 복잡도
- 시간 O(q × log N) (q = 시작 층 수, N = 층 수 최댓값), 공간 O(q)
