# [lv0] 1층까지 내려가기

아주 높은 탑에서 하는 놀이가 있습니다. 어떤 층에서 시작해 다음 규칙으로 내려갑니다.

- 지금 층이 **짝수**이면 미끄럼틀을 타고 **절반 층**으로 한 번에 내려갑니다. (예: 10층 → 5층)
- 지금 층이 **홀수**이면 계단으로 **한 층** 내려갑니다. (예: 5층 → 4층)
- 1층에 도착하면 끝납니다.

예를 들어 10층에서 시작하면 10 → 5 → 4 → 2 → 1 로 4번 움직입니다.

시작 층 배열 `starts`가 주어질 때, 각 시작 층에서 1층에 도착할 때까지 움직이는 횟수를 같은 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `starts`의 길이 ≤ 100,000
- 1 ≤ `starts`의 원소 ≤ 1,000,000,000,000,000,000 (10^18, `long`)
- 1층에서 시작하면 움직이지 않으므로 0입니다.

## 입출력 예

| starts | result |
|---|---|
| [1, 2, 3, 10] | [0, 1, 2, 4] |
| [7, 1023] | [4, 18] |
| [1000000000000000000] | [82] |

## 입출력 예 설명
- 예 #1: 2 → 1 (1번), 3 → 2 → 1 (2번), 10 → 5 → 4 → 2 → 1 (4번)
- 예 #2: 7 → 6 → 3 → 2 → 1 (4번). 1023은 홀수와 짝수가 번갈아 나와 18번 움직입니다.
- 예 #3: 10^18층에서도 82번이면 내려옵니다.
