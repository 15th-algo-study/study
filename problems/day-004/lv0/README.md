# [lv0] 엘리베이터 이동 거리

엘리베이터가 1층에서 출발해 배열 `floors`에 적힌 층을 순서대로 방문합니다. 엘리베이터가 움직인 층 수의 합을 return 하도록 `solution` 함수를 완성해 주세요. 예를 들어 5층에서 2층으로 가면 3개 층을 움직인 것입니다.

## 제한사항
- 1 ≤ `floors`의 길이 ≤ 100,000
- 1 ≤ `floors`의 원소 ≤ 1,000

## 입출력 예

| floors | result |
|---|---|
| [5, 2, 8] | 13 |
| [1, 1, 1] | 0 |

## 입출력 예 설명
- 예 #1: 1→5 (4층), 5→2 (3층), 2→8 (6층). 합은 13입니다.
- 예 #2: 계속 1층에 머무릅니다.
