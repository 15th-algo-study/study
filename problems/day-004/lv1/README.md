# [lv1] 택배 트럭 배차

물류 센터에서 택배 상자를 들어온 순서대로 트럭에 싣습니다. 트럭 한 대에 실을 수 있는 무게 합의 최대는 `capacity`입니다.

- 상자는 반드시 들어온 순서대로 싣고, 순서를 바꾸거나 건너뛸 수 없습니다.
- 다음 상자를 지금 트럭에 실으면 무게 합이 `capacity`를 넘는 경우, 지금 트럭을 출발시키고 새 트럭에 그 상자부터 싣기 시작합니다.

상자 무게 배열 `weights`와 `capacity`가 주어질 때, 필요한 트럭의 수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `weights`의 길이 ≤ 200,000
- 1 ≤ `capacity` ≤ 2,000,000,000
- 1 ≤ `weights`의 원소 ≤ `capacity`

## 입출력 예

| weights | capacity | result |
|---|---|---|
| [3, 5, 2, 4, 1] | 7 | 3 |
| [7, 7, 7] | 7 | 3 |

## 입출력 예 설명
- 예 #1: 1번 트럭 [3] (5를 더하면 8 > 7), 2번 트럭 [5, 2], 3번 트럭 [4, 1]
- 예 #2: 상자 하나가 트럭 하나를 가득 채웁니다.
