# 해설 — 택배 트럭 배차

## 접근
지금 트럭의 적재량 `load`를 들고 상자를 순서대로 봅니다. 상자를 더했을 때 `capacity`를 넘으면 트럭 수를 늘리고 적재량을 0으로 되돌린 뒤 싣습니다. 첫 트럭이 있으므로 트럭 수는 1에서 시작합니다.

## 주의할 점
- **정수 오버플로**: `capacity`와 무게가 최대 20억입니다. `load`(최대 20억)에 `w`(최대 20억)를 더하면 40억으로 `int` 최댓값(약 21억)을 넘어 음수가 되고, 비교가 틀어집니다. `load`를 `long`으로 두거나 `w > capacity - load`로 비교하세요.
- 각 상자 무게는 `capacity` 이하라 상자 하나가 트럭 하나에 항상 실립니다.

## 복잡도
- 시간 O(n), 공간 O(1)
