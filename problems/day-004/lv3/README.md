# [lv3] 막대 위의 개미

길이가 `length`인 막대가 수평으로 놓여 있고, 왼쪽 끝이 위치 0, 오른쪽 끝이 위치 `length`입니다. 막대 위에 개미 `n`마리가 서로 다른 정수 위치에 있습니다. `i`번 개미의 위치는 `positions[i]`이고, 처음 바라보는 방향은 `directions`의 `i`번째 글자(`'L'`은 왼쪽, `'R'`은 오른쪽)입니다.

- 모든 개미는 동시에 출발해 초당 1의 속도로 바라보는 방향으로 걷습니다.
- 두 개미가 마주치면 두 개미 모두 즉시 방향을 반대로 바꿉니다 (시간 손실 없음). 마주치는 지점은 정수가 아닐 수도 있습니다.
- 개미가 위치 0이나 `length`에 도달하면 그 순간 막대에서 떨어집니다.

각 개미가 떨어지는 시각을 개미 번호 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 2 ≤ `length` ≤ 1,000,000,000
- 1 ≤ `positions`의 길이 `n` ≤ 200,000
- 0 < `positions[i]` < `length`, 모든 위치는 서로 다릅니다. 정렬되어 있지 않을 수 있습니다.
- `directions`의 길이는 `n`이고 `'L'`, `'R'`로만 이루어져 있습니다.
- 답은 항상 정수입니다.

## 입출력 예

| length | positions | directions | result |
|---|---|---|---|
| 10 | [2, 5, 8] | "RLL" | [5, 8, 8] |
| 7 | [6, 1] | "LR" | [6, 6] |
| 5 | [3] | "R" | [2] |

## 입출력 예 설명
- 예 #1
  - 1.5초에 0번(2→)과 1번(←5)이 위치 3.5에서 마주쳐 방향을 바꿉니다. 0번은 왼쪽으로 3.5를 더 걸어 5초에 떨어집니다.
  - 3초에 1번(3.5→)과 2번(←8)이 위치 5에서 마주칩니다. 1번은 왼쪽으로 5를 걸어 8초에, 2번은 오른쪽으로 5를 걸어 8초에 떨어집니다.
- 예 #2: 1번 개미(1→)와 0번 개미(←6)가 2.5초에 위치 3.5에서 마주쳐 방향을 바꿉니다. 1번 개미는 왼쪽 끝까지 3.5를 더 걸어 6초에, 0번 개미는 오른쪽 끝까지 3.5를 걸어 6초에 떨어집니다.
- 예 #3: 개미 하나는 오른쪽 끝까지 2를 걸어갑니다.
