# 해설 — 막대 위의 개미

## 핵심 관찰 1: 충돌은 "지나치기"와 같다
두 개미가 마주쳐 방향을 바꾸는 것은, 개미의 이름표만 바꿔 단 채 서로 지나쳐 가는 것과 겉보기에 똑같습니다. 그래서 **이름표를 무시하면** 떨어지는 사건들은 충돌이 없을 때와 같습니다.

- `'L'` 개미 하나당 시각 `position`에 왼쪽 끝으로 누군가 떨어집니다.
- `'R'` 개미 하나당 시각 `length - position`에 오른쪽 끝으로 누군가 떨어집니다.

## 핵심 관찰 2: 개미의 좌우 순서는 바뀌지 않는다
개미끼리는 서로를 통과하지 못하므로, 위치로 정렬한 순서가 끝까지 유지됩니다.

- 왼쪽 끝으로 떨어지는 사건이 `L`개라면, 왼쪽 끝에 닿는 것은 언제나 "지금 가장 왼쪽 개미"입니다. 따라서 **왼쪽에서 k번째 개미가 왼쪽 사건 중 k번째로 이른 시각에** 떨어집니다.
- 마찬가지로 **오른쪽에서 k번째 개미가 오른쪽 사건 중 k번째로 이른 시각에** 떨어집니다.

정리하면
1. 개미 번호를 위치 순으로 정렬한다.
2. 왼쪽 사건 시각, 오른쪽 사건 시각을 각각 정렬한다.
3. 위치 순 앞쪽 `L`마리에 왼쪽 시각을 차례로, 뒤쪽에서부터 오른쪽 시각을 차례로 배정한다.

## 주의할 점
- 충돌을 하나씩 처리하는 시뮬레이션은 충돌 횟수가 O(n²)까지 늘어나 20만 마리에서 시간 초과입니다.
- 입력 위치가 정렬되어 있지 않으므로, 결과는 **원래 개미 번호 순서**로 돌려줘야 합니다. 번호를 정렬하는 `Integer[]` + `Comparator` 패턴을 익혀 두세요.

## 복잡도
- 시간 O(n log n), 공간 O(n)
