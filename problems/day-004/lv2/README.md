# [lv2] 한 차로 신호등

한 차로 도로의 교차로에 신호등이 있습니다. 시각 0초에 초록불이 켜지고, 초록불 `green`초 → 빨간불 `red`초가 계속 반복됩니다. 즉 정수 시각 `t`초에 신호가 초록인 것은 `t`를 `green + red`로 나눈 나머지가 `green`보다 작을 때입니다.

자동차 `n`대가 교차로에 도착하는 시각이 배열 `arrivals`에 도착 순서대로 주어집니다. 자동차는 다음 규칙으로 교차로를 통과합니다.

- 자동차는 도착한 순서대로만 통과합니다 (추월 불가).
- 1초에 최대 1대만 통과합니다.
- 각 자동차는 다음을 모두 만족하는 가장 이른 정수 시각 `t`에 통과합니다.
  - `t` ≥ 그 자동차의 도착 시각
  - `t` > 바로 앞 자동차의 통과 시각
  - `t`초에 신호가 초록

각 자동차의 통과 시각을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `green`, `red` ≤ 1,000,000,000
- 1 ≤ `arrivals`의 길이 ≤ 200,000
- 0 ≤ `arrivals`의 원소 ≤ 1,000,000,000, 오름차순(같은 값 가능)으로 주어집니다.
- 통과 시각은 `int` 범위를 넘을 수 있으므로 `long[]`으로 return 합니다.

## 입출력 예

| green | red | arrivals | result |
|---|---|---|---|
| 2 | 3 | [0, 0, 0, 1, 7] | [0, 1, 5, 6, 10] |
| 1 | 1000000000 | [5, 5] | [1000000001, 2000000002] |

## 입출력 예 설명
- 예 #1: 주기는 5초이고 0, 1초(나머지 0, 1)가 초록입니다.
  - 1번 차: 0초 통과. 2번 차: 1초 통과. 3번 차: 2초는 빨강 → 다음 초록은 5초.
  - 4번 차: 6초(나머지 1) 초록 → 6초. 5번 차: 7초 도착, 7초(나머지 2) 빨강 → 10초.
- 예 #2: 주기는 1,000,000,001초이고 각 주기의 첫 1초만 초록입니다.
