# 해설 — 한 차로 신호등

## 접근
자동차마다 "통과할 수 있는 가장 이른 후보 시각"을 구한 뒤, 빨간불이면 **다음 초록불 시작 시각으로 한 번에 점프**합니다.

1. 후보 `t = max(도착 시각, 앞 차 통과 시각 + 1)`
2. `phase = t % (green + red)`
3. `phase < green`이면 초록이므로 `t`에 통과.
   아니면 이번 주기의 빨간불이 끝나는 `t + (cycle - phase)`가 다음 초록의 시작이고, 그때 통과합니다.

점프한 시각은 초록의 시작이라 항상 통과 가능하고, 앞 차보다 늦다는 조건도 이미 만족합니다.

## 주의할 점
- **1초씩 시간을 흘리는 시뮬레이션은 안 됩니다.** 빨간불이 10억 초면 자동차 한 대에 10억 번 반복합니다.
- **오버플로**: `green + red`는 최대 20억으로 `int`를 넘습니다. `(long) green + red`처럼 더하기 전에 `long`으로 바꿔야 합니다. 통과 시각도 최대 약 2×10^5 × 2×10^9 = 4×10^14이라 `long`입니다.
- 같은 시각에 여러 대가 도착하면 1초 간격으로 차례로 통과합니다.

## 복잡도
- 시간 O(n), 공간 O(n)
