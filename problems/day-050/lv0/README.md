# [lv0] 버스 번호판의 단골 숫자

시내버스 동호회에서는 버스 번호판의 숫자 가운데 **가장 여러 번 나온 숫자**를 그 버스의 "단골 숫자"라고 부릅니다. 가장 많이 나온 숫자가 여럿이면 그중 **가장 작은 숫자**를 고릅니다. 예를 들어 112233은 1, 2, 3이 두 번씩이라 단골 숫자는 1이고, 90909는 9가 세 번이라 9입니다.

번호판 숫자 배열 `plates`가 주어질 때, 각 번호판의 단골 숫자를 같은 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `plates`의 길이 ≤ 100,000
- 0 ≤ `plates`의 원소 ≤ 1,000,000,000,000,000,000 (10^18, `long`)
- 번호판이 0이면 숫자 0 하나로 이루어진 것으로 보아 단골 숫자는 0입니다.

## 입출력 예

| plates | result |
|---|---|
| [112233, 7, 90909] | [1, 7, 9] |
| [0, 1000000000000000000, 5454] | [0, 0, 4] |

## 입출력 예 설명
- 예 #1: 112233은 1·2·3이 두 번씩이라 가장 작은 1. 7은 7. 90909는 9가 세 번, 0이 두 번이라 9.
- 예 #2: 0은 0. 10^18은 0이 열여덟 번이라 0. 5454는 4와 5가 두 번씩이라 4.
