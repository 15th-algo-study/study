# [lv3] 도예 공방의 가마 배정

도예 공방에 똑같은 가마 `k`대가 있습니다. 작품 굽기 신청이 `works`로 주어지는데, `works[i] = [start, duration]`은 시각 `start`부터 `duration`시간 동안, 즉 `start` 이상 `start + duration` **미만**의 시간 동안 가마 하나를 통째로 써야 한다는 뜻입니다. 시각은 바꿀 수 없고, 가마 한 대는 한 번에 작품 하나만 구울 수 있습니다. 앞 작품이 끝나는 시각에 다음 작품을 바로 넣는 것은 괜찮습니다.

신청 가운데 일부를 골라 가마 `k`대에 겹치지 않게 배정할 때, **구울 수 있는 작품 수의 최댓값**을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `works`의 길이 `n` ≤ 400,000
- 1 ≤ `k` ≤ 400,000
- 0 ≤ `start` ≤ 1,000,000,000
- 1 ≤ `duration` ≤ 1,000,000,000
- 같은 신청이 여러 번 들어올 수 있습니다.

## 입출력 예

| works | k | result |
|---|---|---|
| [[5, 1], [2, 1], [3, 4], [0, 4], [0, 4]] | 2 | 4 |
| [[0, 2], [1, 2], [2, 2], [1, 4]] | 1 | 2 |
| [[0, 10], [0, 10], [0, 10]] | 5 | 3 |

## 입출력 예 설명
- 예 #1: 사용 시간은 [5, 6), [2, 3), [3, 7), [0, 4), [0, 4)입니다. 가마 1에 [2, 3), [3, 7), 가마 2에 [0, 4), [5, 6)을 넣으면 4개입니다. [0, 4) 두 개를 모두 받으면 [2, 3)과 [3, 7)을 받을 수 없어 3개가 됩니다.
- 예 #2: 가마가 하나이면 [0, 2), [2, 4)의 2개가 최대입니다.
- 예 #3: 가마가 작품보다 많으면 모두 구울 수 있습니다.
