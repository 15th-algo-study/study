# [lv2] 번호 타일 이어 붙이기

타일 공방에 숫자가 새겨진 타일 `n`장이 있습니다. 각 타일에는 1자리 이상 9자리 이하의 수가 새겨져 있고, 타일 `i`의 수는 문자열 `tiles[i]`로 주어집니다. 타일 `n`장을 **모두** 한 줄로 이어 붙이면 긴 수가 하나 만들어집니다.

타일의 순서를 잘 정해 만들 수 있는 **가장 큰 수**를 문자열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `tiles`의 길이 `n` ≤ 200,000
- `tiles[i]`는 숫자로만 이루어진 길이 1 이상 9 이하의 문자열이고, 첫 글자는 `'0'`이 아닙니다.
- 결과는 매우 길 수 있으므로 숫자로 바꾸지 말고 문자열 그대로 return 합니다.

## 입출력 예

| tiles | result |
|---|---|
| ["3", "30", "34", "5", "9"] | "9534330" |
| ["12", "121"] | "12121" |
| ["7", "77", "777"] | "777777" |

## 입출력 예 설명
- 예 #1: 9, 5, 34, 3, 30 순서로 붙이면 9534330입니다. 수가 큰 순서(34, 30, 9, 5, 3)로 붙이면 3430953, 문자열 사전 역순(9, 5, 34, 30, 3)으로 붙이면 9534303이라 더 작습니다.
- 예 #2: "12" + "121" = 12121이 "121" + "12" = 12112보다 큽니다. 사전순으로는 "121"이 "12"보다 뒤에 오므로 사전 역순 정렬은 틀립니다.
- 예 #3: 어떤 순서로 붙여도 777777입니다.
