# 해설 — 대장간 주문 지각

## 접근
**약속 시각이 이른 순서**(마감 오름차순)로 처리합니다. 정렬한 뒤 끝나는 시각을 누적하면서 `끝 시각 − 약속 시각`의 최댓값을 구하고, 음수이면 0으로 봅니다.

왜 맞는지(교환 논법): 어떤 순서에서 이웃한 두 주문 `a`(앞), `b`(뒤)의 약속 시각이 `due_a > due_b`라고 합시다. 둘을 바꾸면 다른 주문의 끝 시각은 그대로입니다. 두 주문이 모두 끝나는 시각을 `T`라 하면, 바꾸기 전 둘의 지각 최댓값은 `max(T − time_b − due_a, T − due_b)` 이상인데 `T − due_b`가 가장 큰 값입니다. 바꾼 뒤에는 `b`가 먼저 끝나 지각이 `T − time_a − due_b < T − due_b`이고, `a`는 `T − due_a < T − due_b`입니다. 즉 바꾼 뒤 둘의 최대 지각이 바꾸기 전보다 작거나 같습니다. 따라서 마감 순서를 어긴 이웃 쌍이 없을 때, 즉 마감 오름차순일 때가 최적입니다.

## 주의할 점
- "짧은 주문부터"(예 #1에서 11)는 평균 대기 시간을 줄이지만 최대 지각에는 틀린 그리디입니다.
- 끝 시각은 최대 2×10^14라 `long`으로 누적해야 합니다.
- 모두 제시간에 끝나면 0입니다. 최댓값의 초깃값을 0으로 두면 음수 지각이 자연스럽게 걸러집니다.

## 복잡도
- 시간 O(n log n), 공간 O(1) 추가
