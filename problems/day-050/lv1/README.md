# [lv1] 대장간 주문 지각

대장간에 주문 `n`건이 밀려 있습니다. 주문 `i`는 만드는 데 `orders[i][0]`시간이 걸리고, 손님이 **시각 `orders[i][1]`까지** 받기로 했습니다. 대장장이는 시각 0부터 한 번에 한 건씩, 쉬지 않고 이어서 작업합니다. 주문을 끝낸 시각이 약속 시각보다 늦으면 그 차이만큼 **지각**한 것이고, 늦지 않았으면 지각은 0입니다.

주문 처리 순서를 자유롭게 정할 수 있을 때, **가장 많이 지각한 주문의 지각 시간**이 최소가 되도록 순서를 정했을 때의 그 값을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `orders`의 길이 `n` ≤ 200,000
- `orders[i] = [time, due]`, 1 ≤ `time` ≤ 1,000,000,000, 1 ≤ `due` ≤ 1,000,000,000
- 답이 `int` 범위를 넘을 수 있으므로 `long`을 return 합니다.

## 입출력 예

| orders | result |
|---|---|
| [[2, 9], [2, 1], [9, 2]] | 9 |
| [[3, 3], [2, 5], [1, 6]] | 0 |
| [[5, 1]] | 4 |

## 입출력 예 설명
- 예 #1: 약속이 급한 순서 [2, 1] → [9, 2] → [2, 9]로 하면 끝나는 시각은 2, 11, 13이고 지각은 1, 9, 4라 최대 9입니다. 짧은 주문부터 [2, 1] → [2, 9] → [9, 2]로 하면 끝나는 시각 2, 4, 13에 지각 1, 0, 11이라 최대 11입니다.
- 예 #2: 주어진 순서대로 하면 3, 5, 6에 끝나 아무도 늦지 않습니다.
- 예 #3: 시각 5에 끝나므로 4만큼 지각합니다.
