# 해설 — 같은 브랜드 매장 사이의 거리 합

## 접근
같은 브랜드끼리 모든 쌍을 직접 더하면 한 브랜드에 매장이 많을 때 O(n²)입니다. 관찰은 다음과 같습니다.

매장이 위치 순으로 주어지므로, `j`번 매장을 볼 때 **같은 브랜드의 이전 매장들은 모두 왼쪽**에 있습니다. 이전 매장이 `k`개이고 위치 합이 `S`라면, `j`번 매장과 그들 사이의 거리 합은

> `(p_j - p_1) + (p_j - p_2) + … + (p_j - p_k) = p_j × k - S`

입니다. 따라서 브랜드마다 `(개수 k, 위치 합 S)` 두 값만 `HashMap`에 들고 가면, 매장 하나당 O(1)에 그 매장이 만드는 쌍의 거리 합을 모두 더할 수 있습니다. 더한 뒤 `k += 1`, `S += p_j`로 갱신합니다.

## 주의할 점
- 모든 쌍 `(i, j)`를 보며 브랜드가 같은지 비교하면 약 4.5×10^10 번이라 시간 초과입니다. 브랜드별로 묶은 뒤 그 안에서 모든 쌍을 더해도 브랜드가 하나뿐이면 역시 O(n²)입니다.
- `p_j × k`는 최대 10^8 × 3×10^5 = 3×10^13이고 총합은 약 2.3×10^18까지 커질 수 있습니다. 모든 계산을 `long`으로 하세요. 위치 합 `S`도 `long`이어야 합니다.
- `Math.abs`가 필요 없습니다. 입력이 위치 순이라 항상 `p_j`가 더 크기 때문입니다.
- 브랜드 이름 대소문자를 구분합니다 (`equalsIgnoreCase`나 `toLowerCase`를 쓰면 안 됩니다).

## 복잡도
- 시간 O(n), 공간 O(브랜드 종류 수)
