# [lv3] 같은 브랜드 매장 사이의 거리 합

긴 직선 도로를 따라 매장 `n`개가 서 있습니다. `i`번 매장의 위치는 `positions[i]`(도로 시작점에서의 거리)이고, 브랜드 이름은 `brands[i]`입니다. 매장은 위치가 **커지는 순서**로 주어지며 같은 위치에 두 매장이 있지는 않습니다.

본사는 브랜드마다 "같은 브랜드의 매장 두 곳 사이의 거리"를 모든 쌍에 대해 더한 값을 알고 싶어 합니다. 모든 브랜드에 대해 이 값을 더한 총합을 return 하도록 `solution` 함수를 완성해 주세요. 총합은 `int` 범위를 넘으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `n` ≤ 300,000
- 1 ≤ `positions[i]` ≤ 100,000,000, `positions[i] < positions[i+1]`
- `brands[i]`는 길이 1 이상 10 이하의 영문 대소문자·숫자로만 이루어져 있습니다. 대소문자가 다르면 다른 브랜드입니다.
- 같은 브랜드의 매장이 하나뿐이면 그 브랜드의 거리 합은 0입니다.

## 입출력 예

| positions | brands | result |
|---|---|---|
| [1, 3, 6, 10, 15] | ["A", "B", "A", "A", "B"] | 30 |
| [2, 5, 9] | ["x", "y", "z"] | 0 |
| [1, 2, 3, 4] | ["k", "k", "k", "k"] | 10 |

## 입출력 예 설명
- 예 #1: 브랜드 A의 매장은 1, 6, 10에 있어 거리 합이 (6-1) + (10-1) + (10-6) = 18입니다. 브랜드 B는 3, 15에 있어 12입니다. 총합은 30입니다.
- 예 #2: 모두 다른 브랜드라 더할 쌍이 없습니다.
- 예 #3: 여섯 쌍의 거리는 1, 2, 3, 1, 2, 1이고 합은 10입니다.
