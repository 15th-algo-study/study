# [lv1] 두 동아리 명단 비교

학교에 축구 동아리와 밴드 동아리가 있습니다. 축구 동아리 명단 `soccer`와 밴드 동아리 명단 `band`가 학생 이름 배열로 주어집니다. 명단은 출석부를 그대로 옮긴 것이라 **같은 학생이 한 명단에 여러 번 적혀 있을 수 있습니다.** 이름이 같으면 같은 학생이고, 대소문자가 다르면 다른 학생입니다.

다음 세 값을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

1. 축구 동아리에만 속한 학생 수
2. 밴드 동아리에만 속한 학생 수
3. 두 동아리에 모두 속한 학생 수

## 제한사항
- 1 ≤ `soccer`의 길이, `band`의 길이 ≤ 200,000
- 이름은 길이 1 이상 10 이하의 영문 대소문자·숫자로만 이루어져 있습니다.

## 입출력 예

| soccer | band | result |
|---|---|---|
| ["kim", "lee", "park", "choi", "kim"] | ["lee", "choi", "jung"] | [2, 1, 2] |
| ["ann", "bob"] | ["cat"] | [2, 1, 0] |
| ["Kim", "kim"] | ["kim", "kim"] | [1, 0, 1] |

## 입출력 예 설명
- 예 #1: 축구 동아리 학생은 kim, lee, park, choi 네 명입니다(kim은 두 번 적혀 있습니다). 둘 다 속한 학생은 lee, choi이고, 축구에만 속한 학생은 kim, park, 밴드에만 속한 학생은 jung입니다.
- 예 #2: 겹치는 학생이 없습니다.
- 예 #3: `Kim`과 `kim`은 다른 학생입니다. `kim`은 둘 다 속하고 `Kim`은 축구에만 속합니다.
