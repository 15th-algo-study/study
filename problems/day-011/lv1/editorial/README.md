# 해설 — 두 동아리 명단 비교

## 접근
명단을 `HashSet<String>`에 넣으면 중복이 사라지고, 어떤 이름이 들어 있는지 O(1)에 물어볼 수 있습니다.

1. 두 명단을 각각 `HashSet`으로 만듭니다 (`a`, `b`).
2. `a`의 이름마다 `b.contains(name)`이면 "둘 다", 아니면 "축구만"으로 셉니다.
3. "밴드만"은 `b.size() - 둘 다`입니다.

## 주의할 점
- 명단에 같은 이름이 여러 번 있어도 **학생 수**를 세야 하므로 배열 그대로 세면 안 됩니다. 집합에 먼저 넣으세요.
- 이름마다 다른 배열을 끝까지 훑어 비교하면 O(n·m) = 4×10^10 번 비교라 시간 초과입니다.
- `String`은 `==`가 아니라 `equals`로 비교해야 하지만, `HashSet`을 쓰면 신경 쓸 일이 없습니다.

## 복잡도
- 시간 O(n + m), 공간 O(n + m)
