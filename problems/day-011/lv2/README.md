# [lv2] 순이익이 딱 맞는 기간

작은 가게의 하루 손익을 순서대로 기록한 배열 `records`가 주어집니다. `records[i]`는 `i`번째 날의 손익으로, 양수면 이익, 음수면 손실, 0이면 본전입니다.

사장님은 "연속된 며칠"을 하나의 기간으로 보고, 그 기간의 손익 합이 **정확히 `target`**인 기간이 몇 개인지 알고 싶어 합니다. 기간은 하루 이상이어야 하며, 시작 날이나 끝 날이 다르면 다른 기간으로 셉니다.

손익 합이 `target`인 기간의 개수를 return 하도록 `solution` 함수를 완성해 주세요. 개수는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `records`의 길이 ≤ 500,000
- -1,000,000 ≤ `records`의 원소 ≤ 1,000,000
- -1,000,000,000 ≤ `target` ≤ 1,000,000,000

## 입출력 예

| records | target | result |
|---|---|---|
| [3, -1, 4, -1, 2] | 3 | 3 |
| [0, 0, 0] | 0 | 6 |
| [5, -5, 5, -5] | 5 | 3 |

## 입출력 예 설명
- 예 #1: 합이 3인 기간은 `[3]`, `[-1, 4]`, `[4, -1]` 세 개입니다.
- 예 #2: 어떤 기간을 잡아도 합이 0입니다. 길이 1인 기간 3개, 길이 2인 기간 2개, 길이 3인 기간 1개로 모두 6개입니다.
- 예 #3: `[5]`(0번 날), `[5]`(2번 날), `[5, -5, 5]` 세 개입니다.
