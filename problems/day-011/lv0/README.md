# [lv0] 가장 더운 날과 추운 날

어느 도시의 하루 최고 기온을 여러 날 동안 기록한 배열 `temps`가 주어집니다. `temps[i]`는 `i`번째 날(0번부터 셈)의 기온입니다.

가장 기온이 높았던 날의 번호와 가장 기온이 낮았던 날의 번호를 `[가장 더운 날, 가장 추운 날]` 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 같은 기온인 날이 여러 개면 **가장 앞선 날**의 번호를 사용합니다.

## 제한사항
- 1 ≤ `temps`의 길이 ≤ 1,000,000
- -50 ≤ `temps`의 원소 ≤ 50 (영하 기온은 음수입니다)

## 입출력 예

| temps | result |
|---|---|
| [3, 8, -2, 8, -2] | [1, 2] |
| [-9, -1, -5] | [1, 0] |
| [7] | [0, 0] |

## 입출력 예 설명
- 예 #1: 최고 기온 8은 1번과 3번 날에 나오므로 앞선 1번, 최저 기온 -2는 2번과 4번 날에 나오므로 앞선 2번입니다.
- 예 #2: 모두 영하입니다. 가장 높은 -1은 1번 날, 가장 낮은 -9는 0번 날입니다.
- 예 #3: 하루뿐이면 그날이 가장 덥고 가장 춥습니다.
