# 해설 — 가장 더운 날과 추운 날

## 접근
최댓값의 **위치**를 찾는 문제입니다. 0번 날을 답의 초깃값으로 두고 1번 날부터 끝까지 보며, 지금까지의 최고 기온보다 **더 클 때만** 더운 날 번호를 바꿉니다. 추운 날도 같은 방식으로 **더 작을 때만** 바꿉니다. 한 번의 반복에서 두 값을 함께 갱신하면 됩니다.

## 주의할 점
- 최댓값의 초깃값을 0으로 두면 모두 영하인 날(예 #2)에서 틀립니다. 배열의 첫 원소를 초깃값으로 쓰세요.
- `>=`로 비교하면 같은 기온이 나올 때마다 번호가 뒤로 밀려 "가장 앞선 날"이 아니게 됩니다.
- 답은 기온이 아니라 **날 번호(인덱스)**입니다.

## 복잡도
- 시간 O(n), 공간 O(1)
