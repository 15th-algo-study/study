# 해설 — 조약돌 r개 고르기

## 접근
조약돌이 최대 20개이므로 고르는 방법(부분집합)은 2^20 ≈ 105만 가지입니다. 질문마다 부분집합을 다시 세면 105만 × 20만으로 시간 초과이므로, 부분집합을 **한 번만** 전부 열거하면서 `(개수, 합)`별 가짓수 표를 만들어 둡니다.

1. `mask`를 1부터 2^n − 1까지 돌립니다. `mask`의 합은 매번 20개 비트를 다시 더하지 않고, **가장 낮은 비트 하나를 뺀 부분집합**의 합에 그 비트의 무게를 더해 O(1)에 구합니다.
   - `low = Integer.numberOfTrailingZeros(mask)`, `sum[mask] = sum[mask & (mask - 1)] + weights[low]`
   - `mask & (mask - 1)`은 `mask`보다 작으므로 이미 계산되어 있습니다.
2. 개수는 `Integer.bitCount(mask)`입니다. `count[개수][합]++`.
3. 질문 `[r, t]`의 답은 `count[r][t]`입니다 (`r > n` 또는 `t > 전체 합`이면 0).

## 주의할 점
- 조약돌은 무게가 같아도 서로 다른 돌이므로 값이 아니라 **인덱스의 부분집합**을 셉니다(예 #2).
- `mask = 0`(아무것도 안 고름)은 `count[0][0] = 1`로 따로 넣습니다.
- 가짓수의 최댓값은 C(20, 10) = 184,756이라 `int`로 충분합니다.
- 질문의 `r`, `t`가 표 범위를 벗어날 수 있으니 조회 전에 범위를 확인합니다.

## 복잡도
- 시간 O(2^n + m) (m = 질문 수), 공간 O(2^n + n · S) (S = 무게 합 ≤ 2,000)
