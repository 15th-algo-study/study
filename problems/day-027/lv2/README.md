# [lv2] 조약돌 r개 고르기

강가에서 주운 조약돌 `n`개의 무게가 배열 `weights`에 들어 있습니다. 조약돌은 모두 서로 다른 돌이므로 무게가 같아도 구별합니다.

동생이 다음과 같은 질문을 여러 번 합니다.

- `[r, t]`: 조약돌을 **정확히 `r`개** 골라서 무게 합이 **정확히 `t`**가 되게 하는 방법은 몇 가지인가요?

`weights`와 질문 목록 `queries`가 주어질 때, 각 질문의 답을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `weights`의 길이 `n` ≤ 20
- 1 ≤ `weights`의 원소 ≤ 100
- 1 ≤ `queries`의 길이 ≤ 200,000
- `queries`의 각 원소는 `[r, t]` 형태이며 0 ≤ `r` ≤ 20, 0 ≤ `t` ≤ 2,000 입니다.
- `r = 0`, `t = 0`이면 아무것도 고르지 않는 1가지 방법이 있습니다. `r`이 `n`보다 크면 0가지입니다.

## 입출력 예

| weights | queries | result |
|---|---|---|
| [1, 2, 3] | [[2, 3], [1, 3], [3, 6], [0, 0], [2, 10]] | [1, 1, 1, 1, 0] |
| [5, 5, 5, 5] | [[2, 10], [3, 15], [1, 5], [4, 20], [2, 5]] | [6, 4, 4, 1, 0] |

## 입출력 예 설명
- 예 #1: 2개 골라 합 3은 {1, 2} 한 가지, 1개 골라 합 3은 {3} 한 가지, 3개 골라 합 6은 전부 고르는 한 가지, 0개 골라 합 0은 한 가지, 2개 골라 합 10은 없습니다.
- 예 #2: 무게가 모두 5라 어떤 2개를 골라도 합이 10입니다. 서로 다른 돌이므로 2개 고르는 방법은 6가지, 3개는 4가지, 1개는 4가지, 4개는 1가지입니다. 2개 골라 합 5는 불가능합니다.
