# 해설 — 유치원 행진 줄 세우기

## 접근
아이가 최대 9명이라 줄은 9! = 362,880가지입니다. 어떤 줄이 기준 `limit`에서 허용되는지는 그 줄의 **이웃 키 차이의 최댓값 `d`가 `limit` 이하인지**로 결정됩니다. 그러므로

1. 재귀로 모든 순열을 만들며 각 줄의 `d`를 구해 `count[d]++` 합니다 (`d ≤ 999`).
2. `prefix[x] = count[0] + … + count[x]`를 만들어 두면, 기준 `limit`의 답은 `prefix[limit]`입니다.

순열 열거는 한 번만 하고 기준 20만 개는 표 조회로 끝냅니다.

## 주의할 점
- 기준마다 순열을 다시 열거하면 362,880 × 9 × 200,000번 연산으로 시간 초과입니다.
- 아이들은 키가 같아도 **서로 다른 사람**이므로 인덱스의 순열을 세야 합니다. 값이 같다고 중복 제거하면 안 됩니다(예 #2).
- `n = 1`이면 이웃이 없으므로 `d = 0`으로 두어 모든 기준에서 1가지가 되게 합니다.
- 9! = 362,880은 `int` 범위이며, 줄 수의 최댓값이기도 합니다.

## 복잡도
- 시간 O(n! · n + m) (m = 기준 수), 공간 O(n + 1000)
