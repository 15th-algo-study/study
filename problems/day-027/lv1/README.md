# [lv1] 유치원 행진 줄 세우기

유치원 행진에 아이 `n`명이 참가합니다. 아이들의 키가 배열 `heights`에 들어 있고, 아이들은 서로 다른 사람이므로 키가 같아도 구별합니다.

아이들을 한 줄로 세우면 `n!`가지 줄이 나옵니다. 선생님은 안전을 위해 **이웃한 두 아이의 키 차이가 모두 `limit` 이하**인 줄만 허용하려고 합니다. 기준 `limit`의 후보가 여러 개 있어서, 후보마다 허용되는 줄이 몇 가지인지 알고 싶습니다.

`heights`와 기준 후보 배열 `limits`가 주어질 때, 각 후보에 대해 허용되는 줄 세우기 방법의 수를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `heights`의 길이 `n` ≤ 9
- 1 ≤ `heights`의 원소 ≤ 1,000
- 1 ≤ `limits`의 길이 ≤ 200,000
- 0 ≤ `limits`의 원소 ≤ 1,000
- 아이가 한 명이면 이웃이 없으므로 어떤 기준에서도 줄은 1가지입니다.

## 입출력 예

| heights | limits | result |
|---|---|---|
| [10, 20, 40] | [10, 20, 30] | [0, 2, 6] |
| [5, 5] | [0] | [2] |
| [100] | [0, 999] | [1, 1] |

## 입출력 예 설명
- 예 #1: 여섯 가지 줄의 "이웃 키 차이의 최댓값"은 `10,20,40`→20, `10,40,20`→30, `20,10,40`→30, `20,40,10`→30, `40,10,20`→30, `40,20,10`→20 입니다. 기준 10이면 0가지, 20이면 2가지, 30이면 6가지입니다.
- 예 #2: 키가 같은 두 아이도 서로 다른 아이이므로 줄은 2가지이고, 차이가 0이라 기준 0에서도 허용됩니다.
- 예 #3: 아이가 한 명이면 줄은 1가지입니다.
