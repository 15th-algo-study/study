# [lv0] 사탕 똑같이 나눠 담기

사탕 `n`개를 봉지 여러 개에 **남김없이, 봉지마다 같은 개수씩** 나눠 담으려고 합니다. 봉지는 1개만 써도 되고(사탕 `n`개를 한 봉지에), 사탕을 1개씩 담아 `n`개의 봉지를 써도 됩니다.

사탕 개수 `n`이 주어질 때, **봉지 하나에 담는 사탕 개수**로 가능한 값을 모두 오름차순으로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 1,000,000,000,000 (10^12, `long`)
- 가능한 값은 `n`의 약수이며, 1과 `n`은 항상 포함됩니다.

## 입출력 예

| n | result |
|---|---|
| 12 | [1, 2, 3, 4, 6, 12] |
| 49 | [1, 7, 49] |
| 97 | [1, 97] |

## 입출력 예 설명
- 예 #1: 사탕 12개는 1개씩 12봉지, 2개씩 6봉지, 3개씩 4봉지, 4개씩 3봉지, 6개씩 2봉지, 12개를 1봉지로 나눌 수 있습니다.
- 예 #2: 49 = 7 × 7이므로 7은 한 번만 넣습니다.
- 예 #3: 97은 소수라 1개씩 또는 97개를 한 봉지에 담는 방법뿐입니다.
