# 해설 — 사탕 똑같이 나눠 담기

## 접근
봉지 하나에 `d`개씩 담을 수 있다는 것은 `n % d == 0`, 즉 `d`가 `n`의 약수라는 뜻입니다. 그런데 `n`이 10^12까지라 1부터 `n`까지 모두 나눠 보면 1초 안에 끝나지 않습니다.

약수는 **짝**으로 나타납니다. `d`가 약수이면 `n / d`도 약수이고, 둘 중 하나는 반드시 `√n` 이하입니다. 그러므로 `i * i ≤ n`인 `i`(최대 10^6개)만 검사하면서

- `n % i == 0`이면 `i`를 "작은 약수" 목록에, `n / i`를 "큰 약수" 목록에 넣습니다.
- `i == n / i`(완전제곱수)이면 같은 수이므로 한 번만 넣습니다.

작은 약수는 오름차순으로 쌓이고 큰 약수는 내림차순으로 쌓이므로, 작은 목록 뒤에 큰 목록을 **뒤집어** 이어 붙이면 정렬된 답이 됩니다.

## 주의할 점
- `n`은 `long`이므로 반복 변수 `i`도 `long`이어야 `i * i`가 넘치지 않습니다. `int i`로 두면 `i * i`가 약 2.1×10^9를 넘는 순간 음수가 되어 무한 루프에 빠질 수 있습니다.
- `Math.sqrt`로 상한을 잡으면 실수 오차로 경계가 어긋날 수 있으니 `i * i <= n` 조건이 안전합니다.
- `n = 1`이면 답은 `[1]`입니다.

## 복잡도
- 시간 O(√n), 공간 O(약수 개수)
