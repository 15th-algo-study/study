# [lv3] 같은 색이 이웃하지 않는 깃발 배열

운동회 장식용 깃발 `n`개가 있습니다. 깃발의 색은 문자열 `flags`로 주어지며, `i`번째 문자가 `i`번째 깃발의 색입니다. 색은 `'a'`, `'b'`, `'c'`, `'d'` 네 가지 중 하나입니다.

깃발을 **모두** 사용해 한 줄로 걸려고 하는데, 보기 좋게 **같은 색 깃발이 이웃하지 않아야** 합니다. 같은 색 깃발은 서로 구별하지 않으므로, 두 배열은 각 자리의 색이 모두 같을 때 같은 배열로 봅니다.

`flags`가 주어질 때, 조건을 만족하는 **서로 다른 배열의 수**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `flags`의 길이 `n` ≤ 14
- `flags`는 `'a'`~`'d'`로만 이루어져 있습니다.
- `flags`에 주어진 순서는 아무 의미가 없습니다(깃발은 자유롭게 섞어 걸 수 있습니다).

## 입출력 예

| flags | result |
|---|---|
| "aab" | 1 |
| "aabbc" | 12 |
| "aaab" | 0 |

## 입출력 예 설명
- 예 #1: 색 배열로는 `aab`, `aba`, `baa` 세 가지가 가능하지만 같은 색이 이웃하지 않는 것은 `aba` 하나입니다.
- 예 #2: 색 배열은 모두 30가지이고, 그중 `a`끼리 또는 `b`끼리 이웃한 것을 빼면 12가지가 남습니다. (예: `ababc`, `abcab`, `cabab`, …)
- 예 #3: `a` 세 개를 떼어 놓으려면 사이에 다른 깃발이 두 개 필요한데 `b`는 하나뿐이라 불가능합니다.
