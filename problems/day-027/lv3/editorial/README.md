# 해설 — 같은 색이 이웃하지 않는 깃발 배열

## 접근
깃발 14개를 "서로 다른 물건"으로 보고 자리에 하나씩 놓는 순열을 모두 만들면 14! ≈ 8.7×10^10가지라 불가능합니다. 게다가 같은 색은 구별하지 않으므로 똑같은 색 배열이 수없이 중복 생성됩니다.

핵심 관찰: **깃발 하나하나가 아니라 "색"을 고르면 됩니다.**

- 색별로 남은 개수 `remain[c]`를 셉니다 (최대 4가지 색).
- 자리를 앞에서부터 채우며, 각 자리에서 "남은 개수가 1 이상이고 **바로 앞 자리의 색과 다른** 색"을 하나 고릅니다. 고른 색의 `remain`을 1 줄이고 다음 자리로 갑니다.
- `n`개를 모두 놓으면 배열 하나가 완성된 것이므로 1을 셉니다.

이렇게 하면 같은 색 배열은 정확히 한 번씩만 만들어지고(중복 없음), 같은 색이 이웃하는 배열은 처음부터 만들지 않으므로(가지치기) 탐색 노드 수가 "조건을 만족하는 접두사"의 수로 줄어듭니다. 색이 4가지, 길이 14일 때 수백만 노드 수준이라 충분히 빠릅니다.

같은 상태(`remain` 배열, 마지막 색)에서의 결과는 항상 같으므로 메모이제이션을 더하면 더 빨라지지만, 이 문제의 제한에서는 없어도 통과합니다.

## 주의할 점
- "인덱스 순열 + 집합으로 중복 제거"는 14!개를 전부 만들어야 하므로 시간·메모리 모두 불가능합니다.
- 색이 한 가지뿐이고 `n ≥ 2`이면 답은 0, `n = 1`이면 1입니다. 위 탐색은 이 경우도 자연스럽게 처리합니다.
- 답의 최댓값은 14개를 4가지 색으로 배열하는 경우의 수 이하(14!/(4!4!3!3!) = 4,204,200)라 `int` 범위입니다.

## 복잡도
- 시간 O(조건을 만족하는 접두사의 수 × 색의 수), 공간 O(n) (재귀 깊이)
