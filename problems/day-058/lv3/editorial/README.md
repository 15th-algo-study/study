# 해설 — 숲길과 도끼 한 자루

## 접근
"어느 나무를 벨지"를 하나씩 정해 두고 BFS 를 돌리면 나무 수 × 격자 크기 = (3×10^6)² 급이라 불가능합니다. **관찰**: 같은 칸에 있어도 "도끼를 아직 안 썼는지 / 이미 썼는지"에 따라 앞으로 갈 수 있는 길이 다릅니다. 그러므로 BFS 의 정점을 `(칸, 도끼 사용 여부)`로 잡아야 합니다. 정점 수는 격자 칸 수의 2배뿐이고 간선 길이는 모두 1이므로 BFS 한 번이면 됩니다.

상태 `(r, c, used)`에서 이웃 칸 `(nr, nc)`로 가는 규칙:
- 이웃이 빈 땅(`.`, `S`, `T`)이면 `(nr, nc, used)`로 이동.
- 이웃이 나무(`#`)이고 `used == 0`이면 `(nr, nc, 1)`로 이동 (나무를 벤다).
- 이웃이 나무이고 이미 `used == 1`이면 갈 수 없음.

`dist[used][칸]`을 -1로 초기화하고 처음 도착했을 때만 거리를 적습니다. 목표 칸에 `used = 0` 또는 `used = 1`로 처음 도착하는 순간의 거리가 답입니다 (BFS 는 거리 순으로 방문하므로 둘 중 먼저 나온 것이 최솟값).

## 주의할 점
- 방문 표시를 **칸 단위**로만 하면 틀립니다. 도끼를 쓴 채로 먼저 도착한 칸에, 나중에 도끼를 아끼고 도착하는 경로가 막혀 버립니다. 반드시 상태 단위 `(칸, used)`로 표시하세요.
- 격자가 최대 300만 칸, 상태는 600만 개입니다. 큐는 `int[]` 배열(크기 600만)에 `used * (rows*cols) + r*cols + c` 로 묶어 넣으면 메모리와 시간이 모두 여유 있습니다. 객체 큐에 `int[]` 세 개짜리를 넣으면 메모리가 수백 MB 로 불어납니다.
- `S`와 `T`는 빈 땅으로 취급합니다.
- 재귀로 격자를 탐색하면 깊이가 수백만이 되어 스택이 넘칩니다. 반복문 BFS 로 작성하세요.

## 복잡도
- 시간 O(2 × rows × cols), 공간 O(2 × rows × cols)
