# [lv3] 숲길과 도끼 한 자루

숲을 격자 모양의 지도 `forest`로 나타냈습니다. `forest[r]`의 `c`번째 문자가 (r, c) 칸이며, 각 문자의 뜻은 다음과 같습니다.

- `S`: 나무꾼이 서 있는 출발 칸 (정확히 하나)
- `T`: 오두막이 있는 목표 칸 (정확히 하나)
- `.`: 지나갈 수 있는 빈 땅
- `#`: 나무가 서 있어 지나갈 수 없는 칸

나무꾼은 한 번에 상하좌우로 붙어 있는 한 칸으로 움직이며, 지도 밖으로는 나갈 수 없습니다. 나무꾼은 도끼를 한 자루 가지고 있어 **전체 여정에서 최대 한 번** 나무 칸으로 들어가며 그 나무를 벨 수 있습니다. 나무를 베고 들어가는 것도 한 번의 이동으로 셉니다. 벤 나무 칸은 그 뒤로 빈 땅과 같습니다.

출발 칸에서 목표 칸까지 가는 **최소 이동 횟수**를 return 하도록 `solution` 함수를 완성해 주세요. 나무를 한 그루 베더라도 도달할 수 없으면 -1을 return 합니다.

## 제한사항
- 1 ≤ `forest`의 길이 ≤ 2,000
- 1 ≤ 각 `forest[r]`의 길이 ≤ 1,500
- 모든 줄의 길이는 같습니다.
- `forest`는 `S`, `T`, `.`, `#`로만 이루어지며 `S`와 `T`는 각각 정확히 한 번 나옵니다.

## 입출력 예

| forest | result |
|---|---|
| ["S#T"] | 2 |
| ["S##T"] | -1 |
| ["S.#", "###", "..T"] | 4 |

## 입출력 예 설명
- 예 #1: 가운데 나무를 베고 지나가면 두 번 만에 도착합니다.
- 예 #2: 나무가 두 그루 연달아 있어 한 그루만 베서는 지나갈 수 없습니다.
- 예 #3: (0,0) → (0,1) → (1,1)의 나무를 베고 진입 → (2,1) → (2,2). 4번입니다. (1,0)의 나무를 베는 경로도 4번입니다.
