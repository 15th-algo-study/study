# 해설 — 얼음판 위의 펭귄

## 접근
현재 위치 `(r, c)`를 변수로 들고 명령을 한 글자씩 처리합니다. 명령 문자를 **방향 번호**로 바꾸고, 방향 배열 `dr`, `dc`로 다음 위치를 계산한 뒤, 범위 안일 때만 이동합니다.

```java
String dirs = "UDLR";
int[] dr = {-1, 1, 0, 0};
int[] dc = {0, 0, -1, 1};
int d = dirs.indexOf(ch);          // 'U' → 0, 'D' → 1, 'L' → 2, 'R' → 3
int nr = r + dr[d], nc = c + dc[d];
if (0 <= nr && nr < n && 0 <= nc && nc < m) { r = nr; c = nc; }
```

`switch`문으로 네 경우를 나눠 써도 되지만, 방향 배열을 쓰면 "이동 후보 계산"과 "범위 확인"이 한 곳에 모여 네 방향 모두 같은 코드로 처리됩니다.

## 주의할 점
- 범위를 벗어나는 명령은 무시하고 **다음 명령을 계속** 처리해야 합니다. 반복문을 끝내면 안 됩니다.
- 명령이 최대 100만 개이므로 `moves.charAt(i)`를 반복문에서 쓰거나 `toCharArray()`로 바꿔 쓰면 됩니다. 문자열을 `substring`으로 잘라 가며 처리하면 O(n²)이 됩니다.
- 빈 문자열이면 `[0, 0]`입니다.

## 복잡도
- 시간 O(|moves|), 공간 O(1)
