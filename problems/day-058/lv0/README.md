# [lv0] 얼음판 위의 펭귄

세로 `n`칸, 가로 `m`칸인 직사각형 얼음판이 있습니다. 칸의 위치는 (줄, 칸)으로 나타내며 맨 위 왼쪽 칸이 (0, 0), 맨 아래 오른쪽 칸이 (`n`-1, `m`-1)입니다. 펭귄은 처음에 (0, 0)에 서 있습니다.

이동 명령 문자열 `moves`가 주어집니다. 각 문자는 다음 뜻입니다.

- `U`: 한 줄 위로 (줄 번호 -1)
- `D`: 한 줄 아래로 (줄 번호 +1)
- `L`: 한 칸 왼쪽으로 (칸 번호 -1)
- `R`: 한 칸 오른쪽으로 (칸 번호 +1)

명령대로 움직이면 얼음판 밖으로 나가게 되는 경우, 그 명령은 **무시**하고 제자리에 있습니다. 모든 명령을 처리한 뒤 펭귄의 위치를 `[줄, 칸]` 배열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n`, `m` ≤ 1,000
- 0 ≤ `moves`의 길이 ≤ 1,000,000
- `moves`는 `U`, `D`, `L`, `R`로만 이루어집니다.

## 입출력 예

| n | m | moves | result |
|---|---|---|---|
| 3 | 3 | "RRDDLU" | [1, 1] |
| 1 | 4 | "RRRRRU" | [0, 3] |
| 2 | 2 | "" | [0, 0] |

## 입출력 예 설명
- 예 #1: (0,0) → R (0,1) → R (0,2) → D (1,2) → D (2,2) → L (2,1) → U (1,1).
- 예 #2: 오른쪽으로 세 번 움직여 (0,3)에 닿은 뒤의 `R` 두 번과 `U`는 밖으로 나가는 명령이라 무시합니다.
- 예 #3: 명령이 없으면 처음 위치 그대로입니다.
