# 해설 — 소문이 퍼지는 날

## 접근
"`d`일째에 처음 듣는다" = `start`로부터의 **최단 거리가 `d`** 라는 뜻입니다. 간선 길이가 모두 1이므로 **BFS 한 번**으로 모든 사람의 최단 거리를 구해 두고, 질문마다 배열에서 꺼내기만 하면 됩니다.

1. 인접 리스트를 만듭니다 (양방향).
2. `dist` 배열을 -1로 채우고 `dist[start] = 0`, `start`를 큐에 넣습니다.
3. 큐에서 꺼낸 정점 `v`의 이웃 `u` 중 `dist[u] == -1`인 것은 `dist[u] = dist[v] + 1`로 적고 큐에 넣습니다.
4. `people[i]`마다 `dist[people[i]]`를 답으로 씁니다 (닿지 않았으면 -1 그대로).

BFS 는 큐에 "거리 d 인 정점들 → 거리 d+1 인 정점들" 순서로 들어가므로, 어떤 정점을 **처음 발견했을 때**의 거리가 최단 거리입니다. 나중에 다른 경로로 다시 만나도 더 짧을 수 없으니 갱신할 필요가 없습니다.

## 주의할 점
- 질문마다 `start`에서 그 사람까지 BFS 를 새로 돌리면 O(q × (n + m)) ≈ 10^11 로 시간 초과입니다. 출발점이 같으므로 **한 번의 BFS 결과를 모든 질문이 공유**합니다.
- "날마다 `friends` 전체를 훑어 새로 듣는 사람을 찾는" 방식은 O(날짜 수 × m)입니다. 친구 관계가 한 줄로 길게 이어지면 날짜 수가 n 에 가까워져 시간 초과입니다. BFS 는 간선을 양쪽으로 한 번씩만 봅니다.
- 중복 쌍과 `a = b`는 방문 표시 덕분에 영향이 없습니다.
- 재귀 DFS 로는 최단 거리를 구할 수 없고, 깊은 재귀의 위험도 있습니다. 큐를 쓰세요.

## 복잡도
- 시간 O(n + m + q), 공간 O(n + m)
