# [lv2] 소문이 퍼지는 날

마을 사람 `n`명에게 0번부터 `n-1`번까지 번호를 붙였습니다. 서로 친한 사람 쌍의 목록이 2차원 배열 `friends`로 주어집니다. `friends[i] = [a, b]`는 `a`번과 `b`번이 친하다는 뜻이고, 친한 관계는 양방향입니다.

0일째에 `start`번 사람이 소문을 알게 되었습니다. 소문을 아는 사람은 **다음 날** 자기와 친한 모든 사람에게 소문을 전합니다. 즉 `d`일째에 소문을 처음 들은 사람의 친구들은 늦어도 `d+1`일째에는 소문을 알게 됩니다. 이미 소문을 아는 사람이 다시 들어도 달라지는 것은 없습니다.

궁금한 사람들의 번호 목록 `people`이 주어질 때, 각 사람이 **소문을 처음 듣는 날**을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. `start` 본인은 0일째이고, 소문이 끝내 닿지 않는 사람은 -1입니다.

## 제한사항
- 1 ≤ `n` ≤ 200,000
- 0 ≤ `friends`의 길이 ≤ 400,000
- 1 ≤ `people`의 길이 ≤ 200,000
- 0 ≤ `a`, `b`, `start`, `people[i]` < `n`
- 같은 쌍이 여러 번 나오거나 `a = b`인 쌍이 있을 수 있습니다. `people`에는 같은 번호가 여러 번 나올 수 있습니다.

## 입출력 예

| n | friends | start | people | result |
|---|---|---|---|---|
| 6 | [[0, 1], [0, 2], [1, 3], [2, 3], [3, 4]] | 0 | [4, 3, 0, 5] | [3, 2, 0, -1] |
| 3 | [] | 2 | [2, 0] | [0, -1] |
| 4 | [[0, 1], [1, 2], [2, 3], [3, 0]] | 1 | [3, 0, 2] | [2, 1, 1] |

## 입출력 예 설명
- 예 #1: 0일째 {0}, 1일째 {1, 2}, 2일째 {3}, 3일째 {4}. 5번은 친구가 없어 소문을 듣지 못합니다.
- 예 #2: 친구 관계가 없으므로 `start`만 소문을 압니다.
- 예 #3: 1일째에 0번과 2번이, 2일째에 3번이 듣습니다.
