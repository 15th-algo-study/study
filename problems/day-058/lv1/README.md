# [lv1] 픽셀 아트 페인트 통

픽셀 아트 편집기의 캔버스가 문자열 배열 `canvas`로 주어집니다. `canvas[r]`의 `c`번째 문자가 (r, c) 픽셀의 색이며, 색은 영문 소문자 한 글자로 표현됩니다.

페인트 통 도구로 (`r`, `c`) 픽셀을 클릭하면, 그 픽셀과 **같은 색이면서 상하좌우로 연이어 붙어 있는** 픽셀들이 모두 새 색으로 한꺼번에 바뀝니다. 대각선으로만 닿은 픽셀은 이어진 것으로 보지 않습니다.

(`r`, `c`)를 클릭했을 때 **색이 바뀌는 픽셀의 수**(클릭한 픽셀 포함)를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `canvas`의 길이 ≤ 2,000
- 1 ≤ 각 `canvas[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같습니다.
- `canvas`는 영문 소문자로만 이루어집니다.
- 0 ≤ `r` < `canvas`의 길이, 0 ≤ `c` < 각 줄의 길이

## 입출력 예

| canvas | r | c | result |
|---|---|---|---|
| ["aab", "abb", "ccb"] | 0 | 0 | 3 |
| ["aab", "abb", "ccb"] | 2 | 2 | 4 |
| ["xyx"] | 0 | 1 | 1 |

## 입출력 예 설명
- 예 #1: (0,0)의 색 `a`와 이어진 픽셀은 (0,0), (0,1), (1,0)의 세 개입니다.
- 예 #2: (2,2)의 색 `b`와 이어진 픽셀은 (2,2), (1,2), (1,1), (0,2)의 네 개입니다.
- 예 #3: (0,1)의 `y`는 이웃이 모두 다른 색이라 자기 자신만 바뀝니다.
