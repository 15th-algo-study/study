# [lv0] 느린 재귀 함수 고치기

친구가 다음과 같은 재귀 함수를 만들었습니다.

```java
int calc(int n) {
    if (n <= 1) return 1;
    return (calc(n - 1) + calc(n / 2)) % 1_000_000_007;
}
```

이 함수는 `n`이 조금만 커져도 같은 값을 셀 수 없이 다시 계산하느라 결과가 나오지 않습니다. 정수 `n`이 주어질 때, 이 함수의 결과 `calc(n)`과 같은 값을 빠르게 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 100,000
- `/`는 자바의 정수 나눗셈(몫)입니다. 예를 들어 `5 / 2`는 2입니다.

## 입출력 예

| n | result |
|---|---|
| 5 | 7 |
| 10 | 30 |
| 1 | 1 |

## 입출력 예 설명
- 예 #1: calc(2) = calc(1) + calc(1) = 2, calc(3) = calc(2) + calc(1) = 3, calc(4) = calc(3) + calc(2) = 5, calc(5) = calc(4) + calc(2) = 7입니다.
- 예 #2: 이어서 calc(6) = 7 + 3 = 10, calc(7) = 10 + 3 = 13, calc(8) = 13 + 5 = 18, calc(9) = 18 + 5 = 23, calc(10) = 23 + 7 = 30입니다.
- 예 #3: `n <= 1`이면 바로 1입니다.
