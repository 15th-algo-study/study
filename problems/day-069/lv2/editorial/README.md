# 해설 — 주사위 보드게임 완주 확률

## 접근
주사위를 굴리는 모든 경우를 나열하면 k^(굴린 횟수)가지라 불가능합니다. 대신 **각 칸에 말이 멈춰 설 확률**을 앞에서부터 채웁니다.

### 1. 칸에 도착하면 최종적으로 어디에 멈추는가
미끄럼 칸이 이어질 수 있으므로, `stop[i]` = "i번 칸에 도착했을 때 최종적으로 멈추는 칸(지면 -1)"을 **뒤에서부터** 구해 둡니다.
- `.`이면 `stop[i] = i`
- `X`이면 `stop[i] = -1`
- 숫자 d이면 `i + d > n`일 때 -1, 아니면 `stop[i + d]` (이미 구해 둔 값)

### 2. 멈춰 설 확률
`prob[i]` = 말이 i번 칸에 멈춰 서는 확률이라고 하면 `prob[0] = 1`입니다. 앞에서부터 i번 칸의 확률을 다음 칸들로 나눠 보냅니다.

- 눈 d(1 ≤ d ≤ k)마다 `i + d ≤ n`이고 `stop[i + d] = s ≥ 0`이면 `prob[s] += prob[i] / k`

말은 항상 앞으로만 움직이므로(`s > i`), i번 칸 차례가 왔을 때 `prob[i]`는 이미 다 모여 있습니다. 답은 `prob[n]`입니다. 미끄럼·함정 칸에는 말이 멈춰 서지 않으므로 그 칸의 `prob`는 0으로 남습니다.

## 주의할 점
- `n`번 칸에 도착하면 게임이 끝나므로 `n`번 칸에서 다시 굴리지 않습니다(반복을 `i < n`까지만).
- 미끄럼 칸을 처리할 때마다 사슬을 따라가면 같은 사슬을 여러 번 따라가게 됩니다. `stop` 배열에 적어 두면 한 번에 끝납니다.
- 확률은 `double`로 계산합니다. 덧셈만 하므로 오차는 문제 되지 않습니다.

## 복잡도
- 시간 O(n·k), 공간 O(n)
