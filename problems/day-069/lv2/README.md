# [lv2] 주사위 보드게임 완주 확률

보드게임 판이 문자열 `board`로 주어집니다. 칸은 0번부터 `n`번까지 `n + 1`개이고(`n`은 `board`의 길이 - 1), `board`의 `i`번째 문자가 `i`번 칸의 종류입니다.

- `.` : 평범한 칸
- `X` : 함정 칸. 말이 이 칸에 도착하면 게임에서 집니다.
- `1`~`9` : 미끄럼 칸. 말이 이 칸에 도착하면 적힌 수만큼 즉시 앞으로 미끄러집니다. 미끄러져 도착한 칸이 함정이나 미끄럼 칸이면 그 칸의 규칙도 그대로 따릅니다.

말은 0번 칸에서 출발합니다. 매 차례 1부터 `k`까지의 눈이 같은 확률로 나오는 주사위를 굴려, 나온 눈만큼 앞으로 갑니다. 말이 **정확히 `n`번 칸**에 멈추면 완주입니다. `n`번 칸을 지나쳐 판 밖으로 나가면(미끄러져 나가는 경우도 포함) 집니다.

완주할 확률을 return 하도록 `solution` 함수를 완성해 주세요. 정답과의 차이가 10^-6 이하이면 맞은 것으로 봅니다.

## 제한사항
- 2 ≤ `board`의 길이 ≤ 200,001
- `board`는 `.`, `X`, `1`~`9`로만 이루어져 있습니다.
- `board`의 첫 글자(0번 칸)와 마지막 글자(`n`번 칸)는 `.`입니다.
- 1 ≤ `k` ≤ 100

## 입출력 예

| board | k | result |
|---|---|---|
| "..." | 2 | 0.75 |
| ".2X.." | 2 | 0.25 |
| "...." | 6 | 0.22685185185185186 |

## 입출력 예 설명
- 예 #1: 첫 차례에 2가 나오면(1/2) 바로 2번 칸에 도착합니다. 1이 나오면 1번 칸에서 다시 굴려 1이 나와야(1/2) 완주합니다. 1/2 + 1/2 × 1/2 = 0.75입니다.
- 예 #2: 1이 나오면 1번 칸에서 2칸 미끄러져 3번 칸에 멈추고, 2가 나오면 함정입니다. 3번 칸에서 1이 나오면 완주, 2가 나오면 판 밖입니다. 1/2 × 1/2 = 0.25입니다.
- 예 #3: 3을 바로 내거나(1/6), 1·2 또는 2·1을 내거나(2/36), 1·1·1을 내면(1/216) 완주합니다. 합하면 49/216입니다.
