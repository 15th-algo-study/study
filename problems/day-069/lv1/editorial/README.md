# 해설 — 열기구 최대 상승 구간

## 접근
모든 (시작, 끝) 쌍을 보면 구간이 약 n²/2 = 200억 개라 시간 초과입니다.

`ending[i]` = "**i번째 분에서 끝나는** 구간들 중 합의 최댓값"을 생각합니다. i에서 끝나는 구간은

- i 한 칸짜리 구간: `changes[i]`
- i-1에서 끝나는 구간 뒤에 i를 붙인 것: `ending[i-1] + changes[i]`

둘 중 하나이므로 `ending[i] = max(changes[i], ending[i-1] + changes[i])`입니다. 앞 구간의 합이 음수면 이어 붙이는 것이 손해이니 새로 시작한다는 뜻입니다. 답은 모든 `ending[i]` 중 최댓값입니다. 직전 값만 쓰므로 변수 하나로 충분합니다.

## 주의할 점
- 답을 0으로 시작하면 모든 값이 음수일 때(예 #2) 틀립니다. 구간은 비어 있을 수 없으므로 첫 원소나 `Long.MIN_VALUE`로 시작하세요.
- 합은 최대 2 × 10^14이므로 `long`으로 누적합니다. `int`끼리 더한 뒤 `long`에 넣으면 이미 넘친 값이 들어갑니다.

## 복잡도
- 시간 O(n), 공간 O(1)
