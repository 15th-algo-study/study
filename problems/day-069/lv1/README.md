# [lv1] 열기구 최대 상승 구간

열기구가 `n`분 동안 비행한 기록이 있습니다. `changes[i]`는 `i`번째 1분 동안의 고도 변화량(미터)으로, 양수면 올라가고 음수면 내려간 것입니다.

연속한 1분 이상의 구간을 하나 골라, 그 구간 동안의 고도 변화량의 합이 가장 큰 값을 return 하도록 `solution` 함수를 완성해 주세요. 모든 변화량이 음수여도 구간은 반드시 1분 이상이어야 합니다. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `changes`의 길이 ≤ 200,000
- -1,000,000,000 ≤ `changes[i]` ≤ 1,000,000,000

## 입출력 예

| changes | result |
|---|---|
| [3, -5, 4, -1, 3, -6, 5] | 6 |
| [-4, -2, -7] | -2 |
| [1, 2, 3] | 6 |

## 입출력 예 설명
- 예 #1: 2번부터 4번까지 [4, -1, 3]의 합 6이 가장 큽니다. 중간에 1미터 내려가더라도 앞뒤가 이어지는 편이 이득입니다.
- 예 #2: 계속 내려가기만 했습니다. 가장 덜 내려간 1분(-2)이 답입니다.
- 예 #3: 전체 구간의 합 6입니다.
