# 해설 — 구슬 키링 무늬

## 접근
구슬을 고르는 방법은 2^n가지라, 무늬를 하나씩 만들어 집합에 넣어 중복을 없애는 방법은 구슬이 수십 개만 되어도 끝나지 않습니다.

**마지막 글자로 무늬를 나눕니다.** 구슬 줄을 앞에서부터 읽으며 `end[c]` = "지금까지 읽은 부분으로 만들 수 있는, 마지막 글자가 c인 서로 다른 무늬의 수"를 관리합니다.

새 구슬 c를 읽었을 때, 마지막 글자가 c인 무늬는 다음 둘로 빠짐없이, 겹치지 않게 나뉩니다.

1. c 한 글자
2. (지금까지 만들 수 있던, **c로 끝나지 않는** 무늬) 뒤에 c를 붙인 것

서로 다른 무늬 뒤에 c를 붙이면 결과도 서로 다르므로 개수는 `1 + Σ end[d] (d ≠ c)`입니다. 그리고 예전에 만들 수 있던 c로 끝나는 무늬는 모두 이 둘 중 하나로 다시 만들어지므로(**같은 무늬는 가장 최근의 c로 끝내면 됨**), `end[c]`를 이 값으로 **바꿔치기**하면 중복 없이 셀 수 있습니다.

```
updated = 1 + (total − end[c])
total   = total − end[c] + updated
end[c]  = updated
```

`total`은 `end`의 합을 함께 들고 다니는 값이며, 마지막 `total`이 답입니다. 글자마다 O(1)입니다.

## 주의할 점
- `end[c]`에 더하면 안 됩니다. 같은 무늬가 예전 c와 새 c로 두 번 세어집니다. "바꿔치기"가 중복을 없애는 핵심입니다.
- c로 끝나는 무늬 뒤에 c를 붙이면 같은 색이 이웃하므로 빼야 합니다. 그래서 `total`이 아니라 `total − end[c]`를 씁니다.
- 나머지 연산 중에 `total − end[c]`가 음수가 될 수 있으니 `+ MOD` 후 나머지를 구합니다.
- 위치 i에서 끝나는 무늬를 세기 위해 앞의 모든 위치를 훑는 O(n²) DP는 길이 50만에서 시간 초과입니다.

## 복잡도
- 시간 O(n), 공간 O(26)
