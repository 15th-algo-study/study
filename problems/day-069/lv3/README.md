# [lv3] 구슬 키링 무늬

구슬이 한 줄로 꿰어진 구슬 줄이 문자열 `beads`로 주어집니다. 각 문자는 구슬의 색(알파벳 소문자)입니다. 이 줄에서 구슬을 **1개 이상** 골라, 원래 순서를 그대로 유지한 채 새 줄에 옮겨 꿰어 키링을 만들려 합니다. 키링의 무늬는 꿴 구슬의 색을 차례로 읽은 문자열입니다.

단, 같은 색 구슬이 키링에서 바로 이웃하면 무늬가 뭉개져 보이므로 그런 키링은 만들지 않습니다.

만들 수 있는 **서로 다른 무늬**의 수를 1,000,000,007로 나눈 나머지를 return 하도록 `solution` 함수를 완성해 주세요. 고른 구슬의 위치가 달라도 무늬(문자열)가 같으면 한 가지로 셉니다.

## 제한사항
- 1 ≤ `beads`의 길이 ≤ 500,000
- `beads`는 알파벳 소문자로만 이루어져 있습니다.

## 입출력 예

| beads | result |
|---|---|
| "aba" | 5 |
| "aaa" | 1 |
| "abcb" | 11 |

## 입출력 예 설명
- 예 #1: a, b, ab, ba, aba의 5가지입니다. 첫째와 셋째 구슬로 만든 aa는 같은 색이 이웃해서 만들지 않습니다.
- 예 #2: 어떻게 골라도 a 하나짜리 무늬만 됩니다.
- 예 #3: a, b, c, ab, ac, bc, cb, abc, acb, bcb, abcb의 11가지입니다. ab는 둘째 구슬을 써도, 넷째 구슬을 써도 같은 무늬라 한 번만 셉니다.
