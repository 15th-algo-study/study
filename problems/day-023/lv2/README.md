# [lv2] 이삿짐 상자 중 가장 무거운 것

이삿짐 트럭에 상자를 한 줄로 **위로만** 쌓습니다. 상자는 맨 위에만 올릴 수 있고 맨 위 것만 내릴 수 있습니다. 작업 기록이 배열 `ops`로 주어집니다.

- 양수 `w`: 무게가 `w`인 상자를 맨 위에 올립니다.
- `0`: 맨 위 상자를 내립니다. 쌓인 상자가 없으면 아무 일도 일어나지 않습니다.
- `-1`: 지금 쌓여 있는 상자 중 **가장 무거운** 상자의 무게를 기록합니다. 쌓인 상자가 없으면 0을 기록합니다.

`-1`마다 기록한 값을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. `-1`이 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `ops`의 길이 ≤ 1,000,000
- `ops[i]`는 -1 이상 1,000,000,000 이하의 정수입니다.

## 입출력 예

| ops | result |
|---|---|
| [5, 3, -1, 8, -1, 0, -1, 0, 0, -1] | [5, 8, 5, 0] |
| [-1, 0, 2, -1] | [0, 2] |
| [4, 4, -1, 0, -1, 0, -1] | [4, 4, 0] |

## 입출력 예 설명
- 예 #1: [5, 3]에서 최대 5. 8을 올려 최대 8. 8을 내리면 다시 5. 모두 내리면 0.
- 예 #2: 빈 상태에서의 질의는 0, 빈 상태에서 내리기는 무시됩니다.
- 예 #3: 같은 무게 4가 두 개일 때 하나를 내려도 최대는 여전히 4입니다.
