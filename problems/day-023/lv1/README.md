# [lv1] 결재 서류 더미 뒤집기

책상 위에 결재 서류가 한 더미로 쌓여 있습니다. 서류 더미에 대한 명령이 2차원 배열 `commands`로 주어집니다. 각 원소는 `[종류, 값]` 꼴입니다.

- `[1, v]`: 문서 번호가 `v`인 서류를 더미 **맨 위**에 올립니다.
- `[2, x]`: 더미 **맨 위** 서류를 집어 처리하고 그 번호를 기록합니다. 더미가 비어 있으면 `-1`을 기록합니다.
- `[3, x]`: 더미 **전체를 뒤집습니다**. 맨 위였던 서류가 맨 아래로, 맨 아래였던 서류가 맨 위로 갑니다.

종류 2, 3의 `x`는 쓰지 않는 값이며 무시합니다.

처리할 때마다 기록한 값을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 처리 명령이 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `commands`의 길이 ≤ 500,000
- 종류는 1, 2, 3 중 하나입니다.
- 1 ≤ `v` ≤ 1,000,000,000 (문서 번호는 중복될 수 있습니다)
- 종류 2, 3의 `x`는 0 이상 1,000,000,000 이하의 아무 값입니다.

## 입출력 예

| commands | result |
|---|---|
| [[1, 1], [1, 2], [1, 3], [3, 0], [2, 0], [1, 4], [2, 0], [3, 0], [2, 0]] | [1, 4, 3] |
| [[2, 0], [3, 0], [1, 5], [3, 0], [3, 0], [2, 0], [2, 0]] | [-1, 5, -1] |
| [[1, 1], [1, 2], [3, 0], [1, 3], [2, 0], [2, 0], [2, 0]] | [3, 1, 2] |

## 입출력 예 설명
- 예 #1: 아래부터 [1, 2, 3]을 뒤집으면 [3, 2, 1]이 되어 맨 위 1을 처리합니다. 4를 올려 [3, 2, 4], 4를 처리합니다. [3, 2]를 뒤집어 [2, 3], 맨 위 3을 처리합니다.
- 예 #2: 빈 더미에서 처리하면 -1, 빈 더미를 뒤집는 것은 아무 일도 없습니다. 5를 올리고 두 번 뒤집은 뒤 5를 처리하고, 다시 빈 더미라 -1입니다.
- 예 #3: [1, 2]를 뒤집어 [2, 1], 3을 올려 [2, 1, 3]. 위에서부터 3, 1, 2를 처리합니다.
