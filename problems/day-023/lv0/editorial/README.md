# 해설 — 빵집 대기줄

## 접근
"맨 뒤에 서고 맨 앞부터 나간다"는 **큐**입니다. `ArrayDeque`를 큐로 씁니다.

- 줄 서기: `queue.offer(v)` (= `addLast`)
- 입장: 비어 있지 않을 때만 `queue.poll()` (= `pollFirst`)

입장한 손님은 `List<Integer>`에 모았다가 배열로 바꾸거나, 0의 개수를 먼저 세어 두고 배열을 바로 채워도 됩니다(빈 줄에서의 0은 기록되지 않으므로 리스트 쪽이 간단합니다).

## 주의할 점
- 빈 큐에서 `poll()`은 `null`을 돌려주고 `remove()`는 예외를 던집니다. 어느 쪽이든 `isEmpty()`를 먼저 확인하는 습관을 들이세요.
- 어제의 접시 더미(스택)와 달리 큐는 **먼저 선 사람이 먼저** 나갑니다. `push`/`pop`(앞에서 넣고 앞에서 빼기)을 쓰면 스택이 되어 버리니 `offer`/`poll`을 쓰세요.
- `LinkedList`도 `Queue`를 구현하지만, 보통 `ArrayDeque`가 더 빠릅니다.

## 복잡도
- 시간 O(n), 공간 O(n)
