# [lv0] 빵집 대기줄

인기 빵집 앞에는 손님들이 한 줄로 서서 차례로 입장합니다. 하루 동안의 기록이 배열 `events`로 주어집니다.

- 양수 `v`: 번호가 `v`인 손님이 줄의 **맨 뒤**에 섭니다.
- `0`: 줄의 **맨 앞** 손님이 입장합니다. 줄이 비어 있으면 아무 일도 일어나지 않습니다.

입장한 손님의 번호를 입장 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 입장한 손님이 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `events`의 길이 ≤ 200,000
- 0 ≤ `events[i]` ≤ 1,000,000,000
- 손님 번호는 중복될 수 있습니다.

## 입출력 예

| events | result |
|---|---|
| [5, 3, 0, 9, 0, 0] | [5, 3, 9] |
| [0, 4, 0, 0] | [4] |
| [1, 2, 3] | [] |

## 입출력 예 설명
- 예 #1: 5, 3이 줄을 서고 5가 입장합니다. 9가 서고 3, 9가 차례로 입장합니다.
- 예 #2: 빈 줄에서의 입장은 무시되고, 4가 서서 입장합니다. 마지막 입장은 다시 빈 줄이라 무시됩니다.
- 예 #3: 아무도 입장하지 않았습니다.
