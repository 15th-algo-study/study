# [lv3] 컨테이너 출고 순서

항만 야적장에 컨테이너 `n`개가 번호가 적힌 채 한 대씩 정해진 순서로 도착합니다. 도착 순서대로의 번호가 배열 `arrivals`에 담겨 있습니다.

야적장에는 **임시 적재탑**이 하나 있습니다.

- 도착한 컨테이너는 반드시 적재탑의 **맨 위**에 올립니다.
- 크레인은 언제든 적재탑 **맨 위**의 컨테이너를 내려 출고할 수 있습니다. 한 번 출고한 컨테이너는 다시 들어오지 않습니다.
- 도착과 출고는 아무 때나 번갈아 할 수 있습니다. 예를 들어 도착하자마자 바로 출고해도 되고, 여러 개를 쌓아 둔 뒤 출고해도 됩니다.

모든 컨테이너를 출고했을 때 만들 수 있는 출고 순서는 여러 가지입니다. 그중 **사전순으로 가장 앞서는** 출고 순서를 return 하도록 `solution` 함수를 완성해 주세요. 두 순서의 사전순 비교는 앞에서부터 처음으로 다른 위치의 번호가 더 작은 쪽이 앞서는 것으로 합니다.

## 제한사항
- 1 ≤ `arrivals`의 길이 `n` ≤ 1,000,000
- 1 ≤ `arrivals[i]` ≤ 1,000,000,000
- 컨테이너 번호는 서로 다릅니다.

## 입출력 예

| arrivals | result |
|---|---|
| [3, 1, 2] | [1, 2, 3] |
| [2, 3, 1] | [1, 3, 2] |
| [3, 4, 1, 2] | [1, 2, 4, 3] |

## 입출력 예 설명
- 예 #1: 3을 쌓고, 1을 쌓은 뒤 바로 출고합니다(1). 2를 쌓고 출고(2), 마지막으로 3을 출고(3)합니다.
- 예 #2: 1을 먼저 내보내려면 2, 3을 모두 쌓아야 하고, 그러면 3이 2 위에 있으므로 [1, 3, 2]가 됩니다. [1, 2, 3]은 만들 수 없습니다.
- 예 #3: 3, 4, 1을 쌓고 1을 출고합니다. 남은 적재탑은 아래부터 [3, 4]이고 아직 2가 도착하지 않았으므로, 2를 쌓고 출고한 뒤 4, 3 순서로 출고합니다.
