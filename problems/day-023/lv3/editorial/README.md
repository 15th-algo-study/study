# 해설 — 컨테이너 출고 순서

## 접근
매 순간 선택지는 두 가지뿐입니다: 적재탑 맨 위를 출고하거나, 다음 컨테이너를 도착시켜 쌓거나.

**관찰**: 적재탑 맨 위 번호를 `top`, 아직 도착하지 않은 컨테이너 중 가장 작은 번호를 `minRest`라 하면,

- `top < minRest`이면 **지금 출고**하는 것이 최선입니다. 앞으로 어떤 컨테이너가 와도 `top`보다 작은 것은 없고, 더 쌓으면 `top`이 묻혀서 더 큰 번호가 먼저 나가게 될 뿐입니다.
- `top > minRest`이면 `minRest`를 먼저 내보내야 사전순이 앞서므로, `minRest`가 도착할 때까지 **계속 쌓아야** 합니다(번호가 서로 다르므로 같은 경우는 없습니다).

`minRest`는 **뒤에서부터 구한 최솟값 배열**(`suffixMin[i]` = `arrivals[i..n-1]`의 최솟값)로 O(1)에 알 수 있습니다. 따라서

```
for i in 0..n-1:
    stack.push(arrivals[i])
    while stack 비어있지 않고 stack.top < suffixMin[i+1]:   # i+1 이후에 더 작은 게 없다
        출력에 stack.pop()
```

마지막 `suffixMin[n]`은 무한대로 두면 남은 컨테이너가 모두 출고됩니다.

## 주의할 점
- "남은 것 중 최솟값"을 매번 다시 훑으면 O(n²)로 n = 10^6에서 시간 초과입니다. 반드시 미리 계산해 두세요.
- 출고 판단은 **쌓은 직후**뿐 아니라, 하나 출고한 뒤 새로 드러난 맨 위에 대해서도 반복해야 합니다(`while`).
- 출력 배열 크기는 정확히 n이므로 `int[n]`을 인덱스로 채우면 됩니다.

## 복잡도
- 시간 O(n), 공간 O(n)
