# [lv3] 구멍 뚫린 카펫

정사각형 카펫에 다음 규칙으로 구멍을 뚫어 무늬를 만듭니다.

- **0단계 카펫**은 1 × 1 칸짜리이고, 그 한 칸은 채워져 있습니다.
- **k단계 카펫**은 (k − 1)단계 카펫 9장을 3 × 3으로 늘어놓은 것인데, **가운데 자리 한 장은 통째로 비워 둡니다**(구멍). 따라서 한 변이 3^k 칸입니다.

예를 들어 1단계 카펫은 3 × 3 칸 중 정중앙만 비어 있고, 2단계 카펫(9 × 9)은 가운데 3 × 3 블록 전체가 비어 있으며 나머지 8개 블록은 각각 1단계 카펫 모양입니다.

`n`단계 카펫의 행과 열에 0번부터 3^n − 1번까지 번호를 붙입니다. 질문 `queries[i] = [r, x, y]`는 **`r`번 행에서 `x`번 열과 `y`번 열 사이(두 열 포함)에 채워진 칸이 몇 개인지** 묻습니다. `x`와 `y`의 크기 순서는 정해져 있지 않습니다(`x > y`일 수도 있습니다).

각 질문의 답을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 30
- 1 ≤ `queries`의 길이 ≤ 200,000
- 0 ≤ `r`, `x`, `y` ≤ 3^n − 1 (`long`)
- 답은 `long[]`로 return 합니다.

## 입출력 예

| n | queries | result |
|---|---|---|
| 1 | [[1, 0, 2], [0, 0, 2], [1, 1, 1]] | [2, 3, 0] |
| 2 | [[4, 0, 8], [4, 2, 6], [0, 0, 8], [3, 8, 0]] | [4, 2, 9, 6] |
| 30 | [[0, 0, 205891132094648], [102945566047324, 0, 205891132094648]] | [205891132094649, 1073741824] |

## 입출력 예 설명
- 예 #1: 1단계 카펫의 1번 행은 `■□■`이므로 채워진 칸이 2개, 0번 행은 `■■■`이므로 3개입니다. (1, 1)은 구멍입니다.
- 예 #2: 2단계 카펫의 4번 행은 `■□■□□□■□■`입니다. 전체에서 4개, 2번~6번 열에서는 2개입니다. 0번 행은 모두 채워져 9개입니다. 3번 행은 `■■■□□□■■■`이고 `x = 8`, `y = 0`이므로 전체 범위에서 6개입니다.
- 예 #3: 0번 행은 구멍을 전혀 지나지 않아 3^30개가 모두 채워져 있습니다. 정중앙 행(102945566047324번)은 모든 단계의 구멍을 지나며 2^30개만 채워져 있습니다.
