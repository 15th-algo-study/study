# 해설 — 구멍 뚫린 카펫

## 접근
카펫을 실제로 만들면 3^30 × 3^30 칸이라 불가능하고, 한 행만 훑어도 2×10^14칸입니다. **재귀 구조를 따라 "구간 안의 채워진 칸 수"를 계산**해야 합니다.

### 관찰 1: 한 칸이 채워졌는지
칸 `(r, c)`는 어떤 단계에서든 "3 × 3 배치의 가운데"에 들어가면 구멍입니다. `r`과 `c`를 3진법으로 쓸 때 **같은 자리의 숫자가 둘 다 1인 자리가 하나라도 있으면** 구멍, 없으면 채워진 칸입니다.

### 관찰 2: 한 행 전체의 채워진 칸 수
`k`단계 카펫에서 행 `r`의 채워진 칸 수 `full(k, r)`은 `r`의 3진법 아래 `k`자리를 보며, 그 자리가 1이면 2배(열 숫자가 0 또는 2만 가능), 아니면 3배를 곱한 값입니다. 0번 행은 3^k개, 정중앙 행(모든 자리가 1)은 2^k개입니다.

### 관찰 3: 접두사 `[0, x)` 안의 채워진 칸 수 `prefix(k, r, x)`
`k`단계 카펫을 3 × 3 블록으로 보면 행 `r`은 블록 행 `rr = r / 3^(k-1)`에 있고, 열 구간 `[0, x)`는 블록 열 `cx = x / 3^(k-1)`개를 통째로 덮고 그다음 블록을 `x' = x mod 3^(k-1)`칸 덮습니다.

- 통째로 덮인 블록 `j < cx`마다: 구멍(`rr == 1 && j == 1`)이면 0, 아니면 `full(k−1, r mod 3^(k-1))`
- 부분 블록 `cx`: 구멍이면 0, 아니면 `prefix(k−1, r mod 3^(k-1), x')` — **재귀는 이 한 갈래뿐**입니다.

답은 `prefix(n, r, max+1) − prefix(n, r, min)`입니다. 단계마다 `full` 값이 필요하므로 질문마다 `r`의 3진법 자리를 아래부터 보며 `full(0..n)`을 미리 만들어 두면 질문당 O(n)입니다.

## 주의할 점
- 3^30 ≈ 2×10^14 이므로 행·열 번호, 3의 거듭제곱, 답(최대 3^30) 모두 `long`입니다.
- `x`와 `y`의 순서가 바뀌어 있을 수 있습니다. `min`, `max`를 먼저 정리하세요.
- 접두사 길이 `x = 3^k`(끝까지)이면 `cx = 3`, `x' = 0`이 되어 세 블록을 모두 세고 재귀는 더 하지 않습니다. 이 경우를 따로 처리하지 않아도 되는지 확인하세요.
- 재귀 깊이는 `n ≤ 30`이라 안전합니다. 칸을 하나씩 세는 풀이는 구간이 길면 시간 초과입니다.

## 복잡도
- 시간 O(q × n) (q = 질문 수), 공간 O(n + q)
