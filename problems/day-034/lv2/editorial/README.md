# 해설 — 사탕 봉지 나누기

## 접근
"가장 많이 담은 봉지에 몇 개를 담을지"로 경우를 나누면 재귀가 됩니다. `ways(n, m)` = 사탕 `n`개를 봉지당 최대 `m`개로 나누는 방법의 수라 하면

- `m`개 담은 봉지가 **하나도 없는** 경우: 봉지당 최대 `m − 1`개 → `ways(n, m − 1)`
- `m`개 담은 봉지가 **하나 이상 있는** 경우: 그중 하나를 빼면 사탕 `n − m`개를 최대 `m`개로 나누는 문제 → `ways(n − m, m)`

> `ways(n, m)` = `ways(n, m − 1)` + `ways(n − m, m)` (단 `n ≥ m`)
> 종료: `ways(0, m) = 1`, `ways(n, 0) = 0` (`n > 0`)

이 재귀를 메모 없이 부르면 호출 수가 답(최대 9×10^15)만큼 커져 시간 초과입니다. 하지만 상태는 `(n, m)` 301 × 301개뿐이므로 **2차원 표에 저장**하면 한 번 채우고 20만 질문에 O(1)로 답할 수 있습니다. 표는 재귀 + 메모로 채워도 되고, 작은 `n`, `m`부터 반복문으로 채워도 됩니다(모범 풀이는 반복문).

## 주의할 점
- `ways(300, 300)` ≈ 9.3×10^15 라 표는 `long[][]`이어야 합니다.
- `m > n`이면 `ways(n, m) = ways(n, n)`입니다. 표를 `m ≤ 300`까지 그대로 채우면 자동으로 처리됩니다.
- 표를 질문마다 다시 만들지 마세요. 한 번만 만들고 재사용합니다.
- 메모 없는 재귀는 `n = 60` 정도부터 눈에 띄게 느려지고 `n = 100`이면 사실상 끝나지 않습니다. 메모이제이션 전후의 차이를 꼭 체감해 보세요.

## 복잡도
- 시간 O(300 × 300 + q), 공간 O(300 × 300)
