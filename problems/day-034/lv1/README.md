# [lv1] 팔씨름 토너먼트

`n`명의 선수가 팔씨름 토너먼트를 합니다. `n`은 2의 거듭제곱이고, 선수 번호는 0번부터 `n − 1`번까지, `i`번 선수의 처음 힘은 `power[i]`입니다.

- 1라운드에서는 (0번, 1번), (2번, 3번), (4번, 5번), … 이 대결합니다.
- 대결에서는 **현재 힘이 큰** 선수가 이깁니다. 힘이 같으면 **번호가 작은** 선수가 이깁니다.
- 이긴 선수는 지친 나머지 힘이 **진 선수 힘의 절반(소수점 버림)** 만큼 줄어듭니다. 진 선수는 탈락합니다.
- 다음 라운드에서는 남은 선수들이 **원래 번호 순서**로 다시 둘씩 짝지어 대결합니다. 이것을 한 명이 남을 때까지 반복합니다.

예를 들어 `power = [10, 9, 7, 1]`이면 1라운드에서 0번(10)이 1번(9)을 이기고 힘이 10 − 4 = 6이 되며, 2번(7)이 3번(1)을 이기고 힘이 7 − 0 = 7이 됩니다. 결승에서 0번(6)과 2번(7)이 대결해 2번이 이기고 힘은 7 − 3 = 4가 됩니다.

`power`가 주어질 때, 우승자의 번호와 우승 직후 남은 힘을 `[번호, 힘]` 형태로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `power`의 길이 `n` ≤ 131,072 (= 2^17), `n`은 2의 거듭제곱입니다.
- 1 ≤ `power`의 원소 ≤ 1,000,000,000
- 선수가 한 명이면 그 선수가 힘 그대로 우승합니다.

## 입출력 예

| power | result |
|---|---|
| [10, 9, 7, 1] | [2, 4] |
| [5, 3, 8, 8] | [0, 2] |
| [7] | [0, 7] |

## 입출력 예 설명
- 예 #1: 지문의 예입니다. 힘이 가장 센 2번이 우승하지만 결승에서 힘이 4만 남습니다.
- 예 #2: 1라운드 (0번 5 vs 1번 3) → 0번 승, 힘 5 − 1 = 4. (2번 8 vs 3번 8) → 번호가 작은 2번 승, 힘 8 − 4 = 4. 결승 (0번 4 vs 2번 4) → 번호가 작은 0번 승, 힘 4 − 2 = 2.
- 예 #3: 대결 없이 우승합니다.
