# 해설 — 팔씨름 토너먼트

## 접근
"남은 선수들이 원래 번호 순서로 둘씩"이라는 규칙 때문에 대진표는 **구간을 반으로 나누는 재귀 구조**입니다. 구간 `[l, r]`의 우승자는 왼쪽 절반 `[l, m]`의 우승자와 오른쪽 절반 `[m + 1, r]`의 우승자가 대결해 정해집니다.

```
winner(l, r):
  l == r 이면 (l, power[l])
  (a, pa) = winner(l, m), (b, pb) = winner(m + 1, r)
  pa ≥ pb 이면 (a, pa - pb / 2)   ← 같으면 왼쪽(번호 작은 쪽)이 이긴다
  아니면      (b, pb - pa / 2)
```

왼쪽 절반의 우승자가 항상 번호가 더 작으므로 "힘이 같으면 번호가 작은 쪽"은 `≥` 비교 하나로 처리됩니다. 재귀 깊이는 log₂(131072) = 17이고 대결은 `n − 1`번이라 O(n)입니다.

반환값이 두 개(번호, 힘)이므로 `int[2]`를 돌려주거나, 번호만 돌려주고 힘은 `power` 배열에 직접 덮어써도 됩니다(모범 풀이는 후자).

## 주의할 점
- 라운드마다 남은 선수 배열을 새로 만들어 돌리는 반복문 풀이도 O(n)이라 정답입니다. 재귀 구조와 반복 구조가 같은 결과를 낸다는 점을 확인해 보세요.
- 힘은 `int` 범위를 벗어나지 않습니다. 승자의 힘은 `pa - pb / 2 ≥ pb - pb / 2 ≥ 1`이라 항상 1 이상입니다.
- `pb / 2`는 정수 나눗셈(버림)입니다. 실수로 바꾸지 마세요.
- 선수가 한 명(`n = 1`)이면 `[0, power[0]]`입니다.

## 복잡도
- 시간 O(n), 공간 O(log n) (재귀 깊이)
