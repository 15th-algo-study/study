# 해설 — 덩굴 잎 세기

## 접근
규칙은 재귀 함수 그대로입니다.

> `leaves(n)` = `n ≤ 2 ? n : 2 × leaves(n − 1) + leaves(n − 2)`

그런데 이 함수를 그대로 부르면 `leaves(45)` 하나를 구하는 데 호출이 약 6×10^16번 일어납니다. `leaves(44)`와 `leaves(43)`을 부르고, `leaves(44)`가 다시 `leaves(43)`을 부르는 식으로 **같은 값을 셀 수 없이 다시 계산**하기 때문입니다. 메모 없는 재귀의 한계를 몸으로 느끼는 문제입니다.

해결은 간단합니다. 1일차부터 45일차까지의 값을 **배열에 한 번만 순서대로 채워** 두고(`leaf[i] = 2 * leaf[i-1] + leaf[i-2]`), 질문마다 배열에서 꺼내 줍니다. 재귀로 쓰고 싶다면 계산한 값을 배열에 저장했다가 다시 부르면 바로 돌려주는 **메모이제이션**을 하면 됩니다. 어느 쪽이든 덧셈 45번이면 끝납니다.

## 주의할 점
- 45일차는 약 5.9×10^16 이라 `long`이어야 합니다. `int`로 계산하면 25일차 근처에서 넘칩니다.
- 질문이 10만 개이므로 질문마다 처음부터 다시 계산하지 말고 한 번 만든 표를 재사용합니다 (질문마다 45번 더해도 450만 번이라 통과는 합니다).
- 배열 인덱스를 1일차 = `leaf[1]`로 맞추면 헷갈리지 않습니다 (`leaf[0]`은 쓰지 않거나 0).

## 복잡도
- 시간 O(45 + q) (q = 질문 수), 공간 O(45 + q)
