# [lv0] 덩굴 잎 세기

어느 덩굴은 잎이 다음 규칙으로 늘어납니다.

- 1일차에는 잎이 1장, 2일차에는 2장입니다.
- 3일차부터는 **(전날 잎 수) × 2 + (전전날 잎 수)** 장이 됩니다.

즉 3일차는 2 × 2 + 1 = 5장, 4일차는 5 × 2 + 2 = 12장, 5일차는 12 × 2 + 5 = 29장입니다.

궁금한 날짜들이 배열 `days`로 주어질 때, 각 날짜의 잎 수를 같은 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `days`의 길이 ≤ 100,000
- 1 ≤ `days`의 원소 ≤ 45
- 잎 수는 `int` 범위를 넘을 수 있으므로 `long[]`로 return 합니다.

## 입출력 예

| days | result |
|---|---|
| [1, 2, 3, 4, 5] | [1, 2, 5, 12, 29] |
| [10, 3] | [2378, 5] |
| [45] | [59341817924539925] |

## 입출력 예 설명
- 예 #1: 규칙대로 1, 2, 5, 12, 29장입니다.
- 예 #2: 6일차부터 차례로 70, 169, 408, 985, 2378장이므로 10일차는 2378장입니다.
- 예 #3: 45일차의 잎 수는 약 5.9×10^16으로 `int` 범위를 훨씬 넘습니다.
