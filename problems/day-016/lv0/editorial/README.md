# 해설 — 가장 비슷한 두 키

## 접근
모든 두 사람 쌍을 비교하면 n²/2 번 비교해야 합니다. 대신 **정렬**하면, 차이가 가장 작은 두 사람은 반드시 정렬된 배열에서 **이웃한 위치**에 있습니다 (사이에 다른 사람이 끼어 있으면 그 사람과의 차이가 더 작거나 같기 때문입니다).

1. `Arrays.sort(heights)` 로 오름차순 정렬합니다.
2. 이웃한 원소의 차이 `heights[i + 1] - heights[i]` 중 최솟값을 구합니다.

## 주의할 점
- `Arrays.sort` 는 배열을 **제자리에서** 바꿉니다. 원본을 보존해야 하면 `heights.clone()` 을 정렬하세요.
- 최솟값의 초기값은 충분히 큰 값(`Integer.MAX_VALUE`)이나 첫 차이로 둡니다. 0으로 두면 답이 항상 0이 됩니다.
- 이중 반복문(O(n²))은 20만 명에서 약 2×10^10 번 비교라 시간 초과입니다.

## 복잡도
- 시간 O(n log n), 공간 O(1) (정렬에 쓰는 추가 공간 제외)
