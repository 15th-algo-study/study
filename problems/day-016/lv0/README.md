# [lv0] 가장 비슷한 두 키

합창단 단원들의 키가 정수 배열 `heights`로 주어집니다. 단원 중 **키 차이가 가장 작은 두 사람**을 골라, 그 두 사람의 키 차이를 return 하도록 `solution` 함수를 완성해 주세요.

키가 같은 단원이 있으면 키 차이는 0입니다.

## 제한사항
- 2 ≤ `heights`의 길이 ≤ 200,000
- 1 ≤ `heights`의 원소 ≤ 1,000,000,000

## 입출력 예

| heights | result |
|---|---|
| [170, 155, 163, 171, 180] | 1 |
| [5, 5, 100] | 0 |
| [1, 1000000] | 999999 |

## 입출력 예 설명
- 예 #1: 키 순서로 늘어놓으면 155, 163, 170, 171, 180 입니다. 이웃한 키 차이는 8, 7, 1, 9 이고, 가장 작은 값은 170과 171의 차이 **1**입니다.
- 예 #2: 키가 5인 단원이 두 명이므로 **0**입니다.
- 예 #3: 두 명뿐이므로 둘의 차이 **999999**입니다.
