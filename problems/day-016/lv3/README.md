# [lv3] 울타리 말뚝 다듬기

나무 말뚝 `n`개를 한 줄로 박아 울타리를 만들었는데 높이가 제각각입니다. 모든 말뚝의 높이를 **같은 높이 `t`** 로 맞추려고 합니다. `t`는 1 이상의 정수 중에서 자유롭게 고를 수 있습니다.

- 높이가 `t`보다 큰 말뚝은 윗부분을 잘라 냅니다. 1만큼 자르는 데 비용 `cut`이 듭니다.
- 높이가 `t`보다 작은 말뚝은 나무를 덧대어 늘립니다. 1만큼 늘리는 데 비용 `extend`가 듭니다.

말뚝 높이 배열 `heights`와 비용 `cut`, `extend`가 주어질 때, 높이를 맞추는 데 드는 **최소 총비용**을 return 하도록 `solution` 함수를 완성해 주세요. 총비용은 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `heights`의 길이 `n` ≤ 300,000
- 1 ≤ `heights`의 원소 ≤ 1,000,000,000
- 1 ≤ `cut`, `extend` ≤ 1,000

## 입출력 예

| heights | cut | extend | result |
|---|---|---|---|
| [1, 5, 9] | 1 | 1 | 8 |
| [1, 5, 9] | 1 | 10 | 12 |
| [10, 10, 10] | 3 | 7 | 0 |

## 입출력 예 설명
- 예 #1: `t = 5`로 맞추면 9를 4만큼 자르고(비용 4) 1을 4만큼 늘려(비용 4) 총 **8**입니다. `t = 1`이나 `t = 9`로 맞추면 12가 듭니다.
- 예 #2: 늘리는 비용이 비싸므로 가장 낮은 높이 `t = 1`로 맞춥니다. 5와 9를 각각 4, 8만큼 잘라 총 **12**입니다. `t = 5`면 4 + 40 = 44, `t = 9`면 120이 듭니다.
- 예 #3: 이미 높이가 같으므로 0입니다.
