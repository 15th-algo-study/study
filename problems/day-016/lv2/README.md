# [lv2] 제설 구간

길이 1,000,000,000 의 직선 도로가 있고, 위치는 0부터 1,000,000,000 까지의 수로 나타냅니다. 밤사이 제설차 여러 대가 도로의 일부 구간을 치웠습니다. `i`번째 제설 기록은 `sections[i] = [start, length]` 로, 위치 `start`부터 `start + length`까지의 구간을 치웠다는 뜻입니다.

치워진 구간들은 서로 겹치거나 끝이 맞닿을 수 있습니다. 서로 겹치거나 맞닿은 구간들은 하나로 이어진 **제설 구역**으로 봅니다. 예를 들어 `[1, 4]`와 `[4, 7]`(끝이 맞닿음), `[1, 4]`와 `[3, 7]`(겹침)은 모두 하나의 구역 `[1, 7]`입니다.

제설 기록 `sections`가 주어질 때, **제설 구역의 개수**와 **치워진 도로의 총 길이**를 `[구역 수, 총 길이]` 형태의 `long` 배열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `sections`의 길이 ≤ 200,000
- `sections[i]`의 길이는 2입니다.
- 0 ≤ `start`, 1 ≤ `length`, `start + length` ≤ 1,000,000,000

## 입출력 예

| sections | result |
|---|---|
| [[1, 3], [6, 3], [3, 2], [9, 3]] | [2, 10] |
| [[0, 1000000000], [5, 5]] | [1, 1000000000] |
| [[2, 1], [5, 1], [8, 1]] | [3, 3] |

## 입출력 예 설명
- 예 #1: 치운 구간은 `[1, 4]`, `[6, 9]`, `[3, 5]`, `[9, 12]` 입니다. `[1, 4]`와 `[3, 5]`는 겹쳐 `[1, 5]`가 되고, `[6, 9]`와 `[9, 12]`는 맞닿아 `[6, 12]`가 됩니다. 구역은 2개, 총 길이는 4 + 6 = **10**입니다.
- 예 #2: 두 번째 기록은 첫 번째 안에 완전히 들어 있습니다. 구역 1개, 길이 **1,000,000,000**입니다.
- 예 #3: 세 구간이 서로 떨어져 있어 구역 3개, 총 길이 3입니다.
