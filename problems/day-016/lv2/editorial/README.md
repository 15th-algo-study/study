# 해설 — 제설 구간

## 접근
도로 길이가 10^9 라 위치마다 표시를 남길 수 없습니다. **구간을 시작 위치로 정렬**하면 겹치는 구간은 반드시 이웃하게 되고, 한 번 훑으며 합칠 수 있습니다.

1. 각 기록을 `[start, end = start + length]`로 바꾸고 `start` 오름차순으로 정렬합니다.
2. 현재 구역 `[curStart, curEnd]`를 들고 다음 구간 `[s, e]`를 봅니다.
   - `s ≤ curEnd` 이면 겹치거나 맞닿은 것이므로 `curEnd = max(curEnd, e)`로 구역을 늘립니다.
   - 그렇지 않으면 현재 구역을 확정(개수 +1, 길이 += `curEnd - curStart`)하고 `[s, e]`를 새 구역으로 삼습니다.
3. 마지막 구역을 잊지 말고 확정합니다.

## 주의할 점
- **맞닿은 경우(`s == curEnd`)도 같은 구역**입니다. 비교를 `<` 로 쓰면 예 #1의 `[6, 9]`, `[9, 12]`가 둘로 나뉩니다.
- 뒤 구간이 앞 구간 안에 완전히 포함될 수 있습니다(예 #2). `curEnd = e`가 아니라 **`max(curEnd, e)`** 로 갱신해야 합니다.
- `int[][]`를 `Arrays.sort(sections, (a, b) -> Integer.compare(a[0], b[0]))` 로 정렬하면 됩니다. 정렬하지 않고 구간마다 기존 구역들을 모두 훑으며 합치면 O(n²)이라 시간 초과입니다.
- 총 길이는 최대 10^9 라 `int`에 들어가지만, 반환 타입이 `long[]`이므로 그대로 담으면 됩니다.

## 복잡도
- 시간 O(n log n), 공간 O(1) (정렬 외 추가 공간 없음)
