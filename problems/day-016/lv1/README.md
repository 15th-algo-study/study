# [lv1] 낚시 대회 순위

낚시 대회에 참가자 `n`명이 참가했습니다. 참가자 번호는 0번부터 `n-1`번이고, `i`번 참가자의 기록은 `catches[i] = [weight, count]` 입니다. `weight`는 그 참가자가 잡은 물고기 중 가장 무거운 것의 무게(g), `count`는 잡은 물고기 수입니다.

순위는 다음 기준으로 정합니다.

1. `weight`가 큰 참가자가 앞섭니다.
2. `weight`가 같으면 `count`가 많은 참가자가 앞섭니다.
3. 둘 다 같으면 참가자 번호가 작은 쪽이 앞섭니다.

순위 순서대로 참가자 번호를 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `catches`의 길이 `n` ≤ 200,000
- `catches[i]`의 길이는 2입니다.
- 0 ≤ `weight` ≤ 1,000,000,000
- 0 ≤ `count` ≤ 100,000

## 입출력 예

| catches | result |
|---|---|
| [[3200, 4], [5000, 2], [3200, 6], [1500, 10]] | [1, 2, 0, 3] |
| [[100, 1], [100, 1], [100, 1]] | [0, 1, 2] |
| [[0, 0], [10, 0]] | [1, 0] |

## 입출력 예 설명
- 예 #1: 가장 무거운 물고기는 1번(5000g)입니다. 0번과 2번은 3200g으로 같으므로 마릿수가 많은 2번이 앞섭니다. 마지막은 3번(1500g)입니다.
- 예 #2: 기록이 모두 같으므로 번호 순서입니다.
- 예 #3: 한 마리도 못 잡은 0번이 뒤로 갑니다.
