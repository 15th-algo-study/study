# [lv3] 글자 섞기 기계

암호 장치가 문자열의 글자 위치를 정해진 규칙으로 섞습니다. 규칙은 배열 `p`로 주어지며, 기계를 **한 번** 돌리면 모든 `i`에 대해 현재 `i`번 위치에 있던 글자가 `p[i]`번 위치로 **동시에** 옮겨집니다. `p`는 0부터 `n-1`까지의 수가 한 번씩 나오는 순열이므로, 한 번 돌린 뒤에도 모든 위치에 글자가 정확히 하나씩 놓입니다.

예를 들어 `s = "abcd"`, `p = [1, 2, 3, 0]`이면 한 번 돌린 뒤 `a`는 1번, `b`는 2번, `c`는 3번, `d`는 0번으로 가서 `"dabc"`가 됩니다. 한 번 더 돌리면 `"cdab"`입니다.

문자열 `s`, 규칙 `p`, 기계를 돌리는 횟수 `k`가 주어질 때, `k`번 돌린 뒤의 문자열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `s`의 길이 `n` ≤ 200,000
- `s`는 영문 소문자로만 이루어져 있습니다.
- `p`의 길이는 `n`이고, 0 이상 `n-1` 이하의 정수가 정확히 한 번씩 나옵니다.
- 1 ≤ `k` ≤ 1,000,000,000

## 입출력 예

| s | p | k | result |
|---|---|---|---|
| "abcd" | [1, 2, 3, 0] | 2 | "cdab" |
| "abcde" | [1, 0, 3, 4, 2] | 3 | "bacde" |
| "hello" | [0, 1, 2, 3, 4] | 1000000000 | "hello" |

## 입출력 예 설명
- 예 #1: `abcd` → `dabc` → `cdab`
- 예 #2: 0번과 1번 글자는 서로 자리를 바꾸고, 2번·3번·4번 글자는 2 → 3 → 4 → 2로 돌아갑니다. 3번 돌리면 0번·1번은 홀수 번 바뀌어 `ba`가 되고, 2번·3번·4번은 세 번 만에 제자리로 돌아와 `cde` 그대로입니다.
- 예 #3: 모든 글자가 제자리에 머무는 규칙이므로 몇 번을 돌려도 같습니다.
