# [lv0] 글자 늘려 쓰기

문자열 `s`와 정수 `k`가 주어집니다. `s`의 각 글자를 **순서대로 `k`번씩 반복**해 쓴 문자열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 100,000
- `s`는 영문 소문자와 숫자로만 이루어져 있습니다.
- 1 ≤ `k` ≤ 10

## 입출력 예

| s | k | result |
|---|---|---|
| "abc" | 3 | "aaabbbccc" |
| "xy" | 1 | "xy" |
| "a1" | 4 | "aaaa1111" |

## 입출력 예 설명
- 예 #1: `a`, `b`, `c`를 각각 3번씩 씁니다.
- 예 #2: `k`가 1이면 원래 문자열과 같습니다.
- 예 #3: 숫자도 글자와 똑같이 반복합니다.
