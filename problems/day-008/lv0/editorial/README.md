# 해설 — 글자 늘려 쓰기

## 접근
이중 반복문입니다. 바깥은 `s`의 글자, 안쪽은 `k`번 반복하며 `StringBuilder`에 `append`합니다. 결과 길이가 `s.length() * k`로 미리 정해지므로 `new StringBuilder(n * k)`처럼 용량을 지정하면 재할당이 없습니다.

`String.valueOf(ch).repeat(k)`를 붙여도 됩니다.

## 주의할 점
- `answer += ch`로 이어 붙이면 결과가 길어질수록 매번 전체를 복사해 O(결과 길이²)이 됩니다. 결과가 100만 글자면 시간 초과입니다.
- `sb.append(ch * k)`처럼 쓰면 `char`가 `int`로 바뀌어 숫자가 붙습니다. 글자를 `k`번 붙이는 것과 글자 코드에 `k`를 곱하는 것은 다릅니다.

## 복잡도
- 시간 O(n × k), 공간 O(n × k)
