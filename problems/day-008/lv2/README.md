# [lv2] 파일 이름 패턴 검색

파일 이름 목록 `names`에서 검색 패턴 `pattern`에 맞는 파일이 몇 개인지 세려고 합니다. 패턴의 글자는 다음과 같이 해석합니다.

- `?`: 아무 글자 **하나**와 맞습니다.
- `*`: 길이 0 이상의 아무 글자열과 맞습니다. 패턴에 `*`는 **최대 한 번**만 나옵니다.
- 그 밖의 글자: 같은 글자와만 맞습니다.

파일 이름 전체가 패턴 전체와 맞아야 합니다(일부만 맞는 것은 인정하지 않습니다). 패턴에 맞는 파일 이름의 개수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `names`의 길이 ≤ 200,000
- 각 파일 이름의 길이는 1 이상 200,000 이하이고, 모든 파일 이름 길이의 합은 1,000,000 이하입니다.
- 1 ≤ `pattern`의 길이 ≤ 200,000
- 파일 이름은 영문 소문자, 숫자, `.`, `_`로만 이루어져 있습니다.
- 패턴은 영문 소문자, 숫자, `.`, `_`, `?`, `*`로만 이루어져 있으며 `*`는 많아야 하나입니다.

## 입출력 예

| names | pattern | result |
|---|---|---|
| ["report_01.txt", "report_2024.txt", "report.txt", "summary.txt"] | "report_*.txt" | 2 |
| ["img1.png", "img22.png", "img.png"] | "img?.png" | 1 |
| ["abc", "abcabc", "ac"] | "a*c" | 3 |

## 입출력 예 설명
- 예 #1: `report_01.txt`와 `report_2024.txt`는 `*`가 각각 `01`, `2024`에 해당해 맞습니다. `report.txt`는 `report_`로 시작하지 않고, `summary.txt`는 전혀 다릅니다.
- 예 #2: `?`는 글자 하나와만 맞으므로 `img1.png`만 맞습니다.
- 예 #3: `*`가 `b`, `bcab`, 빈 문자열에 해당해 세 이름 모두 맞습니다.
