# 해설 — 폭에 맞춰 줄 나누기

## 접근
`text.split(" ")`으로 단어를 나눈 뒤 앞에서부터 그리디하게 채웁니다. 현재 줄을 `StringBuilder line`에 모으면서

- `line`이 비어 있으면 단어를 그냥 넣습니다 (단어가 `width`보다 길어도 넣습니다).
- 비어 있지 않으면 `line.length() + 1 + word.length() <= width`일 때만 공백과 단어를 붙이고, 아니면 `line`을 결과에 넣고 새 줄을 이 단어로 시작합니다.

마지막 줄을 결과에 넣는 것을 잊지 마세요.

## 주의할 점
- 줄을 `String line += " " + word`로 만들면 줄이 길어질수록 매번 전체를 복사합니다. 폭이 100만이고 단어가 50만 개면 한 줄에 전부 들어가므로 복사량이 약 10^11 글자가 되어 시간 초과입니다. 줄도 `StringBuilder`로 모으세요.
- "단어가 폭보다 길면 혼자 한 줄"은 별도 처리가 필요 없습니다. 빈 줄에는 무조건 넣고, 그 뒤에 어떤 단어도 붙지 못하기 때문입니다. 다만 **빈 줄에 넣을 때 폭을 검사하면** 그 단어가 영원히 들어가지 못하는 버그가 납니다.
- 줄 수를 미리 알 수 없으므로 `List<String>`에 모은 뒤 `toArray(new String[0])`로 바꿉니다.

## 복잡도
- 시간 O(|text|), 공간 O(|text|)
