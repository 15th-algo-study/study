# [lv1] 폭에 맞춰 줄 나누기

영문 소문자 단어들이 공백 하나로 구분된 문자열 `text`를, 한 줄의 폭이 `width`인 화면에 표시하려고 합니다. 줄은 다음 규칙으로 나눕니다.

- 첫 단어부터 순서대로 현재 줄에 넣습니다. 한 줄 안에서 단어 사이에는 공백 하나를 둡니다.
- 다음 단어를 넣었을 때 줄의 길이(공백 포함)가 `width`를 넘으면, 그 단어부터 새 줄을 시작합니다.
- 단어 하나의 길이가 `width`보다 길면 그 단어는 **혼자 한 줄**을 차지합니다. 이때만 줄의 길이가 `width`를 넘을 수 있습니다.

줄을 나눈 결과를 문자열 배열로 return 하도록 `solution` 함수를 완성해 주세요. 각 줄의 앞뒤에 공백은 없습니다.

## 제한사항
- 1 ≤ `text`의 길이 ≤ 1,000,000
- `text`는 영문 소문자와 공백으로 이루어져 있으며, 공백은 연속되지 않고 맨 앞과 맨 뒤에 오지 않습니다. 즉 단어가 1개 이상 있습니다.
- 1 ≤ `width` ≤ 1,000,000

## 입출력 예

| text | width | result |
|---|---|---|
| "the quick brown fox jumps" | 10 | ["the quick", "brown fox", "jumps"] |
| "a bb ccc dddd" | 3 | ["a", "bb", "ccc", "dddd"] |
| "ab cd ef" | 100 | ["ab cd ef"] |

## 입출력 예 설명
- 예 #1: `the quick`은 9글자, 여기에 `brown`을 더하면 15글자가 되어 넘칩니다. `brown fox`는 9글자, `jumps`를 더하면 넘칩니다.
- 예 #2: `a bb`는 4글자라 넘치므로 `a`와 `bb`가 각각 한 줄입니다. `dddd`는 폭 3보다 길지만 혼자 한 줄을 차지합니다.
- 예 #3: 폭이 충분하면 한 줄입니다.
