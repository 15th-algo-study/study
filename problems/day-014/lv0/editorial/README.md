# 해설 — 두 번째로 높은 기록

## 접근
최댓값 `first`와 "최댓값보다 작은 값 중 최댓값" `second`를 한 번의 반복으로 함께 관리합니다. 값 `v`를 볼 때

- `v > first`이면 기존 `first`가 `second`로 내려가고 `v`가 `first`가 됩니다.
- `first > v > second`이면 `second = v`입니다.
- `v == first`이면 아무것도 하지 않습니다 (같은 기록은 같은 등수).

`second`의 초깃값은 "아직 없음"을 뜻하는 -1로 둡니다. 기록은 0 이상이라 -1과 겹치지 않습니다.

정렬한 뒤 뒤에서부터 최댓값과 다른 첫 값을 찾는 방법도 맞지만 O(n log n)이고, 중복을 빼지 않고 "뒤에서 두 번째"를 고르면 예 #1에서 50이 나와 틀립니다.

## 주의할 점
- `v == first`인 경우를 `second`로 내려 보내면 안 됩니다. 반드시 `v > first`일 때만 내려 보내세요.
- `second`의 초깃값을 0으로 두면 `[7, 7, 7]`에서 0을 return 하게 됩니다.
- 기록이 하나뿐이면 -1입니다.

## 복잡도
- 시간 O(n), 공간 O(1)
