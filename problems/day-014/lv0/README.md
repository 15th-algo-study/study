# [lv0] 두 번째로 높은 기록

줄넘기 대회 참가자들의 기록(연속으로 넘은 횟수)이 배열 `records`로 주어집니다. 금메달은 가장 높은 기록에게, 은메달은 **그다음으로 높은 기록**에게 줍니다. 기록이 같은 참가자는 같은 등수이므로, 은메달 기록은 가장 높은 기록보다 **작은 기록 중 가장 큰 값**입니다.

은메달 기록을 return 하도록 `solution` 함수를 완성해 주세요. 모든 참가자의 기록이 같아서 은메달 기록이 없으면 -1을 return 합니다.

## 제한사항
- 1 ≤ `records`의 길이 ≤ 1,000,000
- 0 ≤ `records`의 원소 ≤ 1,000,000,000

## 입출력 예

| records | result |
|---|---|
| [30, 50, 50, 20] | 30 |
| [7, 7, 7] | -1 |
| [1, 2] | 1 |

## 입출력 예 설명
- 예 #1: 가장 높은 기록 50(두 명)이 금메달, 그다음인 30이 은메달입니다.
- 예 #2: 모두 같은 기록이라 은메달 기록이 없습니다.
- 예 #3: 2가 금메달, 1이 은메달입니다.
