# 해설 — 포인트 적립왕

## 접근
`HashMap<String, Long>`에 회원별 점수 합을 쌓습니다 (`merge(name, (long) p, Long::sum)`). 다 쌓은 뒤 맵을 순회하며

- 합이 더 크면 답을 바꾸고,
- 합이 같으면 `name.compareTo(best) < 0`일 때만 바꿉니다.

`HashMap`의 순회 순서는 정해져 있지 않지만, 동률 조건을 **값이 아니라 이름 비교**로 두었으므로 어떤 순서로 보아도 결과가 같습니다.

## 주의할 점
- **정수 오버플로**: 한 회원이 10억 점을 세 번만 적립해도 30억으로 `int` 범위(약 21억)를 넘어 음수가 됩니다 (예 #3). 합은 반드시 `long`으로 쌓으세요. `map.merge(name, points[i], Integer::sum)`처럼 `Integer`로 쌓으면 조용히 틀립니다.
- 동률 처리를 "먼저 나온 회원"으로 착각하지 마세요. 이 문제는 **사전순**입니다.
- 대소문자를 바꾸지 말고 그대로 비교합니다.

## 복잡도
- 시간 O(n · L) (L = 이름 길이), 공간 O(회원 수)
