# [lv1] 포인트 적립왕

편의점 멤버십의 하루 적립 기록이 두 배열로 주어집니다. `i`번째 적립은 회원 `names[i]`에게 `points[i]`점을 준 것입니다. 한 회원이 여러 번 적립할 수 있습니다.

하루 동안 적립한 점수의 합이 가장 큰 회원의 이름을 return 하도록 `solution` 함수를 완성해 주세요. 합이 같은 회원이 여러 명이면 이름이 **사전순으로 가장 앞선** 회원을 return 합니다. 이름은 대소문자를 구분하며, 사전순은 자바의 `String.compareTo` 기준(대문자가 소문자보다 앞)입니다.

## 제한사항
- 1 ≤ `names`의 길이 = `points`의 길이 ≤ 200,000
- 이름은 길이 1 이상 10 이하의 영문 대소문자·숫자로만 이루어져 있습니다.
- 1 ≤ `points`의 원소 ≤ 1,000,000,000

## 입출력 예

| names | points | result |
|---|---|---|
| ["kim", "lee", "kim", "park"] | [100, 300, 250, 300] | "kim" |
| ["b", "a", "b", "a"] | [1, 1, 1, 1] | "a" |
| ["big", "big", "big", "small"] | [1000000000, 1000000000, 1000000000, 5] | "big" |

## 입출력 예 설명
- 예 #1: kim 350점, lee 300점, park 300점입니다.
- 예 #2: a와 b 모두 2점이므로 사전순으로 앞선 a입니다.
- 예 #3: big의 합은 30억 점입니다.
