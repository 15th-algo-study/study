# 해설 — 실시간 1위

## 접근
표마다 모든 후보의 득표수를 훑어 1위를 찾으면 O(n × 후보 수)로, 후보가 수만 명이면 시간 초과입니다. 관찰은 **1위는 "현재 1위의 득표수를 넘어서는 순간"에만 바뀐다**는 것입니다.

- 현재 1위 `leader`와 그 득표수 `top`을 들고 있습니다.
- 표를 받은 후보 `c`의 득표수를 `HashMap<String, Integer>`에서 1 늘립니다.
- 늘어난 득표수가 `top`보다 **크면** `leader = c`, `top = 득표수`.
- 같으면 바꾸지 않습니다. 현재 1위는 이미 그 득표수에 도달해 있었으므로 "먼저 도달한" 쪽이기 때문입니다.
- 작으면 당연히 그대로입니다.

이렇게 하면 표 한 장에 O(1)입니다.

## 주의할 점
- 득표수가 같을 때 `>=`로 비교해 바꾸면 "먼저 도달한 후보" 규칙을 어깁니다 (예 #1의 2번째, 4번째 표).
- "1위가 바뀐 순간"만 기록하지 말고 **모든 표마다** 1위를 기록해야 합니다. 답의 길이는 `votes.length`입니다.
- 매번 맵 전체를 순회하거나 정렬하면 후보가 많은 입력에서 시간 초과입니다.

## 복잡도
- 시간 O(n), 공간 O(후보 수 + n)
