# [lv2] 실시간 1위

학교 축제 인기상 투표가 진행 중입니다. 표가 한 장씩 들어올 때마다 전광판에 **현재 1위**를 띄우려고 합니다. 들어온 순서대로 각 표에 적힌 후보 이름이 배열 `votes`에 담겨 있습니다.

현재 1위는 다음 규칙으로 정합니다.

- 지금까지 가장 많은 표를 받은 후보가 1위입니다.
- 가장 많은 표를 받은 후보가 여러 명이면, 그 득표수에 **가장 먼저 도달한** 후보가 1위입니다.

`i`번째 표가 들어온 직후의 1위 후보 이름을 `i`번째 원소로 하는 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `votes`의 길이 ≤ 200,000
- 후보 이름은 길이 1 이상 10 이하의 영문 소문자·숫자로만 이루어져 있습니다.

## 입출력 예

| votes | result |
|---|---|
| ["a", "b", "b", "a", "c", "c", "c"] | ["a", "a", "b", "b", "b", "b", "c"] |
| ["p", "q", "p", "q", "q"] | ["p", "p", "p", "p", "q"] |
| ["x"] | ["x"] |

## 입출력 예 설명
- 예 #1
  - 1번째 표: a 1표 → 1위 a
  - 2번째 표: a 1표, b 1표. 1표에 먼저 도달한 a가 1위
  - 3번째 표: b 2표 → b
  - 4번째 표: a 2표, b 2표. 2표에 먼저 도달한 b가 1위
  - 5~6번째 표: c가 1표, 2표가 되지만 b를 넘지 못함
  - 7번째 표: c 3표 → c
- 예 #2: 4번째 표에서 p와 q가 2표로 같지만 p가 먼저 2표에 도달했습니다. 5번째 표에서 q가 3표로 앞섭니다.
