# [lv3] 회문이 되는 블록 쌍

장난감 글자 블록 묶음 `n`개가 있습니다. `i`번 묶음에 들어 있는 글자들을 이어 쓴 문자열이 `blocks[i]`입니다 (글자 순서는 의미가 없습니다).

두 묶음을 골라 블록을 모두 합친 뒤 **적절히 배열하면 회문**(앞뒤로 읽어도 같은 문자열)을 만들 수 있는 묶음 쌍의 수를 return 하도록 `solution` 함수를 완성해 주세요. `i < j`인 쌍 `(i, j)`를 셉니다. 개수는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 2 ≤ `blocks`의 길이 ≤ 200,000
- 각 원소는 길이 1 이상 10 이하의 영문 소문자로만 이루어져 있습니다.

## 입출력 예

| blocks | result |
|---|---|
| ["ab", "ba", "abc", "c", "aa"] | 4 |
| ["a", "a", "a"] | 3 |
| ["xy", "zw"] | 0 |

## 입출력 예 설명
- 예 #1: 가능한 쌍은 (`ab`, `ba`) → `abba`, (`ab`, `abc`) → `abcba`, (`ba`, `abc`) → `abcba`, (`c`, `aa`) → `aca` 네 가지입니다. (`ab`, `aa`)는 `a` 3개, `b` 1개라 홀수 개인 글자가 둘이어서 회문을 만들 수 없습니다.
- 예 #2: 어떤 두 묶음을 합쳐도 `aa`입니다. 세 쌍 모두 됩니다.
- 예 #3: 네 글자가 모두 한 번씩이라 회문이 될 수 없습니다.
