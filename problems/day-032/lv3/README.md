# [lv3] 단체 사진에서 가려지는 쌍

`n`명이 한 줄로 서서 단체 사진을 찍습니다. 사진사는 줄의 **앞**에서 찍고, 맨 앞 사람부터 순서대로 키가 `heights[0]`, `heights[1]`, …, `heights[n − 1]`입니다.

앞에 선 사람 `i`와 뒤에 선 사람 `j` (`i < j`)에 대해, 앞사람이 뒷사람보다 키가 `t` 이상 크면, 즉 `heights[i] − heights[j] ≥ t`이면 **"i가 j를 가린다"**고 합니다. 두 사람 사이에 누가 서 있든 상관없습니다.

키 배열 `heights`와 기준 `t`가 주어질 때, 가리는 (앞사람, 뒷사람) 쌍의 개수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `heights`의 길이 `n` ≤ 500,000
- 1 ≤ `heights`의 원소 ≤ 1,000,000,000
- 0 ≤ `t` ≤ 1,000,000,000
- 쌍의 개수는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 입출력 예

| heights | t | result |
|---|---|---|
| [170, 160, 175, 150] | 10 | 4 |
| [170, 160, 175, 150] | 15 | 2 |
| [150, 150, 150] | 0 | 3 |

## 입출력 예 설명
- 예 #1: (0, 1) 차 10, (0, 3) 차 20, (1, 3) 차 10, (2, 3) 차 25 → 4쌍. (0, 2)와 (1, 2)는 뒷사람이 더 큽니다.
- 예 #2: 차가 15 이상인 쌍은 (0, 3)과 (2, 3)뿐입니다.
- 예 #3: `t = 0`이면 앞사람이 뒷사람 이상이기만 하면 됩니다. 세 쌍 모두 해당합니다.
