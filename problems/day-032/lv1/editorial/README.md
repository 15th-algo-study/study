# 해설 — 가운데부터 호명하기

## 접근
"구간의 가운데를 부르고, 왼쪽 구간을 같은 규칙으로, 오른쪽 구간을 같은 규칙으로"는 그대로 재귀 함수 `call(l, r)`입니다.

1. `l > r`이면 빈 구간이므로 돌아갑니다.
2. `mid = (l + r) / 2` (정수 나눗셈이라 짝수 길이에서 자동으로 왼쪽 가운데)를 결과에 추가합니다.
3. `call(l, mid - 1)`, `call(mid + 1, r)`을 차례로 호출합니다.

구간이 매번 절반으로 줄어들므로 재귀 깊이는 약 log₂(200,000) ≈ 18이고, 학생마다 한 번씩만 추가되어 O(n)입니다. 결과는 인덱스를 하나 들고 배열에 직접 채우면 됩니다.

## 주의할 점
- 배열을 실제로 잘라서(`Arrays.copyOfRange`) 재귀에 넘기면 복사 비용이 매 단계 O(n)씩 들어 O(n log n)이 됩니다. 통과는 하지만 **인덱스 `l`, `r`만 넘기는** 습관을 들이세요.
- 결과를 `ArrayList`에 모아도 되지만, 개수를 미리 알므로 `int[]`에 바로 채우는 편이 빠릅니다.
- `mid`를 `(l + r) / 2`로 계산할 때 `l + r`은 최대 4×10^5라 넘치지 않습니다. 일반적으로는 `l + (r - l) / 2`가 안전한 습관입니다.

## 복잡도
- 시간 O(n), 공간 O(n) (결과) + 재귀 깊이 O(log n)
