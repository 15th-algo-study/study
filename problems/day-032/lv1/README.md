# [lv1] 가운데부터 호명하기

체험학습에 온 학생 `n`명이 한 줄로 서 있고, 왼쪽부터 순서대로 이름표 번호가 `numbers`에 적혀 있습니다. 인솔 선생님은 다음 규칙으로 학생을 한 명씩 호명합니다.

- 어떤 구간의 학생들을 호명할 때는, 먼저 그 구간의 **가운데** 학생을 부릅니다. 구간의 길이가 짝수이면 가운데 두 명 중 **왼쪽** 학생이 가운데입니다.
- 그다음 가운데 학생의 **왼쪽 구간** 전체를 같은 규칙으로 호명하고, 그것이 끝나면 **오른쪽 구간** 전체를 같은 규칙으로 호명합니다.
- 빈 구간은 건너뜁니다.

처음에는 줄 전체가 한 구간입니다. `numbers`가 주어질 때, 호명되는 순서대로 이름표 번호를 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `numbers`의 길이 `n` ≤ 200,000
- 1 ≤ `numbers`의 원소 ≤ 1,000,000,000
- 같은 번호가 여러 번 나올 수 있습니다. 호명 순서는 번호가 아니라 **서 있는 위치**로 정해집니다.

## 입출력 예

| numbers | result |
|---|---|
| [1, 2, 3, 4, 5, 6, 7] | [4, 2, 1, 3, 6, 5, 7] |
| [10, 20, 30, 40] | [20, 10, 30, 40] |
| [9] | [9] |

## 입출력 예 설명
- 예 #1: 전체의 가운데는 4. 왼쪽 구간 `[1, 2, 3]`의 가운데 2, 그 왼쪽 1, 오른쪽 3. 오른쪽 구간 `[5, 6, 7]`도 같은 식으로 6, 5, 7.
- 예 #2: 길이 4의 가운데는 두 번째(20). 왼쪽 구간 `[10]` → 10. 오른쪽 구간 `[30, 40]`의 가운데는 왼쪽인 30, 그 오른쪽 40.
- 예 #3: 한 명이면 그 학생을 부릅니다.
