# 해설 — 리본 똑같이 자르기

## 접근
모든 리본을 남김없이 나누는 조각 길이는 모든 길이의 **공약수**이고, 가장 긴 것은 **최대공약수** `g`입니다. 조각 수는 `(길이 합) / g`입니다.

최대공약수는 유클리드 호제법을 재귀로 씁니다.

> `gcd(a, b)` = `b == 0 ? a : gcd(b, a % b)`

배열 전체의 최대공약수는 `g = gcd(g, ribbons[i])`를 앞에서부터 누적하면 됩니다. `a % b`는 `b`보다 작아지므로 재귀는 금방 끝나고(10^9에서 많아야 45번), 깊이를 걱정할 필요가 없습니다.

## 주의할 점
- 길이 합은 최대 10^5 × 10^9 = 10^14 라 `long`에 누적해야 합니다.
- 리본이 하나뿐이면 `g`는 그 길이 자체이므로 답은 1입니다. 누적의 시작값을 0으로 두면 `gcd(0, x) = x`라 자연스럽게 처리됩니다.
- 조각 수를 리본마다 `ribbons[i] / g`로 더해도 같지만, 합을 먼저 구해 한 번만 나누는 쪽이 간단합니다.

## 복잡도
- 시간 O(n log M) (M = 리본 길이 최댓값), 공간 O(1)
