# [lv0] 리본 똑같이 자르기

길이가 서로 다른 리본 여러 개가 있습니다. 모든 리본을 **남는 부분 없이** 같은 길이의 조각으로 자르려고 합니다. 조각 하나의 길이를 **가능한 한 길게** 할 때, 조각이 모두 몇 개 나오는지 구하려고 합니다.

예를 들어 리본 길이가 12, 18, 30이면 조각 길이를 6으로 해야 가장 길고, 조각은 2 + 3 + 5 = 10개 나옵니다.

리본 길이 배열 `ribbons`가 주어질 때, 조각의 개수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `ribbons`의 길이 ≤ 100,000
- 1 ≤ `ribbons`의 원소 ≤ 1,000,000,000
- 조각의 개수는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 입출력 예

| ribbons | result |
|---|---|
| [12, 18, 30] | 10 |
| [7] | 1 |
| [5, 10, 15, 25] | 11 |

## 입출력 예 설명
- 예 #1: 조각 길이 6 → 2 + 3 + 5 = 10개
- 예 #2: 리본이 하나뿐이면 자르지 않는 것이 가장 깁니다. 1개
- 예 #3: 조각 길이 5 → 1 + 2 + 3 + 5 = 11개
