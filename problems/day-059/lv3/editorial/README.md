# 해설 — 구도심 일방통행 골목

## 접근
"0에서 `v`로 갈 수 있는가"는 0에서 BFS 한 번이면 모든 `v`에 대해 알 수 있습니다. 문제는 "`v`에서 0으로 올 수 있는가"입니다. 교차로마다 BFS 를 돌리면 O(n × (n + m)) ≈ 10^11 로 시간 초과입니다.

**관찰**: 모든 골목의 방향을 뒤집은 **역방향 그래프**에서 "0에서 `v`로 갈 수 있다"는 것은 원래 그래프에서 "`v`에서 0으로 올 수 있다"는 것과 같습니다. 경로 `v → … → 0`을 거꾸로 읽으면 역그래프의 경로 `0 → … → v`이기 때문입니다.

1. 정방향 인접 리스트 `adj`와 역방향 인접 리스트 `rev`를 만듭니다. 골목 `[a, b]`에 대해 `adj[a].add(b)`, `rev[b].add(a)`.
2. `adj`에서 0부터 BFS → `reach[v]` (0에서 갈 수 있는가).
3. `rev`에서 0부터 BFS → `back[v]` (0으로 올 수 있는가).
4. 둘 다 참인 정점의 수가 답입니다.

이렇게 구한 집합은 0번이 속한 **강한 연결 요소**입니다. 일반적인 강한 연결 요소 알고리즘(타잔, 코사라주)은 더 어렵지만, 한 정점이 속한 요소만 필요할 때는 BFS 두 번이면 충분합니다.

## 주의할 점
- 무방향 그래프처럼 양쪽 모두에 간선을 넣으면 안 됩니다. 방향을 구분해 두 리스트를 **따로** 만들어야 합니다.
- 두 BFS 는 같은 코드에 리스트만 바꿔 넣으면 되므로 메서드로 분리하면 깔끔합니다.
- 중복 골목과 `a = b` 골목은 방문 표시 덕분에 결과에 영향이 없습니다.
- 골목이 한 줄로 길게 이어진 입력에서 재귀 DFS 깊이가 n 까지 커질 수 있으므로 큐 기반 BFS 를 권장합니다.

## 복잡도
- 시간 O(n + m), 공간 O(n + m)
