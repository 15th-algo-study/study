# [lv3] 구도심 일방통행 골목

구도심에 교차로 `n`곳이 있고 0번부터 `n-1`번까지 번호가 붙어 있습니다. 교차로 사이의 골목은 모두 **일방통행**이며, 목록이 2차원 배열 `alleys`로 주어집니다. `alleys[i] = [a, b]`는 `a`번 교차로에서 `b`번 교차로로만 갈 수 있는 골목입니다. 같은 골목이 여러 번 나오거나 `a = b`인 골목이 있을 수 있습니다.

0번 교차로에 관광 안내소가 있습니다. 어떤 교차로 `v`가 다음 두 조건을 **모두** 만족하면 "왕복 가능한 교차로"라고 합니다.

- 0번에서 출발해 골목을 따라 `v`에 도착할 수 있다.
- `v`에서 출발해 골목을 따라 0번으로 돌아올 수 있다.

0번 교차로 자신은 항상 왕복 가능한 교차로입니다. 왕복 가능한 교차로의 수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 200,000
- 0 ≤ `alleys`의 길이 ≤ 400,000
- 0 ≤ `a`, `b` < `n`

## 입출력 예

| n | alleys | result |
|---|---|---|
| 5 | [[0, 1], [1, 2], [2, 0], [2, 3], [3, 4]] | 3 |
| 3 | [[1, 0], [2, 1]] | 1 |
| 4 | [[0, 1], [1, 0], [2, 3], [3, 2]] | 2 |

## 입출력 예 설명
- 예 #1: 0 → 1 → 2 → 0 으로 0, 1, 2는 왕복할 수 있습니다. 3과 4는 갈 수는 있지만 돌아올 골목이 없습니다.
- 예 #2: 1과 2에서 0으로 올 수는 있지만 0에서 그곳으로 갈 수 없습니다. 0번만 셉니다.
- 예 #3: 0과 1은 서로 오갈 수 있고, 2와 3은 0에서 갈 수 없습니다.
