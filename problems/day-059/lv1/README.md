# [lv1] 트램 노선의 모양

어느 도시의 트램 정류장 `n`곳에 0번부터 `n-1`번까지 번호를 붙였습니다. 정류장 사이의 선로 목록이 두 배열 `from`, `to`로 주어집니다. `i`번째 선로는 `from[i]`번 정류장과 `to[i]`번 정류장을 직접 잇고, 양방향으로 다닐 수 있습니다.

노선망 전체의 모양을 다음 세 가지로 분류하려고 합니다.

- `"LINE"`: 모든 정류장이 **한 줄**로 이어져 있다. 즉 양 끝 두 정류장에는 선로가 하나씩, 나머지 정류장에는 선로가 둘씩 연결되어 있고, 어떤 정류장에서든 다른 모든 정류장으로 갈 수 있다. 정류장이 하나뿐이고 선로가 없는 경우도 `"LINE"`이다.
- `"RING"`: 모든 정류장이 **하나의 고리**로 이어져 있다. 즉 정류장이 3곳 이상이고, 모든 정류장에 선로가 정확히 둘씩 연결되어 있으며, 어떤 정류장에서든 다른 모든 정류장으로 갈 수 있다.
- `"NONE"`: 둘 다 아니다.

노선망의 모양을 나타내는 문자열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 200,000
- 0 ≤ `from`의 길이 = `to`의 길이 ≤ 200,000
- 0 ≤ `from[i]`, `to[i]` < `n`
- 같은 두 정류장을 잇는 선로가 여러 개 있거나 `from[i] = to[i]`인 선로가 있을 수 있습니다. 그런 선로도 정류장에 연결된 선로 수에 포함됩니다 (`from[i] = to[i]`이면 그 정류장에 2개로 셉니다).

## 입출력 예

| n | from | to | result |
|---|---|---|---|
| 4 | [2, 1, 0] | [0, 3, 1] | "LINE" |
| 3 | [0, 1, 2] | [1, 2, 0] | "RING" |
| 5 | [0, 1, 3] | [1, 2, 4] | "NONE" |

## 입출력 예 설명
- 예 #1: 선로는 2–0, 1–3, 0–1 입니다. 2–0–1–3 순서로 한 줄로 이어집니다.
- 예 #2: 0–1–2–0 으로 고리를 이룹니다.
- 예 #3: 0–1–2 와 3–4 두 덩어리로 나뉘어 있어 어느 쪽도 아닙니다.
