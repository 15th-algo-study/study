# 해설 — 트램 노선의 모양

## 접근
두 가지를 확인하면 됩니다. **(1) 각 정류장에 연결된 선로 수(차수)의 조건**과 **(2) 모든 정류장이 하나로 이어져 있는지(연결성)**.

1. 인접 리스트를 만들면서 차수 `deg[v]`를 셉니다. `from[i] = to[i]`인 선로는 `adj[v]`에 두 번 들어가 차수 2가 됩니다.
2. 선로 수 `m`과 차수로 후보를 고릅니다.
   - `LINE` 후보: `m == n - 1`이고, 차수 1인 정류장이 정확히 2개, 나머지는 모두 차수 2. (`n = 1`, `m = 0`이면 바로 `LINE`. `n = 2`, `m = 1`이면 두 정류장 모두 차수 1.)
   - `RING` 후보: `n ≥ 3`, `m == n`이고 모든 정류장의 차수가 2.
   - 그 밖에는 `NONE`.
3. 후보가 되었으면 0번에서 BFS 를 돌려 **n개 정류장을 모두 방문하는지** 확인합니다. 모두 방문하면 후보대로, 아니면 `NONE`.

차수 조건만으로는 부족합니다. 고리 두 개(예: 0–1–2–0 과 3–4–5–3)는 모든 차수가 2이고 `m == n`이지만 하나의 고리가 아닙니다. 연결성 확인이 꼭 필요합니다.

## 주의할 점
- `m == n - 1`과 차수 조건을 먼저 확인하면, 연결성 확인 때는 "선로 수가 정류장 수보다 작은 연결 그래프 = 트리"라는 사실 덕분에 중복 선로를 따로 걱정하지 않아도 됩니다. 중복 선로나 자기 자신 선로가 있으면 어딘가 차수가 어긋나거나 연결이 끊깁니다.
- `n = 2`에서 같은 두 정류장을 잇는 선로가 2개면 차수가 둘 다 2이고 `m == n`이지만, 고리는 정류장 3곳 이상이어야 하므로 `NONE`입니다.
- 연결성은 BFS 로 확인하세요. 재귀 DFS 는 선로가 한 줄로 20만 개 이어진 입력(`LINE` 자체가 그렇습니다)에서 재귀 깊이가 20만이 되어 환경에 따라 스택이 넘칠 수 있습니다.

## 복잡도
- 시간 O(n + m), 공간 O(n + m)
