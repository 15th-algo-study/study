# [lv0] 다랑논에 물이 고이는 칸

산비탈의 다랑논을 격자로 나누어 각 칸의 높이를 2차원 배열 `paddy`에 적었습니다. `paddy[r][c]`는 (r, c) 칸의 높이입니다.

비가 오면 물은 낮은 곳으로 흐릅니다. 어떤 칸이 **상하좌우로 붙어 있는 모든 칸보다 높이가 낮으면** 그 칸에 물이 고입니다. 격자 밖은 생각하지 않으므로, 가장자리 칸은 격자 안에 있는 이웃만 비교합니다. 이웃 중 하나라도 높이가 같거나 낮으면 물이 고이지 않습니다.

물이 고이는 칸의 수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `paddy`의 줄 수, 각 줄의 칸 수 ≤ 1,000
- 모든 줄의 칸 수는 같습니다.
- 1 ≤ `paddy[r][c]` ≤ 1,000,000

## 입출력 예

| paddy | result |
|---|---|
| [[3, 1, 3], [2, 5, 2], [3, 1, 3]] | 4 |
| [[1, 1], [1, 1]] | 0 |
| [[5]] | 1 |

## 입출력 예 설명
- 예 #1: (0,1), (1,0), (1,2), (2,1)의 네 칸은 각각 이웃이 모두 자기보다 높습니다. 모서리의 3들은 이웃에 1이나 2가 있어 고이지 않고, 가운데 5는 가장 높습니다.
- 예 #2: 높이가 모두 같아 "더 낮은" 칸이 없습니다.
- 예 #3: 칸이 하나뿐이면 비교할 이웃이 없으므로 물이 고입니다.
