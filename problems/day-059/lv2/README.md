# [lv2] 스위치 루프 찾기

사무실에 네트워크 스위치 `n`대가 있고 0번부터 `n-1`번까지 번호가 붙어 있습니다. 스위치 사이에 연결된 케이블 목록이 2차원 배열 `cables`로 주어집니다. `cables[i] = [a, b]`는 `a`번과 `b`번 스위치를 잇는 케이블 하나입니다. 같은 두 스위치 사이에 케이블이 여러 개 꽂혀 있을 수도 있고, 실수로 한 스위치의 두 포트를 같은 케이블로 이은 경우(`a = b`)도 있습니다.

케이블로 서로 이어진 스위치들의 묶음을 **네트워크**라고 합니다. 어떤 네트워크 안에서 **같은 케이블을 두 번 쓰지 않고** 어떤 스위치에서 출발해 다시 그 스위치로 돌아오는 경로가 있으면, 그 네트워크에는 **루프**가 있다고 합니다. 같은 두 스위치를 잇는 케이블 두 개는 (한 케이블로 갔다가 다른 케이블로 돌아오므로) 루프이고, `a = b`인 케이블도 루프입니다.

루프가 있는 네트워크의 수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 500,000
- 0 ≤ `cables`의 길이 ≤ 500,000
- 0 ≤ `a`, `b` < `n`

## 입출력 예

| n | cables | result |
|---|---|---|
| 6 | [[0, 1], [1, 2], [2, 0], [3, 4]] | 1 |
| 4 | [[0, 1], [1, 0]] | 1 |
| 5 | [[0, 1], [1, 2], [2, 0], [3, 3]] | 2 |

## 입출력 예 설명
- 예 #1: 네트워크는 {0, 1, 2}, {3, 4}, {5}입니다. 0–1–2–0 이 루프이고 나머지 둘에는 루프가 없습니다.
- 예 #2: 0번과 1번 사이에 케이블이 두 개라 루프입니다. 2번, 3번은 혼자이며 루프가 없습니다.
- 예 #3: {0, 1, 2}의 루프와 3번의 자기 자신 케이블 루프로 2개입니다.
