# 해설 — 스위치 루프 찾기

## 접근
연결 요소마다 "루프가 있는가"를 판단해야 합니다. **관찰**: 정점 `V`개가 모두 이어진 연결 요소에서 간선이 `V - 1`개이면 트리(루프 없음)이고, 간선이 `V`개 이상이면 반드시 루프가 있습니다. 중복 케이블과 자기 자신 케이블도 간선으로 세면 이 규칙이 그대로 맞습니다.

1. 인접 리스트를 만듭니다. 자기 자신 케이블 `[a, a]`도 `adj[a]`에 넣습니다 (두 번 들어갑니다).
2. 방문하지 않은 정점마다 BFS 로 요소를 돌며 **정점 수 `V`** 와 **인접 리스트 길이의 합 `D`** 를 더합니다. 간선 하나가 양 끝에서 한 번씩 세어지므로 간선 수 `E = D / 2`입니다 (자기 자신 케이블도 `adj[a]`에 두 번 들어가 2로 세어집니다).
3. `E >= V`이면 루프가 있는 요소입니다.

DFS 중 "부모가 아닌 이미 방문한 정점을 만나면 루프"로 판별해도 되지만, 중복 케이블(부모로 되돌아가는 두 번째 간선)을 루프로 인식하려면 **간선 번호**로 부모 간선을 구별해야 해서 번거롭습니다. 개수 세기가 훨씬 단순하고 안전합니다.

## 주의할 점
- 간선 수를 셀 때 각 정점의 인접 리스트 길이를 더하면 모든 간선이 정확히 두 번 세어집니다. 자기 자신 케이블은 `adj[a].add(a)`를 두 번 하므로 역시 두 번 세어집니다. 한 번만 넣었다면 홀수가 나와 2로 나눌 때 어긋납니다.
- "부모 정점으로 돌아가지 않기"만으로 루프를 판별하면 `[0, 1], [1, 0]` 같은 중복 케이블을 루프로 잡지 못합니다. 예 #2가 이 경우입니다.
- 스위치가 한 줄로 길게 이어진 요소에서 재귀 DFS 깊이는 50만에 이를 수 있습니다. 큐를 쓰는 BFS 로 작성하세요.

## 복잡도
- 시간 O(n + m), 공간 O(n + m)
