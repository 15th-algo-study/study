# [lv0] 두 대각선의 합

`n × n` 정사각 행렬 `matrix`가 주어집니다. 왼쪽 위에서 오른쪽 아래로 가는 대각선과, 오른쪽 위에서 왼쪽 아래로 가는 대각선 위에 있는 수를 모두 더한 값을 return 하도록 `solution` 함수를 완성해 주세요. 두 대각선이 겹치는 칸(가운데 칸)은 **한 번만** 더합니다.

## 제한사항
- 1 ≤ `n` ≤ 1,000
- `matrix`는 `n × n` 크기입니다.
- -100 ≤ `matrix`의 원소 ≤ 100

## 입출력 예

| matrix | result |
|---|---|
| [[1, 2, 3], [4, 5, 6], [7, 8, 9]] | 25 |
| [[1, 2], [3, 4]] | 10 |

## 입출력 예 설명
- 예 #1: 1 + 5 + 9 + 3 + 7 = 25. 가운데 5는 한 번만 더합니다.
- 예 #2: 1 + 4 + 2 + 3 = 10. 크기가 짝수면 겹치는 칸이 없습니다.
