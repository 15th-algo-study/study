# [lv3] 벽화 덧칠

`rows × cols` 크기의 벽이 있고, 모든 칸의 물감 두께는 0입니다. 작업 목록 `ops`의 각 작업 `[r1, c1, r2, c2, v]`는 두 꼭짓점 칸 (r1, c1)과 (r2, c2)를 마주 보는 모서리로 하는 직사각형 안의 모든 칸에 두께 `v`를 더합니다. `v`가 음수면 그만큼 긁어냅니다(두께는 음수가 될 수도 있습니다). 두 꼭짓점은 어느 쪽이 위·왼쪽인지 정해져 있지 않습니다.

모든 작업이 끝난 뒤 **가장 두꺼운 두께**와 **그 두께인 칸의 개수**를 `[두께, 개수]`로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `rows`, `cols` ≤ 1,000
- 1 ≤ `ops`의 길이 ≤ 200,000
- `ops`의 원소는 `[r1, c1, r2, c2, v]` 형태입니다.
  - 0 ≤ `r1`, `r2` < `rows`, 0 ≤ `c1`, `c2` < `cols`
  - -1,000 ≤ `v` ≤ 1,000
- 결과는 `long[]`로 return 합니다.

## 입출력 예

| rows | cols | ops | result |
|---|---|---|---|
| 3 | 3 | [[0, 0, 1, 1, 2], [1, 1, 2, 2, 3]] | [5, 1] |
| 2 | 3 | [[1, 2, 0, 0, -1]] | [-1, 6] |
| 2 | 2 | [[0, 0, 0, 0, 5], [1, 1, 1, 1, 5], [0, 1, 1, 0, -5]] | [0, 2] |

## 입출력 예 설명
- 예 #1: 두 직사각형이 겹치는 (1, 1)만 2 + 3 = 5입니다.
- 예 #2: 꼭짓점 (1, 2)와 (0, 0)이 이루는 직사각형은 벽 전체입니다. 6칸 모두 -1입니다.
- 예 #3: 세 번째 작업의 꼭짓점 (0, 1), (1, 0)도 벽 전체를 덮습니다. (0,0)과 (1,1)은 5 - 5 = 0, 나머지 두 칸은 -5입니다.
