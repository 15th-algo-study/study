# 해설 — 벽화 덧칠

## 접근
작업마다 직사각형 안을 직접 칠하면 작업 하나에 최대 10^6칸, 전체 2×10^11번이라 시간 초과입니다. **2차원 차분 배열**로 작업 하나를 O(1)에 기록하고 마지막에 한 번만 복원합니다.

1. 정규화: `top = min(r1, r2)`, `bottom = max(r1, r2)`, `left`, `right`도 마찬가지.
2. 기록: 크기 `(rows+1) × (cols+1)` 배열에
   - `(top, left) += v`, `(top, right+1) -= v`, `(bottom+1, left) -= v`, `(bottom+1, right+1) += v`
3. 복원: 각 행을 가로로 누적한 뒤, 각 열을 세로로 누적하면 칸의 실제 값이 됩니다.
4. 전체를 훑어 최댓값과 그 개수를 셉니다.

### 왜 되는가
1차원에서 `[l, r]`에 v를 더하는 것은 `d[l] += v, d[r+1] -= v` 후 누적합과 같습니다. 2차원은 이것을 가로·세로 두 번 적용한 것이고, 네 모서리 표시는 포함–배제로 직사각형 바깥의 효과를 지웁니다.

## 주의할 점
- **꼭짓점 순서 정규화**를 빼먹으면 예 #2, #3처럼 거꾸로 주어진 작업에서 틀립니다.
- 배열을 한 칸씩 크게 잡아야 `right + 1`, `bottom + 1`이 범위를 넘지 않습니다.
- 칸 값은 최대 2×10^5 × 1,000 = 2×10^8이라 `int`로도 담기지만, 결과 타입에 맞춰 `long`을 썼습니다.
- 최댓값 초기값을 0으로 두면 모든 칸이 음수일 때(예 #2) 틀립니다.

## 복잡도
- 시간 O(Q + R·C), 공간 O(R·C)
