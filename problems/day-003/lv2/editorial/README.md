# 해설 — 거울 미로의 레이저

## 접근
레이저를 한 칸씩 따라가는 시뮬레이션입니다. 방향을 0~3 정수로 두고, 거울마다 "들어온 방향 → 나가는 방향" 표를 만들어 두면 조건문이 단순해집니다.

| 들어온 방향 | `/` | `\` |
|---|---|---|
| 위(0) | 오른쪽(1) | 왼쪽(3) |
| 오른쪽(1) | 위(0) | 아래(2) |
| 아래(2) | 왼쪽(3) | 오른쪽(1) |
| 왼쪽(3) | 아래(2) | 위(0) |

칸에 들어갈 때마다 처음이면 `count++`, 거울이면 방향을 바꾸고 다음 칸으로 갑니다. 방 밖으로 나가면 끝입니다.

## 왜 끝나는가
레이저의 상태는 (칸, 방향) 쌍이고, 각 상태의 다음 상태와 이전 상태가 하나로 정해집니다(되돌려 추적할 수 있음). 그래서 바깥에서 들어온 경로는 순환에 갇힐 수 없고, 같은 (칸, 방향)을 두 번 지나지 않습니다. 따라서 이동 횟수는 최대 4·R·C입니다.

## 주의할 점
- 재귀로 한 칸씩 따라가면 경로 길이(최대 400만)만큼 호출이 쌓여 `StackOverflowError`가 납니다. 반복문을 쓰세요.
- 자바 문자 리터럴에서 역슬래시는 `'\\'`로 씁니다.
- 같은 칸을 여러 번 지날 수 있으므로 방문 배열로 중복을 거릅니다.

## 복잡도
- 시간 O(R·C), 공간 O(R·C)
