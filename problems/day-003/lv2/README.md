# [lv2] 거울 미로의 레이저

직사각형 방이 문자열 배열 `grid`로 주어집니다. 각 칸은 다음 중 하나입니다.

- `'.'`: 빈 칸. 레이저는 방향을 바꾸지 않고 지나갑니다.
- `'/'`: 거울. 오른쪽으로 가던 레이저는 위로, 위로 가던 레이저는 오른쪽으로, 왼쪽으로 가던 레이저는 아래로, 아래로 가던 레이저는 왼쪽으로 꺾입니다.
- `'\'`: 거울. 오른쪽 → 아래, 아래 → 오른쪽, 왼쪽 → 위, 위 → 왼쪽으로 꺾입니다.

레이저는 방 왼쪽 바깥에서 맨 위 왼쪽 칸 (0, 0)으로 **오른쪽 방향**으로 들어옵니다. 레이저가 방 밖으로 나갈 때까지 지나간 **서로 다른 칸의 개수**를 return 하도록 `solution` 함수를 완성해 주세요. 거울이 있는 칸도 지나간 칸으로 셉니다. 같은 칸을 여러 번 지나도 한 번만 셉니다.

## 제한사항
- 1 ≤ `grid`의 길이(행 수) ≤ 1,000
- 1 ≤ `grid[r]`의 길이(열 수) ≤ 1,000, 모든 행의 길이는 같습니다.
- `grid`는 `'.'`, `'/'`, `'\'`로만 이루어져 있습니다.
- 바깥에서 들어온 레이저는 언제나 유한한 시간 안에 방 밖으로 나갑니다.

## 입출력 예

| grid | result |
|---|---|
| [".\\.", "...", "./."] | 5 |
| ["/.."] | 1 |
| ["..\\", "...", "\\./"] | 8 |

표의 `"\\"`는 자바 문자열 표기로, 실제 글자는 `\` 하나입니다.

## 입출력 예 설명
- 예 #1: (0,0) → (0,1)의 `\`에서 아래로 → (1,1) → (2,1)의 `/`에서 왼쪽으로 → (2,0) → 밖. 5칸입니다.
- 예 #2: 첫 칸의 `/`에서 위로 꺾여 바로 밖으로 나갑니다.
- 예 #3: 오른쪽 위 `\`에서 아래로, 오른쪽 아래 `/`에서 왼쪽으로, 왼쪽 아래 `\`에서 위로 꺾여 (1,0), (0,0)을 지나 위로 나갑니다. (0,0)은 두 번 지나지만 한 번만 세어 8칸입니다.
