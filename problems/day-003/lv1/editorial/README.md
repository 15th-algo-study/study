# 해설 — 지뢰 숫자판

## 접근
칸마다 8방향 이웃을 확인해 지뢰를 셉니다. 방향은 `DR`, `DC` 배열로 만들어 두면 반복문 하나로 처리할 수 있습니다.

결과 행은 `char[]`에 채운 뒤 `new String(char[])`로 만듭니다.

## 주의할 점
- 가장자리 칸의 이웃은 판 밖일 수 있으므로 **범위 검사를 먼저** 해야 합니다.
- 숫자를 문자로 바꿀 때 `(char) ('0' + mines)`를 씁니다. `(char) mines`는 제어 문자가 됩니다.
- 행마다 `String`에 `+=`로 한 글자씩 붙이면 1000×1000에서 느려집니다. `char[]`나 `StringBuilder`를 쓰세요.
- 지뢰 하나에서 주변 8칸에 +1을 뿌리는 방법도 같은 복잡도입니다.

## 복잡도
- 시간 O(R·C), 공간 O(R·C)
