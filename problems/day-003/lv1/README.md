# [lv1] 지뢰 숫자판

지뢰 찾기 게임판이 문자열 배열 `board`로 주어집니다. `'*'`는 지뢰, `'.'`는 빈 칸입니다. 모든 빈 칸을, 그 칸을 둘러싼 **8방향 이웃 칸에 있는 지뢰의 개수**(`'0'`~`'8'`)로 바꾼 게임판을 return 하도록 `solution` 함수를 완성해 주세요. 지뢰 칸은 `'*'` 그대로 둡니다.

## 제한사항
- 1 ≤ `board`의 길이(행 수) ≤ 1,000
- 1 ≤ `board[r]`의 길이(열 수) ≤ 1,000, 모든 행의 길이는 같습니다.
- `board`는 `'*'`와 `'.'`으로만 이루어져 있습니다.

## 입출력 예

| board | result |
|---|---|
| ["*..", "...", "..*"] | ["*10", "121", "01*"] |
| ["***", "*.*", "***"] | ["***", "*8*", "***"] |

## 입출력 예 설명
- 예 #1: 가운데 칸은 왼쪽 위와 오른쪽 아래 지뢰 두 개와 이웃합니다. 맨 위 오른쪽 칸은 이웃에 지뢰가 없습니다.
- 예 #2: 가운데 칸은 8방향 모두 지뢰입니다.
