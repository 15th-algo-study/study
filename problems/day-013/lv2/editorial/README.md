# 해설 — 저울추 두 개 고르기

## 접근
추를 왼쪽부터 하나씩 보면서, "지금 추 `w`와 짝이 되려면 앞에 `target - w`짜리 추가 있어야 한다"고 생각합니다. 앞에서 본 무게별 개수를 `HashMap<Integer, Integer>`에 들고 있으면

1. `answer += map.get(target - w)` (없으면 0)
2. `map`에 `w`를 하나 더한다

를 순서대로 하면 끝입니다. 각 쌍은 **뒤쪽 추를 볼 때 정확히 한 번** 세어지므로 순서 중복도, 자기 자신과 짝짓는 일도 생기지 않습니다.

## 주의할 점
- 모든 쌍을 보는 O(n²)은 40만 개에서 8×10^10 번이라 시간 초과입니다.
- 무게별 개수를 다 센 뒤 `cnt[w] × cnt[target - w]`를 더하는 방법도 되지만, 그러면 쌍이 두 번씩 세어지고 `w = target - w`(예 #2)인 경우는 `cnt × (cnt - 1) / 2`로 따로 처리해야 합니다. "먼저 세고 나중에 넣기" 한 줄이 이 두 함정을 모두 피합니다.
- 답은 최대 n(n-1)/2 ≈ 8×10^10이므로 `long`입니다.
- `target - w`는 음수가 될 수 있지만 맵에 없을 뿐이니 문제없습니다.

## 복잡도
- 시간 O(n), 공간 O(n)
