# [lv2] 저울추 두 개 고르기

실험실 서랍에 저울추가 여러 개 있고, `i`번 추의 무게는 `weights[i]`입니다. 서랍에서 추 **두 개**를 골라 무게 합이 정확히 `target`이 되게 하려고 합니다.

고르는 방법의 수를 return 하도록 `solution` 함수를 완성해 주세요. 추는 서로 다른 물건이므로 무게가 같아도 다른 추이며, 고르는 순서는 구분하지 않습니다. 즉 `i < j`인 쌍 `(i, j)` 중 `weights[i] + weights[j] = target`인 것의 개수입니다. 개수는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `weights`의 길이 ≤ 400,000
- 1 ≤ `weights`의 원소 ≤ 1,000,000,000
- 2 ≤ `target` ≤ 1,000,000,000

## 입출력 예

| weights | target | result |
|---|---|---|
| [1, 5, 3, 3, 5, 2] | 6 | 3 |
| [4, 4, 4, 4] | 8 | 6 |
| [10, 20, 30] | 100 | 0 |

## 입출력 예 설명
- 예 #1: 1과 5(1번 추), 1과 5(4번 추), 3과 3 → 3가지입니다. 5와 1을 고르는 것은 1과 5를 고르는 것과 같은 방법입니다.
- 예 #2: 네 개 중 두 개를 고르는 모든 방법 6가지가 합 8입니다.
- 예 #3: 합이 100이 되는 쌍이 없습니다.
