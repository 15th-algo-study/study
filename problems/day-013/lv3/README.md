# [lv3] 입고 횟수 질의

물류 창고에 물건이 하나씩 들어온 기록이 배열 `items`로 주어집니다. `items[i]`는 `i`번째(0번부터 셈)로 들어온 물건의 품목 번호입니다.

관리자가 질의 여러 개를 보냈습니다. 각 질의 `queries[k] = [l, r, x]`는 "`l`번째부터 `r`번째까지의 입고 기록 중 품목 번호가 `x`인 것은 몇 건인가?"를 뜻합니다 (양 끝 포함).

질의 순서대로 답을 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `items`의 길이 `n` ≤ 200,000
- 1 ≤ `items`의 원소 ≤ 1,000,000,000
- 1 ≤ `queries`의 길이 ≤ 200,000
- 각 질의는 `[l, r, x]`이며 0 ≤ `l` ≤ `r` < `n`, 1 ≤ `x` ≤ 1,000,000,000

## 입출력 예

| items | queries | result |
|---|---|---|
| [7, 3, 7, 7, 5, 3] | [[0, 5, 7], [1, 3, 7], [2, 2, 3], [0, 5, 9]] | [3, 2, 0, 0] |
| [1, 1, 1] | [[0, 0, 1], [0, 2, 1], [1, 2, 2]] | [1, 3, 0] |
| [5] | [[0, 0, 5], [0, 0, 6]] | [1, 0] |

## 입출력 예 설명
- 예 #1: 전체에서 7은 3건, 1~3번에서 7은 2건(2번, 3번), 2번 기록은 7이라 3은 0건, 9는 한 번도 들어오지 않았습니다.
- 예 #2: 1이 세 번 들어왔습니다. 2는 없습니다.
- 예 #3: 기록이 하나뿐입니다.
