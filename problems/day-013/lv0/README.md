# [lv0] 빠진 번호표

은행 창구에서 1번부터 `n`번까지 번호표를 순서대로 뽑아 갔습니다. 하루가 끝나고 회수된 번호표의 번호가 배열 `tickets`에 담겨 있습니다. 같은 번호가 두 번 회수되는 일은 없습니다.

회수되지 않은 번호를 **오름차순**으로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 모두 회수되었다면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `n` ≤ 1,000,000
- 0 ≤ `tickets`의 길이 ≤ `n`
- `tickets`의 원소는 1 이상 `n` 이하의 서로 다른 정수입니다.

## 입출력 예

| n | tickets | result |
|---|---|---|
| 6 | [2, 5, 1] | [3, 4, 6] |
| 3 | [3, 1, 2] | [] |
| 4 | [] | [1, 2, 3, 4] |

## 입출력 예 설명
- 예 #1: 1, 2, 5번이 돌아왔으므로 3, 4, 6번이 빠졌습니다.
- 예 #2: 모두 돌아왔습니다.
- 예 #3: 하나도 돌아오지 않았습니다.
