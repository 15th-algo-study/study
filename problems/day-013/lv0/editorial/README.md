# 해설 — 빠진 번호표

## 접근
번호는 1부터 `n`까지라고 범위가 정해져 있으니, 크기 `n + 1`인 `boolean` 배열 `returned`를 만들어 회수된 번호에 표시합니다. 그다음 1부터 `n`까지 차례로 보며 표시가 없는 번호를 모으면 자동으로 오름차순이 됩니다.

답의 개수는 `n - tickets.length`로 미리 알 수 있으므로 그 크기의 배열을 만들어 채우면 `List`가 필요 없습니다.

## 주의할 점
- 번호마다 `tickets`를 끝까지 뒤지면 O(n²)으로 100만 개에서 시간 초과입니다.
- 배열 크기를 `n`으로 잡으면 `n`번 번호에서 인덱스 초과가 납니다. `n + 1`로 잡고 0번은 비워 두세요.
- `tickets`가 비어 있을 수도 있고, 답이 빈 배열일 수도 있습니다.

## 복잡도
- 시간 O(n), 공간 O(n)
