# [lv1] 가장 오래 기다린 재관람

영화 애호가가 매일 영화 한 편을 봅니다. `i`번째 날(0번부터 셈)에 본 영화 제목이 `movies[i]`입니다. 전에 본 영화를 다시 보는 것을 **재관람**이라 하고, 재관람의 **대기 일수**는 그 영화를 **직전에 본 날**과의 날짜 차이입니다. 예를 들어 0번 날과 3번 날에 같은 영화를 봤다면 3번 날의 재관람은 대기 일수가 3입니다.

모든 재관람 중 대기 일수의 최댓값을 return 하도록 `solution` 함수를 완성해 주세요. 재관람이 한 번도 없으면 0을 return 합니다. 제목은 대소문자를 구분합니다.

## 제한사항
- 1 ≤ `movies`의 길이 ≤ 200,000
- 제목은 길이 1 이상 20 이하의 영문 대소문자·숫자로만 이루어져 있습니다.

## 입출력 예

| movies | result |
|---|---|
| ["up", "cars", "up", "soul", "cars", "up"] | 3 |
| ["a", "b", "c"] | 0 |
| ["x", "x", "x"] | 1 |

## 입출력 예 설명
- 예 #1: `up`은 0, 2, 5번 날에 봤으므로 재관람 대기 일수는 2, 3입니다. `cars`는 1, 4번 날이라 3입니다. 최댓값은 3입니다.
- 예 #2: 재관람이 없습니다.
- 예 #3: 매일 같은 영화를 봐서 대기 일수는 늘 1입니다.
