# 해설 — 가장 오래 기다린 재관람

## 접근
영화마다 "마지막으로 본 날"만 기억하면 됩니다. `HashMap<String, Integer>`에 제목 → 마지막으로 본 날을 저장하고, 날짜 순으로 보며

1. 제목이 맵에 있으면 `오늘 - 마지막 날`을 답 후보로 삼습니다.
2. 맵의 값을 오늘로 갱신합니다 (`put`은 있든 없든 덮어씁니다).

## 주의할 점
- "처음 본 날"과의 차이가 아니라 **직전에 본 날**과의 차이입니다. 값을 갱신하지 않고 처음 날만 남기면 틀립니다 (`["k","k","z","z","z","z","k"]`에서 답은 5이지 6이 아닙니다).
- 영화마다 앞쪽을 거슬러 찾는 O(n²)은 시간 초과입니다.
- 재관람이 없으면 0을 return 해야 하므로 답의 초깃값을 0으로 둡니다.

## 복잡도
- 시간 O(n), 공간 O(영화 종류 수)
