# 해설 — 공항 수하물 로봇

## 접근
칸마다 BFS를 돌려 가장 가까운 출구를 찾으면 칸 하나에 O(칸 수), 전체 O((칸 수)²)라 100만 칸에서는 불가능합니다.

**관찰 1 — 거꾸로 보기**: "칸 `u`에서 출구까지의 최단 거리"는 "출구에서 출발해 간선을 **거꾸로** 따라가 `u`에 닿는 최단 거리"와 같습니다. 이동이 한쪽으로만 가능한(컨베이어) 칸이 있어도, 간선 방향만 뒤집으면 됩니다.

**관찰 2 — 출구는 한꺼번에**: 가장 가까운 출구까지의 거리이므로 모든 출구를 거리 0으로 큐에 함께 넣고 BFS를 한 번 돌립니다(다중 시작점 BFS).

거꾸로 따라가는 규칙: 큐에서 꺼낸 칸 `v`의 상하좌우 이웃 `u`가 **`u`에서 `v`로 한 번에 움직일 수 있으면** `dist[u] = dist[v] + 1`입니다.
- `u`가 `.`이면 항상 가능
- `u`가 컨베이어면 화살표가 `v`를 가리킬 때만 가능
- `u`가 기둥이면 불가능

인접 리스트를 따로 만들 필요 없이, 이웃 4칸을 보며 "그 칸이 나를 가리키는가"만 확인하면 역방향 간선이 됩니다. BFS가 끝난 뒤 `dist`가 있는 칸은 더하고, 없는 칸은 도착할 수 없는 칸으로 셉니다.

## 주의할 점
- 출구에서 **정방향** 이웃을 따라가면 틀립니다. 예 #3에서 (0,1)의 컨베이어는 출구와 붙어 있지만 출구 반대쪽을 가리키므로 거리 1이 아니라 5입니다.
- 화살표가 기둥이나 밖을 가리키는 칸, 화살표끼리 빙빙 도는 칸은 출구로 가는 간선이 없어 자연스럽게 `dist = -1`로 남습니다.
- 칸마다 BFS를 하면서 출구를 만나면 멈추는 방식도, 출구가 멀거나 하나뿐이면 결국 칸마다 격자 대부분을 훑게 되어 시간 초과입니다.
- 거리의 합은 최대 약 (10^6)² / 2 수준이라 `long`이 필요합니다.

## 복잡도
- 시간 O(rows × cols), 공간 O(rows × cols)
