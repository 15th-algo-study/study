# [lv3] 공항 수하물 로봇

공항 수하물 처리장의 바닥을 격자 모양의 지도 `floor`로 나타냈습니다. `floor[r]`의 `c`번째 문자가 (r, c) 칸이며, 각 문자의 뜻은 다음과 같습니다.

- `E`: 짐을 내려놓는 출구 칸
- `.`: 평범한 바닥. 이 칸에서는 상하좌우 어느 쪽으로든 한 칸 움직일 수 있습니다.
- `>`, `<`, `^`, `v`: 컨베이어 벨트. 이 칸에 있는 로봇은 **화살표 방향으로만** 한 칸 움직일 수 있습니다. (`>` 오른쪽, `<` 왼쪽, `^` 위, `v` 아래)
- `#`: 기둥. 들어갈 수 없습니다.

로봇은 한 번에 한 칸씩 움직이며, 처리장 밖이나 기둥 칸으로는 움직일 수 없습니다. 컨베이어 칸에는 어느 방향에서든 들어갈 수 있습니다. 화살표가 처리장 밖이나 기둥을 가리키는 컨베이어 칸에 들어가면 로봇은 그곳에서 더 움직일 수 없습니다. 로봇이 어느 출구 칸에든 도착하면 일을 마칩니다.

출구도 기둥도 아닌 **모든 칸 각각에** 로봇을 하나씩 놓는다고 할 때, 그 칸에서 가장 가까운 출구까지의 최소 이동 횟수를 생각합니다. 다음 두 값을 차례로 담은 `long` 배열을 return 하도록 `solution` 함수를 완성해 주세요.

1. 출구에 도착할 수 있는 칸들의 최소 이동 횟수를 모두 더한 값
2. 어느 출구에도 도착할 수 없는 칸의 수

## 제한사항
- 1 ≤ `floor`의 길이 ≤ 1,000
- 1 ≤ 각 `floor[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같습니다.
- `floor`는 `E`, `.`, `>`, `<`, `^`, `v`, `#`로만 이루어집니다. 출구가 하나도 없을 수도 있습니다.

## 입출력 예

| floor | result |
|---|---|
| [".>E", "..^"] | [9, 0] |
| ["E<.", "#v>"] | [3, 2] |
| ["E>.", "..."] | [15, 0] |

## 입출력 예 설명
- 예 #1: (0,1)과 (1,2)의 컨베이어는 출구를 바로 가리켜 1번, (0,0)과 (1,1)은 2번, (1,0)은 3번이면 출구에 갑니다. 1 + 1 + 2 + 2 + 3 = 9입니다.
- 예 #2: (0,1)은 1번, (0,2)는 왼쪽 컨베이어를 거쳐 2번입니다. (1,1)과 (1,2)의 컨베이어는 처리장 밖을 가리켜 움직일 수 없습니다. 합은 3, 도착할 수 없는 칸은 2개입니다.
- 예 #3: (0,1)의 컨베이어는 출구 반대쪽을 가리킵니다. (0,1)에 놓인 로봇은 (0,2) → (1,2) → (1,1) → (1,0) → (0,0)으로 5번 움직여야 합니다. (0,2)는 4번, (1,0)은 1번, (1,1)은 2번, (1,2)는 3번이라 합은 15입니다.
