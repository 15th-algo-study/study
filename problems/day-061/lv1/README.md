# [lv1] 돌담 정원의 이끼

돌담 정원을 격자 모양의 지도 `garden`으로 나타냈습니다. `garden[r]`의 `c`번째 문자가 (r, c) 칸이며, 각 문자의 뜻은 다음과 같습니다.

- `M`: 처음부터 이끼가 덮여 있는 칸
- `.`: 아직 이끼가 없는 맨돌 칸
- `#`: 작은 연못이라 이끼가 자랄 수 없는 칸

이끼는 하루에 한 번 한꺼번에 번집니다. 하루가 지날 때마다, 그 전날까지 이끼가 덮인 칸과 **상하좌우로 붙어 있는** 모든 맨돌 칸이 새로 이끼로 덮입니다. 새로 덮인 칸은 다음 날부터 이끼를 퍼뜨립니다. 연못 칸과 정원 밖으로는 번지지 않습니다.

이끼가 더 이상 새 칸으로 번지지 않을 때까지 기다린다고 할 때, 다음 두 값을 차례로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

1. 마지막으로 새 칸이 덮인 날 (첫날이 1일째입니다. 한 칸도 새로 덮이지 않으면 0)
2. 끝내 이끼가 닿지 못하는 맨돌 칸의 수

## 제한사항
- 1 ≤ `garden`의 길이 ≤ 1,000
- 1 ≤ 각 `garden[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같습니다.
- `garden`은 `M`, `.`, `#`로만 이루어지며 `M`은 한 개 이상 있습니다.

## 입출력 예

| garden | result |
|---|---|
| ["M..", ".#.", "..."] | [4, 0] |
| ["M#.", "##.", "..."] | [0, 5] |
| ["..M..", "#####", "M...."] | [4, 0] |

## 입출력 예 설명
- 예 #1: 1일째 (0,1)과 (1,0), 2일째 (0,2)와 (2,0), 3일째 (1,2)와 (2,1), 4일째 (2,2)가 덮입니다. 남는 맨돌 칸은 없습니다.
- 예 #2: 이끼가 연못에 둘러싸여 한 칸도 번지지 못합니다. 맨돌 칸 5개가 끝까지 남습니다.
- 예 #3: 위쪽 이끼는 2일째에 줄 끝까지 닿고, 아래쪽 이끼는 (2,4)에 4일째에 닿습니다. 두 이끼는 같은 날 동시에 번집니다.
