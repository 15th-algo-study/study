# 해설 — 돌담 정원의 이끼

## 접근
어떤 맨돌 칸이 덮이는 날은 **가장 가까운 처음 이끼 칸까지의 최단 거리**와 같습니다. 이끼가 하루에 한 칸씩, 모든 이끼 칸에서 동시에 번지기 때문입니다.

그래서 처음 이끼 칸들을 **모두 0일째로 한꺼번에 큐에 넣고** BFS를 한 번 돌리면 됩니다(다중 시작점 BFS). 큐에서 꺼낸 칸의 날짜 + 1을 아직 덮이지 않은 이웃 맨돌 칸에 적습니다. BFS는 날짜 순서대로 칸을 꺼내므로, 처음 적힌 날짜가 곧 그 칸이 덮이는 날입니다.

- 마지막으로 새 칸이 덮인 날 = 적힌 날짜의 최댓값 (새로 덮인 칸이 없으면 0)
- 끝내 닿지 못한 칸 = BFS가 끝난 뒤에도 날짜가 비어 있는 맨돌 칸

## 주의할 점
- 하루씩 격자 전체를 훑으며 "이웃에 이끼가 있으면 덮기"를 반복하면 하루에 O(칸 수)이고, 구불구불한 길에서는 날짜가 수십만 일까지 늘어나 O(날짜 × 칸 수)로 시간 초과입니다. BFS는 각 칸을 한 번씩만 꺼내므로 O(칸 수)입니다.
- 이끼 칸마다 BFS를 따로 돌리면 이끼가 많을 때 O(이끼 수 × 칸 수)가 됩니다. 시작점을 한 큐에 모두 넣는 것이 핵심입니다.
- 같은 날 덮인 칸이 그날 바로 이웃을 덮으면 안 됩니다. BFS에서 "꺼낸 칸 날짜 + 1"을 적는 방식이면 저절로 지켜집니다.
- 칸을 `r * cols + c` 정수 하나로 묶고 `int[]` 배열을 큐로 쓰면 100만 칸도 빠르게 처리됩니다.

## 복잡도
- 시간 O(rows × cols), 공간 O(rows × cols)
