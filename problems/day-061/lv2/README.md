# [lv2] 옥수수밭 미로에서 만나기

옥수수밭 미로에서 아이와 아빠가 서로 떨어졌습니다. 미로를 격자 모양의 지도 `maze`로 나타냈고, `maze[r]`의 `c`번째 문자가 (r, c) 칸입니다. 각 문자의 뜻은 다음과 같습니다.

- `A`: 아이가 있는 칸 (정확히 하나)
- `B`: 아빠가 있는 칸 (정확히 하나)
- `.`: 두 사람 모두 지나갈 수 있는 길
- `a`: 옥수숫대 사이의 낮은 틈. 몸이 작은 **아이만** 지나갈 수 있습니다.
- `b`: 진흙 웅덩이. 장화를 신은 **아빠만** 지나갈 수 있습니다.
- `#`: 옥수수가 빽빽해 아무도 지나갈 수 없는 칸

두 사람은 휴대폰으로 연락하며 동시에 움직입니다. 1분마다 두 사람은 각자 **상하좌우로 붙은 칸 중 자기가 지나갈 수 있는 칸으로 한 칸 이동하거나, 제자리에 머무를** 수 있습니다. `A`와 `B` 칸은 두 사람 모두 지나갈 수 있습니다. 미로 밖으로는 나갈 수 없습니다.

두 사람이 **같은 시각에 같은 칸**에 있으면 만난 것입니다. 서로 마주 보고 이동하다 스쳐 지나가는 것(두 칸을 맞바꾸는 것)은 만난 것이 아닙니다.

두 사람이 가장 잘 움직였을 때 만날 수 있는 가장 이른 시각(분)을 return 하도록 `solution` 함수를 완성해 주세요. 만날 수 없으면 -1을 return 합니다.

## 제한사항
- 1 ≤ `maze`의 길이 ≤ 1,000
- 1 ≤ 각 `maze[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같습니다.
- `maze`는 `A`, `B`, `.`, `a`, `b`, `#`로만 이루어지며 `A`와 `B`는 각각 정확히 한 번 나옵니다.

## 입출력 예

| maze | result |
|---|---|
| ["A.b.B"] | 3 |
| ["AaB"] | 2 |
| ["AabB"] | -1 |

## 입출력 예 설명
- 예 #1: 아이는 진흙 웅덩이 `b`를 건널 수 없어 (0,0)과 (0,1)에만 갈 수 있습니다. 아빠가 웅덩이를 건너 3분 만에 (0,1)에 오고, 아이는 1분 만에 (0,1)에 와서 기다리면 3분에 만납니다.
- 예 #2: 아빠는 틈 `a`를 지나갈 수 없습니다. 아이가 틈을 지나 2분 만에 아빠가 있는 칸으로 가면 만납니다.
- 예 #3: 아이는 `b`를, 아빠는 `a`를 지나갈 수 없어 두 사람이 함께 설 수 있는 칸에 동시에 있을 방법이 없습니다.
