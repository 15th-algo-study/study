# 해설 — 등번호 스티커 세기

## 접근
필요한 스티커 장수는 등번호를 글자로 썼을 때의 글자 수와 같습니다. `String.valueOf(number)`(또는 `Integer.toString`)로 수를 문자열로 바꾸면 음수의 `-`까지 포함한 표기가 나오므로, 그 `length()`를 모두 더하면 됩니다.

- `String.valueOf(-305)` → `"-305"` → 4장
- `String.valueOf(0)` → `"0"` → 1장

## 주의할 점
- 10으로 나누며 자릿수를 세는 방식이라면 0을 따로 처리해야 합니다. `while (x != 0)` 반복은 0에서 한 번도 돌지 않아 0장이 됩니다.
- 음수를 `Math.abs`로 바꾼 뒤 자릿수를 세면 `-2147483648`에서 틀립니다. `int`의 양수 최댓값은 2147483647이라 `Math.abs(-2147483648)`은 다시 `-2147483648`이 됩니다(오버플로). 문자열로 바꾸면 이런 걱정이 없습니다.
- 답은 최대 11 × 100,000 = 1,100,000이라 `int`로 충분합니다.

## 복잡도
- 시간 O(n), 공간 O(1) (수 하나의 문자열은 최대 11글자)
