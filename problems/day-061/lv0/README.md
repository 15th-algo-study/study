# [lv0] 등번호 스티커 세기

운동회 날 친구들의 조끼에 등번호를 붙이려고 합니다. 등번호는 숫자 스티커를 한 글자에 한 장씩 붙여 만들고, 음수 번호 앞의 `-` 기호도 스티커 한 장이 필요합니다. 예를 들어 `-305`를 붙이려면 `-`, `3`, `0`, `5` 네 장이 필요합니다.

등번호를 담은 정수 배열 `numbers`가 주어질 때, 모든 등번호를 붙이는 데 필요한 스티커의 총 장수를 return 하도록 `solution` 함수를 완성해 주세요. 등번호는 앞에 0을 붙이지 않은 보통의 십진수 표기로 붙입니다. 예를 들어 0은 `0` 한 장입니다.

## 제한사항
- 1 ≤ `numbers`의 길이 ≤ 100,000
- -2,147,483,648 ≤ `numbers`의 원소 ≤ 2,147,483,647

## 입출력 예

| numbers | result |
|---|---|
| [12, -7, 0] | 5 |
| [-2147483648, 2147483647] | 21 |
| [100000, 99999, -1] | 13 |

## 입출력 예 설명
- 예 #1: `12`는 2장, `-7`은 `-`와 `7`로 2장, `0`은 1장입니다. 모두 5장입니다.
- 예 #2: `-2147483648`은 기호 1장과 숫자 10장으로 11장, `2147483647`은 10장입니다. 모두 21장입니다.
- 예 #3: 6장 + 5장 + 2장 = 13장입니다.
