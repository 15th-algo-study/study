# [lv0] 댐 유입량 구간 합

댐 관리소는 매일 댐으로 흘러 들어온 물의 양(톤)을 기록합니다. 기록 배열 `inflow`가 주어지고, `inflow[i]`는 `i`번째 날(0번부터 셈)의 유입량입니다.

두 날짜 번호 `a`, `b`(`a` ≤ `b`)가 주어질 때, `a`번째 날부터 `b`번째 날까지(양 끝 포함) 유입량의 합을 return 하도록 `solution` 함수를 완성해 주세요. 합이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `inflow`의 길이 `n` ≤ 1,000,000
- 0 ≤ `inflow`의 원소 ≤ 1,000,000
- 0 ≤ `a` ≤ `b` < `n`

## 입출력 예

| inflow | a | b | result |
|---|---|---|---|
| [5, 3, 8, 2, 7] | 1 | 3 | 13 |
| [1000000, 1000000, 1000000] | 0 | 2 | 3000000 |
| [4, 9, 1] | 2 | 2 | 1 |

## 입출력 예 설명
- 예 #1: 1, 2, 3번째 날의 유입량 3 + 8 + 2 = 13입니다.
- 예 #2: 세 날을 모두 더하면 3,000,000입니다. 하루 100만 톤이 100만 일 이어지면 `int`로는 담을 수 없으니 `long`을 씁니다.
- 예 #3: `a`와 `b`가 같으면 그 하루의 유입량만 더합니다.
