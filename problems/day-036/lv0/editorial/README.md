# 해설 — 댐 유입량 구간 합

## 접근
`a`부터 `b`까지 반복문으로 더하면 끝입니다. 더하는 변수는 처음부터 `long`으로 선언합니다.

```java
long sum = 0;
for (int i = a; i <= b; i++) sum += inflow[i];
```

## 주의할 점
- 양 끝을 **포함**하므로 반복 조건은 `i <= b`입니다. `i < b`로 쓰면 마지막 날이 빠집니다.
- `int sum`으로 더하면 100만 × 100만 = 10^12에서 넘칩니다. 원소는 `int`여도 합은 `long`에 담습니다.
- 원소가 `int`라도 `sum += inflow[i]`에서 `sum`이 `long`이면 덧셈은 `long`으로 수행됩니다.

## 복잡도
- 시간 O(b − a + 1) ≤ O(n), 공간 O(1)
