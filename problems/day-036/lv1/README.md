# [lv1] 수족관 연속 k일 관람객

수족관의 하루 관람객 수가 배열 `visitors`로 주어집니다. `visitors[i]`는 `i`번째 날(0번부터 셈)의 관람객 수입니다.

연속한 `k`일의 관람객 수 합이 가장 큰 구간을 찾아, `[최대 합, 그 구간의 시작 날짜 번호]`를 길이 2인 `long` 배열로 return 하도록 `solution` 함수를 완성해 주세요. 합이 최대인 구간이 여러 개이면 **시작 날짜 번호가 가장 작은** 것을 고릅니다.

## 제한사항
- 1 ≤ `visitors`의 길이 `n` ≤ 200,000
- 0 ≤ `visitors`의 원소 ≤ 1,000,000,000
- 1 ≤ `k` ≤ `n`
- 합이 `int` 범위를 넘을 수 있으므로 반환 배열은 `long[]`입니다. 시작 날짜 번호도 같은 배열에 `long`으로 담습니다.

## 입출력 예

| visitors | k | result |
|---|---|---|
| [3, 1, 4, 1, 5, 9, 2] | 3 | [16, 4] |
| [5, 5, 5, 5] | 2 | [10, 0] |
| [1000000000, 1000000000, 0] | 2 | [2000000000, 0] |

## 입출력 예 설명
- 예 #1: 연속 3일의 합은 시작 날짜 0부터 차례로 8, 6, 10, 15, 16입니다. 가장 큰 16은 4번째 날에 시작합니다.
- 예 #2: 모든 구간의 합이 10으로 같으므로 시작 번호가 가장 작은 0을 고릅니다.
- 예 #3: 합 2,000,000,000은 `int`의 최댓값(2,147,483,647)에 가깝습니다. 하루 10억 명이 20만 일 이어지면 `int`로는 담을 수 없습니다.
