# 해설 — 수족관 연속 k일 관람객

## 접근
시작 날짜마다 `k`개를 다시 더하면 O(n·k)입니다. 대신 **누적합**을 만들어 둡니다.

- `prefix[i]` = 0번째 날부터 `i − 1`번째 날까지의 합 (`prefix[0] = 0`)
- 시작 날짜 `s`부터 `k`일의 합 = `prefix[s + k] − prefix[s]`

`s`를 0부터 `n − k`까지 훑으며 최댓값을 갱신합니다. "더 클 때만" 갱신하면 같은 값 중 가장 앞선 시작 번호가 자연히 남습니다.

같은 아이디어를 창문을 한 칸씩 밀면서 "새로 들어오는 날을 더하고 나가는 날을 빼는" 방식으로도 쓸 수 있습니다.

## 주의할 점
- 누적합은 `long[]`이어야 합니다. 원소 하나가 최대 10^9라 둘만 더해도 `int` 최댓값에 가깝습니다.
- `k = n`이면 구간이 하나뿐이고 시작 번호는 0입니다.
- 최댓값의 초깃값을 0으로 두고 `>`로만 갱신하면 모든 날이 0일 때 시작 번호가 갱신되지 않을 수 있습니다. 첫 구간의 값으로 초기화하거나 `-1`로 시작하세요.
- 시작마다 `k`번 더하는 풀이는 `n = 200,000`, `k = 100,000`에서 10^10번 연산이라 시간 초과입니다.

## 복잡도
- 시간 O(n), 공간 O(n)
