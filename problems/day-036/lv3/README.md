# [lv3] 해적의 보물 삼등분

해적선에 보물 상자 `n`개가 한 줄로 놓여 있습니다. `coins[i]`는 `i`번째 상자에 든 금화 수입니다.

세 해적이 이 줄을 **두 군데에서 끊어** 연속한 세 묶음으로 나누려 합니다. 세 묶음은 각각 상자가 하나 이상이어야 하고, 세 묶음의 금화 합이 모두 같아야 합니다. 상자의 순서를 바꾸거나 상자를 빼놓을 수는 없습니다.

나누는 방법의 수를 return 하도록 `solution` 함수를 완성해 주세요. 끊는 위치가 다르면 다른 방법으로 셉니다. 방법 수가 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 3 ≤ `coins`의 길이 `n` ≤ 1,000,000
- 0 ≤ `coins`의 원소 ≤ 1,000,000,000

## 입출력 예

| coins | result |
|---|---|
| [1, 2, 3, 0, 3] | 2 |
| [0, 0, 0, 0] | 3 |
| [2, 2, 2, 2] | 0 |

## 입출력 예 설명
- 예 #1: 금화는 모두 9개이므로 묶음마다 3개씩이어야 합니다. `[1, 2] | [3] | [0, 3]`과 `[1, 2] | [3, 0] | [3]` 두 가지입니다.
- 예 #2: 모든 묶음의 합이 0입니다. 상자 4개를 세 묶음으로 나누는 방법은 끊는 위치 두 개를 세 틈 중에서 고르는 3가지입니다.
- 예 #3: 금화 8개는 3으로 나누어떨어지지 않으므로 방법이 없습니다.
