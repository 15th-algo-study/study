# 해설 — 해적의 보물 삼등분

## 접근
끊는 위치 두 개를 모두 시도하면 O(n²)으로 `n = 10^6`에서 시간 초과입니다.

전체 합을 `S`라 하면 `S`가 3의 배수가 아닐 때 답은 0입니다. 3의 배수이면 목표 `T = S / 3`이고, 앞에서부터의 **누적합**으로 조건을 다시 씁니다.

- `prefix[i]` = 앞 `i`개 상자의 합 (1 ≤ i ≤ n − 1 이 끊는 위치의 후보)
- 첫 번째 끊는 위치 `i`는 `prefix[i] = T`, 두 번째 끊는 위치 `j`는 `prefix[j] = 2T` 이고 `i < j` 이어야 합니다. 그러면 셋째 묶음의 합은 자동으로 `S − 2T = T`입니다.

따라서 답은 **`prefix[j] = 2T`인 `j`마다, 그보다 앞에 있는 `prefix[i] = T`인 `i`의 개수**를 더한 값입니다. 앞에서부터 한 번 훑으면서 "지금까지 본 `T`인 위치 수"를 세고, `2T`를 만날 때마다 그 수를 답에 더합니다. 순서가 중요합니다: 위치 `j`에서는 먼저 답에 더한 뒤에 `T` 개수를 갱신해야 `i < j`(같은 위치 금지)가 지켜집니다.

`T = 0`(합이 0)이면 `T`와 `2T`가 같은 값이지만 위의 순서대로 처리하면 `i < j`인 쌍만 세어져 그대로 맞습니다. 예 #2가 그 경우입니다.

## 주의할 점
- 누적합과 답 모두 `long`입니다. 상자 10^6개 × 10^9이면 합이 10^15, 방법 수는 최대 약 5 × 10^11입니다.
- 끊는 위치는 `1 ≤ i < j ≤ n − 1`입니다. 첫 묶음과 마지막 묶음도 상자가 하나 이상이어야 하므로 `prefix[0]`과 `prefix[n]`은 후보가 아닙니다.
- 금화가 0인 상자가 많으면 같은 누적합 값이 여러 번 나와 방법 수가 급격히 늘어납니다. 그래서 "첫 위치 하나만 기억"이 아니라 **개수**를 세야 합니다.

## 복잡도
- 시간 O(n), 공간 O(1)
