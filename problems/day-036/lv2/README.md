# [lv2] 태양광 패널 구역 발전량

태양광 발전소의 패널이 `R`행 `C`열 격자로 놓여 있습니다. `panels[r][c]`는 `r`행 `c`열 패널의 하루 발전량(Wh)입니다.

관리자는 직사각형 구역의 발전량 합을 여러 번 조회합니다. 조회 `queries`의 각 원소는 `[r1, c1, r2, c2]`로, 두 칸 `(r1, c1)`과 `(r2, c2)`를 **마주 보는 꼭짓점**으로 하는 직사각형 구역을 뜻합니다. 두 꼭짓점은 어느 쪽이 왼쪽 위든 상관없습니다(예: `(2, 2)`와 `(0, 0)`은 `(0, 0)`과 `(2, 2)`로 만든 구역과 같습니다).

각 조회에 대한 구역 발전량 합을 순서대로 담은 `long` 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `R`, `C` ≤ 1,000
- 0 ≤ `panels`의 원소 ≤ 1,000,000
- 1 ≤ `queries`의 길이 ≤ 200,000
- 0 ≤ `r1`, `r2` < `R`, 0 ≤ `c1`, `c2` < `C`
- 합이 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| panels | queries | result |
|---|---|---|
| [[1, 2, 3], [4, 5, 6], [7, 8, 9]] | [[0, 0, 1, 1], [2, 2, 0, 0], [1, 0, 1, 2]] | [12, 45, 15] |
| [[5]] | [[0, 0, 0, 0]] | [5] |
| [[1, 1], [1, 1], [1, 1]] | [[2, 1, 0, 0], [1, 1, 1, 0]] | [6, 2] |

## 입출력 예 설명
- 예 #1
  - `[0, 0, 1, 1]`: 왼쪽 위 2×2 구역 1 + 2 + 4 + 5 = 12
  - `[2, 2, 0, 0]`: 꼭짓점 순서가 바뀌어 있지만 격자 전체이므로 45
  - `[1, 0, 1, 2]`: 1행 전체 4 + 5 + 6 = 15
- 예 #2: 패널이 하나뿐입니다.
- 예 #3: 3행 2열 격자입니다. 첫 조회는 전체(6), 둘째 조회는 1행의 두 칸(2)입니다.
