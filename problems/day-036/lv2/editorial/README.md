# 해설 — 태양광 패널 구역 발전량

## 접근
조회마다 구역 안의 칸을 모두 더하면 조회 하나에 최대 10^6칸, 20만 조회면 시간 초과입니다. **2차원 누적합**을 한 번 만들어 두면 조회 하나를 O(1)에 처리합니다.

`S[i][j]` = 왼쪽 위 `(0, 0)`부터 `(i − 1, j − 1)`까지 직사각형의 합 (0행·0열은 0으로 비워 둡니다).

```
S[i][j] = panels[i-1][j-1] + S[i-1][j] + S[i][j-1] - S[i-1][j-1]
```

`(r1, c1)`~`(r2, c2)` (r1 ≤ r2, c1 ≤ c2) 구역의 합은 포함–배제로

```
S[r2+1][c2+1] - S[r1][c2+1] - S[r2+1][c1] + S[r1][c1]
```

조회의 두 꼭짓점은 순서가 보장되지 않으므로 `Math.min`/`Math.max`로 먼저 정렬합니다.

## 주의할 점
- 누적합 배열은 `long[][]`이어야 합니다. 전체 합이 최대 10^6 × 10^6 = 10^12입니다.
- 누적합 배열을 `(R + 1) × (C + 1)`로 잡으면 `i − 1`, `j − 1` 경계 검사가 필요 없습니다.
- 겹치는 `S[r1][c1]`을 빼는 것을 잊으면 두 번 빼인 모서리가 틀립니다.

## 복잡도
- 시간 O(R·C + Q), 공간 O(R·C)
