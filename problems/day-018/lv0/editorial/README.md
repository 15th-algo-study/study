# 해설 — 책장 정리

## 접근
2차원 배열은 "배열의 배열"입니다. 바깥 배열을 돌면서 각 행 `shelves[i]`(1차원 `int[]`)에 `Arrays.sort`를 적용하면 됩니다.

```java
for (int[] row : shelves) Arrays.sort(row);
```

행마다 길이가 달라도(들쭉날쭉한 배열) 각 행은 독립된 1차원 배열이므로 똑같이 동작합니다.

## 주의할 점
- `Arrays.sort(shelves)`처럼 **2차원 배열 자체**를 정렬하면 행들의 순서를 바꾸려 시도하다가 `int[]`는 비교할 수 없다는 예외(`ClassCastException`)가 납니다. 정렬할 대상은 각 행입니다.
- 입력 배열을 제자리에서 정렬해 그대로 돌려줘도 되고, 새 배열을 만들어 복사한 뒤 정렬해도 됩니다. 모범 풀이는 원본을 건드리지 않도록 행마다 `clone()`을 씁니다.
- 반환 타입이 `int[][]` 이므로 템플릿의 `int[][] answer = {};`를 지우고 결과 배열을 돌려주면 됩니다.

## 복잡도
- 시간 O(Σ k_i log k_i) (k_i = 각 칸의 책 수, 전체 최대 10^6), 공간 O(Σ k_i)
