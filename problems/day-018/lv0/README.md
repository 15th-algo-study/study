# [lv0] 책장 정리

책장의 각 칸에 꽂힌 책들의 높이가 2차원 배열 `shelves`로 주어집니다. `shelves[i]`는 `i`번 칸에 꽂힌 책들의 높이를 왼쪽부터 순서대로 담은 배열입니다. 칸마다 책의 수는 다를 수 있습니다.

모든 칸의 책을 **낮은 것부터 높은 것 순서**로 다시 꽂은 결과를 return 하도록 `solution` 함수를 완성해 주세요. 책은 다른 칸으로 옮기지 않습니다.

## 제한사항
- 1 ≤ `shelves`의 길이 ≤ 1,000
- 1 ≤ `shelves[i]`의 길이 ≤ 1,000
- 1 ≤ 책의 높이 ≤ 1,000,000,000

## 입출력 예

| shelves | result |
|---|---|
| [[30, 10, 20], [5, 1], [7]] | [[10, 20, 30], [1, 5], [7]] |
| [[3, 3, 1], [2, 2]] | [[1, 3, 3], [2, 2]] |

## 입출력 예 설명
- 예 #1: 각 칸을 따로 오름차순으로 정렬합니다. 책이 한 권뿐인 칸은 그대로입니다.
- 예 #2: 높이가 같은 책이 있어도 문제없습니다.
