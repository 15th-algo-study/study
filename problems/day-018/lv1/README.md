# [lv1] 수영 대회 순위

수영 대회에 참가한 선수 `n`명의 기록이 배열 `records`로 주어집니다. `records[i]`는 `i`번 선수의 기록을 1/100초 단위로 나타낸 정수입니다. 기록이 짧을수록 순위가 높습니다.

순위는 다음과 같이 매깁니다.

- 어떤 선수의 순위는 **그 선수보다 기록이 짧은 선수의 수 + 1** 입니다.
- 따라서 기록이 같은 선수들은 같은 순위이고, 그다음 순위는 그만큼 건너뜁니다. 예를 들어 1위가 두 명이면 다음 선수는 3위입니다.

각 선수의 순위를 **선수 번호 순서대로** 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `records`의 길이 `n` ≤ 200,000
- 1 ≤ `records`의 원소 ≤ 1,000,000,000

## 입출력 예

| records | result |
|---|---|
| [5230, 4875, 5230, 6001, 4875] | [3, 1, 3, 5, 1] |
| [100, 200, 300] | [1, 2, 3] |
| [7, 7] | [1, 1] |

## 입출력 예 설명
- 예 #1: 4875가 두 명이라 둘 다 1위, 5230은 자기보다 빠른 선수가 2명이라 3위(두 명), 6001은 4명이 빠르므로 5위입니다.
- 예 #2: 기록이 모두 다르므로 1, 2, 3위입니다.
- 예 #3: 두 선수가 공동 1위입니다.
