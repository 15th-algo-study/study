# 해설 — 수영 대회 순위

## 접근
선수마다 "나보다 빠른 선수 수"를 직접 세면 O(n²)입니다. 대신 **선수 번호를 기록 순으로 정렬**하면, 정렬된 위치가 곧 "나보다 앞에 있는 선수 수"입니다.

1. `Integer[] order = {0, 1, …, n-1}`를 `records` 기준 오름차순으로 정렬합니다.
2. 정렬된 순서로 훑으면서 순위를 매깁니다. `k`번째(0부터) 선수의 기록이 **바로 앞 선수와 다르면** 순위는 `k + 1`, **같으면** 앞 선수의 순위를 그대로 씁니다.
3. `answer[order[k]] = 순위` 로 원래 번호 자리에 적습니다.

동점일 때 순위를 "그대로 물려주는" 것이 "건너뛰는 순위"를 만드는 핵심입니다. 공동 1위 두 명 다음 선수는 `k = 2`에서 기록이 달라지므로 3위가 됩니다.

## 주의할 점
- 결과는 **원래 선수 번호 순서**여야 합니다. 정렬한 배열에 그대로 순위를 쓰면 순서가 뒤섞입니다. 번호 배열을 정렬하고 `answer[order[k]]`에 적는 패턴을 익혀 두세요.
- 같은 기록을 비교할 때는 `records[order[k]] == records[order[k-1]]` 처럼 **정렬된 이웃**과 비교합니다. 값이 같은 선수들은 정렬 뒤 반드시 붙어 있습니다.
- `Integer[]`를 쓰면 박싱 비용이 있지만 20만 명은 문제없습니다.

## 복잡도
- 시간 O(n log n), 공간 O(n)
