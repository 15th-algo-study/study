# 해설 — 체조 단체전 결선 진출자

## 접근: 정렬로 그룹 묶기
팀별로 상위 2명을 고르려면 같은 팀 선수들을 모아야 합니다. 해시 맵 없이도 **(팀 오름차순, 점수 내림차순, 번호 오름차순)으로 정렬**하면 같은 팀이 연속해서 나오고, 각 팀의 첫 두 명이 곧 진출자입니다.

1. 선수 번호 배열을 `(team ↑, score ↓, index ↑)` 로 정렬합니다.
2. 앞에서부터 훑으며 "이 팀에서 몇 명째인지"를 셉니다. 팀이 바뀌면 0으로 되돌리고, 2명째까지만 진출자 목록에 넣습니다.
3. 진출자 목록을 다시 `(score ↓, team ↑, index ↑)` 로 정렬해 돌려줍니다.

정렬을 두 번 하지만 각각 O(n log n)이라 충분히 빠릅니다.

## 주의할 점
- 두 정렬의 **기준 순서가 다릅니다**. 첫 번째는 팀을 묶기 위해 팀이 첫 기준이고, 두 번째는 명단 출력을 위해 점수가 첫 기준입니다.
- 선수마다 "같은 팀에서 나보다 앞선 선수 수"를 직접 세면 O(n²)입니다. 모든 선수가 한 팀인 입력에서 4×10^10 번 비교하게 되어 시간 초과입니다.
- 점수가 0일 수 있고 팀 번호는 1부터 시작합니다. 비교는 모두 `Integer.compare`로 쓰세요.
- 진출자 수는 미리 알 수 없으므로 `List<Integer>`에 모은 뒤 정렬하고 배열로 바꿉니다.

## 복잡도
- 시간 O(n log n), 공간 O(n)
