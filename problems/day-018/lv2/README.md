# [lv2] 체조 단체전 결선 진출자

체조 대회 예선에 여러 팀의 선수들이 출전했습니다. 선수 번호는 0번부터 `n-1`번이고, `i`번 선수의 기록은 `athletes[i] = [team, score]` (소속 팀 번호, 예선 점수)입니다.

결선 진출자는 다음 규칙으로 정합니다.

1. **팀마다** 점수가 높은 순서로 최대 2명이 진출합니다. 한 팀 안에서 점수가 같으면 선수 번호가 작은 쪽이 우선합니다. 선수가 1명뿐인 팀은 그 1명이 진출합니다.
2. 진출자 명단은 **점수가 높은 순**으로 정렬합니다. 점수가 같으면 **팀 번호가 작은 순**, 팀 번호도 같으면 **선수 번호가 작은 순**입니다.

정렬된 진출자 명단을 선수 번호 배열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `athletes`의 길이 `n` ≤ 200,000
- `athletes[i]`의 길이는 2입니다.
- 1 ≤ `team` ≤ 100,000
- 0 ≤ `score` ≤ 1,000,000,000

## 입출력 예

| athletes | result |
|---|---|
| [[1, 90], [2, 85], [1, 95], [1, 92], [2, 85], [3, 70]] | [2, 3, 1, 4, 5] |
| [[7, 50]] | [0] |
| [[1, 10], [2, 10], [1, 10], [2, 10], [1, 10]] | [0, 2, 1, 3] |

## 입출력 예 설명
- 예 #1
  - 1팀: 2번(95), 3번(92), 0번(90) 중 2번과 3번이 진출합니다.
  - 2팀: 1번(85), 4번(85) 두 명 모두 진출합니다.
  - 3팀: 5번(70) 한 명이 진출합니다.
  - 점수 순으로 정렬하면 2번(95), 3번(92), 1번(85), 4번(85), 5번(70)입니다. 1번과 4번은 점수·팀이 같으므로 선수 번호 순입니다.
- 예 #2: 선수 한 명이 그대로 진출합니다.
- 예 #3: 1팀은 0, 2, 4번이 모두 10점이라 번호가 작은 0번, 2번이 진출하고, 2팀은 1번, 3번이 진출합니다. 네 명 모두 10점이므로 팀 번호 순, 그다음 선수 번호 순으로 [0, 2, 1, 3]입니다.
