# [lv3] 고속도로 라디오

직선 고속도로 위의 위치를 0 이상의 정수로 나타냅니다. 고속도로 주변에 라디오 방송국 `n`개가 있고, `i`번 방송국의 정보는 `stations[i] = [p, d]` 입니다. 이 방송국의 전파는 위치 `p`를 중심으로 거리 `d` 이내, 즉 `p - d` 이상 `p + d` 이하인 모든 위치에 닿습니다.

고속도로 위에 자동차 `m`대가 있고, `j`번 자동차의 위치는 `cars[j]` 입니다. 각 자동차에서 **전파가 닿는 방송국의 수**를 자동차 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `stations`의 길이 `n` ≤ 300,000
- `stations[i]`의 길이는 2입니다.
- 0 ≤ `p` ≤ 1,000,000,000, 0 ≤ `d` ≤ 1,000,000,000
- 1 ≤ `cars`의 길이 `m` ≤ 300,000
- 0 ≤ `cars[j]` ≤ 1,000,000,000
- 같은 위치에 여러 자동차나 여러 방송국이 있을 수 있습니다.

## 입출력 예

| stations | cars | result |
|---|---|---|
| [[10, 5], [20, 3], [12, 1]] | [11, 17, 4, 23] | [2, 1, 0, 1] |
| [[0, 1000000000]] | [0, 1000000000, 500] | [1, 1, 1] |
| [[5, 0], [5, 0]] | [5, 6] | [2, 0] |

## 입출력 예 설명
- 예 #1: 세 방송국의 전파 범위는 각각 [5, 15], [17, 23], [11, 13]입니다. 위치 11의 자동차는 첫째·셋째 방송국이 닿아 2, 위치 17은 둘째 방송국만 1, 위치 4는 어느 범위에도 없어 0, 위치 23은 둘째 방송국의 경계라 1입니다.
- 예 #2: 방송국 하나가 고속도로 전체를 덮습니다.
- 예 #3: 범위가 한 점뿐인 방송국 두 개입니다. 위치 5에는 둘 다 닿고, 6에는 닿지 않습니다.
