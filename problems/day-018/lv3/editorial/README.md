# 해설 — 고속도로 라디오

## 핵심 관찰: "덮는 구간 수"를 두 개의 개수 차로 바꾸기
자동차 위치 `q`를 덮는 방송국은 `left = p - d ≤ q` 이고 `right = p + d ≥ q` 인 것입니다. `left ≤ q` 인 방송국 중에서 `right < q` 인 것을 빼면 됩니다. 그런데 `right < q` 이면 자동으로 `left ≤ q` 이므로

**답 = (`left ≤ q` 인 방송국 수) − (`right < q` 인 방송국 수)**

입니다. 이제 문제는 "정렬된 배열에서 `q` 이하(미만)인 값이 몇 개인가"를 자동차마다 구하는 것으로 바뀝니다.

## 알고리즘: 질의도 정렬해서 포인터를 앞으로만 움직이기 (오프라인 처리)
1. `lefts[]`, `rights[]` 를 각각 오름차순으로 정렬합니다.
2. 자동차 번호를 위치 순으로 정렬합니다.
3. 자동차를 위치가 작은 것부터 보면서
   - 포인터 `a`를 `lefts[a] ≤ q` 인 동안 전진 → `a`가 `left ≤ q` 인 수
   - 포인터 `b`를 `rights[b] < q` 인 동안 전진 → `b`가 `right < q` 인 수
   - `answer[원래 번호] = a - b`
4. 자동차 위치가 커지기만 하므로 포인터는 절대 뒤로 가지 않습니다. 전체 O(n + m).

같은 값을 이분 탐색(`upperBound`)으로 찾아도 되지만, 정렬된 질의를 한 방향으로 훑는 방식은 코드가 더 단순하고 이분 탐색 경계 실수도 없습니다.

## 주의할 점
- `p - d`는 음수가 될 수 있고, `p + d`는 최대 2×10^9 로 **`int`를 넘습니다**. `long[]`에 담으세요.
- 경계 포함: 범위는 닫힌 구간 `[p - d, p + d]` 입니다. `left ≤ q` 와 `right < q` 의 부등호를 섞어 쓰지 않도록 주의하세요 (예 #1의 위치 23, 예 #3의 위치 5가 경계 케이스입니다).
- 결과는 **입력 자동차 순서**여야 하므로 자동차 번호를 함께 정렬하고 원래 자리에 적습니다.
- 자동차마다 모든 방송국을 확인하면 O(n·m) = 9×10^10 이라 시간 초과입니다.

## 복잡도
- 시간 O((n + m) log(n + m)) (정렬), 공간 O(n + m)
