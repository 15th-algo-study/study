# [lv1] 산호 가지 세기

어느 산호는 가지의 종류가 `k`가지이고, 종류를 영문 소문자 `a`, `b`, `c`, … 순서로 부릅니다 (`k = 3`이면 `a`, `b`, `c`). 해마다 **모든 가지가 동시에** 정해진 규칙대로 바뀝니다. `rules[i]`는 종류 `i`(문자 `'a' + i`)의 가지 하나가 1년 뒤에 어떤 가지들로 바뀌는지 나타내는 문자열로, 길이는 1 또는 2입니다.

예를 들어 `rules = ["ab", "a"]`이면 `a` 가지는 1년 뒤 `a` 가지와 `b` 가지 두 개가 되고, `b` 가지는 `a` 가지 하나가 됩니다. 지금 가지가 `"a"` 하나뿐이라면 1년 뒤 `"ab"`, 2년 뒤 `"aba"`, 3년 뒤 `"abaab"`가 됩니다.

지금의 가지 나열 `start`와 햇수 `years`가 주어질 때, `years`년 뒤 각 종류의 가지가 몇 개인지 종류 순서(`a`, `b`, …)대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `rules`의 길이 `k` ≤ 5
- `rules[i]`의 길이는 1 또는 2이고, 각 문자는 `'a'`부터 `'a' + k − 1`까지 중 하나입니다.
- 1 ≤ `start`의 길이 ≤ 1,000, 각 문자는 `'a'`부터 `'a' + k − 1`까지 중 하나입니다.
- 0 ≤ `years` ≤ 50
- 가지의 총 개수는 `int` 범위를 넘을 수 있으므로 `long[]`로 return 합니다. (1.2×10^18을 넘지 않습니다.)

## 입출력 예

| rules | start | years | result |
|---|---|---|---|
| ["ab", "a"] | "a" | 3 | [3, 2] |
| ["b", "c", "a"] | "abc" | 1 | [1, 1, 1] |
| ["aa"] | "aaa" | 0 | [3] |

## 입출력 예 설명
- 예 #1: `a` → `ab` → `aba` → `abaab`. `a`가 3개, `b`가 2개입니다.
- 예 #2: 모든 가지가 다른 종류로 바뀌어 `bca`가 됩니다. 종류별 개수는 그대로 1개씩입니다.
- 예 #3: 0년 뒤는 지금 그대로입니다.
