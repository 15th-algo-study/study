# 해설 — 산호 가지 세기

## 접근
가지 나열을 문자열로 실제로 만들면 길이가 해마다 최대 2배로 늘어 50년 뒤에는 10^18개가 됩니다. 만들 수 없습니다.

하지만 답은 **종류별 개수**뿐이고, 개수는 재귀적으로 정해집니다.

> `years`년 뒤 종류 `c`의 개수 = Σ (종류 `x`의 `years − 1`년 뒤 개수 × `rules[x]`에 들어 있는 `c`의 개수)

즉 "1년 뒤 개수"는 "지금 개수"만으로 계산되므로, 종류별 개수 배열 `cnt[k]`를 들고 해마다 `next` 배열을 새로 채우는 일을 `years`번 반복하면 됩니다. 처음 `cnt`는 `start`의 글자를 세어 만듭니다.

## 주의할 점
- 개수는 최대 1,000 × 2^50 ≈ 1.1×10^18 이라 `long`이어야 합니다. `int`로 세면 30년 안쪽에서 넘칩니다.
- `next`를 매년 새 배열(또는 0으로 초기화)로 시작해야 합니다. 같은 배열에 덮어쓰면 아직 쓰지 않은 종류의 "지금 개수"가 사라집니다.
- `years = 0`이면 `start`의 개수를 그대로 돌려줍니다.
- 문자열을 직접 키우는 풀이(`StringBuilder`에 규칙을 적용해 새 문자열 생성)는 길이가 2^30만 넘어도 메모리와 시간이 모두 터집니다. "구조를 만들지 말고 개수만 따라가기"가 이번 주의 반복되는 주제입니다.

## 복잡도
- 시간 O(|start| + years × k × 2), 공간 O(k)
