# [lv3] 롤러코스터 트랙 설계

롤러코스터 트랙은 길이가 같은 구간 `2n`개를 이어 만듭니다. 각 구간은 오르막 `U` 또는 내리막 `D`이고, 트랙은 다음 조건을 모두 만족해야 합니다.

- 오르막이 정확히 `n`개, 내리막이 정확히 `n`개입니다.
- 출발점의 높이는 0이고, 오르막은 높이를 1 올리고 내리막은 1 내립니다. 트랙의 **어느 지점에서도 높이가 0 미만이 되면 안 됩니다** (지면 아래로 내려갈 수 없습니다).

예를 들어 `n = 2`이면 가능한 트랙은 `UDUD`와 `UUDD` 두 가지입니다. `DUUD`는 첫 구간에서 높이가 −1이 되어 불가능합니다.

가능한 트랙을 모두 **사전순**으로 나열합니다. 문자 `D`가 `U`보다 앞섭니다. 트랙 길이 `n`과 질문 배열 `ks`가 주어질 때, 각 질문 `ks[i]`에 대해 사전순으로 `ks[i]`번째 트랙을 담은 문자열 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 30
- 1 ≤ `ks`의 길이 ≤ 100,000
- 1 ≤ `ks`의 원소 ≤ (가능한 트랙의 수) (`long`). `n = 30`일 때 가능한 트랙은 3,814,986,502,092,304가지입니다.

## 입출력 예

| n | ks | result |
|---|---|---|
| 2 | [1, 2] | ["UDUD", "UUDD"] |
| 3 | [3, 5, 1] | ["UUDDUD", "UUUDDD", "UDUDUD"] |
| 1 | [1] | ["UD"] |

## 입출력 예 설명
- 예 #1: 가능한 트랙을 사전순으로 나열하면 `UDUD`, `UUDD`입니다.
- 예 #2: `n = 3`의 트랙은 사전순으로 `UDUDUD`, `UDUUDD`, `UUDDUD`, `UUDUDD`, `UUUDDD` 다섯 가지입니다.
- 예 #3: `UD` 하나뿐입니다.
