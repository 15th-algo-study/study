# [lv0] 사물함 번호 뒤집기

학교 사물함 번호가 새 규칙으로 바뀝니다. 새 번호는 **옛 번호의 자릿수를 거꾸로 읽은 수**입니다. 거꾸로 읽었을 때 앞에 오는 0은 수의 일부가 아니므로 사라집니다.

예를 들어 옛 번호 1200은 거꾸로 읽으면 `0021`이므로 새 번호는 21입니다. 한 자리 수는 뒤집어도 그대로입니다.

옛 번호 배열 `numbers`가 주어질 때, 각 사물함의 새 번호를 같은 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `numbers`의 길이 ≤ 100,000
- 0 ≤ `numbers`의 원소 ≤ 100,000,000,000,000,000 (10^17, `long`)
- 새 번호도 `long` 범위이므로 `long[]`로 return 합니다.

## 입출력 예

| numbers | result |
|---|---|
| [1200, 7, 0, 98765] | [21, 7, 0, 56789] |
| [100000000000000000, 12345678901234567] | [1, 76543210987654321] |

## 입출력 예 설명
- 예 #1: 1200 → 0021 → 21, 7 → 7, 0 → 0, 98765 → 56789
- 예 #2: 10^17은 1 뒤에 0이 17개이므로 뒤집으면 1입니다. 17자리 수 12345678901234567을 뒤집으면 76543210987654321입니다.
