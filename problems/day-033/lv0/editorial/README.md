# 해설 — 사물함 번호 뒤집기

## 접근
수를 뒤집는 것을 "마지막 자리를 떼어 지금까지 만든 수의 뒤에 붙인다"로 보면 재귀가 됩니다.

> `reverse(n, acc)` = `n == 0 ? acc : reverse(n / 10, acc * 10 + n % 10)`

처음에는 `reverse(n, 0)`으로 부릅니다. 1200이면 `reverse(1200, 0)` → `reverse(120, 0)` → `reverse(12, 0)` → `reverse(1, 2)` → `reverse(0, 21)` → 21. 뒤에 붙은 0은 `acc`가 0인 동안 `0 * 10 + 0 = 0`이라 자연스럽게 사라집니다.

자릿수가 최대 18개이므로 재귀 깊이도 18 이하입니다.

## 주의할 점
- 입력이 `long`이므로 `n % 10`, `n / 10`, `acc`가 모두 `long`이어야 합니다.
- 10^17 이하의 수를 뒤집으면 많아야 18자리라 `long`(약 9.2×10^18)을 넘지 않습니다. 제한이 10^18이었다면 19자리 수를 뒤집을 때 넘칠 수 있다는 점을 기억하세요.
- 문자열로 바꿔 `StringBuilder.reverse()` 뒤 `Long.parseLong`을 해도 되지만, 이 문제는 재귀 연습이 목적입니다.
- 0은 `reverse(0, 0)`이 바로 0을 돌려줍니다.

## 복잡도
- 시간 O(n × 자릿수), 공간 O(n) (결과 배열)
