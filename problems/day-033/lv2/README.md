# [lv2] 초콜릿 바 쪼개기

길이가 정수인 길쭉한 초콜릿 바를 다음 규칙으로 쪼갭니다.

- 길이가 `limit`보다 **긴** 조각은 반으로 쪼갭니다. 길이가 홀수이면 한 조각이 다른 조각보다 1 더 깁니다. 예를 들어 길이 7은 3과 4로 쪼개집니다.
- 길이가 `limit` **이하**인 조각은 더 이상 쪼개지 않습니다.
- 쪼개진 조각 각각에 같은 규칙을 다시 적용합니다.

예를 들어 길이 10, `limit = 3`이면 10 → (5, 5) → (2, 3, 2, 3)이 되어 조각 4개로 끝납니다.

여러 초콜릿 바에 대해 질문이 주어집니다. `i`번 질문은 길이 `lengths[i]`인 초콜릿 바를 `limits[i]`를 기준으로 쪼갰을 때 **마지막에 남는 조각의 개수**입니다. 각 질문의 답을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `lengths`의 길이 = `limits`의 길이 ≤ 200,000
- 1 ≤ `lengths`의 원소 ≤ 10^18 (`long`)
- 1 ≤ `limits`의 원소 ≤ 10^18 (`long`)
- 처음부터 길이가 `limit` 이하이면 쪼개지 않으므로 조각은 1개입니다.
- 답은 `long` 범위입니다.

## 입출력 예

| lengths | limits | result |
|---|---|---|
| [10, 7, 1] | [3, 3, 1] | [4, 3, 1] |
| [9, 8] | [4, 2] | [3, 4] |
| [1000000000000000000] | [1] | [1000000000000000000] |

## 입출력 예 설명
- 예 #1
  - 10 → (5, 5) → (2, 3, 2, 3): 4개
  - 7 → (3, 4): 3은 그대로, 4 → (2, 2): 모두 3개
  - 1은 이미 1 이하이므로 1개
- 예 #2
  - 9 → (4, 5): 4는 그대로, 5 → (2, 3): 모두 3개
  - 8 → (4, 4) → (2, 2, 2, 2): 4개
- 예 #3: 길이 1이 될 때까지 쪼개므로 조각은 10^18개입니다.
