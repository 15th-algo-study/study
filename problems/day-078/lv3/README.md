# [lv3] 전세 헬기와 산길

산골 마을 `n`개(0번 ~ `n - 1`번)가 양방향 산길로 이어져 있고, 몇몇 마을에는 헬기장이 있습니다. 전세 헬기를 부르면 **어느 헬기장에서든 다른 어느 헬기장으로든** 바로 날아갈 수 있습니다. 헬기 요금은 거리와 상관없이 출발 헬기장의 이륙료와 도착 헬기장의 착륙료를 더한 값입니다.

- `helipads`의 원소 `[town, takeoff, landing]`은 `town`번 마을에 있는 헬기장 하나를 나타냅니다. 이 헬기장에서 **떠날 때** `takeoff`, 이 헬기장에 **내릴 때** `landing`의 요금이 듭니다.
- 즉 헬기장 `i`에서 떠나 헬기장 `j`에 내리면 `takeoff_i + landing_j`를 내고 `town_i`에서 `town_j`로 이동합니다.
- 한 마을에 헬기장이 여러 개 있을 수 있습니다.
- `roads`의 원소 `[a, b, c]`는 마을 `a`와 `b`를 잇는 양방향 산길로, 지나는 데 비용 `c`가 듭니다. 같은 두 마을을 잇는 산길이 여러 개이거나 `a = b`인 산길이 있을 수 있습니다.

0번 마을에서 `n - 1`번 마을까지 가는 최소 비용을 return 하도록 `solution` 함수를 완성해 주세요. 산길과 헬기를 몇 번이든 섞어 쓸 수 있습니다. 갈 수 없으면 -1을 return 합니다. 비용의 합이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 2 ≤ `n` ≤ 200,000
- 0 ≤ `roads`의 길이 ≤ 300,000
- `roads`의 원소는 `[a, b, c]` 형태이며 0 ≤ `a`, `b` < `n`, 1 ≤ `c` ≤ 1,000,000,000
- 0 ≤ `helipads`의 길이 ≤ 200,000
- `helipads`의 원소는 `[town, takeoff, landing]` 형태이며 0 ≤ `town` < `n`, 0 ≤ `takeoff`, `landing` ≤ 1,000,000,000

## 입출력 예

| n | roads | helipads | result |
|---|---|---|---|
| 5 | [[0, 1, 4], [1, 2, 4], [2, 3, 4], [3, 4, 4]] | [[1, 3, 2], [3, 5, 1], [0, 10, 10]] | 12 |
| 3 | [] | [[0, 5, 5], [2, 1, 1]] | 6 |
| 3 | [[0, 1, 1]] | [[1, 2, 3]] | -1 |

## 입출력 예 설명
- 예 #1: 산길로만 가면 16입니다. 0 → 1을 걸어(4) 1번 마을 헬기장에서 떠나(3) 3번 마을 헬기장에 내린 뒤(1), 3 → 4를 걸으면(4) 4 + 3 + 1 + 4 = 12입니다. 0번 마을 헬기장에서 바로 떠나 3번 마을에 내리면 10 + 1 + 4 = 15입니다.
- 예 #2: 산길이 없지만 0번 마을 헬기장에서 떠나(5) 2번 마을 헬기장에 내리면(1) 6입니다.
- 예 #3: 헬기장이 하나뿐이라 날아갈 곳이 없고, 2번 마을로 가는 산길도 없습니다.
