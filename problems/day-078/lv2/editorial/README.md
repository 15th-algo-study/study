# 해설 — 순찰차의 최단 경로 가짓수

## 접근
다익스트라를 돌리면서 거리와 함께 **그 거리로 도착하는 경로 수** `ways[v]`를 관리합니다.

정점 `v`를 큐에서 꺼내 확정한 뒤, 간선 `(v, u, t)`마다 `nd = dist[v] + t`를 보고
- `nd < dist[u]`: 더 짧은 길을 찾았으므로 `dist[u] = nd`, **`ways[u] = ways[v]`로 새로 시작**, 큐에 넣기
- `nd == dist[u]`: 같은 길이의 다른 길이므로 `ways[u] += ways[v]`
- `nd > dist[u]`: 무시

양수 가중치의 다익스트라는 정점을 거리 순으로 확정하므로, `v`를 꺼낼 때 `v`로 들어오는 최단 경로(모두 `dist`가 더 작은 정점에서 옴)는 이미 다 더해져 `ways[v]`가 완성되어 있습니다. 그래서 `ways[v]`를 이웃에게 한 번만 넘겨주면 됩니다.

답은 `ways[n]`이고, 도달할 수 없으면 0입니다.

## 주의할 점
- 지연 삭제를 쓰는 다익스트라에서 **오래된 항목을 건너뛰지 않으면** 같은 정점을 두 번 처리하면서 `ways`를 이웃에게 두 번 넘겨 경로 수가 부풀려집니다. `if (d > dist[v]) continue;`가 꼭 필요합니다.
- 거리가 줄어들 때 `ways[u] += ways[v]`로 누적하면, 앞서 더 긴 길로 왔던 경로 수가 섞여 틀립니다. 반드시 덮어씁니다.
- 경로 수는 지수적으로 커지므로 더할 때마다 1,000,000,007로 나눈 나머지를 유지합니다(`long`으로 더한 뒤 나머지).
- 거리는 최대 약 2 × 10^14라 `long`입니다.
- 최단 경로를 DFS로 하나씩 세면 경로 수만큼 시간이 걸려 시간 초과입니다.

## 복잡도
- 시간 O((n + m) log m), 공간 O(n + m)
