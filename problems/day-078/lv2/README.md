# [lv2] 순찰차의 최단 경로 가짓수

교차로 `n`개(1번 ~ `n`번)가 양방향 도로로 이어져 있습니다. 경찰서는 1번 교차로에, 순찰 목표 지점은 `n`번 교차로에 있습니다. 순찰차는 항상 걸리는 시간이 가장 짧은 경로로만 이동하는데, 그런 경로가 여러 가지면 매번 무작위로 하나를 고릅니다.

도로 정보 `roads`가 주어질 때, 1번에서 `n`번까지 가는 **최단 시간 경로의 가짓수**를 1,000,000,007로 나눈 나머지를 return 하도록 `solution` 함수를 완성해 주세요. `n`번에 갈 수 없으면 0을 return 합니다.

- `roads`의 원소 `[a, b, t]`는 교차로 `a`와 `b`를 잇고 지나는 데 `t`분 걸리는 양방향 도로입니다.
- 경로는 지나는 **도로의 순서**로 구분합니다. 같은 두 교차로를 잇는 도로가 여러 개면 어느 도로를 탔는지에 따라 서로 다른 경로입니다.

## 제한사항
- 2 ≤ `n` ≤ 200,000
- 1 ≤ `roads`의 길이 ≤ 300,000
- `roads`의 원소는 `[a, b, t]` 형태입니다.
  - 1 ≤ `a`, `b` ≤ `n` (`a = b`인 도로가 있을 수 있습니다)
  - 1 ≤ `t` ≤ 1,000,000,000

## 입출력 예

| n | roads | result |
|---|---|---|
| 4 | [[1, 2, 1], [2, 4, 1], [1, 3, 1], [3, 4, 1], [1, 4, 3]] | 2 |
| 3 | [[1, 2, 2], [1, 2, 2], [2, 3, 1], [1, 3, 3]] | 3 |
| 3 | [[1, 2, 5]] | 0 |

## 입출력 예 설명
- 예 #1: 최단 시간은 2분이며 1 → 2 → 4, 1 → 3 → 4 두 가지입니다. 직통 도로는 3분이라 최단이 아닙니다.
- 예 #2: 최단 시간은 3분입니다. 1 → 2를 잇는 도로 두 개 중 하나를 타고 2 → 3으로 가는 경로 2가지와, 1 → 3 직통 도로 1가지를 합쳐 3가지입니다.
- 예 #3: 3번 교차로로 가는 도로가 없습니다.
