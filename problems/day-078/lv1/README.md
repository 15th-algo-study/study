# [lv1] 항공 화물 운임표

공항 `n`곳(0번 ~ `n - 1`번) 사이의 항공 화물 운임표 `fare`가 있습니다. `fare[i][j]`는 `i`번 공항에서 `j`번 공항으로 가는 **직항** 화물기의 운임이고, 0이면 직항이 없다는 뜻입니다. 운임은 방향마다 다를 수 있습니다(`fare[i][j]`와 `fare[j][i]`가 다를 수 있음). `fare[i][i]`는 쓰지 않습니다.

화물은 여러 공항을 거치며 화물기를 갈아탈 수 있고, 탈 때마다 그 화물기의 운임을 냅니다. 0번 공항에서 각 공항으로 화물을 보내는 최소 운임을 구하려고 합니다.

`i`번 원소가 0번 공항에서 `i`번 공항까지의 최소 운임인 배열을 return 하도록 `solution` 함수를 완성해 주세요. 보낼 수 없는 공항은 -1, 0번 공항 자신은 0입니다. 운임의 합이 `int` 범위를 넘을 수 있으므로 `long[]`로 return 합니다.

## 제한사항
- 1 ≤ `n` ≤ 5,000
- `fare`는 `n` × `n` 크기입니다.
- 0 ≤ `fare[i][j]` ≤ 1,000,000,000

## 입출력 예

| fare | result |
|---|---|
| [[0, 4, 1, 0], [0, 0, 0, 2], [0, 2, 0, 7], [3, 0, 0, 0]] | [0, 3, 1, 5] |
| [[0, 0], [5, 0]] | [0, -1] |
| [[7]] | [0] |

## 입출력 예 설명
- 예 #1
  - 2번: 0 → 2 직항 1
  - 1번: 직항(4)보다 0 → 2 → 1(1 + 2 = 3)이 쌉니다.
  - 3번: 0 → 2 → 3(1 + 7 = 8)보다 0 → 2 → 1 → 3(1 + 2 + 2 = 5)이 쌉니다.
- 예 #2: 1번에서 0번으로 가는 직항은 있지만 0번에서 1번으로 가는 방법은 없습니다.
- 예 #3: 공항이 하나뿐이며 `fare[0][0]`은 쓰지 않습니다.
