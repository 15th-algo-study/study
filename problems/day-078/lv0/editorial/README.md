# 해설 — 패킷 체크섬

## 접근
패킷마다 마지막 원소를 뺀 나머지를 `^`로 누적하고, 마지막 원소와 비교합니다.

```java
int x = 0;
for (int j = 0; j < p.length - 1; j++) x ^= p[j];
if (x != p[p.length - 1]) broken++;
```

XOR 누적의 시작값은 0입니다(`0 ^ a = a`).

## 주의할 점
- 마지막 원소까지 XOR 하면 정상 패킷은 결과가 0이 됩니다(`a ^ a = 0`). 이 성질을 써서 "전체 XOR이 0이 아니면 망가짐"으로 판정해도 됩니다.
- `^`는 자바에서 거듭제곱이 아니라 XOR 입니다. 거듭제곱은 `Math.pow`입니다.
- 비교 연산자 `!=`가 `^`보다 먼저 계산되므로 `a ^ b != c`는 `a ^ (b != c)`로 해석되어 컴파일 오류가 납니다. 괄호를 칩니다.

## 복잡도
- 시간 O(전체 원소 수), 공간 O(1)
