# [lv0] 패킷 체크섬

통신 장비가 보내는 패킷은 정수 여러 개로 이루어져 있습니다. 마지막 정수는 **체크섬**이고, 나머지는 데이터입니다. 패킷이 망가지지 않았다면 체크섬은 데이터 정수들을 모두 XOR(`^`) 한 값과 같습니다.

예를 들어 `[5, 3, 6]`은 데이터 `5`, `3`과 체크섬 `6`으로 이루어진 패킷이고, `5 ^ 3` = `101`₂ ^ `011`₂ = `110`₂ = 6이므로 정상입니다.

받은 패킷 목록 `packets`가 주어질 때, 체크섬이 맞지 않는(망가진) 패킷의 개수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `packets`의 길이 ≤ 100,000
- 2 ≤ `packets[i]`의 길이 ≤ 10 (패킷마다 길이가 다를 수 있습니다)
- 0 ≤ `packets[i][j]` ≤ 1,000,000,000

## 입출력 예

| packets | result |
|---|---|
| [[5, 3, 6], [1, 2, 3, 0], [7, 7, 1]] | 1 |
| [[10, 10], [0, 0]] | 0 |
| [[1, 2, 4, 8, 15], [1000000000, 999999999, 1024]] | 1 |

## 입출력 예 설명
- 예 #1: `5 ^ 3 = 6`(정상), `1 ^ 2 ^ 3 = 0`(정상), `7 ^ 7 = 0`인데 체크섬이 1(망가짐) → 1개
- 예 #2: 데이터가 하나뿐이면 그 값이 곧 체크섬이어야 합니다. 둘 다 정상입니다.
- 예 #3: `1 ^ 2 ^ 4 ^ 8 = 15`(정상). 1,000,000,000은 2진수로 끝에 0이 9개 있어서 1을 빼면 그 9자리가 모두 1로 바뀌고 바로 위 1이 0이 됩니다. 그래서 `1000000000 ^ 999999999` = 2^10 − 1 = 1023이고, 체크섬 1024와 달라 망가진 패킷입니다.
