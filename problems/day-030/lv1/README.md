# [lv1] 수학여행 조 편성

수학여행을 앞두고 학생 `n`명(0번부터 `n−1`번) 중 `r`명을 뽑아 한 조를 만들려고 합니다. 그런데 지난 학기에 다툰 기록이 있는 두 학생은 같은 조에 넣지 않기로 했습니다.

다툰 기록은 2차원 배열 `fights`로 주어지며, 각 원소 `[a, b]`는 학생 `a`와 `b`가 다툰 적이 있다는 뜻입니다. 같은 두 학생의 기록이 여러 번 나올 수 있고, `[a, b]`와 `[b, a]`는 같은 뜻입니다.

`n`, `r`, `fights`가 주어질 때, 다툰 적 있는 두 학생이 함께 들어가지 않도록 `r`명을 뽑는 방법의 수를 return 하도록 `solution` 함수를 완성해 주세요. 조 안에서의 순서는 구별하지 않습니다.

## 제한사항
- 2 ≤ `n` ≤ 20
- 1 ≤ `r` ≤ 5, `r` ≤ `n`
- 0 ≤ `fights`의 길이 ≤ 1,000,000
- `fights`의 각 원소는 `[a, b]` 형태이며 0 ≤ `a`, `b` < `n`, `a ≠ b` 입니다.

## 입출력 예

| n | r | fights | result |
|---|---|---|---|
| 4 | 2 | [[0, 1], [1, 2], [0, 1]] | 4 |
| 5 | 3 | [[0, 1]] | 7 |
| 3 | 3 | [] | 1 |

## 입출력 예 설명
- 예 #1: 두 명 조합 6가지 중 {0, 1}과 {1, 2}를 뺀 {0, 2}, {0, 3}, {1, 3}, {2, 3}의 4가지입니다.
- 예 #2: 세 명 조합 10가지 중 0번과 1번이 함께 들어간 {0, 1, 2}, {0, 1, 3}, {0, 1, 4}를 뺀 7가지입니다.
- 예 #3: 다툰 기록이 없으므로 세 명 전부를 뽑는 1가지입니다.
