# [lv3] 보석 두 상자에 나누기

보석 `n`개의 가치가 배열 `gems`에 들어 있습니다. 보석을 **모두** 두 상자 A, B에 나누어 담되(한 상자가 비어도 됩니다), 두 상자에 담긴 가치의 합이 최대한 비슷하게 만들고 싶습니다.

`gems`가 주어질 때, 두 상자의 가치 합의 차이(절댓값)의 **최솟값**을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `gems`의 길이 `n` ≤ 40
- 1 ≤ `gems`의 원소 ≤ 1,000,000,000
- 가치의 합이 `int` 범위를 넘을 수 있으므로 `long`을 return 합니다.

## 입출력 예

| gems | result |
|---|---|
| [3, 1, 4, 2] | 0 |
| [8, 1, 1] | 6 |
| [1, 2, 4, 8, 16, 32] | 1 |

## 입출력 예 설명
- 예 #1: A = {3, 2}, B = {1, 4}로 나누면 합이 5로 같아 차이가 0입니다.
- 예 #2: 8을 어느 쪽에 두어도 다른 쪽은 최대 2이므로 차이는 6입니다.
- 예 #3: 전체 합이 63이라 가장 가깝게 나누면 31과 32로 차이가 1입니다.
