# [lv2] 줄다리기 균형 배치

체육대회 줄다리기 연습을 위해 선수 `n`명(0번부터 `n−1`번)의 몸무게를 배열 `weights`에 적어 두었습니다. 연습 한 판은 다음과 같이 **배치**합니다.

- 선수마다 **왼쪽 팀**, **오른쪽 팀**, **쉼** 중 하나를 정합니다. 왼쪽 팀과 오른쪽 팀은 서로 다른 팀이므로 두 팀을 통째로 바꾼 배치는 다른 배치입니다.
- 두 팀 모두 최소 한 명은 있어야 합니다.
- 두 팀의 몸무게 합이 같아야 합니다. 이런 배치를 **균형 배치**라고 부릅니다.

코치는 선수별로 "이 선수가 (어느 팀이든) 경기에 **참가하는** 균형 배치는 몇 가지인가?"를 알고 싶어 합니다. 질문할 선수 번호 배열 `players`가 주어질 때, 각 질문의 답을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `weights`의 길이 `n` ≤ 16
- 1 ≤ `weights`의 원소 ≤ 1,000
- 1 ≤ `players`의 길이 ≤ 200,000
- 0 ≤ `players`의 원소 < `n`, 같은 선수가 여러 번 나올 수 있습니다.

## 입출력 예

| weights | players | result |
|---|---|---|
| [1, 2, 3] | [0, 1, 2] | [2, 2, 2] |
| [5, 5, 5] | [0] | [4] |
| [1, 2] | [0, 1] | [0, 0] |

## 입출력 예 설명
- 예 #1: 균형 배치는 "왼쪽 {0, 1}, 오른쪽 {2}"와 "왼쪽 {2}, 오른쪽 {0, 1}"의 2가지뿐이고, 세 선수 모두 두 배치에 참가합니다.
- 예 #2: 균형 배치는 한 명 대 한 명인 6가지(왼쪽에 올 선수 3가지 × 오른쪽에 올 선수 2가지)입니다. 0번 선수가 참가하는 배치는 왼쪽일 때 2가지, 오른쪽일 때 2가지로 4가지입니다.
- 예 #3: 몸무게 1과 2로는 균형을 맞출 수 없습니다.
