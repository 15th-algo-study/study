# 해설 — 줄다리기 균형 배치

## 접근
선수마다 선택지가 왼쪽·오른쪽·쉼의 3가지이므로 배치는 3^16 ≈ 4,300만 가지입니다. 이 정도는 재귀로 **한 번** 전부 열거할 수 있습니다. 하지만 질문이 20만 개이므로 질문마다 열거하면 안 되고, 열거하면서 "어떤 선수들이 참가하는 균형 배치가 몇 개인지"를 기록해 두어야 합니다.

1. `assign(i, left, right, mask)`: `i`번 선수를 왼쪽(`left += w`), 오른쪽(`right += w`), 쉼 중 하나로 정하고 다음 선수로 갑니다. `mask`는 참가(왼쪽 또는 오른쪽)한 선수들의 비트마스크입니다.
2. 모든 선수를 정했을 때 `left == right`이고 두 팀이 모두 비어 있지 않으면 `balanced[mask]++`.
3. 선수 `p`의 답은 `p`번 비트가 켜진 모든 `mask`에 대한 `balanced[mask]`의 합입니다. `mask`는 2^16개뿐이므로 선수 16명 각각에 대해 미리 합을 구해 두면(16 × 65,536) 질문은 O(1)입니다.

두 팀이 모두 비어 있지 않은지는 "왼쪽 팀 비트마스크 ≠ 0, 오른쪽 팀 비트마스크 ≠ 0"으로 확인하거나, 각 팀의 인원 수를 함께 넘기면 됩니다.

## 주의할 점
- 왼쪽 팀과 오른쪽 팀을 바꾼 배치는 **다른** 배치입니다(예 #2에서 6가지). 한쪽만 세고 2배 하는 식으로 풀어도 되지만, 그 경우 왼쪽 집합 S와 오른쪽 집합 T를 열거할 때 S와 T가 겹치지 않아야 합니다.
- 균형 배치 수의 최댓값은 몸무게가 모두 같을 때로 약 5,196,626가지라 `int` 범위입니다.
- 재귀 깊이는 16으로 얕지만 호출 횟수가 약 6,500만 번이므로, 재귀 안에서 객체를 만들거나 컬렉션을 쓰면 느려집니다. 기본형 인자만 넘기세요.
- 왼쪽과 오른쪽을 따로 2^16씩 독립적으로 열거해 "겹치지 않으면 센다"로 하면 4^16 ≈ 4.3×10^9번이라 시간 초과입니다.

## 복잡도
- 시간 O(3^n + n · 2^n + m) (m = 질문 수), 공간 O(2^n)
