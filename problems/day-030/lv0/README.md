# [lv0] 도미노 놓을 자리

`R`행 `C`열 격자판의 각 칸에 수가 적혀 있고, 2차원 배열 `board`로 주어집니다. 도미노 하나는 **가로 또는 세로로 이웃한 두 칸**을 덮습니다.

도미노를 놓았을 때 덮인 두 칸의 수의 합이 `k`의 배수가 되는 자리가 몇 개인지 return 하도록 `solution` 함수를 완성해 주세요. 도미노는 한 번에 하나만 놓는다고 생각하고, 서로 다른 두 칸의 쌍을 모두 자리로 셉니다.

## 제한사항
- 1 ≤ `R`, `C` ≤ 1,000 (`board`의 행 수 `R`, 열 수 `C`)
- 1 ≤ `board`의 원소 ≤ 1,000,000
- 1 ≤ `k` ≤ 2,000,000

## 입출력 예

| board | k | result |
|---|---|---|
| [[1, 2, 3], [4, 5, 6]] | 3 | 3 |
| [[1], [1], [1]] | 2 | 2 |
| [[2]] | 1 | 0 |

## 입출력 예 설명
- 예 #1: 가로 자리는 (1, 2)=3, (2, 3)=5, (4, 5)=9, (5, 6)=11이고 세로 자리는 (1, 4)=5, (2, 5)=7, (3, 6)=9입니다. 3의 배수인 자리는 3, 9, 9의 세 곳입니다.
- 예 #2: 세로로만 두 자리가 있고 두 곳 모두 합이 2입니다.
- 예 #3: 칸이 하나뿐이라 도미노를 놓을 자리가 없습니다.
