# 해설 — 도미노 놓을 자리

## 접근
모든 칸 `(r, c)`를 이중 반복문으로 돌면서, 그 칸을 **왼쪽 칸**으로 하는 가로 자리 `(r, c)-(r, c+1)`과 **위쪽 칸**으로 하는 세로 자리 `(r, c)-(r+1, c)`를 확인합니다. 이렇게 하면 모든 자리를 정확히 한 번씩 봅니다.

- 가로: `c + 1 < C`일 때 `(board[r][c] + board[r][c+1]) % k == 0`
- 세로: `r + 1 < R`일 때 `(board[r][c] + board[r+1][c]) % k == 0`

## 주의할 점
- 오른쪽 끝 열에서는 가로 자리가, 맨 아래 행에서는 세로 자리가 없습니다. 범위 검사를 빠뜨리면 `ArrayIndexOutOfBoundsException`이 납니다.
- 왼쪽·오른쪽, 위·아래를 모두 확인하면 같은 자리를 두 번 셉니다. 한 방향(오른쪽, 아래)만 봅니다.
- 두 칸의 합은 최대 2,000,000이라 `int`로 충분합니다.

## 복잡도
- 시간 O(R × C), 공간 O(1)
