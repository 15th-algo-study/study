# [lv3] 조립식 책상 높이 맞추기

조립식 책상은 **상판, 다리, 받침, 바퀴** 네 부품을 하나씩 골라 쌓아 만듭니다. 책상의 높이는 네 부품 높이의 합입니다.

창고에 있는 부품 후보의 높이가 네 배열 `tops`, `legs`, `bases`, `wheels`에 들어 있습니다. 같은 배열 안에 높이가 같은 부품이 여러 개 있어도 서로 다른 부품입니다.

네 부품을 하나씩 골라 책상 높이가 **정확히 `target`**이 되게 하는 방법의 수를 return 하도록 `solution` 함수를 완성해 주세요. 두 방법은 고른 부품 중 하나라도 다르면 다른 방법입니다.

## 제한사항
- 1 ≤ `tops`, `legs`, `bases`, `wheels`의 길이 ≤ 1,600 (네 길이는 서로 다를 수 있습니다)
- 1 ≤ 각 부품의 높이 ≤ 1,000,000,000
- 1 ≤ `target` ≤ 4,000,000,000 (`long`)
- 방법의 수가 `int` 범위를 넘을 수 있으므로 `long`을 return 합니다.

## 입출력 예

| tops | legs | bases | wheels | target | result |
|---|---|---|---|---|---|
| [1, 2] | [10, 20] | [100] | [5, 5] | 116 | 2 |
| [1, 1] | [1, 1] | [1, 1] | [1, 1] | 4 | 16 |
| [3] | [3] | [3] | [3] | 13 | 0 |

## 입출력 예 설명
- 예 #1: 1 + 10 + 100 + 5 = 116이고, 바퀴는 높이 5짜리가 두 개라 2가지입니다. 다른 조합은 116이 되지 않습니다.
- 예 #2: 어떤 부품을 골라도 높이가 4이므로 2 × 2 × 2 × 2 = 16가지입니다.
- 예 #3: 유일한 조합의 높이는 12입니다.
