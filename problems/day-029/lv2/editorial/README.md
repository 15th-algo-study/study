# 해설 — 마카롱 상자 구성

## 접근
구성은 "맛별 개수 `(c₀, c₁, …, c_{k−1})`, 합이 `n`"인 **중복조합**입니다. 개수는 최대 C(20 + 7 − 1, 7 − 1) = C(26, 6) = 230,230가지뿐이므로 모두 열거할 수 있습니다. 다만 손님마다 다시 열거하면 230,230 × 200,000 ≈ 4.6×10^10번이라 시간 초과이므로, 한 번만 열거해 **총액별 가짓수 표**를 만들고 누적합으로 답합니다.

1. 재귀 `fill(flavor, left, cost)`: `flavor`번 맛에 0개부터 `left`개까지 차례로 배정하고 다음 맛으로 넘어갑니다. 마지막 맛에는 남은 `left`개를 전부 배정합니다(합이 정확히 `n`이 되도록).
2. 모든 맛을 배정했으면 `count[cost]++` (총액 ≤ 20 × 1,000 = 20,000).
3. `prefix[b] = count[0] + … + count[b]`를 만들고, 손님의 답은 `prefix[min(예산, 최대 총액)]`입니다.

## 주의할 점
- 같은 맛의 마카롱은 구별하지 않으므로 "어떤 마카롱을 고르나"가 아니라 "맛별로 몇 개인가"를 열거해야 합니다. 순열이나 일반 조합으로 세면 같은 구성을 여러 번 셉니다.
- 마지막 맛에서 `0..left`를 모두 시도하면 합이 `n`보다 작은 구성까지 세게 됩니다. 마지막 맛은 남은 개수를 전부 받아야 합니다.
- 가짓수의 최댓값 230,230은 `int` 범위이고, 예산이 최대 총액보다 크면 표 범위를 넘으므로 잘라서 조회합니다.

## 복잡도
- 시간 O(C(n+k−1, k−1) · k + S + m) (S = 최대 총액 ≤ 20,000, m = 손님 수), 공간 O(S)
