# [lv2] 마카롱 상자 구성

마카롱 가게에 맛이 `k`가지 있고, 맛별 가격(한 개당)이 배열 `prices`에 들어 있습니다. 선물 상자에는 마카롱을 **정확히 `n`개** 담아야 하며, 맛별로 몇 개를 담을지는 자유입니다(어떤 맛은 0개여도 되고, 같은 맛만 `n`개여도 됩니다). 같은 맛의 마카롱은 서로 구별하지 않으므로, 상자의 **구성**은 "맛별 개수"로만 정해집니다.

손님들이 예산을 말하면, 그 예산 **이하**로 만들 수 있는 상자 구성이 몇 가지인지 알려 주려고 합니다.

`prices`, `n`, 손님들의 예산 배열 `budgets`가 주어질 때, 각 손님에 대해 총액이 예산 이하인 구성의 수를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `prices`의 길이 `k` ≤ 7
- 1 ≤ `prices`의 원소 ≤ 1,000
- 1 ≤ `n` ≤ 20
- 1 ≤ `budgets`의 길이 ≤ 200,000
- 0 ≤ `budgets`의 원소 ≤ 20,000

## 입출력 예

| prices | n | budgets | result |
|---|---|---|---|
| [100, 200] | 3 | [300, 400, 600, 299] | [1, 2, 4, 0] |
| [50, 50, 50] | 2 | [100] | [6] |
| [300] | 20 | [5999, 6000] | [0, 1] |

## 입출력 예 설명
- 예 #1: 3개를 담는 구성은 (3, 0)=300원, (2, 1)=400원, (1, 2)=500원, (0, 3)=600원입니다. 예산 300이면 1가지, 400이면 2가지, 600이면 4가지, 299면 0가지입니다.
- 예 #2: 세 가지 맛에서 2개를 담는 구성은 (2,0,0), (0,2,0), (0,0,2), (1,1,0), (1,0,1), (0,1,1)의 6가지이고 모두 100원입니다.
- 예 #3: 한 가지 맛뿐이라 구성은 20개 담는 하나(6000원)뿐입니다.
