# [lv1] 숫자 도장으로 만드는 수

숫자 도장 `n`개가 있고, 각 도장에 새겨진 숫자가 배열 `digits`에 들어 있습니다. 숫자는 1부터 9까지이며 같은 숫자의 도장이 여러 개 있을 수 있습니다.

도장을 **모두 한 번씩** 찍어 `n`자리 수를 만듭니다. 같은 숫자의 도장을 서로 바꿔 찍으면 같은 수가 되므로, **서로 다른 수**만 모아 오름차순으로 나열합니다.

질문 배열 `ks`가 주어질 때, 각 `ks[i]`에 대해 나열한 수 중 `ks[i]`번째(1번부터) 수를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 만들 수 있는 서로 다른 수가 `ks[i]`개보다 적으면 그 자리에는 `-1`을 넣습니다.

## 제한사항
- 1 ≤ `digits`의 길이 `n` ≤ 9
- 1 ≤ `digits`의 원소 ≤ 9
- 1 ≤ `ks`의 길이 ≤ 200,000
- 1 ≤ `ks`의 원소 ≤ 362,880

## 입출력 예

| digits | ks | result |
|---|---|---|
| [1, 2, 2] | [1, 2, 3, 4] | [122, 212, 221, -1] |
| [3, 1] | [2, 1] | [31, 13] |
| [5] | [1, 2] | [5, -1] |

## 입출력 예 설명
- 예 #1: 도장 세 개를 모두 찍어 만들 수 있는 서로 다른 수는 122, 212, 221 세 개입니다. 4번째 수는 없으므로 -1입니다.
- 예 #2: 13과 31을 만들 수 있고, 2번째 수는 31, 1번째 수는 13입니다.
- 예 #3: 한 자리 수 5 하나뿐입니다.
