# 해설 — 숫자 도장으로 만드는 수

## 접근
도장이 최대 9개이므로 찍는 순서(순열)는 9! = 362,880가지뿐입니다. 순열을 **한 번만** 모두 만들어 수의 목록을 완성해 두고, 질문은 목록에서 바로 꺼냅니다.

1. 재귀로 모든 순열을 만들며 수를 계산해(`value = value * 10 + digit`) 배열에 모읍니다.
2. 배열을 정렬한 뒤 이웃한 같은 값을 건너뛰며 **서로 다른 수**만 앞쪽으로 모읍니다(중복 제거).
3. 질문 `k`에 대해 `k ≤ 서로 다른 수의 개수`이면 `distinct[k − 1]`, 아니면 `-1`입니다.

## 주의할 점
- 질문마다 순열을 다시 만들면 362,880 × 9 × 200,000번 연산이라 시간 초과입니다.
- 9자리 수의 최댓값 999,999,999는 `int` 범위입니다.
- 같은 숫자 도장을 바꿔 찍은 순열은 같은 수가 되므로 반드시 중복을 제거해야 합니다(예 #1에서 순열은 6가지지만 수는 3가지). `TreeSet`을 써도 되지만 배열 정렬 + 중복 건너뛰기가 더 빠릅니다.
- 중복 제거 후 개수가 질문의 `k`보다 작을 수 있으므로 범위를 확인하고 `-1`을 넣습니다.

## 복잡도
- 시간 O(n! · n + n! log n! + m) (m = 질문 수), 공간 O(n!)
