# 해설 — 쿠키 상자 직사각형 배치

## 접근
`m`개의 배치 가짓수는 `w ≤ h`, `w × h = m`인 쌍의 수, 즉 `m`의 약수 쌍의 수입니다. 개수마다 약수를 하나하나 세면 `n = 10^6`에서 느려질 수 있으므로, 반대로 **가로 `w`와 세로 `h`를 중첩 반복문으로 돌리며 `w × h`칸에 1을 더합니다.**

```
for w = 1, 2, … (w * w <= n)
    for h = w, w+1, … (w * h <= n)
        count[w * h]++
```

- 바깥 반복은 `√n ≈ 1,000`번, 안쪽 반복은 `n / w − w + 1`번이라 전체 약 `n · ln(√n)` ≈ 700만 번입니다.
- 마지막에 1부터 `n`까지 훑으며 `count[m]`이 **처음으로** 최댓값을 넘는 `m`을 기억하면 "가장 작은 개수" 조건이 자동으로 지켜집니다.

## 주의할 점
- 안쪽 반복을 `h = 1`부터 시작하면 `w × h`와 `h × w`를 두 번 셉니다. `h = w`부터 시작해야 합니다.
- 최댓값 갱신 조건을 `>=`로 쓰면 같은 가짓수 중 가장 큰 개수가 남습니다. `>`를 써야 가장 작은 개수가 남습니다.
- `count` 배열은 인덱스 `n`까지 쓰므로 크기를 `n + 1`로 잡습니다.

## 복잡도
- 시간 O(n log n), 공간 O(n)
