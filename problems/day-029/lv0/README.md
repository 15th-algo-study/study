# [lv0] 쿠키 상자 직사각형 배치

정사각형 쿠키를 상자에 **직사각형 모양으로 빈틈없이** 담으려고 합니다. 쿠키 `m`개를 가로 `w`개, 세로 `h`개(`w ≤ h`, `w × h = m`)로 놓는 것을 하나의 배치로 봅니다. 예를 들어 쿠키 12개는 1×12, 2×6, 3×4 세 가지 배치가 가능합니다. (3×4와 4×3은 상자를 돌리면 같으므로 하나로 셉니다.)

정수 `n`이 주어질 때, 1개부터 `n`개까지의 쿠키 개수 중 **배치의 가짓수가 가장 많은 개수**와 **그 가짓수**를 `[개수, 가짓수]` 형태로 return 하도록 `solution` 함수를 완성해 주세요. 가짓수가 같은 개수가 여럿이면 가장 작은 개수를 고릅니다.

## 제한사항
- 1 ≤ `n` ≤ 1,000,000

## 입출력 예

| n | result |
|---|---|
| 12 | [12, 3] |
| 6 | [4, 2] |
| 1 | [1, 1] |

## 입출력 예 설명
- 예 #1: 12개는 1×12, 2×6, 3×4로 3가지입니다. 1~11개 중 3가지인 개수는 없습니다.
- 예 #2: 4개(1×4, 2×2)와 6개(1×6, 2×3)가 2가지로 가장 많고, 더 작은 4를 고릅니다.
- 예 #3: 쿠키 1개는 1×1 한 가지입니다.
