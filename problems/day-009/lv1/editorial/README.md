# 해설 — 문서 제목 번호 매기기

## 접근
크기 7인 정수 배열 `counter`(1~6번 칸 사용)를 두고 줄마다 다음을 합니다.

1. 앞에서부터 `#`의 개수 `d`를 셉니다. 제목은 `line.substring(d + 1)`입니다.
2. `counter[d]++`, 그리고 `d+1`부터 6까지는 0으로 되돌립니다.
3. `counter[1]`부터 `counter[d]`까지를 `.`으로 이어 붙이고, 공백과 제목을 붙입니다.

번호 하나는 최대 6개 수를 이어 붙인 짧은 문자열이므로 줄마다 `StringBuilder`를 새로 써도 충분합니다.

## 주의할 점
- 더 깊은 수준의 칸을 **0으로 되돌리는 것**을 빠뜨리면 `# body` 뒤의 `### detail`이 `2.2.1`처럼 이전 장의 번호를 끌고 옵니다.
- 수준이 뛰어넘어 올라갈 때(1수준 → 3수준) 중간 칸은 0이어야 하므로 `0`도 그대로 출력합니다. "0인 칸은 건너뛴다"고 임의로 바꾸면 안 됩니다.
- `#`의 개수는 `indexOf(' ')`로 한 번에 구할 수 있습니다. 제목에는 공백이 없으므로 첫 공백이 곧 `#` 부분의 끝입니다.
- 20만 줄을 `String.join`이나 `String.format`으로 만들면 조금 느리지만 통과합니다. 다만 `String.format`은 수십만 번 호출하면 눈에 띄게 느려지니 `StringBuilder`가 안전합니다.

## 복잡도
- 시간 O(줄 수 × 6 + 전체 글자 수), 공간 O(출력 크기)
