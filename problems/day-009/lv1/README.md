# [lv1] 문서 제목 번호 매기기

문서의 제목 줄들이 문자열 배열 `lines`로 주어집니다. 각 줄은 `#`가 1개 이상 6개 이하 이어진 뒤 공백 하나, 그 뒤에 제목이 오는 형태입니다. `#`의 개수가 제목의 **수준**입니다 (`#`는 1수준, `##`는 2수준, …).

제목에 번호를 매기려고 합니다. 수준마다 번호 칸이 하나씩 있고(1수준 칸부터 6수준 칸까지), 처음에는 모두 0입니다. 줄을 앞에서부터 처리하며

- `d`수준 제목이 나오면 `d`수준 칸을 1 늘리고, `d`보다 깊은 수준의 칸은 모두 0으로 되돌립니다.
- 그 제목의 번호는 1수준 칸부터 `d`수준 칸까지의 값을 `.`으로 이어 붙인 것입니다.

각 줄을 `"번호 제목"` 형태(번호, 공백 하나, 제목)로 바꾼 문자열 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `lines`의 길이 ≤ 200,000
- 각 줄은 `#` 1~6개, 공백 하나, 제목 순서이며 제목은 영문 소문자와 숫자로 이루어진 1자 이상 20자 이하의 문자열입니다.
- 수준은 어떤 순서로도 나올 수 있습니다. 예를 들어 첫 줄이 3수준이거나, 1수준 다음에 바로 3수준이 올 수도 있습니다.

## 입출력 예

| lines | result |
|---|---|
| ["# intro", "## goal", "## scope", "# body", "### detail"] | ["1 intro", "1.1 goal", "1.2 scope", "2 body", "2.0.1 detail"] |
| ["### a", "# b", "# c"] | ["0.0.1 a", "1 b", "2 c"] |
| ["# x", "## y", "### z", "## w", "# v", "## u"] | ["1 x", "1.1 y", "1.1.1 z", "1.2 w", "2 v", "2.1 u"] |

## 입출력 예 설명
- 예 #1: `# body`에서 1수준 칸이 2가 되고 2수준 칸은 0으로 돌아갑니다. 이어서 `### detail`은 2수준 칸이 0인 채로 3수준 칸만 1이 되어 `2.0.1`입니다.
- 예 #2: 첫 줄이 3수준이면 1·2수준 칸은 0인 채로 `0.0.1`입니다. 이후 `# b`에서 1수준 칸이 1이 되고 2·3수준 칸은 0으로 돌아갑니다.
- 예 #3: 수준이 하나씩 깊어졌다가 얕아지는 일반적인 문서입니다.
