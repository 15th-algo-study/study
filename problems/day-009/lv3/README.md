# [lv3] 끝없는 암호 띠

영문 소문자 문자열 `s`를 바탕으로 끝없이 긴 암호 띠를 만듭니다. 띠는 `s`를 변형한 **조각**들을 차례로 이어 붙인 것입니다.

- 0번 조각은 `s` 그대로입니다.
- `k`번 조각은 `s`의 모든 글자를 알파벳 순서로 `k`칸 뒤로 민 것입니다. `z` 다음은 다시 `a`로 돌아갑니다. 즉 `k`번 조각의 글자는 `(원래 글자 + k) mod 26`입니다.
- 띠는 0번 조각, 1번 조각, 2번 조각, … 순서로 끝없이 이어집니다.

예를 들어 `s = "ab"`이면 띠는 `ab` `bc` `cd` `de` … 로 이어져 `abbccdde…`가 됩니다.

띠의 위치는 맨 앞 글자를 1번으로 하여 셉니다. 질의 배열 `queries`의 각 원소는 `"l r c"` 형태로, 두 위치 `l`, `r`과 소문자 하나 `c`를 뜻합니다. 각 질의마다 **두 위치 사이(양 끝 포함)에 글자 `c`가 몇 번 나오는지**를 구해 순서대로 담은 `long` 배열을 return 하도록 `solution` 함수를 완성해 주세요. `l`이 `r`보다 클 수도 있으며, 이때도 두 위치 사이의 구간을 뜻합니다.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 200,000
- `s`는 영문 소문자로만 이루어져 있습니다.
- 1 ≤ `queries`의 길이 ≤ 200,000
- 각 질의는 `"l r c"` 형태이고, 1 ≤ `l`, `r` ≤ 10^18, `c`는 영문 소문자입니다. 공백은 각각 하나입니다.
- 답은 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| s | queries | result |
|---|---|---|
| "ab" | ["1 4 b", "3 3 b", "1 52 a", "5 1 c"] | [2, 1, 2, 2] |
| "z" | ["1 27 z", "26 26 y"] | [2, 1] |
| "abc" | ["1 1000000000000000000 a"] | [38461538461538461] |

## 입출력 예 설명
- 예 #1: 띠는 `a b b c c d d e e f …` 입니다.
  - 1~4번: `a b b c` → `b`는 2번
  - 3~3번: `b` → 1번
  - 1~52번은 0번~25번 조각 전체입니다. `a`는 0번 조각(`ab`)의 첫 글자와 25번 조각(`za`)의 둘째 글자에 나와 2번입니다.
  - `5 1 c`는 1~5번 구간이고 `a b b c c` → `c`는 2번
- 예 #2: 띠는 `z a b c … y z a …` 로, `z`는 1번과 27번 위치에 있습니다. 26번 위치는 25번 조각의 `y`입니다.
- 예 #3: 조각 26개(78글자)마다 `a`가 정확히 3번 나옵니다. 10^18 = 78 × 12,820,512,820,512,820 + 40 이고, 남은 40글자(0번~12번 조각과 13번 조각의 첫 글자) 중 `a`는 0번 조각의 첫 글자 하나뿐이므로 3 × 12,820,512,820,512,820 + 1 입니다.
