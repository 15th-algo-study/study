# [lv0] 번갈아 대소문자

문자열 `s`의 영문자를 **앞에서부터 번갈아** 대문자, 소문자, 대문자, … 로 바꾸려고 합니다. 규칙은 다음과 같습니다.

- 영문자만 셉니다. 첫 번째 영문자는 대문자, 두 번째 영문자는 소문자, 세 번째는 대문자, … 로 바꿉니다.
- 숫자와 공백은 그대로 두며, 번갈아 세는 순서에도 넣지 않습니다.

규칙을 적용한 문자열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 1,000,000
- `s`는 영문 대문자, 영문 소문자, 숫자, 공백으로만 이루어져 있습니다.

## 입출력 예

| s | result |
|---|---|
| "hello world" | "HeLlO wOrLd" |
| "a1b2c3" | "A1b2C3" |
| "ABC" | "AbC" |

## 입출력 예 설명
- 예 #1: 공백은 순서에 넣지 않으므로 `w`는 `o` 다음의 6번째 영문자로서 소문자입니다.
- 예 #2: 숫자를 건너뛰고 `a`, `b`, `c`가 1·2·3번째 영문자입니다.
- 예 #3: 원래 대문자였더라도 규칙대로 바꿉니다.
