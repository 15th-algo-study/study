# 해설 — 따옴표가 있는 표 한 줄 나누기

## 접근
"지금 따옴표 안인가"를 뜻하는 플래그 하나로 돌아가는 **상태 기계**입니다. 글자를 한 번씩만 보며 현재 칸을 `StringBuilder`에 모읍니다.

- **따옴표 밖**에서
  - `,` → 현재 칸을 결과에 넣고 새 칸 시작
  - `"` → 따옴표 안으로 들어감 (칸이 시작될 때만 나옵니다)
  - 그 밖 → 칸에 붙임
- **따옴표 안**에서
  - `"` 다음 글자가 `"` → 큰따옴표 하나를 칸에 붙이고 **두 글자**를 건너뜀
  - `"` 다음 글자가 `"`가 아님(또는 끝) → 따옴표 밖으로 나감
  - 그 밖(쉼표 포함) → 칸에 붙임

줄이 끝나면 마지막 칸을 결과에 넣습니다. 쉼표로 끝났다면 마지막 칸은 빈 문자열이 되어 자연스럽게 처리됩니다.

## 주의할 점
- `line.split(",")`은 따옴표 안의 쉼표에서도 잘라 버리고, 줄 끝의 빈 칸도 버립니다(`split`은 뒤쪽 빈 문자열을 제거합니다). 이 문제에서는 두 가지 모두 오답입니다.
- `""`를 처리할 때 **두 글자를 함께 소비**해야 합니다. 한 글자씩 보며 "따옴표를 만나면 상태를 뒤집는" 식으로만 짜면 `""`가 닫힘-열림으로 해석되어 우연히 맞는 경우도 있지만, `"a""",b`처럼 `""` 바로 뒤에 닫는 따옴표가 오면 틀립니다. 다음 글자를 미리 보고 결정하세요.
- 칸 하나가 20만 글자일 수 있으니 칸 내용은 `StringBuilder`로 모읍니다. `String +=`는 O(n²)입니다.
- 결과 칸 수를 미리 알 수 없으므로 `List<String>`에 모은 뒤 배열로 바꿉니다.

## 복잡도
- 시간 O(n), 공간 O(n)
