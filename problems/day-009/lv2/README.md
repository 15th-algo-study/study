# [lv2] 따옴표가 있는 표 한 줄 나누기

표 데이터 한 줄이 문자열 `line`으로 주어집니다. 칸(필드)은 쉼표(`,`)로 구분되는데, 칸 안에 쉼표나 따옴표를 넣기 위해 다음 규칙을 씁니다.

- 칸은 **따옴표로 감싼 칸**과 **감싸지 않은 칸** 두 종류입니다.
- 감싸지 않은 칸에는 쉼표와 큰따옴표(`"`)가 들어 있지 않습니다. 빈 칸(길이 0)도 가능합니다.
- 감싼 칸은 `"`로 시작해 `"`로 끝납니다. 그 안에서 쉼표는 그냥 글자이고, 연속된 두 개의 큰따옴표 `""`는 큰따옴표 글자 하나를 뜻합니다. 그 밖의 홑 큰따옴표는 칸의 끝입니다.
- 감싼 칸의 여는 `"` 바로 앞과 닫는 `"` 바로 뒤에는 쉼표가 오거나 줄의 시작·끝입니다.

예를 들어 `a,"x,y",,"he said ""hi"""`는 네 칸 `a` / `x,y` / (빈 칸) / `he said "hi"` 로 나뉩니다.

`line`을 칸으로 나누고, 따옴표 규칙을 푼 **칸의 내용**을 순서대로 담은 문자열 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `line`의 길이 ≤ 200,000
- `line`은 영문 소문자, 숫자, 공백, `,`, `"`로만 이루어져 있으며 위 규칙에 맞는 올바른 한 줄입니다.
- 칸은 1개 이상입니다. `line`이 쉼표로 끝나면 마지막 칸은 빈 칸입니다. 예를 들어 `"a,"`는 두 칸 `a` / (빈 칸) 입니다.

## 입출력 예

| line | result |
|---|---|
| `a,b,c` | ["a", "b", "c"] |
| `a,"x,y",,"he said ""hi"""` | ["a", "x,y", "", "he said \"hi\""] |
| `"",a,` | ["", "a", ""] |

## 입출력 예 설명
- 예 #1: 따옴표가 없으면 쉼표로 나누기만 하면 됩니다.
- 예 #2: `"x,y"` 안의 쉼표는 구분자가 아닙니다. `"he said ""hi"""`는 안쪽의 `""` 두 쌍이 각각 큰따옴표 글자 하나가 되고, 마지막 `"`가 칸을 닫습니다.
- 예 #3: 첫 칸은 따옴표로 감싼 빈 칸이고, 마지막 쉼표 뒤에 빈 칸이 하나 더 있습니다.
