# [lv3] 거리 공연 의뢰

거리 공연가에게 공연 의뢰 `n`건이 들어왔습니다. 의뢰 `i`는 **`deadline[i]`일까지**(그날 포함) 공연해 주면 출연료 `fee[i]`를 줍니다. 공연가는 하루에 **한 건**만 공연할 수 있고, 오늘은 1일째입니다. 즉 의뢰 `i`는 1일, 2일, …, `deadline[i]`일 가운데 하루를 골라 공연할 수 있으며, 공연하지 않은 의뢰는 출연료를 받지 못합니다.

받을 수 있는 **출연료 합의 최댓값**을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 400,000 (`deadline`과 `fee`의 길이는 같습니다)
- 1 ≤ `deadline[i]` ≤ 1,000,000,000
- 1 ≤ `fee[i]` ≤ 1,000,000,000
- 답이 `int` 범위를 넘을 수 있으므로 `long`을 return 합니다.

## 입출력 예

| deadline | fee | result |
|---|---|---|
| [1, 1, 2] | [3, 6, 7] | 13 |
| [2, 3, 1, 3] | [7, 1, 4, 9] | 20 |
| [5] | [10] | 10 |

## 입출력 예 설명
- 예 #1: 1일에 의뢰 1(출연료 6), 2일에 의뢰 2(출연료 7)를 공연하면 13입니다. 의뢰 0과 1은 모두 1일까지라 둘 중 하나만 할 수 있습니다.
- 예 #2: 1일에 의뢰 2(4), 2일에 의뢰 0(7), 3일에 의뢰 3(9)을 하면 20입니다. 의뢰 1(1)은 포기합니다.
- 예 #3: 아무 날이나 하루 공연하면 됩니다.
