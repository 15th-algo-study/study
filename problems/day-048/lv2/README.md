# [lv2] 운세 카드 뒤집기

운세 카드 `n`장이 한 줄로 놓여 있고, 카드 `i`에는 정수 `cards[i]`가 적혀 있습니다. 카드를 한 장 뒤집으면 적힌 수의 **부호가 바뀝니다**(3 → −3, −3 → 3, 0 → 0). 같은 카드를 여러 번 뒤집어도 됩니다.

카드를 **정확히 `k`번** 뒤집은 뒤, 카드에 적힌 수의 합이 가장 커지게 하려 합니다. 그 최댓값을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `cards`의 길이 `n` ≤ 200,000
- −1,000,000,000 ≤ `cards`의 원소 ≤ 1,000,000,000
- 1 ≤ `k` ≤ 1,000,000,000
- 답이 `int` 범위를 넘을 수 있으므로 `long`을 return 합니다.

## 입출력 예

| cards | k | result |
|---|---|---|
| [3, -1, -4, 2] | 2 | 10 |
| [3, -1, -4, 2] | 3 | 8 |
| [5, 0, 2] | 1 | 7 |

## 입출력 예 설명
- 예 #1: −4와 −1을 한 번씩 뒤집으면 3 + 1 + 4 + 2 = 10입니다.
- 예 #2: 뒤집기를 한 번 더 해야 합니다. 10에서 절댓값이 가장 작은 1을 뒤집어 3 − 1 + 4 + 2 = 8이 최선입니다. 같은 카드를 두 번 뒤집어 돌려놓는 식으로 횟수를 쓸 수도 있지만, 세 번은 홀수라 어떤 카드든 하나는 부호가 바뀐 채 남습니다.
- 예 #3: 0을 뒤집으면 아무 변화가 없어 7 그대로입니다.
