# 해설 — 운세 카드 뒤집기

## 접근
1. 오름차순으로 정렬한 뒤, **절댓값이 큰 음수부터**(정렬된 앞쪽부터) 뒤집기 횟수가 남아 있는 동안 한 번씩 뒤집습니다. 음수 하나를 뒤집으면 합이 `2|x|`만큼 늘어나므로, 뒤집을 음수를 고른다면 절댓값이 큰 것부터 고르는 것이 당연히 유리합니다(교환 논법: 작은 음수를 뒤집고 큰 음수를 남긴 해에서 둘을 바꾸면 합이 커집니다).
2. 음수가 다 떨어졌거나 횟수를 다 썼으면 멈춥니다. 남은 횟수 `k'`가 **짝수**이면 한 카드를 두 번 뒤집어 없앨 수 있으므로 지금 합이 답입니다.
3. `k'`가 **홀수**이면 어떤 카드든 한 장은 부호가 바뀐 채 남아야 합니다. 손해를 가장 적게 보려면 **현재 절댓값이 가장 작은 카드**를 뒤집습니다(답은 `합 − 2 × 최소 절댓값`). 0이 있으면 손해가 없습니다.

## 주의할 점
- 횟수가 음수 개수보다 많을 때가 핵심입니다. "작은 값 k개를 한 번씩 뒤집는다"는 가짜 그리디는 `[1, 2, 3], k = 2`에서 −1 −2 + 3 = 0을 내지만 정답은 6입니다(1을 두 번 뒤집음).
- 3단계의 "절댓값이 가장 작은 카드"는 1단계에서 뒤집은 뒤의 값으로 찾아야 합니다. 예를 들어 `[-3, -2, -1], k = 4`이면 세 장을 뒤집어 `[3, 2, 1]`이 되고 남은 1회로 1을 뒤집어 4입니다.
- 합은 최대 2×10^14라 `long`이 필요합니다.
- `k`가 10^9이므로 "뒤집기를 k번 반복하며 매번 최솟값을 찾는" 시뮬레이션은 시간 초과입니다. 횟수의 홀짝만 중요하다는 관찰로 한 번에 처리하세요.

## 복잡도
- 시간 O(n log n), 공간 O(1) 추가
