# [lv1] 포크댄스 짝 정하기

체육 시간에 포크댄스를 추려고 두 명씩 짝을 정합니다. 학생들의 키가 배열 `heights`로 주어집니다. 동작이 어긋나지 않도록 **키 차이가 `d` 이하**인 두 학생만 짝이 될 수 있고, 한 학생은 많아야 한 짝에만 속합니다. 짝이 없는 학생은 구경을 합니다.

만들 수 있는 **짝의 최대 개수**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `heights`의 길이 ≤ 200,000
- 1 ≤ `heights`의 원소 ≤ 1,000,000,000
- 0 ≤ `d` ≤ 1,000,000,000

## 입출력 예

| heights | d | result |
|---|---|---|
| [150, 160, 151, 170, 161] | 2 | 2 |
| [1, 2, 2, 3] | 1 | 2 |
| [10, 20, 30] | 5 | 0 |

## 입출력 예 설명
- 예 #1: (150, 151), (160, 161) 두 짝을 만들 수 있고 170은 구경합니다.
- 예 #2: 키 차이가 0인 (2, 2)를 먼저 짝지으면 1과 3은 차이가 2라 짝이 못 되어 1쌍뿐이지만, (1, 2), (2, 3)으로 하면 2쌍입니다.
- 예 #3: 어떤 두 학생도 차이가 5를 넘습니다.
