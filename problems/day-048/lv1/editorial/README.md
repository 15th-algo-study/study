# 해설 — 포크댄스 짝 정하기

## 접근
키를 오름차순으로 정렬한 뒤 앞에서부터 봅니다. 가장 작은 학생 `a`와 그 다음 학생 `b`의 차이가 `d` 이하이면 둘을 짝짓고 두 칸 넘어가고, 아니면 `a`는 누구와도 짝이 될 수 없으므로(그 다음 학생들은 더 크니까) 한 칸만 넘어갑니다.

왜 맞는지(교환 논법): 가장 작은 학생 `a`가 짝이 될 수 있다면(`b − a ≤ d`), `a`와 `b`를 짝짓는 최적해가 있습니다. 어떤 최적해에서 `a`의 짝이 `x`, `b`의 짝이 `y`라면(`a`나 `b`가 짝이 없는 경우도 포함) `(a, b), (x, y)`로 바꿔도 `x`와 `y`는 둘 다 `[a, a + d]` 안에 있으므로 차이가 `d` 이하이고 짝 수는 줄지 않습니다. `a`와 `b`를 빼고 같은 논리를 반복합니다.

## 주의할 점
- "차이가 가장 작은 쌍부터 묶는다"는 그럴듯하지만 예 #2에서 틀립니다. 정렬 뒤 **가장 작은 학생부터** 처리해야 합니다.
- `d = 0`이면 키가 같은 학생끼리만 짝입니다. 비교를 `<=`로 하세요.
- 짝을 지은 뒤에는 인덱스를 **두 칸** 넘기고, 못 지으면 한 칸만 넘깁니다. 마지막 학생이 혼자 남는 경우(`i + 1 == n`)에 배열 범위를 넘지 않도록 반복 조건을 `i + 1 < n`으로 둡니다.

## 복잡도
- 시간 O(n log n), 공간 O(1) 추가
