# [lv0] 주행거리계 회문

택시 기사가 운행을 마칠 때마다 주행거리계의 숫자를 기록해 두었습니다. 기록 가운데 **거꾸로 읽어도 같은 수**(회문 수)가 몇 번인지 세어 보려 합니다. 예를 들어 12321과 1001은 회문 수이고, 120은 거꾸로 읽으면 021 = 21이라 회문 수가 아닙니다. 한 자리 수는 모두 회문 수입니다.

기록 배열 `readings`가 주어질 때, 회문 수인 기록의 개수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `readings`의 길이 ≤ 100,000
- 0 ≤ `readings`의 원소 ≤ 1,000,000,000,000,000,000 (10^18, `long`)
- 0은 한 자리 수이므로 회문 수입니다.

## 입출력 예

| readings | result |
|---|---|
| [12321, 1001, 120, 7] | 3 |
| [0, 10, 1000000000000000000] | 1 |

## 입출력 예 설명
- 예 #1: 12321, 1001, 7이 회문 수입니다.
- 예 #2: 0만 회문 수입니다. 10과 10^18은 거꾸로 읽으면 1이 됩니다.
