# 해설 — 주행거리계 회문

## 접근
수를 뒤집은 값을 정수 연산으로 만들어 원래 수와 비교합니다. `reversed = reversed * 10 + n % 10`, `n /= 10`을 `n`이 0이 될 때까지 반복하면 자릿수가 거꾸로 쌓입니다. 끝에 0이 있는 수(120)는 뒤집으면 21이 되어 자연스럽게 회문이 아니라고 판정됩니다.

## 주의할 점
- 10^18 이하의 수를 뒤집은 값은 10^19 미만으로 보이지만, 실제로 가능한 19자리 수는 10^18 하나뿐이고 그 뒤집은 값은 1입니다. 18자리 이하의 수를 뒤집은 값은 10^18 미만이므로 `long`에 안전하게 들어갑니다.
- 뒤집는 변수도 `long`이어야 합니다. `int`로 두면 10자리부터 넘칩니다.
- `String.valueOf(n)`과 `StringBuilder.reverse()`로 비교해도 되지만, 정수 연산으로 자릿수를 다루는 연습이 목적입니다.

## 복잡도
- 시간 O(n × 19), 공간 O(1)
