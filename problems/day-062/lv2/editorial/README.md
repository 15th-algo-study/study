# 해설 — 박물관 경비 로봇의 회전

## 접근
같은 칸에 있어도 바라보는 방향이 다르면 다음에 할 수 있는 일(어느 칸으로 전진하는지)이 달라집니다. 그래서 BFS의 정점을 칸이 아니라 **`(칸, 방향)` 상태**로 잡습니다. 상태 수는 칸 수 × 4입니다.

각 상태에서 1초 걸리는 명령은 세 가지이므로 간선도 세 개입니다.
- 좌회전: `(칸, (방향 + 3) % 4)`
- 우회전: `(칸, (방향 + 1) % 4)`
- 전진: 바라보는 방향의 이웃 칸이 전시실 안의 `.`이면 `(이웃 칸, 방향)`

모든 간선의 길이가 1이므로 `start` 상태에서 BFS를 돌려 `goal` 상태에 처음 도착한 시간이 답입니다. 상태를 `(r * cols + c) * 4 + d` 정수 하나로 묶으면 `int[]` 배열 하나로 거리와 방문 여부를 관리할 수 있습니다.

## 주의할 점
- 방문 표시를 칸 단위로만 하면 틀립니다. 어떤 칸에 "나쁜 방향"으로 먼저 도착해 칸을 막아 버리면, 조금 늦더라도 "좋은 방향"으로 도착하는 경로를 놓칩니다.
- 회전도 1초가 걸리는 명령입니다. "이동 칸 수"만 세는 일반 격자 BFS로는 회전 비용이 빠집니다. 예 #1에서 위로 가는 길과 아래로 가는 길은 이동 칸 수가 같지만 회전 횟수가 달라 걸리는 시간이 다릅니다.
- 도착 칸에서 방향까지 맞아야 합니다. 예 #2처럼 같은 칸에서 방향만 바꾸는 데도 시간이 듭니다.
- 상태가 최대 400만 개이므로 객체 큐 대신 `int[]` 배열 큐를 쓰면 빠르고 메모리도 적게 듭니다.

## 복잡도
- 시간 O(rows × cols × 4), 공간 O(rows × cols × 4)
