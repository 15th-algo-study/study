# [lv2] 박물관 경비 로봇의 회전

박물관 전시실을 격자 모양의 지도 `museum`으로 나타냈습니다. `museum[r]`의 `c`번째 문자가 (r, c) 칸이며, `.`은 빈 바닥, `#`은 전시대라서 들어갈 수 없는 칸입니다.

경비 로봇은 한 칸을 차지하며 항상 북·동·남·서 중 한 방향을 바라봅니다. 방향은 정수로 나타냅니다.

| 방향 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 뜻 | 북 (위, 행 번호 감소) | 동 (오른쪽, 열 번호 증가) | 남 (아래, 행 번호 증가) | 서 (왼쪽, 열 번호 감소) |

로봇은 1초에 다음 명령 중 하나를 수행합니다.

- **전진**: 바라보는 방향으로 한 칸 움직입니다. 그 칸이 전시실 밖이거나 전시대면 전진할 수 없습니다.
- **좌회전**: 제자리에서 왼쪽으로 90° 돕니다. (예: 북 → 서)
- **우회전**: 제자리에서 오른쪽으로 90° 돕니다. (예: 북 → 동)

로봇의 처음 상태 `start = [r, c, d]`와 순찰을 마칠 상태 `goal = [r, c, d]`가 주어집니다. 로봇이 (r, c) 칸에서 방향 d를 바라보는 상태입니다. `start` 상태에서 `goal` 상태가 되는 데 걸리는 **최소 시간(초)**을 return 하도록 `solution` 함수를 완성해 주세요. 불가능하면 -1을 return 합니다.

## 제한사항
- 1 ≤ `museum`의 길이 ≤ 1,000
- 1 ≤ 각 `museum[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같고, `museum`은 `.`과 `#`로만 이루어집니다.
- `start`와 `goal`은 길이 3인 배열이며, 두 상태의 칸은 모두 `.` 칸입니다. 방향은 0 이상 3 이하입니다.

## 입출력 예

| museum | start | goal | result |
|---|---|---|---|
| ["...", ".#.", "..."] | [0, 0, 1] | [2, 2, 2] | 5 |
| ["..."] | [0, 1, 0] | [0, 1, 2] | 2 |
| [".#."] | [0, 0, 1] | [0, 2, 3] | -1 |

## 입출력 예 설명
- 예 #1: 동쪽을 보며 두 번 전진해 (0,2), 우회전해 남쪽, 두 번 전진해 (2,2)에 남쪽을 보며 도착합니다. 5초입니다. 아래로 돌아가면 마지막에 방향을 한 번 더 바꿔야 해서 7초가 걸립니다.
- 예 #2: 같은 칸에서 북쪽을 보다가 남쪽을 보려면 같은 방향으로 두 번 돌아야 합니다.
- 예 #3: 가운데 전시대 때문에 오른쪽 칸으로 갈 수 없습니다.
