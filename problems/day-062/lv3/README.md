# [lv3] 같은 무늬 마법진

마법사의 탑 한 층을 격자 모양의 지도 `tower`로 나타냈습니다. `tower[r]`의 `c`번째 문자가 (r, c) 칸이며, 각 문자의 뜻은 다음과 같습니다.

- `S`: 견습 마법사가 서 있는 출발 칸 (정확히 하나)
- `T`: 스승이 기다리는 목표 칸 (정확히 하나)
- `.`: 빈 바닥
- `#`: 벽
- 영문 소문자 `a`~`z`: 바닥에 그려진 마법진. 같은 글자의 마법진은 같은 무늬입니다.

견습 마법사는 1초에 다음 중 한 가지를 할 수 있습니다.

- 상하좌우로 붙어 있는 벽이 아닌 칸으로 한 칸 걷기 (마법진 칸도 바닥처럼 밟고 지나갈 수 있습니다)
- 마법진 위에 서 있다면, 그 마법진과 **같은 무늬인 다른 마법진 칸 아무 곳으로나** 순간이동하기

출발 칸에서 목표 칸까지 가는 데 걸리는 **최소 시간(초)**을 return 하도록 `solution` 함수를 완성해 주세요. 갈 수 없으면 -1을 return 합니다.

## 제한사항
- 1 ≤ `tower`의 길이 ≤ 1,000
- 1 ≤ 각 `tower[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같습니다.
- `tower`는 `S`, `T`, `.`, `#`, 영문 소문자로만 이루어지며 `S`와 `T`는 각각 정확히 한 번 나옵니다.
- 같은 무늬의 마법진이 아주 많을 수도 있습니다.

## 입출력 예

| tower | result |
|---|---|
| ["Sa#", "##a", "..T"] | 3 |
| ["S.a", "###", "a.T"] | 5 |
| ["S#T"] | -1 |

## 입출력 예 설명
- 예 #1: (0,1)의 마법진으로 걸어가고(1초), (1,2)의 같은 무늬 마법진으로 순간이동한 뒤(2초), 아래로 걸어 목표에 도착합니다(3초).
- 예 #2: (0,2)까지 2초, (2,0)으로 순간이동해 3초, 오른쪽으로 두 칸 걸어 5초에 도착합니다.
- 예 #3: 벽에 막혀 갈 수 없습니다.
