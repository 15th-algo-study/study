# [lv1] 점수판 리모컨

체육관의 전자 점수판에는 0부터 999,999까지의 정수 하나를 표시할 수 있습니다. 점수판 리모컨에는 버튼이 세 개 있습니다.

- `+1`: 표시된 수에 1을 더합니다.
- `×2`: 표시된 수를 2배로 만듭니다.
- `뒤집기`: 표시된 수의 숫자 순서를 거꾸로 뒤집습니다. 뒤집은 결과의 맨 앞에 오는 0은 사라집니다. 예를 들어 `1230`을 뒤집으면 `321`, `7`을 뒤집으면 `7`, `0`을 뒤집으면 `0`입니다.

버튼을 눌렀을 때 999,999보다 큰 수가 되면 점수판이 고장 나므로 그런 버튼은 누를 수 없습니다.

지금 점수판에는 `start`가 표시되어 있습니다. 정수 배열 `targets`의 각 수에 대해, 점수판에 그 수를 표시하려면 버튼을 **최소 몇 번** 눌러야 하는지 구해 같은 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 각 수는 모두 `start`에서 따로 시작해 계산하며, 표시할 수 없는 수는 -1입니다.

## 제한사항
- 0 ≤ `start` ≤ 999,999
- 1 ≤ `targets`의 길이 ≤ 200,000
- 0 ≤ `targets`의 원소 ≤ 999,999

## 입출력 예

| start | targets | result |
|---|---|---|
| 12 | [12, 21, 24, 42, 25] | [0, 1, 1, 2, 2] |
| 999999 | [999999, 0] | [0, -1] |
| 10 | [1, 2, 100] | [1, 2, 6] |

## 입출력 예 설명
- 예 #1: 12는 그대로 0번, 21은 뒤집기 1번, 24는 ×2 1번입니다. 42는 12 → 21 → 42 (뒤집기, ×2)로 2번, 25는 12 → 24 → 25 (×2, +1)로 2번입니다.
- 예 #2: 999,999에서 `+1`과 `×2`를 누르면 999,999를 넘고, 뒤집어도 999,999입니다. 다른 수는 표시할 수 없습니다.
- 예 #3: 10을 뒤집으면 1이고, 1 → 2는 `+1`이나 `×2` 한 번입니다. 100은 99에서 `+1` 하거나 50에서 `×2` 해야만 만들 수 있습니다(뒤집어서 100이 되는 수는 없습니다). 10 → 11 → 12 → 24 → 25 → 50 → 100으로 6번이 최소입니다.
