# [lv0] 받아올림을 잊은 덧셈

동생이 덧셈 숙제를 하는데 자꾸 받아올림을 잊어버립니다. 동생은 두 수를 오른쪽 끝(일의 자리)에 맞춰 세로로 쓰고, 같은 자리의 숫자끼리 더한 값의 **일의 자리 숫자만** 그 자리에 적습니다. 자릿수가 모자란 쪽은 그 자리를 0으로 봅니다. 예를 들어 `1234`와 `987`을 더하면 다음과 같습니다.

```
  1 2 3 4
+   9 8 7
---------
  1 1 1 1
```

0 이상의 정수 두 개가 문자열 `a`, `b`로 주어질 때, 동생이 적는 답을 문자열로 return 하도록 `solution` 함수를 완성해 주세요. 답의 맨 앞에 오는 0은 모두 지우고, 모두 지워져 아무것도 남지 않으면 `"0"`을 return 합니다.

## 제한사항
- 1 ≤ `a`의 길이, `b`의 길이 ≤ 1,000,000
- `a`와 `b`는 숫자(`0`~`9`)로만 이루어져 있습니다.
- `a`와 `b`는 `"0"`이 아니라면 0으로 시작하지 않습니다.

## 입출력 예

| a | b | result |
|---|---|---|
| "1234" | "987" | "1111" |
| "905" | "5" | "900" |
| "96" | "15" | "1" |

## 입출력 예 설명
- 예 #1: 위 그림과 같습니다. 일의 자리부터 4+7=11 → 1, 3+8=11 → 1, 2+9=11 → 1, 1+0=1입니다.
- 예 #2: 일의 자리 5+5=10 → 0, 십의 자리 0+0=0, 백의 자리 9+0=9라서 `"900"`입니다.
- 예 #3: 일의 자리 6+5=11 → 1, 십의 자리 9+1=10 → 0이라 `"01"`이 되고, 맨 앞의 0을 지우면 `"1"`입니다.
