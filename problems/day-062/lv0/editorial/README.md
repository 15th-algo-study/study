# 해설 — 받아올림을 잊은 덧셈

## 접근
수가 최대 100만 자리라 `int`나 `long`으로 바꿀 수 없습니다. 문자열 그대로 한 자리씩 다룹니다.

1. 결과의 길이는 두 수 중 긴 쪽의 길이입니다.
2. 오른쪽 끝에서 `k`번째 자리끼리 더합니다. 숫자 글자를 수로 바꿀 때는 `ch - '0'`, 수를 다시 글자로 바꿀 때는 `(char) ('0' + d)`를 씁니다. 짧은 쪽에 그 자리가 없으면 0으로 봅니다.
3. 합의 일의 자리 `(x + y) % 10`만 적습니다.
4. 맨 앞의 0을 건너뛰되, 모두 0이면 마지막 한 글자 `"0"`은 남깁니다.

## 주의할 점
- `a.charAt(i)`는 `'7'` 같은 **글자**이고 그 코드값은 55입니다. 숫자 7을 얻으려면 `'7' - '0'`처럼 빼야 합니다.
- `Integer.parseInt`, `Long.parseLong`은 100만 자리 수를 다룰 수 없습니다(넘치거나 예외).
- 결과를 `answer = digit + answer`처럼 문자열 `+`로 앞에 붙이면 붙일 때마다 전체를 복사해 O(n²)이고, 100만 자리에서는 시간 초과입니다. `char[]` 배열에 채우거나 `StringBuilder`에 모은 뒤 뒤집으세요.
- `"55"`와 `"55"`처럼 모든 자리가 0이 되면 `"0"`을 돌려줘야 합니다. 빈 문자열이 되지 않게 주의합니다.

## 복잡도
- 시간 O(n), 공간 O(n) (n = 긴 쪽의 길이)
