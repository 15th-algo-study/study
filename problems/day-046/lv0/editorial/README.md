# 해설 — 유물 번호의 숫자 폭

## 접근
번호를 10으로 나눈 나머지(`% 10`)가 마지막 자릿수이고, 10으로 나누면(`/ 10`) 그 자리가 떨어져 나갑니다. 번호가 0이 될 때까지 반복하면서 가장 큰 숫자와 가장 작은 숫자를 갱신하고, 끝나면 둘의 차를 적습니다.

번호가 0이면 반복문이 한 번도 돌지 않으므로 따로 처리하거나, `do-while`로 적어도 한 번은 자릿수를 꺼내게 합니다.

## 주의할 점
- 번호가 10^18까지이므로 `long`으로 받아야 합니다. `int`로 바꾸면 넘칩니다.
- 최댓값의 초깃값은 0(가장 작은 숫자보다 작게), 최솟값의 초깃값은 9(가장 큰 숫자보다 크게)로 두면 첫 자릿수에서 자연스럽게 갱신됩니다.
- 문자열로 바꿔 `charAt`으로 읽어도 되지만, 정수 연산만으로 풀어 보는 것이 이번 트랙의 목표입니다.

## 복잡도
- 시간 O(n × 19) (자릿수는 최대 19개), 공간 O(n)
