# [lv0] 유물 번호의 숫자 폭

박물관 수장고의 유물에는 0 이상의 정수로 된 번호가 붙어 있습니다. 학예사는 번호를 빨리 구분하려고 번호의 **숫자 폭**을 적어 두기로 했습니다. 숫자 폭은 번호에 쓰인 자릿수 가운데 **가장 큰 숫자에서 가장 작은 숫자를 뺀 값**입니다.

예를 들어 번호 2026의 자릿수는 2, 0, 2, 6이므로 숫자 폭은 6 − 0 = 6입니다. 한 자리 번호는 가장 큰 숫자와 가장 작은 숫자가 같아 폭이 0입니다.

유물 번호 배열 `codes`가 주어질 때, 각 번호의 숫자 폭을 같은 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `codes`의 길이 ≤ 100,000
- 0 ≤ `codes`의 원소 ≤ 1,000,000,000,000,000,000 (10^18, `long`)
- 번호가 0이면 자릿수는 0 하나이므로 숫자 폭은 0입니다.

## 입출력 예

| codes | result |
|---|---|
| [2026, 7, 905, 0] | [6, 0, 9, 0] |
| [1000000000000000000, 918273645] | [1, 8] |

## 입출력 예 설명
- 예 #1: 2026 → 6 − 0 = 6, 7 → 7 − 7 = 0, 905 → 9 − 0 = 9, 0 → 0 − 0 = 0.
- 예 #2: 10^18의 자릿수는 1 하나와 0 열여덟 개이므로 1 − 0 = 1. 918273645는 9 − 1 = 8.
