# [lv3] 서커스 인간 탑

서커스 단원 `n`명이 한 줄로 어깨 위에 올라서는 **인간 탑**을 만듭니다. 단원 `i`의 몸무게는 `weight[i]`, 버티는 힘은 `strength[i]`입니다. 탑에서 어떤 단원의 **위험도**는 다음과 같이 정합니다.

> 위험도 = (그 단원 **위에** 올라선 모든 단원의 몸무게 합) − (그 단원의 버티는 힘)

맨 위 단원은 위에 아무도 없으므로 위험도가 `−strength`입니다. 공연의 위험도는 단원들의 위험도 가운데 **최댓값**입니다.

단원들이 서는 순서를 자유롭게 정할 수 있을 때, 공연 위험도의 **최솟값**을 return 하도록 `solution` 함수를 완성해 주세요. 결과는 음수일 수 있습니다.

## 제한사항
- 1 ≤ `n` ≤ 200,000 (`weight`와 `strength`의 길이는 같습니다)
- 1 ≤ `weight[i]` ≤ 1,000,000,000
- 0 ≤ `strength[i]` ≤ 1,000,000,000
- 몸무게 합이 `int` 범위를 넘을 수 있으므로 `long`을 return 합니다.

## 입출력 예

| weight | strength | result |
|---|---|---|
| [2, 8, 6] | [6, 1, 5] | 5 |
| [10, 1] | [1, 5] | 0 |
| [7] | [3] | -3 |

## 입출력 예 설명
- 예 #1: 위에서부터 단원 0(2, 6), 단원 1(8, 1), 단원 2(6, 5) 순서로 서면 위험도는 각각 0 − 6 = −6, 2 − 1 = 1, 10 − 5 = 5이므로 공연 위험도는 5입니다. 다른 어떤 순서도 5보다 작게 만들 수 없습니다. 예를 들어 가벼운 순서(2, 6, 8)로 서면 위험도는 −6, 2 − 5 = −3, 8 − 1 = 7이라 7입니다.
- 예 #2: 단원 1(1, 5)을 위에, 단원 0(10, 1)을 아래에 세우면 위험도는 −5, 1 − 1 = 0이므로 0입니다. 반대로 세우면 −1, 10 − 5 = 5라 5입니다.
- 예 #3: 혼자 서면 위에 아무도 없어 0 − 3 = −3입니다.
