# [lv2] 온천 가족탕 예약

온천의 가족탕은 하나뿐이라 한 번에 한 팀만 쓸 수 있습니다. 예약 신청이 `bookings`로 주어지는데, `bookings[i] = [start, duration]`은 시각 `start`부터 `duration`분 동안, 즉 `start` 이상 `start + duration` **미만**의 시간 동안 탕을 쓰고 싶다는 뜻입니다. 앞 팀이 나가는 시각에 다음 팀이 바로 들어오는 것은 괜찮습니다.

신청 가운데 서로 시간이 겹치지 않도록 골라 **받아 줄 수 있는 예약 수의 최댓값**을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `bookings`의 길이 ≤ 200,000
- 0 ≤ `start` ≤ 1,000,000,000
- 1 ≤ `duration` ≤ 1,000,000,000
- 같은 예약이 여러 번 신청될 수 있습니다.

## 입출력 예

| bookings | result |
|---|---|
| [[1, 3], [2, 2], [4, 2], [6, 1], [5, 3]] | 3 |
| [[0, 10], [9, 2], [10, 10]] | 2 |
| [[0, 100], [1, 1], [2, 1], [3, 1]] | 3 |

## 입출력 예 설명
- 예 #1: 사용 시간은 [1, 4), [2, 4), [4, 6), [6, 7), [5, 8)입니다. [1, 4), [4, 6), [6, 7)을 받으면 3팀이고, 4팀은 불가능합니다.
- 예 #2: 가장 짧은 [9, 11)을 먼저 받으면 나머지 둘과 모두 겹쳐 1팀뿐이지만, [0, 10)과 [10, 20)을 받으면 2팀입니다.
- 예 #3: 가장 먼저 시작하는 [0, 100)을 받으면 1팀뿐입니다. 뒤의 세 팀을 받으면 3팀입니다.
