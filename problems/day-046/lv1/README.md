# [lv1] 장작 묶기

겨울을 앞두고 장작 `n`개를 묶음으로 나눠 보관하려 합니다. 장작의 길이는 배열 `logs`로 주어집니다. 묶음이 가지런하도록, **한 묶음 안에서는 가장 긴 장작과 가장 짧은 장작의 길이 차가 `d` 이하**여야 합니다. 한 묶음에 들어가는 장작 수에는 제한이 없고, 장작 하나만으로도 묶음을 만들 수 있습니다.

모든 장작을 빠짐없이 묶을 때 필요한 **묶음 수의 최솟값**을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `logs`의 길이 `n` ≤ 200,000
- 1 ≤ `logs`의 원소 ≤ 1,000,000,000
- 0 ≤ `d` ≤ 1,000,000,000

## 입출력 예

| logs | d | result |
|---|---|---|
| [12, 3, 7, 20, 15, 8] | 5 | 3 |
| [5, 5, 5] | 0 | 1 |
| [1, 10, 100] | 1 | 3 |

## 입출력 예 설명
- 예 #1: {3, 7, 8}, {12, 15}, {20}으로 나누면 각 묶음의 길이 차가 5, 3, 0이라 조건을 만족하고, 묶음 2개로는 불가능합니다.
- 예 #2: 길이가 모두 같으면 `d = 0`이어도 한 묶음입니다.
- 예 #3: 어떤 두 장작도 길이 차가 1을 넘으므로 하나씩 묶습니다.
