# 해설 — 장작 묶기

## 접근
길이를 오름차순으로 정렬하면 한 묶음은 정렬된 배열에서 **연속한 구간**으로 잡아도 손해가 없습니다(묶음의 범위 `[최소, 최소 + d]` 안에 있는 장작은 전부 그 묶음에 넣어도 조건이 깨지지 않기 때문입니다).

그리고 **가장 짧은 장작**은 반드시 어떤 묶음에 들어가야 하는데, 그 묶음의 범위를 `[가장 짧은 길이, 가장 짧은 길이 + d]`로 잡고 그 안의 장작을 전부 넣는 것이 가장 유리합니다. 최적해가 그 묶음에 어떤 장작을 빼놓았다면, 그 장작을 이 묶음으로 옮겨도 묶음 수는 늘지 않습니다(교환 논법). 남은 장작에 같은 일을 반복합니다.

구현: 정렬 후 현재 묶음의 시작 길이 `start`를 기억하며 훑다가, `logs[i] > start + d`가 되는 순간 새 묶음을 열고 `start = logs[i]`로 바꿉니다.

## 주의할 점
- `start + d`는 최대 2×10^9라 `int`를 넘습니다. `long`으로 비교하거나 `logs[i] - start > d`로 바꿔 씁니다.
- `d = 0`이면 같은 길이끼리만 묶입니다. 정렬 뒤 비교가 `>`(초과)인지 `>=`인지 확인하세요.
- 정렬하지 않고 입력 순서대로 묶으면 예 #1에서 틀립니다.

## 복잡도
- 시간 O(n log n) (정렬), 공간 O(1) 추가
