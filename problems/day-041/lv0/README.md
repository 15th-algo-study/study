# [lv0] 다음 버스 출발 시각

버스 정류장의 시간표에는 오늘 출발하는 버스의 출발 시각이 **이른 순서대로** 적혀 있습니다. 출발 시각은 자정부터 흐른 분 수로 나타내며, 배열 `times`로 주어집니다. 같은 시각에 여러 대가 출발할 수도 있습니다.

손님이 정류장에 도착한 시각 `t`가 주어질 때, 손님이 탈 수 있는 **가장 이른 버스의 출발 시각**을 return 하도록 `solution` 함수를 완성해 주세요. 출발 시각이 `t`와 같은 버스도 탈 수 있습니다. 탈 수 있는 버스가 없으면 -1을 return 합니다.

## 제한사항
- 1 ≤ `times`의 길이 ≤ 1,000,000
- 0 ≤ `times`의 원소 ≤ 1,000,000,000, 오름차순으로 정렬되어 있습니다 (같은 값 가능)
- 0 ≤ `t` ≤ 1,000,000,000

## 입출력 예

| times | t | result |
|---|---|---|
| [300, 420, 540, 900] | 430 | 540 |
| [60, 120] | 121 | -1 |
| [10, 10, 20] | 10 | 10 |

## 입출력 예 설명
- 예 #1: 430분에 도착했으므로 300분·420분 버스는 이미 떠났고, 540분 버스가 가장 이릅니다.
- 예 #2: 마지막 버스(120분)보다 늦게 도착해 탈 버스가 없습니다.
- 예 #3: 도착 시각과 같은 10분 버스를 탈 수 있습니다.
