# 해설 — 다음 버스 출발 시각

## 접근
배열이 오름차순이므로 **앞에서부터 보다가 처음으로 `t` 이상인 값**이 답입니다. 그 값을 만나는 순간 `return` 하면 되고, 끝까지 못 만나면 -1입니다.

정렬된 배열이라 이분 탐색(`Arrays.binarySearch`나 직접 구현)으로도 풀 수 있지만, 질의가 하나뿐이므로 한 번 훑는 O(n)으로 충분합니다.

## 주의할 점
- "`t` 이상"입니다. `>`로 쓰면 예 #3처럼 도착 시각과 같은 버스를 놓칩니다.
- 처음 만난 값을 바로 return 해야 합니다. 조건을 만족하는 값을 계속 덮어쓰면 마지막 버스가 답이 됩니다.

## 복잡도
- 시간 O(n), 공간 O(1)
