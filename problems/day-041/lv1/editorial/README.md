# 해설 — 버섯 채집 일지

## 접근
기간마다 `HashSet`을 새로 만들어 세면 기간 하나에 O(k), 전체 O(nk)라 `k`가 10만 정도일 때 시간 초과입니다.

기간이 하루씩 오른쪽으로 **미끄러질 때 바뀌는 것은 두 원소뿐**입니다. 왼쪽 끝 하루가 빠지고 오른쪽 끝 하루가 들어옵니다.

1. 종 번호별 개수 배열 `cnt[200001]`과 "현재 기간의 종류 수" `distinct`를 둡니다.
2. 원소를 넣을 때 `cnt[v]`가 0 → 1이 되면 `distinct++`, 뺄 때 1 → 0이 되면 `distinct--`.
3. 처음 `k`개를 넣어 첫 기간을 만들고, 이후 한 칸씩 밀며 (넣기, 빼기, 기록)을 반복합니다.

## 주의할 점
- 넣는 것과 빼는 것의 순서는 상관없지만, `distinct`를 갱신하는 조건(0↔1 경계)을 정확히 지켜야 합니다. `cnt[v] > 0`일 때 또 들어오면 종류 수는 그대로입니다.
- 결과 배열의 길이는 `n - k + 1`입니다. `k = n`이면 1개입니다.
- 종 번호 범위가 작으므로 `HashMap` 대신 배열 카운팅이 빠릅니다.

## 복잡도
- 시간 O(n), 공간 O(n + 200000)
