# [lv1] 버섯 채집 일지

버섯 채집가가 `n`일 동안 매일 버섯을 하나씩 채집해 종 번호를 일지에 적었습니다. `i`번째 날(0번부터 셈)에 채집한 버섯의 종 번호는 `kinds[i]`입니다.

연속한 `k`일을 하나의 기간으로 봅니다. 즉 `[0, k-1]`, `[1, k]`, …, `[n-k, n-1]`일의 기간이 차례로 `n - k + 1`개 있습니다. 각 기간에 채집한 버섯이 **서로 다른 종 몇 가지**인지 세어, 기간 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `kinds`의 길이 `n` ≤ 200,000
- 1 ≤ `kinds`의 원소 ≤ 200,000
- 1 ≤ `k` ≤ `n`

## 입출력 예

| kinds | k | result |
|---|---|---|
| [1, 2, 1, 3, 2] | 3 | [2, 3, 3] |
| [4, 4, 4] | 1 | [1, 1, 1] |
| [1, 2, 3] | 3 | [3] |

## 입출력 예 설명
- 예 #1: 기간은 [1, 2, 1] → 2가지, [2, 1, 3] → 3가지, [1, 3, 2] → 3가지입니다.
- 예 #2: 하루짜리 기간은 항상 1가지입니다.
- 예 #3: 기간이 하나뿐이고 세 종이 모두 다릅니다.
