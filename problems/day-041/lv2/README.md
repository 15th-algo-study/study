# [lv2] 현미경 렌즈 조합

실험실 현미경에는 렌즈 `n`개가 한 줄로 꽂혀 있고, `i`번 렌즈의 배율은 `mags[i]`입니다. **연속한** 렌즈 몇 개를 골라 겹치면 배율은 고른 렌즈 배율의 **곱**이 됩니다. 렌즈 하나만 골라도 됩니다.

현미경이 견딜 수 있는 최대 배율이 `limit`일 때, 겹친 배율이 `limit` **이하**가 되는 연속 렌즈 구간 `[l, r]`의 개수를 return 하도록 `solution` 함수를 완성해 주세요. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `mags`의 길이 `n` ≤ 1,000,000
- 1 ≤ `mags`의 원소 ≤ 1,000,000,000
- 1 ≤ `limit` ≤ 10^18

## 입출력 예

| mags | limit | result |
|---|---|---|
| [2, 3, 1, 4] | 6 | 8 |
| [10, 1, 1] | 5 | 3 |
| [1000000000, 1000000000] | 1000000000000000000 | 3 |

## 입출력 예 설명
- 예 #1: 조건을 만족하는 구간은 [2], [3], [1], [4], [2, 3]=6, [3, 1]=3, [1, 4]=4, [2, 3, 1]=6으로 8개입니다. [3, 1, 4]=12와 [2, 3, 1, 4]=24는 넘습니다.
- 예 #2: 10은 혼자서도 넘으므로 10을 포함한 구간은 모두 안 됩니다. [1], [1], [1, 1]로 3개입니다.
- 예 #3: 두 렌즈를 모두 겹치면 정확히 10^18로 `limit`과 같아 허용됩니다.
