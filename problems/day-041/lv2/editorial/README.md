# 해설 — 현미경 렌즈 조합

## 접근
모든 배율이 1 이상이므로 구간을 **늘리면 곱은 절대 줄지 않습니다**. 그래서 오른쪽 끝 `r`을 고정했을 때 조건을 만족하는 왼쪽 끝 `l`은 어떤 값 이상의 연속한 범위이고, `r`이 커질수록 그 경계도 오른쪽으로만 움직입니다. 전형적인 **가변 창(슬라이딩 윈도우)** 입니다.

1. 창 `[l, r]`의 곱 `prod`를 유지하며 `r`을 하나씩 늘립니다.
2. `mags[r]`을 곱했을 때 `limit`을 넘으면 넘지 않을 때까지 `l`을 올리며 `prod /= mags[l]`.
3. 끝이 `r`인 유효 구간은 `l..r`에서 시작하는 `r - l + 1`개이므로 답에 더합니다.

## 주의할 점
- **곱셈 오버플로**: `prod`가 `limit`(최대 10^18) 이하라도 여기에 10^9를 곱하면 `long`을 넘습니다. 곱하기 전에 나눗셈으로 비교하세요: `prod > limit / mags[r]`이면 곱이 `limit`을 넘는 것입니다 (`prod * x ≤ limit ⇔ prod ≤ ⌊limit / x⌋`).
- `mags[r]` 하나가 `limit`보다 크면 `r`을 포함하는 구간은 하나도 없습니다. 창을 비우고(`prod = 1`, `l = r + 1`) 다음으로 넘어갑니다.
- 답은 최대 n(n+1)/2 ≈ 5 × 10^11이라 `long`입니다.
- 왼쪽 끝마다 오른쪽으로 곱해 가며 세는 O(n²) 풀이는 배율이 거의 1인 large 케이스에서 창이 수십만 길이가 되어 시간 초과입니다.

## 복잡도
- 시간 O(n), 공간 O(1)
