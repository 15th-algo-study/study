# [lv3] 레고 블록 한 줄 바꾸기

레고 블록 `n`개가 한 줄로 끼워져 있고, `i`번 블록의 색은 `colors[i]`입니다. 블록을 **최대 `k`개**까지 빼서 원하는 색의 블록으로 갈아 끼울 수 있습니다. 어떤 색으로든 바꿀 수 있고, 꼭 `k`개를 다 바꿀 필요는 없습니다.

갈아 끼운 뒤 **같은 색 블록이 연속으로 이어지는 구간의 최대 길이**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `colors`의 길이 `n` ≤ 500,000
- 1 ≤ `colors`의 원소 ≤ 500,000
- 0 ≤ `k` ≤ `n`

## 입출력 예

| colors | k | result |
|---|---|---|
| [1, 1, 2, 1, 2, 2, 1] | 1 | 4 |
| [3, 3, 3] | 0 | 3 |
| [1, 2, 3, 4] | 2 | 3 |

## 입출력 예 설명
- 예 #1: 2번 블록을 1번 색으로 바꾸면 [1, 1, 1, 1, 2, 2, 1]이 되어 앞의 4개가 이어집니다. 3번 블록을 2번 색으로 바꿔 [2, 2, 2, 2]를 만들어도 4입니다. 하나만 바꿔서는 5개를 이을 수 없습니다.
- 예 #2: 바꾸지 않아도 3개가 이어져 있습니다.
- 예 #3: 두 개를 바꾸면 어떤 색이든 3개까지 이을 수 있습니다.
