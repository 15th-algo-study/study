# [lv1] 무전 숫자 암호 해석

무전병들은 단어장에 실린 단어를 번호로 주고받습니다. 단어장에 실린 번호의 목록은 `codes`입니다. 수신한 기록 `signal`은 보낸 번호들을 구분 기호 없이 그대로 이어 붙인 숫자 문자열입니다. 번호를 쓸 때 앞에 0을 붙이지 않습니다.

`signal`을 단어장에 있는 번호들로 빠짐없이 나누는 방법의 수를 1,000,000,007로 나눈 나머지를 return 하도록 `solution` 함수를 완성해 주세요. 나누는 위치가 하나라도 다르면 다른 방법입니다.

## 제한사항
- 1 ≤ `signal`의 길이 ≤ 200,000
- `signal`은 숫자 `0`~`9`로만 이루어져 있습니다.
- 1 ≤ `codes`의 길이 ≤ 300,000
- 1 ≤ `codes[i]` ≤ 1,000,000
- `codes`에 같은 번호가 여러 번 들어 있을 수 있습니다.

## 입출력 예

| signal | codes | result |
|---|---|---|
| "1225" | [1, 2, 5, 12, 22, 25] | 5 |
| "7007" | [7, 70, 700, 7007] | 2 |
| "123" | [4, 5] | 0 |

## 입출력 예 설명
- 예 #1: 1|2|2|5, 12|2|5, 1|22|5, 1|2|25, 12|25의 5가지입니다. 122는 단어장에 없습니다.
- 예 #2: 700|7과 7007의 2가지입니다. 7|007이나 70|07처럼 0으로 시작하는 조각은 번호가 될 수 없습니다.
- 예 #3: 어떤 조각도 단어장에 없습니다.
