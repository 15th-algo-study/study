# 해설 — 무전 숫자 암호 해석

## 접근
`ways[i]` = "`signal`의 앞 `i`글자를 번호들로 나누는 방법의 수"라고 합시다. 앞 `i`글자를 나눈 방법에서 **마지막 조각**을 `signal[j..i-1]`이라 하면, 그 앞부분 `j`글자를 나누는 방법은 `ways[j]`가지입니다. 그러므로

- `ways[0] = 1` (빈 문자열을 나누는 방법 하나)
- `ways[i] = Σ ways[j]` (조각 `signal[j..i-1]`이 단어장 번호인 모든 `j`)

답은 `ways[n]`입니다.

**관찰**: 번호는 1,000,000 이하이므로 조각은 길어야 7글자입니다. 그래서 `i`마다 마지막 조각의 길이 1~7만 보면 됩니다. 조각이 번호인지는 길이 1,000,001짜리 `boolean` 배열(또는 `HashSet`)로 O(1)에 확인합니다.

- 조각의 첫 글자가 `0`이면 번호가 될 수 없습니다.
- 조각을 뒤에서부터 한 글자씩 늘리며 값을 만들면(`value += 숫자 × 10^자리`) 부분 문자열을 매번 새로 만들지 않아도 됩니다.

## 주의할 점
- 마지막 조각의 길이를 제한하지 않고 모든 `j`를 보면 O(n²)이고, 긴 조각을 `int`/`long`으로 바꾸다 넘치기도 합니다. 길이 7까지만 보세요.
- 재귀로 "앞에서부터 조각을 하나씩 떼어 보는" 방법은 같은 위치를 몇 번이고 다시 계산해 경우의 수만큼 시간이 걸립니다.
- `ways[j]`를 최대 7개 더하면 `int`를 넘을 수 있으니 `long`으로 더하고 나머지를 구합니다.

## 복잡도
- 시간 O(7n + |codes|), 공간 O(n + 10^6)
