# [lv0] 세포 분열 실험

크기가 자연수인 세포는 다음 규칙에 따라 분열합니다.

- 크기가 2 이하인 세포는 더 이상 분열하지 않습니다.
- 크기 `x`가 3 이상이고 3의 배수이면, 크기가 `x / 3`인 세포 3개로 나뉩니다.
- 크기 `x`가 3 이상이고 3의 배수가 아니면, 크기가 `⌊x / 2⌋`인 세포와 `⌈x / 2⌉`인 세포 2개로 나뉩니다. (`⌊ ⌋`는 내림, `⌈ ⌉`는 올림)

새로 생긴 세포도 같은 규칙으로 계속 분열합니다. 크기 `x`인 세포 하나에서 시작해 더 이상 분열할 세포가 없을 때의 세포 수를 `x`의 '최종 세포 수'라고 하겠습니다.

배열 `queries`가 주어질 때, 각 원소의 최종 세포 수를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `queries`의 길이 ≤ 1,000
- 1 ≤ `queries[i]` ≤ 10^18

## 입출력 예

| queries | result |
|---|---|
| [7] | [5] |
| [1, 2, 3, 9] | [1, 1, 3, 9] |
| [10] | [8] |

## 입출력 예 설명
- 예 #1: 7 → 3, 4로 나뉩니다. 3 → 1, 1, 1이고 4 → 2, 2입니다. 최종 세포는 1, 1, 1, 2, 2의 5개입니다.
- 예 #2: 1과 2는 분열하지 않습니다. 3 → 1, 1, 1이고 9 → 3, 3, 3 → 각각 1, 1, 1이 되어 9개입니다.
- 예 #3: 10 → 5, 5이고 5 → 2, 3 → 2, 1, 1, 1로 4개가 됩니다. 5가 둘이므로 8개입니다.
