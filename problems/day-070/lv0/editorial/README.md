# 해설 — 세포 분열 실험

## 접근
세포를 하나씩 실제로 분열시키면 최종 세포 수만큼(최대 약 10^18개) 일해야 하므로 불가능합니다.

크기 `x` 세포의 최종 세포 수를 `cells(x)`라고 하면 규칙을 그대로 재귀식으로 옮길 수 있습니다.

- `x ≤ 2`이면 `cells(x) = 1`
- `x`가 3의 배수이면 `cells(x) = 3 × cells(x / 3)`
- 아니면 `cells(x) = cells(x / 2) + cells(x - x / 2)` (`x - x / 2`가 올림)

이 재귀를 그대로 돌리면 여전히 느립니다. 그런데 **같은 크기의 세포가 아주 많이 반복해서 나옵니다.** 10^18에서 시작해도 등장하는 서로 다른 크기는 수백 가지뿐입니다. 그래서 `HashMap<Long, Long>`에 `cells(x)`를 적어 두고, 다시 필요하면 꺼내 씁니다(메모이제이션). 크기가 10^18까지라 배열로는 적어 둘 수 없으므로 `HashMap`을 씁니다.

메모를 질의 사이에 공유하면 다른 질의에서 이미 구한 값도 재사용됩니다.

## 주의할 점
- 크기와 세포 수가 모두 `int` 범위를 넘으므로 `long`을 씁니다. 최종 세포 수는 최대 `x` 이하라 `long`에 들어갑니다.
- 올림은 `(x + 1) / 2`로 써도 되지만, `x - x / 2`로 쓰면 더하기 오버플로를 걱정하지 않아도 됩니다.
- `HashMap.get`은 값이 없으면 `null`을 돌려주므로 `Long`으로 받아 `null`인지 확인합니다.

## 복잡도
- 시간 O(Q × 서로 다른 크기 수) (서로 다른 크기는 질의당 수백 개 정도), 공간 O(서로 다른 크기 수)
