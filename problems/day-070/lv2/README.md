# [lv2] 스키 슬로프 깃발 모으기

스키 슬로프가 격자 모양 지도 `slope`로 주어집니다. `slope[r]`의 `c`번째 문자가 (r, c) 칸이며, 숫자 `'0'`~`'9'`는 그 칸에 꽂힌 깃발의 수, `'#'`은 나무가 있어 지날 수 없는 칸입니다.

스키어는 (0, 0) 칸에서 출발해 오른쪽 아래 끝 칸까지 내려가며, 한 번에 오른쪽 또는 아래쪽으로 붙어 있는 칸으로만 이동합니다. 지나는 모든 칸(출발 칸과 도착 칸 포함)의 깃발을 모읍니다.

모을 수 있는 깃발 수의 최댓값과, 그 최댓값만큼 모으는 서로 다른 경로의 수를 1,000,000,007로 나눈 나머지를 차례로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 도착 칸까지 갈 수 없으면 `[-1, 0]`을 return 합니다.

## 제한사항
- 1 ≤ `slope`의 길이 ≤ 1,000
- 1 ≤ `slope[r]`의 길이 ≤ 1,000이며, 모든 문자열의 길이는 같습니다.
- `slope`는 `'0'`~`'9'`와 `'#'`으로만 이루어져 있습니다.

## 입출력 예

| slope | result |
|---|---|
| ["123", "456", "789"] | [29, 1] |
| ["111", "111"] | [4, 3] |
| ["1#", "#1"] | [-1, 0] |

## 입출력 예 설명
- 예 #1: 1 → 4 → 7 → 8 → 9로 내려가면 29개를 모읍니다. 29개를 모으는 경로는 이것 하나뿐입니다.
- 예 #2: 어느 경로든 4칸을 지나 4개를 모으고, 경로는 3가지입니다.
- 예 #3: 출발 칸의 오른쪽과 아래쪽이 모두 나무라 도착할 수 없습니다.
