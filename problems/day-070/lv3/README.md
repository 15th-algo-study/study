# [lv3] 단열 패널 시공

높이 3칸, 너비 `n`칸인 벽에 단열 패널을 붙이려 합니다. 벽은 문자열 3개로 이루어진 배열 `wall`로 주어지며, `wall[r]`의 `c`번째 문자가 (r, c) 칸입니다. `.`은 패널을 붙여야 하는 칸이고, `#`은 창문이라 패널을 붙이면 안 되는 칸입니다.

패널은 1×2 크기이며 가로나 세로로 붙일 수 있습니다. 모든 `.` 칸을 패널로 빈틈없이, 겹치지 않게 덮어야 하며, 패널이 창문 칸이나 벽 밖에 걸치면 안 됩니다.

패널을 붙이는 방법의 수를 1,000,000,007로 나눈 나머지를 return 하도록 `solution` 함수를 완성해 주세요. 조건대로 덮을 수 없으면 0을 return 합니다. 패널끼리는 구별하지 않으며, 어떤 두 칸이 한 패널로 묶이는지가 다르면 다른 방법입니다.

## 제한사항
- `wall`의 길이는 3입니다.
- 1 ≤ `wall[r]`의 길이 `n` ≤ 1,000,000이며, 세 문자열의 길이는 같습니다.
- `wall`은 `.`과 `#`으로만 이루어져 있습니다.

## 입출력 예

| wall | result |
|---|---|
| ["..", "..", ".."] | 3 |
| ["...", ".#.", "..."] | 2 |
| ["....", "....", "...."] | 11 |

## 입출력 예 설명
- 예 #1: 가로 패널 3장, 위 두 줄에 세로 패널 2장 + 아래 줄에 가로 패널, 위 줄에 가로 패널 + 아래 두 줄에 세로 패널 2장의 3가지입니다.
- 예 #2: 가운데 창문을 둘러싼 8칸을 고리 모양으로 두 칸씩 묶는 방법은 묶음을 한 칸씩 어긋나게 잡는 2가지입니다.
- 예 #3: 3×4 벽을 덮는 방법은 11가지입니다.
