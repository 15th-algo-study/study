# [lv1] 골동품 양 끝 판매

골동품 가게의 긴 진열장에 물건 `n`점이 한 줄로 놓여 있습니다. 왼쪽에서 `i`번째 물건의 기본 가격은 `values[i]`입니다. 주인은 앞으로 `n`일 동안 하루에 한 점씩 모든 물건을 팔려고 합니다.

- 진열장이 좁아서 매일 **현재 남아 있는 물건 중 맨 왼쪽 또는 맨 오른쪽** 물건만 꺼내 팔 수 있습니다.
- 골동품 시세가 날마다 달라서, `d`번째 날(1일째부터) 판 물건은 `기본 가격 × rates[d - 1]`에 팔립니다.

`n`일 동안 모든 물건을 팔았을 때 얻을 수 있는 **판매 금액 합의 최댓값**을 return 하도록 `solution` 함수를 완성해 주세요. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `values`의 길이 = `rates`의 길이 = `n` ≤ 2,000
- 1 ≤ `values[i]` ≤ 1,000,000
- 1 ≤ `rates[d]` ≤ 1,000

## 입출력 예

| values | rates | result |
|---|---|---|
| [3, 5, 1, 4] | [1, 2, 3, 4] | 35 |
| [3, 9, 4] | [1, 1, 10] | 97 |
| [7] | [3] | 21 |

## 입출력 예 설명
- 예 #1: 오른쪽 4(1일째, 4), 오른쪽 1(2일째, 2), 왼쪽 3(3일째, 9), 마지막 5(4일째, 20) 순서로 팔면 35입니다. 매일 양 끝 중 싼 물건부터 팔면 3, 4, 1, 5 순서가 되어 3 + 8 + 3 + 20 = 34로 더 적습니다.
- 예 #2: 가운데 9는 양옆을 먼저 팔아야 꺼낼 수 있습니다. 3과 4를 먼저 팔고 시세가 10배인 3일째에 9를 팔면 3 + 4 + 90 = 97입니다.
- 예 #3: 물건 하나를 1일째에 팔아 7 × 3 = 21입니다.
