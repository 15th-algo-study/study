# 해설 — 외계 행성의 달력

## 접근
1. **행 수 구하기**: 앞의 빈칸 `start`개와 날짜 `days`개를 합친 `start + days`칸을 한 행에 `week`칸씩 채웁니다. 필요한 행 수는 올림 나눗셈 `(start + days + week - 1) / week`입니다.
2. `new int[rows][week]`로 0으로 채워진 달력을 만듭니다.
3. **날짜 적기**: `d`일(1부터)은 처음부터 셌을 때 `start + d - 1`번째 칸입니다(0부터 셈). 이 번호를 `week`로 나눈 몫이 행, 나머지가 열입니다.

```java
int pos = start + d - 1;
calendar[pos / week][pos % week] = d;
```

## 주의할 점
- `(start + days) / week`로 행 수를 구하면 나누어떨어지지 않을 때 한 행이 모자랍니다. 올림 나눗셈을 쓰세요. 반대로 무조건 1을 더하면 예 #2처럼 나누어떨어질 때 빈 행이 하나 더 생깁니다.
- 1일의 위치는 `start`번 칸이지만 날짜 번호는 1부터라 `start + d - 1`처럼 1을 빼야 합니다.
- 칸 수는 최대 약 100만 개라 `int`로 충분합니다.

## 복잡도
- 시간 O(rows × week), 공간 O(rows × week) (결과 배열)
