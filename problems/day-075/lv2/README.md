# [lv2] 선물 꾸러미 경우의 수

선물 가게에 상품 `n`개가 진열되어 있고, `i`번 상품의 가격은 `prices[i]`원입니다. 손님은 상품을 **정확히 `k`개** 골라 꾸러미를 만들려고 하며, 고른 상품 가격의 합이 **정확히 `budget`원**이어야 합니다.

- 상품은 모두 서로 다른 물건입니다. 가격이 같은 상품이라도 다른 상품을 고르면 다른 꾸러미로 셉니다.
- 같은 상품을 두 번 고를 수는 없습니다.
- 고르는 순서는 상관없습니다. 같은 상품들로 이루어진 꾸러미는 한 가지로 셉니다.

만들 수 있는 꾸러미의 수를 **1,000,000,007로 나눈 나머지**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `prices`의 길이 `n` ≤ 100
- 1 ≤ `prices[i]` ≤ 10,000
- 1 ≤ `k` ≤ `n`
- 1 ≤ `budget` ≤ 10,000

## 입출력 예

| prices | k | budget | result |
|---|---|---|---|
| [1, 2, 3, 4, 5] | 2 | 6 | 2 |
| [2, 2, 2, 2] | 2 | 4 | 6 |
| [5, 10] | 1 | 7 | 0 |

## 입출력 예 설명
- 예 #1: 두 개를 골라 6원이 되는 꾸러미는 {1, 5}, {2, 4} 두 가지입니다. {3, 3}은 3원짜리 상품이 하나뿐이라 만들 수 없습니다.
- 예 #2: 2원짜리 상품 4개 중 2개를 고르는 방법은 4 × 3 / 2 = 6가지입니다.
- 예 #3: 7원짜리 상품이 없습니다.
