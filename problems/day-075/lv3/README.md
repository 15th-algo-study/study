# [lv3] 두 탐험가의 경유지

두 탐험가가 같은 군도를 각자 탐험하고 돌아왔습니다. 섬마다 고유 번호가 있으며, 첫 번째 탐험가가 들른 섬의 번호를 들른 순서대로 적은 배열이 `routeA`, 두 번째 탐험가의 배열이 `routeB`입니다. 한 탐험가는 같은 섬을 두 번 들르지 않았습니다.

탐험 협회는 두 기록에서 **공통 항로**를 찾으려고 합니다. 공통 항로는 섬 번호의 목록으로, 다음 조건을 만족합니다.

- `routeA`에서 섬 몇 개를 골라 **순서를 바꾸지 않고** 나열한 것입니다. 고른 섬들이 기록에서 붙어 있지 않아도 됩니다.
- `routeB`에서도 같은 방법으로 만들 수 있습니다.

가장 긴 공통 항로에 들어 있는 **섬의 수**를 return 하도록 `solution` 함수를 완성해 주세요. 두 탐험가가 함께 들른 섬이 없으면 0을 return 합니다.

## 제한사항
- 1 ≤ `routeA`의 길이, `routeB`의 길이 ≤ 200,000
- 1 ≤ 섬 번호 ≤ 1,000,000,000
- `routeA` 안의 번호는 모두 서로 다르고, `routeB` 안의 번호도 모두 서로 다릅니다.

## 입출력 예

| routeA | routeB | result |
|---|---|---|
| [5, 1, 7, 3, 9] | [1, 9, 5, 3, 7] | 2 |
| [10, 20, 30] | [40, 50] | 0 |
| [4, 8, 15, 16, 23, 42] | [8, 4, 15, 42, 16, 23] | 4 |

## 입출력 예 설명
- 예 #1: [5, 7], [5, 3], [1, 3], [1, 7] 등이 길이 2인 공통 항로입니다. 길이 3인 공통 항로는 없습니다.
- 예 #2: 함께 들른 섬이 없습니다.
- 예 #3: [4, 15, 16, 23]이나 [8, 15, 16, 23]이 길이 4인 공통 항로입니다.
