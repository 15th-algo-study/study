# 해설 — 해상 레이더의 탐지 범위

## 접근
원점에서의 거리는 `Math.sqrt(x*x + y*y)`이지만, 제곱근을 구하지 않아도 됩니다. 거리 ≤ r 은 **x² + y² ≤ r²** 과 같으므로 정수 곱셈과 비교만으로 판정합니다. 실수 오차가 생길 틈이 없어 경계(거리가 정확히 `r`)도 정확합니다.

## 주의할 점
- `x`가 10^9이면 `x * x`는 10^18이라 `int`(최대 약 2.1×10^9)를 한참 넘칩니다. `int * int`는 `int`로 계산되어 조용히 틀린 값이 되므로, 곱하기 **전에** `long`으로 바꿔야 합니다: `(long) x * x`. `(long) (x * x)`는 이미 넘친 뒤에 바꾸는 것이라 소용없습니다.
- `x² + y²`는 최대 2×10^18, `r²`은 최대 10^18이라 `long`(약 9.2×10^18) 안에 들어갑니다.
- `Math.hypot(x, y) <= r`이나 `Math.sqrt(...) <= r`처럼 실수로 비교하면 거리가 정확히 `r`인 배에서 오차로 틀릴 수 있습니다. 정수로 비교할 수 있으면 정수로 비교하세요.

## 복잡도
- 시간 O(n), 공간 O(1)
