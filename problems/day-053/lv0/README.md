# [lv0] 해상 레이더의 탐지 범위

항구의 해상 레이더가 좌표 평면의 원점 `(0, 0)`에 있고, 탐지 반경은 `r`입니다. 레이더는 원점에서의 거리가 `r` **이하**인 배를 탐지합니다 (거리가 정확히 `r`인 배도 탐지합니다).

배들의 위치가 `ships`로 주어집니다. `ships[i] = [x, y]`는 `i`번 배의 좌표입니다. 레이더가 탐지하는 배의 수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `ships`의 길이 ≤ 1,000,000
- -1,000,000,000 ≤ `x`, `y` ≤ 1,000,000,000
- 0 ≤ `r` ≤ 1,000,000,000
- 같은 위치에 배가 여러 척 있을 수 있습니다.

## 입출력 예

| ships | r | result |
|---|---|---|
| [[3, 4], [5, 0], [-6, 1], [0, 0]] | 5 | 3 |
| [[1000000000, 1000000000]] | 1000000000 | 0 |
| [[-2, -2], [2, 2]] | 2 | 0 |

## 입출력 예 설명
- 예 #1: 거리가 각각 5, 5, √37 ≈ 6.08, 0입니다. 5 이하인 배는 3척입니다.
- 예 #2: 거리는 √2 × 10^9 ≈ 1.41 × 10^9로 반경보다 큽니다.
- 예 #3: 두 배 모두 거리가 √8 ≈ 2.83으로 반경 2보다 큽니다.
