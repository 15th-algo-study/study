# [lv1] 드래곤의 금화 더미

드래곤의 동굴에 금화 더미가 `n`개 있고, `coins[i]`는 `i`번 더미의 금화 수입니다.

도둑이 동굴에 `k`번 숨어들어 매번 다음과 같이 금화를 훔칩니다.
- 그 순간 금화가 **가장 많은 더미** 하나를 고릅니다 (같은 수의 더미가 여럿이면 어느 것을 골라도 결과는 같습니다).
- 그 더미에서 금화의 **절반을 올림한 만큼** 훔칩니다. 더미에 `x`개가 있었다면 `⌈x / 2⌉`개를 훔치고 `⌊x / 2⌋`개가 남습니다. 더미가 비어 있으면 아무것도 훔치지 못합니다.

도둑이 `k`번 동안 훔친 금화의 총 수를 return 하도록 `solution` 함수를 완성해 주세요. 결과는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `coins`의 길이 `n` ≤ 200,000
- 1 ≤ `coins`의 원소 ≤ 1,000,000,000
- 1 ≤ `k` ≤ 200,000

## 입출력 예

| coins | k | result |
|---|---|---|
| [10, 4, 7] | 3 | 12 |
| [8, 8] | 2 | 8 |
| [1] | 5 | 1 |

## 입출력 예 설명
- 예 #1: 10에서 5를 훔쳐 [5, 4, 7] → 7에서 4를 훔쳐 [5, 4, 3] → 5에서 3을 훔쳐 [2, 4, 3]. 합계 5 + 4 + 3 = 12.
- 예 #2: 8에서 4, 남은 8에서 4를 훔칩니다.
- 예 #3: 첫 번째에 1개를 훔치면 더미가 비고, 나머지 네 번은 빈손입니다.
