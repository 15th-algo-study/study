# 해설 — 드래곤의 금화 더미

## 접근
매번 "가장 큰 값을 꺼내 바꿔서 다시 넣는" 작업이므로 **최대 힙**이 제격입니다.

1. 모든 더미를 최대 힙(`PriorityQueue<Integer>`에 `Collections.reverseOrder()`)에 넣습니다.
2. `k`번 반복: 맨 위 `x`를 `poll`하고, `(x + 1) / 2`를 훔친 양에 더한 뒤 `x / 2`를 다시 `offer`합니다.

## 주의할 점
- 매번 배열을 정렬하거나(O(k·n log n)) 최댓값을 찾아 훑으면(O(k·n)) 20만 × 20만 = 4×10^10이라 시간 초과입니다. 힙은 한 번에 O(log n)입니다.
- 훔친 총량은 최대 2×10^5 × 10^9 = 2×10^14이므로 `long`에 누적합니다.
- `⌈x / 2⌉`는 `(x + 1) / 2`로 씁니다. `x`가 10^9여도 `x + 1`은 `int` 안입니다.
- 힙 맨 위가 0이면 더 훔칠 것이 없으므로 일찍 멈춰도 됩니다(안 멈춰도 정답은 같습니다).

## 복잡도
- 시간 O((n + k) log n), 공간 O(n)
