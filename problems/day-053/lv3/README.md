# [lv3] 양봉장 벌통 무게의 이동 중앙값

양봉장의 저울이 벌통 하나의 무게를 매일 한 번 잰 기록이 `weights`로 주어집니다. `weights[i]`는 `i`번째 날의 무게입니다.

양봉가는 하루하루의 튀는 값을 걸러 보려고 **연속한 `k`일의 중앙값**을 봅니다. 어떤 `k`일 구간의 중앙값은 그 `k`개의 값을 오름차순으로 늘어놓았을 때 가운데 값이고, `k`가 짝수이면 가운데 두 값 중 **작은 쪽**입니다. 즉 오름차순으로 `⌈k / 2⌉`번째 값입니다.

`weights[0..k-1]`, `weights[1..k]`, …, `weights[n-k..n-1]` 각 구간의 중앙값을 순서대로 담은 길이 `n - k + 1`의 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `k` ≤ `weights`의 길이 `n` ≤ 200,000
- 1 ≤ `weights`의 원소 ≤ 1,000,000,000

## 입출력 예

| weights | k | result |
|---|---|---|
| [1, 3, 2, 6, 5, 4] | 3 | [2, 3, 5, 5] |
| [5, 4, 3, 2, 1] | 2 | [4, 3, 2, 1] |
| [9, 1, 8, 2] | 4 | [2] |

## 입출력 예 설명
- 예 #1: [1, 3, 2] → 2, [3, 2, 6] → 3, [2, 6, 5] → 5, [6, 5, 4] → 5
- 예 #2: 두 값 중 작은 쪽입니다.
- 예 #3: 구간이 하나뿐입니다. 정렬하면 [1, 2, 8, 9]이고 가운데 두 값 2, 8 중 작은 쪽 2입니다.
