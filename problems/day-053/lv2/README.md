# [lv2] 전기차 충전소 배정

고속도로 휴게소의 전기차 충전소에 충전기가 `m`대 있고 1번부터 `m`번까지 번호가 붙어 있습니다. 차 `n`대가 차례로 도착합니다. `i`번째(0번부터) 차는 `arrive[i]`분에 도착해 충전에 `need[i]`분이 걸립니다. `arrive`는 오름차순(같은 값 가능)이며, 같은 시각에 도착한 차는 배열에서 앞선 차가 먼저 처리됩니다.

배정 규칙은 다음과 같습니다.
- 차가 도착했을 때 비어 있는 충전기가 있으면 그중 **번호가 가장 작은** 충전기에서 바로 충전을 시작합니다. 어떤 차의 충전이 끝나는 시각과 같은 시각에 도착한 차는 그 충전기를 바로 쓸 수 있습니다.
- 비어 있는 충전기가 없으면 **도착 순서대로 줄을 서서** 기다립니다. 충전기가 비면 줄의 맨 앞 차가 그 충전기에서 즉시 충전을 시작합니다. 같은 시각에 충전기가 여러 대 비면 번호가 작은 충전기부터 줄 앞의 차에게 차례로 배정됩니다.
- 충전은 한 번 시작하면 중단 없이 `need[i]`분 동안 이어집니다.

각 차가 사용한 충전기의 번호를 차 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `arrive`의 길이 `n` ≤ 400,000, `need`의 길이는 `n`과 같습니다.
- 0 ≤ `arrive`의 원소 ≤ 1,000,000,000, 오름차순(비내림차순)입니다.
- 1 ≤ `need`의 원소 ≤ 1,000,000,000
- 1 ≤ `m` ≤ 300,000

## 입출력 예

| arrive | need | m | result |
|---|---|---|---|
| [0, 0, 0, 1, 5] | [5, 2, 8, 3, 1] | 2 | [1, 2, 2, 1, 1] |
| [0, 10, 20] | [5, 5, 5] | 3 | [1, 1, 1] |
| [0, 0, 0, 0] | [4, 4, 1, 1] | 2 | [1, 2, 1, 2] |

## 입출력 예 설명
- 예 #1
  - 0분: 0번 차 → 1번 충전기(5분까지), 1번 차 → 2번 충전기(2분까지), 2번 차는 빈 충전기가 없어 대기
  - 1분: 3번 차 도착, 대기 (줄: 2번 차, 3번 차)
  - 2분: 2번 충전기가 비어 2번 차가 2번 충전기 사용(10분까지)
  - 5분: 1번 충전기가 비어 3번 차가 1번 충전기 사용(8분까지). 같은 5분에 도착한 4번 차는 빈 충전기가 없어 대기
  - 8분: 4번 차가 1번 충전기 사용
- 예 #2: 매번 1번 충전기가 비어 있습니다.
- 예 #3: 0번·1번 차가 1번·2번 충전기를 4분까지 씁니다. 4분에 두 충전기가 동시에 비므로 줄 앞의 2번 차가 1번, 3번 차가 2번 충전기를 씁니다.
