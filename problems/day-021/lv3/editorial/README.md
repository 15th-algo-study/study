# 해설 — 출입국 심사대

## 접근
승객마다 "가장 먼저 비는 심사대"를 `k`개 중에서 고르면 O(nk)라 최악 4.5×10^10 번으로 시간 초과입니다. 우선순위 큐로 O(n log k)에 풀 수도 있지만, 이 문제에는 더 단순한 관찰이 있습니다.

**관찰**: 심사 시간이 모두 `s`로 같으므로, 승객 `i`가 시작할 때 가장 먼저 비는 심사대는 **`k`명 앞 승객(`i - k`)이 쓰던 심사대**입니다. 시작 시각은 줄 순서대로 단조 증가하므로, 직전 `k`명 중 가장 먼저 시작한 사람이 가장 먼저 끝나기 때문입니다.

따라서

```
start[i] = max(arrivals[i], start[i - k] + s)   (i < k 이면 start[i] = arrivals[i])
```

가 되고, 필요한 것은 **최근 `k`명의 시작 시각**뿐입니다. 큐(`ArrayDeque<Long>`)에 시작 시각을 넣고, 크기가 `k`를 넘으면 맨 앞을 꺼내 `start[i - k]`로 씁니다. 큐의 맨 앞이 항상 "지금 비는 심사대의 시각"이 됩니다.

## 주의할 점
- 대기 시간 하나가 최대 약 3×10^11(승객 30만 명 × 10^6초)까지 커지므로 `start`와 합계 모두 `long`이어야 합니다.
- "끝나는 그 순간 도착한 승객도 바로 시작"이므로 `max`로 충분하며 `+1` 같은 보정은 필요 없습니다.
- 심사 시간이 승객마다 다르면 이 관찰은 성립하지 않습니다(그때는 힙이 필요합니다). 조건이 왜 성립하는지 한 번 따져 보세요.

## 복잡도
- 시간 O(n), 공간 O(k)
