# [lv3] 출입국 심사대

공항 입국장에 심사대가 `k`개 있습니다. 승객 `n`명이 한 줄로 서서 차례를 기다리며, 승객들의 도착 시각이 줄 선 순서대로 배열 `arrivals`에 담겨 있습니다(오름차순, 같은 시각 가능). 심사는 누구나 정확히 `s`초가 걸립니다.

- 비어 있는 심사대가 있고 줄 맨 앞 승객이 이미 도착해 있으면, 그 승객은 **즉시** 심사를 시작합니다. 심사가 끝나는 바로 그 순간에 도착한 승객도 바로 시작할 수 있습니다.
- 줄은 항상 도착 순서(배열 순서)대로 처리되며, 새치기는 없습니다.
- 비어 있는 심사대가 여러 개면 어느 것을 써도 결과에 영향이 없습니다.

승객의 **대기 시간**은 `심사 시작 시각 - 도착 시각`입니다. 모든 승객의 대기 시간의 합을 return 하도록 `solution` 함수를 완성해 주세요. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `arrivals`의 길이 `n` ≤ 300,000
- 0 ≤ `arrivals[i]` ≤ 1,000,000,000, `arrivals`는 오름차순(같은 값 가능)으로 정렬되어 있습니다.
- 1 ≤ `k` ≤ 300,000
- 1 ≤ `s` ≤ 1,000,000

## 입출력 예

| arrivals | k | s | result |
|---|---|---|---|
| [0, 0, 0, 0] | 2 | 10 | 20 |
| [0, 1, 2, 3, 4, 5] | 1 | 3 | 30 |
| [0, 5, 100, 100, 100] | 2 | 10 | 10 |

## 입출력 예 설명
- 예 #1: 앞의 두 명은 0초에 시작하고, 뒤의 두 명은 심사대가 비는 10초에 시작합니다. 대기 시간은 0 + 0 + 10 + 10 = 20입니다.
- 예 #2: 심사대가 하나라 0, 3, 6, 9, 12, 15초에 차례로 시작합니다. 대기 시간은 0 + 2 + 4 + 6 + 8 + 10 = 30입니다.
- 예 #3: 첫 두 명은 각각 0초, 5초에 바로 시작합니다. 100초에 도착한 세 명 중 두 명은 바로 시작하고, 마지막 한 명은 심사대가 비는 110초에 시작하므로 10초를 기다립니다.
