# [lv0] 단체 사진에서 빠지는 사람

`n`명이 1번부터 `n`번까지 번호 순서대로 한 줄로 서서 단체 사진을 찍으려 합니다. 그런데 촬영 직전에 몇 사람이 차례로 줄을 떠났습니다.

배열 `leave`의 `i`번째 원소는 `i`번째로 떠난 사람이 **떠나는 그 순간** 줄의 왼쪽에서 몇 번째에 서 있었는지(1부터 셈)를 나타냅니다. 누군가 떠나면 그 오른쪽에 있던 사람들이 한 칸씩 당겨 서므로, 다음 사람의 위치는 당겨진 줄을 기준으로 셉니다.

모두 떠난 뒤 줄에 남은 사람들의 번호를 왼쪽부터 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 아무도 남지 않으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `n` ≤ 10,000
- 0 ≤ `leave`의 길이 ≤ `n`
- 1 ≤ `leave[i]` ≤ (그 순간 줄에 서 있는 사람 수) — 항상 유효한 위치만 주어집니다.

## 입출력 예

| n | leave | result |
|---|---|---|
| 5 | [2, 2, 1] | [4, 5] |
| 3 | [3, 1, 1] | [] |
| 4 | [] | [1, 2, 3, 4] |

## 입출력 예 설명
- 예 #1: [1, 2, 3, 4, 5]에서 2번째(2번)가 떠나 [1, 3, 4, 5], 다시 2번째(3번)가 떠나 [1, 4, 5], 1번째(1번)가 떠나 [4, 5]가 남습니다.
- 예 #2: 3번째(3번), 1번째(1번), 1번째(2번) 순서로 모두 떠나 아무도 남지 않습니다.
- 예 #3: 아무도 떠나지 않았습니다.
