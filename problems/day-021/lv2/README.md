# [lv2] 저수지 수위가 더 높아지는 날

저수지의 수위를 매일 한 번씩 측정해 배열 `levels`에 기록했습니다. `levels[i]`는 `i`번째 날(0부터 셈)의 수위입니다.

각 날짜 `i`에 대해, 그날보다 수위가 **엄격히 높은** 날이 처음 나타나는 날 `j`(`j > i`)까지 며칠이 걸리는지(`j - i`)를 구하려 합니다. 그런 날이 없으면 0으로 둡니다.

각 날짜에 대한 값을 날짜 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `levels`의 길이 ≤ 500,000
- 0 ≤ `levels[i]` ≤ 1,000,000,000
- 같은 수위는 "더 높은" 것으로 치지 않습니다.

## 입출력 예

| levels | result |
|---|---|
| [3, 1, 4, 1, 5, 9, 2, 6] | [2, 1, 2, 1, 1, 0, 1, 0] |
| [5, 5, 5] | [0, 0, 0] |
| [1, 2, 3] | [1, 1, 0] |

## 입출력 예 설명
- 예 #1: 0일(3)보다 높은 첫날은 2일(4)이므로 2, 1일(1)은 바로 다음 날 4가 되므로 1, 5일(9)보다 높은 날은 없으므로 0입니다.
- 예 #2: 수위가 계속 같으므로 더 높아지는 날이 없습니다.
- 예 #3: 매일 높아지므로 마지막 날을 빼고 모두 1입니다.
