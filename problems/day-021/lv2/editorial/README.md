# 해설 — 저수지 수위가 더 높아지는 날

## 접근
날짜마다 오른쪽을 끝까지 훑으면 수위가 계속 내려가는 입력에서 O(n²) = 1.25×10^11 번이라 시간 초과입니다.

**아직 답을 못 찾은 날짜들**을 스택에 쌓아 두고, 새 날짜 `j`가 올 때마다 "`j`가 답이 되는 날짜"를 스택에서 꺼냅니다.

1. 스택에는 날짜 인덱스를 넣습니다. 스택 안의 날짜들은 위로 갈수록 수위가 **낮거나 같게** 유지됩니다.
2. 날짜 `j`를 처리할 때, 스택 맨 위의 날짜 `i`가 `levels[i] < levels[j]`이면 `j`가 `i`의 답입니다. `answer[i] = j - i`로 적고 꺼냅니다. 더 꺼낼 게 없을 때까지 반복합니다.
3. `j`를 스택에 넣습니다.
4. 끝까지 처리한 뒤 스택에 남은 날짜는 답이 0입니다 (`int[]` 기본값이므로 따로 할 일이 없습니다).

각 날짜는 스택에 한 번 들어가고 한 번 나오므로 전체 O(n)입니다.

## 주의할 점
- 비교는 **엄격한 부등호**(`<`)여야 합니다. `<=`로 꺼내면 같은 수위도 "더 높은" 날로 셉니다.
- 스택에 수위 값이 아니라 **인덱스**를 넣어야 날짜 차이를 계산할 수 있습니다.
- `ArrayDeque<Integer>`도 충분히 빠르지만, 50만 개라면 `int[]` 배열과 top 인덱스로 스택을 직접 만들면 더 간단하고 빠릅니다.

## 복잡도
- 시간 O(n), 공간 O(n)
