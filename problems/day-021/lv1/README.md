# [lv1] 매표소 우대 줄

공연장 매표소에는 창구가 하나뿐이고, 손님들은 **우대 줄**과 **일반 줄** 두 줄로 섭니다. 우대 줄에 선 손님들의 대기 번호가 선 순서대로 배열 `priority`에, 일반 줄에 선 손님들의 대기 번호가 선 순서대로 배열 `general`에 담겨 있습니다.

창구는 두 줄이 모두 빌 때까지 다음을 반복합니다.

1. 우대 줄의 앞에서부터 최대 `k`명을 차례로 처리합니다. 우대 줄에 `k`명보다 적게 남아 있으면 남은 사람을 모두 처리하고, 아무도 없으면 건너뜁니다.
2. 일반 줄의 맨 앞 1명을 처리합니다. 일반 줄이 비어 있으면 건너뜁니다.

창구가 손님을 처리한 순서대로 대기 번호를 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 0 ≤ `priority`의 길이 ≤ 100,000
- 0 ≤ `general`의 길이 ≤ 100,000
- 두 배열의 길이의 합은 1 이상입니다.
- 1 ≤ `k` ≤ 100,000
- 대기 번호는 1 이상 1,000,000,000 이하의 정수이며, 두 배열을 통틀어 서로 다릅니다.

## 입출력 예

| priority | general | k | result |
|---|---|---|---|
| [1, 2, 3, 4, 5] | [10, 20, 30] | 2 | [1, 2, 10, 3, 4, 20, 5, 30] |
| [7] | [8, 9, 10] | 3 | [7, 8, 9, 10] |
| [5, 6, 7] | [] | 1 | [5, 6, 7] |

## 입출력 예 설명
- 예 #1: 우대 2명(1, 2) → 일반 1명(10) → 우대 2명(3, 4) → 일반 1명(20) → 우대 1명(5, 남은 사람이 1명뿐) → 일반 1명(30) 순서입니다.
- 예 #2: 우대 줄에는 7 한 명뿐이라 첫 반복에서 7, 8을 처리하고, 그 뒤로는 우대 줄이 비어 있으므로 일반 줄에서 9, 10을 차례로 처리합니다.
- 예 #3: 일반 줄이 비어 있으므로 우대 줄만 순서대로 처리합니다.
