# 해설 — 매표소 우대 줄

## 접근
두 줄을 각각 **큐**(`ArrayDeque`)에 담고 지문의 규칙을 그대로 시뮬레이션합니다.

```
while (우대 큐나 일반 큐가 비어 있지 않음) {
    k번 반복: 우대 큐가 비어 있지 않으면 poll 해서 결과에 추가
    일반 큐가 비어 있지 않으면 poll 해서 결과에 추가
}
```

한 사람은 정확히 한 번 꺼내지므로 전체 처리 횟수는 두 배열 길이의 합과 같습니다.

## 주의할 점
- 우대 줄이 비어 있을 때 `k`번 반복하는 안쪽 루프가 헛돌면 바깥 루프 한 번당 O(k)가 되어 k = 100,000, 일반 줄 100,000명이면 10^10번 돕니다. `min(k, 우대 큐 크기)`번만 돌거나, 큐가 비면 바로 `break` 하세요.
- 결과 배열의 길이는 두 배열 길이의 합이므로 미리 `int[]`를 만들어 채우면 `List` 없이도 됩니다.
- 큐 대신 두 인덱스(`pi`, `gi`)로 배열을 직접 훑어도 같은 답이 나옵니다. 큐 API(`offer`/`poll`/`isEmpty`)에 익숙해지는 것이 이 문제의 목표입니다.

## 복잡도
- 시간 O(n + m) (n, m은 두 줄의 길이), 공간 O(n + m)
