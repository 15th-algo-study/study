# 해설 — 욕실 타일 무늬 고르기

## 접근
"모든 무늬가 `t`장 이하"라는 조건은 구간을 **줄이면 유지되고 늘리면 깨질 수 있는** 단조 조건이므로 가변 창으로 풉니다.

1. 무늬별 개수 `cnt`를 유지하며 오른쪽 끝 `r`을 늘립니다 (`cnt[tiles[r]]++`).
2. 방금 들어온 무늬의 개수가 `t`를 넘으면, 넘지 않을 때까지 왼쪽 끝을 올립니다 (`cnt[tiles[l]]--`, `l++`). 다른 무늬는 넘칠 수 없으므로(들어오기 전까지 조건을 만족했으므로) 방금 들어온 무늬만 확인하면 됩니다.
3. 창 `[l, r]`은 끝이 `r`인 가장 긴 유효 구간입니다. 길이가 지금까지의 최댓값보다 **엄격히 클 때만** 답을 갱신하면, 같은 길이 중 가장 먼저 발견된 것, 즉 시작 인덱스가 가장 작은 것이 남습니다.

## 주의할 점
- 동률일 때 가장 왼쪽 시작을 골라야 합니다. `r`이 커지는 순서로 창을 보면 `l`도 줄어들지 않으므로, 같은 길이의 구간은 나중에 나올수록 시작이 큽니다. 그래서 `>`(엄격)로 갱신해야 하고, `>=`로 쓰면 가장 오른쪽 시작이 남습니다.
- n이 100만이므로 `HashMap`보다 `int[200001]` 배열 카운팅이 안전합니다.
- 왼쪽 끝마다 오른쪽으로 늘려 보는 O(n × 창 길이) 풀이는 무늬 두 종류에 `t`가 큰 large 케이스에서 창 길이가 20만 정도라 시간 초과입니다.

## 복잡도
- 시간 O(n), 공간 O(200000)
