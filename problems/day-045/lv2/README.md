# [lv2] 욕실 타일 무늬 고르기

욕실 벽 한 줄에 타일 `n`장이 붙어 있고, `i`번 타일(0번부터 셈)의 무늬 번호는 `tiles[i]`입니다. 이 줄에서 **연속한 구간**을 골라 사진을 찍으려는데, 사진 안에 **같은 무늬가 `t`장을 넘게** 들어가면 단조로워 보여서 안 됩니다. 즉 구간 안의 모든 무늬가 각각 `t`장 이하여야 합니다.

조건을 만족하는 구간 중 **가장 긴 구간의 길이**와, 그런 구간이 여럿이면 **가장 왼쪽에서 시작하는 구간의 시작 인덱스**를 `[길이, 시작 인덱스]` 형태로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `tiles`의 길이 `n` ≤ 1,000,000
- 1 ≤ `tiles`의 원소 ≤ 200,000
- 1 ≤ `t` ≤ `n`

## 입출력 예

| tiles | t | result |
|---|---|---|
| [1, 2, 1, 1, 2, 3] | 2 | [5, 1] |
| [1, 1, 2, 2] | 1 | [2, 1] |
| [4, 4, 4] | 1 | [1, 0] |

## 입출력 예 설명
- 예 #1: 전체는 1번 무늬가 3장이라 안 됩니다. 1번부터 시작하는 [2, 1, 1, 2, 3]은 1번 2장, 2번 2장, 3번 1장으로 조건을 만족하고 길이 5입니다.
- 예 #2: 길이 2인 구간 중 조건을 만족하는 것은 [1, 2](1번부터)뿐입니다. 0번부터 시작하는 [1, 1]은 안 됩니다.
- 예 #3: 어떤 두 장을 골라도 같은 무늬가 2장이므로 한 장짜리 구간만 가능하고, 가장 왼쪽은 0번입니다.
