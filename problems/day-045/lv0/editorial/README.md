# 해설 — 과속 단속 카메라 집계

## 접근
후보마다 배열을 처음부터 세면 20만 × 20만 = 4 × 10^10번이라 시간 초과입니다. 배열이 정렬되어 있으므로 "`x` 이하인 원소의 개수"는 **`x`보다 큰 값이 처음 나오는 위치**와 같고, 이 위치는 이분 탐색으로 찾습니다.

```java
int lo = 0, hi = n;          // 답은 0..n 사이
while (lo < hi) {
    int mid = (lo + hi) / 2;
    if (speeds[mid] > x) hi = mid;   // mid 도 후보: 더 왼쪽에 답이 있을 수 있다
    else lo = mid + 1;               // mid 는 x 이하 → 답은 mid 오른쪽
}
return lo;                   // x 보다 큰 첫 위치 = x 이하인 개수
```

같은 값이 여러 개라 `Arrays.binarySearch`는 어느 위치를 돌려줄지 정해지지 않으므로, 위처럼 직접 씁니다.

## 주의할 점
- `hi`의 초깃값은 `n - 1`이 아니라 `n`입니다. 모든 속도가 `x` 이하이면 답이 `n`이어야 합니다.
- 비교는 "초과(`>`)"입니다. `>=`로 쓰면 "`x` 미만인 개수"가 되어 예 #1의 60에서 1이 나옵니다.
- `lo < hi`로 돌면 `lo == hi`에서 끝나고 그 값이 답입니다. 무한 루프가 걱정되면 `mid`가 범위를 줄이는지(`hi = mid`, `lo = mid + 1`) 확인하세요.

## 복잡도
- 시간 O(q log n), 공간 O(q)
