# [lv0] 과속 단속 카메라 집계

고속도로 단속 카메라가 하루 동안 측정한 차량 속도가 배열 `speeds`에 **오름차순**으로 정렬되어 담겨 있습니다. 같은 속도가 여러 번 나올 수 있습니다.

경찰서에서는 제한 속도 후보를 여러 개 두고, 각각에 대해 "제한 속도 **이하**로 달린 차량 수"를 알고 싶어 합니다. 제한 속도 후보들이 배열 `limits`에 담겨 있을 때, 후보마다 제한 속도 이하로 달린 차량 수를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `speeds`의 길이 `n` ≤ 200,000
- 1 ≤ `speeds`의 원소 ≤ 1,000,000,000, 오름차순으로 정렬되어 있습니다 (같은 값 가능)
- 0 ≤ `limits`의 길이 ≤ 200,000
- 0 ≤ `limits`의 원소 ≤ 1,000,000,000

## 입출력 예

| speeds | limits | result |
|---|---|---|
| [50, 60, 60, 80, 100] | [60, 59, 120, 10] | [3, 1, 5, 0] |
| [30] | [30, 29] | [1, 0] |
| [7, 7, 7] | [7, 6, 8] | [3, 0, 3] |

## 입출력 예 설명
- 예 #1: 60 이하는 50, 60, 60으로 3대, 59 이하는 50 하나, 120 이하는 전부, 10 이하는 없습니다.
- 예 #2: 차량이 한 대뿐입니다. 제한 속도와 같으면 포함됩니다.
- 예 #3: 모두 같은 속도 7입니다.
