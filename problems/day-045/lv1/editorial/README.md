# 해설 — 사진 콜라주 액자

## 접근
`s`가 커질수록 `s × s`도 커지므로, "`s × s ≥ p`인가?"는 어느 지점부터 계속 참이 되는 단조 조건입니다. 그 **첫 `s`를 이분 탐색**으로 찾습니다 (답에 대한 이분 탐색의 가장 단순한 형태입니다).

- `lo = 1`, `hi = 1,000,000,000` (10^9 × 10^9 = 10^18 ≥ 모든 `p`)
- `mid × mid ≥ p`이면 `hi = mid`, 아니면 `lo = mid + 1`

`s`를 1부터 하나씩 올리면 질의 하나에 최대 10^9번이라 시간 초과입니다.

## 주의할 점
- **`Math.sqrt`에 의존하면 틀립니다.** `double`은 유효 숫자가 약 16자리라 10^18 근처에서는 정수 1 차이를 구별하지 못합니다. 예 #3의 999,999,998,000,000,002는 `Math.sqrt`가 999,999,999.0으로 계산되어 `ceil`을 해도 999,999,999가 나오지만, 실제 답은 1,000,000,000입니다. `sqrt`로 근사치를 구한 뒤 ±1을 정수 곱셈으로 보정하는 방법은 가능하지만, 처음부터 `long` 이분 탐색으로 푸는 편이 안전합니다.
- `mid × mid`는 `mid ≤ 10^9`일 때 최대 10^18이라 `long` 범위 안입니다. `hi`를 더 크게 잡으면 넘칠 수 있으니 상한을 10^9로 두세요.
- `p = 1`이면 답은 1입니다 (`lo = 1`에서 시작).

## 복잡도
- 시간 O(q log 10^9), 공간 O(q)
