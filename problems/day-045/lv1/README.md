# [lv1] 사진 콜라주 액자

사진 `p`장을 모두 넣을 수 있는 **정사각형 격자 액자**를 고르려 합니다. 한 변이 `s`칸인 액자에는 사진이 `s × s`장까지 들어갑니다. 사진을 전부 넣을 수 있는 액자 중 가장 작은 것, 즉 `s × s ≥ p`인 가장 작은 양의 정수 `s`를 구해야 합니다.

여러 콜라주의 사진 수가 배열 `photos`에 담겨 있을 때, 각 콜라주에 필요한 최소 변 길이 `s`를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `photos`의 길이 ≤ 100,000
- 1 ≤ `photos`의 원소 ≤ 10^18 (`long`)

## 입출력 예

| photos | result |
|---|---|
| [1, 2, 4, 5, 10, 16] | [1, 2, 2, 3, 4, 4] |
| [100, 101, 99] | [10, 11, 10] |
| [999999998000000002] | [1000000000] |

## 입출력 예 설명
- 예 #1: 사진 5장은 2×2 = 4칸에 안 들어가므로 3×3이 필요합니다. 16장은 4×4에 딱 맞습니다.
- 예 #2: 100장은 10×10, 101장은 11×11, 99장은 10×10입니다.
- 예 #3: 999,999,999² = 999,999,998,000,000,001이라 한 장이 남으므로 1,000,000,000이 필요합니다.
