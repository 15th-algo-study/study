# 해설 — 와인 시음 코스의 중앙값

## 접근
구간마다 중앙값을 구하려면 정렬이 필요해 O(n² log n)이라 불가능합니다. 중앙값을 직접 구하지 말고 **"중앙값이 `X` 이상인 코스가 존재하는가?"** 를 판정하는 문제로 바꿉니다. `X`가 작을수록 존재하기 쉬우므로 단조이고, 참이 되는 가장 큰 `X`를 **답에 대한 이분 탐색**으로 찾습니다.

**판정 `check(X)`**: 각 평점을 `X` 이상이면 `+1`, 미만이면 `-1`로 바꾼 배열 `b`를 생각합니다. 길이 `L`인 구간의 중앙값(⌈L/2⌉번째)이 `X` 이상이라는 것은 "`X` 미만인 원소가 ⌈L/2⌉ − 1개 이하", 즉 **`X` 이상인 원소가 `X` 미만인 원소보다 많다**는 뜻이고, 이는 그 구간의 `b` 합이 **양수**라는 조건과 같습니다 (홀수·짝수 길이 모두 같은 식입니다).

그러면 "길이 `k` 이상이면서 `b` 합이 양수인 구간이 있는가?"는 누적합 `P`로 O(n)에 판정합니다. 오른쪽 끝 `r`(`P[r]`, `r ≥ k`)마다 왼쪽 끝 후보는 `P[0..r−k]`이고, 그중 최솟값 `minP`를 유지하며 `P[r] − minP > 0`인지 봅니다.

- 탐색 범위: `lo = 1`(또는 최솟값), `hi = max(scores)`. `check(mid)`가 참이면 `lo = mid`, 거짓이면 `hi = mid − 1` (참인 최대값 찾기).
- 답이 실제 평점 중 하나인 이유: `check`는 평점 값에서만 바뀌므로, 참인 최대 `X`는 어떤 평점과 같습니다.

## 주의할 점
- 중앙값 정의가 **⌈L/2⌉번째(작은 쪽 중앙값)** 입니다. "`b` 합 ≥ 0"으로 쓰면 짝수 길이에서 큰 쪽 중앙값이 되어 예 #2의 [5, 1]에서 5가 나오는 등 답이 달라집니다. 반드시 **양수(> 0)** 조건을 쓰세요.
- 왼쪽 끝 후보 `P[r−k]`를 **`r`이 늘 때마다 하나씩** 최솟값에 반영해야 합니다. 전체 최솟값을 쓰면 길이 `k` 미만 구간이 섞입니다.
- 모든 구간을 정렬하거나, 이분 탐색마다 O(n²)으로 구간을 훑는 풀이는 n = 2 × 10^5에서 시간 초과입니다.

## 복잡도
- 시간 O(n log V) (V = 평점 최댓값), 공간 O(n)
