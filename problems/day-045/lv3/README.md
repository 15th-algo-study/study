# [lv3] 와인 시음 코스의 중앙값

와인 바의 시음 목록에 와인 `n`종이 순서대로 적혀 있고, `i`번 와인의 평점은 `scores[i]`입니다. 손님은 목록에서 **연속한 `k`종 이상**을 골라 시음 코스를 만듭니다.

코스의 점수는 고른 와인 평점들의 **중앙값**으로 정합니다. 여기서 길이 `L`인 코스의 중앙값은 평점을 오름차순으로 정렬했을 때 **⌈L / 2⌉번째(1번부터 셈)** 값입니다. 예를 들어 평점이 [3, 9, 2]이면 정렬 [2, 3, 9]의 2번째인 3이고, [1, 10]이면 정렬 [1, 10]의 1번째인 1입니다.

만들 수 있는 코스 중 **중앙값이 가장 큰 코스의 중앙값**을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `scores`의 길이 `n` ≤ 200,000
- 1 ≤ `scores`의 원소 ≤ 1,000,000,000
- 1 ≤ `k` ≤ `n`

## 입출력 예

| scores | k | result |
|---|---|---|
| [1, 2, 3, 2, 1] | 3 | 2 |
| [5, 1, 5, 1, 5] | 2 | 5 |
| [2, 8, 8, 1, 1, 1, 9] | 3 | 8 |

## 입출력 예 설명
- 예 #1: 길이 3 이상인 어떤 구간도 중앙값이 2를 넘지 않습니다. 예를 들어 [2, 3, 2]의 중앙값은 2이고, [1, 2, 3, 2]는 정렬 [1, 2, 2, 3]의 2번째인 2입니다.
- 예 #2: [5, 1, 5]의 중앙값은 정렬 [1, 5, 5]의 2번째인 5입니다. 길이 2인 [5, 1]은 중앙값이 1이라 더 작습니다.
- 예 #3: [2, 8, 8]의 중앙값은 8입니다. 9는 한 번뿐이라 9를 포함한 길이 3 이상의 구간은 중앙값이 9가 될 수 없습니다.
