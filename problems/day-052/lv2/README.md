# [lv2] 중고 장터의 최저가

동네 중고 장터 앱의 기록이 배열 `events`로 주어집니다. `events[i] = [t, v]`는 다음 중 하나입니다.

- `t = 0`: 가격이 `v`인 상품이 **등록**됩니다. 상품에는 등록된 순서대로 1번부터 번호가 붙습니다.
- `t = 1`: `v`번 상품이 **내려갑니다**(판매 완료). 아직 등록되지 않은 번호이거나 이미 내려간 상품이면 아무 일도 일어나지 않습니다.
- `t = 2`: 지금 올라와 있는 상품 중 **가장 싼 가격**을 기록합니다. 올라온 상품이 없으면 `-1`을 기록합니다. 이때 `v`는 무시합니다.

`t = 2`에서 기록한 값을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. `t = 2`인 기록이 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `events`의 길이 ≤ 200,000
- `t`는 0, 1, 2 중 하나입니다.
- `t = 0`이면 1 ≤ `v` ≤ 1,000,000,000 (가격)
- `t = 1`이면 1 ≤ `v` ≤ 1,000,000,000 (상품 번호. 존재하지 않는 번호일 수 있습니다)

## 입출력 예

| events | result |
|---|---|
| [[0, 500], [0, 300], [2, 0], [1, 2], [2, 0], [1, 2], [0, 100], [2, 0]] | [300, 500, 100] |
| [[2, 0], [0, 7], [1, 1], [2, 0]] | [-1, -1] |
| [[0, 5], [0, 5], [1, 1], [2, 0], [1, 2], [2, 0]] | [5, -1] |

## 입출력 예 설명
- 예 #1: 500원(1번), 300원(2번) 등록 → 최저가 300. 2번이 내려가 최저가 500. 2번을 다시 내리는 기록은 무시. 100원(3번) 등록 → 최저가 100.
- 예 #2: 처음엔 상품이 없어 -1. 7원(1번)을 등록했다가 바로 내렸으므로 다시 -1.
- 예 #3: 같은 가격 5원인 상품 둘 중 1번이 내려가도 2번이 남아 5. 2번까지 내려가면 -1.
