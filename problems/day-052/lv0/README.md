# [lv0] 금고 다이얼

금고의 다이얼에는 `0`부터 `n - 1`까지의 눈금이 시계 방향으로 둥글게 새겨져 있습니다. 다이얼은 처음에 `0`을 가리킵니다.

다이얼을 돌린 기록이 배열 `turns`로 주어집니다. `turns[i]`가 양수면 시계 방향으로 그 칸 수만큼, 음수면 반시계 방향으로 절댓값만큼 돌린 것입니다. 시계 방향으로 한 칸 돌리면 눈금이 1 커지고, `n - 1`에서 한 칸 더 돌리면 `0`으로 돌아옵니다.

모든 기록을 순서대로 적용한 뒤 **다이얼이 가리키는 눈금**과, 방향에 관계없이 **돌린 칸 수의 합**을 `[눈금, 칸 수의 합]` 순서의 `long` 배열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 1,000,000,000
- 0 ≤ `turns`의 길이 ≤ 1,000,000
- -1,000,000,000 ≤ `turns`의 원소 ≤ 1,000,000,000
- 칸 수의 합은 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| n | turns | result |
|---|---|---|
| 10 | [3, -5, 12] | [0, 20] |
| 5 | [-1] | [4, 1] |
| 100 | [1000000000, 1000000000, 1000000000] | [0, 3000000000] |

## 입출력 예 설명
- 예 #1: 0 → 3 → (반시계 5칸) 8 → (시계 12칸 = 한 바퀴 + 2칸) 0. 돌린 칸 수는 3 + 5 + 12 = 20입니다.
- 예 #2: 0에서 반시계로 한 칸 돌리면 가장 큰 눈금 4입니다.
- 예 #3: 30억 칸을 돌렸고 100의 배수이므로 다시 0입니다. 칸 수의 합 3,000,000,000은 `int`에 담기지 않습니다.
