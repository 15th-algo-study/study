# 해설 — 금고 다이얼

## 접근
눈금은 "지금까지 돌린 칸 수의 합(부호 포함)을 `n`으로 나눈 나머지"입니다. 부호 있는 합 `signed`와 절댓값의 합 `total`을 각각 `long`으로 누적한 뒤,

- 눈금 = `Math.floorMod(signed, n)` — 음수여도 `0 ~ n-1` 사이의 값을 돌려줍니다.
- 칸 수의 합 = `total` (각 항은 `Math.abs(turns[i])`).

## 주의할 점
- 자바의 `%`는 피제수가 음수면 음수를 돌려줍니다. `-5 % 10`은 `-5`이므로 그대로 쓰면 눈금이 음수가 됩니다. `Math.floorMod(-5, 10)`은 `5`입니다. `((signed % n) + n) % n`으로 써도 같습니다.
- `turns`의 원소 10^9가 100만 개면 합이 10^15라 `int`로 누적하면 넘칩니다. 누적 변수를 `long`으로 두세요. `Math.floorMod(long, int)` 오버로드가 있어 그대로 쓸 수 있습니다.
- `turns`가 비어 있으면 `[0, 0]`입니다.

## 복잡도
- 시간 O(n), 공간 O(1)
