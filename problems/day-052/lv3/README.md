# [lv3] 무대 조명의 밝기 면적

길게 뻗은 무대를 수직선으로 보고, 조명 `n`개가 무대를 비춥니다. `lights[i] = [s, len, b]`는 `i`번 조명이 `s` 이상 `s + len` 미만인 구간을 밝기 `b`로 비춘다는 뜻입니다.

무대 위 한 지점의 **밝기**는 그 지점을 비추는 조명들의 밝기 중 **최댓값**이고, 비추는 조명이 없으면 0입니다 (밝기는 더해지지 않습니다). 무대의 **밝기 면적**은 밝기를 무대 전체에 걸쳐 적분한 값, 즉 밝기가 일정한 구간마다 `(구간 길이) × (밝기)`를 모두 더한 값입니다.

밝기 면적을 return 하도록 `solution` 함수를 완성해 주세요. 결과는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `lights`의 길이 `n` ≤ 200,000
- 0 ≤ `s` ≤ 1,000,000,000
- 1 ≤ `len` ≤ 1,000,000,000
- 1 ≤ `b` ≤ 1,000,000,000

## 입출력 예

| lights | result |
|---|---|
| [[0, 4, 2], [2, 4, 3]] | 16 |
| [[0, 10, 1], [3, 2, 5], [20, 1, 7]] | 25 |
| [[5, 3, 4], [5, 3, 4]] | 12 |

## 입출력 예 설명
- 예 #1: [0, 2)는 밝기 2(길이 2 → 4), [2, 6)은 두 조명 중 큰 3(길이 4 → 12). 합 16.
- 예 #2: [0, 3)은 1(→ 3), [3, 5)는 5(→ 10), [5, 10)은 1(→ 5), [20, 21)은 7(→ 7). 합 25. [10, 20)은 조명이 없어 0입니다.
- 예 #3: 같은 조명 둘이 겹쳐도 밝기는 4입니다. 3 × 4 = 12.
