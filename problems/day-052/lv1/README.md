# [lv1] 우주 정거장 수리 요청

우주 정거장의 관제 콘솔에 수리 요청이 들어오고, 정비사가 요청을 하나씩 처리합니다. 기록 `ops`와 `urgency`가 주어집니다.

- `ops.charAt(i)`가 `'A'`이면 긴급도가 `urgency[i]`인 수리 요청이 하나 도착합니다. 요청에는 도착한 순서대로 1번부터 번호가 붙습니다.
- `ops.charAt(i)`가 `'P'`이면 정비사가 처리되지 않은 요청 중 하나를 처리합니다. **긴급도가 가장 높은** 요청을 처리하고, 긴급도가 같으면 **먼저 도착한** 요청을 처리합니다. 처리할 요청이 없으면 아무 일도 하지 않습니다. 이때 `urgency[i]`는 무시합니다.

`'P'`마다 처리한 요청의 번호를, 처리할 요청이 없었으면 `0`을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. `'P'`가 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `ops`의 길이 ≤ 200,000
- `ops`는 `'A'`와 `'P'`로만 이루어집니다.
- `urgency`의 길이는 `ops`의 길이와 같고, 1 ≤ `urgency`의 원소 ≤ 1,000,000

## 입출력 예

| ops | urgency | result |
|---|---|---|
| "AAPAPPP" | [3, 5, 1, 5, 1, 1, 1] | [2, 3, 1, 0] |
| "APPA" | [4, 1, 1, 8] | [1, 0] |
| "AAA" | [1, 2, 3] | [] |

## 입출력 예 설명
- 예 #1
  - 1번(긴급도 3), 2번(긴급도 5) 도착 → `P`: 긴급도가 높은 2번 처리
  - 3번(긴급도 5) 도착 → `P`: 남은 요청 중 긴급도 5는 3번뿐이므로 3번 처리
  - `P`: 1번 처리 → `P`: 남은 요청이 없어 0
- 예 #2: 1번 처리 후 두 번째 `P`에는 요청이 없습니다. 마지막에 도착한 4번은 처리되지 않습니다.
- 예 #3: 처리가 한 번도 없으므로 빈 배열입니다.
