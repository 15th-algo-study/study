# [lv2] 산장 숙박 경로

산길을 따라 산장 `n`개가 있고 입구 쪽부터 0번, 1번, …, `n - 1`번입니다. 0번 산장에서 첫날 밤을 묵은 뒤 출발해, 마지막 `n - 1`번 산장에서 묵는 것으로 여정을 마치려 합니다. `i`번 산장에서 하룻밤 묵는 숙박비는 `fees[i]`원입니다.

하루에 걸을 수 있는 거리가 정해져 있어, `i`번 산장에서 출발한 날에는 `i + 1`번부터 `i + k`번 산장 중 한 곳까지만 가서 묵을 수 있습니다. 뒤로 돌아가지는 않습니다.

숙박비 합이 가장 적은 일정에서 묵는 산장 번호를 차례로 담은 배열(0번과 `n - 1`번 포함)을 return 하도록 `solution` 함수를 완성해 주세요. 숙박비 합이 가장 적은 일정이 여러 개라면, 산장 번호 배열이 **사전순으로 가장 앞서는** 일정을 return 합니다.

두 배열의 사전순은 앞에서부터 비교해 처음으로 다른 원소가 작은 쪽이 앞섭니다. 예를 들어 [0, 1, 4]는 [0, 2, 3, 4]보다 앞섭니다.

## 제한사항
- 2 ≤ `fees`의 길이 `n` ≤ 200,000
- 0 ≤ `fees[i]` ≤ 1,000,000,000
- 1 ≤ `k` ≤ 100

## 입출력 예

| fees | k | result |
|---|---|---|
| [3, 8, 2, 9, 4, 1] | 2 | [0, 2, 4, 5] |
| [0, 0, 0, 0] | 3 | [0, 1, 2, 3] |
| [1, 1, 1, 0, 1] | 2 | [0, 1, 3, 4] |

## 입출력 예 설명
- 예 #1: 0 → 2 → 4 → 5번 산장에 묵으면 3 + 2 + 4 + 1 = 10으로 가장 적습니다.
- 예 #2: 모든 일정의 숙박비가 0입니다. [0, 3], [0, 1, 3], [0, 2, 3], [0, 1, 2, 3] 중 사전순으로 가장 앞서는 것은 [0, 1, 2, 3]입니다.
- 예 #3: [0, 2, 4], [0, 1, 3, 4], [0, 2, 3, 4]의 숙박비가 모두 3으로 가장 적습니다. 이 중 사전순으로 가장 앞서는 것은 [0, 1, 3, 4]입니다.
