# 해설 — 퍼레이드 우회로

## 접근
질의마다 그 칸을 막고 경로 수 DP를 다시 돌리면 질의 하나에 O(rows × cols) = 10^6, 질의 20만 개면 2 × 10^11이라 시간 초과입니다.

**관찰**: 칸 하나를 막았을 때 사라지는 경로는 정확히 **그 칸을 지나는 경로**입니다. 그러므로

> 답 = (원래 경로 수) − ((r, c)를 지나는 경로 수)

이고, (r, c)를 지나는 경로는 "출발 → (r, c)" 부분과 "(r, c) → 도착" 부분을 자유롭게 이어 붙인 것이므로 그 수는 두 경우의 수의 **곱**입니다.

1. `from[r][c]` = 출발에서 (r, c)까지 오는 경로 수 — 왼쪽 위부터 `from[r-1][c] + from[r][c-1]`
2. `to[r][c]` = (r, c)에서 도착까지 가는 경로 수 — 오른쪽 아래부터 `to[r+1][c] + to[r][c+1]`
3. 원래 경로 수 `total = from[rows-1][cols-1]`
4. 질의 (r, c)의 답 = `total − from[r][c] × to[r][c]` (mod)

두 번의 DP는 O(rows × cols), 질의는 각각 O(1)입니다.

특별한 경우도 이 식이 그대로 처리합니다.
- 원래 막힌 칸은 `from = 0`이라 지나는 경로가 0 → 답은 `total`
- 출발 칸은 `from × to = 1 × total` → 답은 0. 도착 칸도 마찬가지
- 출발이나 도착이 원래 막혀 있으면 `total = 0`이고 모든 답이 0

## 주의할 점
- `from × to`는 각각 10^9 근처라 곱하면 10^18에 가까워집니다. `long`으로 곱한 뒤 나머지를 구하세요.
- 나머지 세계에서 `total − through`는 음수가 될 수 있습니다. `(total − through + MOD) % MOD`로 맞춥니다.
- 격자가 최대 100만 칸이므로 `long[rows*cols]` 두 개(약 16MB)로 충분합니다.

## 복잡도
- 시간 O(rows × cols + |blocked| + |queries|), 공간 O(rows × cols)
