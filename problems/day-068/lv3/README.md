# [lv3] 퍼레이드 우회로

축제 퍼레이드가 `rows`×`cols` 격자 모양 도시를 지납니다. 퍼레이드는 (0, 0) 칸에서 출발해 (`rows - 1`, `cols - 1`) 칸에 도착하며, 한 번에 오른쪽 또는 아래쪽으로 붙어 있는 칸으로만 이동합니다. `blocked`의 각 원소 `[r, c]`는 원래부터 막혀 있어 지날 수 없는 칸입니다.

축제 위원회는 도로 공사 계획을 검토하고 있습니다. 질의 `queries[i] = [r, c]`는 "원래 상태에서 (r, c) 칸 하나를 추가로 막으면 퍼레이드 경로가 몇 가지 남는가?"를 묻습니다. 질의는 서로 독립이어서, 매번 원래 상태에서 그 칸 하나만 추가로 막는다고 생각합니다.

각 질의의 답을 1,000,000,007로 나눈 나머지를 질의 순서대로 담아 return 하도록 `solution` 함수를 완성해 주세요. 원래 막혀 있는 칸을 묻는 질의의 답은 원래 상태의 경로 수이고, 출발 칸이나 도착 칸을 막으면 답은 0입니다.

## 제한사항
- 1 ≤ `rows`, `cols` ≤ 1,000
- 0 ≤ `blocked`의 길이 ≤ 100,000
  - 원소 `[r, c]`는 0 ≤ `r` < `rows`, 0 ≤ `c` < `cols`를 만족합니다.
  - 같은 칸이 여러 번 들어 있을 수 있고, 출발 칸이나 도착 칸이 들어 있을 수도 있습니다.
- 1 ≤ `queries`의 길이 ≤ 200,000
  - 원소 `[r, c]`는 0 ≤ `r` < `rows`, 0 ≤ `c` < `cols`를 만족합니다.

## 입출력 예

| rows | cols | blocked | queries | result |
|---|---|---|---|---|
| 3 | 3 | [] | [[1, 1], [0, 1], [2, 2]] | [2, 3, 0] |
| 2 | 3 | [[0, 2]] | [[0, 2], [1, 0], [1, 1]] | [2, 1, 0] |
| 1 | 4 | [] | [[0, 2], [0, 0]] | [0, 0] |

## 입출력 예 설명
- 예 #1: 원래 경로는 6가지입니다. 가운데 (1, 1)을 지나는 경로 4가지가 사라지면 2가지, (0, 1)을 지나는 경로 3가지가 사라지면 3가지가 남습니다. 도착 칸을 막으면 0입니다.
- 예 #2: 원래 경로는 "오른쪽, 아래, 오른쪽"과 "아래, 오른쪽, 오른쪽" 2가지입니다. (0, 2)는 이미 막혀 있어 그대로 2, (1, 0)을 막으면 첫째 경로만 남아 1, (1, 1)은 두 경로 모두 지나므로 0입니다.
- 예 #3: 한 줄짜리 도시라 경로는 하나뿐이고, 어느 칸을 막아도 0입니다.
