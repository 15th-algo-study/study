# 해설 — 해변 파라솔 대여

## 접근
앞에서부터 자리를 하나씩 보며 "빌려줄지 말지"를 정합니다. `i`번 자리를 빌려줄 수 있는지는 **바로 앞 자리를 빌려줬는지**에만 달려 있으므로, 두 가지 값만 들고 다니면 됩니다.

- `take` = 지금 자리까지 정했고, 지금 자리를 빌려줬을 때의 최대 합
- `skip` = 지금 자리까지 정했고, 지금 자리를 빌려주지 않았을 때의 최대 합

다음 자리 `f`로 넘어갈 때

- `take' = skip + f` — 지금 자리를 빌려주려면 앞 자리는 비워 둬야 함
- `skip' = max(take, skip)` — 비워 두면 앞 자리는 상관없음

답은 마지막의 `max(take, skip)`입니다.

## 주의할 점
- 가장 단순한 DP는 "i번을 빌려줄 때 i-2번 이전 자리들 중 최댓값"을 매번 앞에서부터 훑어 찾는 O(n²)입니다. n = 20만이면 200억 번이라 시간 초과입니다. 앞에서 구한 최댓값을 그대로 들고 오세요.
- 짝수 번 자리끼리, 홀수 번 자리끼리 더해 큰 쪽을 고르는 방법은 틀립니다(예 #2: 짝수 6, 홀수 6이지만 답은 10).
- 합은 최대 10만 × 10^9 = 10^14이므로 `long`입니다.

## 복잡도
- 시간 O(n), 공간 O(1)
