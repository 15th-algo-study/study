# [lv1] 해변 파라솔 대여

해변에 파라솔 자리 `n`개가 한 줄로 놓여 있습니다. `i`번 자리를 빌려주면 대여료 `fees[i]`원을 받습니다. 그런데 바로 옆에 붙은 두 자리를 함께 빌려주면 파라솔 그늘이 겹쳐 손님들이 불편해하므로, **이웃한 두 자리를 동시에 빌려줄 수는 없습니다.**

빌려줄 자리를 골라 받을 수 있는 대여료 합의 최댓값을 return 하도록 `solution` 함수를 완성해 주세요. 한 자리도 빌려주지 않을 수도 있습니다. 답이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `fees`의 길이 ≤ 200,000
- 0 ≤ `fees[i]` ≤ 1,000,000,000

## 입출력 예

| fees | result |
|---|---|
| [3, 7, 4, 6, 5] | 13 |
| [5, 1, 1, 5] | 10 |
| [4] | 4 |

## 입출력 예 설명
- 예 #1: 1번(7)과 3번(6) 자리를 빌려주면 13입니다. 0·2·4번 자리를 빌려주면 12로 더 적습니다.
- 예 #2: 0번과 3번 자리를 빌려주면 10입니다. 두 자리를 건너뛰어도 됩니다.
- 예 #3: 자리가 하나뿐입니다.
