# 해설 — 가장 큰 숫자 빼기

## 접근
질의마다 직접 빼 보면, 100만은 한 번에 많아야 9씩 줄어드니 십수만 번을 빼야 합니다. 질의가 10만 개면 100억 번이 넘어 너무 느립니다.

**관찰**: `x`에서 한 번 빼면 `y = x - (x의 가장 큰 자릿수)`가 되고, 그 뒤로는 `y`에서 시작한 것과 똑같이 진행됩니다. 그러므로

- `steps[0] = 0`
- `steps[x] = steps[y] + 1`

입니다. `y`는 항상 `x`보다 작으므로, **1부터 차례로** `steps` 배열을 채우면 `steps[y]`는 이미 구해져 있습니다. 질의 중 가장 큰 값까지만 채운 뒤, 각 질의는 배열에서 바로 꺼내 답합니다. 계산한 결과를 배열에 적어 두고 다시 쓰는 것이 메모이제이션입니다.

가장 큰 자릿수는 `x % 10`으로 끝자리를 보고 `x /= 10`으로 지우기를 반복해 구합니다.

## 주의할 점
- 0이 들어 있는 수(예: 100)도 가장 큰 자릿수가 1 이상이므로 항상 줄어듭니다.
- 같은 수가 여러 번 질의되어도 배열에서 꺼내기만 하면 됩니다.

## 복잡도
- 시간 O(M × 자릿수 + Q) (M = 질의의 최댓값, Q = 질의 수), 공간 O(M)
