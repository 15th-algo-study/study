# [lv0] 가장 큰 숫자 빼기

어떤 자연수에서 **그 수의 자릿수 중 가장 큰 숫자**를 빼는 일을 0이 될 때까지 반복합니다. 이렇게 빼는 횟수를 그 수의 '빼기 횟수'라고 부르겠습니다.

예를 들어 24는 24 → 20 → 18 → 10 → 9 → 0으로 5번 만에 0이 되므로 빼기 횟수가 5입니다. (24에서 4를, 20에서 2를, 18에서 8을, 10에서 1을, 9에서 9를 뺍니다.)

정수 배열 `queries`가 주어질 때, 각 원소의 빼기 횟수를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `queries`의 길이 ≤ 100,000
- 1 ≤ `queries[i]` ≤ 1,000,000

## 입출력 예

| queries | result |
|---|---|
| [24] | [5] |
| [9, 10, 1] | [1, 2, 1] |
| [24, 24, 100] | [5, 5, 17] |

## 입출력 예 설명
- 예 #1: 문제 설명과 같습니다.
- 예 #2: 9 → 0 (1번), 10 → 9 → 0 (2번), 1 → 0 (1번)입니다.
- 예 #3: 100 → 99 → 90 → 81 → 73 → 66 → 60 → 54 → 49 → 40 → 36 → 30 → 27 → 20 → 18 → 10 → 9 → 0으로 17번입니다.
