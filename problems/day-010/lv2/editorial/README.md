# 해설 — 벽지 무늬의 반복 단위

## 접근
길이 `n`인 무늬 `t`가 길이 `d`인 단위의 반복이려면

1. **`d`가 `n`의 약수**여야 하고 (단위를 정수 번 이어 붙여야 하므로)
2. 모든 `i ≥ d`에 대해 `t[i] == t[i - d]` 여야 합니다. (단위가 계속 같은 모양으로 반복된다는 뜻)

따라서 `d`를 1부터 올려 가며 **`n`의 약수인 `d`에 대해서만** 2번 조건을 검사하고, 처음 통과하는 `d`가 답입니다. 2번 조건이 통과하지 못하는 `d`는 대개 앞부분에서 금방 틀리므로 빠르게 넘어가고, `n` 자체는 항상 통과합니다.

약수의 개수는 100만 이하에서 많아야 240개이므로, 무늬 하나에 최대 240 × n 번 비교, 실제로는 훨씬 적습니다.

## 주의할 점
- 약수가 아닌 `d`까지 모두 검사하면 O(n²)입니다. 예를 들어 `"aaa…ab"`(a가 999,999개 뒤에 b)는 어떤 `d`에서도 비교가 **끝까지 가서야** 틀리므로 100만 × 100만 / 2번 비교가 되어 시간 초과입니다. 약수만 보면 같은 입력에서 49 × 100만 번으로 끝납니다.
- `t.substring(0, d).repeat(n / d).equals(t)`도 약수만 검사한다면 통과하지만, 문자열을 매번 새로 만들어 메모리를 많이 씁니다. 인덱스 비교가 가볍습니다.
- `(t + t).indexOf(t, 1)` 같은 요령은 자바의 `indexOf`가 최악의 경우 O(n²)이라 위와 같은 입력에서 시간 초과입니다.
- 단위 길이의 **최솟값**을 묻고 있으므로 작은 `d`부터 검사하고 처음 성공할 때 멈춥니다.

## 복잡도
- 시간 O(Σ n × d(n)) (d(n)은 약수 개수, 실제로는 대부분의 약수에서 일찍 탈출), 공간 O(1)
