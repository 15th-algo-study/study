# [lv2] 벽지 무늬의 반복 단위

벽지 두루마리의 무늬를 영문 소문자 문자열로 나타냈습니다. 벽지 공장에서는 무늬 전체를 찍는 대신 **가장 짧은 단위 무늬**를 만들어 두고 그것을 여러 번 이어 붙여 찍으려고 합니다.

문자열 `t`가 문자열 `u`의 **반복**이라는 것은 `u`를 1번 이상 이어 붙여 `t`를 정확히 만들 수 있다는 뜻입니다. 예를 들어 `"abcabcabc"`는 `"abc"`의 반복이고 `"abcabcabc"` 자신의 반복이기도 하지만, `"abcab"`의 반복은 아닙니다.

벽지 무늬들이 문자열 배열 `rolls`로 주어질 때, 각 무늬에 대해 그 무늬가 반복이 되는 **가장 짧은 단위 무늬의 길이**를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `rolls`의 길이 ≤ 100,000
- 각 무늬의 길이는 1 이상 1,000,000 이하이고, 모든 무늬 길이의 합은 1,000,000 이하입니다.
- 무늬는 영문 소문자로만 이루어져 있습니다.

## 입출력 예

| rolls | result |
|---|---|
| ["abcabcabc", "aaaa", "abcd", "abab"] | [3, 1, 4, 2] |
| ["xyxyxyx", "abaabaaba"] | [7, 3] |
| ["z"] | [1] |

## 입출력 예 설명
- 예 #1: `abc` × 3, `a` × 4, `abcd` × 1, `ab` × 2 입니다.
- 예 #2: `xyxyxyx`는 길이 7이고 `xy`를 반복하면 끝이 맞지 않으므로 자기 자신(7)이 가장 짧은 단위입니다. `abaabaaba`는 `aba` × 3 입니다.
- 예 #3: 한 글자는 길이 1인 단위의 반복입니다.
