# [lv3] 두루마리에서 단어 찾기

영문 소문자로 쓰인 긴 두루마리 `scroll`이 있습니다. 두루마리의 글자 위치는 맨 앞을 1번으로 셉니다.

두루마리에서 단어를 찾는 방법은 다음과 같습니다. 정해진 시작 위치부터 오른쪽으로 읽어 가며 단어의 첫 글자와 같은 글자를 만나면 표시하고, 거기서 계속 오른쪽으로 읽어 가며 단어의 둘째 글자와 같은 글자를 만나면 표시하고, … 이렇게 단어의 마지막 글자까지 표시하면 단어를 찾은 것입니다. 즉 단어는 두루마리에서 **순서대로 띄엄띄엄** 나타나도 됩니다. 글자는 항상 **가능한 한 가장 앞쪽**에 표시합니다.

질의 배열 `queries`의 각 원소는 `"p word"` 형태로, 두루마리의 `p`번 위치부터(그 위치 포함) 단어 `word`를 찾으라는 뜻입니다. 각 질의마다 단어의 **마지막 글자를 표시한 위치**를 구해 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 끝까지 읽어도 단어를 다 찾지 못하면 그 질의의 답은 -1입니다.

## 제한사항
- 1 ≤ `scroll`의 길이 ≤ 200,000
- 1 ≤ `queries`의 길이 ≤ 200,000
- 각 질의는 `"p word"` 형태이며 1 ≤ `p` ≤ `scroll`의 길이, `word`는 영문 소문자 1자 이상입니다. 공백은 하나입니다.
- 모든 질의의 `word` 길이의 합은 200,000 이하입니다.

## 입출력 예

| scroll | queries | result |
|---|---|---|
| "abcabc" | ["1 abc", "2 abc", "1 cb"] | [3, 6, 5] |
| "abcabc" | ["4 ca", "1 aa", "6 c"] | [-1, 4, 6] |
| "aaaab" | ["1 b", "5 b", "1 ab"] | [5, 5, 5] |

## 입출력 예 설명
- 예 #1
  - `1 abc`: 1번부터 읽어 `a`(1번), `b`(2번), `c`(3번)을 표시합니다. 답은 3.
  - `2 abc`: 2번부터 읽으면 첫 `a`는 4번에 있고, 이어서 `b`(5번), `c`(6번). 답은 6.
  - `1 cb`: `c`는 3번, 그 뒤의 `b`는 5번. 답은 5.
- 예 #2
  - `4 ca`: `c`는 6번에서 찾지만 그 뒤에 `a`가 없으므로 -1.
  - `1 aa`: `a`(1번), 다음 `a`(4번). 답은 4.
  - `6 c`: 6번 글자가 바로 `c`입니다.
- 예 #3: `b`는 5번에만 있습니다. `1 ab`는 `a`(1번), `b`(5번)으로 5.
