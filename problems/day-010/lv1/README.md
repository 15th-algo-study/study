# [lv1] 표 계산 범위의 칸 수

표 계산 프로그램에서 칸의 주소는 **열 이름 + 행 번호**로 씁니다. 열 이름은 영문 대문자로 `A`, `B`, …, `Z` 다음에 `AA`, `AB`, …, `AZ`, `BA`, …, `ZZ`, `AAA`, … 순서로 이어지고, 행 번호는 1부터 시작하는 정수입니다. 예를 들어 `B2`는 2번째 열의 2번째 행입니다.

범위는 `"주소:주소"` 형태로 두 칸을 적어 나타내며, 두 칸을 **마주 보는 꼭짓점으로 하는 직사각형** 안의 모든 칸을 뜻합니다. 두 칸은 어느 쪽이 왼쪽 위인지 정해져 있지 않습니다. 예를 들어 `B2:D5`와 `D5:B2`는 같은 범위이고, 열 `B`~`D`(3개)와 행 2~5(4개)이므로 칸이 12개입니다.

범위 문자열 배열 `ranges`가 주어질 때, 각 범위에 들어 있는 칸의 수를 순서대로 담은 `long` 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `ranges`의 길이 ≤ 200,000
- 각 범위는 `"열행:열행"` 형태이며 공백이 없습니다.
- 열 이름은 영문 대문자 1자 이상 6자 이하입니다. (`A` = 1번째 열, `Z` = 26번째, `AA` = 27번째, `ZZ` = 702번째, `AAA` = 703번째, …)
- 행 번호는 1 이상 1,000,000,000 이하의 정수이며 0으로 시작하지 않습니다.
- 칸의 수는 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| ranges | result |
|---|---|
| ["B2:D5", "A1:A1", "Z1:AA1"] | [12, 1, 2] |
| ["AA10:A1", "ZZ1:AAA1"] | [270, 2] |
| ["A1:ZZZZZZ1000000000"] | [321272406000000000] |

## 입출력 예 설명
- 예 #1: `Z`는 26번째, `AA`는 27번째 열이므로 `Z1:AA1`은 가로로 이웃한 두 칸입니다.
- 예 #2: `AA10:A1`은 열 1~27(27개), 행 1~10(10개)이므로 270칸입니다. `ZZ`는 702번째, `AAA`는 703번째 열입니다.
- 예 #3: `ZZZZZZ`는 321,272,406번째 열이고 행이 10억 개이므로 321,272,406 × 1,000,000,000 칸입니다.
