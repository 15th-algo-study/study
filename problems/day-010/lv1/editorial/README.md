# 해설 — 표 계산 범위의 칸 수

## 접근
주소 하나를 **열 번호**와 **행 번호**로 바꾸는 함수를 만들면 나머지는 산수입니다.

- 주소에서 앞부분의 대문자가 열 이름, 뒷부분의 숫자가 행 번호입니다. 첫 숫자의 위치를 찾아 자릅니다.
- 열 이름은 **0이 없는 26진법**입니다. `A`=1 … `Z`=26이고, 글자를 하나씩 읽으며 `col = col * 26 + (ch - 'A' + 1)`로 누적하면 열 번호가 됩니다. (`AA` = 1×26 + 1 = 27, `ZZ` = 26×26 + 26 = 702, `AAA` = 27×26 + 1 = 703)
- 칸 수 = `(|col1 - col2| + 1) × (|row1 - row2| + 1)`

## 주의할 점
- 보통의 26진법과 달리 자리에 0이 없습니다. `A`를 0으로 두면 `Z`(26)와 `AA`(27)가 구분되지 않고 `AAA`가 0이 되어 버립니다. 반드시 `+ 1`을 하세요.
- 열 번호는 최대 321,272,406으로 `int`에 들어가지만, 행 수 10^9 과의 **곱은 `long`** 이어야 합니다. `int * int`를 `long` 변수에 넣어도 곱셈 자체가 `int`로 이루어지므로 넘칩니다. 한쪽을 먼저 `long`으로 두세요.
- 두 칸이 어느 쪽이 왼쪽 위인지 정해져 있지 않으므로 차이에 절댓값을 취합니다.
- `split(":")`으로 두 주소를 나누고, 각 주소는 첫 숫자의 인덱스를 찾아 `substring`으로 나누면 됩니다. 정규식 없이 `Character.isDigit`으로 찾는 편이 빠릅니다.

## 복잡도
- 시간 O(전체 글자 수), 공간 O(결과 크기)
