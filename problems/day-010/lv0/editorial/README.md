# 해설 — 문자열 속 숫자들의 합

## 접근
"지금 만들고 있는 수" `current`를 하나 두고 문자열을 한 번 훑습니다.

- 숫자 글자 `ch`를 만나면 `current = current * 10 + (ch - '0')`
- 영문자를 만나면 `current`를 합에 더하고 0으로 되돌립니다.

문자열이 숫자로 끝날 수 있으므로 반복이 끝난 뒤 `current`를 한 번 더 더해야 합니다.

## 주의할 점
- `ch - '0'`이 숫자 글자의 값입니다. `(int) ch`는 문자 코드(`'0'`은 48)이므로 다릅니다.
- 수 하나는 `int`에 들어가지만 합은 최대 약 10^14 이므로 **합은 `long`** 으로 누적합니다.
- 숫자 덩어리를 `substring`으로 잘라 `Integer.parseInt`를 해도 되지만, 위처럼 직접 누적하는 편이 간단하고 빠릅니다.
- 마지막 수를 빠뜨리는 실수가 가장 흔합니다. `"a12b3"`에서 3을 더하려면 반복문이 끝난 뒤의 처리가 필요합니다.

## 복잡도
- 시간 O(n), 공간 O(1)
