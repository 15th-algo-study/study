# [lv0] 문자열 속 숫자들의 합

영문 소문자와 숫자가 섞인 문자열 `s`가 주어집니다. `s`에서 **연속된 숫자 글자들은 하나의 수**로 읽습니다. 예를 들어 `"a12b3"`에는 12와 3 두 수가 들어 있습니다. `s`에 들어 있는 모든 수의 합을 return 하도록 `solution` 함수를 완성해 주세요. 합은 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

- 수는 0으로 시작할 수도 있습니다. `"007"`은 7로 읽습니다.
- 숫자가 하나도 없으면 0을 return 합니다.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 1,000,000
- `s`는 영문 소문자와 숫자(`0`~`9`)로만 이루어져 있습니다.
- 연속된 숫자 글자는 많아야 9개입니다. 즉 수 하나는 999,999,999 이하입니다.

## 입출력 예

| s | result |
|---|---|
| "a12b3" | 15 |
| "007" | 7 |
| "999999999x999999999" | 1999999998 |

## 입출력 예 설명
- 예 #1: 12 + 3 = 15
- 예 #2: 앞의 0은 값에 영향을 주지 않습니다.
- 예 #3: 999,999,999 + 999,999,999 = 1,999,999,998 로 `int` 범위를 넘습니다.
