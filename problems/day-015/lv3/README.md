# [lv3] 겹치지 않는 목표 구간

카드 게임을 여러 판 했습니다. `i`번째 판의 점수 변동이 `scores[i]`이며, 이긴 판은 양수, 진 판은 음수, 비긴 판은 0입니다.

연속된 판 몇 개를 묶어 **묶음의 점수 합이 정확히 `k`**가 되는 묶음을 "목표 묶음"이라고 합니다. 한 판은 많아야 하나의 묶음에만 속할 수 있습니다. 즉, 묶음끼리는 **겹치지 않아야** 합니다(인접한 것은 괜찮습니다).

겹치지 않게 고를 수 있는 목표 묶음의 **최대 개수**를 return 하도록 `solution` 함수를 완성해 주세요. 묶음은 한 판 이상이어야 합니다.

## 제한사항
- 1 ≤ `scores`의 길이 ≤ 300,000
- -1,000,000 ≤ `scores`의 원소 ≤ 1,000,000
- -1,000,000,000 ≤ `k` ≤ 1,000,000,000

## 입출력 예

| scores | k | result |
|---|---|---|
| [2, -1, 2, 1, -2, 3, 0] | 3 | 2 |
| [1, 1, 1, 1] | 2 | 2 |
| [5, -5, 5] | 0 | 1 |

## 입출력 예 설명
- 예 #1: 합이 3인 묶음은 `[2, -1, 2]`(0~2번), `[2, 1]`(2~3번), `[3]`(5번), `[3, 0]`(5~6번)입니다. 겹치지 않게 고르면 예를 들어 `[2, -1, 2]`와 `[3]`으로 2개가 최대입니다.
- 예 #2: `[1, 1]`, `[1, 1]` 두 묶음입니다.
- 예 #3: `[5, -5]`와 `[-5, 5]`는 1번 판을 공유하므로 둘 중 하나만 고를 수 있습니다.
