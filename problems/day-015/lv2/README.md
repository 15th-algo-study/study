# [lv2] 의심스러운 중복 결제

카드사가 하루 동안의 결제 기록을 **시각 순서대로** 받았습니다. `i`번째 결제는 카드 `cards[i]`로 가게 `shops[i]`에서 `times[i]`초에 이루어졌습니다.

같은 카드로 같은 가게에서 **직전에 결제한 뒤** `limit`초 이내에 다시 결제가 일어나면, 그 결제를 **중복 의심 결제**로 표시합니다. 직전 결제가 중복 의심 결제였더라도 기준이 되는 데에는 영향이 없습니다. 즉, 결제 `i`에 대해 같은 카드·같은 가게의 결제 중 가장 최근 것 `j`(`j < i`)가 존재하고 `times[i] - times[j] ≤ limit`이면 `i`는 중복 의심 결제입니다.

중복 의심 결제의 수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `cards`의 길이 = `shops`의 길이 = `times`의 길이 ≤ 200,000
- 카드와 가게 이름은 길이 1 이상 10 이하의 영문 대소문자·숫자로만 이루어져 있습니다.
- 0 ≤ `times`의 원소 ≤ 1,000,000,000이고 `times`는 비내림차순입니다 (같은 시각이 있을 수 있습니다).
- 0 ≤ `limit` ≤ 1,000,000,000

## 입출력 예

| cards | shops | times | limit | result |
|---|---|---|---|---|
| ["c1", "c2", "c1", "c1", "c2"] | ["s1", "s1", "s1", "s2", "s1"] | [0, 5, 10, 15, 100] | 10 | 1 |
| ["a", "a", "a"] | ["x", "x", "x"] | [1, 2, 3] | 1 | 2 |
| ["ab", "a"] | ["c", "bc"] | [0, 0] | 10 | 0 |

## 입출력 예 설명
- 예 #1
  - 2번 결제(c1, s1, 10초): 직전 같은 카드·가게 결제는 0번(0초)이고 10 - 0 = 10 ≤ 10이므로 중복 의심입니다.
  - 3번 결제(c1, s2): 같은 카드·가게의 이전 결제가 없습니다.
  - 4번 결제(c2, s1, 100초): 직전은 1번(5초)이고 95 > 10이라 아닙니다.
- 예 #2: 1번 결제는 0번과 1초 차이, 2번 결제는 1번과 1초 차이로 둘 다 중복 의심입니다.
- 예 #3: 카드 `ab`·가게 `c`와 카드 `a`·가게 `bc`는 서로 다른 조합입니다.
