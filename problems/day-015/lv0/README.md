# [lv0] 점수대별 인원수

학생들의 시험 점수가 배열 `scores`로 주어집니다. 점수는 0점 이상 100점 이하의 정수입니다.

점수를 10점 단위 점수대로 나누어 각 점수대의 인원수를 세려고 합니다. 점수대는 0~9점, 10~19점, …, 80~89점, 90~100점의 10개이며, **100점은 90점대에 포함**합니다.

`[0점대 인원, 10점대 인원, …, 90점대 인원]` 순서로 담은 길이 10인 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `scores`의 길이 ≤ 1,000,000
- 0 ≤ `scores`의 원소 ≤ 100

## 입출력 예

| scores | result |
|---|---|
| [95, 100, 42, 47, 0, 89] | [1, 0, 0, 0, 2, 0, 0, 0, 1, 2] |
| [100, 100] | [0, 0, 0, 0, 0, 0, 0, 0, 0, 2] |
| [9, 10, 19, 20] | [1, 2, 1, 0, 0, 0, 0, 0, 0, 0] |

## 입출력 예 설명
- 예 #1: 0점대에 0점, 40점대에 42점·47점, 80점대에 89점, 90점대에 95점·100점이 있습니다.
- 예 #2: 100점은 90점대입니다.
- 예 #3: 9점은 0점대, 10점과 19점은 10점대, 20점은 20점대입니다.
