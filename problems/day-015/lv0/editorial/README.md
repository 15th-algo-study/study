# 해설 — 점수대별 인원수

## 접근
점수 `s`의 점수대 번호는 `s / 10`입니다 (정수 나눗셈이라 42 → 4, 9 → 0). 다만 100점은 `100 / 10 = 10`이 되어 배열 밖이므로 `Math.min(s / 10, 9)`로 9번에 넣습니다. 길이 10인 배열에 점수대 번호를 인덱스로 써서 하나씩 더합니다.

## 주의할 점
- 100점 처리를 빼먹으면 `ArrayIndexOutOfBoundsException`이 납니다.
- `if (s >= 90) … else if (s >= 80) …`처럼 조건문 10개를 써도 맞지만, 나눗셈 한 번이 훨씬 짧고 실수가 적습니다.
- 인원이 없는 점수대는 0이어야 합니다. `new int[10]`은 0으로 초기화되어 있습니다.

## 복잡도
- 시간 O(n), 공간 O(1)
