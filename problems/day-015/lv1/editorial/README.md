# 해설 — 다트가 겹친 자리

## 접근
좌표가 10억까지라 2차원 배열은 만들 수 없습니다. **두 수를 하나의 키로 합쳐** 해시에 넣습니다.

- `long key = x * 1_000_000_001L + y` — `y`가 `0 ~ 10^9`이므로 `x`에 `10^9 + 1`을 곱하면 서로 다른 `(x, y)`는 항상 다른 키가 됩니다.
- 또는 `x + "," + y` 같은 문자열 키도 됩니다 (조금 느리지만 20만 개는 충분합니다).

`HashMap<Long, Integer>`로 키별 횟수를 센 뒤 값이 2 이상인 키의 개수를 세면 끝입니다. 혹은 `HashSet` 두 개(한 번 본 칸, 두 번 이상 본 칸)로 횟수 없이 셀 수도 있습니다.

## 주의할 점
- `x * 1000000001`을 `int`로 계산하면 넘칩니다. 곱하기 전에 `long`으로 바꾸세요 (`1_000_000_001L`처럼 리터럴에 `L`).
- `x + y`나 `x * y`는 키가 될 수 없습니다. (1, 10)과 (11, 0)이 같은 값이 됩니다.
- `int[]`를 `HashMap` 키로 쓰면 내용이 같아도 다른 키로 취급됩니다 (배열은 `equals`/`hashCode`를 내용으로 비교하지 않습니다).
- 다트마다 앞의 다트를 모두 비교하는 O(n²)은 시간 초과입니다.
- 세 번 꽂힌 칸도 한 칸으로 셉니다.

## 복잡도
- 시간 O(n), 공간 O(n)
