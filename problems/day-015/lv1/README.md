# [lv1] 다트가 겹친 자리

아주 큰 격자 모양 다트판에 다트를 여러 번 던졌습니다. `i`번째 다트가 꽂힌 칸의 좌표가 `darts[i] = [x, y]`입니다. 같은 칸에 다트가 여러 번 꽂힐 수 있습니다.

다트가 **두 번 이상** 꽂힌 칸의 개수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `darts`의 길이 ≤ 200,000
- 0 ≤ `x`, `y` ≤ 1,000,000,000

## 입출력 예

| darts | result |
|---|---|
| [[1, 2], [3, 4], [1, 2], [3, 4], [3, 4], [5, 6]] | 2 |
| [[0, 0], [0, 1], [1, 0]] | 0 |
| [[7, 7], [7, 7], [7, 7]] | 1 |

## 입출력 예 설명
- 예 #1: (1, 2)에 2번, (3, 4)에 3번 꽂혔습니다. (5, 6)은 한 번뿐입니다.
- 예 #2: 모두 다른 칸입니다.
- 예 #3: 세 번 모두 같은 칸이므로 그 칸 하나를 셉니다.
