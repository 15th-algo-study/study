# 해설 — 오늘의 인기 메뉴

## 접근
메뉴 이름이 문자열이라 배열로 셀 수 없으니 `HashMap<String, Integer>`로 메뉴별 주문 횟수를 셉니다. 그다음 **원래 주문 순서대로** 배열을 한 번 더 훑으며 횟수가 지금까지의 최댓값보다 **클 때만** 답을 바꾸면, 동률일 때 먼저 주문된 메뉴가 남습니다.

`HashMap`을 순회하는 순서는 넣은 순서와 무관하므로, 동률 처리를 위해서는 맵이 아니라 원래 배열을 다시 훑어야 합니다.

## 주의할 점
- `map.keySet()`을 돌며 최댓값을 찾으면 동률일 때 어떤 메뉴가 나올지 보장되지 않습니다.
- `>=`로 비교하면 동률에서 나중 메뉴가 답이 됩니다.
- 메뉴마다 배열 전체를 세는 O(n²)은 메뉴 종류가 많으면 시간 초과입니다.
- `map.merge(name, 1, Integer::sum)` 또는 `map.put(name, map.getOrDefault(name, 0) + 1)`로 셉니다.

## 복잡도
- 시간 O(n), 공간 O(메뉴 종류 수)
