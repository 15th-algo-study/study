# [lv3] 세 색이 고른 구간

빨강(`R`), 초록(`G`), 파랑(`B`) 구슬을 한 줄로 꿴 목걸이가 문자열 `beads`로 주어집니다. `beads[i]`는 `i`번 구슬의 색입니다.

목걸이에서 **연속된** 구슬 구간을 하나 잘라내려고 합니다. 잘라낸 구간 안에 빨강, 초록, 파랑 구슬이 **모두 같은 개수**로 들어 있어야 합니다.

조건을 만족하는 구간 중 가장 긴 것의 길이를 return 하도록 `solution` 함수를 완성해 주세요. 그런 구간이 없으면 0을 return 합니다.

## 제한사항
- 1 ≤ `beads`의 길이 ≤ 300,000
- `beads`는 `R`, `G`, `B`로만 이루어져 있습니다.

## 입출력 예

| beads | result |
|---|---|
| "RGBBGR" | 6 |
| "GRGBRR" | 3 |
| "RRRR" | 0 |

## 입출력 예 설명
- 예 #1: 목걸이 전체에 각 색이 2개씩 들어 있습니다.
- 예 #2: `"RGB"`(1~3번)와 `"GBR"`(2~4번)이 조건을 만족하고, 길이 6인 전체는 R이 3개라 안 됩니다. 답은 3입니다.
- 예 #3: 빨강뿐이라 조건을 만족하는 구간이 없습니다.
