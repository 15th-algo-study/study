# 해설 — 주사위 눈 횟수

## 접근
길이 6인 배열 `count`를 만들고, 눈 `r`이 나올 때마다 `count[r - 1]++` 합니다. 눈은 1부터 시작하지만 배열 인덱스는 0부터 시작하므로 1을 빼서 맞춥니다. 다 세면 그 배열이 그대로 답입니다.

## 주의할 점
- `count[r]++`로 쓰면 눈 6에서 인덱스 6에 접근해 `ArrayIndexOutOfBoundsException`이 납니다.
- 눈마다 배열 전체를 다시 세면 6배 느려집니다. 한 번만 훑으세요.
- 아무 눈도 나오지 않은 자리는 0으로 남겨야 합니다. `new int[6]`은 처음부터 0으로 채워져 있습니다.

## 복잡도
- 시간 O(n), 공간 O(1)
