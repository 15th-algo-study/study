# [lv0] 주사위 눈 횟수

보드게임을 하며 주사위를 여러 번 던졌습니다. 나온 눈을 순서대로 기록한 배열 `rolls`가 주어집니다.

1부터 6까지 각 눈이 몇 번 나왔는지 `[1의 횟수, 2의 횟수, 3의 횟수, 4의 횟수, 5의 횟수, 6의 횟수]` 순서로 담은 길이 6인 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `rolls`의 길이 ≤ 1,000,000
- `rolls`의 원소는 1 이상 6 이하의 정수입니다.

## 입출력 예

| rolls | result |
|---|---|
| [1, 3, 3, 6, 2, 3] | [1, 1, 3, 0, 0, 1] |
| [6, 6, 6] | [0, 0, 0, 0, 0, 3] |
| [4] | [0, 0, 0, 1, 0, 0] |

## 입출력 예 설명
- 예 #1: 1이 1번, 2가 1번, 3이 3번, 6이 1번 나왔고 4와 5는 나오지 않았습니다.
- 예 #2: 6만 세 번 나왔습니다.
- 예 #3: 4가 한 번 나왔습니다.
