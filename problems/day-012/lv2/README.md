# [lv2] 글자 타일 묶기

글자 타일 놀이에서 만든 단어들이 문자열 배열 `words`로 주어집니다. 두 단어가 **같은 타일 묶음**으로 만들어졌다면, 즉 각 알파벳이 쓰인 개수가 모두 같다면 같은 그룹에 속합니다. 예를 들어 `"race"`, `"care"`, `"acre"`는 같은 그룹이고, 똑같은 단어가 여러 번 나와도 같은 그룹입니다.

`words`의 단어를 그룹으로 나누었을 때, `[그룹의 수, 가장 큰 그룹에 속한 단어 수]`를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `words`의 길이 ≤ 200,000
- 각 단어는 길이 1 이상 10 이하의 영문 소문자로만 이루어져 있습니다.

## 입출력 예

| words | result |
|---|---|
| ["race", "care", "acre", "cat", "act", "dog"] | [3, 3] |
| ["aa", "aa", "a"] | [2, 2] |
| ["ab", "cd", "ef"] | [3, 1] |

## 입출력 예 설명
- 예 #1: {race, care, acre}, {cat, act}, {dog} 세 그룹이고 가장 큰 그룹은 3개입니다.
- 예 #2: `"aa"` 둘은 같은 그룹, `"a"`는 타일 수가 다르므로 다른 그룹입니다.
- 예 #3: 모두 다른 그룹입니다.
