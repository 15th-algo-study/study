# 해설 — 글자 타일 묶기

## 접근
"같은 그룹"을 판별하는 **대표 키**를 만들면 해시 한 번으로 묶입니다. 단어의 글자를 정렬하면 같은 타일 묶음에서 나온 단어는 모두 같은 문자열이 됩니다 (`race`, `care`, `acre` → `acer`). 길이 26인 개수 배열을 문자열로 만든 것도 키가 됩니다.

1. 단어마다 `char[]`로 바꿔 `Arrays.sort`한 뒤 다시 `String`으로 만들어 키로 씁니다.
2. `HashMap<String, Integer>`에 키별 개수를 셉니다.
3. 그룹 수는 `map.size()`, 가장 큰 그룹은 값들 중 최댓값입니다.

## 주의할 점
- 두 단어씩 짝지어 비교하면 O(n²)이라 20만 개에서 시간 초과입니다. 키를 만들어 한 번에 묶으세요.
- `char[]`는 `HashMap`의 키로 쓸 수 없습니다 (배열은 내용이 아니라 주소로 비교됩니다). 반드시 `new String(chars)`로 바꾸세요.
- 길이가 다른 단어는 글자 종류가 같아도 다른 그룹입니다 (`"a"` vs `"aa"`). 정렬 키는 길이를 자연히 반영합니다.
- 단어 길이가 10 이하라 정렬 비용은 상수에 가깝습니다.

## 복잡도
- 시간 O(n · L log L) (L ≤ 10), 공간 O(n)
