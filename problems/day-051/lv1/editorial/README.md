# 해설 — 유성우 관측 일지

## 접근
"지금까지 중 k번째로 큰 값"은 **크기 k인 최소 힙**으로 유지합니다.

- 힙에는 지금까지 본 값 중 **큰 쪽 k개**만 남깁니다.
- 새 값을 넣고(`offer`) 크기가 k를 넘으면 가장 작은 값을 빼냅니다(`poll`). 빠지는 값은 상위 k개에 들 수 없는 값입니다.
- 힙 크기가 k가 되면 힙의 맨 위(`peek`, 가장 작은 값)가 바로 k번째로 큰 값입니다.

자바의 `PriorityQueue<Integer>`는 기본이 최소 힙이라 비교자 없이 그대로 쓰면 됩니다.

## 주의할 점
- 관측마다 지금까지의 배열을 정렬하면 O(n² log n), 정렬된 리스트에 끼워 넣어도 O(n²)이라 20만 개에서 시간 초과입니다. 힙은 관측마다 O(log k)입니다.
- 힙 크기가 k 미만일 때는 `peek`하지 말고 -1을 적습니다.
- 같은 밝기도 각각 세므로 `Set`이 아니라 힙(중복 허용)을 써야 합니다.

## 복잡도
- 시간 O(n log k), 공간 O(k)
