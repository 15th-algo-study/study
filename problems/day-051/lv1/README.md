# [lv1] 유성우 관측 일지

유성우 관측소에서 밤새 유성이 하나씩 관측됩니다. `bright[i]`는 `i`번째(0번부터)로 관측된 유성의 밝기입니다.

관측소는 유성이 하나 관측될 때마다 **지금까지 관측된 유성 중 `k`번째로 밝은 유성의 밝기**를 일지에 적습니다. 밝기가 같은 유성도 각각 따로 셉니다. 예를 들어 지금까지의 밝기가 `[9, 7, 7, 1]`이면 2번째로 밝은 밝기는 7, 3번째도 7입니다. 아직 관측된 유성이 `k`개 미만이면 `-1`을 적습니다.

일지에 적힌 값을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `bright`의 길이 `n` ≤ 200,000
- 1 ≤ `bright`의 원소 ≤ 1,000,000,000
- 1 ≤ `k` ≤ `n`

## 입출력 예

| bright | k | result |
|---|---|---|
| [5, 1, 9, 3, 7] | 2 | [-1, 1, 5, 5, 7] |
| [4, 4, 4] | 1 | [4, 4, 4] |
| [2, 8] | 3 | [-1, -1] |

## 입출력 예 설명
- 예 #1
  - 5 관측: 1개뿐이라 -1
  - 1 관측: {5, 1} → 2번째로 밝은 값 1
  - 9 관측: {9, 5, 1} → 5
  - 3 관측: {9, 5, 3, 1} → 5
  - 7 관측: {9, 7, 5, 3, 1} → 7
- 예 #2: `k = 1`이면 지금까지의 최댓값입니다.
- 예 #3: 끝까지 3개가 되지 않아 모두 -1입니다.
