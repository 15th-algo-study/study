# [lv0] 유리 공방의 막대 주문

유리 공방에 유리 막대 주문이 `n`건 들어왔습니다. `need[i]`는 `i`번 주문에 필요한 유리 막대의 총 길이(mm)입니다. 공방은 길이가 `bar`(mm)로 고정된 막대를 통째로만 사들이고, **주문마다 막대를 따로** 씁니다. 한 주문에 필요한 길이가 막대 하나보다 길면 막대 여러 개를 쓰고, 마지막 막대에서 남는 부분은 그 주문의 자투리가 됩니다 (다른 주문에 돌려쓰지 않습니다).

모든 주문을 처리할 때 **필요한 막대의 총 개수**와 **자투리의 총 길이(mm)** 를 `[막대 개수, 자투리 길이]` 순서의 `long` 배열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `need`의 길이 `n` ≤ 1,000,000
- 1 ≤ `need`의 원소 ≤ 1,000,000,000
- 1 ≤ `bar` ≤ 1,000,000,000
- 막대 개수와 자투리 길이는 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| need | bar | result |
|---|---|---|
| [250, 1000, 1001] | 500 | [6, 749] |
| [7, 7, 7] | 7 | [3, 0] |
| [1] | 1000000000 | [1, 999999999] |

## 입출력 예 설명
- 예 #1: 250mm는 막대 1개(자투리 250), 1000mm는 2개(자투리 0), 1001mm는 3개(자투리 1500 − 1001 = 499)입니다. 합쳐서 막대 6개, 자투리 749mm입니다.
- 예 #2: 주문마다 막대가 딱 맞습니다.
- 예 #3: 1mm를 위해 막대 하나를 통째로 쓰고 999,999,999mm가 남습니다.
