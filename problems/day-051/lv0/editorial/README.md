# 해설 — 유리 공방의 막대 주문

## 접근
주문 하나에 필요한 막대 수는 `need[i] / bar`를 **올림**한 값입니다. 자투리는 `막대 수 × bar − need[i]`입니다. 주문마다 이 두 값을 더하면 끝입니다.

올림 나눗셈을 자바로 쓰는 방법은 두 가지입니다.
- 정수만으로: `(need[i] + bar - 1) / bar` — 나누어떨어지지 않을 때만 몫이 1 커집니다.
- `Math.ceil`로: `(long) Math.ceil((double) need[i] / bar)` — 반드시 **나누기 전에** `double`로 바꿔야 합니다.

## 주의할 점
- `Math.ceil(need[i] / bar)`는 틀립니다. `int / int`는 이미 소수점이 버려진 정수라서 `Math.ceil`이 할 일이 없습니다. `(double) need[i] / bar`처럼 캐스팅이 먼저입니다.
- `need[i] + bar - 1`은 최대 2×10^9 − 1이라 `int`(약 2.1×10^9)를 겨우 넘지 않지만, 안전하게 `long`으로 계산하는 습관이 좋습니다.
- 막대 개수의 합은 최대 10^6 × 10^9 = 10^15이므로 누적 변수는 `long`이어야 합니다.
- `Math.ceil`의 반환형은 `double`이므로 정수 변수에 넣으려면 `(long)` 캐스팅이 필요합니다.

## 복잡도
- 시간 O(n), 공간 O(1)
