# [lv2] 수산시장 경매 중앙값

새벽 수산시장 경매에서 입찰가가 차례로 들어옵니다. `bids[i]`는 `i`번째(0번부터)로 들어온 입찰가입니다.

전광판은 입찰가가 하나 들어올 때마다 **지금까지 들어온 입찰가들의 중앙값**을 보여 줍니다. 중앙값은 지금까지의 입찰가를 오름차순으로 늘어놓았을 때 가운데 값이고, 개수가 짝수이면 가운데 두 값 중 **작은 쪽**입니다.

전광판에 표시된 값을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `bids`의 길이 `n` ≤ 1,000,000
- 1 ≤ `bids`의 원소 ≤ 1,000,000,000

## 입출력 예

| bids | result |
|---|---|
| [5, 15, 1, 3] | [5, 5, 5, 3] |
| [10, 1, 20, 2, 30] | [10, 1, 10, 2, 10] |
| [2, 2, 2] | [2, 2, 2] |

## 입출력 예 설명
- 예 #1
  - {5} → 5
  - {5, 15} → 짝수 개이므로 작은 쪽 5
  - {1, 5, 15} → 5
  - {1, 3, 5, 15} → 가운데 두 값 3, 5 중 작은 쪽 3
- 예 #2: {10} → 10, {1, 10} → 1, {1, 10, 20} → 10, {1, 2, 10, 20} → 2, {1, 2, 10, 20, 30} → 10
- 예 #3: 모두 같은 값입니다.
