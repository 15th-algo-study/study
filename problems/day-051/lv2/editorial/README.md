# 해설 — 수산시장 경매 중앙값

## 접근
지금까지의 값을 **작은 쪽 절반**과 **큰 쪽 절반**으로 나누어 힙 두 개에 둡니다.

- `low`: 작은 쪽 절반을 담는 **최대 힙** (`Collections.reverseOrder()`). 맨 위가 작은 쪽의 최댓값.
- `high`: 큰 쪽 절반을 담는 **최소 힙**. 맨 위가 큰 쪽의 최솟값.
- 불변식: `low`의 모든 값 ≤ `high`의 모든 값, 그리고 `low.size()`는 `high.size()`와 같거나 1 큽니다.

새 값 x가 오면 `low`가 비었거나 `x ≤ low.peek()`이면 `low`에, 아니면 `high`에 넣고, 크기 차이가 깨지면 한쪽 맨 위를 다른 쪽으로 옮겨 맞춥니다. 그러면 전체 개수가 홀수든 짝수든 **중앙값(짝수면 작은 쪽)은 항상 `low.peek()`** 입니다.

## 주의할 점
- 매번 정렬하면 O(n² log n), 정렬된 `ArrayList`에 이분 탐색으로 끼워 넣어도 삽입이 O(n)이라 O(n²)입니다. 100만 개에서는 시간 초과입니다.
- 크기를 맞추는 조건을 `low.size() > high.size() + 1`과 `low.size() < high.size()` 두 가지로 정확히 두어야 합니다. 한 번에 하나씩 넣으면 한 번 옮기는 것으로 충분합니다.
- `PriorityQueue<Integer>`에 `Collections.reverseOrder()`를 주면 최대 힙이 됩니다. 비교자를 빠뜨리면 두 힙 모두 최소 힙이 되어 조용히 틀립니다.

## 복잡도
- 시간 O(n log n), 공간 O(n)
