# [lv3] 사막 캐러밴의 물 보급

캐러밴이 사막 입구(0km 지점)를 떠나 `dist`km 떨어진 도시로 갑니다. 캐러밴은 1km를 갈 때마다 물을 1통 마시며, 출발할 때 물 `water`통을 가지고 있습니다. 물통을 싣는 데 한도는 없습니다.

사막에는 오아시스가 `n`곳 있습니다. `oases[i] = [pos, amount]`는 입구에서 `pos`km 지점에 있는 오아시스에서 물을 `amount`통 얻을 수 있다는 뜻입니다. 오아시스에 **멈추면** 그곳의 물을 전부 얻고, 멈추지 않고 지나칠 수도 있습니다. 물이 정확히 0이 되는 지점에 오아시스나 도시가 있으면 도착한 것으로 봅니다. 같은 지점에 오아시스가 여럿일 수도 있습니다.

도시에 도착하기 위해 **멈춰야 하는 오아시스의 최소 개수**를 return 하도록 `solution` 함수를 완성해 주세요. 어떻게 해도 도착할 수 없으면 `-1`을 return 합니다.

## 제한사항
- 1 ≤ `dist` ≤ 1,000,000,000
- 0 ≤ `water` ≤ 1,000,000,000
- 0 ≤ `oases`의 길이 `n` ≤ 300,000
- 1 ≤ `pos` ≤ `dist`, 1 ≤ `amount` ≤ 1,000,000,000
- `oases`는 정렬되어 있지 않으며, 같은 `pos`가 여러 번 나올 수 있습니다.

## 입출력 예

| dist | water | oases | result |
|---|---|---|---|
| 10 | 4 | [[3, 2], [5, 4], [8, 3]] | 2 |
| 10 | 10 | [[1, 100]] | 0 |
| 10 | 3 | [[4, 10]] | -1 |

## 입출력 예 설명
- 예 #1: 물 4통으로는 4km 지점까지만 갈 수 있으므로 3km 오아시스에 멈춥니다(물 1 + 2 = 3통, 6km까지 가능). 5km 오아시스에 멈추면 물 1 + 4 = 5통이 되어 10km 도시까지 갑니다. 두 번 멈추는 것이 최소입니다. 8km 오아시스는 들르지 않아도 됩니다.
- 예 #2: 처음 물로 바로 도착합니다.
- 예 #3: 물 3통으로는 4km 지점의 오아시스에 닿지 못합니다.
