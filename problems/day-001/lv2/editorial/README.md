# 해설 — 회전 진열대

## 접근
배열을 실제로 돌리지 않습니다. 회전해도 상품들의 **원형 순서는 그대로**이고, "지금 맨 앞에 있는 상품이 원래 몇 번째였는지(`start`)"만 바뀝니다.

- `L k`: 맨 앞이 k칸 뒤의 상품으로 바뀌므로 `start = (start + k) mod n`
- `R k`: `start = (start - k) mod n` (음수가 되지 않게 `Math.floorMod`)
- `Q i`: 현재 i번 위치 = 원래 `(start + i) mod n`번

## 주의할 점
- 명령마다 배열을 k칸 옮기면 명령 하나에 O(n)~O(nk)라 20만 × 20만에서 시간 초과입니다. `k mod n`만 옮겨도 마찬가지입니다.
- 자바의 `%`는 음수에서 음수를 돌려줍니다. `(start - k) % n`이 음수가 될 수 있으니 `Math.floorMod`를 쓰거나 `+ n`을 해 줍니다.
- `start + k`는 최대 약 10^9 + 2×10^5라 `int`로도 넘치지 않지만, 습관적으로 `long`을 쓰면 안전합니다.
- 결과 개수를 미리 모르므로 `List`에 모은 뒤 배열로 바꿉니다.

## 복잡도
- 시간 O(n + m) (m = 명령 수), 공간 O(m)
