# [lv2] 회전 진열대

원형으로 도는 진열대에 상품 `n`개가 한 줄로 놓여 있습니다. 처음 상품 순서는 배열 `items`와 같고, 맨 앞(0번 위치) 상품이 손님 앞에 보입니다. 진열대에는 다음 명령이 순서대로 내려집니다.

- `"L k"`: 왼쪽으로 `k`칸 회전합니다. 맨 앞 상품을 맨 뒤로 옮기는 동작을 `k`번 한 것과 같습니다.
- `"R k"`: 오른쪽으로 `k`칸 회전합니다. 맨 뒤 상품을 맨 앞으로 옮기는 동작을 `k`번 한 것과 같습니다.
- `"Q i"`: 현재 `i`번 위치(맨 앞이 0번)에 있는 상품 번호를 기록합니다.

명령 목록 `commands`가 주어질 때, `"Q"` 명령으로 기록한 상품 번호를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. `"Q"` 명령이 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `items`의 길이 `n` ≤ 200,000
- 1 ≤ `items`의 원소 ≤ 1,000,000,000
- 1 ≤ `commands`의 길이 ≤ 200,000
- `commands`의 원소는 `"L k"`, `"R k"`, `"Q i"` 형식입니다.
  - 0 ≤ `k` ≤ 1,000,000,000
  - 0 ≤ `i` < `n`

## 입출력 예

| items | commands | result |
|---|---|---|
| [10, 20, 30, 40, 50] | ["L 2", "Q 0", "R 1", "Q 4", "L 7", "Q 2"] | [30, 10, 10] |
| [1, 2, 3] | ["Q 1", "R 1000000000", "Q 0"] | [2, 3] |

## 입출력 예 설명
- 예 #1
  - `L 2` → [30, 40, 50, 10, 20], `Q 0` → 30
  - `R 1` → [20, 30, 40, 50, 10], `Q 4` → 10
  - `L 7` → 7칸은 5칸(한 바퀴) + 2칸이므로 [40, 50, 10, 20, 30], `Q 2` → 10
- 예 #2: 1,000,000,000칸 오른쪽 회전은 3칸짜리 진열대에서 1칸 오른쪽 회전과 같습니다. [3, 1, 2]가 되어 `Q 0` → 3
