# [lv1] 가장 긴 오르막 구간

등산로를 일정한 간격으로 측정한 높이가 배열 `heights`에 순서대로 들어 있습니다. 바로 앞 지점보다 **높이가 엄격하게 높아지는** 지점이 연속으로 이어진 구간을 "오르막 구간"이라고 합니다. 지점 하나만으로 이루어진 구간도 길이 1인 오르막 구간으로 봅니다.

가장 긴 오르막 구간의 길이(지점 수)를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `heights`의 길이 ≤ 200,000
- 1 ≤ `heights`의 원소 ≤ 1,000,000,000

## 입출력 예

| heights | result |
|---|---|
| [1, 2, 3, 2, 5, 6, 7, 1] | 4 |
| [5, 5, 5] | 1 |

## 입출력 예 설명
- 예 #1: `2, 5, 6, 7` 구간이 길이 4로 가장 깁니다. `1, 2, 3`은 길이 3입니다.
- 예 #2: 높이가 같으면 오르막이 아닙니다. 모든 구간의 길이가 1입니다.
