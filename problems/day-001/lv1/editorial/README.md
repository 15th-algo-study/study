# 해설 — 가장 긴 오르막 구간

## 접근
"i번째 지점에서 끝나는 오르막 구간의 길이" `run`을 들고 왼쪽에서 오른쪽으로 한 번 훑습니다.

- `heights[i] > heights[i-1]`이면 앞 구간이 이어지므로 `run + 1`
- 아니면 새 구간이 시작되므로 `run = 1`

매 단계의 `run` 중 최댓값이 답입니다.

## 주의할 점
- 시작점마다 오른쪽으로 늘려 보는 이중 반복은 O(n²)입니다. 높이가 계속 오르는 입력(n = 200,000)에서 약 2×10^10번 비교가 필요해 시간 초과가 납니다.
- "엄격하게" 높아져야 하므로 `>=`가 아니라 `>`입니다.
- 원소가 하나면 답은 1입니다 (`best`의 초깃값).

## 복잡도
- 시간 O(n), 공간 O(1)
