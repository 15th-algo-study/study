# [lv0] 짝수 합과 홀수 합의 차

정수 배열 `numbers`가 주어집니다. 배열에 들어 있는 **짝수의 합**에서 **홀수의 합**을 뺀 값을 return 하도록 `solution` 함수를 완성해 주세요.

0은 짝수이고, 음수도 2로 나누어떨어지면 짝수입니다.

## 제한사항
- 1 ≤ `numbers`의 길이 ≤ 100,000
- -1,000 ≤ `numbers`의 원소 ≤ 1,000

## 입출력 예

| numbers | result |
|---|---|
| [1, 2, 3, 4, 5] | -3 |
| [10, -3, 0, -8] | 5 |

## 입출력 예 설명
- 예 #1: 짝수 합 2 + 4 = 6, 홀수 합 1 + 3 + 5 = 9 → 6 - 9 = **-3**
- 예 #2: 짝수 합 10 + 0 + (-8) = 2, 홀수 합 -3 → 2 - (-3) = **5**
