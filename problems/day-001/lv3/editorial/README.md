# 해설 — 달팽이 좌석표

## 접근
n이 최대 10억이라 표를 만들 수 없습니다. 좌석 하나의 번호를 **O(1) 공식**으로 구합니다.

1. **껍질 번호** `d`: 좌석이 바깥에서 몇 번째 고리에 있는지는 네 변까지의 거리 중 최솟값입니다.
   `d = min(r-1, c-1, n-r, n-c)`
2. 그 껍질의 한 변 길이는 `m = n - 2d`이고, 바깥 껍질들이 이미 쓴 번호는 `n² - m²`개입니다.
3. 껍질 안에서는 윗변(→), 오른쪽 변(↓), 아랫변(←), 왼쪽 변(↑) 순서로 번호가 붙습니다. 각 변이 `m - 1`칸씩 차지한다고 보면 오프셋이 바로 나옵니다.
   - 윗변 `r = d+1`: `c - (d+1)`
   - 오른쪽 변 `c = n-d`: `(m-1) + (r - (d+1))`
   - 아랫변 `r = n-d`: `2(m-1) + ((n-d) - c)`
   - 왼쪽 변: `3(m-1) + ((n-d) - r)`

   모서리 칸은 위 순서대로 먼저 맞는 변에 속하게 하면 됩니다. `m = 1`(가운데 한 칸)이면 윗변 조건에 걸려 오프셋 0입니다.

## 주의할 점
- `n * n`은 최대 10^18이라 `int`로 계산하면 넘칩니다. 계산 전에 `long`으로 바꿔야 합니다 (`int` 끼리 곱한 뒤 `long`에 담으면 이미 넘친 값입니다).
- 바깥 껍질부터 한 겹씩 세며 들어가는 방법은 질의 하나에 O(n)이라 10만 개 질의 × 5억 겹에서 시간 초과입니다.
- 모서리 판정 순서가 바뀌면 모서리 좌석 번호가 틀립니다.

## 복잡도
- 시간 O(q), 공간 O(q)
