# [lv3] 달팽이 좌석표

`n × n` 크기의 공연장 좌석에 1부터 `n²`까지 번호를 매깁니다. 맨 위 왼쪽 좌석 (1, 1)에서 1로 시작해 **오른쪽 → 아래 → 왼쪽 → 위** 순서로 시계 방향 나선을 그리며 안쪽으로 들어갑니다. 다음은 `n = 4`일 때입니다.

```
 1  2  3  4
12 13 14  5
11 16 15  6
10  9  8  7
```

좌석 위치 `[r, c]`(r행 c열, 1부터 시작) 목록 `queries`가 주어질 때, 각 좌석의 번호를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 1,000,000,000
- 1 ≤ `queries`의 길이 ≤ 100,000
- `queries`의 원소는 `[r, c]` 형태이며 1 ≤ `r`, `c` ≤ `n`
- 좌석 번호는 최대 10^18이므로 `long`으로 return 합니다.

## 입출력 예

| n | queries | result |
|---|---|---|
| 4 | [[1, 1], [2, 3], [4, 1], [3, 3]] | [1, 14, 10, 15] |
| 1000000000 | [[1, 1000000000], [1000000000, 1000000000]] | [1000000000, 1999999999] |

## 입출력 예 설명
- 예 #1: 위 그림과 같습니다.
- 예 #2: 맨 위 줄은 1부터 10억까지, 오른쪽 끝 열은 10억부터 아래로 이어져 (n, n)은 2n - 1 = 1,999,999,999입니다.
