# 해설 — 곱셈표에서 k의 배수 찾기

## 접근
행 `i`와 열 `j`를 이중 반복문으로 모두 훑으면서 `(i * j) % k == 0`인 칸을 셉니다. `n ≤ 3,000`이므로 칸은 최대 900만 개이고, 곱셈·나머지 연산 한 번씩이라 1초 안에 충분합니다.

## 주의할 점
- `i * j`는 최대 9,000,000이라 `int`로 충분합니다.
- `k = 1`이면 모든 칸이 답(`n × n`)입니다. 배수 판정은 나머지가 0인지로 하면 이런 경우도 따로 처리할 필요가 없습니다.
- 반복문 범위를 0부터 시작하면 0행·0열이 끼어들어 답이 커집니다. 1부터 `n`까지입니다.

## 복잡도
- 시간 O(n²), 공간 O(1)
