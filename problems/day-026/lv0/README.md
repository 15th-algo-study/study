# [lv0] 곱셈표에서 k의 배수 찾기

교실 벽에 `n`×`n` 곱셈표 포스터가 붙어 있습니다. 포스터의 `i`행 `j`열 칸에는 `i × j`가 적혀 있습니다 (`1 ≤ i, j ≤ n`).

정수 `n`과 `k`가 주어질 때, 포스터에서 **`k`의 배수가 적힌 칸의 개수**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 3,000
- 1 ≤ `k` ≤ 1,000,000
- 같은 수가 여러 칸에 적혀 있어도 칸마다 따로 셉니다.

## 입출력 예

| n | k | result |
|---|---|---|
| 3 | 2 | 5 |
| 4 | 6 | 4 |
| 2 | 5 | 0 |

## 입출력 예 설명
- 예 #1: 곱셈표는 `[1, 2, 3] / [2, 4, 6] / [3, 6, 9]`입니다. 2의 배수는 2, 2, 4, 6, 6 다섯 칸입니다.
- 예 #2: 6의 배수가 적힌 칸은 (2, 3), (3, 2), (3, 4), (4, 3) 네 칸입니다. (3, 4) 칸과 (4, 3) 칸의 12는 따로 셉니다.
- 예 #3: 1, 2, 2, 4 중 5의 배수는 없습니다.
