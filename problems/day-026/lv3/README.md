# [lv3] 드론 쇼 k번째 비행 순서

드론 쇼에 1번부터 `n`번까지 드론 `n`대가 참가합니다. 드론은 한 대씩 차례로 이륙하며, 이륙 순서는 `n`대의 순열 하나로 표현합니다.

가능한 `n!`가지 순서를 **사전순**(앞자리부터 비교해 번호가 작은 드론이 먼저 오는 순서가 앞)으로 나열하고 1번부터 번호를 매겼습니다. 예를 들어 `n = 3`이면 다음과 같습니다.

| 번호 | 순서 |
|---|---|
| 1 | [1, 2, 3] |
| 2 | [1, 3, 2] |
| 3 | [2, 1, 3] |
| 4 | [2, 3, 1] |
| 5 | [3, 1, 2] |
| 6 | [3, 2, 1] |

연출팀이 번호 목록 `ks`를 주면, 각 번호에 해당하는 이륙 순서를 찾아 주어야 합니다. 드론 수 `n`과 번호 배열 `ks`가 주어질 때, `i`번째 행이 `ks[i]`번 순서인 2차원 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 20
- 1 ≤ `ks`의 길이 ≤ 100,000
- 1 ≤ `ks`의 원소 ≤ `n!` (`20!`은 약 2.43×10^18 이므로 `ks`는 `long[]`입니다)
- return 하는 배열의 각 행은 길이 `n`이고 1부터 `n`까지의 번호를 한 번씩 담습니다.

## 입출력 예

| n | ks | result |
|---|---|---|
| 3 | [1, 4, 6] | [[1, 2, 3], [2, 3, 1], [3, 2, 1]] |
| 4 | [9, 24] | [[2, 3, 1, 4], [4, 3, 2, 1]] |
| 1 | [1] | [[1]] |

## 입출력 예 설명
- 예 #1: 위 표에서 1번, 4번, 6번 순서입니다.
- 예 #2: `n = 4`일 때 1번 드론으로 시작하는 순서가 1~6번, 2번 드론으로 시작하는 순서가 7~12번입니다. 7번은 [2, 1, 3, 4], 8번은 [2, 1, 4, 3], 9번은 [2, 3, 1, 4]입니다. 24번은 사전순 마지막인 [4, 3, 2, 1]입니다.
- 예 #3: 드론이 한 대면 순서도 하나입니다.
