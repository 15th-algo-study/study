# 해설 — 드론 쇼 k번째 비행 순서

## 접근
순열을 사전순으로 하나씩 만들어 `k`번째까지 세는 방법은 `n = 20`일 때 `k`가 10^18 근처라 불가능합니다. 대신 **사전순 순열의 구조**를 관찰합니다.

- 첫 자리에 올 수 있는 드론은 `n`가지이고, 첫 자리가 정해지면 나머지 `n−1`대의 순서는 `(n−1)!`가지입니다. 사전순으로는 "첫 자리가 가장 작은 번호인 순열 `(n−1)!`개 → 그다음 번호인 순열 `(n−1)!`개 → …" 순으로 묶여 있습니다.
- 따라서 0부터 세는 번호 `k' = k − 1`에 대해, 첫 자리는 **남은 드론 중 `k' / (n−1)!`번째(0부터)로 작은 것**이고, 그 묶음 안에서의 위치는 `k' % (n−1)!`입니다.
- 같은 과정을 둘째 자리, 셋째 자리, … 에 대해 `(n−2)!`, `(n−3)!`, … 로 반복하면 자리마다 드론이 하나씩 결정됩니다.

남은 드론 목록을 오름차순으로 유지하며 "`idx`번째 원소를 꺼낸다"를 반복하면 됩니다. 질문마다 O(n²)이고, 질문이 10만 개여도 충분히 빠릅니다.

## 주의할 점
- 번호는 1부터 시작하므로 반드시 `k − 1`로 바꿔 시작해야 합니다. 그렇지 않으면 `k = n!`에서 범위를 벗어납니다.
- `20! ≈ 2.43×10^18`은 `long`에 들어가지만 `21!`은 넘칩니다. 팩토리얼 표는 `n`까지만 만듭니다.
- `k' / (n−1)!`의 몫은 최대 `n−1`이라 `int`로 바꿔도 안전합니다.
- "다음 순열"을 `k−1`번 반복하는 방법은 `k`가 작을 때만 통하고, 큰 `k`에서는 시간 초과입니다.

## 복잡도
- 시간 O(m · n²) (m = 질문 수, 리스트에서 원소를 빼는 비용 포함), 공간 O(n) (답 제외)
