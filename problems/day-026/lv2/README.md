# [lv2] 이어달리기 바통 전달 시간

이어달리기 팀에 선수가 `n`명 있고 0번부터 `n−1`번까지 번호가 붙어 있습니다. 경기에서는 `n`명 모두가 한 번씩 달리며, 달리는 순서는 자유롭게 정할 수 있습니다.

선수 `i`가 달린 직후 선수 `j`에게 바통을 넘기는 데 걸리는 시간은 `handoff[i][j]`입니다. 어떤 순서로 달릴 때의 **총 전달 시간**은 이웃한 두 주자 사이의 전달 시간을 모두 더한 값입니다.

코치는 전략을 세우기 위해 다음 질문을 여러 개 합니다.

- `[a, b]`: "선수 `a`가 달린 **바로 다음**에 선수 `b`가 달리는 순서" 중 총 전달 시간이 가장 짧은 것의 총 전달 시간은?

질문들은 서로 독립적입니다(앞 질문의 조건이 뒤 질문에 적용되지 않습니다). `handoff`와 질문 목록 `queries`가 주어질 때, 각 질문의 답을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 2 ≤ `n` ≤ 8
- `handoff`는 `n`×`n` 2차원 배열이고, `i ≠ j`일 때 1 ≤ `handoff[i][j]` ≤ 1,000,000 입니다.
- `handoff[i][i]`는 사용되지 않습니다(어떤 값이든 올 수 있습니다).
- `handoff[i][j]`와 `handoff[j][i]`는 다를 수 있습니다.
- 1 ≤ `queries`의 길이 ≤ 200,000
- `queries`의 각 원소는 `[a, b]` 형태이며 0 ≤ `a`, `b` < `n`, `a ≠ b` 입니다. 같은 질문이 여러 번 나올 수 있습니다.

## 입출력 예

| handoff | queries | result |
|---|---|---|
| [[0, 1, 5], [2, 0, 3], [4, 6, 0]] | [[0, 1], [1, 0], [2, 0]] | [4, 7, 5] |
| [[0, 10], [20, 0]] | [[0, 1], [1, 0]] | [10, 20] |

## 입출력 예 설명
- 예 #1: 가능한 순서와 총 전달 시간은 `0→1→2`: 1+3=4, `0→2→1`: 5+6=11, `1→0→2`: 2+5=7, `1→2→0`: 3+4=7, `2→0→1`: 4+1=5, `2→1→0`: 6+2=8 입니다.
  - `[0, 1]`: 0 바로 다음이 1인 순서는 `0→1→2`(4), `2→0→1`(5) → 4
  - `[1, 0]`: `1→0→2`(7), `2→1→0`(8) → 7
  - `[2, 0]`: `1→2→0`(7), `2→0→1`(5) → 5
- 예 #2: 두 명뿐이라 순서는 `0→1`(10)과 `1→0`(20) 둘입니다.
