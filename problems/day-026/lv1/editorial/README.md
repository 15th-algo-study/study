# 해설 — 와플 토핑 고르기

## 접근
토핑이 15종류뿐이므로 고를 수 있는 조합은 2^15 = 32,768가지입니다. 조합을 한 번만 전부 열거해 **만들 수 있는 총액**을 표시해 두고, 손님은 표를 보고 바로 답합니다.

1. `mask`를 0부터 2^n − 1까지 돌리며 비트 `i`가 켜져 있으면 `prices[i]`를 더해 그 조합의 총액을 구하고 `reachable[총액] = true`로 표시합니다.
2. `best[b]` = "b원 이하로 만들 수 있는 가장 큰 총액"을 `b`가 커지는 순서로 채웁니다. `reachable[b]`이면 `b`, 아니면 `best[b - 1]`입니다.
3. 손님마다 `best[min(예산, 전체 합)]`을 답합니다.

## 주의할 점
- 손님마다 조합을 다시 열거하면 32,768 × 15 × 200,000 ≈ 10^11번 연산이라 시간 초과입니다. 열거는 **한 번**, 손님 처리는 O(1)이어야 합니다.
- 예산이 전체 토핑 합보다 크면 표의 범위를 벗어나므로 전체 합으로 잘라서 조회합니다.
- 아무것도 고르지 않는 조합(총액 0)이 항상 있으므로 답은 0 이상입니다.

## 복잡도
- 시간 O(2^n · n + S + m) (S = 가격 합 ≤ 15,000, m = 손님 수), 공간 O(S)
