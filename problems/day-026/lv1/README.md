# [lv1] 와플 토핑 고르기

와플 가게에는 토핑이 `n`종류 있고, 토핑의 가격은 배열 `prices`에 들어 있습니다. 손님은 토핑을 **종류별로 최대 하나씩** 골라 와플에 올립니다. 아무 토핑도 고르지 않아도 됩니다(이때 토핑 값은 0원).

손님마다 토핑에 쓸 수 있는 예산이 정해져 있고, 배열 `budgets`에 손님 순서대로 들어 있습니다. 각 손님은 **예산을 넘지 않는 토핑 조합 중 가장 비싼 조합**을 고릅니다.

`prices`와 `budgets`가 주어질 때, 손님마다 고른 토핑 조합의 총액을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `prices`의 길이 `n` ≤ 15
- 1 ≤ `prices`의 원소 ≤ 1,000
- 1 ≤ `budgets`의 길이 ≤ 200,000
- 0 ≤ `budgets`의 원소 ≤ 20,000
- 손님들은 서로 영향을 주지 않습니다(토핑은 넉넉합니다).

## 입출력 예

| prices | budgets | result |
|---|---|---|
| [300, 500, 700] | [1000, 200, 1500] | [1000, 0, 1500] |
| [400, 400, 900] | [850, 1300] | [800, 1300] |

## 입출력 예 설명
- 예 #1: 만들 수 있는 조합의 총액은 0, 300, 500, 700, 800, 1000, 1200, 1500입니다. 예산 1000이면 1000(300+700), 200이면 아무것도 못 골라 0, 1500이면 전부 골라 1500입니다.
- 예 #2: 총액은 0, 400, 800, 900, 1300, 1700입니다. 예산 850이면 800(400+400), 1300이면 1300(400+900)입니다.
