# [lv2] 약초 다발 묶기

약재상이 말린 약초 다발 `n`개를 끈으로 묶어 하나의 큰 다발로 만들려 합니다. `herbs[i]`는 `i`번 다발의 무게(g)입니다.

한 번에 다발 **두 개**를 골라 하나로 묶을 수 있고, 묶은 다발의 무게는 두 무게의 합입니다. 두 다발을 묶는 데 드는 **끈의 길이**는 묶은 다발의 무게와 같습니다 (예: 3g과 5g을 묶으면 끈 8을 쓰고 8g 다발이 됩니다). 묶은 다발은 다시 다른 다발과 묶을 수 있습니다.

다발이 하나가 될 때까지 묶을 때 쓰는 **끈 길이의 합의 최솟값**을 return 하도록 `solution` 함수를 완성해 주세요. 결과는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다. 다발이 하나뿐이면 0을 return 합니다.

## 제한사항
- 1 ≤ `herbs`의 길이 `n` ≤ 200,000
- 1 ≤ `herbs`의 원소 ≤ 1,000,000,000

## 입출력 예

| herbs | result |
|---|---|
| [4, 3, 2, 6] | 29 |
| [1, 1, 1, 1] | 8 |
| [10] | 0 |

## 입출력 예 설명
- 예 #1: 2 + 3 = 5 (끈 5) → 4 + 5 = 9 (끈 9) → 6 + 9 = 15 (끈 15). 합 29. 예를 들어 6과 4를 먼저 묶으면 10 + 5 + 15 = 30으로 더 듭니다.
- 예 #2: 1 + 1 = 2, 1 + 1 = 2, 2 + 2 = 4. 합 8.
- 예 #3: 묶을 필요가 없습니다.
