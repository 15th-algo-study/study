# [lv3] 순회 공연 일정 잡기

극단이 도시 `k`곳을 도는 순회 공연을 계획합니다. 각 도시는 공연이 가능한 날짜를 몇 개씩 제안했습니다. `dates[i]`는 `i`번 도시가 제안한 날짜들의 배열입니다 (날짜는 1 이상의 정수이고, 정렬되어 있지 않으며 같은 날짜가 여러 번 나올 수 있습니다).

극단은 도시마다 제안된 날짜 중 **하나씩** 골라 공연합니다. 같은 날에 여러 도시에서 공연해도 괜찮습니다. 순회 기간은 고른 날짜 중 가장 이른 날부터 가장 늦은 날까지이며, 극단은 순회 기간의 길이(`가장 늦은 날 − 가장 이른 날`)가 **가장 짧은** 선택을 원합니다. 길이가 같은 선택이 여럿이면 **가장 이른 날이 더 빠른** 쪽을 고릅니다.

그렇게 고른 순회 기간의 `[가장 이른 날, 가장 늦은 날]`을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `dates`의 길이 `k` ≤ 100,000
- 각 `dates[i]`의 길이는 1 이상이고, 모든 `dates[i]`의 길이의 합은 200,000 이하입니다.
- 1 ≤ 날짜 ≤ 1,000,000,000

## 입출력 예

| dates | result |
|---|---|
| [[4, 10, 15], [1, 9, 20], [5, 14, 16]] | [1, 5] |
| [[1, 2, 3], [2], [2, 3]] | [2, 2] |
| [[1, 5], [3, 7]] | [1, 3] |

## 입출력 예 설명
- 예 #1: 4, 1, 5를 고르면 기간은 [1, 5]로 길이 4입니다. 9, 10, 14를 고르면 [9, 14]로 길이 5입니다. 길이 4보다 짧은 선택은 없습니다.
- 예 #2: 세 도시 모두 2일에 공연할 수 있어 길이 0입니다.
- 예 #3: [1, 3], [3, 5], [5, 7] 모두 길이 2입니다. 가장 이른 날이 빠른 [1, 3]을 고릅니다.
