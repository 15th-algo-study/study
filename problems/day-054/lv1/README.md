# [lv1] 구호품 창고 배분

재난 구호 본부가 지역 창고 `n`곳에 구호품 상자를 나누어 보냅니다. `names[i]`는 `i`번 창고의 이름, `stock[i]`는 `i`번 창고에 지금 있는 상자 수입니다. 창고 이름은 겹칠 수 있습니다.

구호품 상자 `m`개가 하나씩 도착하고, 상자가 도착할 때마다 다음 규칙으로 보낼 창고를 하나 고릅니다. 상자를 보내면 그 창고의 상자 수가 1 늘어납니다.
1. 상자 수가 **가장 적은** 창고
2. 그런 창고가 여럿이면 이름이 **사전순으로 앞서는** 창고 (`String.compareTo` 기준)
3. 이름까지 같으면 **번호(`i`)가 작은** 창고

상자를 보낸 창고의 이름을 순서대로 담은 길이 `m`의 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `names`의 길이 `n` ≤ 200,000, `stock`의 길이는 `n`과 같습니다.
- `names`의 원소는 길이 1 이상 10 이하이며 영문 소문자와 숫자로만 이루어진 문자열입니다.
- 0 ≤ `stock`의 원소 ≤ 1,000,000,000
- 1 ≤ `m` ≤ 200,000

## 입출력 예

| names | stock | m | result |
|---|---|---|---|
| ["busan", "seoul", "daegu"] | [2, 1, 2] | 4 | ["seoul", "busan", "daegu", "seoul"] |
| ["b", "a", "a"] | [0, 0, 0] | 3 | ["a", "a", "b"] |
| ["tent", "food"] | [0, 10] | 3 | ["tent", "tent", "tent"] |

## 입출력 예 설명
- 예 #1: 첫 상자는 가장 적은 `seoul`(1 → 2). 이제 셋 다 2개라 사전순으로 `busan`(→ 3), `daegu`(→ 3), 마지막은 남은 `seoul`(→ 3)입니다.
- 예 #2: 모두 0개이고 이름 `a`가 둘이므로 번호가 작은 1번 `a`, 그다음 2번 `a`, 그다음 `b`입니다.
- 예 #3: `tent`가 0 → 1 → 2 → 3이 되어도 `food`의 10보다 적습니다.
