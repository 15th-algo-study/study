# [lv0] 묘목의 키 예측

묘목장에서 묘목 `n`그루의 키를 재어 두었습니다. `heights[i]`는 `i`번 묘목의 현재 키(cm)입니다.

이 품종은 해마다 키가 `rate`% 씩 자랍니다. 즉 1년이 지나면 키가 `(1 + rate / 100)`배가 되고, `years`년이 지나면 `(1 + rate / 100)`의 `years`제곱 배가 됩니다. 다만 이 품종은 아무리 자라도 키가 `limit`cm를 넘지 않으므로, 계산한 값이 `limit`보다 크면 `limit`로 봅니다.

`years`년 뒤 각 묘목의 예상 키를 실수(`double`) 배열로 return 하도록 `solution` 함수를 완성해 주세요. 반올림은 하지 않습니다.

## 제한사항
- 1 ≤ `heights`의 길이 `n` ≤ 1,000,000
- 1 ≤ `heights`의 원소 ≤ 1,000
- 0 ≤ `rate` ≤ 100
- 0 ≤ `years` ≤ 30
- 1 ≤ `limit` ≤ 1,000,000,000
- 결과는 각 원소가 정답과 10^-6 이하로 차이 나면 정답으로 인정됩니다.

## 입출력 예

| heights | rate | years | limit | result |
|---|---|---|---|---|
| [100, 50] | 10 | 2 | 1000 | [121.0, 60.5] |
| [100] | 50 | 3 | 300 | [300.0] |
| [80] | 0 | 10 | 100 | [80.0] |

## 입출력 예 설명
- 예 #1: 1.1² = 1.21배이므로 100 → 121, 50 → 60.5입니다.
- 예 #2: 100 × 1.5³ = 337.5이지만 한계 300을 넘으므로 300입니다.
- 예 #3: 성장률이 0이면 키가 그대로입니다.
