# [lv1] 도자기 가마 예약

도예 공방이 가마 사용 예약을 받았습니다. `bookings[i] = [start, dur]`는 `i`번 예약이 `start`시각부터 `dur`시간 동안, 즉 `start` 이상 `start + dur` 미만인 시간 동안 가마 하나를 쓴다는 뜻입니다. 한 예약이 끝나는 시각에 다른 예약이 시작하면 같은 가마를 이어서 쓸 수 있습니다.

모든 예약을 기다리는 일 없이 소화하려면 가마가 최소 몇 대 필요한지 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `bookings`의 길이 ≤ 200,000
- 0 ≤ `start` ≤ 1,000,000,000
- 1 ≤ `dur` ≤ 1,000,000,000

## 입출력 예

| bookings | result |
|---|---|
| [[0, 10], [5, 10], [15, 5]] | 2 |
| [[1, 3], [4, 3], [7, 3]] | 1 |
| [[2, 5], [2, 5], [2, 5]] | 3 |

## 입출력 예 설명
- 예 #1: [0, 10)과 [5, 15)가 겹치므로 가마 2대가 필요합니다. [15, 20)은 [5, 15)가 끝난 직후라 같은 가마를 씁니다.
- 예 #2: [1, 4), [4, 7), [7, 10)은 끝과 시작이 맞물려 한 대로 충분합니다.
- 예 #3: 세 예약이 완전히 겹칩니다.
