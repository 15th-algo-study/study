# [lv2] 유적 발굴 자금

고고학 탐사대가 자금 `fund`를 가지고 발굴 시즌을 시작합니다. 후보 유적이 `n`곳 있고, `sites[i] = [req, gain]`은 `i`번 유적을 발굴하려면 그 시점의 자금이 `req` **이상**이어야 하며, 발굴을 마치면 자금이 `gain`만큼 **늘어난다**는 뜻입니다 (발굴에 자금이 소모되지는 않습니다). 각 유적은 한 번만 발굴할 수 있고, 발굴은 한 번에 한 곳씩 차례로 진행합니다.

이번 시즌에 발굴할 수 있는 유적은 최대 `k`곳입니다. 시즌이 끝났을 때 자금이 최대가 되도록 발굴 순서와 대상을 고를 때, 그 **최대 자금**을 return 하도록 `solution` 함수를 완성해 주세요. 결과는 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 0 ≤ `fund` ≤ 1,000,000,000
- 1 ≤ `sites`의 길이 `n` ≤ 200,000
- 1 ≤ `k` ≤ `n`
- 0 ≤ `req` ≤ 1,000,000,000, 0 ≤ `gain` ≤ 1,000,000,000

## 입출력 예

| fund | k | sites | result |
|---|---|---|---|
| 1 | 2 | [[0, 2], [1, 5], [2, 4]] | 10 |
| 5 | 1 | [[5, 0], [3, 3], [6, 100]] | 8 |
| 0 | 3 | [[1, 10], [1, 20]] | 0 |

## 입출력 예 설명
- 예 #1: 자금 1로 발굴할 수 있는 곳은 0번(+2)과 1번(+5)입니다. 1번을 먼저 발굴해 자금 6이 되면 2번(+4)도 가능해져 10이 됩니다. 0번을 먼저 하면 3 → 2번 → 7이 최선이라 더 적습니다.
- 예 #2: 한 곳만 발굴할 수 있고, 자금 5로 가능한 곳 중 가장 많이 버는 1번(+3)을 고릅니다. 2번은 자금이 모자랍니다.
- 예 #3: 자금 0으로는 어디도 발굴할 수 없습니다.
