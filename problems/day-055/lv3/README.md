# [lv3] 박람회 부스 설치

박람회 개막을 앞두고 설치팀 하나가 부스 설치 작업을 맡았습니다. 작업 `n`개가 있고 `jobs[i] = [dur, deadline]`은 `i`번 작업이 `dur`시간 걸리며, 시각 `deadline`까지는 **끝나 있어야**(끝나는 시각 ≤ `deadline`) 한다는 뜻입니다.

설치팀은 시각 0부터 일을 시작하고, 한 번에 작업 하나만 할 수 있으며, 시작한 작업은 중단 없이 끝까지 합니다. 작업 사이에 쉬는 시간은 두지 않아도 됩니다. 마감을 지킬 수 없는 작업은 아예 하지 않습니다(마감을 어기며 할 수는 없습니다).

마감을 지키며 완료할 수 있는 작업 수의 **최댓값**을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `jobs`의 길이 `n` ≤ 300,000
- 1 ≤ `dur` ≤ 1,000,000,000
- 1 ≤ `deadline` ≤ 1,000,000,000

## 입출력 예

| jobs | result |
|---|---|
| [[3, 5], [2, 6], [4, 7], [1, 3]] | 3 |
| [[6, 6], [2, 7], [2, 8]] | 2 |
| [[2, 2], [2, 2], [2, 2]] | 1 |

## 입출력 예 설명
- 예 #1: 3번(1시간, 마감 3) → 0번(3시간, 마감 5) → 1번(2시간, 마감 6) 순서로 하면 각각 1, 4, 6에 끝나 모두 마감 안입니다. 네 작업을 다 하려면 10시간이 필요해 마감 7을 넘기므로 불가능합니다.
- 예 #2: 0번을 하면 6에 끝나고, 그 뒤 1번은 8 > 7이라 못 하고 2번만 가능해 2개입니다. 0번을 포기하고 1번(2에 끝남) → 2번(4에 끝남)을 하면 역시 2개입니다. 세 개를 모두 하려면 10시간이라 불가능합니다.
- 예 #3: 어떤 작업이든 하나만 하면 2에 끝나 마감 안이지만, 둘째 작업은 4에 끝나 마감을 넘깁니다.
