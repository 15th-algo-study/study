# 해설 — 냉동 창고 온도 표시판

## 접근
기록 하나의 표시값은 `(int) Math.round(readings[i] / 10.0)`입니다. 이 값을 구하면서 최댓값·최솟값(`Math.max`, `Math.min`)과 `limit`보다 큰 횟수를 셉니다.

## 주의할 점
- `readings[i] / 10`은 정수 나눗셈이라 **0 쪽으로 잘립니다**. `-179 / 10`은 `-17`이고, 반올림한 -18과 다릅니다. 반드시 `10.0`으로 나눠 실수를 만든 뒤 `Math.round`에 넣으세요.
- `Math.round(double)`의 반환형은 **`long`** 입니다. `int` 배열에 넣으려면 `(int)` 캐스팅이 필요합니다 (`Math.round(float)`만 `int`를 돌려줍니다).
- `Math.round`는 "가장 가까운 정수, 0.5는 더 큰 쪽"입니다. 음수에서 `Math.round(-18.5)`는 -18, `Math.round(-0.5)`는 0입니다. 절댓값 기준 반올림(-19, -1)이 아닙니다. 이 규칙은 `Math.floor(x + 0.5)`와 같은 결과입니다.
- `(int) (x + 0.5)`로 반올림하면 음수에서 틀립니다. `(int)` 캐스팅은 0 쪽으로 자르므로 `(int) (-17.9 + 0.5) = (int) (-17.4) = -17`이 됩니다.
- 최댓값·최솟값의 초깃값은 첫 표시값으로 두거나 `Integer.MIN_VALUE`/`Integer.MAX_VALUE`로 둡니다. 0으로 두면 모두 음수인 입력에서 틀립니다.

## 복잡도
- 시간 O(n), 공간 O(1)
