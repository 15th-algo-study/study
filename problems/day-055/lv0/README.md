# [lv0] 냉동 창고 온도 표시판

냉동 창고의 온도 센서는 온도를 **0.1도 단위의 정수**로 기록합니다. `readings[i]`는 `i`번째 기록으로, 예를 들어 `-185`는 -18.5도, `37`은 3.7도를 뜻합니다.

창고 문 앞의 표시판은 소수점이 없어서, 각 기록을 `Math.round`로 **정수 도(℃)로 반올림**해 보여 줍니다. 자바의 `Math.round`는 0.5로 끝나는 값을 **더 큰 쪽**(양의 무한대 방향)으로 올립니다. 예를 들어 -18.5는 -18로, -20.5는 -20으로, 0.5는 1로, -0.5는 0으로 표시됩니다.

표시판에 나타난 값들 중 **최댓값**, **최솟값**, 그리고 표시된 값이 기준 온도 `limit`(정수 도)를 **초과한 기록의 수**를 `[최댓값, 최솟값, 초과 횟수]` 순서로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `readings`의 길이 ≤ 1,000,000
- -1,000,000 ≤ `readings`의 원소 ≤ 1,000,000
- -100,000 ≤ `limit` ≤ 100,000

## 입출력 예

| readings | limit | result |
|---|---|---|
| [-185, -179, -174, -205] | -18 | [-17, -20, 1] |
| [5, -5, 15, -15] | 0 | [2, -1, 2] |
| [-200] | -25 | [-20, -20, 1] |

## 입출력 예 설명
- 예 #1: 표시값은 차례로 -18, -18, -17, -20입니다. 최댓값 -17, 최솟값 -20이고, -18을 초과한 것은 -17 하나입니다.
- 예 #2: 0.5 → 1, -0.5 → 0, 1.5 → 2, -1.5 → -1. 0을 초과한 것은 1과 2입니다.
- 예 #3: -20.0 → -20이고 -25보다 큽니다.
