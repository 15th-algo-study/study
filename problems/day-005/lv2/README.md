# [lv2] 가장 붐비는 시간

24시간 운영하는 공유 회의실의 예약 기록이 문자열 배열 `meetings`로 주어집니다. 각 원소는 `"HH:MM:SS D"` 형식으로, `HH:MM:SS`에 시작해 `D`초 동안 회의실을 쓴다는 뜻입니다.

- 하루는 `00:00:00`부터 `23:59:59`까지 86,400초입니다.
- 회의는 시작 초부터 `D`개의 초를 차지합니다. 예를 들어 `"09:00:00 3600"`은 `09:00:00`부터 `09:59:59`까지입니다.
- 자정을 넘기는 회의는 다음 날 `00:00:00`부터 이어집니다. 모든 회의를 **하루 단위 시계 위에 겹쳐서** 봅니다. 예를 들어 `"23:00:00 7200"`은 `23:00:00`~`23:59:59`와 `00:00:00`~`00:59:59`를 차지합니다.

하루의 각 초마다 그 초를 차지한 회의 수를 셉니다. **동시에 진행되는 회의 수의 최댓값**과, **그 최댓값이 나타나는 초의 개수**를 `[최댓값, 초의 개수]`로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `meetings`의 길이 ≤ 200,000
- `HH`는 `00`~`23`, `MM`과 `SS`는 `00`~`59`인 두 자리 수입니다.
- 1 ≤ `D` ≤ 86,400

## 입출력 예

| meetings | result |
|---|---|
| ["09:00:00 3600", "09:30:00 3600", "10:00:00 1800"] | [2, 3600] |
| ["23:00:00 7200", "00:30:00 1800"] | [2, 1800] |
| ["12:00:00 86400"] | [1, 86400] |

## 입출력 예 설명
- 예 #1: 09:30:00~09:59:59에는 첫째·둘째 회의가, 10:00:00~10:29:59에는 둘째·셋째 회의가 겹칩니다. 최대 2개가 1800 + 1800 = 3600초 동안 나타납니다.
- 예 #2: 첫 회의가 자정을 넘겨 00:59:59까지 이어지므로 00:30:00~00:59:59 1800초 동안 2개가 겹칩니다.
- 예 #3: 하루 전체를 차지하는 회의 하나입니다.
