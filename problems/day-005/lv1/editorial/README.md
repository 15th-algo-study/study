# 해설 — 비밀번호 규칙 검사

## 접근
비밀번호 하나를 검사하는 `isValid`를 따로 만들고, 문자를 한 번 훑으며 네 가지 종류의 등장 여부를 표시합니다.

- 길이 검사는 맨 처음에.
- 문자마다 종류를 판별하고, 어디에도 속하지 않으면 즉시 `false`.
- 현재 문자가 바로 앞 두 문자와 같으면 3연속이므로 `false`.
- 끝까지 통과하면 네 종류가 모두 나왔는지 확인합니다.

## 주의할 점
- `Character.isLetter`, `Character.isDigit`는 유니코드 전체(한글, 전각 숫자 등)를 허용하므로 범위 비교(`'A' <= ch && ch <= 'Z'`)가 이 문제에 정확합니다.
- 정규식으로도 풀 수 있지만(`(.)\1\1` 등), 비밀번호마다 패턴을 새로 컴파일하면 느립니다. 쓰려면 `Pattern`을 한 번만 컴파일해 재사용하세요.
- "2번 연속은 괜찮음"을 놓쳐 2연속에서 거절하는 실수가 흔합니다.

## 복잡도
- 시간 O(전체 글자 수), 공간 O(1)
