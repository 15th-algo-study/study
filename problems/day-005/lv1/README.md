# [lv1] 비밀번호 규칙 검사

회원 가입 페이지의 비밀번호 규칙은 다음과 같습니다.

1. 길이는 8자 이상 20자 이하
2. 영문 대문자, 영문 소문자, 숫자, 특수문자를 **각각 한 개 이상** 포함
3. 특수문자는 `!@#$%^&*` 여덟 가지만 허용하며, 위 네 종류 외의 문자는 사용할 수 없음
4. 같은 문자가 **3번 이상 연속**으로 나오면 안 됨 (2번 연속은 괜찮음)

비밀번호 후보 배열 `passwords`가 주어질 때, 규칙을 모두 만족하는 비밀번호의 개수를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `passwords`의 길이 ≤ 100,000
- 1 ≤ `passwords[i]`의 길이 ≤ 30
- `passwords[i]`는 아스키 코드 33(`!`)~126(`~`) 사이의 문자로 이루어져 있습니다.

## 입출력 예

| passwords | result |
|---|---|
| ["Abcdef1!", "abcdef1!", "Abc1!", "Aaaa1!xyz", "Abcdefg1!?"] | 1 |
| ["Zz9#Zz9#", "P@ssw0rdP@ssw0rdP@ssw0rd"] | 1 |

## 입출력 예 설명
- 예 #1
  - `"Abcdef1!"`: 모든 규칙을 만족합니다.
  - `"abcdef1!"`: 대문자가 없습니다.
  - `"Abc1!"`: 8자보다 짧습니다.
  - `"Aaaa1!xyz"`: `a`가 3번 연속됩니다.
  - `"Abcdefg1!?"`: `?`는 허용되지 않는 문자입니다.
- 예 #2: 두 번째 비밀번호는 24자로 너무 깁니다.
