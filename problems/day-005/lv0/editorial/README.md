# 해설 — 가장 많이 나온 알파벳

## 접근
알파벳은 26개뿐이므로 크기 26인 배열로 셉니다. `ch - 'a'`가 0~25 인덱스입니다. 다 센 뒤 a부터 z까지 보며 **더 클 때만** 최댓값을 바꾸면, 동률일 때 자연스럽게 앞선 알파벳이 남습니다.

## 주의할 점
- `>=`로 비교하면 동률에서 뒤 알파벳이 답이 됩니다.
- 알파벳마다 문자열 전체를 다시 세면 26배 느려집니다(그래도 통과는 하지만 한 번에 세는 습관을 들이세요).
- 인덱스를 다시 문자로 바꿀 때 `(char) ('a' + best)`처럼 형 변환이 필요합니다.

## 복잡도
- 시간 O(n), 공간 O(1)
