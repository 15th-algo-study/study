# [lv0] 가장 많이 나온 알파벳

영문 소문자로 이루어진 문자열 `s`에서 가장 많이 등장한 알파벳을 길이 1인 문자열로 return 하도록 `solution` 함수를 완성해 주세요. 가장 많이 등장한 알파벳이 여러 개면 알파벳 순서로 가장 앞선 것을 return 합니다.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 1,000,000
- `s`는 영문 소문자로만 이루어져 있습니다.

## 입출력 예

| s | result |
|---|---|
| "banana" | "a" |
| "abcabc" | "a" |
| "zzyy" | "y" |

## 입출력 예 설명
- 예 #1: `a` 3번, `n` 2번, `b` 1번입니다.
- 예 #2: `a`, `b`, `c` 모두 2번이므로 알파벳 순서로 가장 앞선 `a`입니다.
- 예 #3: `y`와 `z`가 2번씩이므로 `y`입니다.
