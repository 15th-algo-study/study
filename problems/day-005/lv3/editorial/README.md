# 해설 — 괄호 수식 계산기

## 접근: 두 개의 스택 (Shunting-yard 변형)
값 스택과 연산자 스택을 두고 왼쪽부터 한 번 훑습니다.

- **숫자**: 끝까지 읽어 값 스택에 넣습니다.
- **`(`**: 연산자 스택에 넣습니다.
- **`)`**: `(`가 나올 때까지 연산자를 꺼내 계산하고, `(`를 버립니다.
- **연산자 `op`**: 스택 맨 위 연산자의 우선순위가 `op`보다 **크거나 같으면** 먼저 계산합니다(같을 때도 계산해야 왼쪽부터 계산됨). 그다음 `op`를 넣습니다.
- 끝나면 남은 연산자를 모두 계산합니다.

계산할 때는 값 두 개(`b`가 위, `a`가 아래)를 꺼내 `a op b`를 넣습니다.

## 나머지 연산
덧셈·뺄셈·곱셈은 나머지를 취한 뒤 계산해도 결과의 나머지가 같습니다. 모든 값을 `[0, MOD)`로 유지하면
- 곱셈 `a * b`는 최대 약 10^18이라 `long`에 들어가고,
- 뺄셈은 `(a - b + MOD) % MOD`로 음수를 피합니다.

## 주의할 점
- **깊은 중첩**: 괄호가 10만 겹이면 재귀 하강 파서는 호출이 수십만 단계 쌓여 `StackOverflowError`가 날 수 있습니다. 명시적 스택이 안전합니다.
- **반복 치환은 느립니다**: 가장 안쪽 괄호를 찾아 계산 결과로 바꾸는 것을 반복하면 매번 문자열을 새로 만들어 O(n²)입니다.
- `10 - 2 - 3`은 5입니다. 같은 우선순위에서 오른쪽부터 계산하면 11이 나옵니다.
- 수 하나가 최대 10^9이라 읽을 때 `long`으로 누적하세요.

## 복잡도
- 시간 O(n), 공간 O(n)
