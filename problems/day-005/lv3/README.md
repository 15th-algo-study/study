# [lv3] 괄호 수식 계산기

음이 아닌 정수, 연산자 `+`, `-`, `*`, 괄호 `(`, `)`로 이루어진 수식 문자열 `expression`이 주어집니다. 수식의 값을 1,000,000,007로 나눈 나머지를 return 하도록 `solution` 함수를 완성해 주세요. 값이 음수면 0 이상 1,000,000,006 이하가 되도록 1,000,000,007을 더한 나머지를 return 합니다.

계산 규칙은 일반적인 산수와 같습니다.
- 괄호 안을 먼저 계산합니다.
- `*`는 `+`, `-`보다 먼저 계산합니다.
- 우선순위가 같으면 왼쪽부터 계산합니다.

## 제한사항
- 1 ≤ `expression`의 길이 ≤ 200,000
- `expression`은 숫자, `+`, `-`, `*`, `(`, `)`로만 이루어진 올바른 수식입니다.
  - 공백은 없습니다.
  - 각 수는 0 이상 1,000,000,000 이하이고, `0` 자체가 아니면 0으로 시작하지 않습니다.
  - 단항 연산자(예: `-3`, `+(1)`)는 없습니다. 모든 연산자는 두 피연산자 사이에 있습니다.
  - 괄호는 최대 100,000겹까지 중첩될 수 있습니다.

## 입출력 예

| expression | result |
|---|---|
| "1+2*3" | 7 |
| "(1+2)*3-10" | 1000000006 |
| "1000000000*1000000000" | 49 |

## 입출력 예 설명
- 예 #1: 곱셈이 먼저입니다. 1 + 6 = 7
- 예 #2: 3 × 3 - 10 = -1이고, -1을 1,000,000,007로 나눈 나머지는 1,000,000,006입니다.
- 예 #3: 10^18을 1,000,000,007로 나눈 나머지는 49입니다.
