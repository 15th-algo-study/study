# [lv2] 문서 구조 검사기

간단한 마크업 문서의 구조가 올바른지 검사하려고 합니다. 문서는 **태그**와 **글자**로 이루어집니다.

- 여는 태그 `<name>`, 닫는 태그 `</name>`, 혼자 완결되는 태그 `<name/>` 세 종류가 있습니다. `name`은 영문 소문자 1자 이상입니다.
- 태그가 아닌 영문 소문자는 그냥 글자(본문)입니다.
- 여는 태그와 닫는 태그는 이름이 같은 것끼리 짝을 이루며, 괄호처럼 **가장 최근에 열린 태그부터** 닫혀야 합니다.
- `<name/>`은 열자마자 닫히는 태그라서 짝이 필요 없습니다.

문서가 **올바르다**는 것은 모든 닫는 태그가 가장 최근에 열린(아직 닫히지 않은) 태그와 이름이 같고, 문서가 끝났을 때 열린 채 남은 태그가 없다는 뜻입니다.

올바른 문서에서 각 태그의 **깊이**는 그 태그를 감싸고 있는 열린 태그의 수에 1을 더한 값입니다. 예를 들어 `<a><b/></a>`에서 `a`의 깊이는 1, `b`의 깊이는 2입니다.

문서 `doc`가 주어질 때, 문서가 올바르면 태그 깊이의 최댓값을, 올바르지 않으면 -1을 return 하도록 `solution` 함수를 완성해 주세요. 태그가 하나도 없는 문서는 올바르며 0을 return 합니다.

## 제한사항
- 1 ≤ `doc`의 길이 ≤ 1,000,000
- `doc`는 영문 소문자, `<`, `>`, `/`로만 이루어져 있습니다.
- 모든 `<`는 `<name>`, `</name>`, `<name/>` 중 하나의 형태로 올바르게 닫혀 있고, 태그 밖에 `>`나 `/`가 나오는 일은 없습니다. 즉 **태그 하나하나의 모양은 항상 올바르고**, 태그들의 짝과 순서만 틀릴 수 있습니다.
- 태그 이름의 길이는 1 이상 10 이하입니다.

## 입출력 예

| doc | result |
|---|---|
| "<a>hello<b/>world</a>" | 2 |
| "<a><b></a></b>" | -1 |
| "x<p/>y" | 1 |

## 입출력 예 설명
- 예 #1: `a`가 깊이 1, 그 안의 `b/`가 깊이 2입니다. `a`는 끝에서 올바르게 닫힙니다.
- 예 #2: `</a>`가 나왔을 때 가장 최근에 열린 태그는 `b`이므로 올바르지 않습니다.
- 예 #3: 태그는 `p/` 하나뿐이고 깊이는 1입니다.
