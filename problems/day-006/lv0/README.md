# [lv0] 알파벳 번호의 합

알파벳에 순서대로 번호를 매깁니다. `a`와 `A`는 1, `b`와 `B`는 2, …, `z`와 `Z`는 26입니다. 대소문자는 구분하지 않습니다.

영문 대소문자와 공백으로 이루어진 문자열 `s`가 주어질 때, `s`에 들어 있는 모든 알파벳의 번호를 더한 값을 return 하도록 `solution` 함수를 완성해 주세요. 공백은 더하지 않습니다.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 1,000,000
- `s`는 영문 대문자, 영문 소문자, 공백(`' '`)으로만 이루어져 있습니다.
- 공백만으로 이루어진 문자열이 주어질 수도 있습니다. 이때는 0을 return 합니다.

## 입출력 예

| s | result |
|---|---|
| "abc" | 6 |
| "Hi there" | 73 |
| "zZ" | 52 |

## 입출력 예 설명
- 예 #1: 1 + 2 + 3 = 6
- 예 #2: `H`=8, `i`=9, `t`=20, `h`=8, `e`=5, `r`=18, `e`=5 이므로 8 + 9 + 20 + 8 + 5 + 18 + 5 = 73 입니다. 공백은 더하지 않습니다.
- 예 #3: `z`와 `Z`는 모두 26이므로 52 입니다.
