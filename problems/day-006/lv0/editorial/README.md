# 해설 — 알파벳 번호의 합

## 접근
문자열을 한 글자씩 보며 알파벳이면 번호를 더합니다. 자바의 `char`는 정수처럼 계산할 수 있으므로 소문자는 `ch - 'a' + 1`, 대문자는 `ch - 'A' + 1`이 번호입니다. `Character.toLowerCase(ch)`로 먼저 소문자로 바꾸면 식이 하나로 줄어듭니다.

## 주의할 점
- 공백은 알파벳이 아니므로 건너뜁니다. `Character.isLetter(ch)`로 거르면 됩니다.
- `ch - 'a'`는 0부터 시작하므로 **+1**을 잊지 마세요.
- 최댓값은 1,000,000 × 26 = 26,000,000이라 `int`로 충분합니다.

## 복잡도
- 시간 O(n), 공간 O(1)
