# [lv3] 펜 플로터의 반복 무늬

펜 플로터가 종이 위에서 명령 문자열 `program`을 실행합니다. 펜은 좌표 (0, 0)에서 **위쪽(y가 커지는 방향)** 을 바라보며 시작합니다. 명령은 다음 세 가지이며, 문자열에는 구분자 없이 이어져 있습니다.

- `F<n>`: 바라보는 방향으로 `n`칸 전진합니다.
- `L<n>`: 제자리에서 왼쪽으로 90°씩 `n`번 돕니다.
- `R<n>`: 제자리에서 오른쪽으로 90°씩 `n`번 돕니다.

예를 들어 `"F10R1F5"`는 위로 10칸, 오른쪽으로 돌아 5칸 전진하라는 뜻입니다.

같은 무늬를 반복하려고 `program` 전체를 **처음부터 끝까지 `k`번 연달아** 실행합니다. 두 번째 실행은 첫 번째 실행이 끝난 위치와 방향에서 이어집니다.

`program`과 `k`가 주어질 때, 모든 실행이 끝난 뒤 펜의 좌표를 `[x, y]` 형태의 `long` 배열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 2 ≤ `program`의 길이 ≤ 200,000
- `program`은 `F`, `L`, `R` 뒤에 1 이상 100 이하의 정수가 붙은 명령들이 이어진 올바른 문자열입니다. 정수는 0으로 시작하지 않습니다.
- 1 ≤ `k` ≤ 100,000,000,000 (10^11)
- 좌표의 절댓값은 `long` 범위 안이지만 `int` 범위를 넘을 수 있습니다.
- 오른쪽은 x가 커지는 방향, 위쪽은 y가 커지는 방향입니다.

## 입출력 예

| program | k | result |
|---|---|---|
| "F10R1F5" | 1 | [5, 10] |
| "F2R1" | 5 | [0, 2] |
| "F1L1F1" | 2 | [-2, 0] |

## 입출력 예 설명
- 예 #1: 위로 10칸 → (0, 10). 오른쪽으로 돌아 5칸 → (5, 10).
- 예 #2: 한 번 실행할 때마다 2칸 전진하고 오른쪽으로 돕니다. 실행이 끝날 때마다 위치는 (0, 2) → (2, 2) → (2, 0) → (0, 0) → (0, 2)가 됩니다. 4번 실행하면 제자리로 돌아오고, 5번째 실행 뒤에는 (0, 2)입니다.
- 예 #3: 첫 실행: 위로 1칸 (0, 1), 왼쪽으로 돌아(서쪽) 1칸 (-1, 1). 두 번째 실행은 서쪽을 바라본 채 시작합니다: 1칸 (-2, 1), 왼쪽으로 돌아(남쪽) 1칸 (-2, 0).
