# 해설 — 천 단위 쉼표 찍기

## 접근
쉼표는 오른쪽부터 세 자리마다 들어가므로, **왼쪽에서부터 훑어도 위치를 미리 알 수 있습니다.** 숫자 부분의 길이를 `len`이라 하면, 숫자 부분의 `i`번째 글자(0부터) 앞에 쉼표가 오는 조건은

- `i > 0` 이고 `(len - i) % 3 == 0`

입니다. 즉 "뒤에 남은 자릿수"가 3의 배수인 곳마다 쉼표를 찍습니다. 부호가 있으면 먼저 붙이고 숫자 부분만 이 규칙으로 처리합니다. 결과는 `StringBuilder`에 앞에서부터 순서대로 붙입니다.

## 주의할 점
- 오른쪽부터 세 자리씩 잘라 `sb.insert(0, ...)`로 앞에 끼워 넣거나, `result = chunk + "," + result`처럼 문자열을 앞에 이어 붙이면 매번 지금까지의 결과 전체를 복사합니다. 길이 50만이면 복사량이 수백억 글자가 되어 시간 초과입니다. 뒤에서부터 만들고 싶다면 `StringBuilder`에 `append`한 뒤 마지막에 `reverse()`를 한 번만 하세요.
- 음수 부호는 자릿수에 넣지 않습니다. `"-1000"`에서 숫자 부분은 `1000`(4자리)입니다.
- `Integer.parseInt`나 `Long.parseLong`은 50만 자리 수에 쓸 수 없습니다. 문자열 그대로 다룹니다.

## 복잡도
- 시간 O(n), 공간 O(n)
