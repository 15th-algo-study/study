# [lv1] 천 단위 쉼표 찍기

영수증에 금액을 읽기 쉽게 표시하려고 합니다. 금액은 세 자리마다 오른쪽부터 쉼표(`,`)를 찍어 씁니다. 예를 들어 `1234567`은 `1,234,567`로, `-1000`은 `-1,000`으로 씁니다.

정수를 나타내는 문자열 `amount`가 주어질 때, 세 자리마다 쉼표를 찍은 문자열을 return 하도록 `solution` 함수를 완성해 주세요.

- 쉼표는 **숫자 부분**에만 찍습니다. 음수 부호 `-`는 그대로 맨 앞에 둡니다.
- 자릿수가 3 이하이면 쉼표를 찍지 않습니다.

## 제한사항
- 1 ≤ `amount`의 길이 ≤ 500,000
- `amount`는 선택적인 음수 부호 `-` 뒤에 숫자가 한 자리 이상 이어진 형태입니다.
- 숫자 부분은 `0` 자체가 아니면 0으로 시작하지 않습니다. `-0`은 주어지지 않습니다.

## 입출력 예

| amount | result |
|---|---|
| "1234567" | "1,234,567" |
| "-1000" | "-1,000" |
| "999" | "999" |

## 입출력 예 설명
- 예 #1: 오른쪽부터 세 자리씩 끊으면 `1` / `234` / `567` 입니다.
- 예 #2: 부호는 그대로 두고 숫자 부분 `1000`에만 쉼표를 찍습니다.
- 예 #3: 세 자리이므로 쉼표가 없습니다.
