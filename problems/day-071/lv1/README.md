# [lv1] 약수터 물통 채우기

마을 약수터에는 크기가 서로 다른 바가지들이 걸려 있습니다. 배열 `scoops`의 각 원소는 바가지 하나로 한 번에 뜰 수 있는 물의 양(L)입니다.

물통에 물을 **정확히** `target`L 채우려고 합니다. 규칙은 다음과 같습니다.

- 한 번 물을 부을 때는 바가지 하나를 골라 **가득** 떠서 물통에 붓습니다. 바가지 크기만큼 정확히 들어갑니다.
- 같은 바가지를 몇 번이든 다시 쓸 수 있습니다.
- 물통에 든 물을 덜어 낼 수는 없습니다. 즉 부은 양의 합이 정확히 `target`이어야 합니다.

물을 붓는 **최소 횟수**를 return 하도록 `solution` 함수를 완성해 주세요. 어떻게 해도 정확히 `target`L를 만들 수 없으면 -1을 return 합니다.

## 제한사항
- 1 ≤ `scoops`의 길이 ≤ 100
- 1 ≤ `scoops`의 원소 ≤ 10,000
- `scoops`에는 같은 크기가 여러 번 들어 있을 수 있습니다.
- 1 ≤ `target` ≤ 100,000

## 입출력 예

| scoops | target | result |
|---|---|---|
| [1, 3, 4] | 6 | 2 |
| [5, 7] | 24 | 4 |
| [6, 9, 20] | 43 | -1 |

## 입출력 예 설명
- 예 #1: 3L 바가지로 두 번 부으면 6L입니다. 가장 큰 4L부터 부으면 4 + 1 + 1로 세 번이 걸리므로, 큰 바가지부터 쓰는 방법이 항상 최선은 아닙니다.
- 예 #2: 5 + 5 + 7 + 7 = 24로 네 번입니다. 5L만으로는 24L를 만들 수 없고, 7L를 한 번이나 세 번 쓰면 남는 양(17L, 3L)을 5L로 채울 수 없습니다.
- 예 #3: 6과 9로는 3의 배수만 만들 수 있습니다. 20L를 0번, 1번, 2번 써도 남는 43L, 23L, 3L 중 6과 9로 만들 수 있는 양이 없으므로 -1입니다.
