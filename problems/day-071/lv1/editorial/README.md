# 해설 — 약수터 물통 채우기

## 접근
"크기 `s`인 바가지를 무한히 쓸 수 있다"는 조건은 **무한 배낭**(동전 거스름돈) 형태입니다. 물의 양을 기준으로 표를 채웁니다.

- `best[x]` = 정확히 `x`L를 만드는 최소 붓는 횟수 (만들 수 없으면 무한대)
- `best[0] = 0`
- `best[x] = min(best[x - s] + 1)` (모든 바가지 크기 `s ≤ x`에 대해)

`x`를 1부터 `target`까지 작은 순서로 채우면, `best[x - s]`는 이미 계산된 값입니다. 마지막에 `best[target]`이 무한대면 -1을 return 합니다.

**왜 맞을까?** 정확히 `x`L를 만드는 어떤 방법이든 마지막에 부은 바가지 `s`가 있고, 그 앞까지는 `x - s`L를 만든 방법입니다. 그러니 "마지막 바가지"를 모두 시도해 보면 최솟값을 놓치지 않습니다.

## 주의할 점
- **큰 바가지부터 최대한 쓰는 그리디는 틀립니다.** 예 #1에서 4 + 1 + 1(3번)보다 3 + 3(2번)이 낫습니다.
- 모든 경우를 재귀로 시도하면 경우의 수가 지수적으로 늘어 `target = 100,000`에서 끝나지 않습니다. 같은 양 `x`에 대한 답을 표에 한 번만 계산해 두는 것이 핵심입니다.
- 무한대 값으로 `Integer.MAX_VALUE`를 쓰면 `+ 1`에서 넘칩니다. `target + 1`처럼 답이 될 수 없는 큰 값을 쓰면 안전합니다(바가지 크기가 1 이상이라 답은 `target` 이하).
- 같은 크기의 바가지가 여러 번 나와도 결과는 같습니다.

## 복잡도
- 시간 O(`target` × `scoops.length`), 공간 O(`target`)
