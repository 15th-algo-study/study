# [lv0] 자전거길 쉼터 거리표

강을 따라 곧게 뻗은 자전거길에 쉼터가 `n`곳 있습니다. 배열 `positions`의 `i`번째 값은 자전거길 출발점에서 `i`번 쉼터까지의 거리(km)입니다.

안내판에 붙일 **쉼터 사이 거리표**를 만들려고 합니다. 거리표는 `n`행 `n`열의 2차원 배열이며, `i`행 `j`열에는 `i`번 쉼터와 `j`번 쉼터 사이의 거리를 적습니다.

- 두 쉼터 사이의 거리는 두 위치의 차의 절댓값입니다.
- 같은 쉼터끼리(`i`행 `i`열)의 거리는 0입니다.
- `positions`는 정렬되어 있지 않을 수 있고, 같은 위치에 쉼터가 둘 이상 있을 수도 있습니다.

`positions`가 주어질 때 거리표를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `positions`의 길이 `n` ≤ 1,000
- 0 ≤ `positions`의 원소 ≤ 1,000,000

## 입출력 예

| positions | result |
|---|---|
| [0, 3, 10] | [[0, 3, 10], [3, 0, 7], [10, 7, 0]] |
| [4, 1, 4, 9] | [[0, 3, 0, 5], [3, 0, 3, 8], [0, 3, 0, 5], [5, 8, 5, 0]] |
| [7] | [[0]] |

## 입출력 예 설명
- 예 #1: 0번과 2번 쉼터는 |0 − 10| = 10km, 1번과 2번 쉼터는 |3 − 10| = 7km 떨어져 있습니다.
- 예 #2: 0번과 2번 쉼터는 같은 위치(4km)에 있어 거리가 0입니다. 위치가 정렬되어 있지 않아도 절댓값을 쓰면 됩니다.
- 예 #3: 쉼터가 하나뿐이면 1행 1열짜리 표 `[[0]]`입니다.
