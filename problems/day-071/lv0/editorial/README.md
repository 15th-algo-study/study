# 해설 — 자전거길 쉼터 거리표

## 접근
`n × n` 크기의 2차원 배열을 만들고 이중 반복문으로 칸을 채웁니다.

```java
int[][] table = new int[n][n];
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        table[i][j] = Math.abs(positions[i] - positions[j]);
```

`new int[n][n]`은 모든 칸이 0으로 채워진 배열을 만들어 줍니다. 바깥 반복문의 `i`가 행, 안쪽 반복문의 `j`가 열입니다.

## 주의할 점
- 위치가 정렬되어 있지 않으므로 `positions[i] - positions[j]`가 음수일 수 있습니다. `Math.abs`로 절댓값을 취하세요.
- 거리표는 대각선을 기준으로 대칭(`table[i][j] == table[j][i]`)입니다. `j > i`인 칸만 계산하고 반대쪽에 복사해도 되지만, 이 크기에서는 그냥 모두 계산해도 충분히 빠릅니다.
- 위치가 최대 1,000,000이라 차도 `int` 범위 안입니다.

## 복잡도
- 시간 O(n²), 공간 O(n²) (결과 배열)
