# 해설 — 자막 교정 비용

## 접근
**편집 거리**를 작업별 비용으로 일반화한 문제입니다. 두 문자열의 앞부분끼리 비교하는 2차원 표를 채웁니다.

- `cost[i][j]` = `draft`의 앞 `i`글자를 `target`의 앞 `j`글자로 바꾸는 최소 비용
- `cost[0][j] = j × ins` (빈 문자열에 `j`글자 삽입), `cost[i][0] = i × del` (`i`글자 모두 삭제)
- 나머지 칸은 `draft`의 `i`번째 글자 `a`와 `target`의 `j`번째 글자 `b`를 마지막으로 어떻게 처리했는지로 나눕니다.
  - `a`를 삭제: `cost[i-1][j] + del`
  - `b`를 삽입: `cost[i][j-1] + ins`
  - `a`를 `b`에 맞춤: `cost[i-1][j-1] + (a == b ? 0 : rep)`
  - 셋 중 최솟값

답은 `cost[n][m]`입니다. 각 칸은 위·왼쪽·왼쪽 위 칸만 보므로 행 순서대로 채우면 됩니다.

## 주의할 점
- 교체가 항상 이득은 아닙니다. `rep > ins + del`이면 "삭제 + 삽입"이 더 싸고, 위 점화식은 이 경우를 자동으로 고려합니다(예 #2).
- 모든 작업 순서를 재귀로 시도하면 지수 시간입니다. 같은 `(i, j)`를 여러 번 계산하지 않도록 표에 저장하는 것이 핵심입니다.
- 최대 비용은 약 (3,000 + 3,000) × 1,000 = 6×10^6 이라 `int`로 충분합니다.
- 표 전체(3001 × 3001)를 써도 되지만, 바로 윗행만 필요하므로 1차원 배열 두 개로 줄일 수 있습니다.

## 복잡도
- 시간 O(n × m), 공간 O(m) (두 줄만 유지)
