# [lv3] 꼬치 복원

재료 `n`개에 1번부터 `n`번까지 번호가 붙어 있습니다. 요리사는 재료를 **번호 순서대로** 꼬치에 꽂는데, 각 재료는 그때까지 꽂힌 재료들의 **왼쪽 끝 또는 오른쪽 끝**에만 꽂을 수 있습니다. 1번 재료는 빈 꼬치에 꽂으며, 이때는 "왼쪽"으로 기록하기로 합니다.

완성된 꼬치를 왼쪽부터 읽은 번호 배열 `skewer`가 주어질 때, 각 재료를 어느 쪽에 꽂았는지를 1번부터 `n`번 순서대로 `'L'`(왼쪽) 또는 `'R'`(오른쪽)로 이어 붙인 길이 `n`의 문자열을 return 하도록 `solution` 함수를 완성해 주세요. 그런 방법으로는 만들 수 없는 꼬치이면 빈 문자열 `""`을 return 합니다. 만들 수 있다면 방법은 유일합니다.

## 제한사항
- 1 ≤ `skewer`의 길이 `n` ≤ 1,000,000
- `skewer`는 1부터 `n`까지의 수가 한 번씩 나오는 순열입니다.

## 입출력 예

| skewer | result |
|---|---|
| [4, 2, 1, 3, 5] | "LLRLR" |
| [1, 2, 3] | "LRR" |
| [2, 3, 1] | "" |

## 입출력 예 설명
- 예 #1: [1] → 2를 왼쪽에 [2, 1] → 3을 오른쪽에 [2, 1, 3] → 4를 왼쪽에 [4, 2, 1, 3] → 5를 오른쪽에 [4, 2, 1, 3, 5].
- 예 #2: 1을 꽂고 2, 3을 모두 오른쪽에 꽂았습니다.
- 예 #3: 1 다음에 2를 꽂으면 2는 1의 바로 옆이어야 하는데, 2와 1 사이에 3이 있으므로 만들 수 없습니다.
