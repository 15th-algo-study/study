# [lv2] 징검다리 놓기

개울에 징검다리 돌을 놓고 있습니다. 돌은 서쪽 끝이나 동쪽 끝에만 놓거나 치울 수 있으며, 작업 명령이 2차원 배열 `commands`로 주어집니다. 각 원소는 `[종류, 값]` 꼴입니다.

- `[1, v]`: 번호 `v`인 돌을 **서쪽 끝**에 놓습니다.
- `[2, v]`: 번호 `v`인 돌을 **동쪽 끝**에 놓습니다.
- `[3, i]`: 서쪽에서 `i`번째(1부터 셈) 돌의 번호를 기록합니다. 돌이 `i`개보다 적으면 `-1`을 기록합니다.
- `[4, x]`: 서쪽 끝 돌을 치웁니다. 돌이 없으면 아무 일도 일어나지 않습니다.
- `[5, x]`: 동쪽 끝 돌을 치웁니다. 돌이 없으면 아무 일도 일어나지 않습니다.

종류 4, 5의 `x`는 쓰지 않는 값이며 무시합니다.

종류 3 명령마다 기록한 값을 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 종류 3 명령이 없으면 빈 배열을 return 합니다.

## 제한사항
- 1 ≤ `commands`의 길이 ≤ 1,000,000
- 종류는 1~5 중 하나입니다.
- 1 ≤ `v` ≤ 1,000,000,000 (번호는 중복될 수 있습니다)
- 1 ≤ `i` ≤ 1,000,000
- 종류 4, 5의 `x`는 0 이상 1,000,000,000 이하의 아무 값입니다.

## 입출력 예

| commands | result |
|---|---|
| [[2, 10], [1, 20], [2, 30], [3, 1], [3, 3], [4, 0], [3, 1], [5, 0], [3, 2]] | [20, 30, 10, -1] |
| [[3, 1], [4, 0], [1, 7], [3, 1], [5, 0], [3, 1]] | [-1, 7, -1] |
| [[1, 1], [1, 2], [1, 3], [3, 2]] | [2] |

## 입출력 예 설명
- 예 #1: [10] → [20, 10] → [20, 10, 30]. 1번째는 20, 3번째는 30. 서쪽 끝을 치워 [10, 30], 1번째는 10. 동쪽 끝을 치워 [10], 2번째는 없으므로 -1.
- 예 #2: 빈 상태의 질의는 -1, 빈 상태에서 치우기는 무시됩니다. 7을 놓고 질의하면 7, 동쪽 끝을 치우면 다시 비어 -1.
- 예 #3: 서쪽에 1, 2, 3을 차례로 놓으면 [3, 2, 1]이고 2번째는 2입니다.
