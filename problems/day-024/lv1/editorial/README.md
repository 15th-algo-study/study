# 해설 — 종이컵 세 자리

## 접근
세 자리를 각각 **스택**으로 두고 지문 그대로 시뮬레이션합니다. `ArrayDeque<Integer>` 세 개를 배열에 담아 두면 `piles[from]`, `piles[to]`처럼 인덱스로 고를 수 있습니다.

```
for [from, to, k] in moves:
    k번 반복:
        piles[from] 이 비어 있으면 중단
        piles[to].push(piles[from].pop())
```

한 개씩 `pop`→`push` 하므로 순서가 뒤집히는 것이 자연스럽게 처리됩니다. `from == to`이면 꺼낸 것을 같은 자리에 도로 올리므로 저절로 변화가 없습니다.

끝나면 각 스택을 **아래부터** 읽어 배열로 만듭니다. `push`/`pop`은 덱의 앞쪽을 맨 위로 쓰므로 `descendingIterator()`로 뒤집어 읽거나, 처음부터 `addLast`/`pollLast`를 써서 뒤쪽을 맨 위로 삼으면 자연 순서 순회가 아래→위입니다.

## 주의할 점
- `k`가 남은 컵 수보다 클 때 빈 스택에서 `pop()`을 호출하면 예외가 납니다. 반복마다 `isEmpty()`를 확인하세요.
- 한 이동에 최대 100개, 이동 10만 번이므로 전체 10^7 번의 `pop`/`push`로 충분합니다. 묶어서 옮기려고 `subList` 등을 쓰면 오히려 순서 뒤집기를 빠뜨리기 쉽습니다.
- 반환형이 `int[][]`이므로 빈 자리는 길이 0인 `int[]`를 넣어야 합니다(`null`이 아닙니다).

## 복잡도
- 시간 O(n + Σk) (최대 약 10^7), 공간 O(n)
