# [lv1] 종이컵 세 자리

탁자 위에 종이컵을 쌓는 자리가 0번, 1번, 2번 세 곳 있습니다. 처음에는 0번 자리에만 컵이 쌓여 있고, 아래부터 위 순서로 컵 번호가 배열 `cups`에 담겨 있습니다. 1번, 2번 자리는 비어 있습니다.

이동 명령이 2차원 배열 `moves`로 주어집니다. 각 원소 `[from, to, k]`는 `from` 자리의 **맨 위부터 컵 `k`개를 한 개씩** 집어 `to` 자리 **맨 위**에 올리라는 뜻입니다.

- 한 개씩 옮기므로 옮겨진 컵들은 순서가 뒤집혀 쌓입니다.
- `from` 자리에 컵이 `k`개보다 적으면 있는 컵만 모두 옮깁니다. 컵이 없으면 아무 일도 일어나지 않습니다.
- `from`과 `to`가 같으면 집었다가 같은 자리에 올려놓는 것이므로 아무 변화가 없습니다.

모든 이동을 마친 뒤 세 자리의 상태를 2차원 배열로 return 하도록 `solution` 함수를 완성해 주세요. `result[j]`는 `j`번 자리의 컵 번호를 **아래부터 위 순서로** 담은 배열이며, 빈 자리는 빈 배열입니다.

## 제한사항
- 1 ≤ `cups`의 길이 ≤ 100,000
- 1 ≤ `cups[i]` ≤ 1,000,000,000 (번호는 중복될 수 있습니다)
- 1 ≤ `moves`의 길이 ≤ 100,000
- `from`, `to`는 0, 1, 2 중 하나이고, 1 ≤ `k` ≤ 100입니다.

## 입출력 예

| cups | moves | result |
|---|---|---|
| [1, 2, 3, 4] | [[0, 1, 2], [1, 2, 1], [0, 2, 5]] | [[], [4], [3, 2, 1]] |
| [5] | [[0, 1, 1], [1, 0, 1]] | [[5], [], []] |
| [1, 2, 3] | [[0, 2, 3], [2, 0, 3]] | [[1, 2, 3], [], []] |

## 입출력 예 설명
- 예 #1: 0번에서 4, 3을 차례로 집어 1번에 올리면 1번은 [4, 3]. 1번 맨 위 3을 2번으로 옮기면 2번은 [3]. 0번의 2, 1을 차례로(5개를 요청했지만 2개뿐) 2번에 올리면 2번은 [3, 2, 1].
- 예 #2: 5를 1번으로 보냈다가 다시 0번으로 가져옵니다.
- 예 #3: 세 개를 한 개씩 옮기면 [3, 2, 1]로 뒤집히고, 다시 한 개씩 옮기면 원래 순서 [1, 2, 3]으로 돌아옵니다.
