# [lv0] 양쪽으로 늘어놓는 상자

가게 뒷마당에 빈 상자를 한 줄로 늘어놓습니다. 상자는 배열 `boxes`의 순서대로 하나씩 도착하며, 각 상자에는 번호가 적혀 있습니다.

- 번호가 **홀수**인 상자는 줄의 **왼쪽 끝**에 놓습니다.
- 번호가 **짝수**인 상자는 줄의 **오른쪽 끝**에 놓습니다.

모든 상자를 놓은 뒤 줄을 왼쪽부터 읽은 번호 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `boxes`의 길이 ≤ 500,000
- 1 ≤ `boxes[i]` ≤ 1,000,000,000
- 번호는 중복될 수 있습니다.

## 입출력 예

| boxes | result |
|---|---|
| [1, 2, 3, 4, 5] | [5, 3, 1, 2, 4] |
| [2, 4, 6] | [2, 4, 6] |
| [7, 7, 1] | [1, 7, 7] |

## 입출력 예 설명
- 예 #1: [1] → [1, 2] → [3, 1, 2] → [3, 1, 2, 4] → [5, 3, 1, 2, 4]
- 예 #2: 모두 짝수라 오른쪽으로만 붙어 도착 순서 그대로입니다.
- 예 #3: 모두 홀수라 왼쪽으로만 붙어 도착 순서의 반대가 됩니다.
