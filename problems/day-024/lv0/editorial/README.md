# 해설 — 양쪽으로 늘어놓는 상자

## 접근
양쪽 끝에 붙이는 자료구조가 **덱**(`ArrayDeque`)입니다.

- 홀수: `deque.addFirst(v)`
- 짝수: `deque.addLast(v)`

끝나면 덱을 앞에서부터 순회하면 그대로 왼쪽→오른쪽 순서입니다.

## 주의할 점
- `ArrayList.add(0, v)`로 앞에 넣으면 뒤 원소를 전부 밀어야 해서 O(n)이고, 홀수 50만 개면 10^11 번 가까이 되어 시간 초과입니다. 덱은 양쪽 모두 O(1)입니다.
- 홀짝 판별은 `v % 2 == 1`로 충분합니다(번호가 양수이므로 음수 나머지 걱정이 없습니다).
- 덱 없이 풀려면 홀수의 개수를 먼저 세어 배열의 중간 지점을 정한 뒤 왼쪽·오른쪽으로 채울 수도 있습니다. 두 방법 모두 O(n)입니다.

## 복잡도
- 시간 O(n), 공간 O(n)
