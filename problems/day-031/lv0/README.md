# [lv0] 한 자리가 될 때까지

동호회에서 회원마다 행운 번호를 하나씩 정해 주기로 했습니다. 회원 번호의 **각 자릿수를 모두 더하고**, 그 결과가 두 자리 이상이면 **다시 자릿수를 더하는** 일을 한 자리 수가 될 때까지 반복합니다. 마지막에 남은 한 자리 수가 그 회원의 행운 번호입니다.

예를 들어 회원 번호 9875는 9 + 8 + 7 + 5 = 29 → 2 + 9 = 11 → 1 + 1 = 2 이므로 행운 번호는 2입니다. 처음부터 한 자리 수이면 그 수가 그대로 행운 번호입니다.

회원 번호 배열 `numbers`가 주어질 때, 각 회원의 행운 번호를 같은 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `numbers`의 길이 ≤ 100,000
- 0 ≤ `numbers`의 원소 ≤ 1,000,000,000,000,000,000 (10^18, `long`)
- 회원 번호가 0이면 행운 번호도 0입니다.

## 입출력 예

| numbers | result |
|---|---|
| [9875, 1, 0] | [2, 1, 0] |
| [999999999999999999, 1000000000000000000] | [9, 1] |

## 입출력 예 설명
- 예 #1: 9875 → 29 → 11 → 2. 1과 0은 이미 한 자리이므로 그대로입니다.
- 예 #2: 9가 18개인 수의 자릿수 합은 162이고, 162 → 9입니다. 10^18의 자릿수 합은 1입니다.
