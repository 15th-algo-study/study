# 해설 — 한 자리가 될 때까지

## 접근
"자릿수를 더한 결과에 **같은 일을 또 한다**"는 말이 그대로 재귀입니다.

- `lucky(n)`: `n`이 한 자리(10 미만)이면 `n`을 돌려주고, 아니면 `lucky(자릿수 합(n))`을 돌려줍니다.
- 자릿수 합은 `n % 10`을 더하고 `n /= 10`을 반복하면 됩니다.

10^18은 19자리라 자릿수 합이 최대 171이고, 171의 자릿수 합은 9 이하입니다. 즉 재귀는 많아야 3번 내려가므로 깊이를 걱정할 필요가 없습니다.

## 주의할 점
- 입력이 `long`이므로 `n % 10`, `n / 10`도 `long`으로 계산합니다. `int`로 받으면 컴파일 오류 또는 잘림이 납니다.
- 0은 "한 자리 수"이므로 그대로 0입니다. `while (n > 0)`으로 자릿수 합을 구하면 0의 합은 0이 되어 자연스럽게 맞습니다.
- (참고) 답은 `n == 0 ? 0 : 1 + (n - 1) % 9`로도 구할 수 있지만, 이 문제는 재귀 연습이 목적입니다.

## 복잡도
- 시간 O(n × 자릿수) — 수 하나당 많아야 약 20번의 나눗셈
- 공간 O(n) (결과 배열)
