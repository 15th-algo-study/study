# 해설 — 팀별 급여 총액

## 접근
팀 총액의 정의 자체가 재귀적입니다.

> `team(i)` = `salary[i]` + `team(2i + 1)` + `team(2i + 2)` (없는 부하는 0)

`team(i)`를 재귀 함수로 쓰고, 계산한 값을 `answer[i]`에 저장하면서 돌려주면 한 번의 호출 `team(0)`으로 모든 답이 채워집니다. 사원마다 함수가 정확히 한 번씩 호출되므로 O(n)입니다.

완전 이진 트리의 높이는 약 log₂(200,000) ≈ 18이라 재귀 깊이는 18 정도입니다. 스택 오버플로를 걱정할 필요가 없습니다.

## 주의할 점
- 총액은 최대 2×10^5 × 10^9 = 2×10^14 라 `int`를 넘칩니다. 더하는 변수와 배열 모두 `long`이어야 합니다.
- 부하 번호가 `n - 1`을 넘는지 반드시 확인합니다 (`2i + 1 < n`). 확인하지 않으면 `ArrayIndexOutOfBoundsException`이 납니다.
- 재귀 없이도 풀립니다. 자식 번호가 항상 부모보다 크므로 `i = n - 1`부터 0까지 거꾸로 돌면서 `answer[i] = salary[i] + answer[2i+1] + answer[2i+2]`를 채우면 됩니다. 두 방법 모두 알아 두세요.
- 사원마다 "내 팀에 누가 있나"를 따로 탐색하면 O(n log n)으로 통과는 하지만, 한 번의 재귀로 모두 채우는 쪽이 간단합니다.

## 복잡도
- 시간 O(n), 공간 O(n) (결과 배열) + 재귀 깊이 O(log n)
