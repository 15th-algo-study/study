# [lv1] 팀별 급여 총액

어느 회사의 조직도는 **완전 이진 트리** 모양입니다. 사원은 0번부터 `n - 1`번까지 번호가 있고, 0번이 대표입니다. `i`번 사원의 직속 부하는 `2i + 1`번과 `2i + 2`번입니다 (그 번호가 `n - 1` 이하일 때만 존재합니다).

`i`번 사원의 **팀**은 자기 자신과, 직속 부하, 직속 부하의 부하, … 이렇게 아래로 이어지는 모든 사원입니다. 사원별 월급이 배열 `salary`로 주어질 때, 각 사원의 팀 급여 총액(팀에 속한 모든 사원의 월급 합)을 사원 번호 순서로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `salary`의 길이 `n` ≤ 200,000
- 0 ≤ `salary`의 원소 ≤ 1,000,000,000
- 팀 급여 총액은 `int` 범위를 넘을 수 있으므로 `long[]`로 return 합니다.

## 입출력 예

| salary | result |
|---|---|
| [100, 50, 30, 20, 10] | [210, 80, 30, 20, 10] |
| [1, 2, 3, 4, 5, 6, 7] | [28, 11, 16, 4, 5, 6, 7] |
| [1000000000, 1000000000, 1000000000] | [3000000000, 1000000000, 1000000000] |

## 입출력 예 설명
- 예 #1: 1번의 부하는 3번과 4번이므로 1번 팀의 총액은 50 + 20 + 10 = 80입니다. 2번의 부하 5번, 6번은 없으므로 2번 팀은 2번 혼자입니다. 0번 팀은 전체이므로 100 + 80 + 30 = 210입니다.
- 예 #2: 1번 팀 = {1, 3, 4} → 11, 2번 팀 = {2, 5, 6} → 16, 0번 팀 = 1 + 11 + 16 = 28입니다.
- 예 #3: 0번 팀의 총액 3,000,000,000은 `int` 범위를 넘습니다.
