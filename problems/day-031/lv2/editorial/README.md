# 해설 — 접은 종이의 주름

## 접근
주름 열 `S(n)`은 지문에 적힌 대로 재귀적으로 정의됩니다.

> `S(n)` = `S(n-1)` + `V` + `mirror(S(n-1))`  (`mirror` = 순서를 뒤집고 V↔A 교환)

길이가 2^n − 1이라 `n = 60`이면 문자열을 만들 수 없습니다. 대신 **"p번 주름이 어느 부분에 속하는지"만 따라 내려갑니다.** `mid = 2^(n-1)`이라 하면

- `p == mid`: 가운데 주름이므로 `V`
- `p < mid`: 왼쪽 절반은 `S(n-1)` 그대로이므로 `crease(n-1, p)`
- `p > mid`: 오른쪽 절반은 `S(n-1)`의 거울상입니다. 오른쪽에서 `p - mid`번째는 `S(n-1)`에서 뒤에서 `p - mid`번째, 즉 앞에서 `mid - (p - mid) = 2^n - p`번째와 짝이고 방향이 반대입니다. 따라서 `flip(crease(n-1, 2^n - p))`

한 질문에 재귀가 최대 `n`번 내려가므로 질문당 O(n)입니다.

## 주의할 점
- 2^60은 `int`를 넘으므로 `mid`는 `1L << (n - 1)`처럼 `long`으로 계산합니다. `1 << 60`은 `int` 시프트라 잘못된 값이 됩니다.
- 문자열을 실제로 만들면 `n = 25`쯤부터 메모리·시간이 터집니다. 재귀 정의를 "값을 만드는 것"이 아니라 "위치를 추적하는 것"으로 바꾸는 것이 핵심입니다.
- 결과는 `StringBuilder`에 모읍니다. 20만 번 `+=` 하면 O(m²)입니다.
- 재귀 깊이는 `n ≤ 60`이라 안전합니다. 반복문으로 바꾸려면 `flip` 횟수의 홀짝만 기억하면서 내려가면 됩니다.
- (참고) `p = 2^k × (홀수)`로 쓸 때 그 홀수가 4로 나눈 나머지 1이면 `V`, 3이면 `A`라는 닫힌 꼴도 있습니다. 재귀를 손으로 풀어 보면 같은 결론이 나옵니다.

## 복잡도
- 시간 O(m × n) (m = 질문 수), 공간 O(m) (결과) + 재귀 깊이 O(n)
