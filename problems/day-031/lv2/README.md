# [lv2] 접은 종이의 주름

긴 종이 띠를 책상 위에 왼쪽에서 오른쪽으로 길게 놓고, **오른쪽 끝을 들어 올려 왼쪽 끝 위에 포개는** 방식으로 반을 접습니다. 접힌 종이를 그대로 두고 같은 방향으로 또 반을 접는 일을 모두 `n`번 반복한 뒤, 종이를 완전히 펼쳐 책상 위에 놓습니다.

펼친 종이에는 주름이 2^n − 1개 생기고, 각 주름은 아래로 패인 **골**(`V`)이거나 위로 솟은 **산**(`A`)입니다. 주름에 왼쪽부터 1번, 2번, …, (2^n − 1)번까지 번호를 붙입니다.

- 1번 접은 뒤 펼치면 가운데에 골 하나가 생깁니다: `V`
- 2번 접은 뒤 펼치면 주름은 왼쪽부터 `V`, `V`, `A`입니다.
- 3번 접은 뒤 펼치면 `V`, `V`, `A`, `V`, `V`, `A`, `A`입니다.

일반적으로 `n`번 접은 종이의 주름 열은 "`n − 1`번 접은 주름 열" + `V` + "`n − 1`번 접은 주름 열을 **거꾸로 뒤집고 골과 산을 서로 바꾼 것**"입니다.

접는 횟수 `n`과 질문할 주름 번호 배열 `positions`가 주어질 때, 각 번호의 주름이 골이면 `V`, 산이면 `A`를 질문 순서대로 이어 붙인 문자열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 60
- 1 ≤ `positions`의 길이 ≤ 200,000
- 1 ≤ `positions`의 원소 ≤ 2^n − 1 (`long`)

## 입출력 예

| n | positions | result |
|---|---|---|
| 2 | [1, 2, 3] | "VVA" |
| 3 | [4, 7, 1] | "VAV" |
| 1 | [1] | "V" |

## 입출력 예 설명
- 예 #1: 2번 접은 주름 열 `VVA`를 순서대로 물었습니다.
- 예 #2: 3번 접은 주름 열은 `VVAVVAA`입니다. 4번은 `V`, 7번은 `A`, 1번은 `V`입니다.
- 예 #3: 한 번 접으면 가운데 골 하나뿐입니다.
