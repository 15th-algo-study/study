# [lv3] 왕국 나누기

일렬로 늘어선 `n`칸의 땅이 있고, `i`번 칸의 높이는 `heights[i]`입니다. 옛 왕국은 이 땅을 다음 규칙으로 다스렸습니다.

1. 다스릴 구간 `[l, r]`에서 **가장 높은 칸**(여러 개면 **가장 왼쪽**)에 성을 세웁니다. 성을 세우는 비용은 `(r − l + 1) × (그 칸의 높이)`입니다.
2. 성이 세워진 칸을 기준으로 왼쪽 구간 `[l, 성 − 1]`과 오른쪽 구간 `[성 + 1, r]`은 각각 독립된 작은 왕국이 되어 **같은 규칙**을 따릅니다. 빈 구간에는 비용이 들지 않습니다.

처음 왕국은 땅 전체 `[0, n − 1]`입니다. 땅의 높이 배열 `heights`가 주어질 때, 세워지는 모든 성의 비용 합을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `heights`의 길이 `n` ≤ 300,000
- 1 ≤ `heights`의 원소 ≤ 100,000,000
- 비용 합은 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다. (9×10^18을 넘지 않습니다.)

## 입출력 예

| heights | result |
|---|---|
| [3, 1, 4, 1, 5] | 49 |
| [2, 2, 2] | 12 |
| [5, 1] | 11 |

## 입출력 예 설명
- 예 #1
  - `[0, 4]`: 가장 높은 칸은 4번(높이 5). 비용 5 × 5 = 25. 왼쪽 `[0, 3]`, 오른쪽은 빈 구간.
  - `[0, 3]`: 가장 높은 칸은 2번(높이 4). 비용 4 × 4 = 16. 왼쪽 `[0, 1]`, 오른쪽 `[3, 3]`.
  - `[0, 1]`: 0번(높이 3). 비용 2 × 3 = 6. 오른쪽 `[1, 1]`.
  - `[1, 1]`, `[3, 3]`: 각각 1 × 1 = 1.
  - 합계 25 + 16 + 6 + 1 + 1 = 49
- 예 #2: 높이가 모두 같으므로 항상 가장 왼쪽 칸에 성을 세웁니다. 3 × 2 + 2 × 2 + 1 × 2 = 12
- 예 #3: 2 × 5 + 1 × 1 = 11
