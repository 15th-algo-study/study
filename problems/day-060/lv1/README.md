# [lv1] 비상 연락망

회사 직원 `n`명에게 0번부터 `n-1`번까지 번호를 붙였습니다. 비상시 서로에게 연락하기로 한 직원 쌍의 목록이 2차원 배열 `contacts`로 주어집니다. `contacts[i] = [a, b]`는 `a`번과 `b`번이 서로 연락한다는 뜻이며, 연락은 양방향입니다.

`start`번 직원이 비상 상황을 알게 되면 즉시 연락망에 따라 연락이 퍼집니다. 연락을 받은 직원은 곧바로 자기와 연락하기로 한 모든 직원에게 연락합니다. `start`에서 출발해 **연락을 `k`번 이하 거쳐** 닿을 수 있는 직원의 수(`start` 본인 포함)를 return 하도록 `solution` 함수를 완성해 주세요. 어떤 직원에게 닿는 가장 적은 연락 횟수가 `k`를 넘으면 그 직원은 세지 않습니다.

## 제한사항
- 1 ≤ `n` ≤ 200,000
- 0 ≤ `contacts`의 길이 ≤ 600,000
- 0 ≤ `a`, `b`, `start` < `n`
- 0 ≤ `k` ≤ 200,000
- 같은 쌍이 여러 번 나오거나 `a = b`인 쌍이 있을 수 있습니다.

## 입출력 예

| n | contacts | start | k | result |
|---|---|---|---|---|
| 7 | [[0, 1], [0, 2], [1, 3], [3, 4], [2, 5]] | 0 | 2 | 5 |
| 4 | [[0, 1], [1, 2], [2, 3]] | 3 | 1 | 2 |
| 3 | [[0, 1]] | 0 | 10 | 2 |

## 입출력 예 설명
- 예 #1: 0번(0번 거침) → 1, 2번(1번) → 3, 5번(2번). 4번은 3번 거쳐야 하고 6번은 연락망에 없어 닿지 않습니다. 모두 5명입니다.
- 예 #2: 3번과 바로 연락하는 2번까지 2명입니다.
- 예 #3: `k`가 커도 2번에게는 닿을 수 없습니다.
