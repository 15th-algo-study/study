# 해설 — 비상 연락망

## 접근
"연락을 몇 번 거쳐 닿는가"는 `start`로부터의 **최단 거리**입니다. BFS 로 거리를 구하면서 거리가 `k`인 정점에서는 더 퍼뜨리지 않으면, 큐에 들어간 정점의 수가 답입니다.

1. 인접 리스트를 만듭니다 (양방향).
2. `dist[start] = 0`으로 두고 BFS 를 시작합니다. 정점 `v`를 꺼냈을 때 `dist[v] == k`이면 이웃을 보지 않고 넘어갑니다.
3. 이웃 `u`가 아직 방문 전이면 `dist[u] = dist[v] + 1`로 적고 큐에 넣습니다.
4. 큐에 넣은 정점의 총수를 return 합니다.

BFS 는 거리 순서로 정점을 발견하므로, 거리 `k`에서 멈추면 거리 `k + 1` 이상인 정점은 큐에 들어가지 않습니다.

## 주의할 점
- `k = 0`이면 `start` 한 명뿐입니다. "꺼냈을 때 거리가 `k`이면 멈춤" 규칙이 이 경우도 자연스럽게 처리합니다.
- `k`가 매우 커도 BFS 는 각 정점을 한 번만 방문하므로 시간은 O(n + m)입니다. `k`번 반복하는 구조로 만들면 `k = 200,000`일 때 느립니다.
- 중복 쌍과 `a = b`는 방문 표시 덕분에 영향이 없습니다.
- 재귀 DFS 로 "k 단계 안에 닿는 정점"을 세면 같은 정점에 더 짧은 경로로 다시 도착했을 때 다시 탐색해야 해 지수 시간이 될 수 있습니다. BFS 를 쓰세요.

## 복잡도
- 시간 O(n + m), 공간 O(n + m)
