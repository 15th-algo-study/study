# 해설 — 위성 사진의 숲 구역

## 접근
격자의 **연결 요소** 문제입니다. 방향만 8개로 늘어났을 뿐 방법은 같습니다.

1. 방향 배열을 8개 준비합니다: `dr = {-1,-1,-1,0,0,1,1,1}`, `dc = {-1,0,1,-1,1,-1,0,1}`.
2. 모든 칸을 순회하다가 **아직 방문하지 않은 숲 칸**을 만나면 새 구역입니다. 그 칸에서 BFS 를 시작해 8방향으로 이어진 숲 칸을 모두 방문하며 칸 수를 셉니다.
3. 구역 수를 1 늘리고 최대 칸 수를 갱신합니다.

각 칸은 한 번만 큐에 들어가므로 전체 시간은 칸 수에 비례합니다.

## 주의할 점
- **재귀 flood fill 은 스택이 넘칩니다.** large 에는 2,000 × 1,500 = 300만 칸이 전부 숲인 사진이 있습니다. 재귀는 한 줄기로 300만 깊이까지 파고들어 StackOverflowError 가 납니다. `int[]` 배열 큐를 쓰는 반복문 BFS 로 작성하세요.
- 방문 표시는 큐에 **넣을 때** 합니다. 8방향이라 꺼낼 때 표시하면 같은 칸이 최대 8번 큐에 들어가 메모리와 시간이 크게 늘어납니다.
- 방문 표시용 `boolean[]`을 쓰는 대신 `char[][]`로 복사한 뒤 방문한 `F`를 `.`로 바꿔도 됩니다. 원본 `String[]`은 바꿀 수 없으므로 복사가 필요합니다.
- 좌표를 `r * cols + c` 한 정수로 묶으면 객체 생성 없이 빠릅니다.

## 복잡도
- 시간 O(rows × cols), 공간 O(rows × cols)
