# [lv2] 위성 사진의 숲 구역

위성 사진을 격자로 나누어 문자열 배열 `photo`에 적었습니다. `photo[r]`의 `c`번째 문자가 (r, c) 칸이며, `F`는 숲, `.`은 숲이 아닌 땅입니다.

숲 칸 두 개가 **상하좌우 또는 대각선**(8방향)으로 붙어 있으면 같은 숲 구역에 속합니다. 이렇게 이어진 숲 칸의 묶음 하나를 **숲 구역**이라고 합니다.

숲 구역의 **개수**와 **가장 큰 숲 구역의 칸 수**를 `[개수, 칸 수]` 배열로 return 하도록 `solution` 함수를 완성해 주세요. 숲 칸이 하나도 없으면 `[0, 0]`을 return 합니다.

## 제한사항
- 1 ≤ `photo`의 길이 ≤ 2,000
- 1 ≤ 각 `photo[r]`의 길이 ≤ 1,500
- 모든 줄의 길이는 같습니다.
- `photo`는 `F`와 `.`로만 이루어집니다.

## 입출력 예

| photo | result |
|---|---|
| ["F.F", ".F.", "F.F"] | [1, 5] |
| ["F..F", "....", "F..F"] | [4, 1] |
| ["...."] | [0, 0] |

## 입출력 예 설명
- 예 #1: 네 모서리의 숲이 가운데 숲과 대각선으로 붙어 있어 전체가 하나의 구역입니다.
- 예 #2: 네 숲 칸이 서로 떨어져 있어 크기 1인 구역이 4개입니다.
- 예 #3: 숲이 없습니다.
