# [lv3] 습지 한 칸 메우기

습지를 격자로 나누어 문자열 배열 `wetland`에 적었습니다. `wetland[r]`의 `c`번째 문자가 (r, c) 칸이며, `L`은 땅, `W`는 물입니다.

땅 칸 두 개가 **상하좌우**로 붙어 있으면 같은 육지에 속합니다. 이렇게 이어진 땅 칸의 묶음 하나를 **육지**라고 하고, 육지의 크기는 그 칸의 수입니다.

흙이 한 삽 있어 물 칸 **하나**를 골라 땅으로 메울 수 있습니다(메우지 않아도 됩니다). 메운 칸은 땅 칸이 되어 상하좌우의 땅과 이어집니다. 가장 좋은 칸을 골랐을 때 만들 수 있는 **가장 큰 육지의 크기**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `wetland`의 길이 ≤ 2,000
- 1 ≤ 각 `wetland[r]`의 길이 ≤ 1,500
- 모든 줄의 길이는 같습니다.
- `wetland`는 `L`과 `W`로만 이루어집니다.

## 입출력 예

| wetland | result |
|---|---|
| ["LWL", "WWW", "LWL"] | 3 |
| ["LL", "LL"] | 4 |
| ["WWW"] | 1 |

## 입출력 예 설명
- 예 #1: (0,1)을 메우면 (0,0), (0,1), (0,2)가 이어져 크기 3이 됩니다. 가운데 (1,1)을 메우면 이웃이 모두 물이라 크기 1뿐입니다.
- 예 #2: 물이 없으므로 그대로 4입니다.
- 예 #3: 아무 칸이나 메우면 크기 1인 육지가 생깁니다.
