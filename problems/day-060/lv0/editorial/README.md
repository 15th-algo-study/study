# 해설 — 모자이크의 맞닿은 조각

## 접근
각 조각에서 8방향을 모두 확인하면 모든 쌍이 **두 번씩**(양쪽에서 한 번씩) 세어집니다. 마지막에 2로 나눠도 되지만, 더 깔끔한 방법은 **8방향 중 절반만** 보는 것입니다. 각 조각에서 오른쪽, 아래, 오른쪽 아래, 왼쪽 아래 네 방향만 확인하면 모든 쌍이 정확히 한 번씩 세어집니다. 어떤 쌍이든 "더 위에 있는(같은 줄이면 더 왼쪽에 있는) 조각"에서 보았을 때 이 네 방향 중 하나이기 때문입니다.

```java
int[] dr = {0, 1, 1, 1};   // 오른쪽, 아래, 오른쪽 아래, 왼쪽 아래
int[] dc = {1, 0, 1, -1};
```

이중 반복문으로 모든 조각을 순회하며, 네 방향의 이웃이 격자 안에 있고 색이 같으면 1씩 더합니다.

## 주의할 점
- 왼쪽 아래 방향은 `nc = c - 1`이 음수가 될 수 있으므로 열의 아래쪽 경계뿐 아니라 **왼쪽 경계**도 확인해야 합니다.
- 8방향을 모두 세고 2로 나누는 방법도 맞지만, 홀수가 나오면 어딘가 틀린 것이니 확인하세요.
- 최대 쌍의 수는 약 4×10^6 이라 `int`로 충분합니다.

## 복잡도
- 시간 O(rows × cols), 공간 O(1)
