# [lv3] 비상구 안내 표지판

큰 건물에 방 `n`개가 있고 0번부터 `n-1`번까지 번호가 붙어 있습니다. 방마다 비상구 안내 표지판이 하나씩 있어 "다음에 갈 방"을 **하나** 가리킵니다. 배열 `next`의 `next[i]`는 `i`번 방의 표지판이 가리키는 방 번호입니다. 표지판이 자기 방을 가리킬 수도 있습니다(`next[i] = i`).

사람은 자기 방에서 출발해 표지판이 가리키는 대로 계속 이동합니다. 표지판을 따라가다 보면 언젠가 **이미 지나온 방에 다시 들어서게** 되는데, 그 순간 안내가 잘못되었음을 알아채고 멈춥니다.

출발 방의 목록 `starts`가 주어질 때, 각 출발 방에 대해 **멈출 때까지 지나간 서로 다른 방의 수**(출발 방 포함)를 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `next`의 길이 `n` ≤ 3,000,000
- 0 ≤ `next[i]` < `n`
- 1 ≤ `starts`의 길이 ≤ 200,000
- 0 ≤ `starts[i]` < `n`

## 입출력 예

| next | starts | result |
|---|---|---|
| [1, 2, 0, 1, 3] | [0, 3, 4] | [3, 4, 5] |
| [0] | [0] | [1] |
| [1, 0, 2] | [2, 1] | [1, 2] |

## 입출력 예 설명
- 예 #1
  - 0번 출발: 0 → 1 → 2 → 0(다시 만남). 지나간 방은 {0, 1, 2}로 3개.
  - 3번 출발: 3 → 1 → 2 → 0 → 1(다시 만남). {3, 1, 2, 0}으로 4개.
  - 4번 출발: 4 → 3 → 1 → 2 → 0 → 1(다시 만남). 5개.
- 예 #2: 표지판이 자기 방을 가리키므로 바로 멈춥니다. 1개.
- 예 #3: 2번은 자기 자신을 가리켜 1개, 1번은 1 → 0 → 1 로 2개입니다.
