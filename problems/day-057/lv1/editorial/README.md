# 해설 — 공저자 찾기

## 접근
질문마다 `papers` 전체를 훑으면 O(q × m) = 4×10^10 으로 시간 초과입니다. 먼저 **인접 리스트**를 만들어 두고 질문에 답합니다.

1. `List<Integer>[] adj`를 만들고 각 기록 `[a, b]`(단, `a ≠ b`)에 대해 `adj[a].add(b)`, `adj[b].add(a)`.
2. 각 리스트를 **정렬**한 뒤 **중복을 제거**합니다. 정렬된 리스트에서 바로 앞 원소와 같은 값은 건너뛰며 새 리스트(또는 배열)에 옮겨 담으면 됩니다.
3. 질문 `[v, k]`: 정리된 리스트의 길이가 `k` 이상이면 `k-1`번 인덱스의 값, 아니면 -1.

## 주의할 점
- 리스트마다 정렬하므로 전체 정렬 비용은 O(m log m)입니다. 리스트 하나가 아주 길어도(모두 한 사람과 공저) 문제없습니다.
- 중복 제거를 빠뜨리면 같은 쌍이 여러 번 나올 때 `k`번째가 밀립니다. 예 #2가 이 경우입니다.
- `k`가 리스트 길이보다 클 때 `get(k-1)`을 호출하면 예외가 나므로 길이 비교를 먼저 하세요.
- `HashSet`으로 중복을 걸러도 되지만, 어차피 정렬이 필요하므로 "정렬 후 인접 중복 건너뛰기"가 더 간단하고 빠릅니다.

## 복잡도
- 시간 O(n + m log m + q), 공간 O(n + m)
