# [lv0] 벌통 옆의 꽃

양봉장을 격자 모양으로 나누어 2차원 배열 `field`에 기록했습니다. `field[r][c]`는 다음 중 하나입니다.

- `0`: 빈 땅
- `1`: 꽃이 핀 칸
- `2`: 벌통이 놓인 칸

벌통의 벌들은 벌통 바로 **위·아래·왼쪽·오른쪽**에 붙어 있는 칸의 꽃만 찾아갑니다. 양봉장 밖은 아무것도 없는 땅입니다.

모든 벌통에 대해 "바로 옆에 붙어 있는 꽃 칸의 수"를 구해 전부 더한 값을 return 하도록 `solution` 함수를 완성해 주세요. 같은 꽃 칸이 여러 벌통 옆에 있으면 벌통마다 따로 셉니다.

## 제한사항
- 1 ≤ `field`의 줄 수, 각 줄의 칸 수 ≤ 1,000
- 모든 줄의 칸 수는 같습니다.
- `field[r][c]`는 0, 1, 2 중 하나입니다.

## 입출력 예

| field | result |
|---|---|
| [[1, 2, 1], [0, 1, 0], [2, 0, 1]] | 3 |
| [[2, 2], [1, 1]] | 2 |
| [[1, 1, 1]] | 0 |

## 입출력 예 설명
- 예 #1: (0, 1)의 벌통 옆에는 왼쪽 (0, 0), 오른쪽 (0, 2), 아래 (1, 1)에 꽃이 있어 3입니다. (2, 0)의 벌통 옆에는 위 (1, 0)과 오른쪽 (2, 1)이 모두 빈 땅이라 0입니다. 합은 3입니다.
- 예 #2: 두 벌통 모두 아래 칸에 꽃이 하나씩 있어 1 + 1 = 2입니다. 벌통 옆의 벌통은 꽃이 아닙니다.
- 예 #3: 벌통이 없으므로 0입니다.
