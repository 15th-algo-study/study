# 해설 — 벌통 옆의 꽃

## 접근
2차원 배열을 순회하다가 벌통(2)을 만나면 네 방향 이웃을 확인합니다. 네 방향을 `if`문 네 개로 쓰는 대신 **방향 배열**을 쓰면 코드가 짧아지고 실수가 줄어듭니다.

```java
int[] dr = {-1, 1, 0, 0}; // 위, 아래, 왼쪽, 오른쪽의 줄 변화
int[] dc = {0, 0, -1, 1}; // 같은 순서의 칸 변화
for (int d = 0; d < 4; d++) {
    int nr = r + dr[d], nc = c + dc[d];
    if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue; // 양봉장 밖
    if (field[nr][nc] == 1) answer++;
}
```

## 주의할 점
- 이웃 좌표가 배열 범위를 벗어나는지 **먼저** 확인한 뒤 값을 읽어야 `ArrayIndexOutOfBoundsException`이 나지 않습니다.
- 벌통 옆의 벌통(2)은 꽃이 아니므로 세지 않습니다. 값이 정확히 1인지 비교하세요.
- 최대 10^6 칸 × 4방향 = 4×10^6 번 확인이라 충분히 빠릅니다.

## 복잡도
- 시간 O(rows × cols), 공간 O(1)
