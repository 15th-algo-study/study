# [lv2] 사막 유적의 돌길

사막 한가운데 있는 유적을 격자 모양의 지도 `ruins`로 나타냈습니다. `ruins[r]`의 `c`번째 문자가 (r, c) 칸이며, 각 문자의 뜻은 다음과 같습니다.

- `S`: 탐험가가 서 있는 출발 칸 (정확히 하나)
- `T`: 보물이 묻힌 목표 칸 (정확히 하나)
- `.`: 걸을 수 있는 돌길
- `#`: 빠지면 나올 수 없는 모래 함정

탐험가는 한 번에 상하좌우로 붙어 있는 한 칸으로만 움직일 수 있고, 모래 함정 칸과 지도 밖으로는 갈 수 없습니다. `S`와 `T` 칸은 돌길처럼 밟을 수 있습니다.

출발 칸에서 목표 칸까지 가는 **최소 이동 횟수**를 return 하도록 `solution` 함수를 완성해 주세요. 도달할 수 없으면 -1을 return 합니다.

## 제한사항
- 1 ≤ `ruins`의 길이 ≤ 2,000
- 1 ≤ 각 `ruins[r]`의 길이 ≤ 1,500
- 모든 줄의 길이는 같습니다.
- `ruins`는 `S`, `T`, `.`, `#`로만 이루어지며 `S`와 `T`는 각각 정확히 한 번 나옵니다.

## 입출력 예

| ruins | result |
|---|---|
| ["S.#", ".##", "..T"] | 4 |
| ["S#T"] | -1 |
| ["ST"] | 1 |

## 입출력 예 설명
- 예 #1: (0,0) → (1,0) → (2,0) → (2,1) → (2,2) 로 4번 움직이는 것이 최소입니다. (0,1)로 가는 길은 함정에 막혀 있습니다.
- 예 #2: 가운데 함정 때문에 도달할 수 없습니다.
- 예 #3: 바로 옆이 목표입니다.
