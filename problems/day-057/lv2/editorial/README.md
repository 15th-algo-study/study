# 해설 — 사막 유적의 돌길

## 접근
격자의 각 칸을 정점, 상하좌우로 붙은 두 칸을 간선으로 보면 모든 간선의 길이가 1인 그래프입니다. 이런 그래프의 최단 거리는 **BFS**로 구합니다. BFS 는 출발점에서 가까운 칸부터 차례로 방문하므로, 어떤 칸을 처음 방문했을 때의 거리가 곧 최단 거리입니다.

1. `S`의 위치를 찾아 큐에 넣고 `dist[S] = 0`.
2. 큐에서 칸을 꺼내 네 방향 이웃을 봅니다. 지도 안이고, 함정이 아니고, 아직 방문하지 않았으면 `dist = 현재 + 1`로 적고 큐에 넣습니다.
3. `T`를 꺼내는(또는 큐에 넣는) 순간 그 거리가 답입니다. 큐가 비도록 `T`를 못 만나면 -1.

격자에서는 정점 번호 대신 `(r, c)` 좌표 쌍을 다루므로 인접 리스트를 따로 만들 필요가 없고, **방향 배열** `dr`, `dc`로 이웃을 만듭니다. 큐에는 `r * cols + c`처럼 한 정수로 묶어 넣으면 객체 생성 없이 빠릅니다.

## 주의할 점
- `dist` 배열을 -1로 초기화하면 방문 여부 확인용 배열을 따로 둘 필요가 없습니다.
- **DFS 로는 최단 거리를 구할 수 없습니다.** 처음 도착한 경로가 최단이라는 보장이 없고, 모든 경로를 다 시도하면 지수 시간입니다.
- 격자가 최대 2,000 × 1,500 = 300만 칸입니다. 재귀로 격자를 탐색하면 열린 격자에서 재귀 깊이가 수백만이 되어 스택이 넘칩니다. 큐를 쓰는 반복문 BFS 로 작성하세요.
- `String.charAt`을 반복 호출해도 되지만, 미리 `char[][]`로 바꿔 두면 더 빠릅니다.

## 복잡도
- 시간 O(rows × cols), 공간 O(rows × cols)
