# [lv2] 우편 수송망

우편 집중국 `n`곳(0번 ~ `n - 1`번)이 우편물 수송 노선으로 이어져 있습니다. 노선은 모두 **한 방향**이며, `i`번 노선은 `from[i]`번 집중국에서 `to[i]`번 집중국으로 우편물을 `time[i]`분 만에 옮깁니다.

`start`번 집중국에서 출발한 우편물이 각 집중국에 도착하는 가장 빠른 시간을 구하려고 합니다. 우편물은 여러 노선을 갈아타며 이동할 수 있고, 갈아타는 데 걸리는 시간은 없습니다.

`i`번 원소가 `start`에서 `i`번 집중국까지 걸리는 최소 시간인 배열을 return 하도록 `solution` 함수를 완성해 주세요. 도달할 수 없는 집중국은 -1, `start` 자신은 0입니다. 시간이 `int` 범위를 넘을 수 있으므로 `long[]`로 return 합니다.

## 제한사항
- 1 ≤ `n` ≤ 300,000
- 0 ≤ `from`, `to`, `time`의 길이 ≤ 500,000 (세 배열의 길이는 같습니다)
- 0 ≤ `from[i]`, `to[i]` < `n`
  - 같은 두 집중국 사이에 노선이 여러 개일 수 있고, `from[i] = to[i]`인 순환 노선이 있을 수도 있습니다.
- 1 ≤ `time[i]` ≤ 1,000,000,000
- 0 ≤ `start` < `n`

## 입출력 예

| n | from | to | time | start | result |
|---|---|---|---|---|---|
| 5 | [0, 0, 1, 2, 1] | [1, 2, 2, 3, 3] | [4, 1, 2, 5, 10] | 0 | [0, 4, 1, 6, -1] |
| 3 | [1, 2] | [0, 0] | [1000000000, 1000000000] | 1 | [1000000000, 0, -1] |
| 1 | [] | [] | [] | 0 | [0] |

## 입출력 예 설명
- 예 #1: 0 → 2는 1분, 0 → 1은 4분입니다(0 → 2 → 1로 가는 노선은 없습니다). 3번은 0 → 2 → 3(1 + 5 = 6분)이 0 → 1 → 3(4 + 10 = 14분)보다 빠릅니다. 4번으로 가는 노선은 없습니다.
- 예 #2: 1번에서 0번으로 바로 갑니다. 2번 집중국에서 나가는 노선은 있지만 2번으로 들어가는 노선이 없어 도달할 수 없습니다.
- 예 #3: 집중국이 하나뿐입니다.
