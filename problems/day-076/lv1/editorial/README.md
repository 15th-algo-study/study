# 해설 — 보건지소 자리 정하기

## 접근
모든 마을 쌍의 최단 거리가 필요하고 `n ≤ 200`으로 작으므로 **플로이드–워셜**이 가장 간단합니다.

1. `dist[i][j]`를 큰 값(INF)으로 채우고 `dist[i][i] = 0`.
2. 도로 `[a, b, len]`마다 `dist[a][b]`, `dist[b][a]`를 `len`과 비교해 **더 작은 값**으로 둡니다 (같은 두 마을을 잇는 도로가 여러 개일 수 있음).
3. 경유 마을 `k`를 바깥 반복문으로 두고 `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`.
   `k`번 단계가 끝나면 `dist[i][j]`는 "1 ~ k번 마을만 거쳐 갈 수 있을 때의 최단 거리"가 되고, 마지막 단계 뒤에는 진짜 최단 거리입니다.
4. 마을 `v`마다 `dist[v][*]`의 최댓값을 구해, 그 값이 가장 작은 `v`를 고릅니다. 번호 순으로 보면서 **더 작을 때만** 바꾸면 동률일 때 작은 번호가 남습니다.

## 주의할 점
- 반복문 순서는 반드시 `k`(경유지)가 가장 바깥입니다. `i, j, k` 순서로 돌리면 아직 완성되지 않은 거리를 쓰게 되어 틀립니다.
- 도로를 입력받을 때 `dist[a][b] = len`으로 덮어쓰면, 더 짧은 도로가 먼저 나온 경우 긴 도로로 덮여 틀립니다.
- INF를 `Integer.MAX_VALUE`로 두면 `dist[i][k] + dist[k][j]`에서 넘칩니다. 최단 거리는 최대 199 × 1,000이므로 INF는 10억 정도면 충분하고 더해도 넘치지 않습니다.
- 모든 경로를 DFS로 나열하면 경로 수가 지수적으로 늘어 시간 초과입니다.

## 복잡도
- 시간 O(n³ + m), 공간 O(n²)
