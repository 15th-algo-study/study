# [lv0] 출석 도장 비트맵

독서 동아리는 회원마다 한 달 출석 기록을 정수 하나에 담아 둡니다. 정수를 2진수로 썼을 때 `d`번 비트(가장 오른쪽이 0번)가 1이면 그 회원이 `d + 1`일에 출석했다는 뜻입니다. 예를 들어 `13`은 2진수로 `1101`이므로 0번·2번·3번 비트가 켜져 있고, 1일·3일·4일에 출석한 기록입니다.

회원들의 기록이 담긴 정수 배열 `stamps`와 날짜 `day`가 주어질 때, 다음 두 값을 차례로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

1. `day`일에 출석한 회원 수
2. 모든 회원의 출석 일수(켜진 비트 수)의 합

## 제한사항
- 1 ≤ `stamps`의 길이 ≤ 100,000
- 0 ≤ `stamps`의 원소 ≤ 2,147,483,647 (0번~30번 비트만 쓰입니다)
- 1 ≤ `day` ≤ 31

## 입출력 예

| stamps | day | result |
|---|---|---|
| [13, 6, 1] | 3 | [2, 6] |
| [2147483647, 0] | 31 | [1, 31] |
| [1073741824, 5, 1073741825] | 31 | [2, 5] |

## 입출력 예 설명
- 예 #1
  - `13` = `1101`₂ → 1일, 3일, 4일 출석 (3일)
  - `6` = `110`₂ → 2일, 3일 출석 (2일)
  - `1` = `1`₂ → 1일 출석 (1일)
  - 3일(2번 비트)에 출석한 회원은 앞의 두 명이고, 출석 일수의 합은 3 + 2 + 1 = 6입니다.
- 예 #2: `2147483647`은 0번~30번 비트가 모두 켜진 수라 1일부터 31일까지 모두 출석했습니다. 31일(30번 비트)에 출석한 회원은 1명, 출석 일수의 합은 31입니다.
- 예 #3: `1073741824` = 2^30 은 31일에만, `5` = `101`₂ 은 1일·3일에, `1073741825` = 2^30 + 1 은 1일·31일에 출석했습니다. 31일 출석자는 2명, 출석 일수의 합은 1 + 2 + 2 = 5입니다.
