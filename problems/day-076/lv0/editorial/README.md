# 해설 — 출석 도장 비트맵

## 접근
`day`일은 `day - 1`번 비트입니다. 비트 하나를 확인하는 방법은 두 가지입니다.

- `(x >> b) & 1` : 확인할 비트를 맨 오른쪽으로 밀어 1과 AND → 0 또는 1
- `(x & (1 << b)) != 0` : 그 자리만 1인 마스크와 AND

켜진 비트의 개수는 `Integer.bitCount(x)`가 한 번에 세어 줍니다. 회원마다 두 값을 구해 더하면 됩니다.

## 주의할 점
- 날짜는 1부터, 비트 번호는 0부터 셉니다. `day`번 비트를 보면 하루씩 밀립니다.
- `bitCount`를 직접 구현한다면 `x & (x - 1)`(가장 낮은 켜진 비트 끄기)을 반복하거나 `x >>= 1`로 한 비트씩 확인합니다. 원소가 음수가 아니므로 `>>`로 밀어도 끝납니다.
- 출석 일수의 합은 최대 31 × 100,000 = 3,100,000이라 `int`로 충분합니다.

## 복잡도
- 시간 O(n), 공간 O(1)
