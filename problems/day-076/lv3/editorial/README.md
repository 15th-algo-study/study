# 해설 — 두 농장의 합동 운송

## 접근
만나는 마을 `x`를 정하면 세 구간은 서로 독립입니다. 각 구간을 최단 경로로 가는 것이 최선이므로

`답 = min over x ( dA[x] + dB[x] + dM[x] )`

- `dA[x]`: `farmA`에서 `x`까지 최단 거리 → `farmA`에서 다익스트라
- `dB[x]`: `farmB`에서 `x`까지 최단 거리 → `farmB`에서 다익스트라
- `dM[x]`: `x`에서 `market`까지 최단 거리 → ?

마지막이 핵심입니다. `x`마다 다익스트라를 돌리면 n번이라 불가능합니다. **모든 도로의 방향을 뒤집은 그래프**에서 `market`부터 다익스트라를 한 번 돌리면, 뒤집힌 그래프의 `market → x` 경로가 원래 그래프의 `x → market` 경로와 일대일로 대응하므로 모든 `x`의 `dM[x]`가 한꺼번에 나옵니다.

다익스트라 세 번(정방향 두 번, 역방향 한 번) 뒤 `x`를 모두 훑으면 됩니다. 세 값 중 하나라도 도달 불가인 `x`는 건너뛰고, 모든 `x`가 불가능하면 -1입니다.

`x`가 `market`이면 각자 시장으로 가는 경우, `x`가 `farmA`면 B 트럭이 A 농장으로 가서 합치는 경우라 따로 처리할 필요가 없습니다.

## 주의할 점
- 일방통행이라 `x → market` 거리를 `market`에서 정방향 다익스트라로 구하면 틀립니다. 반드시 간선을 뒤집습니다.
- 합류 뒤에는 공용 경로를 한 번만 내므로 "A의 최단 경로 + B의 최단 경로"보다 쌀 수 있습니다(예 #1).
- 세 거리의 합은 최대 약 6 × 10^14라 `long`이 필요합니다. 도달 불가를 `Long.MAX_VALUE`로 두었다면 더하기 전에 걸러야 넘치지 않습니다.
- 정점마다 다익스트라를 돌리는 풀이는 O(n · m log m)로 시간 초과입니다.

## 복잡도
- 시간 O((n + m) log m), 공간 O(n + m)
