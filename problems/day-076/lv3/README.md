# [lv3] 두 농장의 합동 운송

마을 `n`개(0번 ~ `n - 1`번)가 **일방통행** 도로로 이어져 있습니다. `farmA`번 마을과 `farmB`번 마을에 있는 두 농장이 수확한 농산물을 `market`번 마을의 도매시장으로 보내려고 합니다.

두 농장은 각자 트럭 한 대로 출발합니다. 두 트럭은 원하는 마을 `x` 하나에서 만나 짐을 한 트럭에 합치고, 합친 트럭이 `x`에서 시장까지 갑니다. 도로를 지날 때마다 그 도로의 통행 비용을 내며, 짐을 합친 뒤에는 트럭 한 대 몫만 냅니다. 즉 전체 비용은

- (`farmA` → `x` 트럭의 비용) + (`farmB` → `x` 트럭의 비용) + (`x` → `market` 트럭의 비용)

입니다. `x`는 어느 마을이어도 됩니다. 농장 마을이나 시장 마을이어도 되고, `x`가 `market`이면 두 트럭이 각자 시장까지 가는 것입니다.

도로 정보 `roads`가 주어질 때, 가능한 가장 적은 전체 비용을 return 하도록 `solution` 함수를 완성해 주세요. 두 농장의 농산물을 시장에 모을 방법이 없으면 -1을 return 합니다. 비용이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

- `roads`의 원소 `[a, b, c]`는 `a`번 마을에서 `b`번 마을로만 갈 수 있고 통행 비용이 `c`인 도로입니다.

## 제한사항
- 1 ≤ `n` ≤ 200,000
- 0 ≤ `roads`의 길이 ≤ 400,000
- `roads`의 원소는 `[a, b, c]` 형태입니다.
  - 0 ≤ `a`, `b` < `n` (`a = b`인 도로나 같은 구간의 도로 여러 개가 있을 수 있습니다)
  - 1 ≤ `c` ≤ 1,000,000,000
- 0 ≤ `farmA`, `farmB`, `market` < `n` (서로 같을 수도 있습니다)

## 입출력 예

| n | roads | farmA | farmB | market | result |
|---|---|---|---|---|---|
| 6 | [[0, 2, 2], [1, 2, 3], [2, 3, 4], [3, 5, 1], [0, 4, 1], [4, 5, 9], [1, 5, 20]] | 0 | 1 | 5 | 10 |
| 3 | [[0, 2, 5], [1, 2, 5], [2, 0, 1]] | 0 | 1 | 0 | 6 |
| 3 | [[0, 1, 1]] | 0 | 2 | 1 | -1 |

## 입출력 예 설명
- 예 #1: 두 트럭이 2번 마을에서 만나면 0 → 2(2) + 1 → 2(3) + 2 → 3 → 5(4 + 1 = 5)로 10입니다. 각자 시장으로 가면 0 → 2 → 3 → 5(7)와 1 → 2 → 3 → 5(8)로 15, 3번에서 만나면 6 + 7 + 1 = 14입니다.
- 예 #2: 1번 농장 트럭이 1 → 2 → 0(5 + 1 = 6)으로 0번 마을에 가서 만나면, 0번이 곧 시장이므로 6입니다. 2번 마을에서 만나면 5 + 5 + 1 = 11입니다.
- 예 #3: 2번 마을에서 나가는 도로가 없고 들어오는 도로도 없어 두 트럭이 만날 수 없습니다.
