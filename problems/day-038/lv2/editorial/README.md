# 해설 — 팔레트 묶음 수

## 접근
묶음을 모두 세어 보면 O(n²)으로 `n = 500,000`에서 시간 초과입니다.

누적합 `P[i]` = 앞 `i`개의 합이라 하면, 묶음 `(i, j]`(i < j)의 합은 `P[j] − P[i]`입니다. 이 값이 `k`의 배수라는 것은 **`P[i]`와 `P[j]`를 `k`로 나눈 나머지가 같다**는 뜻입니다.

그러므로 누적합 `P[0] = 0, P[1], …, P[n]`의 나머지를 구해 **나머지별 개수**를 세고, 나머지마다 `c × (c − 1) / 2`(둘을 고르는 경우의 수)를 더하면 답입니다. 또는 앞에서부터 훑으며 "지금 나머지가 이전에 몇 번 나왔는지"를 답에 더하고 개수를 올려도 같습니다.

`k ≤ 10^6`이므로 나머지 개수는 길이 `k`인 배열로 셉니다 (`HashMap`도 됩니다).

## 주의할 점
- `P[0] = 0`의 나머지 0을 **반드시 포함**해야 합니다. 빼먹으면 처음부터 시작하는 묶음(예 #1의 `[2, 4]`)을 놓칩니다.
- 누적합은 `long`입니다. 다만 나머지만 필요하므로 `running = (running + w) % k`로 매번 줄이면 `int`로도 됩니다.
- 답은 `long`입니다. 모두 0인 50만 개에 `k = 1`이면 약 1.25 × 10^11입니다.
- `c × (c − 1) / 2`에서 `c`가 `int`이면 곱이 넘칩니다. `c`를 `long`으로 두세요.

## 복잡도
- 시간 O(n + k), 공간 O(k)
