# [lv2] 팔레트 묶음 수

포장 라인에 상자 `n`개가 순서대로 놓여 있고 `weights[i]`는 `i`번째 상자의 무게입니다. 지게차용 팔레트는 무게 `k`의 배수만 실을 수 있어서, **연속한 상자들**을 한 묶음으로 실으려면 묶음의 무게 합이 `k`의 배수여야 합니다 (합이 0이어도 0은 `k`의 배수입니다).

상자가 하나 이상인 연속 묶음 가운데 무게 합이 `k`의 배수인 묶음의 개수를 return 하도록 `solution` 함수를 완성해 주세요. 시작 또는 끝 위치가 다르면 다른 묶음입니다. 개수가 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `weights`의 길이 `n` ≤ 500,000
- 0 ≤ `weights`의 원소 ≤ 1,000,000,000
- 1 ≤ `k` ≤ 1,000,000

## 입출력 예

| weights | k | result |
|---|---|---|
| [2, 4, 6, 3] | 3 | 6 |
| [5, 5, 5] | 5 | 6 |
| [1, 2, 3] | 10 | 0 |

## 입출력 예 설명
- 예 #1: 합이 3의 배수인 묶음은 `[6]`, `[3]`, `[2, 4]`, `[6, 3]`, `[2, 4, 6]`, `[2, 4, 6, 3]`의 6개입니다.
- 예 #2: 어떤 연속 묶음을 골라도 합이 5의 배수이므로 묶음 수 3 + 2 + 1 = 6입니다.
- 예 #3: 가능한 합은 1, 2, 3, 3, 5, 6뿐이라 10의 배수가 없습니다.
