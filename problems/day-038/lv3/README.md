# [lv3] 장르가 딱 k가지인 플레이리스트 구간

음악 앱의 플레이리스트에 곡 `n`개가 순서대로 들어 있습니다. `genres[i]`는 `i`번째 곡의 장르 번호입니다.

앱은 "연속해서 재생되는 구간" 가운데 서로 다른 장르가 **정확히 `k`가지**인 구간을 추천 묶음으로 뽑으려 합니다. 구간은 곡이 하나 이상이고, 시작 또는 끝이 다르면 다른 구간입니다.

그런 구간의 개수를 return 하도록 `solution` 함수를 완성해 주세요. 개수가 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 1 ≤ `genres`의 길이 `n` ≤ 200,000
- 1 ≤ `genres`의 원소 ≤ 1,000,000
- 1 ≤ `k` ≤ `n`

## 입출력 예

| genres | k | result |
|---|---|---|
| [1, 2, 1, 3] | 2 | 4 |
| [7, 7, 7] | 1 | 6 |
| [1, 2, 1, 2, 1] | 2 | 10 |

## 입출력 예 설명
- 예 #1: 장르가 정확히 2가지인 구간은 `[1, 2]`, `[2, 1]`, `[1, 3]`, `[1, 2, 1]`의 4개입니다. `[2, 1, 3]`은 3가지라 제외됩니다.
- 예 #2: 모든 구간이 장르 1가지이므로 구간 수 3 + 2 + 1 = 6입니다.
- 예 #3: 구간은 모두 15개이고, 장르가 1가지인 구간은 길이 1인 5개뿐이므로 나머지 10개가 모두 2가지입니다.
