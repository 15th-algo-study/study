# 해설 — 마라톤 급수대 거리

## 접근
주자마다 급수대를 처음부터 훑으면 O(n·m)으로 시간 초과입니다. 두 배열이 모두 정렬되어 있으므로 **두 배열을 동시에 앞으로만 나아가는 투 포인터**로 풉니다.

- 급수대 포인터 `j`를 0에서 시작합니다.
- 주자를 순서대로 보면서, `stations[j] ≤ runners[i]`인 동안 `j`를 올립니다. 멈춘 뒤 `j − 1`이 "주자 위치 이하인 마지막 급수대"입니다.
- `j == 0`이면 그런 급수대가 없으므로 −1, 아니면 `runners[i] − stations[j − 1]`.

다음 주자는 위치가 같거나 더 크므로 `j`를 되돌릴 필요가 없습니다. 두 포인터가 각각 끝까지 한 번씩만 가므로 O(n + m)입니다.

## 주의할 점
- 조건은 "작거나 같은"입니다. `<`로 쓰면 같은 위치의 급수대(예 #2)를 놓칩니다.
- `j`를 올리는 반복에 `j < stations.length` 범위 검사를 먼저 둡니다.
- 거리는 최대 10^9라 `int`에 들어갑니다.
- 이분 탐색으로 주자마다 `O(log m)`에 찾아도 통과하지만, 정렬된 두 배열을 함께 훑는 투 포인터가 더 단순합니다.

## 복잡도
- 시간 O(n + m), 공간 O(n)
