# [lv1] 마라톤 급수대 거리

직선 마라톤 코스가 있고 출발점이 위치 0입니다. 현재 주자들의 위치가 배열 `runners`로, 급수대의 위치가 배열 `stations`로 주어집니다. 두 배열 모두 **오름차순**으로 정렬되어 있고, 같은 위치가 여러 번 나올 수 있습니다.

주자는 이미 지나온 급수대를 돌아보며 "가장 최근에 지나친 급수대가 얼마나 뒤에 있는지"를 알고 싶어 합니다. 각 주자에 대해, 그 주자의 위치보다 **작거나 같은** 위치에 있는 급수대 중 가장 가까운 것까지의 거리를 구해 주세요. 그런 급수대가 없으면 −1입니다.

주자 순서대로 거리를 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `runners`의 길이, `stations`의 길이 ≤ 200,000
- 0 ≤ 모든 위치 ≤ 1,000,000,000
- `runners`와 `stations`는 각각 오름차순으로 정렬되어 있습니다(같은 값 가능).

## 입출력 예

| runners | stations | result |
|---|---|---|
| [3, 7, 12] | [5, 10] | [-1, 2, 2] |
| [5, 5, 6] | [5] | [0, 0, 1] |
| [1, 2] | [4, 8] | [-1, -1] |

## 입출력 예 설명
- 예 #1: 위치 3인 주자 뒤에는 급수대가 없습니다. 위치 7인 주자는 5의 급수대까지 2, 위치 12인 주자는 10의 급수대까지 2입니다.
- 예 #2: 급수대와 같은 위치에 있으면 거리 0입니다.
- 예 #3: 모든 급수대가 앞에 있어 둘 다 −1입니다.
