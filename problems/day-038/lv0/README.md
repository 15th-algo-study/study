# [lv0] 저금통 잔액 기록

저금통 장부에 매일 넣거나 꺼낸 금액이 배열 `changes`로 적혀 있습니다. `changes[i]`가 양수이면 `i`번째 날(0번부터 셈)에 그만큼 넣은 것이고, 음수이면 꺼낸 것입니다. 처음 잔액은 0입니다.

각 날이 끝났을 때의 잔액을 날짜 순서대로 담은 `long` 배열을 return 하도록 `solution` 함수를 완성해 주세요. 장부상 잔액은 음수가 될 수도 있습니다(빌린 돈으로 기록합니다).

## 제한사항
- 1 ≤ `changes`의 길이 `n` ≤ 1,000,000
- −1,000,000 ≤ `changes`의 원소 ≤ 1,000,000
- 잔액이 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| changes | result |
|---|---|
| [100, -30, 50] | [100, 70, 120] |
| [-5, 5] | [-5, 0] |
| [1000000, 1000000, 1000000] | [1000000, 2000000, 3000000] |

## 입출력 예 설명
- 예 #1: 100을 넣고(100), 30을 꺼내고(70), 50을 넣습니다(120).
- 예 #2: 첫날 5를 꺼내 잔액이 −5가 되고, 다음 날 5를 넣어 0이 됩니다.
- 예 #3: 하루 100만 원씩 100만 일을 넣으면 잔액이 10^12가 되어 `int`로는 담을 수 없습니다.
