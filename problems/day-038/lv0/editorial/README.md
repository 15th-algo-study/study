# 해설 — 저금통 잔액 기록

## 접근
"앞에서부터 지금까지의 합"을 날마다 기록하면 됩니다. 이것이 **누적 배열(누적합)**입니다.

```java
long[] balance = new long[n];
balance[0] = changes[0];
for (int i = 1; i < n; i++) balance[i] = balance[i - 1] + changes[i];
```

날마다 0번째부터 다시 더하면 O(n²)이지만, 바로 앞 날의 잔액에 오늘 변화만 더하면 O(n)입니다.

## 주의할 점
- 결과 배열은 `long[]`입니다. `int`로 누적하면 예 #3을 100만 일로 늘린 large 케이스에서 넘칩니다.
- `i = 1`부터 시작하면 `balance[0]`을 따로 넣어야 합니다. 변수 `running`에 계속 더하며 `balance[i] = running`으로 채우면 분기가 없습니다.
- 음수 변화도 그냥 더하면 됩니다. 따로 처리할 것이 없습니다.

## 복잡도
- 시간 O(n), 공간 O(n)
