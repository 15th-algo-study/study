# [lv1] 우표 앨범 정리

우표를 모으는 취미가 있습니다. 우표에는 발행 번호가 붙어 있고, 지금까지 모은 우표들의 번호가 배열 `stamps`로 주어집니다. 같은 번호의 우표를 여러 장 가지고 있을 수도 있습니다.

앨범에는 우표를 **번호가 이어지는 묶음** 단위로 정리합니다. 한 묶음은 번호가 연속한 정수(예: 7, 8, 9)로 이루어지며, 번호가 하나라도 빠지면 묶음이 끊깁니다. 같은 번호가 여러 장이어도 묶음에서는 한 번만 셉니다. 묶음은 가능한 한 길게 만듭니다.

우표 번호 배열 `stamps`가 주어질 때, **묶음의 개수**와 **가장 긴 묶음에 들어 있는 서로 다른 번호의 수**를 `[묶음 수, 가장 긴 묶음 길이]` 로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `stamps`의 길이 ≤ 200,000
- 1 ≤ `stamps`의 원소 ≤ 1,000,000,000

## 입출력 예

| stamps | result |
|---|---|
| [3, 1, 2, 7, 8, 10] | [3, 3] |
| [5, 5, 6, 5] | [1, 2] |
| [100] | [1, 1] |

## 입출력 예 설명
- 예 #1: 묶음은 {1, 2, 3}, {7, 8}, {10} 세 개이고 가장 긴 묶음의 길이는 3입니다.
- 예 #2: 번호 5가 세 장이지만 한 번만 셉니다. 묶음은 {5, 6} 하나입니다.
- 예 #3: 우표 한 장이 묶음 하나입니다.
