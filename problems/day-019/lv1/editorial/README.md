# 해설 — 우표 앨범 정리

## 접근
정렬하면 연속한 번호는 이웃하게 됩니다. 정렬된 배열을 한 번 훑으며 **이웃 값의 차이**로 묶음을 나눕니다.

- 차이가 `0`: 같은 번호가 또 나온 것 → 아무것도 하지 않습니다 (중복).
- 차이가 `1`: 묶음이 이어집니다 → 현재 묶음 길이 +1.
- 차이가 `2` 이상: 묶음이 끊깁니다 → 묶음 수 +1, 현재 길이를 최댓값과 비교하고 1로 되돌립니다.

마지막 묶음은 반복문이 끝난 뒤 따로 마무리합니다.

## 주의할 점
- **중복 처리**가 핵심입니다. 차이 0을 "끊김"으로 처리하면 예 #2에서 묶음이 4개가 되고, "이어짐"으로 처리하면 길이가 4가 됩니다.
- 묶음 길이는 "서로 다른 번호의 수"이므로 차이가 1일 때만 늘립니다.
- 반복문이 끝난 뒤 마지막 묶음을 세는 것을 잊지 마세요. 원소가 하나뿐인 입력(예 #3)에서 바로 드러납니다.
- 각 우표마다 "번호 + 1이 있는지"를 배열에서 찾는 방식은 O(n²)이라 시간 초과입니다. 번호 범위가 10^9 라 방문 배열도 만들 수 없습니다.

## 복잡도
- 시간 O(n log n), 공간 O(1)
