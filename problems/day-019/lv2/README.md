# [lv2] 사과 선별 상자

과수원에서 수확한 사과 `n`개의 무게가 배열 `weights`로 주어집니다. 사과를 상자 `k`개에 나누어 담으려고 합니다.

- 사과 하나는 정확히 한 상자에 들어갑니다. 빈 상자가 있어도 됩니다.
- 상자 하나의 **편차**는 그 상자에 담긴 사과 중 가장 무거운 것과 가장 가벼운 것의 무게 차입니다. 사과가 하나뿐이거나 비어 있는 상자의 편차는 0입니다.

모든 상자의 편차 합이 **최소**가 되도록 사과를 담을 때, 그 최솟값을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `weights`의 길이 `n` ≤ 200,000
- 1 ≤ `weights`의 원소 ≤ 1,000,000,000
- 1 ≤ `k` ≤ `n`

## 입출력 예

| weights | k | result |
|---|---|---|
| [1, 7, 3, 20, 22, 9] | 2 | 10 |
| [5, 5, 5] | 1 | 0 |
| [10, 1, 100] | 3 | 0 |

## 입출력 예 설명
- 예 #1: {1, 3, 7, 9}와 {20, 22}로 나누면 편차가 8 + 2 = **10**입니다. 이보다 작게 만들 수는 없습니다.
- 예 #2: 무게가 모두 같아 편차가 0입니다.
- 예 #3: 상자가 사과 수만큼 있으므로 하나씩 담으면 0입니다.
