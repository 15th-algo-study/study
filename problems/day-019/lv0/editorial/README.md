# 해설 — 선반의 k번째 가격

## 접근
2차원 배열의 모든 원소를 **1차원 배열 하나로 펼친 뒤** 정렬하면, `k`번째로 작은 값은 인덱스 `k - 1`에 있습니다.

1. 각 선반의 길이를 모두 더해 전체 상품 수 `total`을 구합니다.
2. `int[] all = new int[total]`을 만들고 이중 반복문으로 가격을 차례로 채웁니다.
3. `Arrays.sort(all)` 후 `all[k - 1]`을 돌려줍니다.

## 주의할 점
- 선반마다 길이가 다르므로 `shelves[0].length × shelves.length` 로 전체 수를 계산하면 안 됩니다. 각 행의 길이를 **더해서** 구하세요.
- `k`는 1부터 세므로 인덱스는 `k - 1`입니다.
- `List<Integer>`에 모아 `Collections.sort`를 써도 되지만, 원소가 100만 개면 박싱 때문에 느리고 메모리도 많이 씁니다. 크기를 먼저 계산해 `int[]`에 담는 습관을 들이세요.

## 복잡도
- 시간 O(N log N) (N = 전체 상품 수, 최대 10^6), 공간 O(N)
