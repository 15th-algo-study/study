# [lv0] 선반의 k번째 가격

창고에 선반이 여러 개 있고, 각 선반에는 상품이 놓여 있습니다. 2차원 배열 `shelves`가 주어지며 `shelves[i]`는 `i`번 선반에 놓인 상품들의 가격 배열입니다. 선반마다 상품 수는 다를 수 있습니다.

창고에 있는 **모든 상품**의 가격을 낮은 순서로 늘어놓았을 때 `k`번째(1번부터 셈) 가격을 return 하도록 `solution` 함수를 완성해 주세요. 같은 가격의 상품이 여러 개면 각각 따로 셉니다.

## 제한사항
- 1 ≤ `shelves`의 길이 ≤ 1,000
- 1 ≤ `shelves[i]`의 길이 ≤ 1,000
- 1 ≤ 상품 가격 ≤ 1,000,000,000
- 1 ≤ `k` ≤ 전체 상품 수

## 입출력 예

| shelves | k | result |
|---|---|---|
| [[500, 1200], [300, 700, 900]] | 3 | 700 |
| [[4, 4], [4]] | 2 | 4 |
| [[10], [2], [8]] | 3 | 10 |

## 입출력 예 설명
- 예 #1: 모든 가격을 낮은 순으로 늘어놓으면 300, 500, 700, 900, 1200 이고 3번째는 **700**입니다.
- 예 #2: 가격이 모두 4라서 몇 번째든 4입니다.
- 예 #3: 2, 8, 10 중 3번째는 **10**입니다.
