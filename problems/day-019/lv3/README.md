# [lv3] 열차 차량 재배열

조차장에 열차 차량 `n`량이 한 줄로 서 있습니다. 차량에는 서로 다른 번호가 붙어 있고, 현재 줄의 앞에서부터 순서대로 배열 `cars`에 담겨 있습니다.

조차장의 크레인은 한 번에 **두 차량의 자리를 맞바꿀** 수 있습니다. 두 차량은 서로 붙어 있지 않아도 되고, 줄의 어느 위치에 있어도 됩니다.

차량을 **번호가 작은 것부터 큰 순서**로 다시 세우는 데 필요한 크레인 작업(맞바꾸기)의 **최소 횟수**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `cars`의 길이 `n` ≤ 500,000
- 1 ≤ `cars`의 원소 ≤ 1,000,000,000
- `cars`의 원소는 모두 서로 다릅니다.

## 입출력 예

| cars | result |
|---|---|
| [40, 10, 30, 20] | 2 |
| [1, 2, 3] | 0 |
| [5, 4, 3, 2, 1] | 2 |

## 입출력 예 설명
- 예 #1: 40과 20을 맞바꾸면 [20, 10, 30, 40], 이어서 20과 10을 맞바꾸면 [10, 20, 30, 40]입니다. 한 번으로는 불가능하므로 **2**입니다.
- 예 #2: 이미 정렬되어 있습니다.
- 예 #3: 5와 1, 4와 2를 맞바꾸면 끝납니다. 가운데 3은 움직이지 않습니다.
