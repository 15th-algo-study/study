# 해설 — 지하철 순차 개통

## 접근
역이 하나 개통될 때마다 개통한 역들만으로 플로이드–워셜을 새로 돌리면 `t`번째에 O(t³), 전체 O(n⁴/4) ≈ 5 × 10^11번이라 시간 초과입니다.

**관찰**: 플로이드–워셜의 바깥 반복문이 하는 일을 다시 봅시다.

```
for k in (아무 순서):
    for i, j: dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

`k` 단계를 마치면 `dist[i][j]`는 "지금까지 처리한 `k`들만 **경유지로** 써서 `i → j`로 가는 최단 거리"입니다. 이 성질은 `k`를 0, 1, 2, … 순서가 아니라 **어떤 순서로** 처리해도 성립합니다. 그리고 끝점 `i`, `j`는 처리 여부와 상관이 없습니다.

그러므로 `k`를 **개통 순서대로** 처리하면, `t`번째 역을 처리한 직후의 `dist[s][e]`가 바로 "개통한 역만 거쳐 `s → e`로 가는 최단 시간"입니다. 개통할 때마다 `k` 단계를 **한 번만** 더 돌리면 되므로 갱신은 단계마다 O(n²), 전체 O(n³)입니다.

1. `dist = time`을 복사하고 `dist[i][i] = 0`. 직통 터널이 모두 있으므로 처음부터 모든 쌍이 유한합니다.
2. `t = 0, 1, …`마다 `k = order[t]`로 모든 `i, j`(개통 안 한 역 포함)에 대해 `k` 단계를 수행합니다.
   - 개통 안 한 역 `i`의 행도 갱신해야 합니다. 나중에 `i`가 개통되면 `dist[i][·]`가 그때까지의 경유지를 반영하고 있어야 하기 때문입니다.
3. 개통한 역 `s`, `e`에 대해 `dist[s][e]`를 모두 더해 `S_t`로 기록합니다.

## 주의할 점
- 끝점까지 "개통한 역"으로 제한해 `dist`를 개통한 역끼리만 관리하면, 새 역이 개통될 때 그 역과 기존 역 사이 거리를 따로 구해야 해서 복잡해집니다. 모든 쌍을 유지하고 **경유지만** 제한하는 것이 핵심입니다.
- 합은 최대 1,200 × 1,199 × 100,000 ≈ 1.4 × 10^11이라 `long`입니다. 반면 `dist` 값은 직통 터널 시간 이하(≤ 100,000)라 `int`로 충분하고, `dist[i][k] + dist[k][j]`도 넘치지 않습니다.
- 매 단계 합을 구할 때 개통한 쌍만 고르는 부분도 O(n²)입니다. 해설 코드는 개통한 열이면 −1, 아니면 0인 마스크를 `&`로 걸어 조건문 없이 더합니다. 작은 메서드로 나눈 단순한 반복문은 JIT가 벡터 명령으로 바꿔 주어 더 빠릅니다.

## 복잡도
- 시간 O(n³), 공간 O(n²)
