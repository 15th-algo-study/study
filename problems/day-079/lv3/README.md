# [lv3] 지하철 순차 개통

새 지하철 노선망에 역 `n`개(0번 ~ `n - 1`번)가 있고, 모든 두 역 사이에 직통 터널이 뚫려 있습니다. `time[i][j]`는 `i`번 역에서 `j`번 역까지 직통 터널로 가는 데 걸리는 시간입니다. 터널은 방향마다 시간이 다를 수 있습니다.

역은 공사가 끝나는 대로 `order`에 적힌 순서로 하나씩 개통합니다. 열차는 **개통한 역에서만** 타고 내리거나 지나갈 수 있습니다. 즉 개통한 역 `s`에서 개통한 역 `e`로 가는 경로는 개통한 역들만 거쳐야 합니다. 갈아타는 시간은 없습니다.

`t`번째 역이 개통된 직후, 개통한 역 중 서로 다른 두 역 `s`, `e`의 모든 순서쌍 `(s, e)`에 대해 `s`에서 `e`까지의 최단 시간을 더한 값을 `S_t`라고 합니다. `[S_1, S_2, …, S_n]`을 return 하도록 `solution` 함수를 완성해 주세요. 값이 `int` 범위를 넘을 수 있으므로 `long[]`으로 return 합니다.

## 제한사항
- 1 ≤ `n` ≤ 1,200
- `time`은 `n` × `n` 크기입니다.
  - `i` ≠ `j`이면 1 ≤ `time[i][j]` ≤ 100,000
  - `time[i][i]`는 0 이상 100,000 이하이며 쓰지 않습니다.
- `order`는 0 ~ `n - 1`을 한 번씩 담은 배열입니다.

## 입출력 예

| time | order | result |
|---|---|---|
| [[0, 4, 1], [2, 0, 7], [3, 1, 0]] | [1, 0, 2] | [0, 6, 12] |
| [[0, 9, 2, 6], [5, 0, 7, 3], [1, 2, 0, 8], [4, 1, 9, 0]] | [3, 1, 0, 2] | [0, 4, 26, 46] |
| [[5]] | [0] | [0] |

## 입출력 예 설명
- 예 #1
  - 1번 역만 개통: 순서쌍이 없어 0
  - 0번 개통: 0 → 1은 4, 1 → 0은 2 → 6
  - 2번 개통: 0 → 1은 0 → 2 → 1(1 + 1 = 2)로 줄고, 1 → 2는 1 → 0 → 2(2 + 1 = 3)로 줄어듭니다. 0 → 1: 2, 0 → 2: 1, 1 → 0: 2, 1 → 2: 3, 2 → 0: 3, 2 → 1: 1 → 합 12
- 예 #2
  - 3, 1번 개통 뒤: 3 → 1은 1, 1 → 3은 3 → 4
  - 0번 개통 뒤: 0 → 1은 0 → 3 → 1(6 + 1 = 7)이 직통(9)보다 빠릅니다. 0 → 1: 7, 0 → 3: 6, 1 → 0: 5, 1 → 3: 3, 3 → 0: 4, 3 → 1: 1 → 합 26
  - 2번 개통 뒤: 0 → 1은 0 → 2 → 1(2 + 2 = 4), 2 → 3은 2 → 1 → 3(2 + 3 = 5), 3 → 2는 3 → 0 → 2(4 + 2 = 6)로 줄어듭니다. 12개 순서쌍의 합은 46입니다.
- 예 #3: 역이 하나뿐입니다.
