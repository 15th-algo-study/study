# [lv0] 색 섞기

그림 앱은 색 하나를 32비트 정수 하나에 담습니다. 16진수로 `0xAARRGGBB` 처럼 8비트씩 네 칸으로 나눠

- 24~31번 비트: 불투명도 A
- 16~23번 비트: 빨강 R
- 8~15번 비트: 초록 G
- 0~7번 비트: 파랑 B

를 저장합니다. 각 칸은 0~255 값입니다. 자바의 `int`는 부호가 있으므로 A가 128 이상이면 정수 값이 음수로 보입니다. 예를 들어 불투명한 빨강 `0xFFFF0000`은 `int`로 -65,536입니다.

같은 길이의 두 색 목록 `first`, `second`가 주어집니다. `i`번째 결과 색은 `first[i]`와 `second[i]`를 **칸마다 평균**(두 값을 더해 2로 나누고 소수점 아래는 버림)한 색입니다. 결과 색들을 같은 방식의 정수로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `first`의 길이 = `second`의 길이 ≤ 100,000
- `first`, `second`의 원소는 `int` 범위의 아무 정수입니다(−2,147,483,648 ~ 2,147,483,647).

## 입출력 예

| first | second | result |
|---|---|---|
| [-16776961] | [-16711936] | [-16744577] |
| [16777215] | [-16777216] | [2139062143] |
| [0, 305419896] | [0, -1] | [0, -2003195205] |

## 입출력 예 설명
- 예 #1: `-16776961` = `0xFF0000FF`(불투명한 파랑), `-16711936` = `0xFF00FF00`(불투명한 초록). 칸마다 평균하면 A = (255 + 255) / 2 = 255, R = 0, G = (0 + 255) / 2 = 127, B = (255 + 0) / 2 = 127이라 `0xFF007F7F` = -16,744,577입니다.
- 예 #2: `16777215` = `0x00FFFFFF`, `-16777216` = `0xFF000000`. 네 칸 모두 (255 + 0) / 2 = 127 = `0x7F`라 `0x7F7F7F7F` = 2,139,062,143입니다.
- 예 #3: `0`과 `0`은 `0`입니다. `305419896` = `0x12345678`과 `-1` = `0xFFFFFFFF`를 섞으면 A = (0x12 + 0xFF) / 2 = `0x88`, R = (0x34 + 0xFF) / 2 = `0x99`, G = (0x56 + 0xFF) / 2 = `0xAA`, B = (0x78 + 0xFF) / 2 = `0xBB`이라 `0x8899AABB` = -2,003,195,205입니다.
