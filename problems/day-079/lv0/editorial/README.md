# 해설 — 색 섞기

## 접근
칸 하나를 꺼내는 공식은 `(c >>> shift) & 0xFF`입니다. `shift`는 A 24, R 16, G 8, B 0.

1. 두 색에서 같은 칸을 꺼내 `(x + y) / 2`로 평균합니다. 두 값 모두 0~255라 넘칠 걱정이 없습니다.
2. 평균값을 다시 제자리로 밀어 `|`로 합칩니다: `result |= avg << shift`.

네 칸을 반복문으로 돌리면 깔끔합니다.

```java
for (int shift = 0; shift < 32; shift += 8) {
    int avg = (((a >>> shift) & 0xFF) + ((b >>> shift) & 0xFF)) / 2;
    mixed |= avg << shift;
}
```

## 주의할 점
- 음수 색에서 `a >> 24`는 부호 비트가 채워져 음수가 됩니다(`0xFF000000 >> 24`는 -1). `>>>`(부호 없는 오른쪽 밀기)를 쓰거나, `>>` 뒤에 꼭 `& 0xFF`를 붙여야 0~255가 나옵니다.
- 정수 전체를 먼저 더하고 2로 나누면(`(a + b) / 2`) 칸 사이로 올림수가 넘어가고 `int`도 넘쳐 틀립니다. 칸별로 나눠서 계산합니다.
- A 칸을 `avg << 24`로 밀면 결과가 음수가 될 수 있는데, 그것이 올바른 표현입니다.

## 복잡도
- 시간 O(n), 공간 O(n)
