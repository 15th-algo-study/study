# [lv2] 섬 여객선 시간표

섬 `n`개(0번 ~ `n - 1`번) 사이를 정기 여객선이 오갑니다. 여객선 노선은 모두 **한 방향**이고 정해진 시각에만 출발합니다.

- `ferries`의 원소 `[from, to, offset, interval, duration]`은 `from`번 섬에서 `to`번 섬으로 가는 노선입니다.
- 이 노선의 배는 시각 `offset`, `offset + interval`, `offset + 2 × interval`, … 에 출발하며(그 이전에는 없습니다), 출발한 지 `duration` 뒤에 `to`번 섬에 도착합니다.
- 섬에 도착한 시각과 같은 시각에 출발하는 배는 탈 수 있습니다. 섬에서는 얼마든지 기다릴 수 있습니다.

시각 0에 0번 섬에 있는 여행자가 `n - 1`번 섬에 도착할 수 있는 **가장 이른 시각**을 return 하도록 `solution` 함수를 완성해 주세요. 도착할 수 없으면 -1을 return 합니다. 시각이 `int` 범위를 넘을 수 있으므로 `long`으로 return 합니다.

## 제한사항
- 2 ≤ `n` ≤ 300,000
- 0 ≤ `ferries`의 길이 ≤ 500,000
- `ferries`의 원소는 `[from, to, offset, interval, duration]` 형태입니다.
  - 0 ≤ `from`, `to` < `n` (`from = to`인 유람선 노선이 있을 수 있습니다)
  - 0 ≤ `offset` ≤ 1,000,000,000
  - 1 ≤ `interval` ≤ 1,000,000,000
  - 1 ≤ `duration` ≤ 1,000,000,000

## 입출력 예

| n | ferries | result |
|---|---|---|
| 3 | [[0, 1, 0, 10, 3], [1, 2, 5, 10, 2], [0, 2, 0, 100, 30]] | 7 |
| 3 | [[0, 1, 0, 10, 3], [1, 2, 2, 100, 2], [0, 2, 0, 100, 30]] | 30 |
| 2 | [[1, 0, 0, 1, 1]] | -1 |

## 입출력 예 설명
- 예 #1: 시각 0에 0 → 1 배를 타 시각 3에 1번 섬에 내립니다. 1 → 2 배는 5, 15, … 에 출발하므로 2만큼 기다려 시각 5에 타고 시각 7에 도착합니다. 0 → 2 직항은 시각 30에 도착합니다.
- 예 #2: 1 → 2 배가 시각 2, 102, … 에 출발해서, 시각 3에 1번 섬에 내리면 102까지 기다려야 하고 104에 도착합니다. 직항을 타면 30에 도착합니다.
- 예 #3: 0번 섬에서 출발하는 노선이 없습니다.
