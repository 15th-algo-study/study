# 해설 — 섬 여객선 시간표

## 접근
간선의 비용이 고정되어 있지 않고 **도착한 시각에 따라 기다리는 시간이 달라지는** 그래프입니다. 그래도 다익스트라를 그대로 쓸 수 있습니다.

`v`번 섬에 시각 `t`에 있을 때 노선 `(v → u, offset, interval, duration)`을 타면
- 출발 시각 `dep`: `t ≤ offset`이면 `offset`, 아니면 `offset + ⌈(t − offset) / interval⌉ × interval`
- `u` 도착 시각: `dep + duration`

**왜 다익스트라가 맞는가**: 어떤 섬에 더 일찍 도착하면, 그 뒤 탈 수 있는 배는 늦게 도착했을 때 탈 수 있는 배를 모두 포함합니다(기다릴 수 있으므로). 즉 도착 시각 함수가 단조 증가(늦게 출발해서 일찍 도착하는 일이 없음)라서, 각 섬은 **가장 이른 도착 시각만** 기억하면 충분하고 이른 섬부터 확정하는 다익스트라가 정당합니다. 예 #2처럼 "1번 섬에 가장 일찍 도착"하는 것이 전체 최적이 아닐 수 있지만, 그것은 1번을 거치지 않는 다른 경로가 있기 때문이지 1번에 늦게 도착하는 게 이득이어서가 아닙니다.

`dist[0] = 0`에서 시작해 큐에서 꺼낸 섬 `v`의 노선마다 위 공식으로 도착 시각을 구해 갱신합니다. `n - 1`번을 꺼내는 순간이 답입니다.

## 주의할 점
- 올림 나눗셈은 `(t - offset + interval - 1) / interval`로 정수로만 계산합니다. `Math.ceil`과 `double`은 10^18 근처에서 정밀도가 깨집니다.
- `t < offset`인 경우를 따로 처리해야 합니다. 그냥 공식에 넣으면 음수 나눗셈이 되어 첫 배보다 이른 출발이 나옵니다.
- 배를 한 번 탈 때마다 시각이 최대 약 3 × 10^9씩 늘어 전체로는 10^15에 가까워질 수 있으므로 `long`으로 계산합니다.
- 시각을 1씩 늘려 가며 흉내 내거나, O(n²) 다익스트라를 쓰면 시간 초과입니다.

## 복잡도
- 시간 O((n + m) log m), 공간 O(n + m)
