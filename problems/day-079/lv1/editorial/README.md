# 해설 — 데이터 센터 사이 최대 대역폭

## 접근
플로이드–워셜은 "경유지 `k`를 하나씩 허용하면서 `i → k → j`로 이어 붙인 경로가 더 좋으면 바꾼다"는 틀입니다. 경로의 값을 **합**이 아니라 **최솟값**으로, 좋은 것을 **작은 값**이 아니라 **큰 값**으로 바꾸면 그대로 쓸 수 있습니다.

- `cap[i][j]`: 지금까지 허용된 경유지만 써서 `i → j`로 갈 때 얻을 수 있는 최대 대역폭 (경로가 없으면 0)
- 초기값: 케이블 `[a, b, bw]`마다 `cap[a][b] = cap[b][a] = max(기존, bw)`
- 갱신: `cap[i][j] = max(cap[i][j], min(cap[i][k], cap[k][j]))`

`i → k`와 `k → j`를 이어 붙인 경로의 대역폭은 두 구간 대역폭 중 작은 값이고, 그것이 기존 값보다 크면 바꿉니다. n³ = 2.7 × 10^7번 뒤에는 모든 질의를 표에서 바로 답합니다.

## 주의할 점
- 경로가 없는 상태를 0으로 두면 `min(0, …) = 0`이라 자연스럽게 "이어 붙일 수 없음"이 됩니다. 합을 쓰는 최단 경로처럼 INF로 초기화하면 틀립니다.
- 같은 쌍의 케이블이 여러 개면 **큰** 값을 남깁니다.
- 질의마다 그래프를 탐색하면 20만 번이라 시간 초과입니다. 모든 쌍을 미리 구해 두는 것이 핵심입니다.
- (참고) 이 값은 "최대 신장 트리 위의 경로에서 가장 작은 간선"과 같습니다. 블록 17에서 다시 만납니다.

## 복잡도
- 시간 O(n³ + m + q), 공간 O(n²)
