# [lv1] 데이터 센터 사이 최대 대역폭

데이터 센터 `n`곳(1번 ~ `n`번)이 양방향 광케이블로 이어져 있습니다. 케이블마다 한 번에 보낼 수 있는 대역폭이 정해져 있고, 데이터가 여러 케이블을 거쳐 가면 그 경로의 대역폭은 **거쳐 가는 케이블 대역폭 중 가장 작은 값**이 됩니다.

케이블 정보 `cables`와 질의 목록 `queries`가 주어집니다. 질의 `[x, y]`마다 `x`번에서 `y`번으로 데이터를 보낼 때 고를 수 있는 경로 중 **대역폭이 가장 큰 경로의 대역폭**을 구해, 질의 순서대로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. `x`에서 `y`로 가는 경로가 없으면 0입니다.

- `cables`의 원소 `[a, b, bw]`는 `a`번과 `b`번을 잇는 대역폭 `bw`의 양방향 케이블입니다. 같은 두 센터를 잇는 케이블이 여러 개일 수 있습니다.

## 제한사항
- 2 ≤ `n` ≤ 300
- 0 ≤ `cables`의 길이 ≤ 50,000
- `cables`의 원소는 `[a, b, bw]` 형태이며 1 ≤ `a`, `b` ≤ `n`, `a` ≠ `b`, 1 ≤ `bw` ≤ 1,000,000,000
- 1 ≤ `queries`의 길이 ≤ 200,000
- `queries`의 원소는 `[x, y]` 형태이며 1 ≤ `x`, `y` ≤ `n`, `x` ≠ `y`

## 입출력 예

| n | cables | queries | result |
|---|---|---|---|
| 5 | [[1, 2, 4], [2, 3, 6], [1, 3, 2], [3, 4, 9]] | [[1, 3], [1, 4], [4, 2], [1, 5]] | [4, 4, 6, 0] |
| 2 | [[1, 2, 3], [2, 1, 8]] | [[2, 1]] | [8] |

## 입출력 예 설명
- 예 #1
  - 1 → 3: 직통 케이블은 2, 1 → 2 → 3은 min(4, 6) = 4 → 4
  - 1 → 4: 1 → 2 → 3 → 4는 min(4, 6, 9) = 4, 1 → 3 → 4는 min(2, 9) = 2 → 4
  - 4 → 2: 4 → 3 → 2는 min(9, 6) = 6, 4 → 3 → 1 → 2는 min(9, 2, 4) = 2 → 6
  - 1 → 5: 5번에 이어진 케이블이 없어 0
- 예 #2: 두 케이블 중 대역폭 8인 케이블로 보냅니다.
