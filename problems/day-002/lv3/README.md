# [lv3] 압축 문서의 k번째 글자

문서를 다음 규칙으로 압축해 저장합니다.

- 영문 소문자는 그대로 씁니다.
- `x[...]`는 괄호 안의 내용을 `x`번 반복한다는 뜻입니다. `x`는 1 이상 1,000,000,000 이하의 정수이고, 숫자 바로 뒤에는 항상 `[`가 옵니다.
- 괄호는 여러 겹으로 중첩될 수 있습니다.

예를 들어 `"ab3[cd]e"`를 풀면 `"abcdcdcde"`이고, `"2[x3[yz]]"`를 풀면 `"xyzyzyzxyzyzyz"`입니다.

압축 문자열 `s`와 정수 `k`가 주어질 때, `s`를 모두 푼 문서의 `k`번째 글자(1번부터 셈)를 길이 1인 문자열로 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 100,000
- `s`는 영문 소문자, 숫자, `[`, `]`로만 이루어진 올바른 압축 문자열입니다.
  - 숫자는 0으로 시작하지 않고, 괄호 안에는 글자가 하나 이상 있습니다.
- 푼 문서의 길이는 10^18을 훨씬 넘을 수도 있습니다.
- 1 ≤ `k` ≤ min(푼 문서의 길이, 10^18)

## 입출력 예

| s | k | result |
|---|---|---|
| "ab3[cd]e" | 6 | "d" |
| "2[x3[yz]]" | 9 | "y" |
| "a1000000000[1000000000[bc]]" | 1000000000000000000 | "b" |

## 입출력 예 설명
- 예 #1: `abcdcdcde`의 6번째 글자는 `d`입니다.
- 예 #2: `xyzyzyz xyzyzyz`(공백은 설명용)의 9번째 글자는 두 번째 덩어리의 2번째 글자 `y`입니다.
- 예 #3: 푼 문서는 `a` 다음에 `bc`가 10^18번 반복되어 길이가 2×10^18 + 1입니다. 10^18번째 글자는 `bc` 반복 구간의 999,999,999,999,999,999번째 글자이고, 홀수 번째이므로 `b`입니다.
