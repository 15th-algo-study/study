# [lv2] 로봇 청소기의 발자국

직사각형 방이 문자열 배열 `grid`로 주어집니다. `grid[r]`의 `c`번째 문자가 `'.'`이면 빈 칸, `'#'`이면 가구가 있는 칸입니다. 로봇 청소기는 맨 위 왼쪽 칸 (0, 0)에서 출발해 명령 문자열 `commands`를 앞에서부터 하나씩 수행합니다.

- `'U'`: 위로 한 칸, `'D'`: 아래로 한 칸, `'L'`: 왼쪽으로 한 칸, `'R'`: 오른쪽으로 한 칸
- 이동할 칸이 방 밖이거나 가구(`'#'`)면 그 명령은 무시하고 제자리에 있습니다.

로봇이 한 번이라도 머문 서로 다른 칸의 개수(출발 칸 포함)를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `grid`의 길이(행 수) ≤ 1,000
- 1 ≤ `grid[r]`의 길이(열 수) ≤ 1,000, 모든 행의 길이는 같습니다.
- `grid`는 `'.'`과 `'#'`으로만 이루어져 있고, `grid[0]`의 0번째 문자는 항상 `'.'`입니다.
- 1 ≤ `commands`의 길이 ≤ 1,000,000
- `commands`는 `'U'`, `'D'`, `'L'`, `'R'`로만 이루어져 있습니다.

## 입출력 예

| grid | commands | result |
|---|---|---|
| ["...", ".#.", "..."] | "RRDDLLUU" | 8 |
| ["..#", "#.."] | "RRRDLUUL" | 3 |

## 입출력 예 설명
- 예 #1: 가운데 가구를 한 바퀴 돌아 출발점으로 돌아옵니다. 가구를 뺀 8칸을 모두 지납니다.
- 예 #2: (0,0) → R (0,1) → R, R은 가구에 막힘 → D (1,1) → L은 가구에 막힘 → U (0,1) → U는 벽 → L (0,0). 머문 칸은 (0,0), (0,1), (1,1) 3칸입니다.
