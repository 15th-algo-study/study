# 해설 — 로봇 청소기의 발자국

## 접근
명령을 그대로 시뮬레이션하면서, 칸마다 방문 여부를 `boolean[][]`에 기록합니다. 처음 들어가는 칸일 때만 개수를 늘립니다.

1. 다음 위치 `(nr, nc)`를 계산한다.
2. 방 밖이거나 `'#'`이면 건너뛴다.
3. 이동하고, 처음 방문이면 `count++`.

## 주의할 점
- 방문 기록을 `HashSet<String>`에 `"r,c"` 문자열로 넣으면 명령 100만 개마다 문자열을 만들고 해시를 계산해 훨씬 느립니다. 좌표가 작은 정수이므로 **2차원 배열**이 가장 빠릅니다. (`Set`을 꼭 쓰려면 `r * cols + c` 정수 키를 쓰세요.)
- 범위 검사를 `grid[nr].charAt(nc)`보다 먼저 해야 예외가 나지 않습니다.
- 막힌 명령에서도 "머문 칸"은 바뀌지 않으므로 개수가 늘지 않습니다.

## 복잡도
- 시간 O(R·C + |commands|), 공간 O(R·C)
