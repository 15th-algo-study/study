# [lv1] 같은 글자 묶기

연속해서 반복되는 글자를 "글자 + 반복 횟수"로 줄여 쓰려고 합니다. 규칙은 다음과 같습니다.

- 같은 글자가 연속된 덩어리마다 그 글자를 한 번 쓰고, 바로 뒤에 덩어리 길이를 씁니다.
- 덩어리 길이가 1이면 숫자를 쓰지 않습니다.
- 길이가 10 이상이면 숫자를 그대로(여러 자리로) 씁니다.

예를 들어 `"aaabccdddd"`는 `"a3bc2d4"`가 됩니다. 소문자 문자열 `s`를 위 규칙으로 줄인 문자열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 200,000
- `s`는 영문 소문자로만 이루어져 있습니다.

## 입출력 예

| s | result |
|---|---|
| "aaabccdddd" | "a3bc2d4" |
| "abc" | "abc" |
| "zzzzzzzzzzzz" | "z12" |

## 입출력 예 설명
- 예 #1: `aaa`→`a3`, `b`→`b`, `cc`→`c2`, `dddd`→`d4`
- 예 #2: 반복이 없으므로 그대로입니다.
- 예 #3: `z`가 12번 연속됩니다.
