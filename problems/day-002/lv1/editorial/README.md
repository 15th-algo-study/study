# 해설 — 같은 글자 묶기

## 접근
덩어리의 시작 `i`에서 같은 글자가 끝나는 곳 `j`까지 전진하고, 글자와 길이 `j - i`를 붙입니다. 다음 덩어리는 `j`에서 시작하므로 각 글자를 한 번씩만 봅니다.

## 주의할 점
- **`answer += ...`로 문자열을 이어 붙이면 안 됩니다.** 자바의 `String`은 불변이라 `+=`마다 지금까지의 문자열 전체를 복사합니다. 결과가 20만 글자면 복사량이 약 2×10^10 글자가 되어 시간 초과입니다. `StringBuilder`를 쓰세요.
- 길이가 10 이상이면 숫자가 여러 자리입니다. `(char) ('0' + count)` 같은 방식은 틀립니다. `append(int)`를 쓰면 됩니다.
- 마지막 덩어리를 빠뜨리지 않도록 주의하세요.

## 복잡도
- 시간 O(n), 공간 O(n)
