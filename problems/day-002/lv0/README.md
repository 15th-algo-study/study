# [lv0] 모음 세기

영문 알파벳과 공백으로 이루어진 문자열 `s`가 주어집니다. `s`에 들어 있는 모음(`a`, `e`, `i`, `o`, `u`)의 개수를 return 하도록 `solution` 함수를 완성해 주세요. 대문자 모음(`A`, `E`, `I`, `O`, `U`)도 모음으로 셉니다.

## 제한사항
- 1 ≤ `s`의 길이 ≤ 1,000,000
- `s`는 영문 대소문자와 공백(`' '`)으로만 이루어져 있습니다.

## 입출력 예

| s | result |
|---|---|
| "Hello World" | 3 |
| "AEIOU xyz" | 5 |

## 입출력 예 설명
- 예 #1: `e`, `o`, `o` 세 개입니다.
- 예 #2: 대문자 `A`, `E`, `I`, `O`, `U` 다섯 개입니다. `y`는 모음이 아닙니다.
