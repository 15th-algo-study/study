# [lv0] 단체 사진 줄 뒤집기

단체 사진을 찍으려고 사람들이 한 줄로 섰습니다. 줄 선 순서대로 키가 배열 `heights`에 담겨 있고, `heights[i]`는 `i`번째(0번부터 셈) 사람의 키입니다.

사진사가 `l`번째부터 `r`번째까지(양 끝 포함) 사람들의 순서를 거꾸로 세우기로 했습니다. 그 구간 바깥 사람들은 그대로 있습니다.

원래 배열 `heights`는 바꾸지 말고, 순서를 바꾼 뒤의 키 배열을 **새 배열**로 만들어 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `heights`의 길이 `n` ≤ 1,000,000
- 1 ≤ `heights`의 원소 ≤ 250
- 0 ≤ `l` ≤ `r` < `n`

## 입출력 예

| heights | l | r | result |
|---|---|---|---|
| [150, 160, 170, 180, 190] | 1 | 3 | [150, 180, 170, 160, 190] |
| [1, 2, 3] | 0 | 2 | [3, 2, 1] |
| [7, 8] | 1 | 1 | [7, 8] |

## 입출력 예 설명
- 예 #1: 1~3번째 사람 `160, 170, 180`을 거꾸로 세우면 `180, 170, 160`입니다.
- 예 #2: 전체를 뒤집습니다.
- 예 #3: `l`과 `r`이 같으면 한 사람뿐이라 바뀌는 것이 없습니다.
