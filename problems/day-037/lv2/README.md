# [lv2] 회전초밥 연속 접시

회전초밥 가게의 레일 위에 접시 `n`개가 원형으로 돌고 있습니다. 접시에는 0번부터 `n − 1`번까지 번호가 붙어 있고 `prices[i]`는 `i`번 접시의 가격입니다. 레일은 원형이라 `n − 1`번 접시 다음에는 0번 접시가 옵니다.

손님은 레일에서 **연속으로 지나가는 접시들**을 집으려 합니다. 즉 어떤 번호에서 시작해 번호 순서대로(끝에 닿으면 0번으로 이어서) 이어진 접시들만 집을 수 있습니다. 집은 접시의 가격 합은 예산 `budget`을 넘을 수 없고, 접시는 한 바퀴에 한 번만 집을 수 있으므로 최대 `n`개까지만 집습니다.

손님이 집을 수 있는 접시 수의 최댓값을 return 하도록 `solution` 함수를 완성해 주세요. 한 접시도 집을 수 없으면 0을 return 합니다.

## 제한사항
- 1 ≤ `prices`의 길이 `n` ≤ 200,000
- 1 ≤ `prices`의 원소 ≤ 1,000,000,000
- 1 ≤ `budget` ≤ 10^15 (`long`)

## 입출력 예

| prices | budget | result |
|---|---|---|
| [3, 5, 2, 4, 1] | 7 | 3 |
| [1, 9, 1, 1] | 3 | 3 |
| [2, 2, 2] | 100 | 3 |

## 입출력 예 설명
- 예 #1: 2, 3, 4번 접시 `2 + 4 + 1 = 7`로 3개를 집을 수 있습니다. 4개를 집는 어떤 연속 구간도 합이 7을 넘습니다.
- 예 #2: 2, 3번 접시 다음에 0번 접시가 이어지므로 `1 + 1 + 1 = 3`으로 3개입니다. 원형으로 이어지지 않는다고 생각하면 2개가 되어 틀립니다.
- 예 #3: 전부 집어도 예산 안이므로 3개입니다. 한 바퀴를 넘어 4개를 셀 수는 없습니다.
