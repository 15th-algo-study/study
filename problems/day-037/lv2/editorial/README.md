# 해설 — 회전초밥 연속 접시

## 접근
가격이 모두 양수이므로 구간을 늘리면 합이 커지고 줄이면 작아집니다. 이 **단조성** 덕분에 투 포인터가 됩니다.

원형은 배열을 **두 번 이어 붙여** 길이 `2n`의 직선으로 바꿉니다. 그러면 원형의 연속 구간은 두 배 배열에서 시작이 `0 ≤ s < n`이고 길이가 `n` 이하인 구간과 일대일로 대응합니다.

- `right`를 한 칸씩 늘리며 `sum += a[right]`.
- `sum > budget`이면 `left`를 올리며 `sum -= a[left]`.
- 길이 `right − left + 1`이 `n`을 넘으면 `left`를 하나 올립니다 (한 바퀴 제한).
- 매 단계 길이의 최댓값을 기록합니다.

`left`는 줄어들지 않으므로 두 포인터 모두 최대 `2n`번만 움직입니다. 실제로 배열을 두 배로 만들 필요 없이 `prices[i % n]`으로 읽어도 됩니다.

## 주의할 점
- `budget`이 전체 합 이상이면 답은 `n`입니다. 길이 제한을 빼먹으면 `2n`이 나옵니다.
- 합은 `long`입니다. 접시 20만 개 × 10억이면 2 × 10^14입니다.
- 어떤 접시 하나도 예산을 넘으면 `left`가 `right`를 지나쳐 길이가 0이 됩니다. 그 경우에도 `sum`이 0으로 돌아오도록 `left ≤ right` 조건을 쓰지 말고 `sum > budget`인 동안 계속 빼세요.
- 시작점마다 한 바퀴를 새로 도는 O(n²) 풀이는 예산이 넉넉한 large 케이스에서 4 × 10^10번 연산이라 시간 초과입니다.

## 복잡도
- 시간 O(n), 공간 O(1)
