# [lv1] 꽃밭 물주기

화단 `n`개가 한 줄로 늘어선 꽃밭이 있습니다. 화단은 0번부터 `n − 1`번까지이고, 처음에는 모두 물을 받지 않은 상태입니다.

물주기 기록 `watering`이 주어집니다. 각 기록은 `[s, len, amount]`로, `s`번 화단부터 오른쪽으로 `len`개의 화단에 각각 `amount`리터씩 물을 주었다는 뜻입니다. 호스가 꽃밭 끝을 넘어가면 마지막 화단까지만 물을 줍니다.

모든 기록을 반영한 뒤, 각 화단이 받은 물의 총량을 화단 번호 순서대로 담은 `long` 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 1,000,000
- 1 ≤ `watering`의 길이 ≤ 200,000
- 0 ≤ `s` < `n`
- 1 ≤ `len` ≤ 1,000,000
- 1 ≤ `amount` ≤ 1,000,000
- 한 화단이 받는 총량이 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| n | watering | result |
|---|---|---|
| 5 | [[1, 3, 2], [0, 2, 5], [3, 10, 1]] | [5, 7, 2, 3, 1] |
| 3 | [[2, 1, 4]] | [0, 0, 4] |
| 4 | [[0, 4, 1], [0, 4, 1]] | [2, 2, 2, 2] |

## 입출력 예 설명
- 예 #1
  - `[1, 3, 2]`: 1, 2, 3번 화단에 2리터씩 → [0, 2, 2, 2, 0]
  - `[0, 2, 5]`: 0, 1번 화단에 5리터씩 → [5, 7, 2, 2, 0]
  - `[3, 10, 1]`: 3번부터 10개이지만 꽃밭이 4번에서 끝나므로 3, 4번만 → [5, 7, 2, 3, 1]
- 예 #2: 2번 화단 하나에만 물을 줍니다.
- 예 #3: 전체에 1리터씩 두 번 줍니다.
