# 해설 — 꽃밭 물주기

## 접근
기록마다 `len`개 화단을 돌며 더하면 최악 20만 × 100만 번이라 시간 초과입니다. **차분 배열**을 씁니다.

- 길이 `n + 1`인 배열 `diff`를 0으로 둡니다.
- 구간 `[s, e]`(`e = min(n − 1, s + len − 1)`)에 `amount`를 더하는 작업은 `diff[s] += amount`, `diff[e + 1] -= amount` 두 번의 갱신으로 적어 둡니다.
- 모든 기록을 적은 뒤 `diff`를 앞에서부터 누적하면 각 화단의 총량이 됩니다: `water[i] = water[i − 1] + diff[i]`.

구간 더하기를 "시작에서 켜고 끝 다음에서 끄는" 표시로 바꾸고, 마지막에 한 번만 누적하는 것이 핵심입니다.

## 주의할 점
- `s + len`이 `n`을 넘으면 끝을 `n − 1`로 잘라야 합니다. 잘라도 `e + 1 ≤ n`이므로 `diff`는 길이 `n + 1`이면 충분합니다.
- `s + len`은 최대 2 × 10^6이라 `int`로 괜찮지만, 총량은 20만 × 100만 = 2 × 10^11이라 `diff`와 결과 모두 `long`이어야 합니다.
- 누적은 `i = 1`부터 시작하고 `water[0] = diff[0]`입니다 (또는 변수 하나에 계속 더해 가며 채웁니다).

## 복잡도
- 시간 O(n + m) (m = 기록 수), 공간 O(n)
