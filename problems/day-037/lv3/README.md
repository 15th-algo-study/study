# [lv3] 경사로 흙 쌓기

조경 공사장에 길이 `n`의 평평한 땅이 있습니다. 땅은 0번부터 `n − 1`번까지의 칸으로 나뉘고, 처음 높이는 모두 0입니다.

덤프트럭이 경사로를 만들기 위해 다음과 같이 흙을 쌓습니다. 작업 기록 `works`의 각 원소는 `[s, len, t]`이고, `s`번 칸부터 오른쪽으로 `len`개의 칸에 차례로 `t`, `2t`, `3t`, … 톤의 흙을 쌓는다는 뜻입니다. 즉 `s + i`번 칸에 `(i + 1) × t`톤을 쌓습니다 (0 ≤ i < len). 땅의 끝을 넘어가면 마지막 칸까지만 쌓습니다.

모든 작업이 끝난 뒤 각 칸에 쌓인 흙의 양(톤)을 칸 번호 순서대로 담은 `long` 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `n` ≤ 1,000,000
- 1 ≤ `works`의 길이 ≤ 200,000
- 0 ≤ `s` < `n`
- 1 ≤ `len` ≤ 1,000,000
- 1 ≤ `t` ≤ 1,000
- 한 칸에 쌓이는 양이 `int` 범위를 넘을 수 있습니다.

## 입출력 예

| n | works | result |
|---|---|---|
| 6 | [[1, 3, 2], [0, 2, 1]] | [1, 4, 4, 6, 0, 0] |
| 4 | [[2, 5, 3]] | [0, 0, 3, 6] |
| 3 | [[0, 3, 1], [0, 3, 1]] | [2, 4, 6] |

## 입출력 예 설명
- 예 #1
  - `[1, 3, 2]`: 1, 2, 3번 칸에 2, 4, 6톤 → [0, 2, 4, 6, 0, 0]
  - `[0, 2, 1]`: 0, 1번 칸에 1, 2톤 → [1, 4, 4, 6, 0, 0]
- 예 #2: 2번 칸부터 5칸이지만 땅이 3번 칸에서 끝나므로 2, 3번 칸에 3, 6톤만 쌓입니다.
- 예 #3: 같은 경사로를 두 번 쌓습니다.
