# 해설 — 경사로 흙 쌓기

## 접근
칸마다 직접 더하면 전체 작업 길이의 합(최대 2 × 10^11)만큼 걸려 시간 초과입니다.

구간에 **같은 값**을 더하는 것은 차분 배열 한 번으로 됩니다. 이 문제는 구간에 `t, 2t, 3t, …` 처럼 **등차수열**을 더합니다. 등차수열은 "차분이 상수인 수열"이므로, **차분을 한 번 더** 하면 상수 몇 개로 표현됩니다.

작업이 구간 `[s, e]`(`e = min(n − 1, s + len − 1)`, 길이 `L = e − s + 1`)에 `t, 2t, …, Lt`를 더한다고 합시다.

1. 더해지는 양 `A[x]`의 1차 차분 `D1[x] = A[x] − A[x − 1]`은 `s ≤ x ≤ e`에서 `t`, `x = e + 1`에서 `−Lt`, 나머지는 0입니다.
2. `D1`의 차분 `D2[x] = D1[x] − D1[x − 1]`은 세 자리만 0이 아닙니다.
   - `D2[s] += t`
   - `D2[e + 1] −= (L + 1) × t`
   - `D2[e + 2] += L × t`

모든 작업을 `D2`에 O(1)씩 기록한 뒤, `D2`를 두 번 누적하면 (첫 누적 → `D1`, 두 번째 누적 → `A`) 최종 높이가 나옵니다.

예 #2로 확인: `n = 4`, 구간 `[2, 3]`, `L = 2`, `t = 3` → `D2[2] = 3`, `D2[4] = −9`, `D2[5] = 6`. 한 번 누적하면 `D1 = [0, 0, 3, 3, −6, 0]`, 다시 누적하면 `[0, 0, 3, 6, 0, 0]`이고 앞 4칸이 답입니다.

## 주의할 점
- `e + 2`는 최대 `n + 1`이므로 `D2`의 길이는 `n + 2`로 잡습니다.
- `(L + 1) × t`는 최대 약 10^9, 한 칸의 최종 높이는 최대 2 × 10^14라 모든 배열이 `long`이어야 합니다.
- 두 번째 누적에서 중간값(1차 차분의 누적)이 음수가 될 수 있지만 마지막 결과는 0 이상입니다. 음수가 보여도 당황하지 마세요.
- 구간을 끝에서 자를 때 `L`도 잘린 길이로 다시 계산해야 합니다. 원래 `len`으로 `D2[e + 1]`을 적으면 틀립니다.

## 복잡도
- 시간 O(n + m) (m = 작업 수), 공간 O(n)
