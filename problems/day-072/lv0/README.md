# [lv0] 트랙터 밭갈이 순서

`rows`행 `cols`열로 나뉜 직사각형 밭을 트랙터 한 대가 갈아엎습니다. 트랙터는 다음 순서로 한 칸씩 지나갑니다.

- 0번 행(맨 위 행)을 **왼쪽에서 오른쪽으로** 지나갑니다.
- 행 끝에 닿으면 바로 아래 행으로 내려가 **오른쪽에서 왼쪽으로** 지나갑니다.
- 이렇게 행이 바뀔 때마다 방향을 반대로 바꾸며 마지막 행까지 지나갑니다.

트랙터가 처음 지나는 칸이 1번, 그다음 칸이 2번, …, 마지막 칸이 `rows × cols`번입니다. 각 칸에 그 칸을 지나는 순번을 적은 `rows`행 `cols`열의 2차원 배열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `rows`, `cols` ≤ 1,000

## 입출력 예

| rows | cols | result |
|---|---|---|
| 3 | 4 | [[1, 2, 3, 4], [8, 7, 6, 5], [9, 10, 11, 12]] |
| 1 | 5 | [[1, 2, 3, 4, 5]] |
| 4 | 1 | [[1], [2], [3], [4]] |

## 입출력 예 설명
- 예 #1: 0번 행은 1~4를 왼쪽부터, 1번 행은 5~8을 오른쪽부터, 2번 행은 9~12를 다시 왼쪽부터 적습니다.
- 예 #2: 행이 하나뿐이라 왼쪽에서 오른쪽으로 한 번 지나갑니다.
- 예 #3: 열이 하나뿐이면 방향이 바뀌어도 같은 칸을 지나므로 위에서부터 1, 2, 3, 4입니다.
