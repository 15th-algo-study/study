# 해설 — 트랙터 밭갈이 순서

## 접근
번호 `num`을 1부터 하나씩 늘려 가며 칸을 채웁니다. 행 번호가 짝수인지 홀수인지에 따라 열을 도는 방향만 바꾸면 됩니다.

- 짝수 행(0, 2, 4, …): 열 `c = 0, 1, …, cols-1` 순서로 채웁니다.
- 홀수 행(1, 3, 5, …): 열 `c = cols-1, cols-2, …, 0` 순서로 채웁니다.

반복문을 둘로 나누는 대신, 한 반복문 안에서 "실제로 채울 열"을 `r % 2 == 0 ? c : cols - 1 - c`로 계산해도 됩니다.

## 주의할 점
- 열 인덱스를 뒤집을 때는 `cols - c`가 아니라 `cols - 1 - c`입니다. 인덱스는 0부터 `cols - 1`까지입니다.
- 번호는 계산식 `r * cols + c + 1`(짝수 행)과 `r * cols + (cols - c)`(홀수 행)로 바로 구해도 됩니다. 최대 10^6이라 `int`로 충분합니다.

## 복잡도
- 시간 O(rows × cols), 공간 O(rows × cols) (결과 배열)
