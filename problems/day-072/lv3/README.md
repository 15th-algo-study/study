# [lv3] 탐사선 화물 싣기

심우주 탐사선에 실을 화물을 고르고 있습니다. 화물은 `n`개이며, `i`번 화물의 무게는 `weights[i]`그램, 연구 가치는 `values[i]`입니다. 탐사선 화물칸에는 무게 합이 `limit`그램 이하가 되도록만 실을 수 있습니다.

- 각 화물은 통째로 싣거나 싣지 않습니다. 쪼갤 수 없고, 같은 화물을 두 번 실을 수도 없습니다.
- 실은 화물의 연구 가치 합을 **최대**로 하려고 합니다.
- 연구 가치 합이 최대가 되는 방법이 여러 가지라면, 그중 무게 합이 **가장 가벼운** 방법을 고릅니다.

`[가치 합의 최댓값, 그때의 최소 무게 합]`을 return 하도록 `solution` 함수를 완성해 주세요. 실을 수 있는 화물이 하나도 없으면 `[0, 0]`을 return 합니다.

## 제한사항
- 1 ≤ `weights`의 길이 = `values`의 길이 = `n` ≤ 100
- 1 ≤ `weights[i]` ≤ 1,000,000,000
- 1 ≤ `values[i]` ≤ 1,000
- 1 ≤ `limit` ≤ 1,000,000,000

## 입출력 예

| weights | values | limit | result |
|---|---|---|---|
| [300000000, 400000000, 500000000] | [3, 5, 6] | 800000000 | [9, 800000000] |
| [5, 2, 2, 4] | [6, 3, 3, 6] | 9 | [12, 8] |
| [10, 20] | [5, 5] | 9 | [0, 0] |

## 입출력 예 설명
- 예 #1: 0번과 2번 화물을 실으면 무게 8억 그램, 가치 9입니다. 0번과 1번은 가치 8, 1번과 2번은 무게 9억 그램이라 실을 수 없습니다.
- 예 #2: 가치 12를 만드는 방법은 {0, 3}번(무게 9), {0, 1, 2}번(무게 9), {1, 2, 3}번(무게 8) 세 가지이고, 가장 가벼운 것은 8그램입니다.
- 예 #3: 어느 화물도 9그램 이하가 아니어서 아무것도 실을 수 없습니다.
