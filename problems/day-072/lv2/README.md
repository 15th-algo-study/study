# [lv2] 산 모양 연등 행렬

절 마당에 연등 `n`개가 한 줄로 걸려 있습니다. 배열 `heights`의 `i`번째 값은 왼쪽에서 `i`번째 연등이 걸린 높이입니다.

몇 개의 연등을 떼어 내고 남은 연등들이 **산 모양**이 되게 하려고 합니다. 연등의 순서는 바꿀 수 없습니다. 남은 연등을 왼쪽부터 `h1, h2, …, hk`라고 할 때, 산 모양은 다음을 뜻합니다.

- 어떤 위치 `p`(1 ≤ `p` ≤ `k`)가 있어서 `h1 < h2 < … < hp`이고 `hp > hp+1 > … > hk`입니다.
- 즉 높이가 **엄격히 올라가다가 엄격히 내려갑니다.** 같은 높이가 이웃하면 안 됩니다.
- 올라가는 부분이나 내려가는 부분 중 한쪽이 없어도 됩니다. 계속 올라가기만 하거나 내려가기만 해도 산 모양이며, 연등 하나도 산 모양입니다.

산 모양이 되도록 남길 수 있는 **연등의 최대 개수**를 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `heights`의 길이 `n` ≤ 5,000
- 1 ≤ `heights`의 원소 ≤ 1,000,000,000

## 입출력 예

| heights | result |
|---|---|
| [1, 3, 2, 5, 4, 2, 1] | 6 |
| [5, 4, 3, 3, 1] | 4 |
| [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5] | 7 |

## 입출력 예 설명
- 예 #1: 왼쪽에서 세 번째 연등(높이 2)을 떼면 1, 3, 5, 4, 2, 1이 남아 5가 꼭대기인 산 모양입니다. 7개를 모두 남기면 3 다음에 2로 내려갔다가 5로 다시 올라가므로 산 모양이 아닙니다.
- 예 #2: 같은 높이 3이 둘 있으므로 하나를 떼어 5, 4, 3, 1을 남깁니다. 내려가기만 하는 산 모양입니다.
- 예 #3: 3, 4, 5, 9, 6, 5, 3을 남기면 9가 꼭대기인 산 모양이 됩니다. 8개 이상 남길 수는 없습니다.
