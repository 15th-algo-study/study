# 해설 — 산 모양 연등 행렬

## 접근
꼭대기 연등 `p`를 정하면, 산 모양은 "**`p`에서 끝나는** 가장 긴 엄격 증가 부분 수열"과 "**`p`에서 시작하는** 가장 긴 엄격 감소 부분 수열"을 이어 붙인 것입니다. 두 부분은 꼭대기 하나를 공유합니다.

1. `up[i]` = `i`번 연등에서 끝나는 가장 긴 엄격 증가 부분 수열의 길이
   - `up[i] = 1 + max(up[j])` (`j < i`이고 `heights[j] < heights[i]`인 모든 `j`, 없으면 0)
2. `down[i]` = `i`번 연등에서 시작하는 가장 긴 엄격 감소 부분 수열의 길이
   - 오른쪽에서 왼쪽으로: `down[i] = 1 + max(down[j])` (`j > i`이고 `heights[j] < heights[i]`)
3. 답 = `max(up[i] + down[i] - 1)` (꼭대기를 두 번 셌으므로 1을 뺌)

`up`은 왼쪽부터, `down`은 오른쪽부터 채우면 필요한 값이 항상 먼저 계산되어 있습니다.

**왜 맞을까?** 산 모양의 꼭대기를 `p`라 하면 왼쪽 부분과 오른쪽 부분은 서로 독립입니다. 왼쪽은 `p`보다 앞의 연등만, 오른쪽은 뒤의 연등만 쓰므로 각각 최대로 길게 고르면 합도 최대입니다.

## 주의할 점
- 모든 부분집합을 확인하면 2^5000가지라 불가능합니다.
- 같은 높이는 이웃할 수 없으므로 비교는 `<`(엄격)입니다. `≤`를 쓰면 예 #2에서 5가 나옵니다.
- 꼭대기를 빼지 않으면 1만큼 크게 나옵니다.
- O(n²) = 2,500만 번 비교라 충분히 빠릅니다. (`up`/`down`을 이분 탐색 LIS로 O(n log n)에 구할 수도 있습니다.)

## 복잡도
- 시간 O(n²), 공간 O(n)
