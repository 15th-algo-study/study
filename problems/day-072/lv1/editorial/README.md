# 해설 — 두 새의 노래

## 접근
**최장 공통 부분 수열(LCS)** 의 길이를 구하는 문제입니다. 두 문자열의 "앞부분"끼리의 답을 2차원 표에 채웁니다.

- `len[i][j]` = `songA`의 앞 `i`글자와 `songB`의 앞 `j`글자의 가장 긴 공통 가락 길이
- `i = 0`이거나 `j = 0`이면 0
- `songA`의 `i`번째 글자와 `songB`의 `j`번째 글자가 **같으면** 그 글자를 공통 가락의 끝으로 씁니다: `len[i][j] = len[i-1][j-1] + 1`
- **다르면** 둘 중 하나는 공통 가락의 끝이 될 수 없으므로 하나를 버립니다: `len[i][j] = max(len[i-1][j], len[i][j-1])`

답은 `len[n][m]`입니다. 표를 위에서 아래로, 왼쪽에서 오른쪽으로 채우면 필요한 칸이 항상 먼저 채워져 있습니다.

## 주의할 점
- 각 글자를 고를지 말지 모두 시도하는 재귀는 지수 시간이라 길이 3,000에서 끝나지 않습니다.
- 문자열 인덱스는 0부터이므로 `i`번째 글자는 `charAt(i - 1)`입니다. 표 크기를 `(n + 1) × (m + 1)`로 잡아 0행·0열을 "빈 문자열"로 쓰면 경계 처리가 사라집니다.
- 매 칸에서 `charAt`을 부르는 대신 `toCharArray()`로 바꿔 두면 조금 더 빠릅니다.
- 표는 약 900만 칸(`int` 36MB)입니다. 바로 윗행만 쓰므로 1차원 배열 두 개로 줄일 수도 있습니다.

## 복잡도
- 시간 O(n × m), 공간 O(n × m) (두 줄만 쓰면 O(m))
