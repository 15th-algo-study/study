# [lv1] 두 새의 노래

숲에서 새 두 마리의 노래를 녹음해 음 이름을 알파벳으로 받아 적었습니다. 첫 번째 새의 노래는 문자열 `songA`, 두 번째 새의 노래는 문자열 `songB`입니다.

두 노래에서 **공통 가락**을 찾으려고 합니다. 공통 가락은 다음 조건을 만족하는 문자열입니다.

- `songA`에서 음 몇 개를 골라 **순서를 바꾸지 않고** 이어 붙여 만들 수 있습니다. 고른 음들은 서로 붙어 있지 않아도 됩니다.
- `songB`에서도 같은 방법으로 만들 수 있습니다.

가장 긴 공통 가락의 **길이**를 return 하도록 `solution` 함수를 완성해 주세요. 공통으로 나오는 음이 하나도 없으면 0을 return 합니다.

## 제한사항
- 1 ≤ `songA`의 길이, `songB`의 길이 ≤ 3,000
- `songA`와 `songB`는 알파벳 소문자로만 이루어져 있습니다.

## 입출력 예

| songA | songB | result |
|---|---|---|
| "cdecdg" | "ecdgc" | 4 |
| "aaaa" | "aa" | 2 |
| "abc" | "def" | 0 |

## 입출력 예 설명
- 예 #1: `"ecdg"`는 `songA`의 3, 4, 5, 6번째 음(`e`, `c`, `d`, `g`)으로도, `songB`의 앞 네 음으로도 만들 수 있습니다. `songB` 전체 `"ecdgc"`는 `songA`에서 `g` 뒤에 `c`가 없어 만들 수 없으므로 답은 4입니다.
- 예 #2: `"aa"`가 가장 긴 공통 가락입니다.
- 예 #3: 공통으로 나오는 음이 없습니다.
