# [lv3] 갯벌 조개잡이

밀물이 들어오는 갯벌에서 조개를 캐고 있습니다. 갯벌을 격자 모양의 지도 `flat`으로 나타냈고, `flat[r]`의 `c`번째 문자가 (r, c) 칸입니다.

- `S`: 내가 조개를 캐고 있는 갯벌 칸 (정확히 하나)
- `.`: 갯벌
- `W`: 처음부터 바닷물에 잠긴 칸
- `L`: 육지. 물이 들어오지 않는 안전한 곳입니다.
- `#`: 바위. 물도 사람도 들어갈 수 없습니다.

**밀물**: 0분에는 `W` 칸만 잠겨 있습니다. 1분이 지날 때마다, 잠긴 칸과 상하좌우로 붙어 있는 갯벌 칸(`.`, `S`)이 모두 잠깁니다. 육지와 바위는 잠기지 않습니다.

**나의 움직임**: 0분부터 `S` 칸에서 조개를 캐다가, `w`분에 캐기를 멈추고 걷기 시작합니다. 그 뒤로는 1분에 한 칸씩 상하좌우로 붙은 갯벌이나 육지 칸으로 걸어갑니다. 지도 밖, 바위, 잠긴 칸으로는 갈 수 없습니다. 더 정확히는 다음을 지켜야 합니다.

- 조개를 캐는 동안(`0`분 ~ `w`분) `S` 칸이 잠기면 안 됩니다. 즉 `S` 칸이 잠기는 시각은 `w`보다 커야 합니다.
- `w + i`분에 도착하는 갯벌 칸은, 그 칸이 잠기는 시각이 `w + i`보다 커야 합니다. (물과 내가 같은 분에 도착하면 갈 수 없습니다.)
- 육지 칸에 도착하면 안전합니다.

`w`는 0 이상 `limit` 이하의 정수입니다. 안전하게 육지에 도착할 수 있는 **가장 큰 `w`**를 return 하도록 `solution` 함수를 완성해 주세요. `w = 0`이어도 육지에 갈 수 없으면 -1을 return 합니다.

## 제한사항
- 1 ≤ `flat`의 길이 ≤ 1,000
- 1 ≤ 각 `flat[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같습니다.
- `flat`은 `S`, `.`, `W`, `L`, `#`로만 이루어지며 `S`는 정확히 한 번 나옵니다.
- 0 ≤ `limit` ≤ 1,000,000,000

## 입출력 예

| flat | limit | result |
|---|---|---|
| ["W..S.L"] | 10 | 2 |
| ["L..", "##.", "S..", "W.."] | 100 | 0 |
| ["S.L"] | 7 | 7 |

## 입출력 예 설명
- 예 #1: 갯벌 (0,1), (0,2), (0,3), (0,4)는 각각 1, 2, 3, 4분에 잠깁니다. `w = 2`면 2분에 `S`를 떠나 3분에 (0,4), 4분에 육지에 도착합니다. `w = 3`이면 3분에 `S`가 잠깁니다.
- 예 #2: `S`는 1분에 잠기므로 바로 떠나야 합니다. (2,1) → (2,2) → (1,2) → (0,2) → (0,1) → (0,0)으로 가며 각 칸에 물보다 1분씩 먼저 도착합니다.
- 예 #3: 바닷물이 없으므로 `limit`까지 캐도 됩니다.
