# [lv2] 장보기 순서 정하기

전통 시장을 격자 모양의 지도 `market`으로 나타냈습니다. `market[r]`의 `c`번째 문자가 (r, c) 칸이며, 각 문자의 뜻은 다음과 같습니다.

- `S`: 시장 입구 (정확히 하나)
- `E`: 시장 출구 (정확히 하나)
- `P`: 오늘 꼭 들러야 하는 가게
- `.`: 지나갈 수 있는 길
- `#`: 좌판이 놓여 지나갈 수 없는 칸

입구에서 출발해 한 번에 상하좌우로 붙은 칸으로 한 칸씩 움직입니다. `#` 칸과 지도 밖으로는 갈 수 없고, `S`, `E`, `P` 칸은 길처럼 지나갈 수 있습니다. 가게 칸을 한 번이라도 밟으면 그 가게에 들른 것입니다. 들르는 순서는 자유입니다.

**모든 가게에 들른 뒤 출구에 도착**하기까지의 최소 이동 횟수를 return 하도록 `solution` 함수를 완성해 주세요. 모든 가게를 들르기 전에 출구 칸을 지나가는 것은 괜찮습니다. 불가능하면 -1을 return 합니다.

## 제한사항
- 1 ≤ `market`의 길이 ≤ 1,000
- 1 ≤ 각 `market[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같습니다.
- `market`은 `S`, `E`, `P`, `.`, `#`로만 이루어지며 `S`와 `E`는 각각 정확히 한 번 나옵니다.
- `P`는 0개 이상 7개 이하입니다.

## 입출력 예

| market | result |
|---|---|
| ["S.P", "...", "P.E"] | 8 |
| ["SPE"] | 2 |
| ["S.E", "###", "P.."] | -1 |

## 입출력 예 설명
- 예 #1: 입구에서 (0,2) 가게까지 2번, (2,0) 가게까지 4번, 출구까지 2번으로 8번입니다. 가게 순서를 바꿔도 8번입니다.
- 예 #2: 입구에서 오른쪽으로 가며 가게를 지나 출구에 도착합니다.
- 예 #3: 가게가 좌판에 막혀 들를 수 없습니다.
