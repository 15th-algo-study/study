# 해설 — 뜨개질 도안 풀기

## 접근
도안을 앞에서부터 한 글자씩 읽습니다.

- 숫자 글자면 지금까지 읽은 수에 이어 붙입니다: `count = count * 10 + (ch - '0')`. 예를 들어 `'1'`, `'2'`를 차례로 읽으면 1 → 12가 됩니다.
- 영문 소문자면 `count`번(수가 없었다면 1번) 그 글자를 결과에 붙이고 `count`를 0으로 되돌립니다.

반복 횟수는 1 이상이므로 "`count`가 0이면 수가 없었다"로 구분할 수 있습니다.

## 주의할 점
- `"12p"`의 `12`를 1과 2로 따로 읽으면 안 됩니다. 숫자가 이어지는 동안 `count * 10 + 숫자`로 쌓아야 합니다.
- `ch - '0'` 대신 `ch`를 그대로 더하면 글자 코드(`'1'`은 49)가 더해집니다.
- 결과를 `answer += ch`로 붙이면 붙일 때마다 문자열 전체를 복사해 O(결과 길이²)입니다. 결과가 100만 글자면 시간 초과이므로 `StringBuilder`를 씁니다.
- 반복 횟수는 결과 길이 이하(100만 이하)라 `int`로 충분합니다.

## 복잡도
- 시간 O(n + 결과 길이), 공간 O(결과 길이)
