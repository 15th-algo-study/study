# [lv0] 뜨개질 도안 풀기

뜨개질 도안은 뜨는 방법(코의 종류)을 영문 소문자 하나로 쓰고, 같은 코를 여러 번 반복할 때는 그 앞에 반복 횟수를 수로 붙여 줄여 씁니다. 예를 들어 `"3k12p"`는 `k`를 3번, 이어서 `p`를 12번 뜨라는 뜻입니다. 앞에 수가 없는 글자는 한 번만 뜹니다.

줄여 쓴 도안 `pattern`이 주어질 때, 반복을 모두 풀어 쓴 문자열을 return 하도록 `solution` 함수를 완성해 주세요.

## 제한사항
- 1 ≤ `pattern`의 길이 ≤ 1,000,000
- `pattern`은 영문 소문자와 숫자로만 이루어집니다.
- 수 바로 다음에는 반드시 영문 소문자가 옵니다. (`pattern`은 숫자로 끝나지 않습니다.)
- 반복 횟수는 1 이상이며 0으로 시작하지 않습니다.
- 풀어 쓴 문자열의 길이는 1,000,000 이하입니다.

## 입출력 예

| pattern | result |
|---|---|
| "3k12p" | "kkkpppppppppppp" |
| "ab2c" | "abcc" |
| "10x1y" | "xxxxxxxxxxy" |

## 입출력 예 설명
- 예 #1: `k` 3번과 `p` 12번입니다. `12`는 1과 2가 아니라 십이로 읽습니다.
- 예 #2: `a`, `b`는 앞에 수가 없어 한 번씩, `c`는 2번입니다.
- 예 #3: `x` 10번, `y` 1번입니다.
