# [lv1] 한지 위의 두 잉크

한지 위에 빨간 잉크와 파란 잉크를 몇 방울 떨어뜨렸습니다. 한지를 격자 모양의 지도 `paper`로 나타냈고, `paper[r]`의 `c`번째 문자가 (r, c) 칸입니다.

- `R`: 빨간 잉크를 떨어뜨린 칸
- `B`: 파란 잉크를 떨어뜨린 칸
- `.`: 아직 마른 칸
- `#`: 기름을 먹여 잉크가 스미지 않는 칸

잉크는 1분마다 한꺼번에 번집니다.

- 1분이 지날 때마다, 빨간 칸과 상하좌우로 붙은 마른 칸은 빨간색이 되고, 파란 칸과 상하좌우로 붙은 마른 칸은 파란색이 됩니다.
- 같은 1분 동안 빨강과 파랑이 **동시에** 스며드는 마른 칸은 **보라색**이 됩니다. 보라색 칸은 더 이상 번지지 않습니다.
- 이미 물든 칸(빨강·파랑·보라)의 색은 바뀌지 않습니다. `#` 칸과 한지 밖으로는 번지지 않습니다.

더 이상 아무 칸도 물들지 않을 때, 빨간 칸의 수, 파란 칸의 수, 보라 칸의 수를 차례로 담은 배열을 return 하도록 `solution` 함수를 완성해 주세요. 처음 잉크를 떨어뜨린 칸도 셉니다.

## 제한사항
- 1 ≤ `paper`의 길이 ≤ 1,000
- 1 ≤ 각 `paper[r]`의 길이 ≤ 1,000
- 모든 줄의 길이는 같습니다.
- `paper`는 `R`, `B`, `.`, `#`로만 이루어집니다. `R`이나 `B`가 하나도 없을 수도 있습니다.

## 입출력 예

| paper | result |
|---|---|
| ["R...B"] | [2, 2, 1] |
| ["R..B"] | [2, 2, 0] |
| ["R.#", "..B", "#.."] | [3, 4, 0] |

## 입출력 예 설명
- 예 #1: 1분 뒤 (0,1)은 빨강, (0,3)은 파랑이 됩니다. 2분 뒤 (0,2)에는 두 색이 동시에 스며들어 보라가 됩니다.
- 예 #2: 1분 뒤 (0,1)은 빨강, (0,2)는 파랑이 되고 끝납니다.
- 예 #3: 1분 뒤 빨강은 (0,1), (1,0)으로, 파랑은 (1,1), (2,2)로 번집니다. 2분 뒤 파랑이 (2,1)로 번집니다. 빨강 3칸, 파랑 4칸입니다.
